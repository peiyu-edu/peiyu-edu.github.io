简单的小数加减法

买一个 0.9 元的卷笔刀和一支 0.5 元的铅笔一共多少钱？为什么列竖式一定要把小数点对齐？

文具店里卷笔刀 0.9 元，铅笔 0.5 元，自动铅笔 1.3 元。列竖式计算小数加减法时，最关键的第一步是什么？

对！小数点左边是「元」，右边第一位是「角」。只有把小数点对齐，才是元对元、角对角，相同单位的数才能直接相加减！

1. 小数竖式演示台：看清进位与退位

点下面的算式按钮，看竖式里红虚线上的三个小数点怎么对齐，以及角位满十进一、不够减借一当十的过程。

计算整数减小数（如 5 − 1.6）时，可以先把整数 5 写成 5.0（5 元 0 角），再对齐小数点相减。

自己试试

一支自动铅笔 1.3 元，一支木头铅笔 0.5 元，自动铅笔比木头铅笔贵多少元？

1.3 − 0.5 = 0.8（元）。

小数加减列竖式，小数点一定要对齐；从最右边算起，满十进一、不够减退一，得数别忘点上小数点！

两个容易错的地方

✗ 整数部分减完剩 0 时漏写 0 算 1.5 − 0.8 时，写成“.7”或“7”。
✓ 整数部分为 0 时要写 0 占位 1.5 − 0.8 = 0.7，小数点左边写 0。
✗ 整数减小数时把整数和小数部分对齐 算 10 − 3.8 时，错把 0 和 8 对齐算成 3.2。
✓ 把整数添上“.0”再对齐相减 10 看作 10.0，10.0 − 3.8 = 6.2。

直接用

1. 直接写得数：1.4 + 2.5 =（ ）。

1.4 + 2.5 = 3.9。

2. 算一算：0.7 + 0.8 =（ ）。

0.7 + 0.8 = 1.5。

3. 列竖式算一算：3.6 + 2.7 =（ ）。

3.6 + 2.7 = 6.3。

容易错

4. 算一算：1.5 − 0.8 =（ ）。

1.5 − 0.8 = 0.7。

5. 一根绳子长 6.4 米，剪去 3.6 米后，还剩（ ）米。

6.4 − 3.6 = 2.8（米）。

想一想

6. 妈妈付给收银员 10 元，买了一盒 3.8 元的彩泥，应找回（ ）元。

把 10 元看成 10.0 元：10.0 − 3.8 = 6.2（元）。
