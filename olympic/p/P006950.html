F4解答题椭圆

在平面直角坐标系中，已知 F1​,F2​ 分别为椭圆

C:a2x2​+b2y2​=1(a>b>0)

的左、右焦点。设点 D(1,0) 为线段 OF2​ 的中点，直线 MN（不与 x 轴重合） 过点 F1​ 且与椭圆 C 交于 M,N 两点，延长 MD,ND 与椭圆 C 交于 P,Q 两点。 设直线 MN,PQ 的斜率分别为 k1​,k2​。将 k2​/k1​ 表示成关于 a 的函数 f(a)，并求 f(a) 的值域。

已知椭圆

10x2​+6y2​=1

的左、右焦点为 F1​,F2​，点 M(1,0)，过点 F1​ 且斜率为 k 的直线 l 与椭圆交于 P,Q 两点（P,Q 不在 x 轴上），直线 MP,MQ 与椭圆的 另一个交点分别为 A,B。

（1）椭圆上是否存在关于直线 l 对称的两点？若有，求斜率 k 的取值范围；若没有， 请说明理由。

（2）若

MAMP​+MBMQ​=3,

求直线 l 的斜率。

打开这道题

提示

先由中点条件确定焦半距。

思路

对椭圆上一点 X，写出直线 DX 上另一交点的分式线性变换，再把整条弦 MN 变到弦 PQ。

解答

设焦半距为 c。由 D(1,0) 是 OF2​ 的中点知 c=2，故

b2=a2−4,a>2,F1​=(−2,0).

设 X=(x,y) 在椭圆上，X′ 是直线 DX 与椭圆的另一交点。以 D+t(X−D) 参数化直线，利用一个交点对应 t=1 及韦达定理，得

x′=2x−a2−1(a2+1)x−2a2​,y′=2x−a2−1(a2−1)y​.

该变换是对合，故反解中交换 x,y 与 x′,y′ 后形式不变。

直线 MN 写成 y=k1​(x+2)。把反解代入，得到 X′ 的轨迹

y′=a2−1k1​​((a2+5)x′−4a2−2),

这就是直线 PQ。因此

f(a)=k1​k2​​=a2−1a2+5​​.

由 a>2，f(a)=1+6/(a2−1) 严格递减，并分别趋于 3 和 1，故值域为

(1,3)​.

复核

MN 不与 x 轴重合保证 k1​=0；a=2 会使 b=0，故两个端值均不取到。

方法总结

从定点出发的“同射线取另一交点”是射影对合；先求点变换，再整体代入弦方程，比逐个解交点简洁。

为什么评为 F4（会透露解法方向）

须导出过D取另一交点的统一变换并利用对合反解，将原焦点弦的直线约束传到PQ后消掉动斜率。

专题卡：直线参数与韦达消交点、定点、轨迹与坐标消元

并排比较

从椭圆内的定点连向一个椭圆点，再取同一直线的另一交点，两题都可用单一参数和根积直接写出变换。先把一个交点记为已知参数，再求另一个，通常比逐个解联立坐标更清楚。

一题把变换用于两段距离比的和，另一题将点变换整体代回弦方程得到新弦；距离绝对值与有向参数不能混同。
