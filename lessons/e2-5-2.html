5.2 导数的运算

按定义求导数每次都要算极限，太慢。这一节记住几个基本函数的导数，再学加减乘除和 \(f(ax+b)\) 的求导规则，大多数函数就能直接写出导数。

一块长方形电子画布，现在长 \(u=4\) 米、宽 \(v=3\) 米，面积是 \(u\cdot v=12\) 平方米。让长和宽同时向外匀速伸展：长每秒增加 \(1\) 米（\(u'=1\)），宽也每秒增加 \(1\) 米（\(v'=1\)）。先点下面的按钮，看看面积多出了哪几块：

有人猜：面积的瞬时增长率 \((uv)'\) 就等于「长的增长率 \(\times\) 宽的增长率」\(u'v'=1\times1=1\)。对照上面的图，这个猜法对吗？

B。看上面的彩色分块图就一清二楚了：

长和宽各长出一小条时，新增面积分成三块：右侧竖条为 \(u'\Delta t\cdot v=3\Delta t\)，上方横条为 \(u\cdot v'\Delta t=4\Delta t\)，右上角小方块为 \(\Delta u\cdot\Delta v=(\Delta t)^2\)，单位都是平方米。故 \(\Delta(uv)=7\Delta t+(\Delta t)^2\)。

把新增面积除以时间间隔，平均增长率是 \(\dfrac{\Delta(uv)}{\Delta t}=3+4+\Delta t\)，单位是平方米/秒；当 \(\Delta t\to0\) 时趋于 \(7\)。所以乘积的导数是两条长边除以 \(\Delta t\) 后的贡献之和：\((uv)'=u'v+uv'\)，并非 \(u'v'\)。这一节继续学习基本初等函数的导数与四则、简单复合运算。

1. 先认识几个词

要用到：5.1 导数的概念和几何意义（回看 5.1）；必修一的幂、指数、对数函数，弧度制和三角函数。

课本用词：先写定义域再选法则；复合函数必须乘内层导数，商法则分子是 \(u'v-uv'\)，分母要平方。

导函数：每个 \(x\) 处的导数 \(f'(x)\) 本身又是 \(x\) 的函数，叫导函数，简称导数。求出导函数后，任意点的切线斜率代入即得。

例：\(f(x)=x^2\)，算得 \(f'(x)=2x\)。于是 \(f'(3)=6, f'(-1)=-2\)，无需每个点重做极限。

指数形式幂改写：幂函数求导法则只适用于 \(x^\alpha\) 标准形式，运算前需先化简改写。

例：\(\dfrac1x=x^{-1}\)，\(\sqrt x=x^{\frac12}\)，\(\dfrac{1}{\sqrt x}=x^{-\frac12}\)，\(x^2\sqrt x=x^{\frac52}\)。

内层与外层：\(y=\sin(3x+1)\) 包含两步：先算 \(u=3x+1\)（内层），再算 \(y=\sin u\)（外层）。本节重点处理内层为一次式 \(ax+b\) 的情形。

例：\(e^{2x-5}\) 的内层是 \(2x-5\)（\(a=2\)），外层是 \(e^u\)；\(\ln(4-x)\) 的内层是 \(4-x\)（\(a=-1\)），外层是 \(\ln u\)。

导数运算法则几何直觉：矩形增量、商的减序与复合链式
法则对照 积法则 vs 商法则
  • 积求导 \([uv]'\)：轮流求导再「相加」，即 \(u'v+uv'\)，两项对称无所谓先后。
  • 商求导 \([\frac uv]'\)：分母平方，分子必须是「减法」：分子导乘分母 先行（\(u'v-uv'\)）。
  • 颠倒惩罚：商法则若颠倒分子减法顺序，导数符号全部反号，单调极值全错。
链式要领 外层套公式，内层补系数
  • 外层导数 \(f'(u)\)：把内层 \(ax+b\) 视作整体变量，原样套用基本初等函数导数表。
  • 内层补偿 \(\times a\)：链式传递必然产生伸缩倍数，切勿遗漏乘一次项系数 \(a\)。
  • 负号暗坑：如 \(\ln(1-x)\) 内层系数 \(a=-1\)，导数必含负号 \(-\dfrac{1}{1-x}\)。

例 1（看一遍怎么写）

求导：① \(y=\dfrac{1}{x^3}\)；② \(y=x\sqrt x\)；③ \(y=2^x\)；④ \(y=\log_3 x\)；⑤ \(f(x)=\sin x\)，求 \(f'\!\left(\dfrac\pi3\right)\)。

① 改写 \(y=x^{-3}\)，\(y'=-3x^{-4}=-\dfrac{3}{x^4}\)。

② 改写 \(y=x^{\frac32}\)，\(y'=\dfrac32x^{\frac12}=\dfrac32\sqrt x\)。

③ \(y'=2^x\ln2\)（\(\ln2\) 是常数，不能丢）。

④ \(y'=\dfrac{1}{x\ln3}\)（\(x>0\)）。

⑤ \(f'(x)=\cos x\)，\(f'\!\left(\dfrac\pi3\right)=\cos\dfrac\pi3=\dfrac12\)。

自己试试：\(y=\dfrac{1}{x^2}\) 的导数是？

A。\(y=x^{-2}\)，\(y'=-2x^{-3}=-\dfrac{2}{x^3}\)。选 B 是把分母直接求导；选 C 丢了负号；选 D 是指数没减 1。

3. 导数运算与三步破题思维链

🧩 典型例题：求乘积与商式函数的导数（如 \(y = \dfrac{\ln x}{x}\)）
👀 信号
认清函数结构：是积式、商式还是复合函数；明确定义域（如对数 \(x>0\)、分母不为 0）。
🔧 步骤
1. 设子函数：设分子 \(u(x)=\ln x\)，分母 \(v(x)=x\)；
2. 分别求导：\(u'(x)=\dfrac1x\)，\(v'(x)=1\)；
3. 套公式化简：套商法则 \(\dfrac{u'v-uv'}{v^2} = \dfrac{\frac1x\cdot x - \ln x\cdot 1}{x^2} = \dfrac{1-\ln x}{x^2}\)。
🛡️ 防坑
商法则分子是 \(u'v - uv'\)，万万不可写成 \(uv' - u'v\)；分母必须平方。

例 2（四则运算与切线结合）

求导：① \(y=x^3-2x+1\)；② \(y=x\ln x\)；③ \(y=\dfrac{e^x}{x}\)；④ 求曲线 \(y=x\ln x\) 在点 \((1,0)\) 处的切线方程。

① 逐项求导：\(y'=3x^2-2\)。

② 积的法则：\(y'=(x)'\ln x+x(\ln x)'=1\cdot\ln x+x\cdot\dfrac1x=\ln x+1\)（\(x>0\)）。

③ 商的法则：\(y'=\dfrac{(e^x)'x-e^x(x)'}{x^2}=\dfrac{e^x\cdot x-e^x\cdot1}{x^2}=\dfrac{(x-1)e^x}{x^2}\)（\(x\ne0\)）。

④ 切点是 \((1,0)\)，切线斜率 \(k=y'|_{x=1}=\ln1+1=1\)。点斜式：\(y-0=1\cdot(x-1)\)，即 \(y=x-1\)。

自己试试：求 \(y=\dfrac{x}{\cos x}\) 的导数时，分子应该整理成？

D。分子 \(=(x)'\cos x-x(\cos x)'=\cos x-x(-\sin x)=\cos x+x\sin x\)，所以 \(y'=\dfrac{\cos x+x\sin x}{\cos^2x}\)。

选 A 忘了 \((\cos x)'=-\sin x\) 的负号；选 B 是分子分母分别求导相除；选 C 是减法顺序反了。

4. 简单复合函数 \(f(ax+b)\) 的导数

内层是一次式 \(ax+b\) 时，先按外层求导（括号里原样不动），再乘内层的系数 \(a\)：

$$[f(ax+b)]'=a\,f'(ax+b)$$

例 3

求导：① \(y=e^{3x-1}\)；② \(y=\cos\left(2x+\dfrac\pi3\right)\)；③ \(y=\ln(1-2x)\)；④ \(y=(2x+1)^3\)。

① \(a=3\)：\(y'=3e^{3x-1}\)。

② \(a=2\)，外层 \((\cos u)'=-\sin u\)：\(y'=-2\sin\left(2x+\dfrac\pi3\right)\)。

③ 定义域 \(1-2x>0 \implies x<\dfrac12\)。\(a=-2\)：\(y'=-2\cdot\dfrac{1}{1-2x}=\dfrac{2}{2x-1}\)。

④ \(a=2\)，外层 \((u^3)'=3u^2\)：\(y'=2\cdot3(2x+1)^2=6(2x+1)^2\)。

自己试试：\(f(x)=e^{-2x}\)，\(f'(0)\) 等于？

B。\(a=-2\)，\(f'(x)=-2e^{-2x}\)，\(f'(0)=-2e^0=-2\)。选 A 是忘了乘内层系数；选 C 丢了负号；选 D 是把 \(e^0\) 当成了 \(e\)。

5. 三大翻车现场红绿对比卡

⚠️ 误区一：积与商直接相乘除
❌ 错误：\((x\cdot x)' = x'\cdot x' = 1\)；\((\frac{x}{\cos x})' = \frac{1}{-\sin x}\)
✅ 正确：积法则必须交叉求导相加：\(u'v+uv'\)；商法则必须套用除法专用公式！
⚠️ 误区二：复合求导漏乘内层 a
❌ 错误：\((e^{3x})' = e^{3x}\)；\([\ln(1-2x)]' = \dfrac{1}{1-2x}\)
✅ 正确：必须补乘内层系数 \(a\)！\((e^{3x})'=3e^{3x}\)，\([\ln(1-2x)]'=\dfrac{-2}{1-2x}\)。
⚠️ 误区三：商法则减法顺序颠倒
❌ 错误：\(\left(\dfrac{\ln x}{x}\right)'\) 算成分子是 \(\ln x - 1\)
✅ 正确：分子导数必须先行！\(u'v - uv' = \frac1x\cdot x - \ln x\cdot 1 = 1-\ln x\)。
🔍 反例微图解：矩形增量两长条 vs 复合伸缩链
左图：乘积求导增量由两条长方形条带 \(u\Delta v + v\Delta u\) 构成；右图：复合函数链式齿轮放大倍数 \(\times a\)。
先写定义域 → 认清结构（和差、积、商，还是 \(f(ax+b)\)）→ 查表、套法则 → 化简。
再深一点（可以先跳过）

内层不是一次式的一般链式法则：\(y=f(g(x))\) 的一般导数为 \(y'=f'(g(x))\cdot g'(x)\)。例如 \([\ln(x^2+1)]'=\dfrac{2x}{x^2+1}\)。

商法则的倒数推导：将 \(\frac uv\) 视为 \(u \cdot \frac1v\)，代入积法则即自然推导得出 \(\frac{u'v-uv'}{v^2}\)。

导数运算与切线斜率双屏联动台

上图为原函数 \(f(x) = x e^{-x}\)，下图为其导函数 \(f'(x) = (1-x)e^{-x}\)。滑动 \(x_0\)，实时观察原函数上的切线姿态与导函数曲线高度的绝对对应关系：

1.0

直接用

1. 已知函数 \(f(x) = x^2 - 3x + \ln x\)，则导数值 \(f'(1)\) 的值为：

B。求导函数：\(f'(x) = 2x - 3 + \dfrac{1}{x}\)。代入 \(x = 1\)：\(f'(1) = 2(1) - 3 + \dfrac{1}{1} = 2 - 3 + 1 = 0\)。此时曲线在点 \((1, f(1))\) 处的切线为水平切线！

2. 函数 \(f(x) = \sin(2x - 1)\) 的导函数 \(f'(x)\) 等于：

A。根据线性内层复合函数求导法则 \([f(ax+b)]' = a f'(ax+b)\)：内层 \(u = 2x-1\) 的导数为 2，外层正弦导数为余弦。因此 \(f'(x) = 2\cos(2x - 1)\)。

易错

3. 函数 \(f(x) = \dfrac{x}{e^x}\) 的导函数 \(f'(x)\) 化简后的形式为：

C。商的法则：\(f'(x) = \dfrac{(x)'e^x - x(e^x)'}{(e^x)^2} = \dfrac{1\cdot e^x - x e^x}{e^{2x}} = \dfrac{e^x(1 - x)}{e^{2x}} = \dfrac{1 - x}{e^x}\)。严防分子减法次序颠倒写成 \(x - 1\)！

4. 曲线 \(y = e^x + x\) 在点 \((0, 1)\) 处的切线方程为：

D。求导 \(y' = e^x + 1\)。在点 \((0, 1)\) 处的导数值（切线斜率）为 \(k = y'|_{x=0} = e^0 + 1 = 1 + 1 = 2\)。由点斜式：\(y - 1 = 2(x - 0) \implies y = 2x + 1\)。

挑战进阶

5. 若直线 \(y = kx\) 是曲线 \(y = \ln x\) 的一条切线，则斜率 \(k\) 的值为：

B。直线 \(y = kx\) 过原点 \((0, 0)\)，这是典型的「过原点切线」问题！设切点为 \((t, \ln t)\)。求导 \(y' = \dfrac{1}{x} \implies\) 切线斜率 \(k = \dfrac{1}{t}\)。切线方程为 \(y - \ln t = \dfrac{1}{t}(x - t)\)。代入原点 \((0, 0)\)：\(-\ln t = -1 \implies \ln t = 1 \implies t = e\)。因此斜率 \(k = \dfrac{1}{t} = \dfrac{1}{e}\)（极度经典的对数过原点切线结论！）。
