七年级上册 · 第三章 代数式

3.1 列代数式表示数量关系

用一个字母代替会变的数，一个式子就能说清一整类情况。这一节学三件事：什么是代数式、怎样把文字关系写成代数式、什么叫“乘积一定”的反比例关系。

本节导读　先修：2.3 有理数的乘方 · 本节路线

要用到：有理数的四则运算和乘方（回看 2.3）；小学里用字母表示运算律和面积公式（没学过也不要紧，这一节从头讲）。

  1. 从买彩笔进入：盒数会变，就用字母代替它。
  2. 认识代数式，分清代数式和等式、不等式；学会书写规范。
  3. 反过来读：按运算顺序说出代数式的意义。
  4. 列代数式：先用文字写出关系，再逐项换成式子。
  5. 反比例关系：两个量的乘积一定；和“和一定”“比值一定”比一比。
  6. 练习与中考真题，回看“哪一步最容易写错”。

文具店里一盒彩笔有 \(12\) 支。点下面的按钮，看看买不同盒数时一共有多少支：

买 \(n\) 盒，一共有多少支彩笔？选出数量关系正确、书写也规范的一项。

A。买几盒就乘几：\(12\times n\)，数和字母相乘时省略乘号、数写在前面，写成 \(12n\)。看关系：C 把「乘」错成了「加」，D 是「平均每盒分」的意思，方向反了，这两项数量关系就错了。看书写：B 的关系没错（也是 \(12\) 乘 \(n\)），但数应写在字母前面，不规范。

只用一个式子 \(12n\)，买 \(2\) 盒、\(5\) 盒、\(30\) 盒都说清了。这样的式子叫代数式。这一节要回答：什么样的式子是代数式？怎样把一句话正确地写成代数式？

1. 先认识几个词：代数式和它的书写规范

前置知识：有理数的乘方（回看 2.3）。代数式：用运算符号（加、减、乘、除、乘方）把数或表示数的字母连接起来的式子，例如 \(12n\)、\(0.8x-5\)、\(a^2\)、\(\tfrac{s}{6}\)。单独一个数或一个字母也是代数式，例如 \(8\)、\(m\)。点下面几个式子，判断它是不是代数式：

直觉微图解 ①有“=”“>”“<”的，就不是代数式

核心概念 ②字母代表的是数

\(12n\) 里的 \(n\) 是“盒数”这个数，不是“彩笔”本身。列式时要说清字母表示哪个量、单位是什么。同一个代数式还能放进不同情境：\(1.5t\) 可以是每千克 \(1.5\) 元的土豆买 \(t\) kg 的钱数，也可以是每秒走 \(1.5\) m、走 \(t\) s 的路程。

核心概念 ③代数式 vs 等式、不等式

代数式只写“怎么算”，不下结论。\(3a\) 是代数式；\(C=3a\) 说“\(C\) 等于 \(3a\)”，是等式；\(2x>5\) 是不等式。它们都不是代数式。

2. 核心点：说出代数式的意义——先算的先说

看到一个代数式，按它的运算顺序说出来：先算的先说，最后一步是什么运算，就说成什么（和、差、积、商、平方）。

\(\color{#2F7A56}{\underbrace{3x}_{\text{先算：}x\text{ 的 3 倍}}}\color{#B5452F}{\underbrace{+\,5}_{\text{最后：与 5 的和}}}\) 而 \(\color{#B5452F}{\underbrace{3\,\cdot}_{\text{最后：3 倍}}}\color{#2F7A56}{\underbrace{(x+5)}_{\text{先算：}x\text{ 与 5 的和}}}\)

直觉微图解 ③把代数式看成一条流水线：数字依次经过每一步

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

说出 \(3(k+2)\) 和 \(3k+2\) 的意义，并各举一个生活中的例子。

① 读懂题意：两个式子长得很像，都有 \(3\)、\(k\)、\(2\)。要说清它们的区别，先看什么？

提示 1：找最后一步

\(3(k+2)\) 先算括号里的 \(k+2\)，最后乘 \(3\)；\(3k+2\) 先算 \(3k\)，最后加 \(2\)。

看完整示范
② 想办法：按「先算的先说，最后一步定名字」来说；举例时，让式子里每一步运算都对应一件事。
③ 执行：\(3(k+2)\) 是「\(k\) 与 \(2\) 的和的 \(3\) 倍」。例：每袋饼干原来有 \(k\) 块，每袋再加 \(2\) 块，\(3\) 袋一共 \(3(k+2)\) 块。
\(3k+2\) 是「\(k\) 的 \(3\) 倍与 \(2\) 的和」。例：\(3\) 袋饼干每袋 \(k\) 块，另有 \(2\) 块散装的，一共 \(3k+2\) 块。
执行中检查：取 \(k=4\)：第一种每袋 \(6\) 块、\(3\) 袋 \(18\) 块；第二种 \(12\) 块加 \(2\) 块是 \(14\) 块。两个结果不同，说明这两个式子确实表示不同的事 ✓。

④ 回头看：括号改变了运算顺序，意义就变了。说意义时，「和的 3 倍」和「3 倍与 2 的和」只差几个字，顺序却完全不同。

自己试试：\(4(n-1)\) 的意义是什么？

B。括号里的 \(n-1\) 先算，最后一步乘 \(4\)，所以是「差的 \(4\) 倍」。A 和 C 说的都是 \(4n-1\)。

3. 核心点：列代数式——先写文字关系，再换成字母

反过来，把一句话写成代数式：按叙述的顺序，先说的先写。题目长的时候分三步：找出有哪些量 → 用文字写出它们的关系 → 逐项换成数和字母。

\(\color{#2F7A56}{\underbrace{\text{找出数量}}_{\text{有哪些量}}}\) → \(\color{#966524}{\underbrace{\text{文字关系}}_{\text{找回的钱 = 付的钱 − 花的钱}}}\) → \(\color{#B5452F}{\underbrace{\text{代数式}}_{\text{逐项换成数和字母}}}\)

直觉微图解 ④用线段图分清“比 \(a\) 的 3 倍少 2”和“\(a\) 与 2 的差的 3 倍”

例 2（示范）

打印店黑白打印每页 \(0.2\) 元，彩色打印每页 \(a\) 元。小敏打印了 \(30\) 页黑白、\(8\) 页彩色，付了 \(20\) 元。应找回多少元？

① 读懂题意：题里有哪几笔钱？哪个量是会变的，用字母表示？

提示 1：先用文字写关系

找回的钱 ＝ 付的钱 － 黑白打印的钱 － 彩色打印的钱。

看完整示范
② 想办法：每一笔钱都是「单价 × 页数」。黑白的单价、页数都已知，能直接算出；彩色的单价是 \(a\)，只能写成式子。
③ 执行：黑白：\(0.2\times30=6\)（元）；彩色：\(8\times a=8a\)（元）。找回 \(20-6-8a\)，即 \((14-8a)\) 元。
执行中检查：数写在字母前（\(8a\) 不写 \(a8\)）；式子是差、后面带单位，要加括号。再取 \(a=1\) 试试：彩色花 \(8\) 元，一共花 \(14\) 元，找回 \(6\) 元；式子 \(14-8\times1=6\) ✓。

④ 回头看：只含具体数的部分（\(20-6\)）可以先算出来；含字母的部分写成 \(8a\) 就是答案，不用再变形。

自己试试：「\(x\) 与 \(5\) 的差的一半」怎样列式？

A。先说「\(x\) 与 \(5\) 的差」，写 \(x-5\)；最后一步是「一半」，整个差除以 \(2\)。分数线起括号的作用。B 是「\(x\) 的一半与 \(5\) 的差」；C 顺序也反了。

再试一个：一个两位数，十位上的数字是 \(a\)，个位上的数字是 \(b\)。这个两位数怎样表示？

提示

先拿一个具体的数想：\(37\) 是几个十加几个一？

B。\(37=3\times10+7\)，所以十位是 \(a\)、个位是 \(b\) 的数是 \(10a+b\)。A 的 \(ab\) 表示 \(a\times b\)，不是把两个数字并排写；C 是数字和；D 把十位和个位弄反了。

4. 核心点：反比例关系——乘积一定的两个量

先回顾正比例：每支笔 \(3\) 元，买的支数和总价一起变，比值（总价 ÷ 支数 \(=3\)）一定。再换一种情况：班上 \(48\) 人分组，每组人数相同。每组 \(x\) 人，分成 \(y\) 组：每组 \(2\) 人有 \(24\) 组，每组 \(4\) 人有 \(12\) 组，每组 \(6\) 人有 \(8\) 组……\(x\) 变，\(y\) 跟着变，但 \(x\cdot y\) 总是 \(48\)。

反比例关系：两个相关联的量，一个量变化，另一个量也随着变化，并且这两个量的乘积一定，这两个量就叫成反比例的量，它们的关系叫反比例关系，写成 \(xy=k\)（\(k\) 是一个确定的值，\(k\ne0\)）。小学学没学过都不要紧，这里从头讲。注意：\(xy=k\) 有等号，是等式，不是代数式。

\(\color{#2F7A56}{\underbrace{x}_{\text{一个量}}}\cdot\color{#966524}{\underbrace{y}_{\text{另一个量}}}=\color{#B5452F}{\underbrace{k}_{\text{确定的值，}k\ne0}}\)

判断依据是乘积一定，不是“一个变大、另一个变小”。

直觉微图解 ⑤三种关系放在一起：每次都算一算 \(x\cdot y\)

例 3（示范）

一个水箱装满了 \(360\) L 水。打开阀门，每分钟放出 \(x\) L，\(y\) min 放完。\(y\) 与 \(x\) 成反比例关系吗？如果成，写出关系式，并说出每分钟放 \(24\) L 时要几分钟放完。

① 读懂题意：哪两个量在变？哪个量不变？

提示 1：写出两个量的乘积

每分钟放的水量 × 放水时间 ＝ ？

看完整示范
② 想办法：变的是每分钟放水量 \(x\) 和时间 \(y\)；不变的是水的总量。先写乘积，再看它是否一定。
③ 执行：\(x\cdot y=\) 放出的总水量 \(=360\)，不管 \(x\) 取多少，乘积都是确定的 \(360\)，所以 \(y\) 与 \(x\) 成反比例关系，关系式是 \(xy=360\)。每分钟放 \(24\) L 时，要 \(360\div24=15\)（min）。
执行中检查：积 \(360\) 有实际意义（水的总量），确定且不为 \(0\)；\(24\times15=360\) ✓。

④ 回头看：判断反比例分两步：写出两个量的乘积；看它是否等于一个确定的非零值，并说出这个积表示什么。

自己试试：下面哪两个量成反比例关系？

A。步长 × 步数 ＝ 路长，\(xy=1200\)，乘积一定。B 是 \(y\div x=4\)，比值一定，是正比例；C 是和一定，乘积会变；D 两个量没有确定的关系。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）顺序写反
❌ 典型错解：“比 \(m\) 的 \(2\) 倍少 \(3\)”写成 \(3-2m\)；“\(m\) 与 \(3\) 的差的 \(2\) 倍”写成 \(2m-3\)。
✅ 看图秒懂：先有 \(2\) 个 \(m\) 那么长，再截掉 \(3\)，剩下 \(2m-3\)。第二句最后一步是“\(2\) 倍”，要写成 \(2(m-3)\)。先划分语句层次，找出最后一步。
翻车现场 ②书写不规范、漏括号
❌ 典型错解：\(t\times5\)、\(a5\)、\(1\tfrac13x\)、\(n\div5\)，还有“\(3x-4\) 千克”。
✅ 一眼看清：依次改成 \(5t\)、\(5a\)、\(\tfrac43x\)、\(\tfrac n5\)、\((3x-4)\) 千克。带分数不化成假分数，会被看成 \(1+\tfrac13x\)。
翻车现场 ③一个变大、一个变小，就是反比例？
❌ 典型错解：“周长 \(20\) cm 的长方形，长变大、宽就变小，所以长和宽成反比例。”
✅ 一眼看清：长 + 宽 \(=10\)，是和一定。长 \(2\) 宽 \(8\)，积 \(16\)；长 \(4\) 宽 \(6\)，积 \(24\)：积在变，不成反比例。先算乘积再下结论。
再深一点（可以先跳过）：\(-a\) 一定是负数吗？为什么规定 \(k\ne0\)？

\(-a\) 不一定是负数。“\(a\) 的相反数与 \(b\) 的 \(3\) 倍的和”写成 \(-a+3b\)。字母可以表示负数：\(a=-4\) 时，\(-a=4\) 是正数（回看 1.2）。

为什么 \(k\ne0\)？如果 \(k=0\)，取 \(x=0\) 时，\(y\) 取什么数都满足 \(xy=0\)，“一个量变、另一个量随着变”就说不通了。

① 找规律：用小棒搭一排“小房子”

每间小房子是一个正方形加一个三角形屋顶，相邻两间共用一面墙。拖动滑条上的圆点（或点一下圆点再用方向键）改变房子的间数 \(n\)。红色是最左边那面墙，每间房子再添 5 根（底、顶、右墙和两根屋顶）。搭 \(n\) 间要几根？先自己写出式子，再拖动核对。

② 进阶：面积一定和周长一定，长和宽的关系一样吗？

拖动长方形右上角的圆点（或选中后按方向键）改变长 \(x\)，每格边长 1 cm。先看面积一定（\(24\) cm²），再切到周长一定（长 + 宽 \(=12\) cm），比一比乘积。

从易到难排好了。卡住时先展开提示。

直接用

1. 小芳每天跳绳 \(x\) 下，坚持了两个星期。她一共跳了多少下？选出数量关系正确、书写也规范的一项。

B。两个星期是 \(14\) 天，总数 ＝ 每天的下数 × 天数 ＝ \(14x\)。看关系：A 只算了一个星期，C 用错了运算。看书写：D 的关系对，但数要写在字母前面。

2. 代数式 \(x^2-3\) 的意义是什么？

B。先算 \(x^2\)，最后减 \(3\)，是「平方与 \(3\) 的差」。A 是 \((x-3)^2\)；C 是 \(2x-3\)，把平方当成了乘 \(2\)。

易错

3. 每支笔 \(y\) 元，小林买了 \(4\) 支，付了 \(20\) 元。应找回多少元？选出数量关系正确、书写也规范的一项。

提示

先用文字写：找回的钱 ＝ 付的钱 － 花的钱。式子是差，后面又要写单位。

A。找回 \(20-4y\)，看关系：C 减反了（花的钱减付的钱），关系错。看书写：B 关系对，但式子是差、后面带单位要加括号，漏了括号读起来像只有 \(4y\) 带单位；D 关系对，但数要写在字母前面。

4. 「\(m\) 与 \(n\) 的差的平方」怎样列式？

提示

最后一步是什么运算？是「差」还是「平方」？

C。先算 \(m\) 与 \(n\) 的差，最后整个差平方，差要加括号。A 是「\(m\) 与 \(n\) 的平方的差」；B 是「\(m\) 的平方与 \(n\) 的平方的差」；D 把平方当成了乘 \(2\)。

5. 下面哪两个量成反比例关系？

提示

每个选项都写出两个量的乘积，看它是不是一个确定的非零值。

A。每瓶的量 × 瓶数 ＝ 油的总量，\(xy=18\)。B 是年龄差一定；C 是长 + 宽 \(=15\)，和一定；D 是 \(y\div x=6\)，比值一定，是正比例。

挑战

6. 一张方桌四边各坐 \(1\) 人。把 \(n\) 张方桌拼成一长条（相邻两张桌子拼在一起的那一边不能坐人），一共能坐多少人？

提示 1：先数前几个

\(1\) 张坐 \(4\) 人，\(2\) 张坐 \(6\) 人，\(3\) 张坐几人？画个草图数一数。

提示 2：从「形」上看

长条的上下两边，每张桌子各坐 \(1\) 人；左右两头再各坐 \(1\) 人。

B。上下两边共 \(2n\) 人，两头 \(2\) 人，一共 \(2n+2\) 人。用前几个验证：\(n=1\) 得 \(4\)，\(n=2\) 得 \(6\)，\(n=3\) 得 \(8\) ✓。A 没减去拼接处少坐的人；C 在 \(n=2\) 时是 \(7\)，不对；D 在 \(n=1\) 时是 \(6\)，不对。
