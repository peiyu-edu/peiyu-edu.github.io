整数加法运算定律推广到小数

整数里的加法交换律、结合律，小数里还能用吗？用它们能不能算得又快又对？

本单元按旧版教材编排。

小丽的三个存钱罐里分别有 2.7 元、4.6 元、3.3 元。要算一共有多少元，哪两个罐里的钱加起来正好是整数？

对，2.7 + 3.3 = 6，正好是整数。先把它们加起来，再加 4.6，就是 10.6 元。整数里的加法运算律，在小数里也能用吗？下面自己来试。

1. 换个顺序，结果变不变

选一个算式，再点一种加法顺序：先算哪两个数。看看每种顺序的得数。

2. 整数里成立的，小数里也成立

整数里，交换两个加数的位置，和不变，例如2.7 + 3.3 = 3.3 + 2.7（加法交换律）。三个数相加，先加哪两个，和也不变，例如(2.7 + 3.3) + 4.6 = 2.7 + (3.3 + 4.6)（加法结合律）。

刚才你试了三个小数的加法，每种顺序的得数都一样。小数也是由计数单位拼成的数，小数点对齐以后，相同数位上的数相加，和整数加法的道理完全一样，所以这两条规律小数里也成立。

用的时候，先找“加起来是整数”的两个数：看小数部分，0.6 和 0.4，0.25 和 0.75，十分位、百分位凑起来正好进成 1。

自己试试

用凑整的办法算：2.4 + 3.3 + 3.6 = ？（先交换位置，把 2.4 和 3.6 放在一起）

2.4 + 3.3 + 3.6 = 2.4 + 3.6 + 3.3 = 6 + 3.3 = 9.3。

3. 连减两个数，也可以先加后减

一张 20.5 元的卡，先花 6.8 元，再花 3.2 元。一共花了 6.8 + 3.2 = 10 元，所以还剩 20.5 − 10 = 10.5 元。

这就是 20.5 − 6.8 − 3.2 = 20.5 − (6.8 + 3.2)：连续减去两个数，等于减去它们的和。括号里的 6.8 + 3.2 正好凑成整数 10。

自己试试

13.4 − 4.6 − 1.4 = 13.4 − (4.6 + 1.4) = ？

4.6 + 1.4 = 6，13.4 − 6 = 7.4。

整数里的加法交换律、结合律，小数里也成立。多个小数相加，先把加起来是整数的数凑在一起；连续减去几个数，可以减去它们的和。

两个容易错的地方

✗ 随便挑两个数凑整

3.58 + 4.9 + 2.42，先算 3.58 + 4.9。

✓ 看小数部分，找凑整的一对

0.58 + 0.42 = 1，所以先算 3.58 + 2.42 = 6，再加 4.9，得 10.9。

✗ 去括号，括号里的加号不变

14.6 − (5.6 + 3.2) 写成 14.6 − 5.6 + 3.2。

✓ 括号前面是减号，两个数都要减

14.6 − (5.6 + 3.2) = 14.6 − 5.6 − 3.2 = 9 − 3.2 = 5.8。

直接用

1. 要简便地算 4.6 + 7.8 + 5.4，先算哪两个数最方便？

C。4.6 + 5.4 = 10，再加 7.8，得 17.8。

2. 6.35 + 2.8 + 3.65 = ？

6.35 + 3.65 + 2.8 = 10 + 2.8 = 12.8。

3. 15.9 − 4.7 − 5.3 = ？

15.9 − (4.7 + 5.3) = 15.9 − 10 = 5.9。

容易错

4. 12.5 − (3.5 + 4.8) = ？

12.5 − 3.5 − 4.8 = 9 − 4.8 = 4.2。

5. 3.46 + 5.2 + 2.54 = ？

3.46 + 2.54 = 6，6 + 5.2 = 11.2。

6. 下面哪一个算式和 9.7 − (2.4 + 3.6) 的得数相等？

A。9.7 − 2.4 − 3.6 = 9.7 − 6 = 3.7，和原式相等。

想一想

7. 5.8 + □ + 4.2 = 17.1，方框里是多少？

5.8 + 4.2 = 10，17.1 − 10 = 7.1。检查：5.8 + 7.1 + 4.2 = 17.1。

8. 关于加法交换律、结合律，下面哪句话对？

B。小数相加也是相同数位上的数相加，运算律和整数一样。
