4.3 等比数列

每一项都是前一项乘同一个数。这一节讲它的通项、等比中项和前 \(n\) 项和，以及用公式前要查的几件事。先从拉面师傅扣面开始。

拉面师傅做手工拉面：一团面拉开再对折叫「一扣」。拉第 \(1\) 扣变成 \(2\) 根，并拢对折拉第 \(2\) 扣变成 \(4\) 根，第 \(3\) 扣变成 \(8\) 根……每次根数都翻倍（乘 \(2\)）。点按钮看看面条根数怎么涨：

一共拉了 \(5\) 扣，手里有几根面条？

D。每拉一扣，根数乘 \(2\)：\(2,\ 4,\ 8,\ 16,\ 32\)。不是每次加 \(2\)（那是 \(10\)），也不是 \(5\times5\)。

后一项总是前一项的同一个倍数，这样的数列叫等比数列。拉完第 \(n\) 扣是 \(2^n\) 根。

这一节讲三件事：第 \(n\) 项怎么写（通项）、三个数怎样成等比（等比中项）、前 \(n\) 项加起来是多少（求和），比如 \(2+4+8+16+32\)。

1. 先认识几个词

要用到：数列、通项、\(S_n\) 的记号（回看 4.1）；等差数列的研究思路，这里把「加 \(d\)」换成「乘 \(q\)」（回看 4.2）；整数指数幂的运算（回看 4.1 指数）和指数函数（回看 4.2 指数函数）。

课本用词：等比求和必须先分流：\(q=1\) 时用 \(S_n=na_1\)，只有 \(q\ne1\) 才能除以 \(1-q\)。

公比 \(q\)：等比数列里，后一项除以前一项得到的那个不变的常数，记作 \(q\)（\(q\ne0\)）。

例：\(3,6,12,24\) 的公比是 \(2\)；\(8,4,2,1\) 的公比是 \(\dfrac12\)；\(1,-2,4,-8\) 的公比是 \(-2\)。

正负交替与摆动：公比是负数时，每乘一次负数符号就翻转一次，数列忽正忽负、上下摆动。

例：\(1,-2,4,-8,16\)：正、负、正、负、正，数列在横轴两侧摆动，不能直接谈单调递增或递减。

前 \(n\) 项和 \(S_n\)：把第 \(1\) 项到第 \(n\) 项加起来，\(S_n=a_1+a_2+\dots+a_n\)。

例：数列 \(1,2,4,8,\dots\) 里，\(S_3=1+2+4=7\)，\(S_4=7+8=15\)。注意 \(S_4\) 是四个数的总和，不是第 \(4\) 项。

一次投入和逐期投入：一次投入是期初一次性存入；逐期投入是每期（如每年）固定存一笔。

例：年利率 \(5\%\) 复利。年初一次存 \(2000\) 元，两年后是 \(2000\times1.05^2=2205\) 元；每年年末存 \(1000\) 元存两次，第二年末是 \(1000\times1.05+1000=2050\) 元。

等比核心直觉：指数暴涨与摆动、错位相减对消、公比分流
中项辨析 等比中项的双解与符号
  • 同号两数等比中项：\(G^2=ab \implies G=\pm\sqrt{ab}\)，通常有正负两个（如 \(1\) 与 \(9\) 的中项是 \(\pm3\)）。
  • 具体数列限制：若在同号数列中（隔两步 \(a_3=a_1q^2\)），符号必与首项一致，负值需舍去。
  • 异号两数无中项：若 \(ab<0\)，实数范围内不存在等比中项。
机制对偶 等差 vs 等比 对偶法则
  • 步进法则：等差「每步加 \(d\)」\(\longleftrightarrow\) 等比「每步乘 \(q\)」。
  • 下标对称：等差「下标和等则项和等」\(\longleftrightarrow\) 等比「下标和等则项积等」（\(a_ma_n=a_pa_q\)）。
  • 求和机制：等差倒序相加对称配对 \(\longleftrightarrow\) 等比错位相减抵消中段。

2. 定义与色彩语义主公式

一个数列从第 \(2\) 项起，每一项与前一项的比都等于同一个常数 \(q\)，它就是等比数列：\(\dfrac{a_{n+1}}{a_n}=q\)。各项均非零（\(a_1\ne0, q\ne0\)）。

定义式：\(\dfrac{a_{n+1}}{a_n} = \color{#0284c7}{q}\quad (a_1\ne0, q\ne0)\)
通项公式：\(a_n = a_1 \color{#0284c7}{q}^{n-1} = a_m \color{#0284c7}{q}^{n-m}\)（乘 \(n-1\) 次公比）
前 \(n\) 项和（公比分流）：\(S_n = \begin{cases} \color{#0284c7}{\dfrac{a_1(1-q^n)}{1-q}} = \dfrac{a_1 - a_n q}{1-q}, & q \ne 1 \\ \color{#16a34a}{n a_1}, & q = 1 \end{cases}\)

例 1（看一遍怎么写）

等比数列 \(\{a_n\}\) 中，\(a_2=6\)，\(a_5=48\)。求 \(q\)、\(a_1\) 和通项。

从 \(a_2\) 到 \(a_5\) 乘了 \(3\) 次 \(q\)：\(a_5=a_2q^3\)，所以 \(q^3=\dfrac{48}{6}=8 \implies q=2\)。

\(a_1=\dfrac{a_2}{q}=\dfrac62=3\)，通项 \(a_n=3\times2^{n-1}\)。验算：\(a_5=3\times2^4=48\)，完全相符。

自己试试：等比数列首项 \(a_1=2\)，公比 \(q=3\)，\(a_4\) 是？

A。\(a_4=2\times3^{3}=54\)：\(2,6,18,54\)。选 B 的同学用了 \(q^4\)，多乘了一次；指数是 \(n-1\)。选 D 是按等差 \(2+3\times3\) 算了。

3. 等比中项与三步破题思维链

🧩 典型例题：含参数公比等比数列的前 n 项和讨论
👀 信号
题目给出首项 \(a_1\) 且公比含有未知字母 \(q\)，要求前 \(n\) 项和 \(S_n\) 的表达式。
🔧 步骤
1. 判定公比分界：检查公比是否可能为 1；
2. 分支书写求和：
- 若 \(q=1\)，数列为常数列，\(S_n = na_1\)；
- 若 \(q\ne1\)，套用错位相减公式 \(S_n = \dfrac{a_1(1-q^n)}{1-q}\)；
3. 核对指数项数：分子中的指数 \(n\) 严格代表项数，切勿因末项指数误减 1。
🛡️ 防坑
公比为字母时漏掉 \(q=1\) 分类会导致分母为 0 严重失分；数项数从 \(q^0\) 到 \(q^{n-1}\) 共 \(n\) 项。

例 2（等比中项求值）

等比数列 \(\{a_n\}\) 中，\(a_1=1\)，\(a_5=16\)，求 \(a_3\)。

\(a_3\) 是 \(a_1\) 与 \(a_5\) 的等比中项：\(a_3^2=a_1a_5=16 \implies a_3=\pm4\)。

再由 \(a_3=a_1q^2=q^2>0\) 可知，隔两步必同号，所以 \(a_3=4\)，负解 \(-4\) 需舍去。

自己试试：\(1\) 和 \(9\) 的等比中项是？

B。\(G^2=1\times9=9 \implies G=\pm3\)：公比为 \(3\) 或 \(-3\) 均可。选 A 漏了负中项；选 C 是等差中项。

4. 前 \(n\) 项和：乘 \(q\) 错位相减法

将 \(S_n\) 整体乘以 \(q\) 后错开一位相减，中间各项完全对消，直接得出求和公式：

\[\small\begin{aligned} S_n&=a_1+a_1q+\dots+a_1q^{n-1}\\ qS_n&=\phantom{a_1+{}}a_1q+\dots+a_1q^{n-1}+a_1q^n \end{aligned}\]

上式减下式得：\((1-q)S_n = a_1 - a_1q^n \implies S_n = \dfrac{a_1(1-q^n)}{1-q}\quad (q\ne1)\)。

例 3

求 \(1+2+4+\dots+2^9\) 的和。

首项 \(a_1=1\)，公比 \(q=2\)。项数：指数从 \(0\) 到 \(9\)，共 \(10\) 项。代入公式：

\(S_{10}=\dfrac{1\times(1-2^{10})}{1-2}=\dfrac{1-1024}{-1}=1023\)。

自己试试：\(3+6+12+24+48=\)？（用公式算，再加一遍核对）

A。\(a_1=3, q=2, n=5\)：\(S_5=\dfrac{3(1-2^5)}{1-2}=3\times31=93\)。选 B 的同学项数数成了 \(6\)；选 C 算的是下一项 \(96\)。

5. 三大翻车现场红绿对比卡

⚠️ 误区一：求和遗漏 q=1 分类
❌ 错误：公比为字母时直接除以 \(1-q\)
✅ 正确：当 \(q=1\) 时分母为 0！必须分流：\(q=1 \implies S_n=na_1\)。
⚠️ 误区二：等比中项漏掉负根
❌ 错误：问 \(1\) 与 \(9\) 的等比中项只答 \(3\)
✅ 正确：\(G^2=ab \implies G=\pm\sqrt{ab}\)，双解 \(\pm3\) 均满足定义！
⚠️ 误区三：项数指数混淆（数漏首项）
❌ 错误：\(2^0+2^1+\dots+2^9\) 误代入 \(n=9\) 项
✅ 正确：从 \(0\) 次幂到 \(9\) 次幂共有 \(9-0+1=10\) 项，公式指数为 \(10\)！
🔍 反例微图解：中项双解交错 vs 指数项数偏差
左图：中项 \(G=\pm3\) 对应公比 \(q=3\)（全正）与 \(q=-3\)（摆动）；右图：末项 \(2^9\) 实为第 \(10\) 项（包含 \(2^0=1\)）。
先确认是等比数列（\(q\ne0\)、各项非零），求和先看 \(q\) 是不是 \(1\)，实际问题先画时间线数每笔钱存了几期。
再深一点（可以先跳过）

与指数函数的关系：当 \(q>0\) 时，点 \((n, a_n)\) 位于曲线 \(y=\frac{a_1}{q}\cdot q^x\) 上。当 \(q<0\) 时正负震荡，无实数连续函数对照。

下标和与乘积性质：若 \(m+n=p+k\)，则 \(a_m a_n = a_p a_k\)。

项数计数技巧：从 \(a_1 q^k\) 到 \(a_1 q^m\)，总项数为 \(m-k+1\) 项。

① 拖 \(a_1\)、\(q\)：看各项和前 \(k\) 项和一起变

圆点是各项 \(a_k\)，柱子是前 \(k\) 项和 \(S_k\)。拖底下的竖线（或选中后按方向键）选一个 \(k\)。把 \(q\) 拖到负数、拖到 \(1\)、拖到 \(0\) 各看一次；纵轴会自动缩放。

② 进阶：逐期投入，每笔钱存了几期

每年存 \(1000\) 元，年利率 \(r\)，按复利。柱子是第 \(j\) 笔钱到第 \(N\) 年末变成多少：浅色是本金，深色是利息。点一根柱子（或用方向键）看它存了几期。切换「年末存 / 年初存」，看时点不同差多少；下面还和「第 \(0\) 年一次存 \(1000N\)」比一比。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 等比数列 \(a_1=4\)，\(q=\dfrac12\)，\(a_5\) 是？

A。\(a_5=4\times\left(\dfrac12\right)^4=\dfrac4{16}=\dfrac14\)：\(4,2,1,\dfrac12,\dfrac14\)。选 B 用了 \(q^5\)，指数应是 \(n-1=4\)。

2. 等比数列 \(a_1=1\)，\(q=3\)，前 \(4\) 项和 \(S_4\) 是？

A。\(S_4=\dfrac{1-3^4}{1-3}=\dfrac{-80}{-2}=40\)，核对：\(1+3+9+27=40\)。选 B 是第 \(4\) 项不是和；选 C 忘了除以 \(1-q\)；选 D 是 \(S_5\)。

易错

3. 下面哪一个是等比数列？

C，公比 \(-1\)。A、B 里有 \(0\)：等比数列每一项都不能是 \(0\)，公比也不能是 \(0\)，否则「后项除以前项」会出现 \(\dfrac00\)。D 是等差数列，\(\dfrac21\ne\dfrac32\)。

C 正负交替，也是等比数列：公比可以是负数，只是不能是 \(0\)。

4. 等比数列首项是 \(3\)，公比是 \(q\)（\(q\) 是一个不为 \(0\) 的常数，没说具体是多少）。前 \(n\) 项和 \(S_n\) 是？

B。公式是两边除以 \(1-q\) 得来的，\(q=1\) 时分母是 \(0\)，A 没法用：比如数列 \(3,3,3\)，\(S_3=9\)，A 却给出 \(\dfrac00\)。不知道 \(q\) 是多少，就要分两种情况写。C 只在 \(q=1\) 时对。

5. 数列 \(a_n=3\times(-2)^{n-1}\)。下面说法对的是？

C。写出来：\(3,-6,12,-24,48,\dots\)，\(-6<3\) 但 \(12>-6\)，忽上忽下。\(|a_n|\) 确实越来越大，但 \(a_n\) 本身不单调。A、B 都是把它当成正底数的指数函数在想；公比 \(-2\) 不是 \(0\)，各项非零，所以它是等比数列，D 错。在「动手」①里把 \(q\) 拖到 \(-2\) 看看。

挑战

6. 年利率 \(4\%\)，按复利。小明每年年初存 \(1000\) 元，连存 \(3\) 年，到第 \(3\) 年年末一共多少元（保留到元）？

B。先画时间线：第一笔在第 \(1\) 年初存，到第 \(3\) 年末存了 \(3\) 年；第二笔 \(2\) 年；第三笔 \(1\) 年。

合计 \(1000\times1.04+1000\times1.04^2+1000\times1.04^3\)：首项 \(1040\)，公比 \(1.04\)，\(3\) 项，\(S_3=\dfrac{1040(1.04^3-1)}{0.04}=3246.464\)，约 \(3246\) 元。

A（\(3121.6\)）是按年末存算的，少算了一年利息；C（\(3374.6\)）是第 \(0\) 年一次存 \(3000\) 元的结果，一次投入和逐期投入混了；D（\(3120\)）是按单利、年末存算的。
