2025 年浙江预赛

二次型约束下线性式最大值

F2填空题不等式的证明

设 x,y,z∈R，且

5x2+6y2+6z2−8yz≤1,

则 x+y+z 的最大值为。

作答

分数写 a/b，根号写 √ 或 sqrt，π 写 pi 也可以。

标准答案：530​​

解析

提示

约束式 5x2+6y2+6z2−8yz≤1 与目标式 x+y+z 关于 y,z 完全对称。

试着想起：2017 年全国高中数学联赛一试（A 卷） 第 3 题 · P007260

在平面直角坐标系 xOy 中，椭圆 C 的方程为 9x2​+10y2​=1，F 为 C 的上焦点，A 为 C 的右顶点，P 是 C 上位于第一象限内的动点，则四边形 OAPF 的面积最大值为。

打开这道题

思路

先将二次型中的 6y2+6z2−8yz 按对称和差配方为 (y+z)2+5(y−z)2，舍去非负项 5(y−z)2 后得到关于 x 与 y+z 的二元平方和约束，再用二元柯西不等式即可一步求出最大值。

解答

利用 y,z 的对称性，将二次型中的后三项按 y+z 与 y−z 配方：

6y2+6z2−8yz=(y+z)2+5(y−z)2.

代入已知条件并利用 5(y−z)2≥0，得

5x2+(y+z)2≤5x2+(y+z)2+5(y−z)2≤1.

再对 x+(y+z) 应用二元柯西不等式：

(x+y+z)2=(x+(y+z))2≤(51​+1)(5x2+(y+z)2)≤56​×1=56​.

因此 x+y+z≤56​​=530​​。 当且仅当 y−z=0、5x=y+z 且 5x2+(y+z)2=1，即 x=3030​​，y=z=1230​​ 时，上述不等式全部取等号。故 x+y+z 的最大值为

530​​​.

复核

将 x=3030​​、y=z=1230​​ 代入核验：y+z=630​​=5x，5x2+6y2+6z2−8yz=5⋅90030​+4⋅14430​=61​+65​=1，且 x+y+z=3030​​+630​​=530​​，等号确能取到。

方法总结

当二次型约束与线性目标对部分变量具有对称性时，优先按对称和 y+z 与差 y−z 正交配方：差平方项在目标中不出现，直接放缩消去即可降维为二元柯西不等式。

为什么评为 F2（会透露解法方向）

按y与z的对称结构令s=y+z、d=y−z，约束成为5x²+s²+5d²≤1，目标x+s直接用配权柯西。
