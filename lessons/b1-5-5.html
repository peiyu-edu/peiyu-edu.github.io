5.5 三角恒等变换

\(\cos(\alpha-\beta)\) 不能拆成 \(\cos\alpha-\cos\beta\)。这一节找出它真正等于什么，再由它得到和角、二倍角公式，最后把 \(a\sin x+b\cos x\) 并成一项。先从两个熟悉的角开始。

\(60^\circ\) 和 \(30^\circ\) 的三角函数值都会：\(\cos60^\circ=\dfrac12=0.5\)，\(\cos30^\circ=\dfrac{\sqrt3}{2}\approx0.866\)。而 \(60^\circ-30^\circ=30^\circ\)。点下面的按钮，比一比单位圆上的投影长度：

算一算：\(\cos(60^\circ-30^\circ)\) 和 \(\cos60^\circ-\cos30^\circ\) 分别约是多少？

B。\(\cos(60^\circ-30^\circ)=\cos30^\circ\approx0.866\)；\(\cos60^\circ-\cos30^\circ\approx0.5-0.866=-0.366\)，连正负号都不一样。

所以 \(\cos\) 不能像乘法分配律那样「拆开」。那 \(\cos(60^\circ-30^\circ)\) 该怎么用 \(60^\circ\)、\(30^\circ\) 各自的值算出来？试试这个：

\(\cos60^\circ\cos30^\circ+\sin60^\circ\sin30^\circ=0.5\times0.866+0.866\times0.5\approx0.866\)。

正好对上。这一节就讲这条公式，以及由它换出来的一串公式。

1. 先认识几个词：和差角、倍角与辅助角变换总纲

要用到：单位圆与诱导公式（5.2、5.3）。三角恒等变换的灵魂是「拆角、合角与降幂」，先看微图解：

直觉微图解 ①旋转等距弦长、二倍角展开与辅助角几何构造全景

口诀心法和角口诀：余弦「同名相反」，正弦「异名相同」

\(\cos(\alpha\pm\beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta\)（两项名字相同，连接符号正好相反）；\(\sin(\alpha\pm\beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta\)（交叉配对，连接符号相同）。

定象限铁律辅助角看点 \((a,b)\) 所在象限，绝不能只算 \(\tan\varphi\)

化简 \(a\sin x+b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)\) 时，\(\cos\varphi = \dfrac{a}{R}\)，\(\sin\varphi = \dfrac{b}{R}\)。角 \(\varphi\) 的终边必经过点 \((a, b)\)。若 \(a=-1, b=-\sqrt{3}\)，点在第三象限，\(\varphi\) 必须取 \(-\dfrac{2\pi}{3}\) 或 \(\dfrac{4\pi}{3}\)，绝不能因为 \(\tan\varphi=\sqrt{3}\) 误取第一象限的 \(\dfrac{\pi}{3}\)！

2. 核心公式全景矩阵

\[\begin{aligned} \textbf{和差角：}&\quad \cos(\alpha\mp\beta)=\cos\alpha\cos\beta\pm\sin\alpha\sin\beta,\quad \sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta \\ \textbf{二倍角：}&\quad \sin 2\alpha = 2\sin\alpha\cos\alpha,\quad \cos 2\alpha = \cos^2\alpha-\sin^2\alpha = 2\cos^2\alpha-1 = 1-2\sin^2\alpha \\ \textbf{降幂扩角：}&\quad \sin^2\alpha = \dfrac{1-\cos 2\alpha}{2},\quad \cos^2\alpha = \dfrac{1+\cos 2\alpha}{2} \\ \textbf{辅助角：}&\quad a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)\quad \left(\cos\varphi=\frac{a}{\sqrt{a^2+b^2}},\ \sin\varphi=\frac{b}{\sqrt{a^2+b^2}}\right) \end{aligned}\]

自己试试：\(\cos75^\circ\) 等于？（\(75^\circ=45^\circ+30^\circ\)）

B。\(\cos75^\circ=\cos45^\circ\cos30^\circ-\sin45^\circ\sin30^\circ=\dfrac{\sqrt6}{4}-\dfrac{\sqrt2}{4}\approx0.259\)。选 A 的同学中间用了加号：和角的余弦中间是减号，A 其实是 \(\cos15^\circ\)。C 是 \(\cos45^\circ+\cos30^\circ\)，约 \(1.57\)，比 \(1\) 还大，余弦不可能这么大。

自己试试：\(\sin15^\circ\) 等于？（\(15^\circ=45^\circ-30^\circ\)）

A。\(\sin15^\circ=\sin45^\circ\cos30^\circ-\cos45^\circ\sin30^\circ=\dfrac{\sqrt6-\sqrt2}{4}\approx0.259\)。选 B 的同学把差角正弦中间写成了加号；C 是 \(\sin45^\circ-\sin30^\circ\)，又「拆开」了。

自己试试：\(\cos\alpha=\dfrac13\)，\(\cos2\alpha\) 等于？

B。手里有 \(\cos\alpha\)，用 \(2\cos^2\alpha-1=\dfrac29-1=-\dfrac79\)。选 A 是把 \(\cos2\alpha\) 当成 \(2\cos\alpha\)；选 C 是把 \(\cos\alpha\) 代进了 \(1-2\sin^2\alpha\) 那个式子，名字对不上。

自己试试：\(3\sin x+4\cos x\) 的最大值是？

B。\(R=\sqrt{9+16}=5\)。选 A 的同学让 \(\sin x\) 和 \(\cos x\) 同时等于 \(1\)，可它们不会同时取到 \(1\)（平方和要是 \(1\)），所以 \(7\) 到不了。

3. 三步破题思维链：三角求值与化简「三看破局」

例题示范：已知 \(\tan\alpha = 2\)，求 \(\dfrac{\sin 2\alpha + \cos 2\alpha}{\sin^2\alpha + 2\cos^2\alpha}\) 的值。

1
👀 第一眼破题信号：分子是二倍角 \(2\alpha\)，分母是单角二次式 \(\alpha\)。角不同、次不同，已知条件是正切 \(\tan\alpha\)。核心目标：角化同、次齐整、切化化！
2
🔧 第二步展开二倍角与齐次分式同除：

• 展开分子：\(\sin 2\alpha = 2\sin\alpha\cos\alpha\)，\(\cos 2\alpha = \cos^2\alpha - \sin^2\alpha\)。

• 原式化为齐次分式：\[\dfrac{2\sin\alpha\cos\alpha + \cos^2\alpha - \sin^2\alpha}{\sin^2\alpha + 2\cos^2\alpha}\]

• 分子分母同时除以 \(\cos^2\alpha\)：化为全 \(\tan\) 形式：\[\dfrac{2\tan\alpha + 1 - \tan^2\alpha}{\tan^2\alpha + 2}\]

3
🛡️ 第三步代入数值终检：

将 \(\tan\alpha = 2\) 代入：分子为 \(2\times 2 + 1 - 4 = 1\)，分母为 \(4 + 2 = 6\)！结果为 \(\dfrac{1}{6}\)。全程无需开方求角所在的象限，正负号完全自洽！

自己试试：\(\tan\alpha=3\)，\(\sin2\alpha\) 等于？

A。\(\dfrac{2\tan\alpha}{\tan^2\alpha+1}=\dfrac{6}{10}=\dfrac35\)。选 B 是把 \(\sin2\alpha\) 当成 \(2\tan\alpha\)，正弦不会大于 \(1\)；C 是 \(\dfrac{2\tan\alpha}{1-\tan^2\alpha}\)，算成了 \(\tan2\alpha\)。

4. 用之前必查：三大高频翻车现场

翻车现场 ①和角余弦公式符号写反（加号误作加号）

典型错解：计算 \(\cos(x+\frac{\pi}{3})\) 时写成 \(\cos x\cos\frac{\pi}{3} + \sin x\sin\frac{\pi}{3}\)。

一眼看清真相：余弦和角公式中间必是减号！\(\cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta\)。反之差角中间才是加号！背口诀「余弦同名符号反」！

翻车现场 ②辅助角公式只算 \(\tan\) 导致象限完全颠倒

典型错解：化简 \(-\sin x - \sqrt{3}\cos x\) 时，算 \(\tan\varphi=\frac{-\sqrt3}{-1}=\sqrt3\)，便断定 \(\varphi=\frac{\pi}{3}\)，写成 \(2\sin(x+\frac{\pi}{3})\)。

看右图秒懂真相：点 \((a,b)=(-1,-\sqrt{3})\) 位于第三象限！\(\cos\varphi=-\frac{1}{2}, \sin\varphi=-\frac{\sqrt3}{2}\)，\(\varphi\) 必须取 \(-\frac{2\pi}{3}\)（即 \(-120^\circ\)）！误取第一象限会与真实函数值正负彻底颠倒！

翻车现场 ③二倍角降幂公式分母漏除以 \(2\)

典型错解：将 \(\sin^2 x\) 降幂误写为 \(1 - \cos 2x\)。

一眼看清真相：由 \(\cos 2x = 1 - 2\sin^2 x\) 移项得 \(2\sin^2 x = 1 - \cos 2x\)，必须除以 \(2\) 得 \(\sin^2 x = \dfrac{1-\cos 2x}{2}\)！忘除 \(2\) 会导致振幅暴涨一倍！

再深一点（可以先跳过）

差角余弦的完整推导：单位圆上取 \(P_1(\cos\alpha,\sin\alpha)\)、\(P_2(\cos\beta,\sin\beta)\)。整个图绕原点转 \(-\beta\)：\(P_2\) 转到 \(A(1,0)\)，\(P_1\) 转到 \(P(\cos(\alpha-\beta),\sin(\alpha-\beta))\)。旋转不改变长度，\(|P_1P_2|=|AP|\)。用两点间距离公式：\(|P_1P_2|^2=2-2(\cos\alpha\cos\beta+\sin\alpha\sin\beta)\)，\(|AP|^2=2-2\cos(\alpha-\beta)\)。两者相等，得证。

积化和差与和差化积：由和差角相加减即得，考试不强求死记，考场随时手推。

① 两条弦一样长（差角余弦从哪来）

拖动单位圆上的 \(P_1\)（角 \(\alpha\)） 和 \(P_2\)（角 \(\beta\)）。点 \(P\) 在角 \(\alpha-\beta\) 的位置，由代码跟着算。看 \(P_1P_2\) 和 \(AP\) 是不是总一样长。键盘：Tab 选中点，方向键每次转 \(5^\circ\)。

试试让 \(P_1\)、\(P_2\) 重合，或让 \(\alpha-\beta\) 超过 \(180^\circ\)。

② 进阶：辅助角 \(\varphi\) 落在哪

点 \((a,b)\) 的横坐标是 \(\sin x\) 的系数，纵坐标是 \(\cos x\) 的系数。拖动它（或点格子），看 \(R\) 和 \(\varphi\) 怎么来。键盘：Tab 选中点，方向键移动。

把点拖到第二象限，\(\varphi\) 是多少？\(\tan\varphi=\frac ba\) 给的角对吗？

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(\alpha\)、\(\beta\) 都是锐角，\(\sin\alpha=\dfrac35\)，\(\cos\beta=\dfrac{5}{13}\)。\(\cos(\alpha+\beta)\) 等于？

B。锐角的余弦、正弦都为正：\(\cos\alpha=\dfrac45\)，\(\sin\beta=\dfrac{12}{13}\)。\(\cos(\alpha+\beta)=\dfrac45\cdot\dfrac{5}{13}-\dfrac35\cdot\dfrac{12}{13}=\dfrac{20-36}{65}=-\dfrac{16}{65}\)。选 A 的同学中间用了加号，那是 \(\cos(\alpha-\beta)\)；D 是 \(\sin(\alpha+\beta)\)。

2. \(\sin15^\circ\cos15^\circ\) 等于？

B。\(\sin15^\circ\cos15^\circ=\dfrac12\cdot2\sin15^\circ\cos15^\circ=\dfrac12\sin30^\circ=\dfrac14\)。选 A 是直接写成 \(\sin30^\circ\)，忘了凑 \(2\) 时要补的 \(\dfrac12\)；C 是把角翻成了 \(60^\circ\)。

易错

3. 已知 \(\tan\alpha=2\)，\(\tan\beta=\dfrac12\)，那么 \(\tan(\alpha+\beta)\) 等于？

C。代公式时分母是 \(1-\tan\alpha\tan\beta=1-2\cdot\frac12=0\)。

分母为 \(0\) 说明 \(\cos(\alpha+\beta)=0\)，即 \(\alpha+\beta=\dfrac{\pi}{2}+k\pi\)，\(\tan(\alpha+\beta)\) 没有定义。A 是把分母写成了 \(1+\tan\alpha\tan\beta\)；B 是看到分母为 \(0\) 就随手当成 \(1\)。正切的和差公式只在所有正切都有意义、分母不为 \(0\) 时才能用。

4. 已知 \(\cos\alpha=\dfrac12\)，且 \(\dfrac{3\pi}{2}<\alpha<2\pi\)，那么 \(\cos\dfrac{\alpha}{2}\) 等于？

B。由 \(\cos\alpha=2\cos^2\dfrac{\alpha}{2}-1\) 得 \(\cos^2\dfrac{\alpha}{2}=\dfrac34\)，开方只能先得到 \(\pm\dfrac{\sqrt3}{2}\)。

符号看半角的范围：\(\dfrac{3\pi}{4}<\dfrac{\alpha}{2}<\pi\)，在第二象限，余弦为负。验证：\(\alpha=\dfrac{5\pi}{3}\)，\(\dfrac{\alpha}{2}=\dfrac{5\pi}{6}\)，\(\cos\dfrac{5\pi}{6}=-\dfrac{\sqrt3}{2}\)。A 是习惯性取正；C 是范围给了却没用上。

5. 解方程 \(\sin2x=\sin x\)，\(x\in[0,2\pi)\)。小明写：\(2\sin x\cos x=\sin x\)，两边约去 \(\sin x\) 得 \(\cos x=\dfrac12\)，所以 \(x=\dfrac{\pi}{3}\) 或 \(\dfrac{5\pi}{3}\)。他对吗？

B。\(\sin x\) 可能等于 \(0\)，不能直接约掉。应该移项提因式：\(\sin x(2\cos x-1)=0\)，所以 \(\sin x=0\) 或 \(\cos x=\dfrac12\)。前者给出 \(x=0,\pi\)，后者给出 \(\dfrac{\pi}{3},\dfrac{5\pi}{3}\)，一共 \(4\) 个解。小明丢了 \(0\) 和 \(\pi\)。

挑战

6. \(\alpha\)、\(\beta\) 都是锐角，\(\cos\alpha=\dfrac45\)，\(\cos(\alpha+\beta)=\dfrac{5}{13}\)。\(\sin\beta\) 等于？

A。比「角」：已知 \(\alpha\) 和 \(\alpha+\beta\)，目标 \(\beta=(\alpha+\beta)-\alpha\)。

\(\sin\alpha=\dfrac35\)；\(0<\alpha+\beta<\pi\)，正弦为正，\(\sin(\alpha+\beta)=\dfrac{12}{13}\)。

\(\sin\beta=\sin(\alpha+\beta)\cos\alpha-\cos(\alpha+\beta)\sin\alpha=\dfrac{12}{13}\cdot\dfrac45-\dfrac{5}{13}\cdot\dfrac35=\dfrac{48-15}{65}=\dfrac{33}{65}\)。选 B 的同学中间用了加号；C 是 \(\sin(\alpha+\beta)\) 取了负号，可锐角 \(\beta\) 的正弦不会是负的。
