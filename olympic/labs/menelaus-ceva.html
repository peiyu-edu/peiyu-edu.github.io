梅涅劳斯与塞瓦：共线与共点

切换三线共点（塞瓦）与截线共线（梅涅劳斯），直接在图中拖动边上分点 E、F 或顶点 A，观察分比乘积等于 1 如何唯一确定底边或延长线上的分点 D。

改变条件

先预测，再核对

先由 u=CE/EA 与 v=AF/FB 估算底边分比 BD/DC = 1/(u·v)，再核对你的预测（误差允许 0.02；共线退化 yₐ=0 或梅涅劳斯模式下平行 u·v=1 时无有限交点）。

为什么成立，边界在哪里

在非退化 △ABC 中，沿三边按循环顺序 B→C→A→B 取分点 D∈BC、E∈CA、F∈AB，记 u = CE/EA > 0，v = AF/FB > 0。塞瓦定理指出：连接顶点与对边内分点的三条塞瓦线 AD、BE、CF 共点于 P，当且仅当 (BD/DC)·(CE/EA)·(AF/FB) = 1（有向线段分比积为 +1）。用同底等高将线段比转化为面积比：BD/DC = S(△ABD)/S(△ACD) = S(△PBD)/S(△PCD) = S(△APB)/S(△APC)，同理 CE/EA = S(△BPC)/S(△BPA)，AF/FB = S(△CPA)/S(△CPB)，三式相乘恒等于 1，故底边内分比必为 BD/DC = 1/(u·v)。

保持同样的两个内分点 E、F，改作截线 EF（梅涅劳斯模式）：由帕施公理，不过顶点的直线不能同时交三角形三边于内点，因此当 E、F 分别为 CA、AB 的内分点时，若 u·v ≠ 1，截线 EF 必然交底边 BC 的延长线于外分点 D。过 A、B、C 向截线 EF 作垂线（或过 C 作 EF 的平行线），利用相似三角形可得长度乘积 (BD/DC)·(CE/EA)·(AF/FB) = 1；若按有向线段计，因 D 为 BC 外分点，BD⃗/DC⃗ = −1/(u·v)，三项有向分比之积等于 −1。

边界与退化姿态：（1）当梅涅劳斯模式下 u·v = 1（即 CE/EA = FB/AF）时，由平行线分线段成比例逆定理知 EF 平行于 BC，截线与底边 BC 平行，欧氏平面内不存在有限交点 D，底边分比 BD/DC 无有限定义（仅在射影平面无穷远点处无向长度比 BD/DC 极限趋于 1，有向分比 BD⃗/DC⃗ 极限为 −1）；（2）当 yₐ = 0 时，A、B、C 三顶点共线，三角形退化为直线段，二维面积比与横截交点 D 不再良定义，此时不进行数值判答。
