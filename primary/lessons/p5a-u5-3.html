用字母表示运算律公式

运算律和图形公式用文字说很长，用字母怎样一眼看清？a² 和 2a 又有什么区别？

本节路线导读

核心问题：怎样把学过的运算律、周长和面积写得简明？a² 和 2a 为什么不能混用？

先修：乘号的省略 · 初中衔接：用字母表示运算规律

想一想：回忆具体算式 → 摆一摆：拖动边长、按行展开 → 讲道理：从数到字母 → 看例题：列式并检验 → 练一练。

查看本课概念与易错卡

先回忆学过的加法交换律：8 + 13 与 13 + 8 都是多少？

换成 24 + 7 与 7 + 24，再换成 3.5 + 2.1 与 2.1 + 3.5。每次改变的是哪些数？不变的是什么？

8 + 13 = 13 + 8；24 + 7 = 7 + 24。交换加数的位置，和没有变。

用 a、b 分别替代两个加数，这个交换过程就写成 a + b = b + a。字母把同一种规律概括到一起。

三年级还学过正方形的周长与面积。先想“四条边相加”和“每行格数 × 行数”，再判断下面的写法。

用 a 表示正方形的边长，它的周长 C 和面积 S 分别怎样用字母表示？

正方形 4 条边相等，周长 C = 4a；面积是边长 × 边长，两个相同的字母相乘 a × a 记作 a²，读作“a 的平方”。

1. 比一比：a² 和 2a 到底有什么不同？

先猜 a = 2 时两边格数是否相同，再猜 a = 4 时呢？拖动滑块验证，最后切换下面的线段，看看每种图形按行展开后有几份。

a² 有 a 行，每行 a 格；线段中的 k 表示行数。

当 a = 3 时，左边 a² = 3 × 3 = 9 格，右边 2a = 2 × 3 = 6 格，9 ≠ 6，两者完全不同！

自己试试：依次取 a = 2、3、4，分别数出“有几行、每行几格”。只试到 a = 2 就说两种式子相同，可靠吗？

为什么字母公式可以把旧知识说清楚？

  1. 运算规律不依赖这一组数字。交换两个加数的位置，和不变；用 a、b 记录两个加数，就是 a + b = b + a。其他学过的运算律也可以照这样把数字换成字母。
  2. 先找数量关系，再简写。正方形四条边相等，周长 C = a + a + a + a = 4a；每行有 a 个单位方格，共有 a 行，面积 S = a × a。
  3. 比较结构，再给名称。a × a 是两个相同的字母相乘，记作 a²，读作“a 的平方”。2a 则是 a + a，也就是 2 × a。a = 2 时数值偶然一样，换成 3、4 就不同；判断含义要看图和运算，不能只看一次试值。

把已经学过的五条运算律换成字母

加法交换律：a + b = b + a

加法结合律：(a + b) + c = a + (b + c)

乘法交换律：ab = ba

乘法结合律：(ab)c = a(bc)

乘法分配律：a(b + c) = ab + ac

如 6 × (10 + 3) = 6 × 10 + 6 × 3：括号里的两部分都要乘外面的数。换成字母时，这个关系保留下来。

a² 读作“a 的平方”，表示两个 a 相乘（a × a）；2a 表示两个 a 相加（2 × a），它们的意义完全不同。

长方形周长公式的两种字母写法：

如果长方形的长是 a，宽是 b，面积是 S = ab，周长 C 有两种等价写法：

  • 写法一：先算“长 + 宽”的和，再乘 2，记作 C = 2(a + b)。
  • 写法二：2 条长加上 2 条宽，记作 C = 2a + 2b。

这正好体现了乘法分配律：2(a + b) = 2a + 2b！

两个容易错的地方

✗ 把 a² 算成 a × 2 例如当 a = 4 时，误把 4² 算成 4 × 2 = 8。
✓ a² 是两个 a 相乘：a × a 当 a = 4 时，4² = 4 × 4 = 16；而 2a 才是 2 × 4 = 8。
✗ 长方形周长写成 2a + b 漏写括号，导致只有长乘了 2，宽没有乘 2。
✓ 加上括号 2(a + b) 或写 2a + 2b 长方形有 2 条长和 2 条宽，长和宽都要乘 2。

例题：同一个长方形，怎样分别求周长和面积？

一张长方形卡纸长 a 厘米、宽 b 厘米。当 a = 7、b = 4 时，求周长与面积。

① 读懂题意：求边线，还是求铺满的格子？

周长是四条边的总长，有两条长和两条宽；面积是每行格数乘行数。先在纸上画出长方形，分别标出这两种量。

② 列式推导：先写关系，再代入

周长 C = 2(a + b) = 2 × (7 + 4) = 22（厘米）。面积 S = ab = 7 × 4 = 28（平方厘米）。

③ 检验：换一种方法核对单位和结果

把四条边相加：7 + 4 + 7 + 4 = 22（厘米）。按 4 行、每行 7 个单位方格数，共 28 个；面积用平方厘米。不能把周长式子漏写成 2a + b。

自己试试

如果用 s 表示路程，v 表示速度，t 表示时间，已知路程公式 s = vt，那么求速度 v 的字母公式是（ ）。

速度 = 路程 ÷ 时间，用字母公式记作 v = s ÷ t；求时间则是 t = s ÷ v。

直接用

1. 运用乘法分配律，5(x + 4) 可以展开写成（ ）。

5(x + 4) = 5 × x + 5 × 4 = 5x + 20。

2. 长方形的长 a = 8 cm，宽 b = 5 cm。它的周长 C = 2(a + b) 是多少 cm？

代入周长公式：C = 2 × (8 + 5) = 2 × 13 = 26（cm）。

3. 汽车平均速度 v = 60 千米/时，行驶时间 t = 3 小时。行驶路程 s = vt 是多少千米？

代入路程公式：s = vt = 60 × 3 = 180（千米）。

容易错

4. 当 a = 5 时，a² 和 2a 的计算结果分别是（ ）。

a² = 5 × 5 = 25；2a = 2 × 5 = 10。

5. 边长为 a 厘米的正方形，如果边长增加 2 厘米，现在正方形的面积是（ ）平方厘米。

现在的边长是（a + 2）厘米，正方形面积 = 边长 × 边长，即 (a + 2)² 平方厘米。

想一想

6. 一个长方形的面积 S = 48 平方厘米，长 a = 8 厘米。根据 S = ab，它的宽 b 是多少厘米？

因为 S = ab，所以宽 b = S ÷ a = 48 ÷ 8 = 6（厘米）。

独立做一做 · 五条运算律都由你写

先独立完成再提交核对。本次作品仅在本页临时保留，刷新即清空，不计入学习记录。

请在每栏写出一个完整的字母等式，不要只写名称。可用 × 或 * 表示乘，括号不能漏。

提交后的核对要点

加法交换：a + b = b + a；结合：(a + b) + c = a + (b + c)。乘法交换：ab = ba；结合：(ab)c = a(bc)；分配：(a + b)c = ac + bc。换用其他字母、等号两边互换也可以，请与同伴核对同样的结构。
