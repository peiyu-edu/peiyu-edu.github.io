用圆规比较线段长短

不用尺子上的刻度量长度，怎样比出两条线段谁长谁短？

查看本课概念与易错卡

纸上有一斜一横两条线段 AB 和 CD，看起来差不多长。如果手边没有带刻度的尺子，只有一把圆规，怎样比出哪条线段更长？

对！圆规是用来画圆的工具，也可以用它量出同样长度的线段。

只要保持圆规两只脚张开的距离不变，就能把线段 AB 的长度「搬」到线段 CD 上比一比。这一课就来动手试一试。

1. 用圆规比一比两条线段的长短

圆规顶上捏手的地方叫手柄，下面有两只脚（一只是有针尖的脚，一只是装笔芯的脚）。按顺序点下面三步按钮，用圆规把线段 AB 移到线段 CD 上比一比；还可以换不同组的线段试试！

把点 A 与点 C 重合（都对齐在左端）：如果点 B 落在点 D 左边，那么 AB < CD；如果点 B 与点 D 重合，那么 AB = CD；如果点 B 落在点 D 右边，那么 AB > CD。

自己试试

像上面那样用圆规比较线段 AB 和线段 CD 的长短，点 A 与点 C 在左端重合。如果点 B 落在了点 D 的右侧（外面），那么 AB 和 CD 谁更长？

C。左端起点对齐后，点 B 超出到了点 D 的右边，说明线段 AB 比线段 CD 长，记作 AB > CD。

2. 在直线上作等长线段、比折线路线

用圆规还能在直线 l 上画出和已知线段一样长的线段，或者把折线的两段首尾相接搬到直线上比总长！在下面动手试试。

在直线上作等长线段时，圆规画出的那道小弧线与直线的交点，就是新线段的端点。如果接着往后作第二段，针尖要固定在第一段刚画出的交点上，这叫首尾相接。

自己试试

在直线 l 上先画长 4 厘米的线段 AB，再用圆规顺着往右作线段 BC 使 BC = AB，接着往右作线段 CD 使 CD = AB（如图）。从点 B 到点 D 的线段 BD 长多少厘米？

8 厘米。BC = AB = 4 厘米，CD = AB = 4 厘米，所以 BD = 4 + 4 = 8（厘米）。

用圆规比线段长短：先将有针尖的脚固定在线段 AB 的端点 A 上，另一只脚张开到点 B；再保持两脚距离不变，将针尖固定在线段 CD 的端点 C 上，转动手柄画弧比一比。

左端起点对齐（点 A 与点 C 重合）后，看另一头：在里面就短（<），重合就相等（=），在外面就长（>）。

两个容易错的地方

✗ 移动圆规时捏着两只脚，把张口捏变了 两脚距离一变，量的就不是原来的长了。
✓ 量好后只捏顶上的“手柄”平移和转动 两脚距离纹丝不动，搬过去才一样长。
✗ 连续截两段时，中间留了空或重回起点 中间断开，总长度就不对了。
✓ 首尾相接：第一段的终点是第二段的起点 两段紧挨着，合起来才是总长。

直接用

如下图，用圆规把线段 AB 移到线段 CD 上，点 A 与点 C 重合，点 B 落在了点 D 的左侧。那么 AB 和 CD 的长短关系是？

A。起点对齐后，点 B 落在点 D 里面，说明线段 AB 比线段 CD 短，记作 AB < CD。

用圆规量好线段 AB 的长度后，要移到直线 l 上作一条同样长的线段，移动时应该怎样拿圆规？

B。捏住顶上的手柄移动和转弧，才能保证两只脚之间的距离不变。

已知线段 MN 长 5 厘米。小芳用圆规量取线段 MN 后，保持两脚距离不变，在直线 l 上作出了线段 PQ（使 PQ = MN）。线段 PQ 长多少厘米？

5 厘米。圆规两脚距离没变，作出的线段 PQ 和线段 MN 一样长，也是 5 厘米。

容易错

观察下面两条带装饰箭头的线段 AB 和 A′B′。用圆规量取 AB 移到 A′B′ 上，发现两端正好重合。这说明什么？

B。两头的箭头会让眼睛误以为上面长、下面短。用圆规一比，两端正好重合，真相是 AB = A′B′！

要把小蚂蚁爬行的两段折线（第 1 段 AB、第 2 段 BC）用圆规移到下面的直线上，合成一条线段比总长。已经从点 M 画弧截出了第 1 段 MN = AB。接下来量好 BC 后，圆规的针尖应该固定在哪里？

C。求两段折线合起来有多长，要首尾相接：第一段的终点 N，就是第二段针尖固定的新起点。

想一想

如下图，两根笔直的木条 AC 和 BD 重叠放在一起（中间重叠的那一段是 BC）。如果用圆规比出左边的 AB = CD，那么整根木条 AC 和整根木条 BD 谁长？

B。AC = AB + BC，BD = CD + BC。因为 AB 和 CD 一样长，同时加上中间公共的一段 BC，结果还是一样长：AC = BD！

已知线段 AB 长 3 厘米。用圆规量取 AB 后，在直线 l 上从点 P 出发，向右边首尾相接连续截取 3 次，最后得到的整条线段长多少厘米？

9 厘米。每次截取的长度都是 3 厘米，首尾相接连续 3 段：3 × 3 = 9（厘米）。
