1.1 集合的概念

把一些对象「打包」成一个整体，并且能说清楚：谁在里面，谁不在。

本节概念地图先认词 → 再认关系 → 再看做法 → 自己用

核心概念：集合是能明确判断成员、把若干对象看成一个整体的数学对象。

前置：初中自然数、整数、有理数、实数　解锁：集合间的基本关系与集合运算

班里学号 \(1\) 到 \(10\) 的十位同学，老师说：「学号是双数的同学，去搬新书。」先点下面的按钮（或直接点学号圆章）试试：

一共有几位同学去搬书？

B。学号 \(2, 4, 6, 8, 10\)，一共 \(5\) 位。

老师这句话把「谁去」说得清清楚楚：报任何一个学号，都能马上答出他去不去——\(7\) 号不去，\(8\) 号去。

这样一群说得清的对象，看成一个整体，就是这一节要讲的集合。同一群人还有两种说法：一个个点名「\(2, 4, 6, 8, 10\) 号」，或者讲规则「\(1\) 到 \(10\) 号里的双数」。这正是集合的两种写法。

1. 概念定义｜先认识几个词：集合与元素（从「收纳盒」到数学定义）

从初中进入高中，第一件事就是学习数学的「通用打包语言」。零散的研究对象叫元素，打包成的整体叫集合：

核心概念 ①集合（Set）与元素（Element）的数学定义

  • 元素（element）：我们把研究的每一个独立对象统称为元素。通常用小写拉丁字母 \(a, b, c, \dots\) 表示。
  • 集合（set，简称为集）：把一些元素组成的总体叫做集合。通常用大写拉丁字母 \(A, B, C, \dots\) 表示。
  • 具身隐喻（数学收纳盒）：零散的数字、点、图形是「物品」（元素）；用一套明确客观的标准把合格物品装进一个密封盒子，这个盒子整体就是「集合」。集合的核心在于：能清楚判定谁在盒里，谁在盒外。

核心概念 ②属于（\(\in\)）vs 不属于（\(\notin\)）

表示元素与集合之间的从属关系：若 \(a\) 是集合 \(A\) 的元素，记作 \(\color{#2F7A56}{a \in A}\)；若不是，记作 \(\color{#B5452F}{a \notin A}\)。
位置铁律：小叉子左边是单个元素，右边是大集合！如 \(0 \in \mathbf{N}\)，但 \(0 \notin \mathbf{N}^*\)。绝不能颠倒写成 \(A \in a\)。

核心概念 ③空集 \(\varnothing\) ≠ \(\{0\}\)！

空集 \(\varnothing\) 是不含任何元素的特殊集合（\(0\) 个元素，空书包）；\(\{0\}\) 是里面装着数字「\(0\)」的单元素集合（\(1\) 个元素，有球的书包）。两者有本质区别！

2. 能当集合的三大铁律

并不是任何一群对象都能叫集合！课标与教材规定，集合里的元素必须满足三大特征：

\(\color{#2F7A56}{\underbrace{\text{确定性}}_{\text{谁在谁不在，标准唯一}}}\) \(\color{#966524}{\underbrace{\text{互异性}}_{\text{同一个元素只写一次（绝不重复）}}}\) \(\color{#3E5C76}{\underbrace{\text{无序性}}_{\text{打乱书写顺序依然是同一集合}}}\)

例 1（示范：跟老师走一遍思考过程）

方程 \(x^2-2x+1=0\) 的解组成的集合是什么？有几个元素？

👀 第一眼看破题信号：解方程求集合，先算出方程所有的实数根。
🔧 第二步因式分解求根： 原方程为 \((x-1)^2=0 \implies x_1=1, x_2=1\)，有两个相等的实数根。
🛡️ 第三步按「互异性」打包： 集合里的元素绝不能重复出现，两个相同的根 \(1\) 只能记一次！所以解组成的集合是 \(\{1\}\)，只有 \(1\) 个元素！

自己试试：下面哪一组对象能组成集合？

B，就是 \(\{1, 2, 3, 4\}\)。A 和 C 都说不清：多高算高？多近算近？\(0.001\) 算接近，\(0.1\) 算不算？给一个对象判断不了在不在，就不「确定」。常见的错是觉得 C 也行——「接近」听起来像数学词，其实没给标准。

3. 集合的两种表示方法：列举法与描述法

表示法 ①列举法：逐一开箱点名

把集合的元素一一列举在大括号内，用逗号隔开。如 \(A = \{1, 2, 3, 4, 5\}\)；有规律的无限集可用省略号表示，如自然数集 \(\{0, 1, 2, 3, \dots\}\)。

表示法 ②描述法：立下准入规则

在大括号内写出元素的代表符号与共同特征。形如 \(\{x \in A \mid p(x)\}\)。最适合元素无限或范围连续的集合（如不等式解集、函数定义域）。

描述法破译秘籍：先看竖线前面的「代表元素」！

\(\{\; \color{#2F7A56}{\underbrace{x \in A}_{\text{看左边代表元：元素到底是什么？（数集还是点集？）}}} \;\mid\; \color{#966524}{\underbrace{p(x)}_{\text{看右边过滤条件：满足什么约束与范围？}}} \;\}\)

例 2（示范：跟老师走一遍思考过程）

用列举法写出 \(B=\{x\in\Z\mid x^2<5\}\)。

👀 第一眼看竖线左边：元素是 整数 \(x \in \mathbf{Z}\)，负整数、\(0\)、正整数都要检验！
🔧 第二步看右边过滤条件： 要求平方小于 \(5\)：\(0^2=0<5\)，\((\pm1)^2=1<5\)，\((\pm2)^2=4<5\)；而 \((\pm3)^2=9\ge5\) 超出。
🛡️ 第三步列举打包： 满足条件的整数有 \(-2, -1, 0, 1, 2\)，列举法写出 \(B=\{-2, -1, 0, 1, 2\}\)，共 \(5\) 个元素。

自己试试：集合 \(\{x\in\N\mid x<4\}\) 有几个元素？

B，是 \(\{0, 1, 2, 3\}\)。选 A 的同学漏了 \(0\)：\(\N\) 含 \(0\)。选 C 是把 \(4\) 也算进去了，可条件是 \(x<4\)，不含 \(4\)。

例 3（点集辨析）

用列举法写出 \(C=\{(x, y)\mid x+y=3,\ x\in\N,\ y\in\N\}\)。

左边是 \((x, y)\)，元素是平面上的点。\(x\) 从 \(0\) 试到 \(3\)，\(y=3-x\) 也要是自然数：\((0, 3)\)，\((1, 2)\)，\((2, 1)\)，\((3, 0)\)。

所以 \(C=\{(0, 3), (1, 2), (2, 1), (3, 0)\}\)，共 \(4\) 个元素。\((1, 2)\) 和 \((2, 1)\) 是两个不同的点，都要写。

自己试试：集合 \(\{(1, 2), (3, 4)\}\) 有几个元素？

A。元素是两个点 \((1, 2)\) 和 \((3, 4)\)。选 B 的同学把每个点里的两个数拆开来数了：一个点不管写几个数，只是一个元素。

4. 用之前必查：三大高频翻车现场

翻车现场 ①解出字母参数后，漏查「互异性」
❌ 典型错解：已知集合 \(A=\{1, a\}\)，若 \(a^2=1\) 解得 \(a=\pm1\)，直接写出 \(a=1\) 或 \(a=-1\)。
✅ 一眼看清真相：代回原集合检验！若 \(a=1\)，集合变成 \(\{1, 1\}\)，严重违背了互异性！因此必须舍去 \(a=1\)，唯一正确解只有 \(a=-1\)。
翻车现场 ②自然数集 \(\mathbf{N}\) 总是漏掉 \(0\)
❌ 典型错解：把「小于 \(4\) 的自然数集」写成 \(\{1, 2, 3\}\)（误以为自然数从 \(1\) 开始）。
✅ 一眼看清真相：高中数学国家标准：\(0\) 属于自然数集 \(\mathbf{N}\)（非负整数）！只有带星号的 \(\mathbf{N}^*\)（或 \(\mathbf{N}_+\)）才是正整数。正确集合是 \(\{0, 1, 2, 3\}\)。
翻车现场 ③（最高频！）把空集写成 \(\{\varnothing\}\) 或 \(\{0\}\)
❌ 典型错解：方程 \(x^2=-1\) 在实数范围内无解，写解集为 \(\{0\}\) 或 \(\{\varnothing\}\)。
✅ 看右图秒懂真相：\(\{0\}\) 含有 \(1\) 个元素 \(0\)；\(\{\varnothing\}\) 含有 \(1\) 个元素 \(\varnothing\)；只有纯粹的 \(\varnothing\) 才是空空如也的空集（\(0\) 个元素）！
再深一点（可以先跳过）

有限集和无限集：\(\{1, 2, 3\}\) 元素能数完，叫有限集；\(\N\)、\(\{x\mid x>1\}\) 元素数不完，叫无限集。无限集一般用描述法；元素有规律时也可以列举加省略号，如 \(\{1, 3, 5, 7, \dots\}\)。

描述法里的字母可以换：\(\{x\mid x>1\}\) 和 \(\{t\mid t>1\}\) 是同一个集合，字母只是个代号。从实数里取时，「\(\in\R\)」常常省略不写。

元素可以是任何东西：数、点、字母、人，甚至集合本身。比如 \(\{\{1\}, 2\}\) 有两个元素：一个是集合 \(\{1\}\)，一个是数 \(2\)。

① 描述法 → 列举法

选一个集合，拖动滑块改参数 \(a\)。数轴上实心绿点是集合里的元素。点一个数（或用 Tab 选中后按回车），看它为什么在或不在。

② 进阶：数集还是点集

拖动点 \(P\)（或选中后用方向键移动，每次 0.5）。靠近抛物线会自动吸上去。看同一个 \(y = x^2\) 配三种「左边」时，判断结果有什么不同。

图例：蓝色抛物线 是点集 \(\{(x,y)\mid y=x^2\}\)；整条 x 轴 是 \(\{x\mid y=x^2\}\)；y 轴的上半段 是 \(\{y\mid y=x^2\}\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 用列举法写 \(\{x\in\Z\mid -1\le x<3\}\)，是哪一个？

B。左边：\(x\) 是整数；右边：\(-1\le x<3\)。\(-1\) 能取（带等号），\(3\) 不能取（不带等号）。选 A 的同学漏了 \(-1\)：负整数也是整数。选 C 的同学多写了 \(3\)。

2. 下面哪个写法是对的？

C。\(-3\) 是整数。A：\(\N^*\) 是正整数，\(0\) 不是正数；B：\(\sqrt2\) 是无理数，不在 \(\Q\) 里；D：\(\dfrac12\) 不是整数。

易错

3. 把英文单词 letter 里出现的字母放进一个集合。这个集合里有几个元素？

C，是 \(\{l, e, t, r\}\)。

选 6 的同学是在数「字母出现了几次」。可集合只关心「谁在里面」：\(e\) 和 \(t\) 各出现两次，也只算一个元素——互不相同。顺序也不重要，写成 \(\{r, t, e, l\}\) 还是同一个集合。

4. \(\{(1, 2)\}\) 和 \(\{1, 2\}\) 是同一个集合吗？

\(\{(1, 2)\}\) 的元素是一个点 \((1, 2)\)，只有 1 个元素；\(\{1, 2\}\) 的元素是两个数。比较集合前，先弄清元素是数还是点。

5. \(a\) 是一个实数。集合 \(\{x \mid x^2 = a\}\) 里一定有元素吗？

\(a < 0\) 时，没有实数的平方等于 \(a\)，集合里一个元素都没有。A 默认了 \(\sqrt a\) 存在；C 把「没有元素」当成了 \(\{0\}\)，可 \(0^2 = 0 \ne a\)，0 根本不在里面。有参数时，先想清楚集合会不会是空的。

挑战

6. 已知集合 \(A = \{1,\ a,\ a^2 - a\}\) 含有 3 个元素，且 \(2 \in A\)，那么 \(a\) 等于多少？

B。\(\{1,\ a,\ a^2-a\}\) 含有 3 个元素，说明这三个式子的值必须互不相同。

\(2 \in A\)，要么 \(a = 2\)，要么 \(a^2 - a = 2\)（解得 \(a = 2\) 或 \(a = -1\)）。

• 若 \(a = 2\)，则 \(a = 2\) 且 \(a^2 - a = 2\)，集合退化为 \(\{1, 2\}\) 只有 2 个元素，与题设「含有 3 个元素」矛盾，舍去；

• 若 \(a = -1\)，集合为 \(\{1, -1, 2\}\)，三个元素互不相同，符合题意。因此只有 \(a = -1\)。

【核心经验】：解出含参集合的参数后，必须代回原集合核验互异性！
