导数应用的核心是把函数条件转成可控制的符号、斜率和极值关系。先确定定义域，再区分局部极值、全局最值与仅能逼近的上确界；含参数时，必要条件与充分性必须分别证明。切线、零点和恒成立不等式常共享同一个辅助函数，但开闭端点、严格性以及等号能否同时成立要分别核查。

知识要点

导数符号与单调区间

求导前先确定函数在哪些连通区间上有定义。导数非负可保证单调不减，但一个驻点并不必然是极值点；若导数不在任何非退化子区间恒为零，仍可严格递增。例如 F(x)=x3 有 F′(0)=0，却在整个实数轴严格递增。写最大单调区间时，函数有定义的驻点端点通常可以并入，分母禁值则不能并入。

最值、极值与上确界

闭区间上的连续函数求最值，要比较两个端点及全部内部驻点；开区间还须检查边界极限。例如 F(x)=x3−3x 在 [0,2] 的候选值为 F(0)=0,F(1)=−2,F(2)=2，故值域为 [−2,2]。而 1−x 在 (0,1) 的上确界为 1，没有最大值；不能把极限值当成已经取得的函数值。

含参单调条件是全区间交集

可导函数的单调性给出导数符号约束，分离参数后须对整个区间同时成立。例如 F(x)=ex−cx 在 [0,+∞) 上单调递增，当且仅当 c≤1：必要性看 x=0 处的右导数，充分性由 ex≥1。临界参数处导数可以在孤立点为零，不能因此删去端点；除以自变量前还要按正负分别改变不等号方向。

斜率界与两点函数值之差

若函数在闭区间连续、内部可导，中值定理把两点差商化为某处导数。全区间 ∣F′∣≤L 给出 ∣F(u)−F(v)∣≤L∣u−v∣；若导数同号且绝对值至少为 L，则可得反向差值下界。例如 F(x)=x2 在 [1,2] 有 2≤F′(x)≤4，所以任意两点的函数值差介于 2∣u−v∣ 与 4∣u−v∣ 之间。

在驻点方程中消参或消对数

极值点往往无法显式解出，但导数为零给出的等式可以简化该点的函数值。例如 F(x)=xlnx−2x 的驻点满足 lnx=1，所以 x=e 且 F(e)=−e。若驻点由参数决定，也可反过来把参数写成驻点的函数，再证明这一函数单调；注意“导数为零”还需配合符号变化或凸性才能认定极值。

零点计数看分支与边界

含参方程能解成 a=h(x) 时，研究水平线与各单调分支的交点。要保留定义域、无穷远极限和重根信息。例如 x2−2x=a 在全实数上有两根当且仅当 a>−1，但限制 x>0 后，两根需 −1<a<0；a=0 的零根不在定义域。含取整或整数解的问题应先分段，再在每段比较端点符号。

切线条件先翻译成代数

在切点横坐标为 t 处，切线为 y=F(t)+F′(t)(x−t)。给定斜率先解 F′(t)=k，过点条件则给出函数值与导数值的线性关系。例如 y=x2 在 t=1 的切线为 y=2x−1；它与坐标轴围成的三角形面积为 1/4。面积或距离式含参数时，还需核查切点存在、两线不同和长度的绝对值。

差函数、连续求导与临界退化

证明不等式可将两边相减，利用已知初值和导数符号逐层返回。例如 H(x)=ex−1−x 满足 H(0)=H′(0)=0、H′′(x)>0，故 x>0 时 H(x)>0。判断指定点的局部极值时，二阶项消失必须继续检查；x3 在零点两侧异号，而 x4 在零点有严格极小值，不能仅凭二阶导数为零下结论。

导数的正负告诉我们函数在升还是降。把导数写成因式乘积，按它变号的点、函数没有定义的点和不可导的点切段，就知道每一段的增减。闭区间上的最大值和最小值，要比较所有分点和两个端点的函数值。

一、是什么

导数是什么

导数 f′(x) 表示函数在 x 处变化的快慢，也就是图像在这一点切线的斜率。以 f(x)=x2 为例，从 x 走到 x+h，平均变化率是 h(x+h)2−x2​=2x+h。让 h 越来越接近 0，这个值越来越接近 2x，所以 (x2)′=2x。

求导公式

常数的导数是 0；(xn)′=nxn−1，n 可以是分数或负数，所以 (x​)′=(x1/2)′=2x​1​，(x1​)′=(x−1)′=−x21​。加减和常数倍可以逐项求：(3x2−5x)′=6x−5。乘积：(uv)′=u′v+uv′，例如 (x⋅x)′=1⋅x+x⋅1=2x，与上面一致。商：(vu​)′=v2u′v−uv′​，要求 v=0。

导数的正负决定增减

在一段连在一起、处处有导数的区间上，f′(x)>0 则函数严格递增，f′(x)<0 则严格递减。直观理由是切线上坡时函数在升，严格证明要用大学的中值定理，这里直接使用。导数只在个别点等于 0 时不影响结论：(x3)′=3x2 只在 x=0 为零，x3 仍在整条数轴上严格递增。这也说明导数为零的点不一定是最大或最小的位置。

为什么只比较分点和端点

导数等于零的点叫驻点。闭区间上函数没有断点、内部处处有导数时，用驻点把区间切成几段，每段都单调，所以每段的最大值和最小值都在这段的两端。于是整个区间的最值，一定出现在驻点或区间端点。比周围都大的点叫极大值点，它只和附近比，不一定是全局最大。例如 x3−3x+1 在 [−2,3] 上，x=−1 处是极大值 3，而全局最大值是 x=3 处的 19。

没有定义的点也要切开

函数 f(x)=x1​ 的导数 −x21​ 处处为负，但 f(−1)=−1<f(1)=1，它不是在整个定义域上递减。原因是 x=0 把定义域断成两段，导数的结论只能在每一段内部使用。所以它的递减区间要写成 (−∞,0) 和 (0,+∞) 两段，不能合并。驻点处函数有定义时可以算进单调区间，写成闭端点。

有定义但没有导数的点也要比较

绝对值的折点就是这种点。g(x)=∣x∣+x2，x∈[−1,2]：x<0 时 g′(x)=−1+2x<0，x>0 时 g′(x)=1+2x>0。x=0 处图像有尖角，左边斜率接近 −1，右边接近 1，没有一条确定的切线，所以没有导数。这里没有驻点，只比较端点值 g(−1)=2，g(2)=6 会出错，最小值其实是 g(0)=0，值域是 [0,6]。它和分母为零的点不同：这种点函数有值，要算进比较，也可以写成单调区间的闭端点；分母为零的点函数没有值，不能算进比较，两侧也不能合并。

先看一道例题

例 1：闭区间上求值域

求 f(x)=x3−3x+1 在 [−2,3] 上的取值范围。

怎么看出来：

闭区间上的三次多项式，直接求导，比较驻点和端点。

解：

f(x) 处处有定义。f′(x)=3x2−3=3(x−1)(x+1)，驻点是 x=−1 和 x=1，都在区间内。符号：(−2,−1) 上 f′>0，(−1,1) 上 f′<0，(1,3) 上 f′>0。函数值：f(−2)=−8+6+1=−1，f(−1)=−1+3+1=3，f(1)=1−3+1=−1，f(3)=27−9+1=19。最小值是 −1，最大值是 19，最大值出现在端点，而不是驻点。函数没有断点，所以 −1 和 19 之间的值都能取到。

答案：

[−1,19]。

二、什么时候想到它

题目里看到应该想到
求单调区间，如 f(x)=x−1x2​写定义域，求导，把导数化成因式乘积，列符号表
闭区间上求最值或值域，如 x∈[−2,3]算出所有驻点、有定义但不可导的点和两个端点的函数值，一起比较
函数含绝对值，如 ∣x∣+x2绝对值的折点可能没有导数，要先分段，并把折点算进切段的点
导数的分母是平方，如 (x−1)2x(x−2)​分母恒正，符号只看分子，但分母为零的点仍要切开
区间不含端点或伸向无穷，如 x∈(0,+∞)比较驻点后，再看两端的趋势（见进阶“开区间的边界”）
比较两个形式相同的数，如 20262027 和 20272026取对数后构造同一个函数，用它的单调性比较（见进阶“指数、对数、三角函数”）
问方程有几个实根，或导数的正负看不出来用单调性加两边异号，或再求一次导（见进阶“再求一次导与数根”）

三、怎么用

  1. 写定义域。例如 f(x)=2x3−3x2，x∈[−1,2]，全程有定义。
  2. 求导并因式分解，恒正的因子可以不看。f′(x)=6x2−6x=6x(x−1)。
  3. 列出切段的点：导数为零的点、没有定义的点、有定义但不可导的点、区间端点。这里没有后两种，切段点是 −1,0,1,2，每段取一个值试正负：(−1,0) 上取 x=−21​，f′=4.5>0；(0,1) 上取 x=21​，f′=−1.5<0；(1,2) 上取 x=23​，f′=4.5>0。
  4. 读出增减。f 在 [−1,0] 和 [1,2] 上递增，在 [0,1] 上递减。
  5. 算所有切段点的函数值并比较。f(−1)=−5，f(0)=0，f(1)=−1，f(2)=4，所以最小值 −5，最大值 4，值域是 [−5,4]，因为函数没有断点，中间的值都能取到。

四、再做一道

例 2：有分母的单调区间

求 f(x)=x−1x2​ 的单调区间。

怎么看出来：

分式函数要用商的公式，并且 x=1 没有定义，必须切开。

解：

定义域是 x=1。由商的公式，f′(x)=(x−1)22x(x−1)−x2​=(x−1)2x2−2x​=(x−1)2x(x−2)​。分母恒正，符号由 x(x−2) 决定。切段点是 0,1,2：x<0 时 f′>0；0<x<1 和 1<x<2 时 f′<0；x>2 时 f′>0。驻点 0 和 2 处函数有定义，可以写成闭端点。[0,1) 和 (1,2] 不能合并：f(21​)=−21​，f(23​)=29​，自变量变大时函数值也变大，不是递减。

答案：

递增区间 (−∞,0] 和 [2,+∞)；递减区间 [0,1) 和 (1,2]。

五、容易错在哪

  • 只比较导数为零的点会漏掉端点和不可导的点，最值常常出现在这些地方，所以它们必须一起算。
  • 极大值只比附近的值大，不一定是全局最大值，要和其他驻点、端点比较后才能下结论。
  • 导数在没有定义的点两侧同号，也不能把两段合并成一个单调区间，因为函数在这里断开了。
  • 导数等于零不代表函数在这里取极值，还要看两侧是否变号，例如 x3 在 x=0 处导数为零，两侧都递增。
  • 开区间上的值域要检查两端的趋势，取不到的边界要用开括号。
进阶：开区间的边界 · 先修：本卡基础部分

开区间：端点取不到，要看趋势

区间不含端点或伸向无穷时，函数值可能只是越来越接近某个数，却取不到。这种“越来越接近”叫极限。常用的办法是把函数夹住。例如 x>0 时 0<x2+1x​<x1​，x 越大右边越接近 0，所以函数值越来越接近 0，但永远不等于 0。写值域时这一端用开括号。

例 3：开区间的值域

求 f(x)=x2+1x​ 在 (0,+∞) 上的值域。

怎么看出来：

区间两端都取不到，所以除了驻点，还要看两端函数值的趋势。

解：

f′(x)=(x2+1)2(x2+1)−x⋅2x​=(x2+1)2(1−x)(1+x)​。x>0 时分母和 1+x 都为正，符号由 1−x 决定：0<x<1 时递增，x>1 时递减，所以最大值是 f(1)=21​。两端的趋势：x 接近 0 时分子接近 0、分母接近 1，函数值接近 0；x 很大时 0<f(x)<x1​，函数值也接近 0。而 x>0 时始终 f(x)>0，所以 0 取不到。函数没有断点，0 和 21​ 之间的值都能取到。

答案：

(0,21​]。

进阶：指数、对数、三角函数 · 先修：对数定义、正弦余弦

指数、对数、三角函数和复合函数的导数

e≈2.718 是一个固定的数，lnx 表示以 e 为底的对数，要求 x>0，且随 x 增大而增大。公式：(ex)′=ex，(lnx)′=x1​，(sinx)′=cosx，(cosx)′=−sinx。复合函数先对外层求导，再乘内层的导数：[ln(x+1)]′=x+11​，(2x+1​)′=22x+1​1​⋅2=2x+1​1​。

例 4：用单调性比较大数

比较 20262027 和 20272026 的大小。

怎么看出来：

数太大不能直接算。两边取对数后，指数和底数可以分开，都写成 xlnx​ 的形式。

解：

设 f(x)=xlnx​，x>0。f′(x)=x2x1​⋅x−lnx​=x21−lnx​。分母为正；x>e 时 lnx>1，所以 f′(x)<0，f 在 (e,+∞) 上递减。因为 e<2026<2027，得 2026ln2026​>2027ln2027​。两边同乘正数 2026×2027，得 2027ln2026>2026ln2027，即 ln20262027>ln20272026。lnx 是增函数，所以 20262027>20272026。

答案：

20262027>20272026。

例 5：三角函数的最值

求 f(x)=x+2cosx 在 [0,π] 上的最大值和最小值。

怎么看出来：

求导后是 1−2sinx，令它为零，得到两个驻点，再和端点比较。

解：

f′(x)=1−2sinx。在 [0,π] 上 sinx=21​ 的解是 x=6π​ 和 x=65π​。0≤x<6π​ 时 f′>0，6π​<x<65π​ 时 f′<0，65π​<x≤π 时 f′>0。函数值：f(0)=2；f(6π​)=6π​+3​≈2.26；f(65π​)=65π​−3​≈0.89；f(π)=π−2≈1.14。比较这四个数。

答案：

最大值 6π​+3​，最小值 65π​−3​。

进阶：再求一次导与数根 · 先修：对数定义、正弦余弦

导数的正负看不出来时，再求一次导

把 f′ 本身当成新函数，求它的最小值。例如 f(x)=ex−2x2​，f′(x)=ex−x，正负不明显。再求导：(ex−x)′=ex−1，x<0 时为负，x>0 时为正，所以 f′ 的最小值是 f′(0)=1>0。于是 f′(x)>0 处处成立，f 在整条数轴上严格递增。

用单调性数实根

严格单调的函数每个值最多取一次，所以方程 f(x)=0 最多一个实根。函数没有断点时，从负值变到正值，中间一定经过 0，所以两边异号又保证至少一个实根。例如 f(x)=x3+3x−1：f′(x)=3x2+3>0，f(0)=−1<0，f(1)=3>0，所以恰有 1 个实根，它在 0 和 1 之间。

进阶：含参数的函数 · 先修：本卡基础部分

函数里有参数：按驻点的位置分类

参数决定驻点在不在区间里、落在哪一段。先按导数能否变号分类，再按驻点在区间内或区间外分类。例如 f(x)=x2−2ax 在 [0,1] 上，f′(x)=2(x−a)：a≤0 时递增，最小值 f(0)=0；0<a<1 时先减后增，最小值 f(a)=−a2；a≥1 时递减，最小值 f(1)=1−2a。

例 6：驻点位置随参数变化

设 a 为实数，求 f(x)=x3−3ax 在 [0,2] 上的最小值。

怎么看出来：

f′(x)=3(x2−a)，驻点 a​ 是否存在、是否落在区间内，都由 a 决定。

解：

分三种情况。当 a≤0 时，f′(x)=3(x2−a)≥0，f 递增，最小值是 f(0)=0。当 0<a<4 时，驻点 a​ 在 (0,2) 内，0<x<a​ 时 f′<0，a​<x<2 时 f′>0，先减后增，最小值是 f(a​)=aa​−3aa​=−2aa​。当 a≥4 时，x∈[0,2] 都有 x2≤4≤a，f′≤0，f 递减，最小值是 f(2)=8−6a。检查分界：a=4 时 −2⋅4⋅2=−16，8−24=−16，两式一致。

答案：

a≤0 时为 0；0<a<4 时为 −2aa​；a≥4 时为 8−6a。

误区对照

容易误以为

f(x)=x3 满足 f′(0)=0，所以 x=0 是 f 的极值点。

应当这样想

f′(x)=3x2 在 x=0 两侧都为正，f 在 R 上严格递增，x=0 不是极值点。

为什么

对可导函数，导数为零只是极值点的必要条件；还要检查导数在该点两侧是否变号。

容易误以为

f(x)=x3−ax 在 R 上单调递增，所以 f′(x)=3x2−a>0 恒成立，得 a<0。

应当这样想

a=0 时 f(x)=x3 仍严格递增，只是 f′(0)=0。正确条件是 f′(x)≥0 恒成立且等号不在一段区间上成立，即 3x2≥a 对所有 x 成立，得 a≤0。

为什么

f′>0 是递增的充分条件而非必要条件；孤立的零导数点不破坏单调性，所以参数范围要用 f′≥0 并回查端点值。

容易误以为

求 f(x)=x3−3x 在 [−2,3] 上的最大值：f′(x)=3(x−1)(x+1)，极大值 f(−1)=2，所以最大值是 2。

应当这样想

闭区间上的最大值要在驻点和端点中比较：f(−2)=−2，f(−1)=2，f(1)=−2，f(3)=18。最大值为 f(3)=18。

为什么

极大值只是局部比较；全局最值必须把区间端点一起列入候选。

概念自测

先想清楚，再确认判断。这些自测只帮助辨清概念，不计入真题做对率。

1. 函数 f(x)=x3−ax 在 R 上单调递增，当且仅当：

遗漏前提：孤立的零导数点不破坏单调性，条件应为 f′≥0。a=0 时 f=x3 也严格递增；只在孤立点 f′=0 不影响单调。

正确。需 3x2−a≥0 对一切 x 成立，取 x=0 得 a≤0，反之 a≤0 时 f′≥0 且只在至多一点为零。

遗漏前提：恒成立要在 3x2 取最小值的点检验。取 a=3，f′(0)=−3<0，在 0 附近递减。不等式 3x2≥a 的最紧处在 x=0。

遗漏前提：恒成立要取 3x2 的最小值 0 而非某个特殊点的值。a=3 时 f′(0)=−3<0；恒成立条件要在 3x2 的最小值 0 处检查，而不是在 x=1 处。

2. 对 f(x)=x3+1，x=0 是：

遗漏前提：极小值点要求导数在该点由负变正。f′(x)=3x2 在 0 的左侧也为正，导数没有由负变正。

遗漏前提：极大值点要求导数在该点由正变负。f′(x)=3x2 在 0 的右侧仍为正，导数没有由正变负。

正确。f′(0)=0，但两侧 f′>0，f 严格递增，故不是极值点。

3. f(x)=x3−3x 在闭区间 [−2,3] 上的最大值为：

遗漏前提：闭区间上的最值须把端点列入候选。2=f(−1) 只是极大值；右端点 f(3)=27−9=18 更大。

正确。候选值 f(−2)=−2,f(−1)=2,f(1)=−2,f(3)=18，最大为 18。

遗漏前提：闭区间上的连续函数必有最大值。多项式在闭区间上连续，最大值一定存在。
