7.3 复数的三角表示（选学）

用模长与辐角表示复数：让乘除法变成「模相乘除、角相加减」的旋转与伸缩，架起代数与平面几何的桥梁。
本节为选学内容，帮助建立代数与几何旋转的深层联系。

在数轴上，把一个数乘以 \(-1\)，相当于把这个点绕原点逆时针旋转了 \(180^\circ\)（半圈）。如果乘以虚数单位 \(i\)，因为 \(i^2 = -1\)，连续乘两次 \(i\) 相当于旋转 \(180^\circ\)。猜一猜：乘一次 \(i\)，是不是逆时针转 \(90^\circ\)？这一节学了乘法法则就能说清楚。

如果从正实轴上的点 \((1, 0)\) 出发，绕原点逆时针旋转 \(45^\circ\)（长度保持为 \(1\)），它落在了第一象限的角平分线上。这个点在复平面上对应的复数是多少？

入门题：把复平面上对应实数 \(1\) 的单位向量绕原点逆时针旋转 \(45^\circ\)，终点对应的复数是？

B。根据直角三角形与三角函数定义：向量长度 \(r=1\)，横坐标为 \(\cos 45^\circ = \dfrac{\sqrt{2}}{2}\)，纵坐标为 \(\sin 45^\circ = \dfrac{\sqrt{2}}{2}\)。所以对应的复数是 \(\dfrac{\sqrt{2}}{2} + \dfrac{\sqrt{2}}{2}i\)。

用代数形式 \(a+bi\) 看起来，这一堆根号并不直观；但如果用「长度为 \(1\)、方向角为 \(45^\circ\)」来看，位置一目了然！这一节我们就来学习复数的三角表示：用距离和方向角描述复数，让几何旋转变成乘除运算。

1. 先认识几个词

要用到：复数的代数形式、复平面和模（回看 7.1）；复数的乘除（回看 7.2）；任意角的三角函数（回看 5.2）；两角和与差的公式（回看 5.5）。

模 \(r=|z|\)：复数 \(z=a+bi\) 对应的点 \(Z(a,b)\) 到原点的距离，\(r=\sqrt{a^2+b^2}\)。它总是 \(\ge 0\)，只有 \(z=0\) 时等于 \(0\)。

例：\(z=1+\sqrt3 i\) 的模 \(r=\sqrt{1^2+(\sqrt3)^2}=2\)；\(z=-3\) 的模是 \(3\)，不是 \(-3\)。

辐角：以正实轴为始边、射线 \(OZ\) 为终边的角 \(\theta\)，叫 \(z\) 的辐角。转一整圈回到同一条射线，所以一个非零复数的辐角有无数个，彼此相差 \(2k\pi\)（\(k\in\mathbf Z\)）。

例：\(z=1+i\) 在第一象限角平分线上，\(\dfrac{\pi}{4}\)、\(\dfrac{9\pi}{4}\)、\(-\dfrac{7\pi}{4}\) 都是它的辐角。

辐角主值 \(\arg z\)：无数个辐角里，落在 \([0,2\pi)\) 内的那一个（本书的约定）。每个非零复数恰有一个主值。

例：\(\arg i=\dfrac{\pi}{2}\)，\(\arg(-1)=\pi\)，\(\arg(-i)=\dfrac{3\pi}{2}\)，\(\arg(1+i)=\dfrac{\pi}{4}\)（不是 \(\dfrac{9\pi}{4}\)）。

2. 代数形式和三角形式互化

非零复数 \(z=a+bi\) 对应点 \(Z(a,b)\)。设模为 \(r\)、辐角为 \(\theta\)，由任意角三角函数的定义，\(a=r\cos\theta\)，\(b=r\sin\theta\)。代回 \(z=a+bi\)：

\(z=r(\cos\theta+i\sin\theta)\)
其中 \(r=|z|>0\)，\(\cos\theta=\dfrac{a}{r}\)，\(\sin\theta=\dfrac{b}{r}\)。

这叫复数的三角形式。标准写法有四条要求：\(r>0\)；中间是「\(+\)」；\(\cos\) 在前、\(i\sin\) 在后；两个角相同。

  • 三角 → 代数：算出 \(\cos\theta\)、\(\sin\theta\)，乘进去就行。
  • 代数 → 三角：先算 \(r\)；再看点 \((a,b)\) 在哪个象限或哪条轴上，找同时满足 \(\cos\theta=\dfrac ar\)、\(\sin\theta=\dfrac br\) 的角。只看 \(\tan\theta=\dfrac ba\) 容易差半圈。

例 1（两个方向各走一遍）

(1) 把 \(z=-\sqrt3+i\) 写成三角形式。(2) 把 \(w=2\left(\cos\dfrac{4\pi}{3}+i\sin\dfrac{4\pi}{3}\right)\) 写成代数形式。

解：(1) 模 \(r=\sqrt{(-\sqrt3)^2+1^2}=2\)。\(\cos\theta=-\dfrac{\sqrt3}{2}\)，\(\sin\theta=\dfrac12\)，点 \((-\sqrt3,1)\) 在第二象限，取 \(\theta=\dfrac{5\pi}{6}\)。

所以 \(z=2\left(\cos\dfrac{5\pi}{6}+i\sin\dfrac{5\pi}{6}\right)\)，辐角主值 \(\dfrac{5\pi}{6}\)。

(2) \(\cos\dfrac{4\pi}{3}=-\dfrac12\)，\(\sin\dfrac{4\pi}{3}=-\dfrac{\sqrt3}{2}\)，

\(w=2\left(-\dfrac12-\dfrac{\sqrt3}{2}i\right)=-1-\sqrt3 i\)。点 \((-1,-\sqrt3)\) 在第三象限，和 \(\dfrac{4\pi}{3}\) 对得上。

自己试试：把 \(z = 1 - i\) 化为标准三角形式，模和辐角主值是？

A。模 \(r = \sqrt{1^2 + (-1)^2} = \sqrt{2}\)；\(\cos\theta = \dfrac{\sqrt{2}}{2}\)，\(\sin\theta = -\dfrac{\sqrt{2}}{2}\)，点 \((1,-1)\) 在第四象限，主值是 \(\dfrac{7\pi}{4}\)。

选 B：数值对，但中间是减号，不是标准形；选 C：模忘了开方；选 D：模不能是负数。

3. 乘法：模相乘，辐角相加

设 \(z_1=r_1(\cos\theta_1+i\sin\theta_1)\)，\(z_2=r_2(\cos\theta_2+i\sin\theta_2)\)。直接展开（\(i^2=-1\)）：

\[\begin{aligned} &z_1 z_2 = r_1 r_2 \big[ \\ &\quad(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) \\ &\quad+ i(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)\big]\end{aligned}\]

两个圆括号正好是 \(\cos(\theta_1+\theta_2)\) 和 \(\sin(\theta_1+\theta_2)\) 的展开式，于是：

\[\begin{aligned} z_1 z_2 = r_1 r_2\big[&\cos(\theta_1+\theta_2) \\ &+ i\sin(\theta_1+\theta_2)\big]\end{aligned}\] 模相乘，辐角相加。

几何意义：\(z\) 乘以 \(r_0(\cos\theta_0+i\sin\theta_0)\)，就是把向量 \(\overrightarrow{OZ}\) 伸缩到原来的 \(r_0\) 倍，再绕原点逆时针转 \(\theta_0\)（\(\theta_0<0\) 时顺时针）。比如 \(i=\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\)，乘 \(i\) 就是逆时针转 \(90^\circ\)，长度不变。

例 2（用三角形式算，再用代数形式验）

求 \((1+\sqrt3 i)(\sqrt3+i)\)。

解：\(1+\sqrt3 i=2\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)\)，\(\sqrt3+i=2\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)\)。

模相乘 \(2\times2=4\)，辐角相加 \(\dfrac{\pi}{3}+\dfrac{\pi}{6}=\dfrac{\pi}{2}\)：

积 \(=4\left(\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\right)=4i\)。

验算：\((1+\sqrt3 i)(\sqrt3+i)=\sqrt3+i+3i+\sqrt3 i^2=4i\)。一致。

自己试试：\(z_1=2\left(\cos\dfrac{5\pi}{4}+i\sin\dfrac{5\pi}{4}\right)\)，\(z_2=3(\cos\pi+i\sin\pi)\)。\(z_1z_2\) 的模和辐角主值是？

A。模 \(2\times3=6\)；辐角 \(\dfrac{5\pi}{4}+\pi=\dfrac{9\pi}{4}\)，超出 \([0,2\pi)\)，减去 \(2\pi\) 得主值 \(\dfrac{\pi}{4}\)。积 \(=3\sqrt2+3\sqrt2 i\)。

选 C：\(\dfrac{9\pi}{4}\) 是辐角，但不是主值；选 B：模要相乘，不是相加；选 D：把模相除了。

4. 除法：模相除，辐角相减

为什么：设 \(\dfrac{z_1}{z_2}=w\)（\(z_2\ne0\)），则 \(w\cdot z_2=z_1\)。按乘法法则，\(w\) 的模乘 \(r_2\) 得 \(r_1\)，\(w\) 的辐角加 \(\theta_2\) 得 \(\theta_1\)，所以 \(w\) 的模是 \(\dfrac{r_1}{r_2}\)，辐角是 \(\theta_1-\theta_2\)。

\[\begin{aligned} \frac{z_1}{z_2} = \frac{r_1}{r_2}\big[&\cos(\theta_1-\theta_2) \\ &+ i\sin(\theta_1-\theta_2)\big]\end{aligned}\] 模相除，辐角相减（被除数的角减除数的角）；要求 \(z_2\ne0\)。

几何上，除以 \(z_2\) 就是伸缩到 \(\dfrac{1}{r_2}\) 倍，再顺时针转 \(\theta_2\)。

例 3

\(z_1=2\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)\)，\(z_2=\cos\dfrac{2\pi}{3}+i\sin\dfrac{2\pi}{3}\)，求 \(\dfrac{z_1}{z_2}\)。

解：模 \(\dfrac{2}{1}=2\)；辐角 \(\dfrac{\pi}{6}-\dfrac{2\pi}{3}=-\dfrac{\pi}{2}\)。

\(\dfrac{z_1}{z_2}=2\left[\cos\left(-\dfrac{\pi}{2}\right)+i\sin\left(-\dfrac{\pi}{2}\right)\right]=-2i\)。

减出负角没关系，它也是辐角；要主值就加 \(2\pi\)，得 \(\dfrac{3\pi}{2}\)。

验算：\(-2i\cdot z_2=-2i\left(-\dfrac12+\dfrac{\sqrt3}{2}i\right)=i+\sqrt3\)，正是 \(z_1=\sqrt3+i\)。

自己试试：\(z_1=3\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)\)，\(z_2=6\left(\cos\dfrac{5\pi}{6}+i\sin\dfrac{5\pi}{6}\right)\)。\(\dfrac{z_1}{z_2}=\)？

A。模 \(\dfrac36=\dfrac12\)；辐角 \(\dfrac{\pi}{3}-\dfrac{5\pi}{6}=-\dfrac{\pi}{2}\)，所以商 \(=\dfrac12(0-i)=-\dfrac12 i\)。

选 B：减反了，用了 \(\theta_2-\theta_1\)；选 C：模除反了；选 D：除法却把角相加了。

5. 用之前要注意

  1. 0 没有确定的辐角，不写三角形式；除数不能是 0。三角形式要求 \(r>0\)，原点引不出确定方向的射线。
    反例：写 \(0=0(\cos0+i\sin0)\)，换成 \(0(\cos1+i\sin1)\) 也等于 \(0\)，角想取什么都行，所以「\(\arg 0=0\)」没有意义。
  2. 模必须是正数。
    反例：\(-2\left(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\right)=-\sqrt2-\sqrt2 i\)，它的模是 \(2\)、主值是 \(\dfrac{5\pi}{4}\)，标准形是 \(2\left(\cos\dfrac{5\pi}{4}+i\sin\dfrac{5\pi}{4}\right)\)，不能读成「模 \(-2\)、角 \(\dfrac{\pi}{4}\)」。
  3. 必须是「\(\cos\theta+i\sin\theta\)」：加号、cos 在前、两个角相同，否则不能直接读模和角、不能套乘除法则。
    反例：\(2\left(\cos\dfrac{\pi}{3}-i\sin\dfrac{\pi}{3}\right)\) 的辐角是 \(-\dfrac{\pi}{3}\)，不是 \(\dfrac{\pi}{3}\)；\(\sin\theta+i\cos\theta\) 要改写成 \(\cos\left(\dfrac{\pi}{2}-\theta\right)+i\sin\left(\dfrac{\pi}{2}-\theta\right)\)；\(2\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{6}\right)=1+i\)，模其实是 \(\sqrt2\)，两个角不同就不是三角形式。
  4. 判断辐角要看象限，不能只看 \(\tan\)。
    反例：\(-1-i\) 的 \(\tan\theta=1\)，但它在第三象限，主值是 \(\dfrac{5\pi}{4}\)，不是 \(\dfrac{\pi}{4}\)。
  5. 辐角有无数个，相差 \(2k\pi\)；主值才唯一。相加、相减后的角可能跑出 \([0,2\pi)\)，要主值就加减 \(2\pi\) 的整数倍。讲「转了多少度」时也一样：转 \(\theta\) 和转 \(\theta+2\pi\) 落在同一处。
    反例：两角相加得 \(\dfrac{7\pi}{3}\)，主值是 \(\dfrac{\pi}{3}\)；有的书把主值取在 \((-\pi,\pi]\)，看到不同答案先核对约定。
三角形式只给非零复数，标准形是 \(r(\cos\theta+i\sin\theta)\)，\(r>0\)。乘：模乘、角加；除：模除、角减，除数非零。角算完记得按需化成主值。
再深一点（可以先跳过）

乘方：同一个复数连乘 \(n\) 次，模变成 \(r^n\)，辐角变成 \(n\theta\)：

\(z^n=r^n(\cos n\theta+i\sin n\theta)\)。

例：\((1+i)^4\)：模 \((\sqrt2)^4=4\)，角 \(4\times\dfrac{\pi}{4}=\pi\)，结果 \(-4\)。

方程 \(z^n=1\) 的根（拓展，不要求人人会）：模为 \(1\)、辐角为 \(\dfrac{2k\pi}{n}\)（\(k=0,1,\dots,n-1\)）的 \(n\) 个点，在 \(n\ge3\) 时正好是单位圆内接正 \(n\) 边形的顶点。这里辐角的多值性很关键：\(n\theta\) 只要等于 \(2k\pi\) 就行，不一定是 \(0\)。

以后会见到：大学里把 \(\cos\theta+i\sin\theta\) 记作 \(\mathrm e^{i\theta}\)（欧拉公式），「角相加」就成了指数相加。本节不用它。

直接用

1. 复数 \(z = 4\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right)\) 的代数形式 \(a+bi\) 是？

A。计算特殊角三角函数值：\(\cos\dfrac{2\pi}{3} = -\dfrac{1}{2}\)，\(\sin\dfrac{2\pi}{3} = \dfrac{\sqrt{3}}{2}\)。

展开可得：\(z = 4\left(-\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right) = -2 + 2\sqrt{3}i\)。

2. 已知 \(z_1 = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)\)，\(z_2 = 3\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\)，则 \(z_1 z_2\) 等于？

B。应用复数乘法的三角法则：模相乘、辐角相加。

模长为 \(2 \times 3 = 6\)；辐角为 \(\dfrac{\pi}{6} + \dfrac{\pi}{3} = \dfrac{\pi}{2}\)。

所以 \(z_1 z_2 = 6\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 6(0 + i) = 6i\)。

选 C 的同学错把模长相加了；选 D 的同学把辐角相减了（\(\dfrac{\pi}{3}-\dfrac{\pi}{6}=\dfrac{\pi}{6}\)），乘法要相加。

易错

3. 下列各式中，哪一个是复数的标准三角形式？

D。标准三角形式必须同时满足四要素：模 \(r > 0\)；中间必须是加号；前余弦、后正弦；两处角完全一致。

A 的模长为 \(-2 < 0\)，三角形式要求模 \(r>0\)；

B 中间是减号，不是加号；

C 前正弦后余弦，颠倒了；

D 完全符合标准结构（它对应的正是点 \((\sqrt{2}, -\sqrt{2})\) 在第四象限的三角形式）。

4. 关于复数 \(z = 0\) 的模与辐角，下列说法正确的是？

B。复数 \(0\) 在复平面上对应原点 \(O\)。到原点的距离（模）确定且等于 \(0\)；但从原点出发不能确定一条射线的方向，因此零复数没有确定的辐角（或称辐角是任意的）。

零复数不能写成确定的标准三角形式，这也是除法法则中分母必须非零的原因。

挑战

5. 复数 \(z_1 = 1 + \sqrt{3}i\)，\(z_2 = 1 + i\)。计算商 \(\dfrac{z_1}{z_2}\) 的模与辐角主值是？

A。化为三角形式：

\(z_1 = 1 + \sqrt{3}i = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\)，模 \(r_1 = 2\)，\(\arg z_1 = \dfrac{\pi}{3}\)；

\(z_2 = 1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)\)，模 \(r_2 = \sqrt{2}\)，\(\arg z_2 = \dfrac{\pi}{4}\)。

根据除法法则（模相除、角相减）：

模长为 \(\dfrac{r_1}{r_2} = \dfrac{2}{\sqrt{2}} = \sqrt{2}\)；辐角为 \(\dfrac{\pi}{3} - \dfrac{\pi}{4} = \dfrac{\pi}{12}\)。

所以 \(\dfrac{z_1}{z_2} = \sqrt{2}\left(\cos\dfrac{\pi}{12} + i\sin\dfrac{\pi}{12}\right)\)。如果用代数形式实数化分母，计算会繁琐得多；三角形式让除法变得异常简洁！
