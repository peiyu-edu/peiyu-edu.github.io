八年级上册 · 第十六章 整式的乘法

16.1 幂的运算

\(a^3\cdot a^2\)、\((a^3)^2\)、\((ab)^3\) 长得很像，算法却各不相同。只要回到乘方的意义——「几个相同的因数相乘」——数一数有几个因数，三条性质就都出来了。

本节导读　先修：2.3 有理数的乘方 · 本节路线

要用到：乘方的意义、幂、底数、指数，负数乘方的符号规律（回看 2.3）；单项式与合并同类项（回看 4.2）。

  1. 从折纸进入：先折 3 次再折 2 次，一共几层？
  2. 同底数幂相乘：数因数个数，指数相加。
  3. 幂的乘方：几个相同的幂相乘，指数相乘。
  4. 积的乘方：每个因式（连同数字和符号）都要乘方。
  5. 三条性质对照，分清「乘、乘方、加」；性质也能倒过来用。
  6. 练习与中考真题，回看最容易错的一步。

一张纸对折一次变成 \(2\) 层，再对折又翻一倍。点下面的按钮，看看折几次是几层：

先对折 \(3\) 次，再接着对折 \(2\) 次，这叠纸一共有多少层？

B。每折一次乘一个 \(2\)：先乘 \(3\) 个 \(2\)，再乘 \(2\) 个 \(2\)，一共乘了 \(5\) 个 \(2\)，\(2^5=32\)。选 A 是把 \(8\) 层和 \(4\) 层加了起来；选 C 是把指数 \(3\) 和 \(2\) 乘了起来；选 D 是算成了 \(5\times2\)。

写成式子就是 \(2^3\times2^2=2^5\)。这一节要回答：幂和幂相乘、幂再乘方、积再乘方，结果的指数怎么来？

1. 先认识几个词：幂、底数、指数

前置提醒：乘方在七年级学过（回看 2.3）。\(a^n\) 表示 \(n\) 个 \(a\) 相乘，\(a\) 叫底数，\(n\) 叫指数，乘方的结果 \(a^n\) 叫幂。没写指数的 \(a\) 就是 \(a^1\)。本节的指数都是正整数，指数里出现字母时，也表示正整数。

直觉微图解 ①两个底数相同的幂相乘：把因数排成一行，数一数

对比 ①同底数幂相乘：能合成一个幂

\(a^3\cdot a^2\) 是 \(3+2\) 个 \(a\) 相乘，等于 \(a^5\)。只看两件事：底数一样吗？中间是乘号吗？

对比 ②同底数幂相加：不能用指数相加

\(a^3+a^2\) 不是同类项，不能合并；\(a^3+a^3=2a^3\) 是合并同类项，系数相加、指数不变。

2. 核心点：同底数幂的乘法

\(a^m\) 是 \(m\) 个 \(a\) 相乘，\(a^n\) 是 \(n\) 个 \(a\) 相乘，接在一起就是 \(m+n\) 个 \(a\) 相乘。底数可以是任意数，条件只加在指数上。

\(\color{#966524}{a^m}\cdot\color{#2F7A56}{a^n}=\underbrace{a^{\color{#966524}{m}+\color{#2F7A56}{n}}}_{\text{底数不变，指数相加}}\)

（\(m,n\) 都是正整数）三个及以上同底数幂相乘也一样：\(a^m\cdot a^n\cdot a^p=a^{m+n+p}\)。

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

计算：(1) \(y^4\cdot y^3\cdot y\)；(2) \((-3)^2\times(-3)^5\)；(3) \(b^{m}\cdot b^{m+2}\)。

① 读懂题意：三道都是幂相乘。先检查：底数相同吗？有没有藏着的指数？

提示 1：先找底数和指数

(1) 底数都是 \(y\)，最后一个 \(y\) 的指数是 \(1\)；(2) 底数都是 \(-3\)，整个 \(-3\) 是底数；(3) 指数是代数式 \(m\) 和 \(m+2\)。

看完整示范
② 想办法：底数都相同、都是乘法，用「底数不变，指数相加」；指数里有字母时，按整式加法把指数加起来。
③ 执行：(1) \(y^{4+3+1}=y^8\)；(2) \((-3)^{2+5}=(-3)^7=-2187\)；(3) \(b^{m+(m+2)}=b^{2m+2}\)。
执行中检查：(2) 用数值核对：\((-3)^2=9\)，\((-3)^5=-243\)，\(9\times(-243)=-2187\) ✓；奇数个负因数，积为负 ✓。

④ 回头看：(1) 最容易漏掉 \(y\) 的指数 \(1\)；(3) 说明性质对字母指数一样成立，指数部分用的是整式加减。

自己试试：\(m^2\cdot m^4\cdot m\) 等于多少？

B。\(m^{2+4+1}=m^7\)。选 A 是把指数 \(2\times4\times1\) 乘了；选 C 漏了 \(m\) 的指数 \(1\)；选 D 把「三个幂相乘」当成了「三个相同的项相加」。

3. 核心点：幂的乘方

\((a^3)^2\) 是什么意思？是 \(2\) 个 \(a^3\) 相乘：\(a^3\cdot a^3=a^{3+3}=a^6\)。一般地，\(n\) 个 \(a^m\) 相乘，指数是 \(n\) 个 \(m\) 相加，也就是 \(m\times n\)。

直觉微图解 ②\((a^m)^n\)：\(n\) 组，每组 \(m\) 个 \(a\)，摆成长方形

\((a^{\color{#966524}{m}})^{\color{#2F7A56}{n}}=\underbrace{a^{\color{#966524}{m}\color{#2F7A56}{n}}}_{\text{底数不变，指数相乘}}\)

（\(m,n\) 都是正整数）依据：乘方的意义 + 同底数幂的乘法。

例 2（示范）

计算：(1) \((y^3)^4\)；(2) \(-(b^2)^5\)；(3) \((x^2)^3\cdot x^4\)。

① 读懂题意：(2) 的负号在括号外面，(3) 是乘方和乘法混在一起。先做哪一步？

提示：先乘方，再乘

(2) 括号外的负号不参加乘方，留到最后；(3) 先算 \((x^2)^3\)，再和 \(x^4\) 相乘。

看完整示范
③ 执行：(1) \(y^{3\times4}=y^{12}\)；(2) \(-b^{2\times5}=-b^{10}\)；(3) \(x^{6}\cdot x^4=x^{10}\)。
执行中检查：(3) 数个数：\((x^2)^3\) 是 \(6\) 个 \(x\)，再乘 \(4\) 个，共 \(10\) 个 ✓。

④ 回头看：同一道题里「乘方的指数相乘」「相乘的指数相加」各用一次，按步骤写，指数才不会混。

自己试试：\((p^4)^2\) 等于多少？

B。\(2\) 个 \(p^4\) 相乘，指数 \(4\times2=8\)。选 A 是指数相加了（那是 \(p^4\cdot p^2\)）；选 C 把 \(4\) 平方了；选 D 把乘方当成了「两个相加」。

4. 核心点：积的乘方

\((ab)^3=(ab)(ab)(ab)\)。用乘法交换律、结合律把 \(a\) 放在一起、\(b\) 放在一起，就是 \(a^3b^3\)。积里的每一个因式都要乘方，数字因数和它的符号也算一个因式。

直觉微图解 ③积的乘方：拆开、按字母重新排队

\((\color{#966524}{a}\color{#2F7A56}{b})^n=\underbrace{\color{#966524}{a^n}\color{#2F7A56}{b^n}}_{\text{每个因式都乘方}}\)

（\(n\) 是正整数）三个及以上因式的积也一样：\((abc)^n=a^nb^nc^n\)。

例 3（示范）

计算：(1) \((-3y)^2\)；(2) \((-2xy^3)^3\)；(3) \(0.25^{6}\times4^{6}\)。

① 读懂题意：(1)(2) 括号里是几个因式的积；(3) 是两个幂相乘，但底数不同。

提示 1：括号里有哪些因式

(2) 括号里有 \(-2\)、\(x\)、\(y^3\) 三个因式，三个都要 \(3\) 次方。

提示 2：(3) 把性质倒过来用

指数相同的两个幂相乘：\(a^nb^n=(ab)^n\)。\(0.25\times4\) 等于多少？

看完整示范
③ 执行：(1) \((-3)^2y^2=9y^2\)；(2) \((-2)^3x^3(y^3)^3=-8x^3y^9\)；(3) \((0.25\times4)^6=1^6=1\)。
执行中检查：符号：(1) 负数的偶次方为正 ✓；(2) 负数的奇次方为负 ✓。

④ 回头看：(3) 若直接算 \(0.25^6\) 和 \(4^6\) 会很繁；性质是等式，从右往左用常常更省事。

自己试试：\((-2a^2)^2\) 等于多少？

B。\((-2)^2\cdot(a^2)^2=4a^4\)。选 A 没给符号乘方（负数的偶次方为正）；选 C 漏乘了数字因数；选 D 是 \(a^2\) 没有乘方。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）同底数幂相乘，把指数乘了
❌ 典型错解：\(a^3\cdot a^2=a^6\)。
✅ 看图秒懂：\(3\) 个 \(a\) 接上 \(2\) 个 \(a\)，一共 \(5\) 个，\(a^3\cdot a^2=a^5\)。指数相乘的是 \((a^3)^2\)。
翻车现场 ②乘法和加法串了
❌ 典型错解：\(m^3+m^3=m^6\)；\(m^3\cdot m^3=2m^3\)。
✅ 一眼看清：加法只能合并同类项：\(m^3+m^3=2m^3\)；乘法才用指数相加：\(m^3\cdot m^3=m^6\)。先问「这是加还是乘」。
翻车现场 ③积的乘方漏乘数字或符号
❌ 典型错解：\((2a)^3=2a^3\)；\((-2a)^2=-4a^2\)。
✅ 一眼看清：\(2\) 也是因式：\((2a)^3=8a^3\)；\(-2\) 整个乘方：\((-2a)^2=(-2)^2a^2=4a^2\)。
再深一点（可以先跳过）：为什么一直强调「正整数指数」「乘」？

三条性质都是从「几个相同因数相乘」数出来的，所以指数必须是正整数。指数是 \(0\) 或负数时，\(a^0\)、\(a^{-2}\) 还没有意义，16.2 和第十八章会先给它们规定意义，再看性质是否仍然成立。另外，三条性质只管乘法和乘方：\((a+b)^2\) 是「和」的乘方，不能写成 \(a^2+b^2\)，到 16.3 再细看。

① 同底数幂相乘：指数相加

拖动两个圆点（或点一下圆点再用方向键）改变 \(m\)、\(n\)。金色是 \(a^m\) 的因数，绿色是 \(a^n\) 的因数。

② 幂的乘方：指数相乘

拖动 \(m\)、\(n\)：每一行是一个 \(a^m\)，一共 \(n\) 行。数一数总共几个 \(a\)。

③ 进阶：带系数的积的乘方 \((k\,a^p)^n\)

拖动系数 \(k\)、指数 \(p\) 和乘方次数 \(n\)。上面一行是 \(n\) 个 \(k\,a^p\) 相乘，下面把系数和字母分开算。

从易到难排好了。卡住时先展开提示。

直接用

1. 计算 \(x^2\cdot x^5\cdot x\)。

B。\(x^{2+5+1}=x^8\)。A 漏了 \(x\) 的指数 \(1\)；C 是把指数 \(2\times5\times1\) 乘了；D 把相乘当成了相加。

2. 某服务器每秒约处理 \(10^6\) 次请求，一天约 \(10^5\) 秒。它一天大约处理多少次请求？

B。\(10^6\times10^5=10^{6+5}=10^{11}\)。A 把指数相乘了；C 把底数也相乘了；D 把「乘」当成了「两个 \(10^{11}\) 相加」。

易错

3. 计算 \((a^3)^4\)。

提示

\((a^3)^4\) 是几个 \(a^3\) 相乘？每个 \(a^3\) 有几个 \(a\)？

B。\(4\) 个 \(a^3\) 相乘，指数 \(3\times4=12\)。A 是指数相加了；C 是算成了 \(3^4\)；D 把乘方当成了相加。

4. 计算 \((-3x^2y)^2\)。

提示

括号里有 \(-3\)、\(x^2\)、\(y\) 三个因式，每个都要平方；\((-3)^2\) 是正还是负？

B。\((-3)^2(x^2)^2y^2=9x^4y^2\)。A 符号没乘方；C 漏了 \(y\)；D 漏乘了数字因数。

5. 下列计算正确的是哪一个？

提示

每个选项先问：这是加、乘，还是乘方？再用对应的规则算一遍。

C。幂的乘方，指数相乘 \(2\times3=6\)。A 是合并同类项，应为 \(2a^2\)；B 应为 \(a^5\)；D 应为 \(4a^2\)。

挑战

6. 已知 \(x^a=2\)，\(x^b=4\)（\(a\)、\(b\) 是正整数），求 \(x^{3a+2b}\) 的值。

提示 1：指数是和，想到哪条性质？

\(x^{3a+2b}=x^{3a}\cdot x^{2b}\)。

提示 2：指数是积，再拆一次

\(x^{3a}=(x^a)^3\)，\(x^{2b}=(x^b)^2\)。

A。\(x^{3a+2b}=(x^a)^3\cdot(x^b)^2=2^3\times4^2=8\times16=128\)。（这组条件能同时成立，例如 \(x=2\)、\(a=1\)、\(b=2\)：\(2^{3+4}=128\) ✓。）B 是把 \(8\) 和 \(16\) 加了起来；C 是把 \(x^{3a}\) 当成 \(3\times2\)、\(x^{2b}\) 当成 \(2\times4\) 后再相加：\(6+8=14\)。

幂的运算常在中考填空题的前几题出现，也常藏在「下列运算正确的是」里。做完看分步解析。
