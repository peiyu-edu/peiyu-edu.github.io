10.2 事件的相互独立性

两件事「互不影响」，在数学里用一个等式来说：\(P(AB)=P(A)P(B)\)。它和「互斥」是两回事，判断它要靠算或靠试验本身，不能凭感觉。先从一枚硬币和一颗骰子开始。

先抛一枚硬币，再掷一颗骰子。硬币有正、反 \(2\) 种结果，骰子有 \(1\sim6\) 共 \(6\) 种，合起来 \(2\times6=12\) 种等可能结果。点下面的按钮在 \(2\times6\) 棋盘上看看：

「硬币正面朝上，并且骰子掷出 \(6\)」的概率是多少？

A。\(12\) 种结果里，只有「正，\(6\)」这一种符合，概率 \(\dfrac1{12}\)。

再看：硬币正面的概率是 \(\dfrac12\)，骰子掷出 \(6\) 的概率是 \(\dfrac16\)，而 \(\dfrac12\times\dfrac16=\dfrac1{12}\)，正好是两个概率相乘。

硬币怎么落，不影响骰子怎么落，所以能乘。这一节就讲：什么样的两个事件能这样相乘（叫「相互独立」），怎么判断，以及它和「互斥」有什么不同。

1. 先认识几个词

要用到：10.1 的样本空间、古典概型、事件的关系和运算（回看 10.1）。

伴读直觉微图解：相互独立乘法本质与互斥辨析

积事件 \(AB\)：\(A\) 和 \(B\) 同时发生，也写成 \(A\cap B\)。

例：掷一颗骰子，\(A=\)「点数是偶数」\(=\{2,4,6\}\)，\(B=\)「点数 \(\ge4\)」\(=\{4,5,6\}\)。那么 \(AB=\{4,6\}\)，\(P(AB)=\dfrac26=\dfrac13\)。

互斥：\(A\)、\(B\) 不可能同时发生，\(AB\) 是空的，\(P(AB)=0\)。

例：掷一颗骰子，\(A=\{2,4,6\}\)，\(C=\)「点数是 \(1\) 或 \(3\)」\(=\{1,3\}\)。没有公共的点数，\(A\)、\(C\) 互斥。

对立事件 \(\overline A\)：\(A\) 不发生。\(P(\overline A)=1-P(A)\)。

例：\(A=\)「点数是偶数」，\(\overline A=\)「点数是奇数」\(=\{1,3,5\}\)，\(P(\overline A)=1-\dfrac12=\dfrac12\)。

两步试验的样本空间：掷两颗骰子，结果记成 \((i,j)\)，\(i\) 是第一颗、\(j\) 是第二颗的点数。一共 \(6\times 6=36\) 种，可能性一样，可以排成一张 \(6\times 6\) 的格子。

例：「点数和为 \(3\)」\(=\{(1,2),(2,1)\}\)，占 \(2\) 格，概率 \(\dfrac2{36}=\dfrac1{18}\)。

核心对决 相互独立 vs 互斥事件

相互独立：用 \(P(AB) = P(A)P(B)\) 定义。若 \(P(A)>0\)，才可等价地说 \(P(B\mid A)=P(B)\)。独立不要求两个概率都为正，也不保证交集非空。

互斥事件：两事件不可能同时发生，\(AB = \varnothing \implies P(AB) = 0\)。这描述集合关系，独立描述概率的乘积关系。

若 \(P(A)>0, P(B)>0\)，互斥必不独立，独立必不互斥。边界例子：\(A=\varnothing\) 时，它与任意 \(B\) 既互斥又独立，因为 \(0=0\cdot P(B)\)。

抽样对比 放回抽样 vs 不放回抽样

有放回抽样：每次放回后充分混匀，并独立地随机抽取，才可用各次抽取独立的模型，各步概率相乘。

不放回抽样：后次抽样的总体组成通常因前次结果而变，不能直接假设独立。先计算条件概率；是否独立仍由 \(P(AB)=P(A)P(B)\) 判断。

提醒：大样本抽样（如数万件中抽数件）虽不放回，但因基数极大，可近似看作相互独立处理。

相互独立定义公式：\(P(AB) = \color{#2563eb}{P(A)}\times \color{#059669}{P(B)}\)
对立独立传递性：\(A, B\text{ 独立} \iff \overline{A}, \overline{B}\text{ 独立} \iff P(\overline{A}\,\overline{B}) = \color{#dc2626}{P(\overline{A})}\times \color{#059669}{P(\overline{B})}\)
“至少发生一个”求逆：\(P(A \cup B) = 1 - P(\overline{A}\,\overline{B}) = 1 - [1 - \color{#2563eb}{P(A)}][1 - \color{#059669}{P(B)}]\)

2. 什么叫相互独立

入门题里，「硬币正面」和「骰子是 \(6\)」同时发生的概率，正好等于两个概率相乘。我们就用这个等式来定义「互不影响」：

如果 \(P(AB)=P(A)P(B)\)，就说事件 \(A\) 与 \(B\) 相互独立（简称独立）。

为什么是相乘：两步各自进行时，样本点是「第一步的结果 \(\times \) 第二步的结果」。\(A\) 只看第一步、\(B\) 只看第二步，那么 \(AB\) 的个数 \(=\) \(A\) 的个数 \(\times \) \(B\) 的个数，除以总数，就是概率相乘。

例 1（看一遍怎么写）

掷两颗骰子，\(A=\)「第一颗是偶数」，\(B=\)「点数和为 \(7\)」。\(A\) 与 \(B\) 独立吗？

\(A\)：第一颗是 \(2,4,6\)，第二颗随便，\(3\times 6=18\) 格，\(P(A)=\dfrac{18}{36}=\dfrac12\)。

\(B\)：\((1,6),(2,5),(3,4),(4,3),(5,2),(6,1)\)，\(6\) 格，\(P(B)=\dfrac6{36}=\dfrac16\)。

\(AB\)：上面第一颗是偶数的 \((2,5),(4,3),(6,1)\)，\(3\) 格，\(P(AB)=\dfrac3{36}=\dfrac1{12}\)。

\(P(A)P(B)=\dfrac12\times \dfrac16=\dfrac1{12}=P(AB)\)，所以 \(A\) 与 \(B\) 独立。

「和」明明跟第一颗有关，算出来却是独立的。所以判断独立要算，不能看着像就下结论。

自己试试：掷两颗骰子，\(A=\)「第一颗是偶数」，\(B=\)「点数和为 \(8\)」。\(A\) 与 \(B\) 独立吗？

B。\(B=\{(2,6),(3,5),(4,4),(5,3),(6,2)\}\)，只有 \(5\) 格，\(P(B)=\dfrac5{36}\)；\(AB=\{(2,6),(4,4),(6,2)\}\)，\(P(AB)=\dfrac3{36}=\dfrac1{12}\)。而 \(P(A)P(B)=\dfrac12\times \dfrac5{36}=\dfrac5{72}\)，\(\dfrac1{12}=\dfrac6{72}\ne\dfrac5{72}\)，不独立。和为 \(7\) 独立，不等于和为 \(8\) 也独立；常见的错是照例 1 类推，或者把和为 \(8\) 也数成 \(6\) 格。

3. 已知独立，就用乘法

实际问题里，独立通常来自试验本身：两个人各自射击、两台机器各自运转、摸球后放回再摸……一次的结果碰不到另一次。题目说「相互独立」也算。这时直接用 \(P(AB)=P(A)P(B)\)。

还有一条常用：\(A\) 与 \(B\) 独立，那么 \(A\) 与 \(\overline B\)、\(\overline A\) 与 \(B\)、\(\overline A\) 与 \(\overline B\) 也都独立（「甲没中」和「乙没中」照样互不影响），「都不发生」也能用乘法。

例 2

甲、乙两人各自射击一次，甲命中的概率是 \(0.8\)，乙是 \(0.6\)，互不影响。求：(1) 两人都中；(2) 都不中；(3) 至少一人中。

(1) 两人都中：\(P=0.8\times 0.6=0.48\)。

(2) 都不中：甲不中是 \(1-0.8=0.2\)，乙不中是 \(1-0.6=0.4\)。因为独立，都不中也是相乘：\(P=0.2\times 0.4=0.08\)。

(3) 至少一人中：对立事件是「都不中」，所以 \(P=1-0.08=0.92\)。

第 (3) 问也可以把「甲中乙不中」「甲不中乙中」「两个都中」加起来：\(0.8\times 0.4+0.2\times 0.6+0.8\times 0.6=0.32+0.12+0.48=0.92\)。但用对立事件算一次乘法就够了。「至少一个」优先想对立。

自己试试：两个开关各自工作，正常的概率分别是 \(0.9\) 和 \(0.7\)，互不影响。至少一个正常的概率是？

B。对立事件是「两个都不正常」，概率 \((1-0.9)\times (1-0.7)=0.1\times 0.3=0.03\)，所以至少一个正常是 \(1-0.03=0.97\)。选 A 的同学算的是「两个都正常」；选 C 的同学以为是 \(0.9\) 加上剩下的部分，没走乘法。

4. 三步破题思维链：独立事件解题标准动作

1
👀 第一眼破题信号

寻找题目中的独立源泉（“各自射击/相互独立/有放回抽样”），理清涉及的各基本事件 \(A, B, C\)。分清所求目标是“全部发生”（积事件）、“至少发生一个”（对立求逆）还是“恰有一件发生”（互斥拆分）。

2
🔧 第二步套公式/方法

① 求全发生：直接相乘 \(P(AB) = P(A)P(B)\)；
② 求“至少一人/台发生”：正难则反，套用逆向对立公式 \(P = 1 - P(\overline{A}\,\overline{B}) = 1 - (1-P(A))(1-P(B))\)；
③ 求“恰好一人发生”：按互斥分类写成 \(A\overline{B} + \overline{A}B\)，分别相乘后求和。

3
🛡️ 第三步必查防坑结论

核查独立性前提（不放回抽样不能把两次原概率原样相乘，先按剩余组成重算后次概率）；核查加法对象是否互斥（独立事件不可盲目直接相加）；最终算出的概率值必须落在 \([0,1]\) 闭区间内。

5. 三大翻车现场与反例辨析

翻车现场 1：把「互斥」当「独立」套乘法公式
❌ 抛骰子 \(A=\)「点数是偶数」，\(B=\)「点数是奇数」，互斥，却套公式算 \(P(AB)=\frac12\times \frac12 = \frac14\)
✔ 互斥表示两事件绝不同时发生，必然有 \(P(AB) = 0\)；正概率互斥事件必然不独立！
翻车现场 2：不放回抽样误套独立乘法
❌ 袋内 2 红 1 白，不放回抽两次，误以为两次摸出红球独立，算出 \(P = \frac23\times \frac23 = \frac49\)
✔ 第一步不放回直接影响第二步总体容量与红球数，两步不独立，正确概率为 \(\frac23\times \frac12 = \frac13\)
翻车现场 3：凭生活直觉主观臆断“无关即独立”
❌ 掷骰子觉得「点数和为 8」与「第一颗是偶数」有关，便主观断定和为 7 也必然不独立
✔ 独立是严格的代数检验 \(P(AB)=P(A)P(B)\)；和为 7 恰好满足等式而独立，和为 8 则不满足
反例微图解：互斥 vs 独立文氏图（为什么正概率互斥事件一定不独立）
互斥要求交集为空，故 \(P(AB)=0\)；当 \(P(A)>0, P(B)>0\) 时，独立却要求 \(P(AB)=P(A)P(B)>0\)，所以此时两者不能兼有。文氏图只示意集合关系，不能直接把任意圆的几何面积当成概率。
再深一点（可以先跳过）

为什么换成对立事件还独立：\(AB\) 和 \(A\overline B\) 互斥，合起来是 \(A\)，所以 \(P(A\overline B)=P(A)-P(AB)=P(A)-P(A)P(B)=P(A)\big(1-P(B)\big)=P(A)P(\overline B)\)。另外两种同理。

两两独立，不等于三个一起独立：抛两枚硬币，\(A=\)「第一枚正」，\(B=\)「第二枚正」，\(C=\)「两枚一样」。三个概率都是 \(\dfrac12\)，\(AB\)、\(AC\)、\(BC\) 都只有「正正」一种，概率 \(\dfrac14=\dfrac12\times \dfrac12\)，两两独立。可 \(ABC\) 也只有「正正」，\(P(ABC)=\dfrac14\ne\dfrac18\)。三个事件「相互独立」要求两两独立，并且 \(P(ABC)=P(A)P(B)P(C)\)。像几个人各自射击、各自破译这类，从试验本身就能确定相互独立。

概率为 \(0\) 的事件：比如不可能事件 \(\varnothing\)，\(P(\varnothing\,B)=0=0\times P(B)\)，它和任何事件都独立，同时也和任何事件互斥。所以「互斥就不独立」一定要带上「两个概率都是正的」。

① 两颗骰子：选两个事件，看独不独立

\(6\times6\) 的格子是掷两颗骰子的 \(36\) 种结果（行是第一颗，列是第二颗）。选好 \(A\)、\(B\)，格子标出 \(A\)、\(B\)、\(AB\)，下面算 \(P(AB)\) 和 \(P(A)P(B)\)。试试「点数和为 \(7\)」和「点数和为 \(8\)」，再试试一对互斥的。

② 进阶：自己画一个事件 B

点格子（或选中图后用方向键移动、空格切换），把它放进或拿出 \(B\)。试着画一个和 \(A\) 互斥、又和 \(A\) 独立的 \(B\)，\(B\) 不能是空的——看看为什么做不到。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 掷两颗骰子，\(A=\)「第一颗点数 \(\le2\)」，\(B=\)「第二颗是 \(6\)」。\(P(AB)=\)？

A。两颗骰子各掷各的，\(A\) 只看第一颗、\(B\) 只看第二颗，独立。\(P(A)=\dfrac26=\dfrac13\)，\(P(B)=\dfrac16\)，\(P(AB)=\dfrac13\times\dfrac16=\dfrac1{18}\)。数格子也一样：\((1,6),(2,6)\) 两格，\(\dfrac2{36}=\dfrac1{18}\)。B 是把两个概率加起来了；D 是只数了一格。

2. 甲、乙两人各自参加一次考试，及格的概率分别是 \(0.7\) 和 \(0.5\)，互不影响。恰有一人及格的概率是？

B。「甲过乙不过」\(0.7\times0.5=0.35\)，「甲不过乙过」\(0.3\times0.5=0.15\)，两种互斥，相加得 \(0.5\)。A 只算了一种（也是「都及格」的概率）；C 是「至少一人及格」\(1-0.3\times0.5=0.85\)；D 直接相加，超过了 \(1\)。

易错

3. 掷一颗骰子，\(A=\)「点数是 \(1\) 或 \(2\)」，\(B=\)「点数是 \(5\) 或 \(6\)」。下面哪句对？

B。没有公共点数，互斥，\(P(AB)=0\)；但 \(P(A)P(B)=\dfrac13\times\dfrac13=\dfrac19\ne0\)，不独立。选 A 是把「互斥」当成了「互不影响」：其实 \(A\) 一发生，\(B\) 就一定不发生，影响最大。两个概率都正的事件，互斥就一定不独立。

4. 掷一颗骰子，\(A=\)「点数是偶数」，\(B=\)「点数 \(\le4\)」。\(A\) 与 \(B\)：

A。\(P(A)=\dfrac12\)，\(P(B)=\dfrac46=\dfrac23\)，\(AB=\{2,4\}\)，\(P(AB)=\dfrac26=\dfrac13\)，而 \(\dfrac12\times\dfrac23=\dfrac13\)，相等，独立。同一次试验里的两个事件也能谈独立，标准只有 \(P(AB)=P(A)P(B)\)。凭感觉选 B 的同学可以对比：把 \(B\) 换成「点数 \(\le3\)」，\(P(AB)=\dfrac16\ne\dfrac14\)，才不独立。

5. \(10\) 张奖券里有 \(2\) 张有奖。甲先抽一张，乙再从剩下的里抽一张（不放回）。甲、乙都中奖的概率是？

B。按顺序数：甲有 \(10\) 种抽法，乙有 \(9\) 种，共 \(90\) 种。两人都中奖：甲 \(2\) 种、乙只剩 \(1\) 种，\(2\) 种，概率 \(\dfrac2{90}=\dfrac1{45}\)。

A 是 \(\dfrac15\times\dfrac15\)：甲、乙各自中奖的概率确实都是 \(\dfrac15\)（乙中奖有 \(2\times1+8\times2=18\) 种，\(\dfrac{18}{90}=\dfrac15\)），可不放回时两件事不独立，不能相乘。放回再抽，答案才是 \(\dfrac1{25}\)。

挑战

6. 甲、乙、丙三人各自破译同一个密码，能破译的概率分别是 \(\dfrac12\)、\(\dfrac13\)、\(\dfrac14\)，互不影响。密码被破译（至少一人破译）的概率是？

B。三人各自破译，相互独立。都破译不了：\(\dfrac12\times\dfrac23\times\dfrac34=\dfrac14\)，所以至少一人破译：\(1-\dfrac14=\dfrac34\)。A 是三人都破译；C 是三个概率相加，超过了 \(1\)；D 是「都破译不了」，忘了用 \(1\) 去减。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
