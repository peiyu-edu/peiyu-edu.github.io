2.3 二次函数与一元二次方程、不等式

一条抛物线，同时回答三个问题：方程 \(ax^2+bx+c=0\) 有哪些根，不等式 \(ax^2+bx+c>0\)（或 \(<0\)）在哪里成立。看图读答案，比背表格可靠。先从抛一个球开始。

把一个球往上抛，\(t\) 秒后它离地面的高度是 \(h=4t-t^2\)（米）。

下面哪一刻，球正好落回地面？

代进去算：\(t=1\) 时 \(h=3\)，\(t=2\) 时 \(h=4\)，\(t=3\) 时 \(h=3\)，\(t=4\) 时 \(h=16-16=0\)。D。

「落地」就是 \(h=0\)，也就是方程 \(4t-t^2=0\)，即 \(t(4-t)=0\)，根是 \(0\)（刚抛出）和 \(4\)（落地）。「在空中」就是 \(h>0\)，也就是不等式 \(4t-t^2>0\)，答案是 \(0<t<4\)。

把 \(h\) 随 \(t\) 的变化画出来是一条开口向下的抛物线：和横轴交在 \(0\) 和 \(4\)，中间拱在横轴上方。方程的根看交点，不等式的解看上方还是下方——这一节就讲这件事。

1. 先认识几个词

要用到：初中的二次函数图象（开口方向、和 \(x\) 轴的交点）和因式分解；集合的写法（回看 1.1）；2.1 的不等式性质，两边乘负数要反向（回看 2.1）。

二次式、一元二次不等式：形如 \(ax^2+bx+c\) 并且 \(a\neq0\) 的式子叫二次式。只含一个未知数、最高是 \(2\) 次的不等式，叫一元二次不等式。

例：\(2x^2-3x+1\) 是二次式，\(a=2\)，\(b=-3\)，\(c=1\)；\(x^2-4\) 也是（\(b=0\)）；\(3x-1\) 不是，它没有 \(x^2\) 项。\(x^2-4>0\) 是一元二次不等式。

判别式 \(\Delta=b^2-4ac\)：不用解方程，就能知道 \(ax^2+bx+c=0\) 有几个实根。\(\Delta>0\) 两个不同实根，\(\Delta=0\) 两根相等（叫重根），\(\Delta<0\) 没有实根。

例：\(x^2-2x-3\)，\(\Delta=4+12=16>0\)，根 \(-1\) 和 \(3\)；\(x^2-2x+1\)，\(\Delta=4-4=0\)，重根 \(1\)；\(x^2-2x+2\)，\(\Delta=4-8=-4<0\)，没有实根。

零点：让函数值等于 \(0\) 的那个 \(x\)。它是一个实数，不是一个点。

例：\(y=x^2-x-2=(x+1)(x-2)\)，\(x=-1\) 和 \(x=2\) 时 \(y=0\)，所以零点是 \(-1\) 和 \(2\)。图象经过的 \((-1,0)\)、\((2,0)\) 是和 \(x\) 轴的交点，零点是它们的横坐标。

解集和区间：不等式所有的解组成的集合叫解集，可以写成集合，也可以写成区间。

例：\(\{x\mid -1<x<3\}\) 写成 \((-1,3)\)，圆括号表示端点不要；\(\{x\mid -1\le x\le 3\}\) 写成 \([-1,3]\)，方括号表示端点要；「\(x\le-1\) 或 \(x>3\)」写成 \((-\infty,-1]\cup(3,+\infty)\)。所有实数是 \(\mathbf R\)，一个解也没有是 \(\varnothing\)。

2. 一个式子，三种问法

设 \(a\neq0\)，把 \(ax^2+bx+c\) 看成函数 \(y=ax^2+bx+c\)，图象是抛物线。

  • 方程 \(ax^2+bx+c=0\) 的实根 = 函数的零点 = 抛物线和 \(x\) 轴交点的横坐标。
  • 不等式 \(ax^2+bx+c>0\) 的解，是抛物线在 \(x\) 轴上方那部分对应的 \(x\)；\(<0\) 看下方。

例 1（看一遍怎么写）

求方程 \(2x^2-3x-2=0\) 的实根、函数 \(y=2x^2-3x-2\) 的零点，以及图象和 \(x\) 轴的交点。

因式分解：\(2x^2-3x-2=(2x+1)(x-2)\)。令它等于 \(0\)，得 \(x=-\dfrac12\) 或 \(x=2\)。

所以方程的实根是 \(-\dfrac12\) 和 \(2\)；函数的零点也是 \(-\dfrac12\) 和 \(2\)；图象和 \(x\) 轴交于 \(\left(-\dfrac12,0\right)\) 和 \((2,0)\)。

自己试试：函数 \(y=x^2-4x+3\) 的零点是？

B。\(x^2-4x+3=(x-1)(x-3)\)，\(x=1\) 和 \(x=3\) 时函数值是 \(0\)。选 A 的同学写成了交点，零点是交点的横坐标，是实数。C 是和 \(y\) 轴的交点；D 是 \(y<0\) 的解集。

3. 开口向上：三步解不等式

  1. 标准化：移项让右边是 \(0\)，\(x^2\) 的系数是正的。
  2. 找根：能因式分解就分解；不能就算 \(\Delta\)、用求根公式。
  3. 读图：开口向上、两根 \(x_1<x_2\) 时，两边在上、中间在下。\(>0\) 取两边，\(<0\) 取中间；带「\(=\)」的把两根也算进去。

例 2

解不等式 \(x^2-x-6\ge0\)。

\(x^2-x-6=(x+2)(x-3)\)，两根 \(-2\) 和 \(3\)。开口向上，两边在 \(x\) 轴上方，中间在下方。要「\(\ge0\)」，取两边，并且两根本身（值是 \(0\)）也要。

解集是 \(\{x\mid x\le-2\text{ 或 }x\ge3\}\)，即 \((-\infty,-2]\cup[3,+\infty)\)。验一下：中间的 \(x=0\) 代进去是 \(-6\)，确实不满足。

自己试试：不等式 \(x^2-5x+4<0\) 的解集是？

A。\(x^2-5x+4=(x-1)(x-4)\)，两根 \(1\) 和 \(4\)，「\(<0\)」取中间，根不要。选 D 的同学把根的符号弄反了：\(x-1=0\) 得 \(x=1\)，不是 \(-1\)。选 B 是读成了「\(>0\)」，选 C 是多要了端点。

4. 开口向下：先乘 \(-1\)

\(x^2\) 的系数是负的，抛物线开口向下，「两边在上」就反过来了。最稳的办法：两边同乘 \(-1\)，不等号反向，变成开口向上，再按第 3 块读。

例 3

解不等式 \(-2x^2+x+1\ge0\)。

两边乘 \(-1\)，不等号反向：\(2x^2-x-1\le0\)。因式分解 \((2x+1)(x-1)\le0\)，两根 \(-\dfrac12\) 和 \(1\)。开口向上，「\(\le0\)」取中间，根也要。

解集是 \(\left[-\dfrac12,1\right]\)。验一下：\(x=0\) 代进原式是 \(1\ge0\)，成立。

自己试试：不等式 \(-x^2+2x+8>0\) 的解集是？

A。乘 \(-1\) 得 \(x^2-2x-8<0\)，即 \((x+2)(x-4)<0\)，取中间 \(-2<x<4\)。选 B 的同学乘了 \(-1\) 却忘了把「\(>\)」改成「\(<\)」。代 \(x=0\) 检查：\(8>0\)，\(0\) 应该在解集里，B 里没有它。

5. \(\Delta=0\) 和 \(\Delta<0\)：碰一下、碰不到

开口向上时：

  • \(\Delta=0\)，重根 \(x_0\)：抛物线在 \(x_0\) 处碰一下 \(x\) 轴又回到上方，不穿过去。除了 \(x_0\) 处值是 \(0\)，别处都 \(>0\)。
  • \(\Delta<0\)：整条抛物线都在 \(x\) 轴上方，值处处 \(>0\)。

例 4

（1）解 \(x^2-6x+9\le0\)。\(x^2-6x+9=(x-3)^2\)，平方不会是负数，只有 \(x=3\) 时等于 \(0\)。所以解集是 \(\{3\}\)。

（2）解 \(x^2+x+1>0\)。\(\Delta=1-4=-3<0\)，没有实根，开口向上，整条在 \(x\) 轴上方。所以解集是 \(\mathbf R\)。

自己试试：不等式 \(x^2+2x+1<0\) 的解集是？

A。\(x^2+2x+1=(x+1)^2\ge0\)，永远不会小于 \(0\)。选 B 的同学把「\(<0\)」当成了「\(\le0\)」：\(x=-1\) 时值是 \(0\)，不满足「小于」。D 是「\(>0\)」的答案。

这些情形不用背。画个草图：开口朝哪、和 \(x\) 轴交在哪，答案就在图上。重根处不变号；根本身要不要，只看不等号带不带「\(=\)」。

6. 用之前，查五件事

  1. 真是二次吗：\(x^2\) 的系数是参数时，先单独看它等于 \(0\) 的情形。
    反例：\(mx^2+x-2>0\)，\(m=0\) 时变成 \(x-2>0\)，解集是 \((2,+\infty)\)，图象是直线，不能用 \(\Delta\) 和「两边、中间」。
  2. 开口朝哪：系数为负，先乘 \(-1\) 并反向。
    反例：\(-x^2+1>0\) 照背「大于取两边」写 \(x<-1\) 或 \(x>1\)；代 \(x=2\) 得 \(-3\)，并不大于 \(0\)。正确是 \(-1<x<1\)。
  3. 根要不要：带「\(=\)」要，不带不要；重根处不变号。
    反例：\((x-1)^2>0\) 的解集不是 \(\mathbf R\)，\(x=1\) 时值是 \(0\)，要去掉。
  4. 零点是数：写 \(1\)，不写 \((1,0)\)。
    反例：「\(y=x^2-1\) 的零点是 \((\pm1,0)\)」是错的，零点是 \(-1\) 和 \(1\)。
  5. 实际问题取交集：算出的解集还要和问题允许的范围取交集。
    反例：\(x\) 是一段长度，由 \(x^2-x-6<0\) 得 \(-2<x<3\)；可长度要 \(x>0\)，答案是 \(0<x<3\)。
解集写成集合或区间：\(\{x\mid -1<x<3\}\) 或 \((-1,3)\)；两段用「或」/ \(\cup\) 连起来；没有解写 \(\varnothing\)。
再深一点（可以先跳过）

根不是整数时：\(x^2-2x-1<0\) 分解不了，\(\Delta=4+4=8\)，根 \(x=\dfrac{2\pm2\sqrt2}{2}=1\pm\sqrt2\)。开口向上取中间，解集 \((1-\sqrt2,1+\sqrt2)\)。

从解集倒推：如果 \(ax^2+bx+c>0\) 的解集是 \((-1,2)\)，「\(>0\)」取了中间，说明开口向下 \(a<0\)，并且 \(-1\)、\(2\) 是两根，所以 \(ax^2+bx+c=a(x+1)(x-2)\)。

另一种看法：符号：\((x+1)(x-3)<0\) 就是两个因式一正一负，只能 \(x+1>0\) 且 \(x-3<0\)，得 \(-1<x<3\)，和读图的答案一样。

「一侧一直上升」：开口向上的抛物线在顶点右边越来越高，这里靠初中的图象知识就够用；严格的说法（单调性）在第 3 章。

① 拖抛物线，看根和解集

拉滑块改 \(a,b,c\)；也可以直接拖图上的顶点（键盘：先按 Tab 选中，再用方向键）。点下面四个按钮切换不等号，图上 \(x\) 轴的高亮段就是解集。实心点 ● 表示根在解集里，空心点 ○ 表示不在。

试试：

② 进阶：含参数，什么时候对一切 \(x\) 都成立

看 \(f(x)=mx^2-mx+1\)。拉 \(m\)（选中滑块后也能用方向键），看抛物线是不是整条在 \(x\) 轴上方。红色是 \(f(x)\le0\) 的地方，有红色就说明「\(f(x)>0\) 对一切 \(x\) 成立」不对。特别看看 \(m=0\) 和 \(m=4\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 不等式 \(x^2+x-12\le0\) 的解集是？

A。\(x^2+x-12=(x+4)(x-3)\)，两根 \(-4\) 和 \(3\)。开口向上，「\(\le0\)」取中间，根也要。选 B 漏了端点；选 C 读到了上方；选 D 是根的符号弄反了。

2. 关于 \(x\) 的方程 \(x^2-2x+k=0\) 没有实根，\(k\) 的取值范围是？

A。没有实根就是 \(\Delta<0\)：\((-2)^2-4k=4-4k<0\)，得 \(k>1\)。选 C 的同学把 \(k=1\) 也算进来了：那时 \(\Delta=0\)，方程是 \((x-1)^2=0\)，有一个重根 \(1\)。B、D 是有实根的情形。

易错

3. 不等式 \(-x^2+x+2>0\) 的解集是什么？（提示：\(-x^2+x+2=0\) 的两个根是 \(-1\) 和 \(2\)。）

B。卡在「开口朝哪」：\(x^2\) 前面是 \(-1\)，开口向下，中间拱在 \(x\) 轴上方，两边掉到下方，所以「大于 0」在两根中间。代 \(x=0\)：\(2>0\)，确实成立。

选 A 的同学背了「大于取两边」，这句话只在开口向上时对。稳妥的做法是先乘 \(-1\)、不等号反向，变成 \(x^2-x-2<0\) 再读。选 D 是把不等式和方程弄混了：\(-1\) 和 \(2\) 让式子等于 0，恰恰不满足「大于 0」。

4. 不等式 \(x^2-4x+4>0\) 的解集是？

C。卡在「根要不要」：\(x^2-4x+4=(x-2)^2\)，\(\Delta=0\)，抛物线在 \(x=2\) 处碰到 \(x\) 轴又回到上方——重根处不变号。除了 \(x=2\) 那一点值是 0，其余地方都大于 0。B 是「\(\ge 0\)」的答案；D 是「\(\le0\)」的答案。在「动手」①里点「重根」，再把四个不等号点一遍。

5. 一块长方形菜地，长比宽多 \(2\) 米，面积至少 \(8\) 平方米。设宽为 \(x\) 米，\(x\) 的取值范围是？

A。卡在「实际问题取交集」：\(x(x+2)\ge8\)，即 \(x^2+2x-8\ge0\)，\((x+4)(x-2)\ge0\)，解得 \(x\le-4\) 或 \(x\ge2\)。宽是长度，要 \(x>0\)，取交集只剩 \(x\ge2\)。选 B 的同学停在了不等式的解集；选 C 读成了中间。

挑战

6. 关于 \(x\) 的不等式 \(mx^2-mx+1>0\) 对一切实数 \(x\) 都成立，\(m\) 的取值范围是？

B。卡在「真是二次吗」：\(m\) 是参数，先看 \(m=0\)：式子变成 \(1>0\)，对所有 \(x\) 都成立，所以 \(m=0\) 要算进去。

\(m\neq0\) 时是二次式。要整条抛物线都在 \(x\) 轴上方，必须开口向上 \(m>0\)，并且和 \(x\) 轴没有交点 \(\Delta=m^2-4m<0\)，得 \(0<m<4\)。\(m=4\) 时 \(\Delta=0\)，式子是 \((2x-1)^2\)，在 \(x=\tfrac12\) 处等于 0，不满足「\(>0\)」。合起来是 \(0\le m<4\)。选 A 漏了 \(m=0\)；选 C 多了 \(m=4\)。可以在「动手」②里拉 \(m\) 对照。
