思路

固定 C 时，点 P 在以 BC 为直径的圆上；先求该圆上到原点的最远距离，再对椭圆内的 C 优化。

解答

取 B=(2,0)。固定 C 后，条件等价于 ∠BPC=90∘，故

∣OP∣≤2∣B+C∣+∣B−C∣​.(1)

右端关于 C 为凸函数，因此在凸椭圆区域上的最大值可取在边界。令 C=(2cost,sint)，记 u=cost。则

∣B+C∣2=5+8u+3u2,∣B−C∣2=5−8u+3u2.

又

∣B+C∣2∣B−C∣2=25−34u2+9u4≤(5−3u2)2.

故 ∣B+C∣+∣B−C∣≤25​。代入（1）得 ∣OP∣≤5​。当 C=(0,1) 时两段长度均为 5​，并可在直径圆上取最远点达到等号。因此

∣OP∣max​=5​​.

复核

凸函数在紧凸集上的最大值可沿射线推至边界；等号构造中的 C 确在椭圆上，所取 P 也满足直角条件。

方法总结

点积为零常转化为直径圆；圆上距原点的极值等于“圆心距加半径”，再把它写成两个向量模长之和。

为什么评为 F4（会透露解法方向）

须先消去P化为两段长度和，再把C推到边界并建立参数上界，最后验证直径圆等号位置。
