27.3 实际问题与反比例函数

工程进度、杠杆、电流、压强，背后常常是同一件事：两个量的积一定。这一节学会从情境里找出这个“定值”，写出反比例函数，并注意实际问题里自变量的范围和“不超过、至少”这类不等关系。

码头的起重机每小时可往一艘轮船上装载 \(700\text{ t}\) 货物，这艘轮船的货物装载完毕恰好用了 \(9\text{ h}\)。此轮船到达另一港口后开始卸货，如果要求卸货总时间不超过 \(6\text{ h}\)，起重机每小时至少要卸载多少货物？

货物总量为 \(700 \times 9 = 6300\text{ t}\)。平均卸货速度 \(v\) 与时间 \(t\) 满足 \(v = \frac{6300}{t}\)。若要求卸货时间 \(t \le 6\text{ h}\)，平均卸货速度 \(v\) 应满足什么条件？

B。总货物量 \(W = 6300\text{ t}\) 保持不变，函数关系式为 \(v = \frac{6300}{t}\)（\(t > 0\)）。

在第一象限内，卸货速度 \(v\) 随时间 \(t\) 的增大而减小。时间要求越短（\(t \le 6\text{ h}\)），起重机的负荷就要越大，速度必须至少达到 \(v \ge \frac{6300}{6} = 1050\text{ t/h}\)！

1. 先认识几个词：反比例函数跨学科实际模型

前置知识：反比例函数的图象与性质（回看 27.2）。反比例函数在实际应用中广泛存在于工程调度与物理定律之中，核心在于寻找“积为常数”的守恒关系：

  • 工程与行程：总量一定时，效率与时间成反比例（\(v = \frac{W}{t}\)；\(v = \frac{s}{t}\)）。
  • 力学杠杆原理：动力 \(\times\) 动力臂 \(=\) 阻力 \(\times\) 阻力臂（\(F_1 L_1 = F_2 L_2 \implies F_1 = \frac{k}{L_1}\)）。动力臂越长，所需动力越小（省力杠杆）。
  • 电学欧姆定律：电压一定时，导体中的电流与导体的电阻成反比例（\(I = \frac{U}{R}\)）。电阻越大，通过的电流越小。
  • 流体与固体压强：压力一定时，压强与受力面积成反比例（\(p = \frac{F}{S}\)）。受力面积越小，产生的压强越大。

实际特征 1实际问题图象：锁定第一象限单支

在纯代数中反比例函数有两支；但在现实问题中，时间、速度、拉力、电阻、面积等物理量都必须是严格正数（\(x > 0, y > 0\)）。因此实际问题的反比例图象仅仅是第一象限内的一支光滑曲线，绝不会延伸到第三象限！

实际特征 2临界不等式的反向逆转

因为在第一象限内函数值随自变量增大而减小，所以“自变量不超过某个上限 \(t \le t_0\)”必然导致“函数值至少达到某个下限 \(v \ge v_0\)”！许多同学做题时习惯顺着写不等号，导致方向搞反全盘皆输。

实际问题解决四步法：如何从文字情境中快速建立模型？
  1. 审题设元：明确自变量和函数对应的现实物理量，设出字母与单位；
  2. 找寻定值：找出情境中保持恒定不变的守恒乘积（如路程、电压、做功、阻力力矩）；
  3. 列出解析式并标明范围：写出 \(y = \frac{k}{x}\)，并结合实际设备量程或尺寸标出自变量范围（如 \(x > 0\) 或 \(a \le x \le b\)）；
  4. 利用单调性求解并检验：代入数值或利用增减性求解，最后检查单位与现实合理性。
警惕单位陷阱：物理公式与数学单位的统一要求

跨学科题目中最隐蔽的陷阱是单位换算：

1. 压强问题中：\(1\text{ Pa} = 1\text{ N/m}^2\)。如果题目给出的是平方厘米（\(\text{cm}^2\)），必须先化为平方米（\(1\text{ cm}^2 = 10^{-4}\text{ m}^2\)），否则算出的常数 \(k\) 会偏差一万倍！

2. 速度问题中：\(\text{km/h}\) 与 \(\text{m/s}\) 之间存在 \(3.6\) 倍换算关系；时间中小时与分钟也常有六十进制陷阱。

为什么现实中的杠杆越长越省力？

由杠杆平衡 \(F_1L_1=F_2L_2\)（右边是定值 \(k\)），动力 \(F_1=\frac{k}{L_1}\)。\(L_1>0\) 时，\(L_1\) 越大，\(F_1\) 越小：动力臂加倍，动力减半。这就是撬棍越长越省力的数学原因。

反比例函数中的“反向变化”在经济生活中的智慧

在消费预算固定时，商品单价越高，能购买的数量越少；在企业营销总预算恒定时，单个客户获取成本越低，能够覆盖的客户规模越大。

理解反比例函数的单调减小特征，不仅是应对考试，更能帮助我们在生活资源受限（乘积守恒）的边界下，做出权衡取舍的最佳决策。

示范例题实际物理气压模型与临界决策

题目：某科技小组在实验中发现，一定质量的气体在温度保持不变时，其压强 \(p\)（单位：\(\text{kPa}\)）与体积 \(V\)（单位：\(\text{m}^3\)）成反比例关系。当体积 \(V = 3\text{ m}^3\) 时，气体的压强 \(p = 40\text{ kPa}\)。
(1) 求压强 \(p\) 关于体积 \(V\) 的函数关系式；
(2) 当气体的体积为 \(2.4\text{ m}^3\) 时，气体的压强是多少？
(3) 如果气体的压强不得超过 \(150\text{ kPa}\)，那么气体的体积至少应为多少？

【Polya 审题与理解】

玻意耳定律：温度恒定时 \(pV = k\) 为定值。已知一组对应值 \((3, 40)\) 可求出常数 \(k\)。第 (3) 问是不超过（\(\le 150\)），求体积的取值范围，考察单调性与临界不等式。

先自己想一想，再展开：想办法、完整解答、回头看

【拟定计划】

第 (1) 问：设 \(p = \frac{k}{V}\)，代入数据求 \(k\)；第 (2) 问：代入 \(V = 2.4\) 算 \(p\)；第 (3) 问：利用 \(p \le 150\) 列不等式，注意单调递减导致的不等号方向。

【执行解答】

解：(1) 设 \(p\) 关于 \(V\) 的函数解析式为 \(p = \frac{k}{V}\)（\(k \ne 0\)）。
把 \(V = 3, p = 40\) 代入得：
\[ k = 40 \times 3 = 120 \]
所以函数关系式为 \(p = \frac{120}{V}\)（\(V > 0\)）。

(2) 当 \(V = 2.4\text{ m}^3\) 时，代入解析式得：
\[ p = \frac{120}{2.4} = 50\text{ kPa} \]
即气体的压强是 \(50\text{ kPa}\)。

(3) 根据题意，压强不得超过 \(150\text{ kPa}\)，即 \(p \le 150\)。
因为 \(p = \frac{120}{V}\)，且 \(V > 0\)，
所以：
\[ \frac{120}{V} \le 150 \implies 120 \le 150V \implies V \ge 0.8 \]
答：气体的体积至少应为 \(0.8\text{ m}^3\)。

【回顾与反思】

当体积减小时气体被压缩，压强急剧升高。因此要保证压强安全（不超过），体积就必须足够大（不小于临界值 \(0.8\text{ m}^3\)），反向不等关系符合物理直觉。检验：\(V=0.8\) 时 \(p=\frac{120}{0.8}=150\)，正好是上限。

【自测 1 · 杠杆动力计算】小明用一根木棒撬动一块大石头，已知阻力与阻力臂的乘积为 \(600\text{ N}\cdot\text{m}\)。若小明手握木棒处的动力臂长为 \(1.5\text{ m}\)，则撬动石头所需的动力为（ ）

A。由杠杆平衡原理，动力 \(F = \frac{k}{L} = \frac{600}{1.5} = 400\text{ N}\)。

【自测 2 · 欧姆定律安全控制】某用电器的额定电压为 \(220\text{ V}\)，为保证电路安全，电路中的电流不得超过 \(10\text{ A}\)。则该用电器的电阻 \(R\) 应满足的条件是（ ）

B。由欧姆定律 \(I = \frac{U}{R} = \frac{220}{R} \le 10\)。两边同乘正数 \(R\) 得 \(220 \le 10R \implies R \ge 22\,\Omega\)。电阻必须足够大才能限制电流不超过安全上限。

【自测 3 · 行程问题用时】甲乙两地相距 \(300\text{ km}\)，某汽车从甲地开往乙地，若要求运行时间控制在 \(3\text{ h}\) 到 \(5\text{ h}\) 之间，则该汽车的平均速度 \(v\)（\(\text{km/h}\)）的取值范围是（ ）

C。函数关系式为 \(v = \frac{300}{t}\)。因为 \(3 \le t \le 5\)，在第一象限单调递减，当 \(t = 5\) 时速度最小 \(v = \frac{300}{5} = 60\text{ km/h}\)；当 \(t = 3\) 时速度最大 \(v = \frac{300}{3} = 100\text{ km/h}\)。所以 \(60 \le v \le 100\)。

4. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）“不超过”时不等号方向写反
❌ 典型错解：\(v=\frac{6300}{t}\)，要求 \(t\le6\)，于是写 \(v\le1050\)。
✅ 看图秒懂：\(v\) 随 \(t\) 增大而减小，时间 \(t\) 越短速度越大：\(t\le6\) 对应 \(v\ge1050\)。拿不准就取一个值试：\(t=3\) 时 \(v=2100\)。
翻车现场 ②单位没有统一
❌ 典型错解：压力 \(24\text{ N}\)，接触面积 \(200\text{ cm}^2\)，\(p=\frac{24}{200}=0.12\text{ Pa}\)。
✅ 一眼看清：\(1\text{ Pa}=1\text{ N/m}^2\)，要先化成平方米：\(200\text{ cm}^2=0.02\text{ m}^2\)，\(p=\frac{24}{0.02}=1200\text{ Pa}\)。
翻车现场 ③漏写自变量范围，图象画到第三象限
❌ 典型错解：\(F=\frac{300}{l}\)，画出两支曲线，也不写 \(l\) 的范围。
✅ 一眼看清：动力臂、拉力都是正数，只要第一象限的一段（一支），关系式后面写上 \(l>0\)；情境里有上下限时（如 \(0.5\le l\le3\)）还要写进范围。

  1. 问题来自自己收集的信息；数据有来源与单位，没有把设想写成实测。
  2. 两个量与问题匹配，说明自变量和因变量；统一单位后再比较。

  5. 记 x、y 的单位分别为 X、Y。反比例 xy=k 时，k≠0，k 的单位为 X·Y，且 x≠0；正比例 y=kx 时，按正比例定义 k≠0，k 的单位为 Y/X，x 能否取0由实际情境范围决定。其他一次函数、其他关系或信息不足时，按实际关系说明常数单位与自变量范围，不统一套用上述两种 k 的单位及非零条件。物理量、设备尺寸和整数个数的实际范围仍须单独说明，不能把整条连续曲线当全部可行值。
  6. 在理想反比例且 k>0、0<x₁<x₂ 时，y₁−y₂=k(x₂−x₁)/(x₁x₂)>0，故同在正数范围时递减。临界不等式要与实际范围取交集；再用独立数据和情境检验。假设变动时需重新建模。

直接用

1. 一块重 \(1200\text{ N}\) 的石板平放在地面上，石板对地面的压强 \(p\)（\(\text{Pa}\)）与受力面积 \(S\)（\(\text{m}^2\)）的函数关系式为（ ）

2. 蓄电池两端的电压是定值。电阻为 \(5\,\Omega\) 时电流是 \(4\text{ A}\)；要让电流降到 \(2.5\text{ A}\)，电阻应调为（ ）

C。\(U=IR=4\times5=20\text{ V}\)，\(R=\frac{20}{2.5}=8\,\Omega\)。A 是按正比例算的 \(5\times\frac{2.5}{4}\)（电流变小，电阻反而变小了，方向反了）；B 是 \(5+2.5\)（把积一定当成和一定）；D 是 \(4\times2.5\)（把两个电流乘了起来）。

提示

\(y\) 随 \(x\) 增大而减小：每天修得最多的时候，天数最少还是最多？把两个端点各算一次。

D。\(x=60\) 时 \(y=30\)（天数最少）；\(x=30\) 时 \(y=60\)（天数最多）。所以 \(30\le y\le60\)。A、B 只用了一个端点；C 的数没有经过计算。

4. 某实验中，两个物理量 \(x\)、\(y\) 都只能取正数，并且 \(xy\) 是一个正的定值，则 \(y\) 关于 \(x\) 的图象是（ ）

提示

\(y=\frac kx\)（\(k>0\)）本来有两支，但 \(x,y\) 都只能取正数时，哪一支还留得下？

A。\(xy=k>0\)，\(y=\frac kx\)，\(x>0,y>0\)，只剩第一象限的一支。B 画出了负数的那一支（第三象限）；C 把「一个增大另一个减小」当成了一次函数；D 的点横坐标为负，不满足「只能取正数」。

5. 一块砖对地面的压力是 \(24\text{ N}\)，与地面的接触面积是 \(200\text{ cm}^2\)，它对地面的压强是（ ）

提示

\(1\text{ Pa}=1\text{ N/m}^2\)。\(1\text{ m}=100\text{ cm}\)，所以 \(1\text{ m}^2=10000\text{ cm}^2\)。

B。\(200\text{ cm}^2=0.02\text{ m}^2\)，\(p=\frac{24}{0.02}=1200\text{ Pa}\)。A 没换算（\(\frac{24}{200}\)）；C 把 \(1\text{ cm}^2\) 当成 \(10^{-3}\text{ m}^2\)（\(200\text{ cm}^2=0.2\text{ m}^2\)）；D 把 \(1\text{ cm}^2\) 当成 \(10^{-5}\text{ m}^2\)（\(200\text{ cm}^2=0.002\text{ m}^2\)）。

6. 用撬棍撬石头，阻力与阻力臂的乘积是 \(1200\text{ N}\cdot\text{m}\)，人最多能用 \(300\text{ N}\) 的力。要撬动石头，动力臂 \(L\)（\(\text{m}\)）应满足（ ）

提示 1：列关系式

\(F=\frac{1200}{L}\)，要求 \(F\le300\)。

提示 2：解不等式

\(L>0\)，两边乘 \(L\) 不变号：\(1200\le300L\)。或者想：\(L\) 越长越省力。

B。\(\frac{1200}{L}\le300\)，\(L>0\)，\(1200\le300L\)，\(L\ge4\)。验算：\(L=4\) 时 \(F=300\)，\(L=8\) 时 \(F=150\)，更省力。A 把不等号写反；C、D 用了 \(\frac{300}{1200}=0.25\)（把 \(k\) 和 \(F\) 的位置颠倒了）。

巩固练习 1：小星在阅读《天工开物》时，看到一种名为桔槔的古代汲水工具：横杆固定于桔槔上的 \(O\) 点并可绕 \(O\) 点转动，在横杆 \(A\) 处连接一竹竿，在横杆 \(B\) 处固定 \(300\,\text{N}\) 的物体，且 \(OB=1\,\text{m}\)。图中人物竖直向下施加的拉力为 \(F\)。当改变点 \(A\) 与点 \(O\) 的距离 \(l\) 时，横杆始终处于水平状态，小星记录了拉力 \(F\) 与 \(l\) 的变化如下表： 点 \(A\) 与点 \(O\) 的距离 \(l/\text{m}\)｜\(1\)｜\(1.5\)｜\(2\)｜\(2.5\)｜\(3\) 拉力的大小 \(F/\text{N}\)｜\(300\)｜\(200\)｜\(150\)｜\(120\)｜\(a\) （1）表格中 \(a\) 的值是＿＿＿＿； （2）写出 \(F\) 关于 \(l\) 的函数关系式； （3）当 \(OA\) 的长增大时，拉力 \(F\) 是增大还是减小？请说明理由。

查看答案与解析，自行核对

答案：（1）\(a=100\)；（2）\(F=\dfrac{300}{l}\ (l>0)\)；（3）减小

（1）\(1\times300=300\)，\(1.5\times200=300\)，\(2\times150=300\)，\(2.5\times120=300\)，积都是 \(300\)，所以 \(3a=300\)，\(a=100\)。（2）\(Fl=300\)，\(F=\frac{300}{l}\)，\(l>0\)。（3）\(k=300>0\)，\(l>0\) 时在第一象限，\(F\) 随 \(l\) 增大而减小：\(OA\) 越长越省力。
