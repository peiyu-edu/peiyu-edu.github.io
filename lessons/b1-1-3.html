1.3 集合的基本运算

两个集合放在一起，能「取公共的」「全放一起」，也能「从全集里去掉」。这一节把这三种运算弄清楚，尤其是数轴上的端点。先从两张名单开始。

班里有两个兴趣小组。篮球组：小明、小红、小刚、小丽；合唱组：小红、小丽、小强。

两个组都参加了的是谁？

A。两张名单里都出现的只有小红和小丽。

换几个问法：「至少参加一个组的」是小明、小红、小刚、小丽、小强，共 \(5\) 人——小红、小丽在两张名单上，人只算一次；「没参加篮球组的」要先说清在哪群人里找：在全班找，就是全班去掉篮球组那 \(4\) 人。

这三种问法，就是这一节的三种运算：交集（都在）、并集（至少在一个里）、补集（在大范围里、但不在它里面）。

1. 先认识几个词

要用到：集合、元素、\(\in\)（回看 1.1）；子集 \(\subseteq\)、空集 \(\varnothing\)（回看 1.2）；初中在数轴上表示不等式。

「同时」和「至少一个」：「同时满足」是两个条件都要满足；「至少满足一个」是满足一个就行，两个都满足也算。

例：在 \(1\) 到 \(10\) 里，「是偶数，同时大于 \(5\)」的有 \(6,8,10\)；「是偶数，或大于 \(5\)（至少一个）」的有 \(2,4,6,7,8,9,10\)。

全集：讨论一个问题时，所有对象都在里面的那个大集合，记作 \(U\)。

例：说「不是偶数的数」。在 \(U=\{1,2,3,4,5,6\}\) 里，是 \(1,3,5\)；在全体整数里，还有 \(-1\)、\(7\)、\(9\)……范围一换，答案就换了。

端点「取到」和「取不到」：\(x\le 3\) 取到 \(3\)，数轴上画实心点 ●；\(x<3\) 取不到 \(3\)，画空心点 ○。

例：\(\{x\mid 1\le x<3\}\) 里，\(1\) 在，\(3\) 不在，\(2.5\)、\(2.99\) 都在（没说是整数，就是一整段实数）。

「动手」② 里会用简写：\([1,3)\) 就是 \(\{x\mid 1\le x<3\}\)，方括号表示端点取到，圆括号表示取不到；\(+\infty\)、\(-\infty\) 表示一直往右、往左。这叫区间，3.1 会正式讲。

空集 \(\varnothing\)：一个元素也没有的集合。

例：「小于 \(0\) 的正整数」组成的集合是 \(\varnothing\)。注意 \(\{0\}\) 不是空集，它里面有一个元素 \(0\)。

2. 交集和并集

交集 \(A\cap B\)（读「\(A\) 交 \(B\)」）：同时属于 \(A\) 和 \(B\) 的元素。并集 \(A\cup B\)（读「\(A\) 并 \(B\)」）：至少属于其中一个的元素。

为什么并集里两边都有的元素只写一次：集合里的元素不重复，就像入口的例子里，小红只算一个人。

例 1（看一遍怎么写）

\(A=\{1,2,3,4\}\)，\(B=\{3,4,5,6\}\)，求 \(A\cap B\) 和 \(A\cup B\)。

两边都有的是 \(3\) 和 \(4\)，所以 \(A\cap B=\{3,4\}\)。

把两边的元素放在一起：\(1,2,3,4\) 和 \(3,4,5,6\)，重复的 \(3,4\) 只写一次，\(A\cup B=\{1,2,3,4,5,6\}\)。

自己试试：\(A=\{1,3,5,7\}\)，\(B=\{2,3,5,8\}\)。\(A\cup B\) 有几个元素？

B。\(A\cup B=\{1,2,3,5,7,8\}\)，\(6\) 个。选 C 的同学把 \(3\)、\(5\) 数了两次；选 D 的同学数的是交集 \(\{3,5\}\)。

3. 补集

补集 \(\complement_U A\)：在全集 \(U\) 里、但不属于 \(A\) 的元素（这里 \(A\subseteq U\)）。

补集一定要先知道全集 \(U\) 是什么。同一个 \(A\)，换一个 \(U\)，补集就变了。

例 2

\(U=\{1,2,3,4,5,6\}\)，\(A=\{1,3,5\}\)，求 \(\complement_U A\)。

从 \(U\) 里把 \(A\) 的元素 \(1,3,5\) 去掉，剩下 \(2,4,6\)，所以 \(\complement_U A=\{2,4,6\}\)。

再看换全集：\(A=\{1,2\}\)，在 \(U=\{1,2,3\}\) 里 \(\complement_U A=\{3\}\)；在 \(U=\{1,2,3,4,5\}\) 里 \(\complement_U A=\{3,4,5\}\)。

自己试试：\(U=\{1,2,3,4,5,6,7\}\)，\(A=\{2,4,6\}\)，\(B=\{1,2,3\}\)。\((\complement_U A)\cap B=\)？

A。先算 \(\complement_U A=\{1,3,5,7\}\)，再和 \(B=\{1,2,3\}\) 取公共的：\(\{1,3\}\)。选 B 的同学算完补集就停了，忘了「\(\cap B\)」；选 C 算成了 \(A\cap B\)。

4. 数轴上的交、并、补：盯住端点

元素是一段一段的实数时，列不出来，就画数轴：交集看「两段重叠的地方」，并集看「被盖住的地方」，补集看「没被盖住的地方」。最容易错的是端点：

  • 端点在两个集合里都取到，交集才取到它；
  • 端点只要在一个集合里取到，并集就取到它；
  • \(A\) 取到的端点，\(\complement_U A\) 就取不到；\(A\) 取不到的，补集就取到（前提是它在 \(U\) 里）。

例 3

\(A=\{x\mid -1\le x<3\}\)，\(B=\{x\mid 1<x\le 5\}\)，全集 \(\mathbf R\)。求 \(A\cap B\)、\(A\cup B\)、\(\complement_{\mathbf R}A\)。

重叠部分从 \(1\) 到 \(3\)。端点 \(1\)：\(B\) 取不到，交集就取不到；端点 \(3\)：\(A\) 取不到，交集也取不到。\(A\cap B=\{x\mid 1<x<3\}\)。

盖住的部分从 \(-1\) 到 \(5\)。\(-1\) 在 \(A\) 里，\(5\) 在 \(B\) 里，都取到；中间的 \(3\) 虽然 \(A\) 取不到，但 \(B\) 盖住了它。\(A\cup B=\{x\mid -1\le x\le 5\}\)。

\(A\) 没盖住的：\(-1\) 左边（\(-1\) 本身在 \(A\) 里，不要）和 \(3\) 右边（\(3\) 不在 \(A\) 里，要）。\(\complement_{\mathbf R}A=\{x\mid x<-1\text{ 或 }x\ge 3\}\)。

自己试试：\(A=\{x\mid x\le 2\}\)，全集 \(\mathbf R\)。\(\complement_{\mathbf R}A=\)？

A。\(2\) 在 \(A\) 里，补集就不能再要它。选 B 的同学把「反过来」只改了方向，没管端点：那样 \(2\) 同时在 \(A\) 和补集里，不可能。

5. 几条一看就懂的关系

\(A\cap B\subseteq A\subseteq A\cup B\)：取公共的只会变少，全放一起只会变多。

\(A\cap B=A\)、\(A\cup B=B\)、\(A\subseteq B\)，三句说的是同一件事。高考里常把「\(A\subseteq B\)」藏成前两种写法。

例 4

\(A=\{1,2\}\)，\(B=\{1,2,3\}\)，\(A\subseteq B\)。算一算：\(A\cap B=\{1,2\}=A\)，\(A\cup B=\{1,2,3\}=B\)。\(A\) 整个在 \(B\) 里，所以「公共部分」就是 \(A\) 自己，「放一起」也没多出东西。

自己试试：已知 \(A\cup B=B\)。下面哪句一定对？

B。把 \(A\) 并进来，\(B\) 一点没变，说明 \(A\) 的元素本来就都在 \(B\) 里。不一定相等：上面的 \(A=\{1,2\}\)，\(B=\{1,2,3\}\) 就满足。在「动手」① 的 Venn 图里，把所有 A 的数都改成「两个都在」，再看 \(A\cup B\) 和 \(B\)。

6. 用之前，查四件事

  1. 全集：求补集先看 \(U\) 是什么。
    反例：\(A=\{x\mid x<2\}\)，\(U=\mathbf R\) 时 \(\complement_U A=\{x\mid x\ge 2\}\)；\(U\) 换成全体整数，补集就只剩 \(2,3,4,\dots\) 这些整数。
  2. 端点：数轴上每个端点单独判断取不取到。
    反例：\(A=\{x\mid x<1\}\)，\(B=\{x\mid x\ge 1\}\)，\(A\cap B=\varnothing\)；把 \(A\) 改成 \(x\le 1\)，交集就成了 \(\{1\}\)。只差一个端点，答案就不一样。
  3. 空集不是 \(\{0\}\)：没有公共元素写 \(\varnothing\)。
    反例：\(\{1\}\cap\{2\}=\varnothing\)，写成 \(\{0\}\) 就错了——\(\{0\}\) 里有一个元素 \(0\)，可 \(0\) 并不在两个集合里。
  4. 带字母时，先想空集：集合里有参数，不能默认它一定有元素。
    反例：\(A=\{x\mid a<x<1\}\)，要 \(A\subseteq B\)。\(a\ge 1\) 时 \(A=\varnothing\)，空集是任何集合的子集，这些 \(a\) 不管 \(B\) 是什么都满足，漏了就错。
再深一点（可以先跳过）

补集和交、并换着用：\(\complement_U(A\cup B)=\complement_U A\cap\complement_U B\)，\(\complement_U(A\cap B)=\complement_U A\cup\complement_U B\)。例：\(U=\{1,\dots,6\}\)，\(A=\{1,2\}\)，\(B=\{2,3\}\)，\(\complement_U(A\cup B)=\{4,5,6\}\)，\(\complement_U A\cap\complement_U B=\{3,4,5,6\}\cap\{1,4,5,6\}=\{4,5,6\}\)，一样。「动手」① 可以随手验证。

「\(A\) 去掉 \(B\)」：属于 \(A\) 但不属于 \(B\) 的元素，就是 \(A\cap\complement_U B\)。例：\(U=\{1,\dots,5\}\)，\(A=\{1,2,3,4\}\)，\(B=\{3,4,5\}\)，\(A\cap\complement_U B=\{1,2\}\)。有的书叫它「差集」，课本不专门讲，用交和补就能写出来。

先看元素是什么：\(\{(x,y)\mid y=x\}\cap\{(x,y)\mid y=2-x\}\) 的元素是点，交集是 \(\{(1,1)\}\)，不能写成 \(\{1\}\)。

数一数元素个数：有限集合里，\(A\cup B\) 的元素个数 \(=\) \(A\) 的个数 \(+\) \(B\) 的个数 \(-\) \(A\cap B\) 的个数。入口的例子：\(4+3-2=5\) 人。

① Venn 图：点数字，把它放进 A、B

全集 \(U=\{1,2,\dots,12\}\)。点一个数字，它会在「都不在 → 只在 A → 只在 B → 两个都在」之间切换。再点上面的运算，看哪些数被选中。

② 进阶：数轴上拖端点，看交、并、补

拖动圆点（或选中后按方向键）改端点；点端点下面的按钮（或选中圆点按空格）切换「取到 ● / 取不到 ○」。全集是全体实数 \(\mathbf R\)。试试让两段只在一个端点处相碰，再切换这个端点。

端点：

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(A\) 是小于 \(10\) 的正奇数组成的集合，\(B=\{3,6,9\}\)。\(A\cap B=\)？

B。先把 \(A\) 列出来：\(A=\{1,3,5,7,9\}\)。和 \(B\) 都有的是 \(3\)、\(9\)。选 C 的同学把 \(6\) 也算进去了，可 \(6\) 不是奇数；D 是并集。

2. \(A=\{x\mid -2<x\le 3\}\)，\(B=\{x\mid x>1\}\)。\(A\cup B=\)？

A。画数轴：\(A\) 从 \(-2\) 盖到 \(3\)，\(B\) 从 \(1\) 往右一直盖下去，合起来是 \(-2\) 右边的全部。\(-2\) 两个集合都不含，取不到。B 是交集；C 把端点 \(-2\) 算进去了；D 漏了 \(3\) 右边那一段。

易错

3. \(A=\{x\mid x<2\}\)，\(B=\{x\mid x\ge 1\}\)。\(A\cap B\) 是什么？

B（端点）。这里的 \(x\) 没说是整数，所以 \(1\) 和 \(2\) 之间的 \(1.5\)、\(1.99\) 都在两个集合里。

选 A 或 C 的同学，是把它们当成了整数；选 D 的同学，是看到符号方向相反就以为没有交集。画一条数轴，两段一叠就看出来了：左端 \(1\) 取到（\(\ge\)），右端 \(2\) 取不到（\(<\)）。

4. \(A=\{x\mid x<2\}\)。如果全集 \(U=\mathbf Z\)（全体整数），\(\complement_U A\) 是什么？

C（全集）。补集只能在全集里找。全集是整数，补集里就只有整数，是 \(\{x\in\mathbf Z\mid x\ge 2\}\)。A 是 \(U=\mathbf R\) 时的答案；B 把端点 \(2\) 弄丢了：\(A\) 取不到 \(2\)，补集就取到 \(2\)。

5. \(A=\{1,3\}\)，\(B=\{2,4\}\)。\(A\cap B\) 应该写成？

A（空集）。没有公共元素，交集就是空集 \(\varnothing\)。\(\{0\}\) 有一个元素 \(0\)；\(\{\varnothing\}\) 有一个元素（这个元素是空集）；\(0\) 是数，不是集合。

挑战

6. \(B=\{x\mid 1\le x\le 4\}\)，\(A=\{x\mid m\le x\le 2m\}\)，且 \(A\cap B=A\)。\(m\) 的取值范围是？

B。\(A\cap B=A\) 就是 \(A\subseteq B\)。带字母，先想空集：

\(m>2m\)，即 \(m<0\) 时，\(A=\varnothing\)，空集是 \(B\) 的子集，满足。

\(m\ge 0\) 时 \(A\) 不空，要整段落在 \([1,4]\) 里：\(m\ge 1\) 且 \(2m\le 4\)，得 \(1\le m\le 2\)。（\(m=0\) 时 \(A=\{0\}\)，\(0\) 不在 \(B\) 里，不行。）

合起来是 B。选 A 的同学漏了空集；选 C、D 的同学没检查 \(0\le m<1\)：比如 \(m=0.5\)，\(A=\{x\mid 0.5\le x\le 1\}\)，\(0.5\) 不在 \(B\) 里。
