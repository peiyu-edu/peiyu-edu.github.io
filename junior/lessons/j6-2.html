6.2 直线、射线、线段

一根拉紧的线、一束手电光、一把尺子的边，三种“直的线”差在哪里？两个点能决定什么？从一点到另一点，哪条路最近？

本节导读　先修：6.1 几何图形 · 本节路线

要用到：点和线的认识（回看 6.1）；小学认识的直线、射线、线段和用尺量长度；列简单的算式求未知数（5.1）。

  1. 从“过两点能画几条直线”进入。
  2. 直线、射线、线段：端点个数和记法。
  3. 两条基本事实：两点确定一条直线；两点之间，线段最短。
  4. 线段的比较：度量法、叠合法；线段的和、差。
  5. 线段的中点；没给图时把各种位置都画出来。
  6. 练习与中考真题，回看“哪一步最容易错”。

在纸上点几个点，过这些点画直线。点下面的按钮，看点数不同时，能画出多少条：

经过 A、B 两个点，能画几条直线？

A。过一个点能画无数条直线，它们可以绕着这个点转；再要求经过第二个点，就只剩一条了。所以用两颗钉子就能把一根木条钉牢，只钉一颗它还会转。

这一节要回答：直线、射线、线段怎么区分、怎么记？两个点能「确定」什么？线段怎样比较长短、怎样加减？

1. 先认识几个词：直线、射线、线段

前置知识：上一节的“线”（回看 6.1）；小学认识过这三种线。区分它们只看两件事：有几个端点、往哪边无限延伸。点下面三种看看：

直觉微图解 ①数端点：0 个、1 个、2 个

直线：向两方无限延伸，没有端点，记作直线 \(l\) 或直线 \(AB\)（\(A\)、\(B\) 是直线上两点，直线 \(AB\) 也就是直线 \(BA\)）。射线：直线上一点和它一旁的部分，有 1 个端点，向一方无限延伸，记作射线 \(OA\)，端点 \(O\) 写在前面。线段：直线上两点和它们之间的部分，有 2 个端点，记作线段 \(AB\)（也就是线段 \(BA\)）或线段 \(a\)。

点 \(P\) 在直线 \(l\) 上，也说直线 \(l\) 经过点 \(P\)；否则点 \(P\) 在直线 \(l\) 外。两条不同的直线有一个公共点时，说它们相交，这个公共点叫交点。

核心概念 ②射线 OA 和射线 AO 不是同一条

射线像手电筒的光，从端点射出去。射线 \(OA\) 从 \(O\) 出发经过 \(A\)；射线 \(AO\) 从 \(A\) 出发经过 \(O\)。端点不同、方向相反。

核心概念 ③只有线段有长度

直线、射线无限延伸，不能量，也不能比长短。连接两点的线段的长度叫这两点间的距离：线段是图形，距离是一个数。

2. 核心点：两条基本事实

\(\color{#2F7A56}{\underbrace{\text{两点确定一条直线}}_{\text{经过两点有一条，并且只有一条}}}\) \(\color{#966524}{\underbrace{\text{两点之间，线段最短}}_{\text{所有连线中，线段最短}}}\)

“确定”有两层意思：有（能画出来）、只有一条（不会有第二条）。第一条管“固定、对齐”，第二条管“路程最短”。

直觉微图解 ②从 A 到 B，三条路比一比

用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时再展开提示。

例 1（示范：跟老师走一遍思考过程）

平面上有 \(A\)、\(B\)、\(C\) 三个点（题目没说它们在不在同一条直线上）。经过其中每两个点画直线，一共能画几条？

① 读懂题意：「每两个点画一条」，有几对点？题目没说三点的位置，要不要分情况？

提示 1：先数有几对点

从 \(A\) 出发：\(AB\)、\(AC\)；从 \(B\) 出发：\(BC\)（\(BA\) 已经数过）。共 3 对。

看完整示范
② 想办法：两点确定一条直线：每对点画出一条，而且只有一条。但不同的两对点，画出的可能是同一条直线。
③ 执行：三点不在同一条直线上：3 对点画出 3 条不同的直线。三点在同一条直线上：3 对点画出的都是这一条，只有 1 条。答：1 条或 3 条。
执行中检查：回到「从例子进入」第三档：三点不在一条直线上，正好 3 条 ✓。

④ 回头看：没给图、没说位置，就把可能的位置都画出来。这个习惯后面算线段时还要用。

自己试试：高速公路遇到大山时，常常打一条隧道直接穿过去，而不是绕着山修。这样做缩短了路程，用到的是哪条基本事实？

B。问的是「路程变短」：起点和终点不变，绕山的路是两点间的一条曲线，隧道接近两点间的线段，线段最短。

3. 核心点：线段的比较、和差与中点

比较两条线段：可以量（度量法），也可以叠（叠合法：把一条移过来，让一个端点重合、两条线段落在同一条直线上的同一侧，看另一个端点落在哪里）。在一条直线上首尾相接，得到两条线段的和；在长线段上截去一条短线段，剩下的是它们的差。

直觉微图解 ③叠合法：一端对齐，看另一端

点 \(M\) 在线段 \(AB\) 上，并且把它分成相等的两条线段 \(AM\) 与 \(MB\)，点 \(M\) 叫线段 \(AB\) 的中点：

\(\color{#2F7A56}{\underbrace{AM}_{\text{左半段}}}=\color{#966524}{\underbrace{MB}_{\text{右半段}}}=\tfrac12\,\underbrace{AB}_{\text{整条}}\)

反过来 \(AB=2AM=2MB\)。把线段分成三等份的点有 2 个（三等分点），分成四等份的有 3 个。

例 2（示范）

线段 \(AB=14\) cm，点 \(C\) 在线段 \(AB\) 上，\(AC=5\) cm，点 \(M\) 是线段 \(CB\) 的中点。求 \(AM\) 的长。

提示 1：先画图、标数

画一条线段 \(AB\)，在靠近 \(A\) 的地方取 \(C\)，在 \(C\)、\(B\) 正中间取 \(M\)。看到「中点」，写出它给的关系：\(CM=MB=\tfrac12 CB\)。

看完整示范
② 想办法：\(AM=AC+CM\)，\(AC\) 已知，只差 \(CM\)；\(CM\) 是 \(CB\) 的一半，\(CB\) 用差算。
③ 执行：\(CB=AB-AC=14-5=9\)（cm）；\(CM=\tfrac12 CB=4.5\)（cm）；\(AM=AC+CM=5+4.5=9.5\)（cm）。
执行中检查：\(MB=AB-AM=14-9.5=4.5=CM\) ✓。

④ 回头看：\(M\) 是 \(CB\) 的中点，不是 \(AB\) 的中点，别写成 \(AM=7\)。先看清「谁的中点」。

自己试试：线段 \(AB=12\) cm，点 \(C\)、\(D\) 是它的两个三等分点（\(C\) 靠近 \(A\)），点 \(M\) 是线段 \(CD\) 的中点。\(AM\) 等于多少？

B。\(AC=CD=DB=4\)，\(CM=\tfrac12 CD=2\)，\(AM=AC+CM=4+2=6\)（cm）。正好是 \(AB\) 的一半，\(M\) 也是 \(AB\) 的中点。选 A 只算到 \(C\)；选 D 只算了 \(CM\)。

题目没给图，只说几个点“在同一条直线上”时，点的先后顺序不确定，要把每种位置都画出来：

直觉微图解 ④\(PQ=6\)，\(QR=2\)：\(R\) 可能在两边

再试一个：点 \(A\)、\(B\)、\(C\) 在同一条直线上，\(AB=9\) cm，\(BC=4\) cm（没有给图）。\(AC\) 等于多少？

C。\(C\) 在 \(B\) 远离 \(A\) 的一侧：\(AC=9+4=13\)；\(C\) 在 \(A\)、\(B\) 之间：\(AC=9-4=5\)。（\(C\) 不会在 \(A\) 的左边：那样 \(BC\) 比 \(AB\) 还长。）只画一种图就漏解。

尺规作图：只用没有刻度的直尺和圆规画图。作一条线段等于已知线段 \(a\)：先画一条射线，用圆规量出 \(a\) 的长，以射线的端点为圆心，在射线上截取。作两条线段的和、差，就是接着往前截、或往回截。本节只要求画出图形，不写作法。

4. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）\(AM=MB\)，就说 \(M\) 是中点
❌ 典型错解：“\(AM=MB\)，所以 \(M\) 是线段 \(AB\) 的中点。”
✅ 看图秒懂：\(M\) 可以不在 \(AB\) 上，像帐篷的尖，到两端一样远，却不是中点。中点必须在线段上。
翻车现场 ②给直线、射线量长度
❌ 典型错解：“直线 \(AB\) 长 5 cm”“射线比线段长”。
✅ 一眼看清：直线、射线没有长度，不能比长短。应说“线段 \(AB\) 长 5 cm”，或“\(A\)、\(B\) 两点间的距离是 5 cm”。
翻车现场 ③两条基本事实用混
❌ 典型错解：“排队时只要看齐前面两个人，整队就站直了——两点之间线段最短。”
✅ 一眼看清：要的是“站成一条直线”，是两点确定一条直线。和“路程长短”有关的，才用线段最短。
再深一点（可以先跳过）：延长线段、数线段

延长线段 \(AB\)指从 \(A\) 向 \(B\) 的方向延长；反方向延长叫反向延长。射线只能反向延长，直线不能延长。“连接 \(AB\)”就是画线段 \(AB\)。

一条直线上有 5 个点，能组成几条线段？从最左边的点出发能连 4 条，下一个点再连 3 条……共 \(4+3+2+1=10\) 条。“动手”③ 可以数更多的点。

① 线段的和、差与中点

拖动 \(A\)、\(B\)、\(C\)（或点一下再用方向键，每次 0.5 cm；直尺单位是 cm）。\(M\) 是线段 \(AB\) 的中点，由代码算出。看 \(C\) 在线段上和线段外时，\(AC\)、\(CB\) 和 \(AB\) 的关系。

② 两点之间，线段最短

拖动点 \(P\)（或用方向键，每次 0.5 cm）。比较折线 \(A\to P\to B\) 的总长和线段 \(AB\)（\(AB=7\) cm）。

③ 进阶：一条直线上有 n 个点，能组成几条线段？

拖动下面的滑块（或用方向键）改变点数。每条弧表示一对端点，提醒你这两个端点确定一条线段；实际的线段在下面的直线上。金色的弧是最左边的点和其他点配成的对，其余的是绿色。

从易到难排好了。卡住时先展开提示。

直接用

1. 以 \(P\) 为端点、经过点 \(Q\) 的射线，应该记作什么？

B。射线的端点字母写在前面。射线 \(QP\) 的端点是 \(Q\)，方向相反。

2. 线段 \(AB=16\) cm，点 \(C\) 是 \(AB\) 的中点，点 \(D\) 是 \(CB\) 的中点。\(AD\) 等于多少？

A。\(AC=CB=8\)，\(CD=\tfrac12 CB=4\)，\(AD=AC+CD=8+4=12\)（cm）。B 只算到 \(C\)；C 只算了 \(CD\)。

易错

3. 下面说法正确的是哪一个？

提示

哪些线能量长度？射线的两个字母能不能交换？距离是图形还是数？

D。线段的两个字母可以交换。A：直线、射线都没有长度，不能比；B：端点不同、方向相反；C：距离是线段的长度，是数，不是线段本身。

4. 「如果 \(AM=BM\)，那么点 \(M\) 是线段 \(AB\) 的中点。」这句话对吗？

提示

试着找一个到 \(A\)、\(B\) 一样远、但不在线段 \(AB\) 上的点。

B。\(M\) 可能不在线段 \(AB\) 上（翻车现场 ①）。要加上「点 \(M\) 在线段 \(AB\) 上」才对。

5. 下面的做法中，能用「两点之间，线段最短」解释的是哪一个？

提示

先问自己：这件事要的是「对齐、固定」，还是「路程短」？

C。只有 C 在比路程长短。A、B、D 都是「两点一定，直线就定了」，用的是两点确定一条直线。

挑战

6. 点 \(A\)、\(B\)、\(C\) 在同一条直线上，\(AB=10\) cm，\(BC=4\) cm，点 \(M\)、\(N\) 分别是 \(AB\)、\(BC\) 的中点。\(MN\) 等于多少？

提示 1：没给图

\(C\) 可能在 \(B\) 远离 \(A\) 的一侧，也可能在 \(A\)、\(B\) 之间。两种图都画。

提示 2：先算 MB、BN

\(MB=5\)，\(BN=2\)。\(M\)、\(N\) 在 \(B\) 的两边时相加，在同一边时相减。

C。\(MB=5\)，\(BN=2\)。\(C\) 在 \(B\) 远离 \(A\) 的一侧时，\(M\)、\(N\) 在 \(B\) 的两边，\(MN=5+2=7\)；\(C\) 在 \(A\)、\(B\) 之间时，\(M\)、\(N\) 都在 \(B\) 的左边，\(MN=5-2=3\)（cm）。D 是 \(AB+BC\)。
