5.2 三角函数的概念

初中的 sin、cos、tan 只管锐角。把角放进坐标系、让终边去碰单位圆，任意角都有正弦、余弦；正切还要求终边不在 y 轴上。坐标也让函数值有了正负号。先从一座摩天轮开始。

一座摩天轮，半径 \(10\) 米。一个座舱从和中心一样高的最右边（\(0^\circ\)）出发，逆时针转。点下面的角度按钮，看座舱里的直角三角形怎么给出“水平距离”和“高度”：

座舱绕中心转过 \(30^\circ\) 时，它比中心高多少米？

A。从座舱向水平线作垂线，得到一个直角三角形：斜边是半径 \(10\)，\(30^\circ\) 角的对边是斜边的一半，\(5\) 米。约 \(8.7\) 米是邻边（水平方向走了多远）。

高度 \(\div\) 半径 \(=\dfrac5{10}=\dfrac12\)，正好是 \(\sin30^\circ\)。

可座舱还会接着转：转过 \(150^\circ\) 时又比中心高 \(5\) 米；转过 \(210^\circ\) 时在中心下方 \(5\) 米，记作 \(-5\)。这时已经画不出含这个角的直角三角形，但「高度 \(\div\) 半径」照样算得出来。这一节就用这个办法，给任意角定义正弦、余弦、正切。

1. 先认识几个词：单位圆定义、象限符号与同角两大关系

要用到：初中的锐角三角比（对边比斜边）；5.1 的任意角与弧度制（回看 5.1）。先看下面这幅微图解：

直觉微图解 ①单位圆坐标定义、四象限符号与同角平方商数

维度飞跃初中边长之比 vs 高中单位圆坐标

初中直角三角形内只能算锐角且恒正；高中在单位圆上取终边交点，将角顶点放原点、始边重合 \(x\) 轴正向，\(\sin\alpha=y,\ \cos\alpha=x\) 赋予坐标正负号，正弦、余弦推广到任意实数角；正切还须检查横坐标不为零。

定义禁区正切无意义点与轴线角

当终边落在 \(y\) 轴上（\(\alpha=\dfrac{\pi}{2}+k\pi\)）时，横坐标 \(x=0\)，\(\tan\alpha=\dfrac{y}{x}\) 分母为零绝对无定义！坐标轴上的轴线角不属于任何象限！

2. 核心数学定义与同角三角恒等式

单位圆上：\(\sin\alpha=y,\quad\cos\alpha=x\)；\(\tan\alpha=y/x\ (x\ne0)\)。 一般终边上取 \(P(x,y)\ne O\)，\(r=\sqrt{x^2+y^2}>0\)：\(\sin\alpha=y/r,\quad\cos\alpha=x/r\)，\(\tan\alpha=y/x\ (x\ne0)\)。

平方关系（知一求二，开方必查象限）：
\(\color{#966524}{\sin^2\alpha + \cos^2\alpha = 1}\)

商数关系（弦化切超级武器）：
\(\color{#3E5C76}{\tan\alpha = \frac{\sin\alpha}{\cos\alpha}}\)，
条件：\(\color{#3E5C76}{\alpha \ne \frac{\pi}{2}+k\pi,\ k\in\mathbb{Z}}\)。

例 1（单位圆坐标求三角函数值）

求 \(\alpha=\dfrac{2\pi}{3}\)（即 \(120^\circ\)）的三个三角函数值。

终边在第二象限，与 \(x\) 轴负半轴夹角为 \(60^\circ\)，单位圆交点 \(P\left(-\dfrac{1}{2}, \dfrac{\sqrt{3}}{2}\right)\)。
由定义直接读坐标：\(\sin\dfrac{2\pi}{3} = \dfrac{\sqrt{3}}{2}\)，\(\cos\dfrac{2\pi}{3} = -\dfrac{1}{2}\)，\(\tan\dfrac{2\pi}{3} = \dfrac{\sqrt{3}/2}{-1/2} = -\sqrt{3}\)。

自己试试：\(\cos\pi=\)？

C。\(\pi\) 的终边落在 \(x\) 轴负半轴，单位圆交点为 \(P(-1, 0)\)，余弦等于横坐标，即 \(\cos\pi = -1\)。选 A 的同学混淆了横纵坐标（\(\sin\pi = 0\)）。

例 2（终边任取一点求值）

角 \(\alpha\) 的终边经过点 \((-3,4)\)，求 \(\sin\alpha,\ \cos\alpha,\ \tan\alpha\)。

到原点距离 \(r = \sqrt{(-3)^2+4^2} = 5\)（距离恒正）。
\(\sin\alpha = \dfrac{y}{r} = \dfrac{4}{5}\)，\(\cos\alpha = \dfrac{x}{r} = -\dfrac{3}{5}\)，\(\tan\alpha = \dfrac{y}{x} = -\dfrac{4}{3}\)。

自己试试：角 \(\alpha\) 的终边经过点 \(P(3,-4)\)，\(\sin\alpha=\)？

C。\(r = \sqrt{3^2+(-4)^2} = 5\)，\(\sin\alpha = \dfrac{y}{r} = -\dfrac{4}{5}\)。选 B 是把边长恒正套了上来，忽略了第四象限纵坐标为负！

3. 三步破题思维链：同角三角函数知一求二与弦化切

例 3（示范：同角求值与齐次分式弦化切三步思维链）

已知 \(\sin\alpha = -\dfrac{3}{5}\)，且 \(\alpha\) 是第四象限角。求 \(\cos\alpha,\ \tan\alpha\)；并求分式 \(\dfrac{2\sin\alpha + \cos\alpha}{\cos\alpha - \sin\alpha}\) 的值。

👀 第一步由象限锁定余弦正负并开方求值： 因 \(\alpha\) 是第四象限角，横坐标必为正，故 \(\cos\alpha > 0\)！
由同角平方公式开方取正根：\(\cos\alpha = +\sqrt{1 - \sin^2\alpha} = \sqrt{1 - \dfrac{9}{25}} = \dfrac{4}{5}\)！
🔧 第二步商数关系求正切： 代入商数关系式：\(\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{-3/5}{4/5} = -\dfrac{3}{4}\)；
核对口诀「四余弦正」，第四象限只有余弦为正，正切为负，完全自洽！
🛡️ 第三步齐次分式弦化切避免通分繁杂运算： 所求式分子、分母均为正弦、余弦的一次齐次式，分子分母同除以 \(\cos\alpha\)（\(\cos\alpha = \dfrac{4}{5} \ne 0\)）：
\(\dfrac{2\sin\alpha + \cos\alpha}{\cos\alpha - \sin\alpha} = \dfrac{2\tan\alpha + 1}{1 - \tan\alpha} = \dfrac{2(-3/4) + 1}{1 - (-3/4)} = \dfrac{-1/2}{7/4} = -\dfrac{2}{7}\)！

自己试试：\(\tan\alpha>0\) 且 \(\cos\alpha<0\)，\(\alpha\) 是第几象限角？

C。\(\tan\alpha>0\) 说明横纵坐标同号（一或三象限）；\(\cos\alpha<0\) 说明横坐标为负（二或三象限）。取交集即为第三象限！

例 4（已知正切化弦求值）

\(\tan\alpha=2\)，求 \(\dfrac{\sin\alpha+\cos\alpha}{\sin\alpha-\cos\alpha}\)。

分子分母同除以 \(\cos\alpha\)（正切存在必有 \(\cos\alpha\ne0\)）：
原式 \(= \dfrac{\tan\alpha+1}{\tan\alpha-1} = \dfrac{2+1}{2-1} = 3\)。

自己试试：\(\tan\alpha=3\)，\(\dfrac{2\sin\alpha-\cos\alpha}{\sin\alpha+\cos\alpha}=\)？

A。同除以 \(\cos\alpha\) 得 \(\dfrac{2\tan\alpha-1}{\tan\alpha+1} = \dfrac{6-1}{3+1} = \dfrac{5}{4}\)。

4. 用之前必查：三大高频翻车现场

翻车现场 ①开方求值不看象限，单解漏解或双解乱套
❌ 典型错解：已知 \(\sin\alpha = \dfrac{4}{5}\)，直接得出 \(\cos\alpha = \sqrt{1-(4/5)^2} = \dfrac{3}{5}\)。
✅ 一眼看清真相：题目若未指明象限，\(\alpha\) 既可能在第一象限（\(\cos\alpha = \dfrac{3}{5}\)），也可能在第二象限（\(\cos\alpha = -\dfrac{3}{5}\)）！必须分类讨论取 \(\pm\dfrac{3}{5}\)！
翻车现场 ②方程两边盲目约掉未知数导致漏根
❌ 典型错解：解方程 \(\sin\alpha\cos\alpha = \cos\alpha\)，两边同时约去 \(\cos\alpha\) 得 \(\sin\alpha = 1\)。
✅ 一眼看清真相：未知式除以 \(\cos\alpha\) 必须先证明其非零！移项因式分解 \(\cos\alpha(\sin\alpha-1)=0\)，解得 \(\cos\alpha=0\) 或 \(\sin\alpha=1\)！直接约分直接漏解！
翻车现场 ③忽视正切在 y 轴轴线角的无定义禁区
❌ 典型错解：以为正切和正弦余弦一样处处有定义，把 \(\tan 90^\circ\) 当成某具体数值。
✅ 看右图秒懂真相：\(\alpha = \dfrac{\pi}{2}+k\pi\) 时终边落在 \(y\) 轴上，横坐标 \(x=0\)，分母断裂绝对无意义！
再深一点（可以先跳过）

为什么终边取任何点比值都一样：终边上任意两点坐标成相似比例，\(\dfrac{y_1}{r_1} = \dfrac{y_2}{r_2}\)，比值只由旋转角度决定，与所取点到原点的距离完全无关！

利用“1”的代换弦化切：对于二次分式如 \(\sin\alpha\cos\alpha\)，可巧妙除以 \(1 = \sin^2\alpha+\cos^2\alpha\)，转化为 \(\dfrac{\sin\alpha\cos\alpha}{\sin^2\alpha+\cos^2\alpha} = \dfrac{\tan\alpha}{\tan^2\alpha+1}\)！这是高考小题高频秒杀技！

单位圆：拖点 \(P\)，读三个函数值

拖动单位圆上的金色点 \(P\) 转动终边（可以多转几圈，也可以顺时针转成负角）。横的粗线是 \(\cos\alpha\)，竖的粗线是 \(\sin\alpha\)。下面的按钮给四个象限涂上某个函数的正负号。键盘：Tab 选中 \(P\)，方向键每次 5°，PageUp / PageDown 每次 90°。

试一试：把 \(P\) 拖到 \(y\) 轴上，看 \(\tan\alpha\) 怎样；再看虚线连着的点 \(P'\)——它和 \(P\) 的正弦一样，余弦相反。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 角 \(\alpha\) 的终边经过点 \((-5,12)\)，\(\cos\alpha=\)？

D。\(r=\sqrt{25+144}=13\)，\(\cos\alpha=\dfrac xr=-\dfrac5{13}\)。A 丢了负号；B 是 \(\sin\alpha\)；C 是 \(\dfrac xy\)，既不是余弦也不是正切。

2. \(\alpha\) 是第二象限角，\(\sin\alpha=\dfrac45\)，\(\tan\alpha=\)？

B。\(\cos^2\alpha=1-\dfrac{16}{25}=\dfrac9{25}\)，第二象限余弦为负，\(\cos\alpha=-\dfrac35\)，\(\tan\alpha=\dfrac{4/5}{-3/5}=-\dfrac43\)。A 忘了余弦的负号；C 把正切算成了 \(\dfrac{\cos\alpha}{\sin\alpha}\)。

易错

3. 已知 \(\sin\alpha=\dfrac35\)，那么 \(\cos\alpha=\)？

C。由 \(\cos^2\alpha=1-\dfrac9{25}=\dfrac{16}{25}\)，开方得 \(\pm\dfrac45\)。

正弦为正，终边可能在第一象限，也可能在第二象限：在单位圆上就是 \(y=\dfrac35\) 这条横线碰到的两个点，一左一右。只写 \(\dfrac45\) 丢了一种；说「求不出」也不对，结果只有这两种。题目给了象限（或角的范围），才能定下一个符号。

4. \(\alpha=\dfrac{3\pi}2\) 时，下面哪句对？

A。\(\dfrac{3\pi}2\) 的终边是 \(y\) 轴负半轴，碰到单位圆在 \((0,-1)\)：\(\sin\alpha=-1\)，\(\cos\alpha=0\)。

B 错：终边在坐标轴上的角不属于任何象限，不能套象限符号表。C 错：\(\cos\alpha=0\) 时 \(\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}\) 这个关系本身就不能用，「\(-\infty\)」不是一个数。D 把横纵坐标弄反了。

5. 已知 \(\sin\alpha=2\cos\alpha\)。小明两边同除以 \(\cos\alpha\)，得 \(\tan\alpha=2\)。他这一步还缺什么？

B。结论 \(\tan\alpha=2\) 是对的，但除法有前提：除数不能为 \(0\)。

这里正好能用平方关系排除 \(\cos\alpha=0\)：那样 \(\sin\alpha\) 也得是 \(0\)，两者的平方和就成了 \(0\)，不是 \(1\)。写上这一句，推理才完整。C 错：两边相除不会产生正负号，正负号是开平方时才有的。

同类例题：终边过含参数点，先求距离再分类

已知角 \(\alpha\) 的终边经过 \(P(-3a,4a)\)，\(a\ne0\)，求 \(\sin\alpha\)、\(\cos\alpha\)、\(\tan\alpha\)。到原点距离为 \(r=5|a|\)，按 \(a>0\) 与 \(a<0\) 分类，原点不取。

挑战

6. \(\alpha\in(0,\pi)\)，\(\sin\alpha+\cos\alpha=\dfrac15\)，\(\tan\alpha=\)？

C。把 \(\sin\alpha+\cos\alpha=\dfrac15\) 和 \(\sin^2\alpha+\cos^2\alpha=1\) 联立：设 \(\sin\alpha=s\)，则 \(\cos\alpha=\dfrac15-s\)，代入得 \(s^2+\left(\dfrac15-s\right)^2=1\)，整理成 \(25s^2-5s-12=0\)，\(s=\dfrac45\) 或 \(s=-\dfrac35\)。

\(\alpha\in(0,\pi)\)，终边在 \(x\) 轴上方，\(\sin\alpha>0\)，只能 \(\sin\alpha=\dfrac45\)，\(\cos\alpha=-\dfrac35\)，\(\tan\alpha=-\dfrac43\)。选 B 是没用角的范围去掉 \(\sin\alpha=-\dfrac35\)、\(\cos\alpha=\dfrac45\) 那一组。

同类例题：乘积与差两个条件，取象限交集

若 \(\sin\theta\cos\theta<0\)，且 \(\cos\theta-\sin\theta>0\)，终边在哪个象限？单位圆上先看 \(xy<0\)，再看 \(x>y\)，取交集得到第四象限。
