7.1 复数的概念

从负数不能开平方到引入虚数单位 \(i\)，数从一维数轴扩充到二维复平面。实部、虚部、模长与几何意义，一次搞明白。

回顾数系的扩充历程，每一次都是因为「现有的数不够用了」：

  • 小减大减不出来，引入了负数，扩充到整数；
  • 除不尽除不出来，引入了分数，扩充到有理数；
  • 正方形边长 \(\sqrt{2}\) 无法表示为分数，引入了无理数，扩充到实数。

在实数范围内，任何数的平方都不能是负数（\(x^2 \ge 0\)）。可如果解下面这个方程呢？

方程 \(x^2 + 1 = 0\) 在实数范围内有解吗？

B。移项得到 \(x^2 = -1\)。因为任何实数的平方都 \(\ge 0\)，所以在实数范围内不存在平方等于 \(-1\) 的数，该方程无实数解。

为了让这类方程也能求解，数学家规定了一个新数 \(i\)，叫做虚数单位，并规定 \(i^2 = -1\)。这样方程 \(x^2 = -1\) 就有了新解 \(x = \pm i\)。

把虚数单位 \(i\) 与实数结合起来相加相乘，就得到了更广阔的数系——复数。从此，数不再只排在一条一维数轴上，而是铺开成了整整一个复平面！

1. 先认识几个词

要用到：实数与平方根（初中学过）；平面向量与坐标表示（必修第二册第 6 章）。

虚数单位 \(i\)：满足 \(i^2 = -1\) 的数。由此负数也可以开平方了，比如 \(\sqrt{-4} = 2i\)。

复数的代数形式 \(z = a + bi\)：其中 \(a, b\) 都是实数。\(a\) 叫做实部，实数 \(b\) 叫做虚部。

例：\(z = 3 + 2i\)，实部是 \(3\)，虚部是 \(2\)（特别注意：虚部是 \(2\)，不是 \(2i\)！）。

复数的分类：设 \(z = a + bi\)（\(a, b \in \mathbf{R}\)）：

  • \(b = 0\) 时，\(z = a\) 是实数；
  • \(b \ne 0\) 时，\(z\) 叫做虚数；
  • \(a = 0\) 且 \(b \ne 0\) 时，\(z = bi\) 叫做纯虚数。

例：\(5\) 是实数；\(3 + 2i\) 是虚数；\(2i\) 是纯虚数；\(0 = 0 + 0i\) 的虚部是 \(0\)，所以 \(0\) 是实数，不是纯虚数。

模长 \(|z|\)：复数 \(z = a + bi\) 对应的点到原点的距离，公式为 \(|z| = \sqrt{a^2 + b^2}\)。模长是一个非负实数。

例：\(z = 3 + 4i\)，模长 \(|z| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\)。

2. 复数相等与分类

两个复数什么时候算「相等」？就像平面上的两个点坐标一样，必须实部对实部、虚部对虚部分别相等：

设 \(a, b, c, d \in \mathbf{R}\)，\(a + bi = c + di \iff a = c \text{ 且 } b = d\)。

这个性质非常强大：一个复数等式，能拆成实部、虚部两个独立的实数方程。求待定字母时，先整理成 \((\dots) + (\dots)i = 0\) 的形式。

例 1（复数相等与方程）

已知实数 \(x, y\) 满足 \((x + 2) + (y - 3)i = 0\)，求 \(x, y\) 的值。

解：因为 \(0 = 0 + 0i\)，由复数相等的充要条件得：

\(\begin{cases} x + 2 = 0 \\ y - 3 = 0 \end{cases} \implies \begin{cases} x = -2 \\ y = 3 \end{cases}\)

所以 \(x = -2\)，\(y = 3\)。

自己试试：已知复数 \(z = (2x - 4) + (x + 1)i\)（\(x \in \mathbf{R}\)）是纯虚数，则实数 \(x\) 的值是？

B。纯虚数必须同时满足两件事：

  • 实部等于 \(0\)：\(2x - 4 = 0 \implies x = 2\)；
  • 虚部不等于 \(0\)：\(x + 1 \ne 0 \implies x \ne -1\)。

检验：将 \(x = 2\) 代入得虚部为 \(2 + 1 = 3 \ne 0\)，符合条件。选 C 的同学忽略了纯虚数的虚部不能为 \(0\)：若 \(x = -1\)，复数为 \(-6 + 0i = -6\)，是实数而不是纯虚数！

3. 复数的几何意义与模长

在数轴上，每一个实数对应数轴上的一个点；而复数包含两个实数分量（实部与虚部），正好一一对应二维平面直角坐标系中的点：

  • 横轴叫做实轴，纵轴叫做虚轴，建立的坐标系叫做复平面。
  • 复数 \(z = a + bi\) 一一对应点 \(Z(a, b)\)，也一一对应向量 \(\vec{OZ} = (a, b)\)。
  • 实轴上的点 \((a, 0)\) 表示实数 \(a\)；虚轴上除去原点的点 \((0, b)\) 表示纯虚数 \(bi\)；原点 \((0, 0)\) 表示实数 \(0\)。
复数 \(z = a + bi\) 的模长就是向量 \(\vec{OZ}\) 的长度：\(|z| = \sqrt{a^2 + b^2}\)。

例 2（几何点与模长计算）

求复数 \(z = -3 + 4i\) 在复平面内对应的点坐标、所在象限及模长 \(|z|\)。

解：实部 \(a = -3\)，虚部 \(b = 4\)。

① 对应的点坐标为 \(Z(-3, 4)\)，横负纵正，位于第二象限；

② 模长 \(|z| = \sqrt{(-3)^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5\)。

自己试试：已知复数 \(z = a - 2i\)（\(a \in \mathbf{R}\)），且 \(|z| = \sqrt{13}\)，在复平面内对应的点在第四象限，则 \(a\) 的值是？

A。由模长公式：\(|z| = \sqrt{a^2 + (-2)^2} = \sqrt{a^2 + 4} = \sqrt{13}\)，两边平方得 \(a^2 + 4 = 13 \implies a^2 = 9 \implies a = \pm 3\)。

因为点落在第四象限，横坐标（实部）必须为正，即 \(a > 0\)，因此 \(a = 3\)。选 C 的同学漏看了象限对符号的正负约束。

4. 用之前，记清这四条红线

考试中最容易失分的，就是专题卡 M2-07-A 划出的这四条边界：

  1. 虚部是实数 \(b\)，不是 \(bi\)：
    反例：复数 \(z = 3 + 4i\) 的虚部是实数 \(4\)，回答「虚部是 \(4i\)」判错。实部和虚部本身都是实数。
  2. 纯虚数必须同时满足「实部为 \(0\) 且 虚部不为 \(0\)」：
    反例：\(0 = 0 + 0i\) 的实部是 \(0\)，但虚部也是 \(0\)，所以 \(0\) 是实数，绝不是纯虚数！原点 \((0, 0)\) 在虚轴上，但它代表实数 \(0\)。
  3. 虚数不能比较大小：
    反例：写出 \(2 + 3i > 1 + 2i\) 或 \(3i > 2i\) 是无意义的错误。复数集中虚数没有大小顺序，只有实数才能比大小；但它们的模长是实数，可以比较大小（如 \(|3i| > |2i|\)）。
  4. 用复数相等拆方程时，前提必须是实系数：
    反例：若没有 \(a, b \in \mathbf{R}\) 的前提，由 \(a + bi = 0\) 不能推导出 \(a = 0, b = 0\)。例如当 \(a = i, b = -1\) 时，\(a + bi = i + (-1)i = 0\)，但 \(a, b\) 都不为 \(0\)。
再深一点（可以先跳过）

共轭复数：实部相等、虚部互为相反数的两个复数叫互为共轭复数，记作 \(\bar{z} = a - bi\)。它们在复平面上的点关于实轴对称，并且乘积是一个非负实数：\(z\bar{z} = (a + bi)(a - bi) = a^2 + b^2 = |z|^2\)。这是下一节复数除法分母实数化的核心工具。

向量三角不等式：复数的加减在几何上对应向量的加减，因此模长满足 \(||z_1| - |z_2|| \le |z_1 \pm z_2| \le |z_1| + |z_2|\)。当两个向量共线同向时取右侧等号，反向时取左侧等号。

复数的三角形式（选学）：设点 \(Z(a, b)\) 到原点的距离为 \(r = |z|\)，从正实轴到 \(\vec{OZ}\) 的角为 \(\theta\)，则 \(z = r(\cos\theta + i\sin\theta)\)。乘法对应「模长相乘、角相加」，在几何上对应一次平面旋转与拉伸。

① 复平面：拖动点 Z，观察实部、虚部、模长与状态

拖动点 \(Z(a, b)\)（或选中后按方向键移动）。观察复数代数形式、实虚部分解、模长 \(\sqrt{a^2 + b^2}\) 以及点落在坐标轴上的类型变化。

从易到难排好了。前两道直接用，中间三道是高频易错红线，最后一道是几何综合挑战。

直接用

1. 复数 \(z = 2 - 3i\) 的虚部是？

A。在代数形式 \(z = a + bi\) 中，虚部是 \(i\) 前面的实数系数 \(b\)，带符号是 \(-3\)，不能带 \(i\)。选 B 的同学混淆了「虚数项」与「虚部」；选 D 是实部。

2. 复数 \(z = -1 + \sqrt{3}i\) 的模长 \(|z|\) 等于？

B。模长公式为 \(|z| = \sqrt{a^2 + b^2} = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2\)。选 C 的同学算出了 \(a^2 + b^2 = 4\) 却忘了开平方。

易错

3. 已知复数 \(z = (m^2 - 1) + (m - 1)i\)（\(m \in \mathbf{R}\)）是纯虚数，则实数 \(m\) 的值是？

B。纯虚数必须满足两个条件：实部为 \(0\) 且 虚部不为 \(0\)。

  • 由实部 \(m^2 - 1 = 0\) 得 \(m = 1\) 或 \(m = -1\)；
  • 由虚部 \(m - 1 \ne 0\) 得 \(m \ne 1\)。

两者综合只能取 \(m = -1\)。若 \(m = 1\)，则 \(z = 0\) 是实数，绝不是纯虚数！这是高频陷阱。

4. 下列关于复数的说法中，正确的是？

C。复数集中只有实数能够比较大小，含有非零虚部的虚数之间根本没有大小顺序，因此 A、B、D 全部是无数学意义的错误说法。但模长是实数，可以比较大小：\(|2 + 3i| = \sqrt{2^2 + 3^2} = \sqrt{13}\)，\(|1 + 2i| = \sqrt{1^2 + 2^2} = \sqrt{5}\)，因为 \(\sqrt{13} > \sqrt{5}\)，所以 C 正确。

5. 已知实数 \(a \in \mathbf{R}\)，复数 \(z = (a - 1) + (a^2 - 4)i\) 在复平面内对应的点位于第二象限，则 \(a\) 的取值范围是？

B。点在第二象限要求横坐标（实部）小于 \(0\) 且纵坐标（虚部）大于 \(0\)：

  • 实部：\(a - 1 < 0 \implies a < 1\)；
  • 虚部：\(a^2 - 4 > 0 \implies a < -2\) 或 \(a > 2\)。

求交集得 \(a < -2\)。选 C 的同学将二次不等式 \(a^2 - 4 > 0\) 误解成了夹在两根之间。

挑战

6. 在复平面内，已知复数 \(z\) 满足 \(|z - (3 + 4i)| = 2\)，则 \(|z|\) 的最大值是？

C。从几何意义理解：\(|z_1 - z_2|\) 表示两点间的距离。\(|z - (3 + 4i)| = 2\) 表示动点 \(Z\) 到定点 \(P(3, 4)\) 的距离恒等于 \(2\)，即点 \(Z\) 的轨迹是以 \(P(3, 4)\) 为圆心、半径 \(R = 2\) 的圆。

\(|z|\) 表示点 \(Z\) 到原点 \(O(0, 0)\) 的距离。圆心到原点的距离为 \(|OP| = \sqrt{3^2 + 4^2} = 5\)。

因此圆上的点到原点的最大距离为 \(|OP| + R = 5 + 2 = 7\)（最小值为 \(5 - 2 = 3\)）。选 C。
