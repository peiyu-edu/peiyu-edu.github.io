9.3 统计分析案例

一次统计调查不是算出一个平均数就完事：先把问题问清楚，再随机地收集数据，整理、分析，最后把「数据说了什么」和「我们建议做什么」分开写。这一节用一个自编的「高一睡眠调查」把整个过程走一遍。

学校想知道：高一年级的同学，上学日一晚大概睡多久？全年级 \(1000\) 人，一个个问太费事，打算只问一部分人。点下面的按钮看看四种找人办法在全年级人群中的分布：

下面哪种找人的办法，得到的数据最能代表全年级？

B。A 里留到最后的人可能本来就睡得晚；C 是愿意填的人才填，他们未必像全年级；D 只有一个班。只有 B 让每个人被抽到的机会一样。

可这只是第一步。拿到 \(50\) 个数之后，还要整理成表和图，算平均数、方差、百分位数，最后写出结论和建议。这一节就把这一整套流程走一遍。

1. 先认识几个词

要用到：9.1 随机抽样；9.2 平均数、方差与百分位数。贯通统计活动全闭环。

直观微图解
统计五步闭环：提出问题 ➔ 收集数据 ➔ 整理表示 ➔ 分析推断 ➔ 建议决策。
样本事实 样本实测结果（客观确定）

话语性质：对受访样本数据本身的描述，是客观确定发生的数据事实。

规范措辞：严格限定在「被抽样调查的 \(n\) 名对象中，样本均值为……」。

界限警示：只能代表该样本，不能在未经推断前直接说成全校全体规律。

总体估计 推断未测全体（或然概率）

话语性质：由局部样本根据统计模型对未知总体的推断性估计。

规范措辞：必须使用「估计总体平均值约为……，存在抽样误差」。

界限警示：绝不可写成「全校平均值就是……」，换一次抽样数值必然波动！

加权合并均值：\(\bar{x} = \dfrac{n_1\bar{x}_1 + n_2\bar{x}_2}{n_1+n_2}\)，权重严格取决于各层人数占样本总量的比例。

合并方差公式：合并方差不仅包含各层内部方差加权，还必须加上各层均值离总均值的偏差平方（组间离差）！

2. 一个完整的统计过程与数据收集

  1. 提出问题：明确研究变量（如高一学生上学日每晚睡眠时长）。
  2. 收集数据：合理确定抽样方法（分层按比例随机抽样）。
  3. 整理表示：列表分组、绘制频率分布直方图或点图。
  4. 分析推断：计算样本均值、方差、中位数、百分位数，合并多层数据。
  5. 结论建议：明确区分样本事实、总体估计与行动建议。

例 1（收集数据分层设计）

全年级走读生 600 人、住校生 400 人，按比例分层抽 50 人，每层各抽几人？

总体 1000 人，抽 50 人，抽样比为 \(\dfrac{50}{1000} = \dfrac{1}{20}\)。
走读生抽：\(600 \times \dfrac{1}{20} = 30\) 人；住校生抽：\(400 \times \dfrac{1}{20} = 20\) 人（合计 50 人）。

自己试试：另一个年级走读生 \(450\) 人、住校生 \(270\) 人，按比例分层抽 \(40\) 人，走读生抽几人？

A。总体 720 人，走读生占 \(\dfrac{450}{720} = \dfrac{5}{8}\)，抽 \(40 \times \dfrac{5}{8} = 25\) 人。选 B 错在把 40 人简单平分。

3. 平均数与方差：代表性与稳定性

例 2（样本数据分析）

住校生样本 10 人的睡眠时长（小时）：\(7.5, 8, 8, 8.5, 7, 8, 8.5, 9, 7.5, 8\)。求平均数与方差。

总和 80，均值 \(\bar{x} = \dfrac{80}{10} = 8.0\) 小时。
离均差平方和：\(0.25+0+0+0.25+1+0+0.25+1+0.25+0 = 3\)。
方差 \(s^2 = \dfrac{3}{10} = 0.30\)，标准差 \(s = \sqrt{0.3} \approx 0.55\) 小时。

自己试试：\(5\) 个数 \(6,7,7,8,7\) 的方差是？

B。\(\bar{x}=7\)，差的平方为 \(1,0,0,1,0\)，总和 2，除以 \(n=5\) 得 0.4。选 A 是除以了 \(n-1=4\)。

4. 分层数据合并与三步思维链

$$\color{#0284c7}{\bar{x} = \frac{n_1\bar{x}_1 + n_2\bar{x}_2}{n}} \qquad \color{#d97706}{s^2 = \frac{n_1}{n}[s_1^2 + (\bar{x}_1 - \bar{x})^2] + \frac{n_2}{n}[s_2^2 + (\bar{x}_2 - \bar{x})^2]}$$
合并方差两大成分：① 加权组内方差（内在波动）；② 加权组间均值差平方（层间落差）！
典型题三步思维链：两层样本数据合并计算均值与总方差

题目：某调查中，走读生样本 30 人，均值 \(\bar{x}_1 = 7.0\)，方差 \(s_1^2 = 0.50\)；住校生样本 20 人，均值 \(\bar{x}_2 = 8.0\)，方差 \(s_2^2 = 0.30\)。求 50 人整体的样本平均数与合并方差。

1
👀 第一眼破题信号： 两层人数不同（30 vs 20），两层均值不同（7.0 vs 8.0），方差不同。合并均值必须按人数加权；合并方差必须计入组间均值落差！
2
🔧 第二步套公式/方法（加权求和与方差双拆解）：

① 求合并均值：
\(\bar{x} = \dfrac{30 \times 7.0 + 20 \times 8.0}{50} = \dfrac{210 + 160}{50} = \dfrac{370}{50} = \mathbf{7.4}\) 小时。

② 求各层均值与总均值的差平方：
走读生层：\((\bar{x}_1 - \bar{x})^2 = (7.0 - 7.4)^2 = (-0.4)^2 = 0.16\)；
住校生层：\((\bar{x}_2 - \bar{x})^2 = (8.0 - 7.4)^2 = (0.6)^2 = 0.36\)。

③ 代入合并方差公式：
\(s^2 = \dfrac{30}{50}[0.50 + 0.16] + \dfrac{20}{50}[0.30 + 0.36] = 0.6 \times 0.66 + 0.4 \times 0.66 = \mathbf{0.66}\)！

3
🛡️ 第三步必查防坑结论： ① 严禁直接把两组方差求平均（\(\frac{0.50+0.30}{2} = 0.40\)，比真值 0.66 严重低估近 40%！丢失了 7.0 与 8.0 之间的群间离差）；
② 校验加权系数之和为 1（\(0.6 + 0.4 = 1.0\)）。

自己试试：走读生 10 人排好序为 \(6,6,6.5,7,7,7,7,7.5,7.5,8.5\)，其第 \(90\) 百分位数是？

C。\(i = 10 \times 90\% = 9\)（整数），取第 9 位（7.5）与第 10 位（8.5）的平均值 \(\frac{7.5+8.5}{2} = 8.0\)。

5. 结论、推断与建议的三重区分

例 5（规范报告结语示范）

  • 样本事实：被调查的 30 名走读生平均睡眠 7.0 小时，20 名住校生平均睡眠 8.0 小时。
  • 总体估计：估计全年级学生平均每晚睡眠约为 7.4 小时，走读生群体比住校生少约 1 小时。
  • 行动建议：建议学校进一步调研走读生晚睡原因（通勤、作业还是手机），审慎评估是否推迟早自习时间。

自己试试：下面哪一句是属于「行动建议」？

C。A 为样本事实，B 为总体推断，C 才是立足现状的决策行动建议。

6. 三大翻车现场与反例微图解

翻车点 1 合并方差错算为各组方差的平均值

❌ \(s^2 = \frac{s_1^2 + s_2^2}{2}\)，完全丢弃两组均值差。

✔ 必须补齐组间离差：公式中的 \((\bar{x}_i - \bar{x})^2\) 绝不可省！均值落差越大，整体离散程度越剧烈。

翻车点 2 把推断估计写成确凿事实

❌ 直接断言「全校学生平均睡眠时间正好是 7.4 小时」。

✔ 统计结论具有或然性：换一批样本结果必然波动，报告必须说「估计全校均值约为 7.4 小时」。

翻车点 3 混淆相关性与因果决策

❌ 看到走读生少睡，立即判定是「玩手机造成的」，出台禁手机令。

✔ 决策必须做因果溯源：统计只能揭示表面数据差异，行动建议前必须做控制变量调研，不可武断归因！

反例微图解：两组方差均为 0，合并总方差却高达 1.0！

组 A（全是 6 小时）和组 B（全是 8 小时）内部方差均为 0。若直接平均得方差 0；但合并后总体为 {6, 6, 8, 8}，均值 7，离差平方和为 4，真实方差高达 1.0！

再深一点（可以先跳过）

多层合并总方差通式：若总体分为 \(K\) 层，样本量为 \(n = \sum n_i\)，则合并总方差为：\(s^2 = \sum_{i=1}^K \dfrac{n_i}{n} [s_i^2 + (\bar{x}_i - \bar{x})^2]\)。

① 拖一拖：平均数、方差、百分位数

点图里是例 3 那 \(10\) 名走读生的睡眠。拖动任一个点（或选中后按方向键，每次 \(0.5\) 小时），看平均数（绿线）、标准差范围（浅色带）和第 \(p\) 百分位数（棕色虚线）怎么变。试试把一个点拖到 \(12\)：平均数动了，中位数呢？

② 进阶：两层合起来

绿块是走读生、棕块是住校生：块的宽是「平均数 \(\pm\) 标准差」，高表示人数。拖动轴上的两个圆点改各层平均数（方向键每次 \(0.1\)），滑块改走读生人数（共 \(50\) 人）。看金色的合并平均数和红色虚线「直接平均」差多少，再看合并方差里的「层间」部分怎么随两层拉开而变大。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 某校高一 \(800\) 人、高二 \(600\) 人、高三 \(600\) 人，按比例分层随机抽 \(100\) 人，高二抽几人？

A。总体 \(2000\) 人，抽样比 \(\dfrac{100}{2000}=\dfrac1{20}\)，高二抽 \(600\times\dfrac1{20}=30\) 人（高一 \(40\)、高三 \(30\)）。选 B、D 是把 \(100\) 平分成三份，没按比例；选 C 是高一的人数。

2. \(8\) 名同学一周的课外运动次数排好序：\(3,5,6,6,7,8,9,10\)。第 \(75\) 百分位数是？

B。\(i=8\times75\%=6\) 是整数，取第 \(6\)、\(7\) 个的平均 \(\dfrac{8+9}{2}=8.5\)。选 A 是只取了第 \(6\) 个；选 C 是只取了第 \(7\) 个。

易错

3. 学校想了解学生每天用手机多久。方案甲：在学校公众号发问卷，三天收回 \(1500\) 份；方案乙：从各年级名单里按比例随机抽 \(120\) 人当面填写。哪个方案的结果更可信？

B。甲是自愿作答：会看公众号、愿意填的人，本身可能就更常用手机，样本偏了。份数再多，偏差也还在，增大样本量修不了抽样方式的毛病。乙虽然人少，但每个人被抽到的机会一样，更有代表性。

4. 甲组 \(10\) 人测验平均 \(70\) 分、方差 \(4\)；乙组 \(10\) 人平均 \(80\) 分、方差 \(4\)。两组合起来 \(20\) 人，方差是？

B。合并平均 \(75\)，两组平均都离它 \(5\)。\(s^2=\dfrac1{20}\left[10\times(4+25)+10\times(4+25)\right]=29\)。选 A 是只平均了两组方差，漏了两组平均分差 \(10\) 分带来的分散；选 C 是把两个方差加了起来。

5. 记录一周睡眠：甲平均 \(6.5\) 小时、方差 \(0.05\)；乙平均 \(8\) 小时、方差 \(0.4\)。有人说「甲的方差小，更稳定，所以甲的睡眠情况更好」。对吗？

B。方差只说波动大小：甲每晚都差不多，但都在 \(6.5\) 小时左右，离 \(8\) 小时差得远。「睡得够不够」先看平均数，「规不规律」才看方差。C 把方差的意思说反了。

挑战

6. 某小组 \(10\) 人每周课外阅读时间：\(9\) 人各 \(2\) 小时，\(1\) 人 \(20\) 小时。报告写：「平均每人每周读 \(3.8\) 小时，超过 \(3\) 小时的目标，说明大部分同学阅读时间达标。」这个结论哪里有问题？

B。平均数 \(\dfrac{9\times2+20}{10}=3.8\) 没算错，可 \(10\) 人里 \(9\) 人只有 \(2\) 小时，中位数是 \(2\)，达标的只有 \(1\) 人。「平均数超过目标」推不出「大部分人达标」。

有极端值时，平均数、中位数要一起看；想说「大部分人」，最好直接数达标的人数，或者看百分位数。C 把平均数和中位数弄混了。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
