在直线上表示数

旧版目录，待新版核对。

把竖着的温度计放平，会怎样？

0 在中间，上面的正数跑到右边，下面的负数跑到左边。这样一条直线，就能把正数、0、负数摆在一起。

把温度计放平后，零下的温度会跑到 0 的哪一边？

温度计上，低的在下；放平后，小的在左，大的在右。负数在 0 的左边。

1. 画一条能表示数的直线：三样东西不能少

这样的直线叫数轴。画它要有三样东西：0 的位置、正方向（规定向右）、单位长度（相邻两格代表多少，格子要一样宽）。

也可以在数轴上点一下或拖一拖，选中的点会跳到最近的格线上。

自己试试

点 A 在 0 左边 3 格，1 格 = 1，它表示（ ）。

0 的左边是负数：一格 −1，两格 −2，三格就是 −3。

2. 谁大谁小，看谁在右边

先把点 A 放到 −3，点 B 放到 2，看读数提示。再点「1 格 = 2」，把点 A 放到 −8，点 B 放到 −4，再看提示：数轴上，右边的数总比左边的数大。

自己试试

−8 和 −3，哪个大？想一想它们在数轴上的位置。

气温 −8 ℃ 比 −3 ℃ 更冷。数轴上 −3 在 −8 的右边，所以 −3 > −8。

数轴上，越往右的数越大，越往左的数越小；正数在 0 的右边，负数在 0 的左边，0 比所有负数大。

两个容易错的地方

✗ 负数「数字大」就更大 说「−9 比 −2 大，因为 9 比 2 大」。
✓ 看谁在右边，右边的大 −2 在 −9 的右边，所以 −2 > −9。气温 −9 ℃ 比 −2 ℃ 冷得多。
✗ 格子画得宽窄不一样 0 到 1 画一格，1 到 2 画两格，读数就乱了。
✓ 单位长度要处处相等 每一格同样宽，0 向左数的格子和向右数的格子一样宽。

直接用

1. 画数轴不能少的三样是（ ）。

数轴必须有 0 的位置、正方向和单位长度，缺一样就没法读出数。

2. 数轴上 1 格 = 2。点 P 在 0 右边 3 格，它表示几？

3 格 × 2 = 6，点 P 表示 6。

容易错

3. 比较大小，正确的是（ ）。

−2 在 −9 的右边，所以 −2 > −9。−1 在 0 的左边，−1 < 0。

4. 把 3、−5、0、−1 按从小到大排列，是（ ）。

从左往右数：−5，−1，0，3。左边的小，右边的大。

5. 数轴上，在 −3 和 2 之间（不含 −3 和 2）有几个整数？

从左往右数：−2、−1、0、1，共 4 个。

想一想

6. 三个城市某天最低气温：甲 −12 ℃，乙 −4 ℃，丙 3 ℃。最冷的是（ ）。

数轴上最靠左的是 −12，所以甲最冷。

7. 小丽说：「0 是最小的数，因为再往左就没有了。」她的话（ ）。

数轴向左一直延伸，−1、−2、−3 …… 都比 0 小，没有最小的数。
