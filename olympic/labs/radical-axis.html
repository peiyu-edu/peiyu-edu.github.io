原创互动实验

共轴圆系、根轴与根心

将两圆圆心对称置于 O₁(−d/2, 0) 与 O₂(d/2, 0)，改变圆心距 d 与半径 r₁、r₂，或在根轴上上下拖动测试点 P：无论两圆相交、相切还是外离，根轴上任意一点对两圆的圆幂恒相等，且与第三圆 ω₃ 的三条两两根轴交于唯一的根心 R。

改变条件

先预测，再核对

先用 x₀=(r₁²−r₂²)/(2d) 估算两圆根轴横坐标 x₀，再核对你的预测（误差允许 0.02；同心 d=0 时不存在唯一有限根轴）。

为什么成立，边界在哪里

平面上一点 P(x, y) 对圆 ω(O, r) 的圆幂定义为 Pow(P, ω) = |PO|² − r²。当 P 在圆外时，Pow(P, ω) > 0，恰好等于过 P 向该圆所作切线长的平方 PT²；当 P 在圆周上（如外切/内切切点或两圆公共弦端点）时，Pow(P, ω) = 0，切线长为 0；当 P 在圆内时，Pow(P, ω) < 0，不存在实切线。取连心线为 x 轴、连心线中点为原点，使 O₁=(−d/2, 0)、O₂=(d/2, 0)。令两圆幂相等：(x + d/2)² + y² − r₁² = (x − d/2)² + y² − r₂²，二次项 x² + y² 完全抵消，化简得一次方程 2d·x = r₁² − r₂²。

当 d > 0 时，等幂点轨迹是垂直于连心线的唯一一条直线 x = x₀ = (r₁² − r₂²)/(2d)，即两圆的根轴（等幂轴）：两圆相交时它是公共弦所在直线；两圆外切或内切时它是公切线；两圆外离或内含时它虽不与圆相交，却依然作为等幂轨迹真实存在。再引入圆心不共线的第三圆 ω₃(O₃, r₃)，由传递性 Pow₁(R)=Pow₂(R) 与 Pow₁(R)=Pow₃(R) 必推出 Pow₂(R)=Pow₃(R)，故三条两两根轴共点于根心 R。

边界与退化姿态：（1）当 d = 0（两圆同心）时，一次项系数 2d = 0：若 r₁ ≠ r₂，幂差 Pow₁(P) − Pow₂(P) = r₂² − r₁² 为非零常数，有限平面内不存在根轴（x₀ 无定义）；若 r₁ = r₂，两圆完全重合，全平面每一点对两圆的圆幂恒相等，不存在唯一根轴（不能把 x₀ 人为约定为 0）；（2）若三圆圆心共线，三条根轴互相平行或重合，有限平面内无唯一根心。
