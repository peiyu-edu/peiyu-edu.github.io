加法运算定律的应用

几个数连加，先看看哪两个数能凑成整十、整百，再用交换、结合的办法，算得又快又不容易错。

旧版目录，待新版核对

跳绳比赛，小东三轮分别跳了 27 下、45 下、73 下。要算一共跳了多少下，先把哪两个数相加最方便？

对，27 + 73 = 100，一下子就凑成了整百，再加 45 就是 145。这样先挑能凑整的数，叫凑整。今天学怎么用加法的交换、结合，把算式变简单。

1. 找一找，配一配

点一个数，再点另一个数，看它们加起来能不能凑成整十。配成功的两个数会变成同一种颜色。配好两对，算式就变简单了。

2. 写成脱式，说清每一步

63 + 48 + 37 + 52

= 63 + 37 + 48 + 52　交换：把 37 换到 63 后面

= (63 + 37) + (48 + 52)　结合：凑整的两个数先加

= 100 + 100 = 200

每一步只改一处。写完数一数：开头 4 个数，括号里也是 4 个数，一个都没少。

① 看数
看每个数的个位，哪两个合起来是 10？
② 凑整
交换位置，把它们放在一起，用括号先算。
③ 算
先算整十、整百，再把剩下的加上。

3. 自己试试

自己试试

用简便方法算：29 + 46 + 71 = □

29 + 46 + 71 = (29 + 71) + 46 = 100 + 46 = 146。

自己试试

58 + 27 + 42 换一种写法，哪一个是对的？

对。(58 + 42) + 27 = 100 + 27 = 127，三个数都用上了。

连加先看数：找个位合起来是 10 的两个数，用交换把它们放在一起，用结合先算它们，凑成整十、整百，再算剩下的。

两个容易错的地方

✗ 凑整时丢了数

45 + 68 + 55 + 12 = 45 + 55 + 68 = 168，12 去哪了？

✓ 每步数一数

(45 + 55) + (68 + 12) = 100 + 80 = 180，4 个数都用上。

✗ 把不能凑整的两个数配在一起

28 + 65 + 72，先算 28 + 65？个位 8 和 5 合起来是 13，凑不成整十。

✓ 看个位，找合起来是 10 的

8 和 2 配对：(28 + 72) + 65 = 100 + 65 = 165。

还要记住：不是每道题都要简算。找不到能凑整的两个数，就直接从左往右算。

直接用

1. 用简便方法算：38 + 47 + 62 = □

(38 + 62) + 47 = 100 + 47 = 147。

2. 用简便方法算：125 + 68 + 75 + 32 = □

(125 + 75) + (68 + 32) = 200 + 100 = 300。

3. 36 + 85 + 64 = 36 + 64 + 85，这一步改变了什么？

A。位置换了用交换，括号换了先算谁才用结合。下一步 (36 + 64) + 85 才用到结合。

容易错

4. 46 + 79 + 54，哪两个数先加才能凑成整十？

B。6 + 4 = 10，46 + 54 = 100，再加 79 是 179。

5. 小华算 83 + 29 + 17 + 61，写成 (83 + 17) + 29 = 129。哪里错了？请算出正确的结果：□

丢了 61。(83 + 17) + (29 + 61) = 100 + 90 = 190。

想一想

6. 三个班给图书角捐书，分别捐了 78 本、45 本、22 本。一共捐了多少本？□

78 + 45 + 22 = (78 + 22) + 45 = 100 + 45 = 145（本）。

7. 下面三道题，哪一道没有能凑成整十的两个数，直接从左往右算就好？

C。41、26、33 的个位是 1、6、3，任意两个加起来都不是 10，直接算：41 + 26 = 67，67 + 33 = 100。不是每题都要简算。

8. 36 + □ + 64 = 150，□ 里填几？

36 + 64 = 100，100 + 50 = 150，所以 □ 是 50。
