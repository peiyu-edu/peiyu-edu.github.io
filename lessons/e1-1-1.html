1.1 空间向量及其运算

把平面向量的加减、数乘和数量积搬到空间：法则不变，新多出来的问题是三个向量共不共面。这一节学这些运算，以及怎样用它们算长度、判垂直。

一架无人机在无风的天空中执行巡检任务。从起飞点出发，无人机先沿水平向东飞行了 \(12\text{ m}\)，接着沿水平向北飞行了 \(5\text{ m}\)，最后垂直向上爬升了 \(9\text{ m}\)。

地面飞控员想知道：无人机现在的空间位置相对于起飞点的总位移大小是多少？

C。水平地面上的向东 \(12\text{ m}\) 与向北 \(5\text{ m}\) 互相垂直，合成后的水平位移大小是 \(\sqrt{12^2+5^2}=13\text{ m}\)；该水平位移再与竖直向上的 \(9\text{ m}\) 垂直合成，总位移长度恰好是一个长方体的体对角线长：\(\sqrt{13^2+9^2} = \sqrt{12^2+5^2+9^2} = \sqrt{250} \approx 15.8\text{ m}\)。

物理中的位移与力具有大小和方向，可以在三维空间中自由合成。那么在数学上，平面向量的加减法法则、共线共面关系以及数量积公式，如何自然推广到三维立体空间？这就是本节要建立的核心体系。

1. 先认识几个词

要用到：平面向量概念与加减法（回看 6.1、6.2）；空间两条直线的位置关系（回看 8.4）。

空间自由向量：在空间中，具有大小和方向的量叫做空间向量。向量的大小叫做向量的模（或长度），记作 \(|\boldsymbol{a}|\)。向量只由大小与方向决定，与起点位置无关，可以在三维空间中自由平行移动。

例：正方体 \(ABCD-A_1B_1C_1D_1\) 中，底面棱向量 \(\overrightarrow{AB}\) 与顶面平行棱向量 \(\overrightarrow{D_1C_1}\)，长度相等且方向相同，它们是同一个向量，即 \(\overrightarrow{AB} = \overrightarrow{D_1C_1}\)。

空间任意两向量必共面：两条空间直线可以既不平行也不相交（异面直线），但向量绝没有「异面」之说！任意给定空间中两个向量，只要把它们的起点平移到同一点 \(O\)，两条有向线段必落在同一个平面内（或在同一条直线上）。

例：正方体中异面棱 \(AB\) 与 \(CC_1\)，其向量 \(\overrightarrow{AB}\) 与 \(\overrightarrow{CC_1}\) 将起点平移到 \(B\) 后为 \(\overrightarrow{AB}\) 与 \(\overrightarrow{BB_1}\)，都在侧面 \(ABB_1A_1\) 内。因此：空间任意两个向量一定共面。

空间向量的夹角：两个非零向量 \(\boldsymbol{a}, \boldsymbol{b}\) 平移到同一起点 \(O\)，它们所成的较小非负角叫做夹角，记作 \(\langle\boldsymbol{a},\boldsymbol{b}\rangle\)，规定范围为 \([0, \pi]\)（即 \(0^\circ \le \langle\boldsymbol{a},\boldsymbol{b}\rangle \le 180^\circ\)）。

例：同向夹角为 \(0\)，互相垂直夹角为 \(90^\circ\)，反向夹角为 \(180^\circ\)。若 \(\boldsymbol{a}\cdot\boldsymbol{b} = 0\) 且两向量非零，则 \(\boldsymbol{a}\perp\boldsymbol{b}\)。

投影向量与投影数量：设 \(\boldsymbol{e} = \dfrac{\boldsymbol{b}}{|\boldsymbol{b}|}\) 是与 \(\boldsymbol{b}\) 同向的单位向量，\(\boldsymbol{a}\) 在 \(\boldsymbol{b}\) 上的投影向量为 \((\boldsymbol{a}\cdot\boldsymbol{e})\boldsymbol{e} = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{b}|^2}\boldsymbol{b}\)（是一个向量）；而投影数量（有向投影长）是实数 \(|\boldsymbol{a}|\cos\langle\boldsymbol{a},\boldsymbol{b}\rangle = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{b}|}\)。

例：若 \(|\boldsymbol{a}|=4\)，夹角为 \(60^\circ\)，则在 \(\boldsymbol{b}\) 上的投影数量为 \(4\cos 60^\circ = 2\)，投影向量是沿 \(\boldsymbol{b}\) 方向长度为 \(2\) 的向量。

2. 加减法与折线回路

意思：空间向量的加法、减法、数乘，规则和平面里一样。为什么：任意两个向量平移到同一起点后落在同一个平面内，两个向量相加就是在这个平面里用平面向量的法则；三个以上的向量，一个一个往上加即可。

  • 三角形法则（首尾相接）：\(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\)；减法：\(\overrightarrow{OB} - \overrightarrow{OA} = \overrightarrow{AB}\)（终点减起点）。
  • 平行四边形法则（共起点）：\(\overrightarrow{OA} + \overrightarrow{OB}\) 是以 \(OA, OB\) 为邻边的平行四边形的对角线向量。
  • 折线回路：首尾相接、最后回到出发点的一串向量，和是零向量： $$\overrightarrow{A_1A_2} + \overrightarrow{A_2A_3} + \cdots + \overrightarrow{A_nA_1} = \boldsymbol{0}$$
  • 平行六面体法则：以 \(\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC}\) 为三条棱作平行六面体，从 \(O\) 出发的体对角线向量 $$\overrightarrow{OP} = \overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC}$$
首尾相接，结果从第一个起点指向最后一个终点；绕一圈回到起点，和是 \(\boldsymbol{0}\)。

例 1（看一遍怎么写）

在正方体 \(ABCD-A_1B_1C_1D_1\) 中，化简：

(1) \(\overrightarrow{AB} + \overrightarrow{CC_1} - \overrightarrow{DA}\)；(2) \(\overrightarrow{AB} + \overrightarrow{BB_1} + \overrightarrow{B_1D_1} + \overrightarrow{D_1A}\)。

解：

(1) 减去一个向量等于加上它的相反向量：\(-\overrightarrow{DA} = \overrightarrow{AD}\)。所以

$$\begin{aligned}\text{原式} &= (\overrightarrow{AB} + \overrightarrow{AD}) + \overrightarrow{CC_1}\\ &= \overrightarrow{AC} + \overrightarrow{CC_1} = \overrightarrow{AC_1}\end{aligned}$$

第一步是底面上的平行四边形法则，第二步是三角形法则。也可以看成：\(\overrightarrow{CC_1} = \overrightarrow{AA_1}\)，三条共起点的棱相加，得体对角线 \(\overrightarrow{AC_1}\)。

(2) 四个向量首尾相接：\(A \to B \to B_1 \to D_1 \to A\)，最后回到出发点 \(A\)，是一条闭合折线，所以原式 \(= \boldsymbol{0}\)。

自己试试：在空间四面体 \(O-ABC\) 中，点 \(M\) 是棱 \(BC\) 的中点，化简 \(\overrightarrow{OM} - \dfrac{1}{2}\overrightarrow{OB} - \dfrac{1}{2}\overrightarrow{OC}\) 的结果是？

A。在 \(\triangle OBC\) 中，\(M\) 是 \(BC\) 中点，\(\overrightarrow{OM} = \dfrac{1}{2}(\overrightarrow{OB} + \overrightarrow{OC})\)，代入后正好减完，结果是零向量 \(\boldsymbol{0}\)。

常见算错：选 B。向量减向量，结果还是向量，要写 \(\boldsymbol{0}\)；实数 \(0\) 是数，不是向量。

3. 共线向量与共面向量定理

意思：判断三点共线、四点共面，就看一个向量能不能用别的向量「伸缩再相加」表示出来。为什么：和 \(\boldsymbol{b}\) 平行的向量只是把 \(\boldsymbol{b}\) 拉长、缩短或反向；两个不共线的向量 \(\boldsymbol{a}, \boldsymbol{b}\) 伸缩后相加，只能走遍它们所在的那个平面。

  • 共线向量定理：\(\boldsymbol{b}\ne\boldsymbol{0}\) 时，\(\boldsymbol{a} \parallel \boldsymbol{b} \iff\) 存在唯一实数 \(\lambda\)，使 \(\boldsymbol{a} = \lambda\boldsymbol{b}\)。
  • 共面向量定理：\(\boldsymbol{a}, \boldsymbol{b}\) 不共线时，\(\boldsymbol{p}\) 与 \(\boldsymbol{a}, \boldsymbol{b}\) 共面 \(\iff\) 存在唯一实数对 \((x, y)\)，使 \(\boldsymbol{p} = x\boldsymbol{a} + y\boldsymbol{b}\)。
  • 四点共面：\(A, B, C\) 不共线，点 \(O\) 在平面 \(ABC\) 外。若 $$\overrightarrow{OP} = x\overrightarrow{OA} + y\overrightarrow{OB} + z\overrightarrow{OC}$$ 则 \(P\) 在平面 \(ABC\) 上 \(\iff x + y + z = 1\)（为什么见 1.2 第 4 块）。
共线：\(\boldsymbol{a} = \lambda\boldsymbol{b}\)；共面：\(\boldsymbol{p} = x\boldsymbol{a} + y\boldsymbol{b}\)（\(\boldsymbol{a}, \boldsymbol{b}\) 不共线）。用平面外一点 \(O\) 展开时，四点共面 \(\iff\) 系数和 \(= 1\)。

例 2

(1) 已知 \(\boldsymbol{a}, \boldsymbol{b}\) 不共线，\(\overrightarrow{AB} = \boldsymbol{a} - 2\boldsymbol{b}\)，\(\overrightarrow{BC} = k\boldsymbol{a} + 6\boldsymbol{b}\)。若 \(A, B, C\) 三点共线，求 \(k\)。

(2) \(A, B, C\) 不共线，点 \(O\) 在平面 \(ABC\) 外，\(\overrightarrow{OP} = \dfrac{1}{3}\overrightarrow{OA} + \dfrac{1}{2}\overrightarrow{OB} + m\overrightarrow{OC}\)。若点 \(P\) 在平面 \(ABC\) 上，求 \(m\)。

解：

(1) \(A, B, C\) 共线，\(\overrightarrow{AB}\) 与 \(\overrightarrow{BC}\) 共线。\(\overrightarrow{AB} \ne \boldsymbol{0}\)，所以存在 \(\lambda\) 使 \(\overrightarrow{BC} = \lambda\overrightarrow{AB}\)：

$$k\boldsymbol{a} + 6\boldsymbol{b} = \lambda\boldsymbol{a} - 2\lambda\boldsymbol{b}$$

\(\boldsymbol{a}, \boldsymbol{b}\) 不共线，两边系数对应相等：\(k = \lambda\)，\(6 = -2\lambda\)。所以 \(\lambda = -3\)，\(k = -3\)。

(2) \(O\) 在平面外，\(P\) 在平面 \(ABC\) 上，系数和为 \(1\)：

$$\frac{1}{3} + \frac{1}{2} + m = 1$$

所以 \(m = 1 - \dfrac{5}{6} = \dfrac{1}{6}\)。

自己试试：\(A, B, C\) 不共线，点 \(P\) 满足 \(\overrightarrow{AP} = 2\overrightarrow{AB} - 3\overrightarrow{AC}\)。点 \(P\) 与平面 \(ABC\) 的关系是？

B。\(\overrightarrow{AP}\) 已经写成了不共线的 \(\overrightarrow{AB}, \overrightarrow{AC}\) 的组合，由共面向量定理，\(\overrightarrow{AP}\) 与它们共面；三个向量又都从 \(A\) 出发，所以 \(P\) 在平面 \(ABC\) 上。

常见算错：算 \(2 + (-3) = -1 \ne 1\)，就选 D。「系数和为 1」只用在从平面外一点 \(O\) 出发、写成 \(\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC}\) 三项的式子；这里是从 \(A\) 出发的两项式子，系数取什么都共面。

4. 数量积与长度、角度、垂直

意思：\(\boldsymbol{a}\cdot\boldsymbol{b} = |\boldsymbol{a}||\boldsymbol{b}|\cos\langle\boldsymbol{a},\boldsymbol{b}\rangle\)，定义和平面里一样。为什么能照搬：两个向量平移到同一起点后在同一平面内，夹角就在这个平面里量。有了它，长度、角度、垂直都能算：

  • 垂直：\(\boldsymbol{a}, \boldsymbol{b}\) 非零时，\(\boldsymbol{a} \perp \boldsymbol{b} \iff \boldsymbol{a}\cdot\boldsymbol{b} = 0\)。
  • 长度：\(|\boldsymbol{a}|^2 = \boldsymbol{a}\cdot\boldsymbol{a}\)，所以 \(|\boldsymbol{a}| = \sqrt{\boldsymbol{a}\cdot\boldsymbol{a}}\)。
  • 夹角：\(\boldsymbol{a}, \boldsymbol{b}\) 非零时，\(\cos\langle\boldsymbol{a},\boldsymbol{b}\rangle = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}\)。

做法：把要求的向量拆成几个「长度、夹角都知道」的向量，再展开。两个基向量不垂直时，展开后的交叉项 \(2\boldsymbol{a}\cdot\boldsymbol{b}\) 不是 \(0\)，必须留着。

求长度先平方：\(|\boldsymbol{a}+\boldsymbol{b}|^2 = |\boldsymbol{a}|^2 + 2\boldsymbol{a}\cdot\boldsymbol{b} + |\boldsymbol{b}|^2\)，交叉项别丢。

例 3

正四面体 \(A-BCD\) 的棱长都是 \(2\)。(1) 求 \(\overrightarrow{AB}\cdot\overrightarrow{CD}\)，说明 \(AB\) 与 \(CD\) 的位置关系；(2) 求 \(|\overrightarrow{AB}+\overrightarrow{CD}|\)。

解：

(1) 用从 \(A\) 出发的棱来拆：\(\overrightarrow{CD} = \overrightarrow{AD} - \overrightarrow{AC}\)。

$$\begin{aligned}\overrightarrow{AB}\cdot\overrightarrow{CD} &= \overrightarrow{AB}\cdot(\overrightarrow{AD}-\overrightarrow{AC})\\ &= \overrightarrow{AB}\cdot\overrightarrow{AD} - \overrightarrow{AB}\cdot\overrightarrow{AC}\end{aligned}$$

每个面都是等边三角形，从 \(A\) 出发的两条棱夹角 \(60^\circ\)：

$$\overrightarrow{AB}\cdot\overrightarrow{AD} = \overrightarrow{AB}\cdot\overrightarrow{AC} = 2\times 2\times\cos 60^\circ = 2$$

所以 \(\overrightarrow{AB}\cdot\overrightarrow{CD} = 2 - 2 = 0\)。两个向量都非零，\(\overrightarrow{AB} \perp \overrightarrow{CD}\)：正四面体的对棱互相垂直（它们是异面直线，垂直指所成角为 \(90^\circ\)）。

(2) 先算平方，交叉项由 (1) 得 \(0\)：

$$\begin{aligned}|\overrightarrow{AB}+\overrightarrow{CD}|^2 &= |\overrightarrow{AB}|^2 + 2\overrightarrow{AB}\cdot\overrightarrow{CD} + |\overrightarrow{CD}|^2\\ &= 4 + 0 + 4 = 8\end{aligned}$$

所以 \(|\overrightarrow{AB}+\overrightarrow{CD}| = \sqrt{8} = 2\sqrt{2}\)。

自己试试：空间向量 \(\boldsymbol{a}, \boldsymbol{b}\) 满足 \(|\boldsymbol{a}| = 2\)，\(|\boldsymbol{b}| = 3\)，\(\langle\boldsymbol{a},\boldsymbol{b}\rangle = 60^\circ\)。\(|\boldsymbol{a}-\boldsymbol{b}|\) 等于？

A。\(\boldsymbol{a}\cdot\boldsymbol{b} = 2\times 3\times\cos 60^\circ = 3\)。

$$|\boldsymbol{a}-\boldsymbol{b}|^2 = 4 - 2\times 3 + 9 = 7$$

所以 \(|\boldsymbol{a}-\boldsymbol{b}| = \sqrt{7}\)。

常见算错：选 B 是丢了交叉项（\(\boldsymbol{a}, \boldsymbol{b}\) 不垂直，\(2\boldsymbol{a}\cdot\boldsymbol{b} \ne 0\)）；选 C 是交叉项符号写成了加号；选 D 是把长度直接相减 \(3 - 2\)。

5. 用之前要注意

从平面到空间，下面四条最容易出错，各配一个反例：

  1. 两两不共线，不等于不共面
    反例：同一个平面内两两成 \(120^\circ\) 的三个向量，两两不共线，但都在这个平面里，不能做空间的基底。
  2. 数量积没有结合律
    反例：\((\boldsymbol{a}\cdot\boldsymbol{b})\boldsymbol{c}\) 是平行于 \(\boldsymbol{c}\) 的向量，而 \(\boldsymbol{a}(\boldsymbol{b}\cdot\boldsymbol{c})\) 是平行于 \(\boldsymbol{a}\) 的向量。\(\boldsymbol{a}\) 与 \(\boldsymbol{c}\) 不共线时，除非 \(\boldsymbol{a}\cdot\boldsymbol{b}\) 与 \(\boldsymbol{b}\cdot\boldsymbol{c}\) 都是 \(0\)，两边不相等。
  3. 数量积不能约去
    反例：若 \(\boldsymbol{a}\cdot\boldsymbol{b} = \boldsymbol{a}\cdot\boldsymbol{c}\)（\(\boldsymbol{a}\ne\boldsymbol{0}\)），移项得 \(\boldsymbol{a}\cdot(\boldsymbol{b}-\boldsymbol{c}) = 0\)，只能说明 \(\boldsymbol{a} \perp (\boldsymbol{b}-\boldsymbol{c})\) 或 \(\boldsymbol{b}=\boldsymbol{c}\)，不能得出 \(\boldsymbol{b}=\boldsymbol{c}\)。例：\(\boldsymbol{a}\) 是竖直向上的单位向量，\(\boldsymbol{b}, \boldsymbol{c}\) 是两个不同的水平向量，\(\boldsymbol{a}\cdot\boldsymbol{b} = \boldsymbol{a}\cdot\boldsymbol{c} = 0\)，但 \(\boldsymbol{b}\ne\boldsymbol{c}\)。
  4. 基向量不垂直时，交叉项要保留
    反例：计算 \(|\boldsymbol{a}+\boldsymbol{b}|^2\) 时，只有当 \(\boldsymbol{a}\perp\boldsymbol{b}\)（直角系）时才等于 \(|\boldsymbol{a}|^2+|\boldsymbol{b}|^2\)；一般基底下必须保留 \(2\boldsymbol{a}\cdot\boldsymbol{b} = 2|\boldsymbol{a}||\boldsymbol{b}|\cos\theta\)。例：\(|\boldsymbol{a}| = |\boldsymbol{b}| = 1\)，夹角 \(60^\circ\)，\(|\boldsymbol{a}+\boldsymbol{b}|^2 = 1 + 1 + 1 = 3\)，不是 \(2\)。

空间里四个向量，为什么总有一个能用另外三个表示？空间只有三个「方向自由度」：三个不共面的向量就能表示空间里所有向量，第四个必然能用它们表示出来。下一节（1.2 空间向量基本定理）把这件事讲清楚。

直接用

1. 在正方体 \(ABCD-A_1B_1C_1D_1\) 中，化简空间折线回路向量表达式 \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CC_1} + \overrightarrow{D_1A_1}\) 的结果是？

A。逐步相加：前三项首尾相连 \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CC_1} = \overrightarrow{AC_1}\)。在正方体顶面中，棱向量 \(\overrightarrow{D_1A_1} = \overrightarrow{C_1B_1}\)。故原式 \(= \overrightarrow{AC_1} + \overrightarrow{C_1B_1} = \overrightarrow{AB_1}\)。

2. 已知空间向量 \(\boldsymbol{a}, \boldsymbol{b}\) 满足 \(|\boldsymbol{a}|=2, |\boldsymbol{b}|=3\)，且 \((\boldsymbol{a}+2\boldsymbol{b})\perp (2\boldsymbol{a}-\boldsymbol{b})\)。则数量积 \(\boldsymbol{a}\cdot\boldsymbol{b}\) 的值为？

A。由垂直充要条件，两向量数量积为 0：

\((\boldsymbol{a}+2\boldsymbol{b})\cdot(2\boldsymbol{a}-\boldsymbol{b}) = 2\boldsymbol{a}^2 + 3\boldsymbol{a}\cdot\boldsymbol{b} - 2\boldsymbol{b}^2 = 0\)。

代入模长 \(|\boldsymbol{a}|=2, |\boldsymbol{b}|=3\)：\(2\times 4 + 3\boldsymbol{a}\cdot\boldsymbol{b} - 2\times 9 = 0 \implies 8 + 3\boldsymbol{a}\cdot\boldsymbol{b} - 18 = 0 \implies 3\boldsymbol{a}\cdot\boldsymbol{b} = 10\)，解得 \(\boldsymbol{a}\cdot\boldsymbol{b} = \dfrac{10}{3}\)。

易错

3. 下列关于空间向量概念与共面性的命题中，正确的是哪一个？

C。逐项辨析核心边界：

C 正确：空间向量是自由向量，平移到同一起点后必在同一平面内，空间中绝对不存在「异面向量」。

A 错误：直线可以异面，但向量可自由平移，不存在异面向量概念。

B 错误：两两不共线不等于不共面！例如正三角形的三边向量两两不共线，但完全共面。

D 错误：四点共面充要条件是系数和等于 1，而 \(\dfrac{1}{2}+\dfrac{1}{3}+\dfrac{1}{4} = \dfrac{13}{12} \ne 1\)，四点不共面。

4. 设 \(\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{c}\) 是空间中三个非零向量，下列运算律中恒成立的是：

C。辨析数量积的关键边界：

C 恒成立：两向量已知非零，\(\boldsymbol{a}\cdot\boldsymbol{b}=0 \iff \cos\theta=0 \iff \theta=90^\circ \iff \boldsymbol{a}\perp\boldsymbol{b}\)。

A 错误：数量积没有消去律！\(\boldsymbol{a}\cdot(\boldsymbol{b}-\boldsymbol{c})=0\) 可能是 \(\boldsymbol{a}\perp(\boldsymbol{b}-\boldsymbol{c})\)，不能推得 \(\boldsymbol{b}=\boldsymbol{c}\)。

B 错误：数量积不满足结合律！左边共线于 \(\boldsymbol{c}\)，右边共线于 \(\boldsymbol{a}\)。

D 错误：夹角可能是 \(180^\circ\)（反向平角），平角不是钝角。

挑战

5. 在棱长为 \(2\) 的正四面体 \(A-BCD\) 中，点 \(E, F\) 分别是棱 \(AB, CD\) 的中点。则对棱中点连线段 \(EF\) 的长度（即向量模长 \(|\overrightarrow{EF}|\)）为：

B。选定基底 \(\overrightarrow{AB}=\boldsymbol{a}, \overrightarrow{AC}=\boldsymbol{b}, \overrightarrow{AD}=\boldsymbol{c}\)，模长均为 2，两两夹角为 \(60^\circ\)，两两数量积为 \(2\times 2\times\cos 60^\circ = 2\)。

\(\overrightarrow{AE} = \dfrac{1}{2}\boldsymbol{a}\)，\(\overrightarrow{AF} = \dfrac{1}{2}(\boldsymbol{b}+\boldsymbol{c})\)，故 \(\overrightarrow{EF} = \overrightarrow{AF} - \overrightarrow{AE} = \dfrac{1}{2}(\boldsymbol{b}+\boldsymbol{c}-\boldsymbol{a})\)。

展开求模平方：

$$|\overrightarrow{EF}|^2 = \frac{1}{4}\left(\boldsymbol{b}^2+\boldsymbol{c}^2+\boldsymbol{a}^2 + 2\boldsymbol{b}\cdot\boldsymbol{c} - 2\boldsymbol{a}\cdot\boldsymbol{b} - 2\boldsymbol{a}\cdot\boldsymbol{c}\right) = \frac{1}{4}(4+4+4 + 4 - 4 - 4) = 2$$

故线段长 \(|\overrightarrow{EF}| = \sqrt{2}\)。
