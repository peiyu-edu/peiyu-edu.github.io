5.1 导数的概念及其意义

汽车的速度表显示的是“这一瞬间”有多快。这一节把“一段时间的平均变化率”一步步缩小到“一瞬间的变化率”，这个数就叫导数；在图上，它是切线的斜率。

本节概念地图先认词 → 再认关系 → 再看做法 → 自己用

核心概念：导数是平均变化率在 \(\Delta x\to0\) 时的极限，也表示曲线在该点的切线斜率。

在初中平面几何中，圆的切线在圆外侧且只碰圆 \(1\) 个点。但到了高中面对一般曲线（如过山车轨道 \(y=x^3\) 或波浪线 \(y=\sin x\)），把切线看作“割线 \(OQ\) 逼近出来的极限直线”时，点下面的按钮看看会发生什么：

如果一条直线与曲线在某处相切，这条直线能不能穿过曲线？它与曲线能不能有多个公共点？

B。初中对圆切线的认识是特殊图形的特例，绝不能推广到一般曲线！

考虑三次曲线 \(y = x^3\)：在原点 \((0, 0)\) 处，曲线的切线就是 \(x\) 轴（直线 \(y = 0\)），它直接横穿过了曲线！又如正弦曲线 \(y = \sin x\)，在最高点处作水平切线，与曲线有无数个交点。

切线的现代微积分本质是局部割线的极限位置。这一节我们就从平均变化率出发，精确建立导数的定义与几何切线意义。

1. 概念定义｜先认识几个词

要用到：函数和函数值（回看 3.1）；直线的斜率（回看选必一 2.1）和点斜式方程（回看选必一 2.2）。

课本用词：按定义求导时先保持 \(\Delta x\ne0\)，代数约分后再令 \(\Delta x\to0\)；“过点切线”要先判断该点是否在曲线上。

增量 \(\Delta x\)、\(\Delta y\)：自变量从 \(x_0\) 变到 \(x_0+\Delta x\)，变了多少就是 \(\Delta x\)（\(\Delta x\ne0\)，可正可负）；函数值变了多少叫 \(\Delta y = f(x_0+\Delta x)-f(x_0)\)。

例：\(f(x)=x^2\)，从 \(2\) 变到 \(2.5\)：\(\Delta x=0.5, \Delta y=6.25-4=2.25\)；变到 \(1.5\)：\(\Delta x=-0.5, \Delta y=-1.75\)。

割线与斜率：曲线上两点连成的直线叫割线，其斜率就是两点间的平均变化率 \(\dfrac{\Delta y}{\Delta x}\)。

例：抛物线 \(y=x^2\) 上 \((1,1)\) 与 \((3,9)\) 的割线斜率是 \(\dfrac{9-1}{3-1}=4\)。

趋近于（\(\to\)）：“\(\Delta x\to0\)”指 \(\Delta x\) 无限接近 \(0\) 但始终不等于 \(0\)，观察分式逼近的确定极限值。

例：式子 \(4+\Delta x\)，当 \(\Delta x\to0\) 时，无论从正侧还是负侧逼近，值均贴近 \(4\)。

导数核心直觉：割线逼近切线、局部以直代曲与切点辨析
极限跨越 平均变化率 vs 瞬时导数
  • 平均变化率：两点割线斜率 \(\dfrac{\Delta y}{\Delta x}\)，反映宏观区间的平均快慢。
  • 瞬时变化率（导数）：割线极限 \(f'(x_0)=\lim_{\Delta x\to0}\dfrac{\Delta y}{\Delta x}\)，是单点的切线斜率。
  • 运算核心：必须先约去分母中的 \(\Delta x\)，绝不能直接代入 \(\Delta x=0\) 算 \(\frac00\)。
切点辨析 “在点处” vs “过某点”
  • 在点 \(P\) 处：\(P(x_0, y_0)\) 是曲线本身的切点，斜率就是 \(f'(x_0)\)，一条确定。
  • 过点 \(P\)：点 \(P\) 通常不在曲线上！必须先设切点 \((t, f(t))\)，代入方程反解 \(t\)。
  • 解的个数：过曲线上某点的切线可能有多条（不仅是在该点处的切线，还可能相切于他处）。

2. 平均变化率、导数与几何意义主公式

导数是平均变化率在区间无限收缩时的极限，几何上严格对应切线的斜率：

割线斜率（平均变化率）：\(\color{#0284c7}{\dfrac{\Delta y}{\Delta x}} = \dfrac{f(x_0+\Delta x)-f(x_0)}{\Delta x}\)
切线斜率（导数定义）：\(\color{#16a34a}{f'(x_0)} = \lim_{\Delta x\to0}\dfrac{\Delta y}{\Delta x} = \color{#16a34a}{k_{\footnotesize\text{切}}}\)
切线方程（点斜式）：\(y - \color{#0284c7}{f(x_0)} = \color{#16a34a}{f'(x_0)}(x - \color{#0284c7}{x_0})\)

例 1（看一遍怎么写）

小球下落，\(t\) 秒内落下 \(s(t)=5t^2\)（米）。求 \([1,1+\Delta t]\) 上的平均速度，再看 \(t=1\) 这一刻的瞬时速度。

\(\Delta s=5(1+\Delta t)^2-5\times1^2 = 10\Delta t+5(\Delta t)^2\)。

平均速度 \(\dfrac{\Delta s}{\Delta t}=10+5\Delta t\)（米/秒）。

当 \(\Delta t\to0\) 时，\(10+5\Delta t\to10\)，所以 \(t=1\) 时的瞬时速度为 \(10\) 米/秒。

自己试试：\(f(x)=x^2+1\) 在区间 \([1,3]\) 上的平均变化率是？

A。\(f(1)=2\)，\(f(3)=10\)，\(\dfrac{\Delta y}{\Delta x}=\dfrac{10-2}{3-1}=4\)。选 B 是只算了 \(\Delta y=8\)；选 C 是没减 \(f(1)\)；\(2\) 是 \(\Delta x\)。

3. 导数几何意义与三步破题思维链

🧩 典型例题：求曲线的切线方程（辨清「在点处」与「过点」）
👀 信号
审视题目字眼：是「在点 \(P\) 处」还是「过点 \(P\)」；验证点 \(P\) 坐标是否在函数曲线上。
🔧 步骤
1. 定切点：若「在点处」，切点即为 \(P(x_0, y_0)\)；若「过点」，必须设切点为 \((t, f(t))\)；
2. 求导数斜率：计算导数得到切线斜率 \(k = f'(t)\)；
3. 点斜式反解：代入 \(y - f(t) = f'(t)(x - t)\)，代入点 \(P\) 坐标解出 \(t\) 并写出所有切线。
🛡️ 防坑
若点 \(P\) 不在曲线上，切勿直接以 \(f'(x_P)\) 当作切线斜率！过曲线外一点往往有两条甚至多条切线。

例 2（按定义求导）

按定义求 \(f(x)=x^2\) 在 \(x=2\) 处的导数。

① \(\Delta y=(2+\Delta x)^2-2^2 = 4\Delta x+(\Delta x)^2\)。

② \(\dfrac{\Delta y}{\Delta x}=4+\Delta x\)。约去分母中的 \(\Delta x\)。

③ 当 \(\Delta x\to0\) 时，\(4+\Delta x\to4\)。故 \(f'(2)=4\)。

自己试试：用定义求 \(f(x)=x^2-3x\) 在 \(x=1\) 处的导数 \(f'(1)\) 是？

A。\(\Delta y=(1+\Delta x)^2-3(1+\Delta x)-(1-3)=-\Delta x+(\Delta x)^2\)，\(\dfrac{\Delta y}{\Delta x}=-1+\Delta x\to-1\)。

选 B 是漏了 \(-3\Delta x\)；选 C 是把函数值 \(f(1)=-2\) 当导数；选 D 是直接代 \(\Delta x=0\) 看到 \(\frac00\)。

4. 几何意义：切线的斜率与方程

在图上，割线 \(PQ\) 的极限位置是曲线在 \(P\) 处的切线。切线斜率 \(k=f'(x_0)\)，方程为 \(y-f(x_0)=f'(x_0)(x-x_0)\)。在切点附近一小段，曲线几乎和切线重合，这就是“以直代曲”。

例 3（求切线方程）

求曲线 \(y=x^2\) 在点 \(P(2,4)\) 处的切线方程。

\(P\) 在曲线上，是切点，切线斜率 \(k=f'(2)=4\)。点斜式：\(y-4=4(x-2)\)，即 \(y=4x-4\)。

自己试试：曲线 \(y=f(x)\) 在点 \(P(1,2)\) 处的切线平行于直线 \(y=3x-1\)，则 \(f'(1)\) 是？

C。平行直线斜率相等，切线斜率 \(k=3\)，故 \(f'(1)=3\)。选 B 是把纵坐标当导数；选 A 拿了横坐标；\(-1\) 是截距。

5. 三大翻车现场红绿对比卡

⚠️ 误区一：混淆「在点处」与「过点」
❌ 错误：求过原点与 \(y=x^2+1\) 的切线，直接令 \(k=f'(0)=0\)
✅ 正确：原点不在曲线上！必须设切点 \((t, t^2+1)\)，解得 \(t=\pm1\)，切线有 \(y=\pm2x\) 两条！
⚠️ 误区二：代入 0 误判零除无意义
❌ 错误：直接把 \(\Delta x=0\) 代入分母看到 \(\frac00\) 判不可导
✅ 正确：\(\Delta x \ne 0\)！必须先代数约分化简出 \(4+\Delta x\)，再令其趋于 \(0\) 获得导数 \(4\)。
⚠️ 误区三：切线等同于唯一公共点
❌ 错误：认为切线绝不可穿过曲线，或只有一个交点必是切线
✅ 正确：切线是割线极限位置！\(y=x^3\) 在原点切线为 \(y=0\)（穿过曲线）；竖直线 \(x=1\) 与抛物线相交一次但非切线。
🔍 反例微图解：过曲线外一点双切线 vs 拐点切线穿透
左图：过原点向 \(y=x^2+1\) 引切线，对称产生两条切线 \(y=\pm2x\)；右图：\(y=x^3\) 在原点的切线 \(y=0\) 直接穿越拐点。
平均变化率是割线斜率，瞬时变化率是它在 \(\Delta x\to0\) 时趋于的数，也就是导数，几何上是切线斜率。
再深一点（可以先跳过）

不可导的典型反例：\(f(x)=|x|\) 在 \(x=0\) 处的左侧变化率为 \(-1\)，右侧变化率为 \(1\)，左右极限不相等，故不可导（几何上为尖点）。

以直代曲的现代意义：在微小邻域内将复杂非线性曲线近似为直线切线，是微积分进行数值计算、物理建模和优化算法的根本基石。

直接用

1. 已知函数 \(f(x)\) 在 \(x = 1\) 处的导数 \(f'(1) = -2\)，且 \(f(1) = 3\)，则曲线 \(y = f(x)\) 在点 \((1, 3)\) 处的切线方程为：

2. 一质点沿直线运动，其位移 \(s\)（单位：\(\text{m}\)）与时间 \(t\)（单位：\(\text{s}\)）满足 \(s(t) = 3t^2 + 2\)。则在 \(t = 2\text{ s}\) 时该质点的瞬时速度为：

B。瞬时速度就是位移函数对时间的导数：\(\Delta s = 3(2+\Delta t)^2 + 2 - (3\times 2^2 + 2) = 12\Delta t + 3(\Delta t)^2\)。平均速度 \(\dfrac{\Delta s}{\Delta t} = 12 + 3\Delta t\)。当 \(\Delta t \to 0\) 时，瞬时速度 \(v(2) = s'(2) = 12\text{ m/s}\)。

易错

3. 直线 \(l\) 过原点 \((0, 0)\) 且与曲线 \(y = x^2 + 1\) 相切，则满足条件的切线 \(l\) 共有几条？

D。注意原点 \((0, 0)\) 不在抛物线 \(y = x^2 + 1\) 上，这是一道典型的「过点切线」问题！

设切点为 \((t, t^2+1)\)，切线斜率 \(k = y'|_{x=t} = 2t\)。

切线方程为 \(y - (t^2+1) = 2t(x - t)\)。代入原点 \((0, 0)\)：

\(0 - (t^2+1) = 2t(0 - t) \implies -t^2 - 1 = -2t^2 \implies t^2 = 1 \implies t = \pm 1\)。

存在两个不同的切点 \((1, 2)\) 和 \((-1, 2)\)，对应两条切线 \(y = 2x\) 与 \(y = -2x\)。共有 2 条！

4. 关于函数 \(y = f(x)\) 在 \(x = x_0\) 处的导数与切线，下列说法中正确的是：

A。A 选项准确表达了导数切线的几何本质；B 选项错误，例如直线 \(x = 1\) 与抛物线 \(y = x^2\) 只有一个公共点，但它与对称轴平行，不是切线；C 选项导数可以是任意实数；D 选项切线可以穿过曲线（如拐点处的切线）。

挑战进阶

5. 若曲线 \(y = x^2\) 与直线 \(y = 2x + b\) 相切，则实数 \(b\) 的值为：

B。切线斜率 \(k = 2\)。由 \(y' = 2x = 2 \implies x = 1\)。代入曲线得切点为 \((1, 1)\)。将切点代入切线方程：\(1 = 2 \times 1 + b \implies b = -1\)。
