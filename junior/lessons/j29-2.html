29.2 圆的有关性质

轴对称遇上旋转对称，圆中角与弦的几何交响！从赵州桥跨度与拱高的千古之谜切入，掌握圆的轴对称性与垂径定理（构造直角三角形求半径与弦长），吃透圆心角-弧-弦定理与圆周角定理（同弧所对圆周角等于圆心角一半、直径所对圆周角是直角），通晓圆内接四边形对角互补。

河北赵县的赵州桥建于隋代（公元 595–605 年），距今已有 1400 多年历史，是世界上现存最早、保存最完好的石拱桥。赵州桥的主桥拱呈圆弧形，桥拱的跨度（弦长 \(AB\)）约为 \(37.4\text{ m}\)，拱高（弧的中点到弦的距离 \(CD\)）约为 \(7.2\text{ m}\)。如何计算赵州桥主拱所在圆的半径？

连接半径 \(OA\)，垂直于弦 \(AB\) 的半径 \(OC\) 经过弧的中点 \(C\)，与弦交于点 \(D\)。在 \(\text{Rt}\triangle OAD\) 中，设半径为 \(R\)，则弦心距 \(OD = R - 7.2\)，半弦长 \(AD = 18.7\)。根据勾股定理可列出方程（ ）

B。连接 \(OA\)，在 \(\text{Rt}\triangle OAD\) 中，斜边是半径 \(OA = R\)。

一直角边是半弦长 \(AD = \frac{37.4}{2} = 18.7\text{ m}\)，另一直角边是弦心距 \(OD = OC - CD = R - 7.2\)。由勾股定理列出方程：\(R^2 = (R - 7.2)^2 + 18.7^2\)，展开解得 \(R \approx 27.9\text{ m}\)。把弯曲的圆弧计算转化为直角三角形代数求解，这就是著名的垂径定理。

1. 先认识几个词：垂径定理与圆的对称性

弦

连接圆上两点的线段叫弦。

直径

经过圆心的弦是直径；每条直径都是弦。

抓住关系： \(\color{#2F7A56}{\underbrace{\angle ACB}_{\text{圆周角}}}=\frac12\color{#966524}{\underbrace{\angle AOB}_{\text{同弧圆心角}}}\)

先检查条件，再使用关系；彩色标注帮助区分量。

前置知识：轴对称图形（回看 15.1）、勾股定理（回看 20.1）。圆是轴对称图形，任意一条直径所在的直线都是圆的对称轴：

  • 垂径定理：垂直于弦的直径平分弦，并且平分弦所对的两条弧。
  • 几何语言：若 \(CD\) 是 \(\odot O\) 的直径，\(CD \perp AB\) 于点 \(E\)，则： \(AE = BE\)，\(\widehat{AC} = \widehat{BC}\)，\(\widehat{AD} = \widehat{BD}\)。
  • 垂径定理推论：平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧。
  • 核心勾股直角三角形：在弦长为 \(a\)、半径为 \(r\)、弦心距（圆心到弦的垂线段长）为 \(d\) 的直角三角形中： \[r^2 = d^2 + \left(\frac{a}{2}\right)^2\] 这个“半径、半弦长、弦心距”直角三角形是解决圆中一切线段计算的核心模型。

直觉微图解 ①垂径定理勾股模型：垂直于弦直径平分弦与两弧

典例 1（波利亚四步法）：垂径定理解决排水管水深问题

【例 1】一条圆形排水管的截面半径 \(r = 10\text{ dm}\)，管内水面宽 \(AB = 16\text{ dm}\)，且水面位于圆心 \(O\) 的下方（即水深小于半径），求截面中水的最大深度 \(CD\)。

  1. ① 读懂题意：排水管截面为 \(\odot O\)，半径 \(OA = OC = 10\text{ dm}\)，水面宽为弦 \(AB = 16\text{ dm}\)，水面在圆心下方，过圆心作 \(OC \perp AB\) 交 \(AB\) 于 \(D\)、交圆底部于 \(C\)，求水深 \(CD\)。
  2. ② 想办法：由垂径定理求出半弦长 \(AD = \frac{1}{2}AB\)，在 \(\text{Rt}\triangle OAD\) 中用勾股定理求出弦心距 \(OD\)，再由 \(CD = OC - OD\) 算出水深。
  3. ③ 执行 + 执行中检查：由 \(OD \perp AB\) 得 \(AD = \frac{1}{2} \times 16 = 8\text{ dm}\)。在 \(\text{Rt}\triangle OAD\) 中，\(OD = \sqrt{OA^2 - AD^2} = \sqrt{10^2 - 8^2} = 6\text{ dm}\)（检查：\(6^2 + 8^2 = 10^2\)）。因水面在圆心 \(O\) 下方，故水深 \(CD = OC - OD = 10 - 6 = 4\text{ dm}\)。
  4. ④ 回头看：若题干未限定水面在圆心下方，则需分类讨论：水面在圆心下方时水深为 \(10 - 6 = 4\text{ dm}\)；水面在圆心上方时水深为 \(10 + 6 = 16\text{ dm}\)。

自己试试 1：已知 \(\odot O\) 的半径为 5，弦 \(AB = 8\)，则圆心 \(O\) 到弦 \(AB\) 的距离（弦心距）为（ ）

A。作 \(OE \perp AB\) 于点 \(E\)。由垂径定理知，\(E\) 是 \(AB\) 的中点，半弦长 \(AE = \frac{8}{2} = 4\)。

连接半径 \(OA = 5\)。在 \(\text{Rt}\triangle OAE\) 中，由勾股定理得弦心距 \(OE = \sqrt{OA^2 - AE^2} = \sqrt{5^2 - 4^2} = 3\)。经典的「3-4-5」勾股数直角三角形！

警惕易错点：为什么垂径定理推论中必须强调“平分弦（不是直径）”？

两条直径必然在圆心相交，且圆心平分每条直径（即任何一条直径都被另一条直径平分）。

但是，两条相交直径并不一定互相垂直！例如两条成 \(60^\circ\) 夹角的直径，它们互相平分，但根本不垂直。因此，只有当平分的弦“不是直径”时，垂直的结论才成立。考试中漏写或混淆这四个字是扣分重灾区！

2. 圆心角、弧、弦的关系定理：知一推二

圆具有旋转不变性，绕圆心旋转任意角度都能与自身完全重合：

  • 圆心角定义：顶点在圆心的角叫作圆心角。
  • 定理：在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦也相等。
  • 推论（知一推二）：在同圆或等圆中，如果两个圆心角、两条弧、两条弦中有一组量相等，那么它们所对应的其余各组量都分别相等。

直觉微图解 ②圆心角-弧-弦联动：同圆中一组量相等则其余俱等

自己试试 2：在 \(\odot O\) 中，已知劣弧 \(\widehat{AB}\) 与劣弧 \(\widehat{CD}\) 相等，则下列说法正确的是（ ）

B。同圆中，相等的弧所对的弦相等，所对的圆心角也相等。弦的位置可以任意分布，不一定平行。

深度辨析：为什么必须加上“同圆或等圆中”的前提？

如果不在同一个圆或等圆中，圆心角即使相等（例如都是 \(60^\circ\)），由于两个圆的半径大小不同，较小圆里所对的弦长和弧长明显短于较大圆里所对的弦长和弧长。必须牢记：圆心角-弧-弦定理只在半径相同的环境下才成立！

3. 圆周角定理与圆内接四边形

当角的顶点从圆心移到圆周上时，产生了中考最为核心的角度定理：

  • 圆周角定义：顶点在圆上，并且两边都与圆相交的角叫作圆周角。
  • 圆周角定理：一条弧所对的圆周角等于它所对的圆心角的一半（即 \(\angle APB = \frac{1}{2}\angle AOB\)）。
  • 推论 1：同弧或等弧所对的圆周角相等。
  • 推论 2（直径对直角）：半圆（或直径）所对的圆周角是直角（\(90^\circ\)）；反之，\(90^\circ\) 的圆周角所对的弦是直径。
  • 圆内接四边形对角互补：四边形四个顶点都在圆上，它的对角互补（\(\angle A + \angle C = 180^\circ\)），任意一个外角等于它的内对角。

直觉微图解 ③圆周角定理与圆内接四边形：同弧圆周角守恒与对角互补

自己试试 3：\(AB\) 是 \(\odot O\) 的直径，点 \(C\) 在 \(\odot O\) 上（不与 \(A, B\) 重合），连接 \(AC, BC\)。若 \(\angle A = 35^\circ\)，则 \(\angle B\) 的度数是（ ）

C。因为 \(AB\) 是直径，根据直径所对的圆周角是直角可知，\(\angle ACB = 90^\circ\)。

在 \(\text{Rt}\triangle ABC\) 中，两锐角互余：\(\angle B = 90^\circ - \angle A = 90^\circ - 35^\circ = 55^\circ\)。解题口诀：「见直径，想直角」！

证明思想：圆周角定理分类讨论法

证明一条弧所对圆周角等于圆心角一半时，采用数学分类讨论法：

  1. 圆心在角一边上：构造等腰三角形，利用外角性质直接证明；
  2. 圆心在角内部：过顶点和圆心作辅助直径，转化为两个第一类角相加；
  3. 圆心在角外部：过顶点和圆心作辅助直径，转化为两个第一类角相减。化繁为简，全部归结为基本模型！
典例 2（波利亚四步法）：圆内接四边形与圆心角综合求角

【例 2】四边形 \(ABCD\) 内接于 \(\odot O\)，连接 \(OB, OD\)。若 \(\angle BOD = 140^\circ\)，且点 \(A\) 在优弧 \(\widehat{BAD}\) 上，求 \(\angle A\) 和 \(\angle BCD\) 的度数。

  1. ① 读懂题意：已知劣弧 \(\widehat{BD}\) 所对的圆心角 \(\angle BOD = 140^\circ\)，点 \(A\) 在优弧上，点 \(C\) 在劣弧上，求圆周角 \(\angle A\) 及内接四边形对角 \(\angle BCD\)。
  2. ② 想办法：先由圆周角定理求出劣弧 \(\widehat{BD}\) 所对的圆周角 \(\angle A = \frac{1}{2}\angle BOD\)；再由圆内接四边形对角互补求出 \(\angle BCD = 180^\circ - \angle A\)。
  3. ③ 执行 + 执行中检查：由圆周角定理得 \(\angle A = \frac{1}{2}\angle BOD = \frac{1}{2} \times 140^\circ = 70^\circ\)。在圆内接四边形 \(ABCD\) 中，\(\angle A + \angle BCD = 180^\circ\)，故 \(\angle BCD = 180^\circ - 70^\circ = 110^\circ\)（检查：优弧所对圆心角为 \(360^\circ - 140^\circ = 220^\circ\)，其一半恰为 \(110^\circ = \angle BCD\)，两种方法完全一致！）。
  4. ④ 回头看：一条弦所对的优弧圆周角与劣弧圆周角恰好构成圆内接四边形的一组对角，因此它们必然互补。

用之前必查：三大翻车现场

翻车 1
错误：平分任何弦的直径都垂直弦
核对：被平分的弦须不是直径：两条斜交直径互相平分却不垂直。
翻车 2
错误：相等圆心角的弧一定相等
核对：需在同圆或等圆中；半径不同的圆同角对应弧长可不同。
翻车 3
错误：圆周角总是任意圆心角的一半
核对：必须对应同一条弧；先看顶点所对的是哪段弧。

练习 1：已知 \(\odot O\) 的直径为 10，弦 \(AB = 8\)，则圆心 \(O\) 到弦 \(AB\) 的距离为（ ）

A。直径为 10，所以半径 \(r = 5\)。半弦长为 \(\frac{8}{2} = 4\)。由勾股定理得距离为 \(\sqrt{5^2 - 4^2} = 3\)。

练习 2：在 \(\odot O\) 中，弦 \(AB\) 所对的圆心角为 \(80^\circ\)，则该弦所对的劣弧对应的圆周角为（ ）

C。同弧所对的圆周角等于圆心角的一半，因此圆周角为 \(\frac{80^\circ}{2} = 40^\circ\)。

练习 3：圆内接四边形 \(ABCD\) 中，若 \(\angle A = 70^\circ\)，则相对的内角 \(\angle C\) 的度数是（ ）

B。圆内接四边形对角互补：\(\angle A + \angle C = 180^\circ\)，因此 \(\angle C = 180^\circ - 70^\circ = 110^\circ\)。

练习 4：已知 \(AB\) 是 \(\odot O\) 的直径，点 \(C\) 在圆上，连接 \(AC, BC\)。若 \(AC = 6, BC = 8\)，则直径 \(AB\) 的长为（ ）

D。直径所对的圆周角是直角，\(\triangle ABC\) 是以 \(AB\) 为斜边的直角三角形。由勾股定理得 \(AB = \sqrt{6^2 + 8^2} = 10\)。

练习 5：在 \(\odot O\) 中，弦 \(AB\) 的长为 \(8\text{ cm}\)，圆心 \(O\) 到 \(AB\) 的距离为 \(3\text{ cm}\)，则 \(\odot O\) 的直径为（ ）

提示

先由半弦长 \(4\text{ cm}\) 和弦心距 \(3\text{ cm}\) 用勾股定理求出半径 \(r\)，再乘 \(2\) 得直径。

B。半弦长为 \(\frac{8}{2} = 4\text{ cm}\)，弦心距 \(d = 3\text{ cm}\)，由勾股定理得半径 \(r = \sqrt{3^2 + 4^2} = 5\text{ cm}\)。注意题目问的是「直径」，故直径为 \(2r = 10\text{ cm}\)。

易错提醒：一条弦对应两种圆周角

题目若表述为“一条弦所对的圆周角”，需注意弦将圆周分为优弧与劣弧两部分，所对的圆周角有两种（它们互补）！但若明确指出“同弧所对的圆周角”，则角度唯一确定等于圆心角的一半。

巩固练习 1：已知 \(\odot O\) 的半径为 \(5\text{ cm}\)，弦 \(AB = 6\text{ cm}\)，则圆心 \(O\) 到弦 \(AB\) 的距离是（　）

B。过圆心 \(O\) 作 \(OD \perp AB\) 于点 \(D\)，连接 \(OA\)．由垂径定理得 \(AD = \frac{1}{2}AB\)，即 \(AD = \frac{1}{2} \times 6 = 3\text{ cm}\)．在 \(\text{Rt}\triangle OAD\) 中，\(OA = 5\text{ cm}\)，由勾股定理得 \(OD = \sqrt{OA^2 - AD^2}\)，即 \(OD = \sqrt{5^2 - 3^2} = 4\text{ cm}\)，即圆心 \(O\) 到弦 \(AB\) 的距离为 \(4\text{ cm}\)，故选 B．

巩固练习 2：\(AB\) 是 \(\odot O\) 的直径，点 \(C, D\) 在 \(\odot O\) 上，且在直径 \(AB\) 的两侧，连接 \(BC, BD, CD\)．若 \(\angle ABD = 50^\circ\)，则 \(\angle BCD\) 的度数为（　）

B。连接 \(AD\)．因为 \(AB\) 是 \(\odot O\) 的直径，由圆周角定理推论（直径所对的圆周角是直角）可知 \(\angle ADB = 90^\circ\)．在 \(\text{Rt}\triangle ABD\) 中，\(\angle ABD = 50^\circ\)，故 \(\angle BAD = 90^\circ - 50^\circ = 40^\circ\)．又因为同弧 \(\widehat{BD}\) 所对的圆周角相等，所以 \(\angle BCD = \angle BAD = 40^\circ\)，故选 B．

巩固练习 3：下列关于圆的性质的命题中，是真命题的是（　）

C。逐项分析：A 项，缺少“在同圆或等圆中”的前提条件，半径不同的圆中相等圆心角所对的弧不相等，故 A 是假命题；B 项，被平分的弦如果是另一条直径，两条直径互相平分但不一定垂直，故 B 是假命题；C 项，严格给出了“平分弦（不是直径）”的前提，是垂径定理的正确推论，故 C 是真命题；D 项，圆内接四边形是“对角互补”，邻角不一定互补，故 D 是假命题．故选 C．

巩固练习 4：四边形 \(ABCD\) 内接于 \(\odot O\)，\(AB\) 是 \(\odot O\) 的直径，连接 \(BD\)．若 \(\angle C = 114^\circ\)，则 \(\angle ABD\) 的度数是______\(^\circ\)．

查看答案与解析，自行核对

答案：\(24\)

因为四边形 \(ABCD\) 是 \(\odot O\) 的内接四边形，由圆内接四边形对角互补得 \(\angle A + \angle C = 180^\circ\)．已知 \(\angle C = 114^\circ\)，故 \(\angle A = 180^\circ - 114^\circ = 66^\circ\)．又因为 \(AB\) 是 \(\odot O\) 的直径，所以 \(\angle ADB = 90^\circ\)．在 \(\text{Rt}\triangle ABD\) 中，\(\angle ABD = 90^\circ - \angle A\)，即 \(90^\circ - 66^\circ = 24^\circ\)．
