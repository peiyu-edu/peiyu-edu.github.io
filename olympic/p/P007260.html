F2填空题椭圆

在平面直角坐标系 xOy 中，椭圆 C 的方程为 9x2​+10y2​=1，F 为 C 的上焦点，A 为 C 的右顶点，P 是 C 上位于第一象限内的动点，则四边形 OAPF 的面积最大值为。

作答

分数写 a/b，根号写 √ 或 sqrt，π 写 pi 也可以。

标准答案：311​/2

解析

思路

把四边形分为两个以坐标轴上的线段为底的三角形，面积便是动点坐标的线性式；椭圆参数化后可用柯西不等式求最大值。

5x2+6y2+6z2−8yz≤1,

解答

由椭圆方程得 A=(3,0)，F=(0,1)。设

P=(3cost,10​sint),0<t<2π​.

连接 OP，则

SOAPF​=SOAP​+SOPF​=23​(10​sint+cost)≤23​(10+1)(sin2t+cos2t)​=2311​​.

当 sint=10/11​、cost=1/11​ 时等号成立，且 t 位于要求的开区间。因此最大值为 311​/2​。

复核

取等点 P=(3/11​,10/11​) 的两坐标均正，代入椭圆方程左边为 1/11+10/11=1。

方法总结

椭圆上的线性目标可先缩放为单位圆上的内积；开象限限制要求单独核对取等点的位置。

为什么评为 F2（会透露解法方向）

面积分解后得到坐标线性式，标准椭圆参数化与柯西直接给界并核象限。
