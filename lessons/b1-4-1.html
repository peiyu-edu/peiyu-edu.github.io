4.1 指数

「开 \(n\) 次方」是乘方倒过来。从它出发，指数从整数推广到分数、再到任意实数——每推广一步，都要看清底数允许取什么。先从一个翻倍的例子开始。

一种细菌，每过 \(1\) 小时，数量变成原来的 \(2\) 倍。那每过半小时呢，变成原来的几倍？先点下面的按钮，拿不同的倍率 \(x\) 连乘两次（两个半小时 \(=1\) 小时）试试看：

半小时变成原来的几倍？

试一试：\(1.5\times1.5=2.25\)，多了；\(1.41\times1.41\approx1.99\)，差不多正好；\(1\times1=1\)、\(2\times2=4\) 都不对。B。

要找的数满足 \(x^2=2\)，就是 \(\sqrt2\approx1.414\)。

\(1\) 小时乘 \(2^1\)，\(2\) 小时乘 \(2^2\)，那半小时自然想写成 \(2^{\frac12}\)。这一节就讲：\(2^{\frac12}\)、\(8^{\frac23}\) 甚至 \(2^{\sqrt2}\) 是什么意思，又该怎么算。

1. 先认识几个词：从「开方运算」到「分数指数」的认知跃迁

要用到：初中的整数指数幂、平方根、立方根和绝对值；3.3 的幂函数图象（回看 3.3）。先看下面这幅微图解：

直觉微图解 ①分数指数幂与根式的精准映射流水线

根次与奇偶奇次方根（来去自由）vs 偶次方根（双根与绝对值）

奇次方程 \(x^n=a\) 对任意实数 \(a\) 有且仅有一个实根，正负原样保留；偶次方程正数有相反数两根，根式 \(\sqrt[n]{a}\) 专指非负根，且 \(\sqrt[n]{a^n}=|a|\) 必须戴绝对值！

符号陷阱指数负号（取倒数指令）vs 数值负号（正负性质）

指数上的负号是「降到分母取倒数」的动作指令，比如 \(2^{-3}=\dfrac{1}{2^3}=\dfrac{1}{8}>0\)！绝不是把整个数变成负数（千万别写成 \(-8\) 或 \(-\dfrac{1}{8}\)）！

2. 核心数学运算法则与根式幂化总览表

\(\color{#2F7A56}{\underbrace{a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m}_{\text{分母 } n \text{ 开方，分子 } m \text{ 乘方（先开方数更小）}}}\) \(\color{#966524}{\underbrace{\sqrt[n]{a^n} = \begin{cases} a, & n\text{ 为奇数} \\ |a|, & n\text{ 为偶数} \end{cases}}_{\text{抵消律：偶次开方自带绝对值护甲}}}\) \(\color{#3E5C76}{\underbrace{a^{-\frac{m}{n}} = \dfrac{1}{a^{\frac{m}{n}}}}_{\text{负指数：纯取倒数，底数必须 } a>0}}\)

例 1（辨清次方根与根式记号）

（1）\(3^4=81\)，\((-3)^4=81\)，所以 \(81\) 的 \(4\) 次方根是 \(\pm3\)，而根式 \(\sqrt[4]{81}=3\) 只指正根。

（2）奇次根符号原样保留：\((-3)^3=-27 \implies \sqrt[3]{-27}=-3\)；\(2^5=32 \implies \sqrt[5]{32}=2\)。

（3）\(-16\) 的偶次方根：实数范围内没有，实数偶次方必然非负，\(\sqrt[4]{-16}\) 无意义。

自己试试：「\(16\) 的 \(4\) 次方根」和「\(\sqrt[4]{16}\)」分别是什么？

C。\(2^4=16\)，\((-2)^4=16\)，所以 \(16\) 的 \(4\) 次方根有两个：\(\pm2\)。

根式 \(\sqrt[4]{16}\) 是一个确定的数，只取非负的那个，等于 \(2\)。偶次方根「有两个」，偶次根式「只取一个」。

例 2（先乘方再开方：绝对值护甲）

（1）\(\sqrt[3]{(-5)^3}=-5\)：奇次开方，原样拿出来。

（2）\(\sqrt{(3-\pi)^2}=|3-\pi|=\pi-3\)：偶次开方，先套绝对值，由 \(3-\pi<0\) 脱绝对值变号！

（3）\(x<1\) 时，\(\sqrt{(x-1)^2}=|x-1|=1-x\)。

自己试试：\(\sqrt[4]{(-3)^4}+\sqrt[3]{(-3)^3}=\)？

B。\(\sqrt[4]{(-3)^4}=\sqrt[4]{81}=3\)（偶次，是 \(|-3|\)），\(\sqrt[3]{(-3)^3}=-3\)（奇次），和是 \(0\)。选 A 的同学把两个都当成「直接抵消」得 \(-3\)；\((-3)^4=81\) 是正数，开 \(4\) 次方完全有意义。

3. 三步破题思维链：化根为幂与指数化简

例 3（示范：根式化简与指数混合运算三步法）

化简并求值：\(\left(2\dfrac{1}{4}\right)^{\frac{1}{2}} - (-9.6)^0 - \left(\dfrac{8}{27}\right)^{-\frac{2}{3}} + \left(\sqrt[3]{-2}\right)^3\)。

👀 第一步化假分数、化负指数为倒数： 带分数化假分数：\(2\dfrac{1}{4}=\dfrac{9}{4}\)；任何非零实数的零次方 \((-9.6)^0=1\)；
负指数翻转底数：\(\left(\dfrac{8}{27}\right)^{-\frac{2}{3}} = \left(\dfrac{27}{8}\right)^{\frac{2}{3}}\)；奇次根方幂直接抵消：\((\sqrt[3]{-2})^3=-2\)。
🔧 第二步底数分解质因数化分数指数： \(\left(\dfrac{9}{4}\right)^{\frac{1}{2}} = \left(\left(\dfrac{3}{2}\right)^2\right)^{\frac{1}{2}} = \dfrac{3}{2}\)；
\(\left(\dfrac{27}{8}\right)^{\frac{2}{3}} = \left(\left(\dfrac{3}{2}\right)^3\right)^{\frac{2}{3}} = \left(\dfrac{3}{2}\right)^2 = \dfrac{9}{4}\)。
🛡️ 第三步合并分数并复核符号： 原式 \(= \dfrac{3}{2} - 1 - \dfrac{9}{4} + (-2) = \dfrac{6}{4} - \dfrac{4}{4} - \dfrac{9}{4} - \dfrac{8}{4} = -\dfrac{15}{4}\)！

自己试试：\(8^{-\frac23}=\)？

B。\(8^{\frac23}=\left(\sqrt[3]8\right)^2=4\)，再取倒数得 \(\dfrac14\)。选 A 的同学把负指数当成了前面加负号；选 C 的是忘了负号。

例 4（实数指数幂运算性质，\(a>0, b>0\)）

（1）\(\sqrt a\cdot\sqrt[3]{a^2}=a^{\frac12}\cdot a^{\frac23}=a^{\frac12+\frac23}=a^{\frac76}\)。

（2）\(\left(a^{\frac12}b^{\frac13}\right)^6=a^{\frac12\times6}\,b^{\frac13\times6}=a^3b^2\)。

（3）\(4^{\frac32}\times8^{-\frac13}=\left(2^2\right)^{\frac32}\times\left(2^3\right)^{-\frac13}=2^3\times2^{-1}=4\)：换成同一个底数 \(2\) 再算。

自己试试：\(a>0\)，\(a^{\frac13}\cdot a^{\frac12}\div a^{\frac16}=\)？

B。同底相乘指数相加，相除指数相减：\(\dfrac13+\dfrac12-\dfrac16=\dfrac23\)。选 A 的同学把「乘」做成了指数相乘、「除」做成了指数相除：\(\dfrac13\times\dfrac12\div\dfrac16=1\)。

例 5（无理数指数幂：有理数夹逼）

由 \(1.4<\sqrt2<1.5\)，得 \(2^{1.4}<2^{\sqrt2}<2^{1.5}\)。其中 \(2^{1.5}=2^{\frac32}=2\sqrt2\approx2.83\)，\(2^{1.4}=2^{\frac75}\approx2.64\)。所以 \(2^{\sqrt2}\) 在 \(2.64\) 和 \(2.83\) 之间。小数位越精确，两头夹逼越贴近！

自己试试：已知 \(1<\sqrt3<2\)，\(3^{\sqrt3}\) 在哪两个数之间？

B。底数 \(3>1\)，\(3^1<3^{\sqrt3}<3^2\)，即在 \(3\) 和 \(9\) 之间（其实约 \(6.7\)）。选 A 的同学拿 \(\sqrt3\) 本身（约 \(1.73\)）去比了，忘了它是指数。

4. 用之前必查：三大高频翻车现场

翻车现场 ①偶次根式直接开方脱壳，忽视绝对值护甲
❌ 典型错解：看到 \(\sqrt{(x-1)^2}\) 直接化简写成 \(x-1\)。
✅ 看右图秒懂真相：若 \(x<1\)，\(x-1\) 实为负数！根式开出来绝不能为负！正确化简必须先挂绝对值：\(\sqrt{(x-1)^2}=|x-1|=1-x\)！
翻车现场 ②给负底数套用分数指数幂，导致多值逻辑灾难
❌ 典型错解：写出 \((-8)^{\frac{1}{3}} = (-8)^{\frac{2}{6}} = \sqrt[6]{(-8)^2} = 2\)。
✅ 一眼看清真相：同一个数换个约分居然从 \(-2\) 变 \(+2\)！这就是为什么数学上严禁对负数定义分数指数幂！遇到负数开奇次根，必须严格用根式 \(\sqrt[3]{-8}\) 书写！
翻车现场 ③把指数上的负号看成整个数值的负号
❌ 典型错解：算 \(4^{-\frac{1}{2}}\) 随手写出 \(-2\) 或 \(-\dfrac{1}{2}\)。
✅ 一眼看清真相：指数上的负号是「降到分母取倒数」，绝对不能把负号提到前面来！\(4^{-\frac{1}{2}} = \dfrac{1}{4^{\frac{1}{2}}} = \dfrac{1}{2} > 0\)！
再深一点（可以先跳过）

负底数的整数次幂没问题：\((-2)^3=-8\)，\((-2)^{-2}=\dfrac14\)，\((-2)^2\cdot(-2)^3=(-2)^5=-32\)。整数指数的法则对不为 \(0\) 的底数都成立，有问题的只是分数指数。

为什么同一个分数换写法，正底数不会出两个值：\(a>0\) 时 \(\sqrt[6]{a^2}\) 和 \(\sqrt[3]{a}\) 都是正数，六次方都等于 \(a^2\)，而正数的六次方根只有一个正的，所以相等。负底数时 \(\sqrt[3]{-8}\) 是负的，\(\sqrt[6]{64}\) 是正的，这条论证就断了。

无理数指数：逼近 \(\sqrt2\) 的分数越精确，\(2\) 的这些次幂就越接近同一个数——这件事需要大学里的「极限」才能严格说清，高中只要求会用。「动手」②可以一位一位看它被夹出来。

① 看见 n 次方根

绿色曲线是 \(y=x^n\)，金色水平线是 \(y=a\)。交点的横坐标就是方程 \(x^n=a\) 的解，也就是 \(a\) 的 \(n\) 次方根。上下拖动右边的圆点改 \(a\)（或 Tab 选中后按方向键），点按钮换 \(n\)。试试：\(n\) 取偶数时把 \(a\) 拖到负数，交点去哪了？\(n\) 取奇数时呢？

② 进阶：把 \(2^{\sqrt2}\) 夹出来

拖动滑块（或选中后按方向键），多取一位 \(\sqrt2\) 的小数。每一行是一对分数指数 \(r_1<\sqrt2<r_2\)，条形从 \(2^{r_1}\) 画到 \(2^{r_2}\)，红色虚线是 \(2^{\sqrt2}\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(27^{\frac23}+16^{-\frac12}=\)？

C。\(27^{\frac23}=\left(\sqrt[3]{27}\right)^2=9\)，\(16^{-\frac12}=\dfrac1{\sqrt{16}}=\dfrac14\)，和是 \(\dfrac{37}{4}\)。选 A 的同学把 \(16^{-\frac12}\) 算成了 \(-4\)；选 B 的把 \(27^{\frac23}\) 算成了 \(27\times\dfrac23=18\)。

2. \(a>0\)，化简 \(\dfrac{a^2}{\sqrt a\cdot\sqrt[3]{a^2}}\)。

B。分母 \(=a^{\frac12}\cdot a^{\frac23}=a^{\frac76}\)，所以原式 \(=a^{2-\frac76}=a^{\frac56}\)。选 A 的同学把分母算成了 \(a^{\frac12\times\frac23}=a^{\frac13}\)；选 C 的把除法做成了加。

易错

3. \(x\) 是任意实数，\(\sqrt{x^2}\) 化简后等于什么？

C。对应「偶次根式取非负」这一条。觉得「先平方再开方，抵消了」会选 A，拿 \(x=-3\) 试：\(\sqrt{(-3)^2}=\sqrt9=3\)，不是 \(-3\)。

选 B 是把「\(9\) 的平方根是 \(\pm3\)」和「\(\sqrt9\)」混了：\(\sqrt{x^2}\) 一定 \(\ge0\)，\(x\ge0\) 时是 \(x\)，\(x<0\) 时是 \(-x\)，合起来就是 \(|x|\)。

4. 小明这样算：\((-8)^{\frac13}=(-8)^{\frac26}=\sqrt[6]{(-8)^2}=\sqrt[6]{64}=2\)。问题出在哪？

B。对应「负底数不写成分数指数幂」这一条。\(\frac13=\frac26\) 没错，错在把正底数下才成立的规则用到了 \(-8\) 上。

\(-8\) 的立方根回到根式去算：\(\sqrt[3]{-8}=-2\)。C 也不对：\(\sqrt[6]{64}\) 是偶次根式，只取 \(2\)。

5. \(0^{\frac23}\) 和 \(0^{-\frac23}\) 各是多少？

D。对应「底数是 \(0\)」这一条。\(0^{\frac23}=\sqrt[3]{0^2}=0\)，正分数指数幂没问题。

\(0^{-\frac23}=\dfrac{1}{0^{\frac23}}=\dfrac10\)，分母为 \(0\)，没有意义。选 C 的同学可能想到了 \(a^0=1\)，但这里指数是 \(-\frac23\)，不是 \(0\)。

挑战

6. 已知 \(a^{\frac12}+a^{-\frac12}=3\)，求 \(a+a^{-1}\)。

A。不用解出 \(a\)，两边平方：\(\left(a^{\frac12}+a^{-\frac12}\right)^2=a+2\,a^{\frac12}a^{-\frac12}+a^{-1}=a+2+a^{-1}=9\)，所以 \(a+a^{-1}=7\)。

中间项 \(a^{\frac12}\cdot a^{-\frac12}=a^0=1\)。选 B 的同学平方时漏了中间的 \(2\)。（题里出现 \(a^{\frac12}\)，已经默认 \(a>0\)。）
