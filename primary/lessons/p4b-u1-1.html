加、减法的意义和各部分间的关系

加法是把两部分合起来，减法是去掉一部分。合起来的和与去掉的部分之间，藏着怎么用一个算式检验另一个算式的办法。

旧版目录，待新版核对

班级有 125 张贴纸，做手抄报用了一些，还剩 40 张。用掉了多少张？想一想，用哪个算式？

对，125 − 40 = 85（张）。全部贴纸分成两段：用掉的和剩下的，从整体里去掉剩下的 40，就是用掉的 85。

这一课就来弄清：加法和减法的几个数，怎样互相“找回”。

1. 一条长条，两段

下面是一条图书角的书：一共 180 本，分成左右两段。拖动滑块改变左段的本数，再试试“盖住”一段，看看被盖住的数怎样算出来。

左段少左段多

加法：两段合起来，和 = 加数 + 加数。

求一个加数：盖住一段，用整条去掉露着的一段，加数 = 和 − 另一个加数。

自己试试

红、蓝两条彩带接在一起共 96 米，红彩带 58 米，蓝彩带有多少米？

96 − 58 = 38（米）。检验：58 + 38 = 96。

2. 换成减法看

还是那条长条，这次把整条叫被减数，去掉的一段叫减数，剩下的叫差。

差 = 被减数 − 减数。被减数是整条，减数和差是它的两段。

所以被减数 = 差 + 减数（两段合起来），减数 = 被减数 − 差（整条去掉露着的一段）。

例：83 − 29 = 54。检验时，把两段 54 和 29 合起来：54 + 29 = 83，回到了整条。

自己试试

一本 210 页的故事书，小林读了一些，还剩 138 页没读。小林已经读了多少页？

210 − 138 = 72（页）。检验：72 + 138 = 210。

加法和减法互相检验：
和 − 一个加数 = 另一个加数；
差 + 减数 = 被减数，被减数 − 差 = 减数。

两个容易错的地方

✗ 检验减法时，加错了数

95 − 38 = 57，用 57 + 95 来检验。

✓ 把减出来的两段合起来

95 是整条，57 和 38 是它的两段，检验用 57 + 38 = 95。

✗ 求减数时也用加法

80 页书，看了一些，还剩 35 页，列 80 + 35。

✓ 看了的页数 = 整体 − 剩下的

80 页是整体，看了的和剩下的是它的两段，看了 80 − 35 = 45 页。

直接用

1. 小明算出 83 − 29 = 54。下面哪个算式能检验这个结果？

A。54 + 29 = 83，正好回到被减数。

2. 礼堂共有 340 个座位，已经坐了 265 人。还有多少个空位？

340 − 265 = 75（个）。检验：265 + 75 = 340。

3. □ + 128 = 305，□ 里应该填多少？

305 − 128 = 177。检验：177 + 128 = 305。

容易错

4. 小店有 90 袋糖，卖出一些后还剩 35 袋。卖出了多少袋？

90 − 35 = 55（袋）。检验：55 + 35 = 90。

5. 200 − 56 − 34 = 110。倒回去检验：110 + 34 = 144，144 再加上 □，才能回到 200。□ 是多少？

144 + 56 = 200。多步减法要一步一步倒回去，每一步都加回去，直到回到最开始的数。

想一想

6. □ − 47 = 38，□ 是被减数，要求 □。下面哪个算式对？

A。被减数 = 差 + 减数 = 38 + 47 = 85。检验：85 − 47 = 38。

7. 两个数的和是 142，其中一个加数比 60 多 7，另一个加数是多少？

先得到已知加数 60 + 7 = 67，再 142 − 67 = 75。检验：67 + 75 = 142。
