乘数中间或末尾有 0

中间的 0 要不要乘？末尾的 0 怎么办？

体育馆每个区有 307 个座位，4 个区一共多少个座位？笔算 307 × 4，十位上写几？

个位 7 × 4 = 28，写 8 进 2；十位 0 × 4 = 0，加上进上来的 2，是 2。

中间的 0 也要乘。积的十位不一定是 0。

1. 中间有 0，也要乘

先估：307 看成 300，300 × 4 = 1200，积应该比 1200 多一些。再一步一步算。

十位：先乘，0 × 4 = 0；再加上小 2，是 2。先乘再加，碰到 0 也一样。

2. 中间有 0，没有进位

802 × 4：个位 2 × 4 = 8，不进位。十位 0 × 4 = 0，写 0 占位，不能空着。

自己试试

笔算。碰到中间的 0，先乘，再看有没有进上来的数。

3. 末尾有 0：先不看 0，乘完落下来

230 × 4：230 是 23 个十。先不看末尾的 0，算 23 × 4 = 92，是 92 个十，再把 0 落下来，就是 920。

这样写时，一位数 4 写在 3 的下面，末尾的 0 用竖虚线隔在右边。点按钮换成「一位数写在个位下面」，0 也乘一遍，积一样。两种写法都对，先不看 0 的写法少乘一次，更简便。

自己试试

350 × 4 = ？

350 是 35 个十。35 × 4 = 140，是 140 个十，就是 1400。积的末尾有 2 个 0：140 里有一个，再落下来一个。

自己试试

用简便的写法笔算，最后别忘了把 0 落下来。

4. 中间的 0 和末尾的 0

只有末尾的 0 能先放一边。中间的 0 前后都有数，不能不看，要乘。

乘数中间有 0，0 也要乘：0 乘几得 0，再加上进上来的数。末尾有 0，可以先不看末尾的 0，乘完把 0 落下来。

算完检查：中间的 0 乘了吗？进上来的数加了吗？末尾的 0 落下来了吗？

两个容易错的地方

✗ 307 × 4 = 1208十位写了 0，忘了加进上来的 2。
✓ 307 × 4 = 1228十位：0 × 4 = 0，再加 2，写 2。
✗ 230 × 4 = 92末尾的 0 没有落下来。
✓ 230 × 4 = 92092 个十，就是 920。

直接用

笔算。末尾有 0 的题，一位数写在 0 前面那一位下面。

405 × 2 = ？

个位 5 × 2 = 10，写 0 进 1；十位 0 × 2 = 0，加 1 是 1；百位 4 × 2 = 8。积是 810。

一本故事书 203 页，3 本一共多少页？

203 × 3：个位 9，十位 0 × 3 = 0 写 0，百位 6。积是 609（页）。

容易错

120 × 4 = ？

120 是 12 个十，12 × 4 = 48，是 48 个十，就是 480。

一件外套 250 元，买 3 件一共多少元？

250 × 3：25 × 3 = 75，是 75 个十，就是 750（元）。

想一想

250 × 4 的积，末尾有几个 0？

25 × 4 = 100，是 100 个十，就是 1000，末尾有 3 个 0。

笔算 507 × 6，小明先算 57 × 6，再在积的末尾添一个 0。这样对吗？

只有末尾的 0 能先放一边。507 × 6：个位 42 写 2 进 4；十位 0 × 6 = 0，加 4 是 4；百位 30。积是 3042。
