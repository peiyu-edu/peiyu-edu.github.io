平行与垂直

在同一平面内，两条直线延伸开去，要么相交，要么永远不碰头。

看操场上的双杠，两根笔直的横杠向两头延伸，它们会相交碰在一起吗？

对，永远不会相交！像双杠、黑板的上下对边、铁轨这样，在同一个平面内不相交的两条直线叫作平行线，也可以说这两条直线互相平行。

这一课我们认识同一平面内两条直线的两种基本位置关系：平行与垂直。

1. 同一平面内两条直线的位置关系：相交与平行

纸上画了三组直线。看起来都没碰头，它们真的不相交吗？点下面的按钮切换，再点“延长两端看一看”！

第 ① 组：还没延长，点「延长两端看一看」检验它们会不会碰头。

平行：在同一个平面内不相交的两条直线叫作平行线。直线 a 与 b 互相平行，记作 a ∥ b，读作“a 平行于 b”。

2. 特殊的相交：互相垂直

转动直线 a，观察两条直线相交成的角。当夹角正好是 90° 时会发生什么？

相交成 90° 直角：直线 a 与 b 互相垂直（a ⊥ b），交点 O 叫垂足！

如果两条直线相交成直角，就说这两条直线互相垂直。
其中一条直线叫作另一条直线的垂线，它们的交点叫作垂足。
记作 a ⊥ b，读作“a 垂直于 b”。

自己试试

纸上画了两条直线，纸面上看起来没有碰头，但延长后交叉在了一起。这两条直线是什么位置关系？

A。直线可以向两端无限延伸。只要延长后相交，它们就是相交的位置关系，绝不是平行线！

自己试试

如果直线 a ⊥ b，那么直线 a 与 b 相交所成的四个角都是直角，每个直角的度数是多少度？

互相垂直相交成直角，直角是 90°。

1. 在同一个平面内，两条直线的位置关系只有两种：相交 或 平行。
2. 不相交的两条直线互相平行，记作 a ∥ b。
3. 相交成直角的两条直线互相垂直，记作 a ⊥ b，交点叫垂足。

两个容易错的地方

✗ 看到没碰到就说“这两条线互相平行”

只看纸面上短短的一截没碰头，就误以为是平行线。

✓ 牢记直线可以无限延伸

用尺子延长看一看：如果延长后相交，就属于相交；永远不相交才是平行。

✗ 单独说“直线 a 是垂线”或“直线 b 是平行线”

把垂线、平行线当成了单独一根线的名字。

✓ 垂线和平行线是两根线相互的关系

必须说“a 与 b 互相垂直”“a 是 b 的垂线”，不能孤立说某一条线是垂线。

直接用

1. 下面哪一幅图展示的是两条直线互相垂直？

B。只有相交成直角（90°）的两条直线才叫互相垂直。

2. 两条直线互相垂直，在交点处一共形成了多少个直角？

两条直线相交成直角时，四个角全部是直角，一共 4 个。

3. 在正方形中，相邻的两条边是什么关系？相对的两条边是什么关系？

C。正方形的四个角都是直角，所以相邻边互相垂直（成90°）；两组对边永不相交，所以对边互相平行。

容易错

4. 下面说法中，哪一句是完全正确的？

A。「在同一个平面内」是定义平行线必不可少的前提条件。

5. 一个普通长方形的四条边中，一共有多少组互相平行的对边？

长与长一组平行，宽与宽一组平行，一共有 2 组互相平行的对边。

想一想

6. 如果在同一张纸上，直线 a 与直线 c 互相平行（a ∥ c），直线 b 与直线 c 也互相平行（b ∥ c）。那么直线 a 与直线 b 是什么位置关系？

B。在同一平面内，两条直线都和第三条直线平行，这两条直线也互相平行（平行线的传递性）。
