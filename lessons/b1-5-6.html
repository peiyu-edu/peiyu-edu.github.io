5.6 函数 y=Asin(ωx+φ)

弹簧上的小球、秋千、交流电，都在「一上一下、周而复始」。它们的图象就是把 \(y=\sin x\) 拉高、压扁、左右挪一挪得到的 \(y=A\sin(\omega x+\varphi)\)。这一节先把 \(A\)、\(\omega\)、\(\varphi\) 一个一个看清，再合起来。

两个小球各挂在一根弹簧下，上下振动。以静止时的位置为 \(0\)，向上为正，单位厘米。点下面的按钮，对比甲球和乙球的弹簧振幅与波形快慢：

  • 甲球：最高到 \(3\)，最低到 \(-3\)，每 \(2\) 秒完整地上下一次。
  • 乙球：最高到 \(5\)，最低到 \(-5\)，每 \(1\) 秒完整地上下一次。

和甲比，乙的振动是？

A。\(5\) 比 \(3\) 高，幅度大；\(1\) 秒一次比 \(2\) 秒一次快。

写成函数（都从 \(0\) 往上出发，\(t\) 是秒）：甲 \(y=3\sin(\pi t)\)，乙 \(y=5\sin(2\pi t)\)。前面的 \(3\)、\(5\) 管「多高」；\(t\) 前面乘的 \(\pi\)、\(2\pi\) 管「多快」，乘得越大，上下一次用的时间越短。

要是乙比甲晚一点出发，括号里还会多加一个数。这一节就讲 \(y=A\sin(\omega x+\varphi)\) 里的这三个数：\(A\) 管多高，\(\omega\) 管多快（多密），\(\varphi\) 管从哪儿出发。

1. 先认识几个词：参数物理几何角色与双轨变换体系

要用到：正弦函数图象与五点法（5.4）、诱导公式（5.3）。先看微图解：

直觉微图解 ①参数 \(A,\omega,\varphi\) 角色与双轨图象变换全景

变换铁律平移永远只针对自变量 \(x\) 自身替换

向左平移 \(d\) 单位，是把式子中所有的 \(x\) 替换为 \((x+d)\)。若已做伸缩得到 \(\sin\omega x\)，平移后得到 \(\sin[\omega(x+d)] = \sin(\omega x + \omega d)\)。要使常数项为 \(\varphi\)，必须令 \(\omega d = \varphi \implies d = \dfrac{\varphi}{\omega}\)！

破局心法看图定解析式：先算 \(A,\omega\)，按已知点的类型定 \(\varphi\)

波峰波谷之差定振幅 \(A = \dfrac{y_{\max}-y_{\min}}{2}\)；峰谷水平间距半周期 \(\dfrac{T}{2} \implies \omega = \dfrac{2\pi}{T}\)；若已知最高点，可优先代入定初相 \(\varphi\)（令 \(\omega x+\varphi = \dfrac{\pi}{2}+2k\pi\)），绝不混淆上冲/下冲零点！

2. 核心公式与参数解系矩阵

先讨论非退化情形 \(A\omega\ne0\)。若 \(A=0\) 或 \(\omega=0\)，函数为常值，没有最小正周期；含 \(\varphi/\omega\) 或横向伸缩的式子要求 \(\omega\ne0\)。读图简式“最高值定 \(A\)、\(\omega=2\pi/T\)、最高点相位为 \(\pi/2\)”先约定 \(A>0,\omega>0\)；也可保留绝对值与符号分支。

\[\begin{aligned} \textbf{函数表达式：}&\quad y = A\sin(\omega x + \varphi) = A\sin\left[\omega\left(x + \frac{\varphi}{\omega}\right)\right] \\ \textbf{核心参量：}&\quad \text{振幅 } |A|,\quad \text{最小正周期 } T = \frac{2\pi}{|\omega|},\quad \text{频率 } f = \frac{1}{T} = \frac{|\omega|}{2\pi},\quad \text{初相 } \varphi \\ \textbf{五点法解系：}&\quad \text{令 } \omega x+\varphi \in \left\{0,\ \frac{\pi}{2},\ \pi,\ \frac{3\pi}{2},\ 2\pi\right\} \implies \text{解出 } x \text{ 描点作图} \\ \textbf{双轨变换：}&\quad \text{先平移后伸缩：平移量为 } |\varphi|;\quad \text{先伸缩后平移：平移量为 } \left|\frac{\varphi}{\omega}\right| \end{aligned}\]

自己试试：\(y=\dfrac12\sin x\) 的值域和最小正周期是？

B。\(A\) 只管上下，不碰横向，周期还是 \(2\pi\)。选 A 的同学以为压扁了周期也会变；选 C 是把「乘 \(\dfrac12\)」当成了「除以 \(\dfrac12\)」。

自己试试：\(y=\sin\dfrac x2\) 的最小正周期是？

C。\(\omega=\dfrac12\)，\(T=2\pi\div\dfrac12=4\pi\)。\(\omega\) 小于 \(1\)，图象被横向拉长。选 A 的同学拿 \(2\pi\) 乘了 \(\dfrac12\)：周期是除以 \(\omega\)。

自己试试：\(y=\sin\left(x+\dfrac\pi6\right)\) 的图象由 \(y=\sin x\) 怎样得到？

B。\(x\) 加正数，向左。选 A 是记反了：新图在 \(x=-\dfrac\pi6\) 处才是 \(\sin0\)，起点挪到了左边。选 C 的同学把括号里加的数当成了加在外面。

自己试试：把 \(y=\sin x\) 图象上所有点的横坐标缩短到原来的 \(\dfrac12\)（纵坐标不变），再向右平移 \(\dfrac{\pi}{4}\)，得到的是？

C。第一步得 \(y=\sin 2x\)；第二步把 \(x\) 换成 \(x-\dfrac\pi4\)，得 \(\sin 2\left(x-\dfrac\pi4\right)=\sin\left(2x-\dfrac\pi2\right)\)。选 A 是把平移量直接写进括号，没有乘 \(\omega=2\)，那是「先平移后伸缩」的结果。在「动手」② 里选路线二，看金点移了多少。

3. 三步破题思维链：从图象特征反推解析式与变换步骤

例题示范：已知函数 \(f(x) = A\sin(\omega x+\varphi)\)（\(A>0, \omega>0, |\varphi|<\frac{\pi}{2}\)）的部分图象最高点为 \(\left(\dfrac{\pi}{6}, 2\right)\)，与其相邻的最低点为 \(\left(\dfrac{2\pi}{3}, -2\right)\)。求其解析式及由 \(y=\sin x\) 经过先伸缩后平移得到的变换步骤。

1
👀 第一眼破题信号：最高点纵坐标为 \(2\)，最低点为 \(-2\)，振幅 \(A = 2\) 秒定！相邻峰谷水平跨度为半个周期：\(\dfrac{T}{2} = \dfrac{2\pi}{3} - \dfrac{\pi}{6} = \dfrac{\pi}{2}\)。
2
🔧 第二步定 \(\omega\) 并代最高点定 \(\varphi\)：

• 周期 \(T = \pi \implies \omega = \dfrac{2\pi}{T} = 2\)。

• 代入最高点 \(\left(\dfrac{\pi}{6}, 2\right)\)：令整体相位取波峰值：\[2\times \dfrac{\pi}{6} + \varphi = \dfrac{\pi}{2} + 2k\pi \implies \varphi = \dfrac{\pi}{6} + 2k\pi\]

• 结合 \(|\varphi| < \dfrac{\pi}{2}\)，取 \(k=0\) 得 \(\varphi = \dfrac{\pi}{6}\)，解析式为 \(f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)\)！

3
🛡️ 第三步双轨平移量核验与防坑：

若要求先伸缩后平移：先将横坐标缩短为原来的 \(\dfrac{1}{2}\) 得到 \(y=\sin 2x\)；提系数 \(2\left(x + \dfrac{\pi}{12}\right)\)，例如向左平移 \(\dfrac{\pi}{12}\) 单位（绝不是 \(\dfrac{\pi}{6}\)！），最后纵坐标伸长到 \(2\) 倍！

自己试试：\(y=A\sin(\omega x+\varphi)\)（\(\omega>0\)）的图象上，相邻的一个最高点和一个最低点，横坐标相差 \(\dfrac\pi2\)。\(\omega=\)？

B。最高点到相邻最低点是半个周期：\(\dfrac T2=\dfrac\pi2\)，\(T=\pi\)，\(\omega=\dfrac{2\pi}{\pi}=2\)。选 C 的同学把 \(\dfrac\pi2\) 当成了整个周期。

4. 用之前必查：三大高频翻车现场

翻车现场 ①先伸缩后平移，平移量忘记提 \(\omega\)

典型错解：将 \(y=\sin 2x\) 变为 \(y=\sin(2x+\frac{\pi}{3})\)，说成「向左平移 \(\frac{\pi}{3}\) 单位」。

看右图秒懂真相：向左移 \(\frac{\pi}{3}\) 是把 \(x\) 换成 \(x+\frac{\pi}{3}\)，得到的是 \(\sin 2(x+\frac{\pi}{3}) = \sin(2x+\frac{2\pi}{3})\)！要得到 \(\sin(2x+\frac{\pi}{3}) = \sin 2(x+\frac{\pi}{6})\)，向左平移 \(\frac{\pi}{6}\) 单位即可，还可加整数个周期 \(\pi\)！

上方反例微图的横轴左端为 \(x=0\)，右端为 \(x=\pi\)：灰线为 \(\sin2x\)，绿线为目标 \(\sin(2x+\pi/3)\)，橙线为错移后的 \(\sin(2x+2\pi/3)\)。

翻车现场 ②参数为负数时直接读振幅与周期

典型错解：对于 \(y = -3\sin(-2x+\frac{\pi}{4})\)，认为振幅是 \(-3\)，周期是 \(-\pi\)。

一眼看清真相：非退化情形的振幅与最小正周期为正；振幅为零时是常值，须另论。可先用诱导公式规范化：原式 \(= 3\sin(2x-\frac{\pi}{4})\)。振幅是 \(3\)，最小正周期是 \(T = \dfrac{2\pi}{2} = \pi\)！

翻车现场 ③看图定 \(\varphi\) 盲目代零点导致反相

典型错解：图象过原点 \((0,0)\)，直接令 \(\sin\varphi = 0 \implies \varphi = 0\)。

一眼看清真相：零点有「上冲零点」（从负变正穿过 \(x\) 轴，相位 \(2k\pi\)）和「下冲零点」（从正变负穿过，相位 \(\pi+2k\pi\)）之分！代错一种会导致整条波上下完全颠倒！按已知点判断相位；若给零点，还要辨升降方向并保留整数圈。

再深一点（可以先跳过）

平衡位置不在 \(x\) 轴：最高 \(5\)、最低 \(1\) 的波，平衡位置在 \(3\)。写成 \(y=A\sin(\omega x+\varphi)+B\)，\(A=\dfrac{5-1}2=2\)，\(B=\dfrac{5+1}2=3\)。\(B\) 只把整条波上下挪，不改振幅和周期。5.7 的实际模型常常这样。

实际模型：用正弦型函数描述潮汐、气温、摩天轮时，要写清时间范围和单位；它是近似，只在给定的范围里好用。

外面直接，里面反着：纵向乘 \(A\)，就是在 \(\sin\) 外面乘 \(A\)；横向缩成 \(\dfrac1\omega\)，却是在里面把 \(x\) 乘 \(\omega\)。向左平移 \(a\)，里面却是 \(+a\)。凡是改 \(x\) 的变换，写进式子都「反着来」。

① 拖三个滑块，看 A、ω、φ 各管什么

先一次只动一个滑块，看它改了什么，再一起动。滑块可以拖，也可以点一下后用方向键调。灰虚线是 \(y=\sin x\)，蓝点线是 \(y=A\sin\omega x\)，绿线是 \(y=A\sin(\omega x+\varphi)\)；金色箭头是从 \(y=A\sin\omega x\) 到绿线的平移。

y=sin xy=A sin ωxy=A sin(ωx+φ)平移 φ/ω

② 进阶：两条路线，先平移还是先伸缩？

用上面滑块的 \(A,\omega,\varphi\)。选一条路线，点「下一步」一步步变。橙线是这一步的结果，灰虚线是上一步，淡绿粗线是终点。金点追踪相位为零的参照点：当本阶段的振幅与频率为正时，它是上穿零点；最终 A=0 时不表示上穿。看它每一步挪到哪。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(y=3\sin\left(2x-\dfrac\pi4\right)\) 的振幅和最小正周期是？

A。\(A=3\)，\(\omega=2\)，\(T=\dfrac{2\pi}2=\pi\)。选 B 是拿 \(2\pi\) 乘了 \(2\)；选 C 是把最高到最低的距离 \(6\) 当成了振幅。

2. \(y=\sin\left(2x-\dfrac\pi3\right)\) 在 \([0,\pi]\) 上取到最大值 \(1\) 时，\(x=\)？

B。令相位 \(2x-\dfrac\pi3=\dfrac\pi2\)，\(2x=\dfrac{5\pi}6\)，\(x=\dfrac{5\pi}{12}\)，在 \([0,\pi]\) 里。选 A 是只解了 \(2x=\dfrac\pi2\)，丢了 \(-\dfrac\pi3\)；选 C 是忘了除以 \(2\)。

易错

3. 要得到 \(y=\sin\left(2x+\dfrac{\pi}{3}\right)\) 的图象，应该把 \(y=\sin 2x\) 的图象怎样平移？

B。把 \(x\) 提出来：\(\sin\left(2x+\dfrac{\pi}{3}\right)=\sin 2\left(x+\dfrac{\pi}{6}\right)\)。平移只看 \(x\) 本身加了多少，这里加了 \(\dfrac{\pi}{6}\)，向左移 \(\dfrac{\pi}{6}\)。

选 A 是看到括号里 \(+\dfrac{\pi}{3}\) 就移 \(\dfrac{\pi}{3}\)。真把 \(y=\sin 2x\) 向左移 \(\dfrac{\pi}{3}\)，得到的是 \(\sin\left(2x+\dfrac{2\pi}{3}\right)\)，多移了一倍。选 C、D 是方向反了。

4. \(y=2\sin(2x+\varphi)\)，\(|\varphi|<\pi\)。它的图象过点 \((0,1)\)，并且在 \(x=0\) 附近，\(x\) 增大时 \(y\) 也增大。\(\varphi=\)？

A。代点只得到 \(\sin\varphi=\dfrac12\)，在 \(|\varphi|<\pi\) 内有 \(\dfrac\pi6\) 和 \(\dfrac{5\pi}6\) 两个解，光代一个点定不下来，还得检验。\(x=0\) 时相位就是 \(\varphi\)；要在这里上升，相位得落在 \(\left(-\dfrac\pi2,\dfrac\pi2\right)\) 里，所以只能是 \(\dfrac\pi6\)。\(\varphi=\dfrac{5\pi}6\) 时图象也过 \((0,1)\)，但在那里是下降的。

5. \(y=-3\sin\left(\dfrac{\pi}{4}-2x\right)\) 的振幅和最小正周期是？

B。振幅是距离、周期是正数，都不会是负的。先规范化：\(-3\sin\left(\dfrac\pi4-2x\right)=3\sin\left(2x-\dfrac\pi4\right)\)，现在 \(A=3>0\)，\(\omega=2>0\)，周期 \(\dfrac{2\pi}{2}=\pi\)。另外，在「动手」① 里把 \(\omega\) 拖到 \(0\)，函数成了常数，就没有最小正周期了。

例题视频：由相邻峰谷求式

视频题目：\(f(x)=A\sin(\omega x+\varphi)\)，其中 \(A>0,\omega>0,|\varphi|<\pi/2\)。图象最高点为 \((\pi/6,2)\)，其右侧相邻最低点为 \((2\pi/3,-2)\)，求解析式。答案为 \(2\sin(2x+\pi/6)\)。

挑战

6. \(y=\sin\left(\omega x+\dfrac\pi6\right)\)（\(\omega>0\)）的图象向右平移 \(\dfrac\pi3\) 后，和原来的图象重合。\(\omega\) 最小是？

B。平移后重合，平移量得是周期的整数倍：\(\dfrac\pi3=k\cdot\dfrac{2\pi}{\omega}\)（\(k\) 是正整数），\(\omega=6k\)，最小是 \(6\)。选 A 是以为移半个周期也重合：可 \(\sin(\theta-\pi)=-\sin\theta\)，移半个周期图象上下翻了过来，不重合。

例题视频：两种变换顺序

视频由 \(y=\sin x\) 变到 \(y=\sin(2x-\pi/3)\)，目标式含减号，讨论向右平移。先伸缩后的一个代表平移为右移 \(\pi/6\)；先平移再伸缩时，先右移 \(\pi/3\)。每一步都核对当前表达式。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
