画平行线和长方形

怎样用直尺和三角尺画出平行线？为什么平行线之间的宽度处处相等？怎样画标准长方形？

火车在平直的铁轨上行驶。如果测量铁轨不同位置两根钢轨之间的垂直宽度，测量结果会怎样？

对，处处相等！在两条平行线之间，所有垂直线段的长度都相等。这也是平行线最重要的性质之一。

怎样准确地画出一组平行线？怎样画出一个规范的长方形呢？

1. 用直尺和三角尺画平行线（平移法）

怎样用三角尺和直尺配合画出平行线？点下面的按钮一步步操作三角尺平移！

第四步「四画」：沿着平移后三角尺的水平直角边画出直线 b，得到 a // b！

画法口诀（一靠、二靠、三移、四画）：
① 一靠：用三角尺的一条直角边紧贴已知直线 a；
② 二靠：拿直尺紧紧靠在三角尺的另一条直角边上（作为平移轨道）；
③ 三移：按紧直尺不要晃动，推动三角尺沿着直尺平移（虚线是平移前的位置，实线是平移后的位置）；
④ 四画：沿着平移后三角尺的第一条直角边画出直线 b。此时 a // b！

2. 平行线间所有垂直线段的长度都相等

如果 a // b，端点分别在 a 和 b 上并且垂直于平行线的所有线段，长度都相等。这个长度叫作平行线间的距离。

3. 画标准长方形和正方形

长方形和正方形的相邻两边都互相垂直。切换图形并点击步骤，看看怎样用三角尺画出指定边长的长方形和正方形！

长方形第 ③ 步：连接两条垂线的上端点封口，长 4 厘米、宽 3 厘米的长方形画好了！

画指定边长的长方形（长 4 厘米、宽 3 厘米）和正方形（边长 3 厘米）：
① 画底边：先用直尺画一条长 4 厘米（画正方形则画 3 厘米）的线段；
② 画两条垂线：过这条线段的两个端点，用三角尺向同一侧分别画出长 3 厘米的垂直线段，并标上直角符号；
③ 连线封口：用直尺连接两条垂直线段的另一个端点，就画出了标准的长方形或正方形。

自己试试

在同一平面内，如果直线 a 与直线 b 都垂直于直线 c（a ⊥ c，b ⊥ c），那么直线 a 与直线 b 是什么位置关系？

A。在同一平面内，两条直线都垂直于同一条直线，那么这两条直线互相平行（a // b）。

自己试试

一个长方形的长是 5 厘米，宽是 3 厘米。两条宽边所在的平行线之间的距离是多少厘米？

长方形的长边垂直于两条宽边，长边的长度就是两条宽所在平行线的距离，是 5 厘米。

1. 画平行线：三角尺靠线，直尺贴边平移，沿三角尺画平行线。
2. 平行线间距离处处相等：端点在两条平行线上且与平行线垂直的所有线段长度都相等。
3. 画长方形：利用相邻两边互相垂直、对边平行且相等的特征一步步画出。

两个容易错的地方

✗ 平移三角尺时，作为导轨的直尺松动了

直尺一动，轨道偏了，画出来的线就无法保持平行。

✓ 牢记「按住直尺不动」

左手手指用力按死直尺，右手单手轻推三角尺平移。

✗ 以为平行线间任意连线都相等

斜着连接平行线上两点的线段，误以为也和平行线距离相等。

✓ 只有「垂直线段」才处处相等

斜线有长有短，只有垂直于平行线的线段长度才是处处相等的距离。

直接用

1. 观察斑马线，白色条纹的两条长边是什么位置关系？条纹之间的垂直距离怎样？

B。斑马线长边是平行线，平行线间的垂直距离处处相等。

2. 一个长方形的长是 6 厘米，宽是 4 厘米。两条长边所在的平行线之间的距离是多少厘米？

两条长边之间的垂直距离正好等于长方形的宽，是 4 厘米。

3. 要过已知直线外一点 P，画出已知直线的平行线。正确的工具配合是：

A。两把尺子（三角尺 + 直尺导轨）配合平移，才能保证画出的直线完全平行。

容易错

4. 下面三条在两条平行线之间的线段，线段 1 斜着倾斜 60°，线段 2 垂直于平行线，线段 3 斜着倾斜 45°。哪一条线段的长度最短？

C。平行线间垂直线段最短，斜线都会比垂直线段长。

5. 在一个长方形中，一共有多少组互相垂直的相邻边？

长方形有 4 个角都是直角，每个直角两边互相垂直，共有 4 组互相垂直的相邻边。

想一想

6. 画两条平行线 a // b，再以这两条平行线作为上下两条边所在的直线，在平行线之间画一个长方形（四个顶点都在平行线上）。这个长方形的对边和这两条平行线有什么关系？

B。长方形的上下一组对边落在平行线上，左右另一组对边作为垂直线段连接两条平行线，长度正好等于平行线间的距离！
