28.1 图形的旋转

围绕定点转动，大小形状不变，全等变换集大成！从钟表指针、风力发电机叶片、汽车雨刮器到几何图形的旋转，看透旋转三要素，掌握对应线段相等、对应角相等、夹角等于旋转角三大几何性质，玩转尺规作图与动点轨迹。

本节导读　先修：7.4 平移 · 14.1 全等三角形 · 15.1 轴对称 · 本节路线

要用到：平移的性质（回看 7.4）、全等三角形对应边角相等（回看 14.1）、轴对称变换的性质（回看 15.1）。

  1. 从风力发电机叶片与钟表指针切入：什么是平面内的旋转？
  2. 抽象出旋转三要素：旋转中心、旋转方向与旋转角；
  3. 掌握旋转的核心几何性质：对应点到中心距离相等、对应点与中心连线夹角等于旋转角、旋转前后图形全等；
  4. 网格作图与坐标旋转变换：如何准确作出旋转后的对应点与图形；
  5. 动手交互实验：三角形定点旋转轨迹台与进阶坐标系旋转映射台（含重置按钮）；
  6. 自检与中考真题演练，突破旋转性质在几何计算与线段轨迹中的综合应用。

生活中的旋转无处不在：钟表指针绕着轴心转动、风力发电机的三叶片在风中呼啸旋转、汽车雨刮器绕着转轴往复摆动。仔细观察如图所示的风力发电机叶片，当叶片绕中心转动时，整个叶片的形状和大小发生改变了吗？

观察这三个完全相同且夹角为 \(120^\circ\) 的叶片，将整个图形绕中心 \(O\) 顺时针旋转多少度后，叶片第一次与原来的图案完全重合？

B。三个叶片将周角 \(360^\circ\) 三等分，每两个相邻叶片的夹角是 \(\frac{360^\circ}{3} = 120^\circ\)。

当旋转角达到 \(120^\circ\) 时，第一个叶片恰好转到第二个叶片的位置，整个图形第一次与自身重合。转动过程中，叶片的长度、宽度和面积丝毫不变，改变的仅仅是图形的位置与方向。这就是几何中三大全等变换之一——旋转。

1. 先认识几个词：什么是图形的旋转与三要素？

旋转中心固定

对应点绕中心走同角度；中心可在图形外。

旋转角有方向

顺、逆时针相反；角度相同时图形通常不同。

抓住关系： \(\color{#2F7A56}{\underbrace{OA}_{\text{原距离}}}=\color{#966524}{\underbrace{OA\prime}_{\text{新距离}}}\)

先检查条件，再使用关系；彩色标注帮助区分量。

前置知识：全等三角形（回看 14.1）、角的概念（回看 6.3）。我们来看看一个几何变换要成为「旋转」，必须明确哪三个核心要素：

  • 旋转的定义：在平面内，把一个平面图形绕着平面内某一点 \(O\) 转动一个角度，叫作图形的旋转（rotation）。
  • 要素一：旋转中心：转动所围绕的定点 \(O\) 叫作旋转中心（可以位于图形内部、边上、顶点或图形外部）。
  • 要素二：旋转方向：转动的方向，分为顺时针方向和逆时针方向。
  • 要素三：旋转角：图形上的点与旋转中心连线转过的角度叫作旋转角（任意一对对应点与旋转中心连线所成的角都是旋转角）。

直觉微图解 ①旋转三要素逐项解析：定点、定方、定角度

自己试试 1：时钟的时针从上午 9 点整转动到中午 12 点整，关于时针的旋转，下列说法正确的是（ ）

C。表针转动的中心是固定不动的表盘轴心；从 9 点到 12 点共走过了 3 个大格，每个大格对应 \(\frac{360^\circ}{12} = 30^\circ\)，旋转角为 \(3 \times 30^\circ = 90^\circ\)，方向为顺时针。

思考：旋转中心必须在图形的顶点或内部吗？

不必！旋转中心是平面内的任意一个固定点：

  • 可以在图形的内部（如汽车车轮转动时绕轴心）；
  • 可以在图形的顶点上（如把直角三角形绕其直角顶点旋转 \(90^\circ\)）；
  • 完全可以在图形的外部（如地球绕太阳公转，摩天轮吊舱绕中心轴转动）。无论旋转中心在哪里，每个点都在以该中心为圆心的同心圆弧上运动。

2. 旋转的核心几何性质：距离相等、夹角相等、图形全等

当平面图形绕点 \(O\) 旋转得到新图形时，几何量之间具有极其严密的守恒关系：

  • 距离守恒：对应点到旋转中心的距离相等，即 \(OA = OA', OB = OB', OC = OC'\)。
  • 角守恒：任意一对对应点与旋转中心所连线段的夹角等于旋转角，即 \(\angle AOA' = \angle BOB' = \angle COC' = \alpha\)。
  • 形状大小守恒：旋转前后的图形全等，对应线段相等，对应角相等，面积与周长保持不变。
  • 动点轨迹：在旋转过程中，图形上的任意一点的运动轨迹都是一段圆弧。

直觉微图解 ②旋转性质动眼看：对应连线与同心圆弧

自己试试 2：将 \(\triangle ABC\) 绕顶点 \(A\) 逆时针旋转 \(70^\circ\) 得到 \(\triangle ADE\)，若点 \(D\) 恰好落在边 \(BC\) 上，则 \(\angle B\) 的度数是（ ）

C。由旋转性质可知，点 \(B\) 的对应点是点 \(D\)，故对应点到旋转中心 \(A\) 的距离相等，即 \(AB = AD\)，且旋转角 \(\angle BAD = 70^\circ\)。

在等腰 \(\triangle ABD\) 中，\(AB = AD\)，顶角 \(\angle BAD = 70^\circ\)，所以底角 \(\angle B = \angle ADB = \frac{180^\circ - \angle BAD}{2} = \frac{180^\circ - 70^\circ}{2} = 55^\circ\)。利用旋转前后「对应点到中心距离相等」构造等腰三角形，是中考旋转类题目的核心破题利器！

深挖：对应线段所成的夹角与旋转角有什么关系？

不仅点与中心的夹角等于旋转角，两条对应线段所在直线的夹角也等于旋转角（或其补角）！

例如线段 \(AB\) 旋转后成为线段 \(A'B'\)，若延长 \(AB\) 与 \(A'B'\) 相交于点 \(P\)，则四边形 \(APA'O\) 内角和为 \(360^\circ\)，容易推导出这两条线段所在直线的锐角夹角恰好等于旋转角 \(\alpha\)（或 \(180^\circ - \alpha\)）。这在证明线段垂直平分或全等三角形模型中极为好用。

典例 1（波利亚四步法）：利用旋转构造等边三角形求角度

【例 1】在 \(\text{Rt}\triangle ABC\) 中，\(\angle ACB = 90^\circ\)，\(\angle B = 30^\circ\)，将 \(\triangle ABC\) 绕点 \(C\) 顺时针旋转 \(60^\circ\) 得到 \(\triangle DEC\)，点 \(D\) 恰好落在斜边 \(AB\) 上，求 \(\angle ADE\) 的度数。

  1. ① 读懂题意：旋转中心是点 \(C\)，旋转角 \(\angle ACD = \angle BCE = 60^\circ\)，点 \(A\) 对应点 \(D\)（在 \(AB\) 上），点 \(B\) 对应点 \(E\)，求 \(\angle ADE\)。
  2. ② 想办法：由旋转保距性 \(CA = CD\) 及旋转角 \(\angle ACD = 60^\circ\)，可判定 \(\triangle ACD\) 为等边三角形；再结合旋转全等性质 \(\angle CDE = \angle CAB\) 即可求 \(\angle ADE\)。
  3. ③ 执行 + 执行中检查：在 \(\text{Rt}\triangle ABC\) 中，\(\angle CAB = 90^\circ - 30^\circ = 60^\circ\)。由旋转性质得 \(CA = CD\)，\(\angle ACD = 60^\circ\)，故 \(\triangle ACD\) 是等边三角形，\(\angle CDA = 60^\circ\)。又由 \(\triangle DEC \cong \triangle ABC\) 得 \(\angle CDE = \angle CAB = 60^\circ\)（检查：对应角顶点顺序 \(D \leftrightarrow A\) 一致）。因此 \(\angle ADE = \angle CDA + \angle CDE = 60^\circ + 60^\circ = 120^\circ\)（注：当 \(D, C\) 分居或共线时亦可验证平角余角关系）。
  4. ④ 回头看：凡遇到「旋转角为 \(60^\circ\)」，连接对应点必得等边三角形！这是旋转几何题中最经典的辅助线直觉。

自己试试 3：在平面直角坐标系中，点 \(P(3, 4)\) 绕原点 \(O\) 顺时针旋转 \(90^\circ\) 后的对应点 \(P'\) 的坐标是（ ）

D。点 \(P(3, 4)\) 位于第一象限，向右 3、向上 4。

绕原点顺时针旋转 \(90^\circ\) 后，原向上的垂直方向旋转为向右的水平方向（横坐标为 4），原向右的水平方向旋转为向下的垂直方向（纵坐标为 \(-3\)）。对应点落在第四象限，坐标为 \((4, -3)\)。一般规律：点 \((x, y)\) 绕原点顺时针旋转 \(90^\circ\) 变为 \((y, -x)\)；逆时针旋转 \(90^\circ\) 变为 \((-y, x)\)。

作图心法：网格中如何作出简单多边形旋转后的图形？
  1. 找关键点：多边形的顶点是决定图形形状的关键点；
  2. 连线与画角：连接各关键点与旋转中心 \(O\)，以 \(O\) 为顶点、连线为始边，按指定方向画出等于旋转角 \(\alpha\) 的角；
  3. 截取等长：在角的终边上截取对应线段，使得 \(OA' = OA, OB' = OB, OC' = OC\)；
  4. 顺次连接：将所得对应顶点顺次连接成多边形。
典例 2（波利亚四步法）：坐标系中线段旋转 45° 求坐标

【例 2】在平面直角坐标系中，点 \(A\) 的坐标为 \((4, 0)\)，将线段 \(OA\) 绕原点 \(O\) 逆时针旋转 \(45^\circ\) 得到线段 \(OA_1\)，求点 \(A_1\) 的坐标。

  1. ① 读懂题意：已知线段长 \(OA = 4\)，旋转中心为原点 \(O\)，旋转角为 \(45^\circ\)（逆时针），求对应点 \(A_1\) 的坐标。
  2. ② 想办法：由旋转性质可知 \(OA_1 = OA = 4\)，\(\angle AOA_1 = 45^\circ\)。过 \(A_1\) 向 \(x\) 轴作垂线，构造含 \(45^\circ\) 角的等腰直角三角形，用勾股定理计算横纵坐标。
  3. ③ 执行 + 执行中检查：作 \(A_1H \perp x\) 轴于 \(H\)。在等腰直角 \(\text{Rt}\triangle OA_1H\) 中，\(\angle A_1OH = 45^\circ\)，故 \(OH = A_1H > 0\)。由勾股定理 \(OH^2 + A_1H^2 = OA_1^2 = 16\)，解得 \(2OH^2 = 16 \implies OH = A_1H = 2\sqrt{2}\)。点 \(A_1\) 在第一象限（检查：横、纵坐标均为正），故 \(A_1(2\sqrt{2}, 2\sqrt{2})\)。
  4. ④ 回头看：验证距离 \(\sqrt{(2\sqrt{2})^2 + (2\sqrt{2})^2} = \sqrt{8 + 8} = 4 = OA\)，与旋转保距性完全吻合。

用之前必查：三大翻车现场

翻车 1
错误：旋转后点必在圆上
核对：点不为中心时，它的对应点在以中心为圆心、原距离为半径的圆上。
翻车 2
错误：只看角度忽略方向
核对：从同一射线顺转与逆转 90°，终边一般不同。
翻车 3
错误：旋转中心必在图内
核对：中心可以在图形外；图形仍绕同一定点转动。

练习 1：下列生活现象中，属于数学中的「旋转」的是（ ）

B。钟摆是以支点为固定旋转中心的转动；火箭升空、自动扶梯、推拉窗均属于平移变换。

练习 2：把一个正五边形绕其中心旋转，至少旋转多少度才能与原来的正五边形自身重合？（ ）

C。正五边形的五个顶点将周角 \(360^\circ\) 五等分，相邻顶点的中心角为 \(\frac{360^\circ}{5} = 72^\circ\)。因此至少顺时针或逆时针旋转 \(72^\circ\) 即可与自身重合。

练习 3：在平面直角坐标系中，点 \(B(0, 3)\) 绕原点 \(O\) 顺时针旋转 \(90^\circ\) 后的对应点 \(B'\) 的坐标是（ ）

A。点 \(B(0, 3)\) 位于 \(y\) 轴正半轴上，距离原点 3 个单位。顺时针旋转 \(90^\circ\) 后落在 \(x\) 轴正半轴上，距离仍为 3，坐标为 \((3, 0)\)。

练习 4：已知点 \(A(-2, 5)\)，将线段 \(OA\) 绕原点 \(O\) 逆时针旋转 \(90^\circ\) 得到线段 \(OA'\)，则点 \(A'\) 的坐标是（ ）

B。点 \(A(-2, 5)\) 在第二象限。逆时针旋转 \(90^\circ\) 后对应点落入第三象限（横纵坐标均为负数）。根据逆时针旋转公式 \((x, y) \to (-y, x)\)，代入得 \((-5, -2)\)。

练习 5：将 \(\triangle OAB\) 绕点 \(O\) 逆时针旋转 \(80^\circ\) 得到 \(\triangle OCD\)（点 \(A\) 的对应点为点 \(C\)），若 \(\angle AOB = 35^\circ\)，且射线 \(OB\) 在 \(\angle AOC\) 内部，则 \(\angle BOC\) 的度数是（ ）

提示

先找出哪两个点的连线夹角是旋转角 \(80^\circ\)（即 \(\angle AOC = 80^\circ\)），再用 \(\angle AOC - \angle AOB\)。

C。因为点 \(A\) 的对应点是点 \(C\)，所以对应点与旋转中心连线的夹角 \(\angle AOC\) 等于旋转角 \(80^\circ\)。又因为 \(\angle AOB = 35^\circ\) 且 \(OB\) 在 \(\angle AOC\) 内部，所以 \(\angle BOC = \angle AOC - \angle AOB = 80^\circ - 35^\circ = 45^\circ\)。

易错提醒：如何秒判坐标旋转后的象限与符号？

画草图定象限法：切忌死背公式，先在草稿纸上标出原点和动点，看它转动 \(90^\circ\) 后落在哪个象限：

  • 原点连线转 \(90^\circ\)，水平线段变成竖直线段，竖直线段变成水平线段，横纵坐标数值互换；
  • 根据目标象限直接赋符号：第一象限 \((+,+)\)、第二象限 \((-,+)\)、第三象限 \((-,-)\)、第四象限 \((+,-)\)。万无一失！

巩固练习 1：三个全等叶片围绕中心 \(O\) 均匀排列，相邻叶片夹角为 \(120^\circ\)。整个叶片组绕 \(O\) 旋转后首次与原图形重合，最小正旋转角为（　）

B。由于风力发电机的三个叶片完全相同且两两夹角为 \(120^\circ\)，该图形具有旋转对称性．当整个叶片组绕旋转中心 \(O\) 顺时针旋转 \(120^\circ\) 时，相邻的另一个叶片端点恰好转到原来端点 \(A\) 所在的位置，整体图形与原位置重合．因此最小正旋转角度为 \(120^\circ\)，故选 B．

巩固练习 2：在平面直角坐标系中，将点 \(P(5, 3)\) 绕原点 \(O\) 逆时针旋转 \(90^\circ\) 得到点 \(P'\)，则点 \(P'\) 的坐标为（　）

A。过点 \(P(5,3)\) 作 \(PA \perp x\) 轴于点 \(A\)，过点 \(P'\) 作 \(P'B \perp y\) 轴于点 \(B\)．由旋转 \(90^\circ\) 的性质可证 \(\text{Rt}\triangle POA \cong \text{Rt}\triangle P'OB\)，得 \(|x_{P'}| = y_P = 3\)，\(|y_{P'}| = x_P = 5\)．因为第一象限的点 \(P(5,3)\) 绕原点逆时针旋转 \(90^\circ\) 后进入第二象限（横负纵正），所以 \(P'(-3, 5)\)，故选 A．
