二次型约束下线性式最大值

F2填空题不等式的证明

设 x,y,z∈R，且

5x2+6y2+6z2−8yz≤1,

则 x+y+z 的最大值为。

作答

分数写 a/b，根号写 √ 或 sqrt，π 写 pi 也可以。

标准答案：530​​

解析

试着想起：2017 年全国高中数学联赛一试（A 卷） 第 3 题 · P007260

在平面直角坐标系 xOy 中，椭圆 C 的方程为 9x2​+10y2​=1，F 为 C 的上焦点，A 为 C 的右顶点，P 是 C 上位于第一象限内的动点，则四边形 OAPF 的面积最大值为。

打开这道题

思路

把正定二次型化成加权平方和，再对目标线性式使用加权柯西不等式。

解答

令

u=x+2y−2z,v=x−y,w=x+z.

直接展开可得

u2+2v2+2w2=5x2+6y2+6z2−8yz,

而解线性方程得

x+y+z=51​u−53​v+57​w.

由加权柯西不等式，

x+y+z≤(251​+509​+5049​)(u2+2v2+2w2)​≤56​​=530​​.

取 x=30​/30，y=z=30​/12 时等号成立，故最大值为

530​​​.

复核

等号点代回原二次型等于 1，三项加权柯西的比例关系也同时成立。

方法总结

正定二次型约束下线性函数的极值，可通过配方或线性代换化成加权单位球，再用对偶范数求出。

为什么评为 F2（会透露解法方向）

按y与z的对称结构令s=y+z、d=y−z，约束成为5x²+s²+5d²≤1，目标x+s直接用配权柯西。

用到的方法（会透露解法方向）

核心工具：柯西支撑与正交投影、作差配方与非负分解

专题卡：配方、作差与非负分解、柯西与加权平方和
