4.2 等差数列

每一项都比前一项多同一个数，这样的数列最简单，也最常用。这一节讲它的第 \(n\) 项怎么写、前 \(n\) 项怎么加，以及加出来的和什么时候最大。

一个小礼堂，第 \(1\) 排有 \(20\) 个座位，往后每一排都比前一排多 \(2\) 个座位。点下面的按钮，数一数从第 \(1\) 排到第 \(6\) 排中间跨了几个「\(+2\)」：

第 \(6\) 排有几个座位？

一排一排数：\(20,\ 22,\ 24,\ 26,\ 28,\ 30\)。第 \(6\) 排是 \(30\)，选 A。

从第 \(1\) 排走到第 \(6\) 排，只多了 \(5\) 次，所以是 \(20+5\times2\)，不是 \(20+6\times2\)。

「每次多同一个数」的数列叫等差数列。这一节讲：第 \(n\) 排有几个座位（通项），前 \(n\) 排一共几个座位（前 \(n\) 项和）。

1. 先认识几个词

要用到：4.1 的数列、项、通项公式、前 \(n\) 项和 \(S_n\)（回看 4.1）；一次函数 \(y=kx+b\) 和二次函数的顶点（函数 3.1、二次函数 2.3）。

课本用词：等差公差可以是 0；求和最值时下标只能取题目允许的正整数，连续函数顶点不能直接当作数列项。

相邻两项的差：后一项减前一项，\(a_{n+1}-a_n\)。

例：\(3,7,11,15\) 的相邻差是 \(4,4,4\)，都一样；\(1,2,4,7\) 的相邻差是 \(1,2,3\)，不一样。

公差 \(d\)：相邻差每一处都等于同一个常数时，这个常数叫公差，记作 \(d\)。它可以是正数、负数，也可以是 \(0\)。

例：\(3,7,11,15,\dots\) 的 \(d=4\)；\(10,7,4,1,\dots\) 的 \(d=-3\)；\(5,5,5,\dots\) 的 \(d=0\)。

前 \(n\) 项和 \(S_n\)：从第 \(1\) 项加到第 \(n\) 项，\(S_n=a_1+a_2+\dots+a_n\)。

例：数列 \(2,5,8,11,\dots\)，\(S_1=2\)，\(S_3=2+5+8=15\)。

一次函数的斜率与公差：\(y=kx+b\) 里，\(x\) 每加 \(1\)，\(y\) 就加 \(k\)。等差数列的公差 \(d\) 正好对应直线的斜率。

例：\(a_n=3n-2\)，点 \((n, a_n)\) 全部落在斜率为 \(3\) 的直线上，但自变量只取正整数。

等差核心特征：斜率离散线、倒序配对与二次求和
中项性质 等差中项与对称求和
  • 等差中项：\(a, A, b\) 成等差 \(\iff 2A=a+b \iff A=\dfrac{a+b}{2}\)。
  • 下标和性质：若 \(m+n=p+q\)，则 \(a_m+a_n=a_p+a_q\)。
  • 奇数项求和：\(S_{2k-1}=(2k-1)a_k\)（首末和换为中间项的 2 倍）。
公式选用 两套求和公式与最值判定
  • 已知首末项：用 \(S_n=\dfrac{n(a_1+a_n)}{2}\)，梯形平均算法最快捷。
  • 已知首项与公差：用 \(S_n=na_1+\dfrac{n(n-1)}{2}d\)，化简后无常数项。
  • 求 \(S_n\) 最值：当 \(a_1>0, d<0\) 时，令 \(a_n\ge0\) 找正项分界点即为最大和。

2. 定义与色彩语义主公式

一个数列，从第 \(2\) 项起，每一项减它的前一项都等于同一个常数 \(d\)，就叫等差数列：

定义式：\(a_{n+1}-a_n = \color{#0284c7}{d}\quad (\forall n \in \mathbf{N}^*)\)
通项公式：\(a_n = a_1 + (n-1)\color{#0284c7}{d} = \color{#0284c7}{d}n + (a_1 - \color{#0284c7}{d})\)（斜率为 \(d\) 的离散直线）
前 \(n\) 项和：\(S_n = \dfrac{n(a_1+a_n)}{2} = na_1 + \dfrac{n(n-1)}{2}\color{#0284c7}{d} = \color{#16a34a}{\dfrac{d}{2}}n^2 + \color{#d97706}{\left(a_1-\dfrac{d}{2}\right)}n\)

例 1（看一遍怎么写）

等差数列中 \(a_3=7\)，\(a_7=19\)，求通项公式和 \(a_{20}\)。

从第 \(3\) 项到第 \(7\) 项走 \(4\) 步：\(a_7-a_3=4d\)，即 \(12=4d \implies d=3\)。

再往回走 \(2\) 步：\(a_1=a_3-2d=7-6=1\)。

所以 \(a_n=1+3(n-1)=3n-2\)，\(a_{20}=3\times20-2=58\)。

自己试试：等差数列 \(a_1=2\)，\(d=3\)，\(a_{20}\) 是？

A。\(a_{20}=2+(20-1)\times3=2+57=59\)。选 B 的同学用了 \(20\times3\)：从第 \(1\) 项到第 \(20\) 项只走 \(19\) 步。

3. 等差中项与三步破题思维链

🧩 典型例题：首正负公差数列的前 n 项和最大值求解
👀 信号
已知等差数列 \(a_1 > 0, d < 0\)（数列从正数递减走向负数），要求前 \(n\) 项和 \(S_n\) 的最大值及对应项数。
🔧 步骤
1. 找正项分界：解不等式 \(a_n = a_1 + (n-1)d \ge 0\)，求出非负项的最大下标整数 \(k\)；
2. 确定最值项：此时前 \(k\) 项均为正或零，加到第 \(k\) 项和达到最大；
3. 代入求和公式：代入 \(S_k = ka_1 + \frac{k(k-1)}{2}d\) 计算极值（若 \(a_k=0\)，则 \(S_{k-1}=S_k\) 均为最大）。
🛡️ 防坑
切忌盲目套用二次函数实数对称轴 \(-\frac{B}{2A}\) 得出非整数结论；下标必须为整数。

例 2（等差中项与性质运用）

(1) \(3\) 与 \(11\) 的等差中项：\(A=\dfrac{3+11}{2}=7\)。检验：\(3,7,11\) 相邻差均为 \(4\)。

(2) 等差数列中 \(a_2+a_8=10\)，求 \(a_5\)。由 \(2+8=5+5\) 得 \(a_2+a_8=2a_5\)，故 \(a_5=5\)。

自己试试：\(-4\) 与 \(10\) 的等差中项是？

A。\(\dfrac{-4+10}{2}=3\)，检验 \(-4,3,10\) 的相邻差都是 \(7\)。选 B 的同学算的是 \(\dfrac{10-(-4)}{2}\)，那是公差，不是中项。

4. 前 \(n\) 项和：倒序相加推导

将数列正着写一遍、倒着写一遍，上下对齐相加，每一列之和恒为 \(a_1+a_n\)，共 \(n\) 列，即 \(2S_n=n(a_1+a_n)\)。

例 3

等差数列 \(a_1=2\)，\(d=3\)，求 \(S_{10}\)。

用公式二：\(S_{10}=10\times2+\dfrac{10\times9}{2}\times3=20+135=155\)。

用公式一验算：\(a_{10}=2+9\times3=29\)，\(S_{10}=\dfrac{10\times(2+29)}{2}=155\)。结果完全一致。

自己试试：\(1+3+5+\dots+19\) 等于？

A。先数项数：\(19=1+(n-1)\times2 \implies n=10\)。\(S_{10}=\dfrac{10\times(1+19)}{2}=100\)。选 B 是忘了除以 \(2\)；选 C 是把项数当成了 \(19\)。

5. 三大翻车现场红绿对比卡

⚠️ 误区一：步数算错（n 误代为 n-1）
❌ 错误：求第 20 项直接算 \(a_{20} = a_1 + 20d\)
✅ 正确：从第 1 项走到第 20 项共跨越 \(20-1=19\) 步公差，应算 \(a_1 + 19d\)！
⚠️ 误区二：求和最值盲信实数对称轴
❌ 错误：\(S_n=-\frac{3}{2}n^2+\frac{23}{2}n\) 误认最大值在 \(n=3.83\)
✅ 正确：项数只能是正整数！比较两边整数 \(S_3=21, S_4=22\)，最大值在 \(n=4\) 取得。
⚠️ 误区三：断言求和必为二次函数
❌ 错误：认为所有等差数列的 \(S_n\) 都是关于 \(n\) 的二次式
✅ 正确：当公差 \(d=0\) 时，数列为常数列 \(c\)，\(S_n=cn\) 不是二次式；\(c\ne0\) 时对应正比例函数，\(c=0\) 时恒为 \(0\)。
🔍 反例微图解：步数跨度 n-1 vs Sn 整数比较峰值
左图：从 \(a_1\) 到 \(a_n\) 只有 \(n-1\) 个间隔（植树原理）；右图：实数顶点 \(n=3.83\) 不存在，必须在整数 \(n=4\) 处截取最大值 \(22\)。
实数顶点只是「找最值的地方大概在哪」：真正的答案要在它两边的正整数（以及范围端点）里比较出来。
再深一点（可以先跳过）

通项是 \(pn+q\) 的形式：一定是等差数列，公差为 \(p\)；若 \(p=0\) 则为常数列。

前 \(n\) 项和是 \(An^2+Bn\) 的形式（无常数项）：数列必为等差数列，公差 \(d=2A\)。若含有非零常数项（如 \(S_n=n^2+1\)），则第一项脱节，并非整体等差数列。

对称轴恰为半整数：若实数对称轴恰为 \(n=4.5\)，则 \(S_4=S_5\) 达到最大值（此时恰有 \(a_5=0\)）。

① 拖首项和公差：点落在一条直线上

画的是前 \(8\) 项 \((n,a_n)\)。拖第 \(1\) 个点改 \(a_1\)，拖第 \(2\) 个点改 \(a_2\)（也就改了 \(d=a_2-a_1\)）；选中圆点后按上下方向键也行。虚线是 \(y=dx+(a_1-d)\)。把 \(d\) 调成 \(0\) 看看。

② 进阶：\(S_n\) 什么时候最大（最小）

实心点是 \(S_1,S_2,\dots,S_{20}\)；虚线是把 \(n\) 当实数画出的抛物线。空心圈是实数顶点，金色点是真正取到最值的整数 \(n\)。拖圆点 \(P\)（或按左右方向键）读任意一个 \(S_n\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 等差数列中 \(a_3=7\)，\(a_9=25\)，\(a_1\) 是？

A。第 \(3\) 项到第 \(9\) 项走 \(6\) 步：\(6d=25-7=18\)，\(d=3\)；再往回走 \(2\) 步：\(a_1=7-2\times3=1\)。选 C 的同学只往回走了 \(1\) 步。

2. 等差数列中 \(a_2+a_8=16\)，\(S_9\) 是？

A。\(1+9=2+8\)，所以 \(a_1+a_9=a_2+a_8=16\)，\(S_9=\dfrac{9\times16}{2}=72\)。不用求出 \(a_1\) 和 \(d\)。选 B 是忘了除以 \(2\)。

易错

3. 数列 \(5,5,5,5,\dots\)（每一项都是 \(5\)）。下面说法对的是？

B。每个相邻差都是 \(0\)，同一个常数，符合定义，\(d=0\) 完全可以。这时 \(a_n=5\)，点排成水平一行；「等差数列的通项是 \(n\) 的一次函数、图象斜着」只在 \(d\ne0\) 时成立。在「动手」①把 \(d\) 调到 \(0\) 就能看到。

4. 数列的前 \(n\) 项和 \(S_n=n^2+1\)。它是等差数列吗？

B。\(a_1=S_1=2\)。\(n\ge2\) 时 \(a_n=S_n-S_{n-1}=2n-1\)，得 \(a_2=3\)，\(a_3=5\)，\(a_4=7\)。数列是 \(2,3,5,7,\dots\)：\(a_2-a_1=1\)，后面都是 \(2\)，不是每一处都一样，不是等差数列。

A 错在 \(a_n=S_n-S_{n-1}\) 只对 \(n\ge2\) 成立，第 \(1\) 项要单独用 \(S_1\) 算；只看后面几项是 \(2\) 就下结论，正是「凭几项」。

5. 等差数列 \(a_1=13\)，\(d=-3\)。\(S_n\) 的最大值是？

B。\(S_n=13n-\dfrac{3n(n-1)}{2}=-\dfrac32n^2+\dfrac{29}{2}n\)。当实数看，顶点 \(n=\dfrac{29}{6}\approx4.83\)，那里的值是 \(\dfrac{841}{24}\approx35.04\)，但没有第 \(4.83\) 项，A 取不到。

比较两边的整数：\(S_4=52-18=34\)，\(S_5=65-30=35\)，最大值是 \(S_5=35\)。选 C 是把 \(4.83\) 直接截成了 \(4\)。从项看：\(13,10,7,4,1\) 都是正的，\(a_6=-2\)，加到第 \(5\) 项最大。

挑战

6. 等差数列 \(a_1=20\)，\(d=-2\)，\(S_n=54\)。\(n\) 是？

C。\(S_n=20n-n(n-1)=21n-n^2=54\)，即 \(n^2-21n+54=0\)，\((n-3)(n-18)=0\)。检验：两个根都是正整数，都要。

\(n=18\) 为什么也行：\(a_4=14\)，\(a_{18}=-14\)，从第 \(4\) 项到第 \(18\) 项正负抵消，和是 \(0\)，所以 \(S_{18}=S_3=54\)。只留一个的同学没把每个根都检验。

对比：若 \(S_n=100\)，\(n^2-21n+100=0\) 的根是 \(\dfrac{21\pm\sqrt{41}}{2}\)，不是整数，这个和取不到。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
