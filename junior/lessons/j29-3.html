29.3 弧长和扇形面积

弯曲的周长与展开的曲面！从摩天轮转过的弧长、折扇铺开的扇面切入，推导弧长公式 \(l = \frac{n\pi R}{180}\) 与扇形面积公式 \(S = \frac{n\pi R^2}{360} = \frac{1}{2}lR\)，玩转圆锥侧面展开图（母线等于扇形半径、底面周长等于扇形弧长），掌握割补法求解不规则阴影面积。

本节导读　先修：20.1 勾股定理 · 29.1 圆的有关概念 · 29.2 圆的有关性质 · 本节路线

要用到：勾股定理计算（回看 20.1）、圆的周长与圆心角性质（回看 29.1、回看 29.2）。

  1. 从摩天轮观光舱运行切入：旋转特定角度时，观光舱在空中划过的弯曲路程是多少？
  2. 掌握弧长公式推导：从圆周长 \(2\pi R\) 到 \(1^\circ\) 的弧长 \(\frac{\pi R}{180}\)，再到 \(n^\circ\) 的弧长公式 \(l = \frac{n\pi R}{180}\)；
  3. 掌握扇形面积公式推导：从圆面积 \(\pi R^2\) 到 \(S = \frac{n\pi R^2}{360}\)，以及类比三角形的 \(S = \frac{1}{2}lR\)；
  4. 理解圆锥侧面展开图的核心等量关系：展开扇形半径等于母线 \(l\)，展开扇形弧长等于底面圆周长 \(2\pi r\)；
  5. 动手交互实验：扇形圆心角与面积测算台、进阶圆锥与展开扇形联动台（含重置按钮）；
  6. 巩固练习与真题演练，吃透弧长与扇形面积计算、圆锥侧面展开问题。

摩天轮在空中缓缓转动，观光舱沿着巨大的圆弧轨迹上升。如果我们知道摩天轮的半径和转过的圆心角度数，怎样算出观光舱在空中走过的圆弧长度？

某景区摩天轮的轮盘半径为 \(R = 20\text{ m}\)，观光舱从最低点 \(A\) 出发逆时针匀速旋转。当观光舱旋转了 \(120^\circ\) 的圆心角到达点 \(B\) 时，观光舱在空中划过的圆弧路径长度是（ ）

B。摩天轮整周对应 \(360^\circ\)，圆周长为 \(C = 2\pi R = 2 \times \pi \times 20 = 40\pi\text{ m}\)。

旋转 \(120^\circ\) 所占整圆的比例为 \(\frac{120^\circ}{360^\circ} = \frac{1}{3}\)。因此，观光舱划过的弧长为 \(\frac{1}{3} \times 40\pi = \frac{40}{3}\pi\text{ m}\)。由此可见，弧长就是圆周长的一部分，比例正好等于圆心角占 \(360^\circ\) 的份额！

1. 先认识几个词：弧长、扇形与圆锥母线

扇形半径

扇形的两条边是圆的半径。

弧长

弧是圆周的一部分；长度和圆心角、半径都有关。

抓住关系： \(\color{#2F7A56}{\underbrace{S}_{\text{扇形面积}}}=\frac12\color{#966524}{\underbrace{l}_{\text{弧长}}}\,R\)

先检查条件，再使用关系；彩色标注帮助区分量。

前置知识：圆的周长与圆心角（回看 29.1、回看 29.2）。在半径为 \(R\) 的圆中，因为 \(360^\circ\) 的圆心角所对的弧长就是圆周长 \(C = 2\pi R\)，所以 \(1^\circ\) 的圆心角所对的弧长是 \(\frac{2\pi R}{360} = \frac{\pi R}{180}\)。由此得到 \(n^\circ\) 的圆心角所对的弧长公式：

  • 弧长公式：\[l = \frac{n\pi R}{180}\]
  • 注意事项：公式中的 \(n\) 表示 \(1^\circ\) 圆心角的倍数，计算时不带度数单位 \(^\circ\)；分母是约分后的 \(180\)。

直觉微图解 ①弧长公式推导：从 1° 份额到 n° 弧长

自己试试 1：已知 \(\odot O\) 的半径 \(R = 6\)，则 \(60^\circ\) 的圆心角所对的弧长是（ ）

B。直接应用弧长公式：\(l = \frac{n\pi R}{180} = \frac{60 \times \pi \times 6}{180} = 2\pi\)。

公式细究：为什么公式里的 \(n\) 不能带度数单位？

在弧长公式 \(l = \frac{n\pi R}{180}\) 中，圆心角的度数是 \(n^\circ\)。由于推导时我们把 \(n^\circ\) 与整圆的 \(360^\circ\) 做比值：\(\frac{n^\circ}{360^\circ} = \frac{n}{360}\)，度数单位 \(^\circ\) 已经在比值中相互抵消变成了纯比率。因此代入公式时 \(n\) 只取纯数字。

2. 扇形面积公式：角度比例与「曲边三角形」双视角

由组成圆心角的两条半径和圆心角所对的弧围成的图形叫作扇形（sector）。在半径为 \(R\) 的圆中，因为 \(360^\circ\) 的圆心角对应圆面积 \(\pi R^2\)，所以圆心角为 \(n^\circ\) 的扇形面积为：

  • 角度比例公式：\(S_{\text{扇形}} = \frac{n\pi R^2}{360}\)（注意分母是 \(360\)，且半径是 \(R^2\)）；
  • 弧长半径公式（类比三角形）：比较扇形面积公式与弧长公式 \(l = \frac{n\pi R}{180}\)，可得： \[S_{\text{扇形}} = \frac{1}{2}lR\] 把弧长 \(l\) 看作「底」，半径 \(R\) 看作「高」，形式与三角形面积 \(\frac{1}{2}\text{底}\times\text{高}\) 完全一致！

直觉微图解 ②扇形面积双公式：角度切分 vs 微小三角形拼接

自己试试 2：已知一个扇形的弧长为 \(4\pi\)，半径为 \(3\)，则该扇形的面积为（ ）

C。已知弧长 \(l = 4\pi\) 和半径 \(R = 3\)，直接套用 \(S = \frac{1}{2}lR = \frac{1}{2} \times 4\pi \times 3 = 6\pi\)，无需反求圆心角。

典例 1（波利亚四步法）：割补法求弓形（不规则阴影）面积

【例 1】水平放置的圆柱形排水管道截面半径为 \(R = 12\text{ cm}\)，其中水面高 \(h = 6\text{ cm}\)（水面在圆心下方），求截面上有水部分（弓形）的面积。

  1. ① 读懂题意：圆半径 \(OA = OB = 12\text{ cm}\)，水深 \(CD = 6\text{ cm}\)，水面为弦 \(AB\)，有水部分是劣弧 \(\widehat{ACB}\) 与弦 \(AB\) 围成的弓形，求弓形面积。
  2. ② 想办法：弓形面积无法直接套公式，采用「割补法」：\(S_{\text{弓形}} = S_{\text{扇形 }OAB} - S_{\triangle OAB}\)。为此需要先求出圆心角 \(\angle AOB\) 和弦长 \(AB\)。
  3. ③ 执行 + 执行中检查：连接 \(OA, OB\)，作 \(OD \perp AB\) 于 \(D\)，则 \(OD = OC - CD = 12 - 6 = 6\text{ cm}\)。在 \(\text{Rt}\triangle OAD\) 中，因为 \(OD = 6 = \frac{1}{2}OA\)，所以 \(\angle OAD = 30^\circ, \angle AOD = 60^\circ\)，故圆心角 \(\angle AOB = 120^\circ\)。由勾股定理得 \(AD = \sqrt{12^2 - 6^2} = 6\sqrt{3}\text{ cm}\)，弦长 \(AB = 12\sqrt{3}\text{ cm}\)（检查：\(S_{\triangle OAB} = \frac{1}{2} \times 12\sqrt{3} \times 6 = 36\sqrt{3}\text{ cm}^2\)）。扇形面积 \(S_{\text{扇形 }OAB} = \frac{120\pi \times 12^2}{360} = 48\pi\text{ cm}^2\)。故有水部分面积 \(S = (48\pi - 36\sqrt{3})\text{ cm}^2\)。
  4. ④ 回头看：求圆中阴影面积的核心心法是「化不规则为规则」——把弓形拆成「扇形与三角形的差（或和）」。

3. 圆锥的侧面积与全面积：三维曲面展开为平面扇形

连接圆锥顶点 \(S\) 与底面圆周上任意一点的线段叫作圆锥的母线（长记为 \(l\)），连接顶点与底面圆心的垂线段叫作圆锥的高（\(h\)）。沿一条母线将圆锥侧面剪开铺平，得到一个平面扇形：

  • 勾股定理关系：底面半径 \(r\)、高 \(h\) 与母线 \(l\) 构成直角三角形：\(r^2 + h^2 = l^2\)；
  • 半径对应：侧面展开图扇形的半径 等于圆锥的母线长 \(l\)；
  • 弧长对应：侧面展开图扇形的弧长 等于圆锥底面圆的周长 \(2\pi r\)；
  • 侧面积与全面积：\(S_{\text{侧}} = \frac{1}{2} \times (2\pi r) \times l = \pi r l\)，\(S_{\text{全}} = \pi r l + \pi r^2\)；
  • 展开圆心角公式：由 \(\frac{n\pi l}{180} = 2\pi r\) 得 \(\frac{n}{360} = \frac{r}{l}\)，即 \(n = \frac{r}{l} \times 360\)。

直觉微图解 ③圆锥侧面展开双桥梁：母线变扇形半径，底面周长变弧长

自己试试 3：已知圆锥的底面半径 \(r = 3\)，母线长 \(l = 5\)，则该圆锥的侧面积为（ ）

A。圆锥侧面积公式为 \(S_{\text{侧}} = \pi r l = \pi \times 3 \times 5 = 15\pi\)。若求全面积（表面积），再加上底面积 \(\pi r^2 = 9\pi\)，全面积为 \(24\pi\)。

典例 2（波利亚四步法）：圆锥侧面展开图求母线与圆锥高

【例 2】用一个半径为 \(10\text{ cm}\)、圆心角为 \(216^\circ\) 的扇形纸片围成一个圆锥的侧面（接缝忽略不计），求这个圆锥的底面圆半径 \(r\) 和圆锥的高 \(h\)。

  1. ① 读懂题意：已知展开扇形的半径即圆锥母线 \(l = 10\text{ cm}\)，扇形圆心角 \(n = 216^\circ\)，求围成圆锥后的底面半径 \(r\) 和高 \(h\)。
  2. ② 想办法：先利用「底面圆周长等于展开扇形弧长」\(2\pi r = \frac{n\pi l}{180}\) 求出底面半径 \(r\)，再在圆锥轴截面直角三角形中由勾股定理 \(h = \sqrt{l^2 - r^2}\) 求出高 \(h\)。
  3. ③ 执行 + 执行中检查：由 \(2\pi r = \frac{216\pi \times 10}{180}\)（或 \(\frac{r}{10} = \frac{216}{360} = \frac{3}{5}\)），解得 \(r = 6\text{ cm}\)（检查：底面周长 \(12\pi\text{ cm}\)，扇形弧长 \(\frac{216}{180}\times 10\pi = 12\pi\text{ cm}\)，完全相等）。再由勾股定理得圆锥的高 \(h = \sqrt{l^2 - r^2} = \sqrt{10^2 - 6^2} = 8\text{ cm}\)。
  4. ④ 回头看：解决圆锥与展开图互化问题，牢牢抓住「扇形半径 \(=\) 母线 \(l\)」和「\(\frac{r}{l} = \frac{n}{360}\)」即可秒解。
秒杀秘诀：圆锥底面半径 \(r\)、母线 \(l\) 与展开扇形圆心角 \(n\) 的比例关系

由「展开扇形弧长等于圆锥底面圆周长」\(\frac{n\pi l}{180} = 2\pi r\)，两边同除以 \(2\pi l\) 立得黄金比例式：\[\frac{r}{l} = \frac{n}{360}\]也就是说，圆锥底面半径占母线的几分之几，侧面展开扇形的圆心角就占周角 \(360^\circ\) 的几分之几！例如当 \(l = 2r\) 时，侧面展开图必定是一个半圆（\(n = 180^\circ\)）。

用之前必查：三大翻车现场

翻车 1
错误：扇形面积只看角度
核对：圆心角相同、半径不同的扇形面积不同。
翻车 2
错误：圆锥展开扇形半径是底面半径
核对：展开扇形半径是母线长；弧长等于底面周长。
翻车 3
错误：先四舍五入弧长再求面积是精确值
核对：先用精确弧长计算，最后才按要求取近似值。

练习 1：已知扇形的半径 \(R = 4\)，圆心角为 \(90^\circ\)，则该扇形的弧长为（ ）

B。应用弧长公式：\(l = \frac{90 \times \pi \times 4}{180} = 2\pi\)。

练习 2：已知一个扇形的面积为 \(12\pi\)，圆心角为 \(120^\circ\)，则该扇形的半径 \(R\) 为（ ）

C。由扇形面积公式 \(S = \frac{n\pi R^2}{360}\)，代入数据得 \(12\pi = \frac{120\pi R^2}{360} = \frac{1}{3}\pi R^2\)，解得 \(R^2 = 36 \implies R = 6\)。

练习 3：已知圆锥的底面半径为 \(2\)，高为 \(\sqrt{5}\)，则该圆锥的侧面积是（ ）

A。由勾股定理得母线长 \(l = \sqrt{r^2 + h^2} = \sqrt{2^2 + (\sqrt{5})^2} = 3\)。因此圆锥的侧面积为 \(S_{\text{侧}} = \pi r l = \pi \times 2 \times 3 = 6\pi\)。

练习 4：已知一个扇形的弧长是 \(6\pi\)，面积是 \(18\pi\)，则该扇形的半径是（ ）

D。直接应用公式 \(S = \frac{1}{2}lR\)：代入得 \(18\pi = \frac{1}{2} \times (6\pi) \times R = 3\pi R\)，解得 \(R = 6\)。

练习 5：已知圆锥的底面半径为 \(3\text{ cm}\)，母线长为 \(4\text{ cm}\)，则这个圆锥的全面积（表面积）是（ ）

提示

全面积等于侧面积 \(\pi r l\) 加上底面圆面积 \(\pi r^2\)，别漏掉底面圆！

C。侧面积 \(S_{\text{侧}} = \pi r l = \pi \times 3 \times 4 = 12\pi\text{ cm}^2\)，底面积 \(S_{\text{底}} = \pi r^2 = \pi \times 3^2 = 9\pi\text{ cm}^2\)，故全面积 \(S_{\text{全}} = 12\pi + 9\pi = 21\pi\text{ cm}^2\)。

易错提醒：圆锥的“底面半径”与“展开扇形半径”千万别搞混！

圆锥底面圆的半径记为 \(r\)，展开扇形的半径是圆锥的母线记为 \(l\)。计算侧面积时公式是 \(\pi r l\)；审题时还要看清题目求的是「侧面积」还是「全面积（含底面圆 \(\pi r^2\)）」。

巩固练习 1：已知扇形的半径为 \(6\)，圆心角为 \(60^\circ\)，则该扇形的弧长为（　）

B。根据弧长公式 \(l = \frac{n\pi R}{180}\)，将 \(n = 60\)，\(R = 6\) 代入，得 \(l = \frac{60 \times \pi \times 6}{180} = 2\pi\)，故选 B．

巩固练习 2：若扇形的圆心角为 \(120^\circ\)，半径为 \(3\sqrt{2}\)，则该扇形的面积为（　）

C。由扇形面积公式 \(S = \frac{n\pi R^2}{360}\)，将 \(n = 120\)，\(R = 3\sqrt{2}\) 代入，注意 \(R^2 = (3\sqrt{2})^2 = 18\)，故 \(S = \frac{120 \times \pi \times 18}{360} = 6\pi\)，故选 C．

巩固练习 3：已知圆锥的底面半径 \(r = 3\text{ cm}\)，高 \(h = 4\text{ cm}\)，则这个圆锥的侧面积为（　）

B。圆锥的底面半径 \(r = 3\text{ cm}\)、高 \(h = 4\text{ cm}\) 与母线长 \(l\) 构成直角三角形，由勾股定理得母线长 \(l = \sqrt{r^2 + h^2} = \sqrt{3^2 + 4^2} = 5\text{ cm}\)．根据圆锥侧面积公式 \(S_{\text{侧}} = \pi r l\)，得 \(S_{\text{侧}} = \pi \times 3 \times 5 = 15\pi\text{ cm}^2\)，故选 B．

巩固练习 4：若圆锥的底面半径为 \(2\text{ cm}\)，母线长为 \(6\text{ cm}\)，则该圆锥侧面展开图扇形的圆心角度数为______\(^\circ\)．

查看答案与解析，自行核对

答案：\(120\)

圆锥底面圆的周长等于侧面展开图扇形的弧长．设展开图扇形的圆心角为 \(n^\circ\)，则 \(2\pi \times 2 = \frac{n\pi \times 6}{180}\)，即 \(4\pi = \frac{n\pi}{30}\)，解得 \(n = 120\)．
