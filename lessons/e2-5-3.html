5.3 导数在研究函数中的应用

导数是正还是负，告诉我们函数在往上走还是往下走。这一节用导数的符号判断单调性，找极大值、极小值，并在闭区间上求最大值和最小值。

在研究函数时，我们常常需要确定它的递增与递减区间。直观上，「切线斜率大于 0」意味着曲线向上爬升：

如果可导函数 \(f(x)\) 在区间 \((a, b)\) 上满足 \(f'(x) \ge 0\)，能不能直接断言函数 \(f(x)\) 在 \((a, b)\) 上严格单调递增？

B。必须排除局部常数区间！

例如常数函数 \(f(x) = 5\)，其导数 \(f'(x) \equiv 0 \ge 0\)，但函数值始终是 5，没有发生任何递增。

严格的数学定理是：若 \(f'(x) > 0\)，则函数必定单调递增；而当 \(f'(x) \ge 0\) 时，只有在导数等于 0 的点只是孤立散点（如 \(f(x) = x^3\) 在 \(x=0\)）的前提下，才能断言函数严格单调递增！

这一节我们就来系统建立单调性判定法则、极值点搜寻机制与闭区间最值求解标准程序。

1. 先认识几个词

要用到：5.1 导数的意义（导数是切线斜率，回看 5.1）；5.2 求导公式（回看 5.2）；必修一里函数单调性的定义。

单调区间：函数在这一段上一直增（或一直减），这一段就是它的单调递增（递减）区间。

例：\(f(x)=x^2\) 在 \((-\infty,0)\) 上递减，在 \((0,+\infty)\) 上递增。

驻点：使 \(f'(x)=0\) 的点，这里切线是水平的。

例：\(f(x)=x^2-4x\)，\(f'(x)=2x-4\)，令它等于 \(0\) 得驻点 \(x=2\)。

极值点与极值：在 \(x_0\) 附近，\(f(x_0)\) 比旁边的值都大（都小），\(x_0\) 叫极大（极小）值点，\(f(x_0)\) 叫极大（极小）值。点是横坐标 \(x\)，值是函数值 \(y\)，别混。

例：\(f(x)=(x-1)^2+3\) 的极小值点是 \(x=1\)，极小值是 \(f(1)=3\)。

最值：在整个给定区间上最大（最小）的函数值。极值只和「附近」比，最值和「全区间」比。

例：\(f(x)=x^2\) 在 \([-1,2]\) 上，极小值是 \(f(0)=0\)，也是最小值；最大值却是端点值 \(f(2)=4\)。

2. 用导数判断单调性

导数是切线斜率。在一段区间里切线一直往上斜（\(f'(x)>0\)），曲线就一直往上走；一直往下斜（\(f'(x)<0\)），曲线就一直往下走。

在区间内 \(f'(x)>0\) ⇒ \(f(x)\) 在这个区间上单调递增；\(f'(x)<0\) ⇒ 单调递减。
反过来只能推出 \(f'(x)\ge0\)（或 \(\le0\)）：\(x^3\) 在 \(\mathbf{R}\) 上递增，但 \(f'(0)=0\)。

做题顺序固定：定义域 → 求导 → 解 \(f'(x)>0\)、\(f'(x)<0\) → 写结论。定义域放第一步，因为区间只能在定义域里取。

例 1（看一遍怎么写）

求 \(f(x)=x-2\ln x\) 的单调区间。

定义域：\(\ln x\) 要求 \(x>0\)，即 \((0,+\infty)\)。

求导：\(f'(x)=1-\dfrac{2}{x}=\dfrac{x-2}{x}\)。

判号：在 \((0,+\infty)\) 上分母 \(x>0\)，符号只看 \(x-2\)。

\(0<x<2\) 时 \(f'(x)<0\)；\(x>2\) 时 \(f'(x)>0\)。

结论：单调递减区间 \((0,2)\)，单调递增区间 \((2,+\infty)\)。

如果忘了定义域，会写出「在 \((-\infty,0)\) 上……」，可那里 \(\ln x\) 根本没有意义。

自己试试：函数 \(f(x)=x-\mathrm{e}^x\) 的单调递增区间是？

A。\(f'(x)=1-\mathrm{e}^x\)。\(f'(x)>0\iff \mathrm{e}^x<1\iff x<0\)。选 B 是把不等号方向弄反了（那是递减区间）；选 C 是把 \(\mathrm{e}^x<1\) 当成了 \(x<1\)，其实 \(\mathrm{e}^0=1\)，分界点是 \(0\)。

3. 极值：导数为 0 只是必要条件，要看两侧变号

山顶处曲线先上后下：左边 \(f'>0\)，右边 \(f'<0\)，正中间切线水平。所以可导函数在内部某点取极值，那里一定有 \(f'(x_0)=0\)。但反过来不行：\(x^3\) 在 \(0\) 处切线也水平，两边却都在往上走，不是山顶也不是谷底。

设 \(f'(x_0)=0\)：左正右负 ⇒ 极大值点；左负右正 ⇒ 极小值点；两侧同号 ⇒ 不是极值点。

所以求极值要列表看两侧符号，不能解出 \(f'(x)=0\) 就停。

例 2

求 \(f(x)=2x^3-3x^2-12x+5\) 的单调区间和极值。

定义域 \(\mathbf{R}\)。求导并因式分解：

$$f'(x)=6x^2-6x-12=6(x+1)(x-2)$$

令 \(f'(x)=0\)，得 \(x=-1\) 或 \(x=2\)。列表：

\(x\)\(f'(x)\)\(f(x)\)
\((-\infty,-1)\)\(+\)递增 ↗
\(-1\)\(0\)极大值 \(12\)
\((-1,2)\)\(-\)递减 ↘
\(2\)\(0\)极小值 \(-15\)
\((2,+\infty)\)\(+\)递增 ↗

极大值 \(f(-1)=-2-3+12+5=12\)；

极小值 \(f(2)=16-12-24+5=-15\)。

单调递增区间 \((-\infty,-1)\) 和 \((2,+\infty)\)，单调递减区间 \((-1,2)\)。

自己试试：函数 \(f(x)=x^3-3x^2+1\) 的极小值是？

A。\(f'(x)=3x^2-6x=3x(x-2)\)，驻点 \(0\) 和 \(2\)。\(x<0\) 时 \(f'>0\)，\(0<x<2\) 时 \(f'<0\)，\(x>2\) 时 \(f'>0\)，所以 \(x=2\) 是极小值点，极小值 \(f(2)=8-12+1=-3\)。选 B 是把极小值点当成了极小值；选 C 是 \(f(0)=1\)，那是极大值；选 D 是极大值点。

4. 闭区间上的最大值与最小值

在闭区间 \([a,b]\) 上连续的函数一定有最大值和最小值。它们要么在区间内部的山顶、谷底（极值点），要么在两个端点。所以把这些候选都算出来比一比就行：

① 求 \((a,b)\) 内的驻点，算出这些点的函数值；② 算端点值 \(f(a)\)、\(f(b)\)；③ 全部比较，最大的是最大值，最小的是最小值。

不在区间里的驻点不算；端点一个都不能漏。

例 3（接例 2）

求 \(f(x)=2x^3-3x^2-12x+5\) 在 \([-2,3]\) 上的最大值和最小值。

驻点 \(-1\) 和 \(2\) 都在 \((-2,3)\) 内：\(f(-1)=12\)，\(f(2)=-15\)。

端点：\(f(-2)=-16-12+24+5=1\)；

\(f(3)=54-27-36+5=-4\)。

比较 \(1,\ 12,\ -15,\ -4\)：最大值 \(12\)（\(x=-1\) 处），最小值 \(-15\)（\(x=2\) 处）。

这一次最值恰好都在极值点上；换个区间就不一定，比如 \([-2,4]\) 上 \(f(4)=37\)，最大值就跑到了端点。

自己试试：\(f(x)=x^3-12x\) 在 \([-3,5]\) 上的最大值和最小值是？

B。\(f'(x)=3x^2-12=3(x+2)(x-2)\)，驻点 \(\pm2\) 都在区间内：\(f(-2)=16\)，\(f(2)=-16\)。端点 \(f(-3)=-27+36=9\)，\(f(5)=125-60=65\)。比较 \(9,16,-16,65\)：最大 \(65\)，最小 \(-16\)。选 A 是只看了极值、忘了端点；选 C、D 是只看了端点。

5. 用之前要注意

  1. \(f'(x)\ge0\) 不能直接说严格递增，要排除导数恒为 \(0\) 的一整段。
    反例：\(f(x)=5\)，\(f'(x)=0\ge0\)，但函数根本没变。只在孤立的点上 \(f'=0\)（如 \(x^3\) 在 \(0\) 处）才仍是严格递增。
  2. 单调区间按定义域的断点分开写，不能用 \(\cup\) 合并。
    反例：\(y=\dfrac1x\) 在 \((-\infty,0)\) 和 \((0,+\infty)\) 上分别递减，但 \(-1<1\) 时 \(f(-1)=-1<1=f(1)\)，在并集上并不递减。
  3. \(f'(x_0)=0\) 后必须看两侧变不变号。
    反例：\(f(x)=x^3\)，\(f'(0)=0\)，两侧 \(f'>0\)，\(0\) 不是极值点。
  4. 极值是局部的，极大值不一定比极小值大。
    反例：\(f(x)=x+\dfrac1x\)，极大值 \(f(-1)=-2\)，极小值 \(f(1)=2\)，极大值反而更小。
  5. 闭区间求最值，端点必须算（例 3 后面的 \([-2,4]\)）。
  6. 开区间上不能默认有最值。
    反例：\(f(x)=x\) 在 \((0,1)\) 上越来越接近 \(1\)，但取不到，没有最大值，也没有最小值。

自己试试：下列关于极值与最值的说法中，正确的是：

C。极值只和附近比，上面第 4 条的 \(x+\dfrac1x\) 就是例子，所以 A 错。B 后半句不对，\(x^3\) 在 \(0\) 处导数为 \(0\) 却不是极值点。D：极值点要求两侧都有函数值可比，必须在区间内部，端点只能参与比最值。

再深一点（可以先跳过）

用单调性证不等式：证 \(\mathrm{e}^x\ge x+1\)。设 \(g(x)=\mathrm{e}^x-x-1\)，\(g'(x)=\mathrm{e}^x-1\)，\(x<0\) 时递减、\(x>0\) 时递增，最小值 \(g(0)=0\)，所以 \(g(x)\ge0\)，等号只在 \(x=0\) 取到。

实际优化：先建模，写出自变量的实际范围（长度为正、件数为整数等），再在这个范围里求最值，最后检查结果说不说得通。

课本不默认用的工具：二阶导数判极值、凹凸性、洛必达法则、拉格朗日中值定理都不是本章要求的依据；解答里用导数的符号和单调表说清楚就够了。

三次多项式单调性与极值全景透视仪

考察函数 \(f(x) = \dfrac{1}{3}x^3 - a x\)（\(a > 0\) 时导数有两个零点 \(x = \pm\sqrt{a}\)）。调节参数 \(a\) 观察峰谷开合，拖动区间滑块观察极大值、极小值与端点值如何竞争全局最值：

1.6 -2.2 2.4

直接用

1. 函数 \(f(x) = x^3 - 3x\) 的单调递减区间是：

A。求导：\(f'(x) = 3x^2 - 3 = 3(x+1)(x-1)\)。令 \(f'(x) < 0 \implies x^2 < 1 \implies -1 < x < 1\)。因此单调递减区间为 \((-1, 1)\)。

2. 函数 \(f(x) = x^3 - 12x + 1\) 的极大值等于：

B。求导：\(f'(x) = 3x^2 - 12 = 3(x+2)(x-2)\)。当 \(x < -2\) 时 \(f'(x) > 0\)，当 \(-2 < x < 2\) 时 \(f'(x) < 0\)。因此 \(x = -2\) 是极大值点。极大值为 \(f(-2) = (-2)^3 - 12(-2) + 1 = -8 + 24 + 1 = 17\)。

易错

3. 函数 \(f(x) = x^3\) 在 \(\mathbf{R}\) 上满足 \(f'(0) = 0\)，则点 \(x = 0\)：

D。求导 \(f'(x) = 3x^2\)。当 \(x \ne 0\) 时恒有 \(f'(x) > 0\)。\(x = 0\) 两侧导数均为正数，导数并没有发生变号！因此函数在 \(x=0\) 处一直在递增爬升，不是极值点。必须死守：导数等于 0 且变号才是极值点！

4. 函数 \(f(x) = x^3 - 3x\) 在闭区间 \([0, 2]\) 上的最大值和最小值分别是：

C。求导 \(f'(x) = 3x^2 - 3 = 0 \implies x = 1 \in [0, 2]\)。极小值 \(f(1) = 1 - 3 = -2\)。计算两端点值：左端点 \(f(0) = 0\)；右端点 \(f(2) = 2^3 - 3(2) = 8 - 6 = 2\)。比对候选池 \(\{f(0)=0, \; f(1)=-2, \; f(2)=2\}\)：最大值为 \(2\)，最小值为 \(-2\)。

挑战进阶

5. 已知函数 \(f(x) = x^3 + ax\) 在 \(\mathbf{R}\) 上单调递增，则实数 \(a\) 的取值范围是：

A。函数在 \(\mathbf{R}\) 上递增，则其导数恒满足 \(f'(x) = 3x^2 + a \ge 0\)。对任意实数 \(x\)，\(3x^2 \ge 0\)，因此只需 \(a \ge 0\)。注意 \(a = 0\) 时 \(f(x) = x^3\) 依然严格递增，所以等号必须取到！范围为 \([0, +\infty)\)。
