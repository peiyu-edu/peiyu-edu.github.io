7.2 离散型随机变量及其分布列

给试验的每个结果配上一个数，再把「每个数出现的概率」列成一张表。从此研究随机现象，就是研究这张表。

同时掷两枚骰子，把两个点数加起来。玩过大富翁的同学可能有感觉：有的和经常出现，有的很少见。先点下面的按钮或柱子，看看 \(36\) 种点数对按「点数和」叠起来是什么形状：

两个点数的和，下面哪个最容易出现？

C。两枚骰子一共 \(6\times6=36\) 种结果，等可能。和为 \(7\) 的有 \((1,6),(2,5),(3,4),(4,3),(5,2),(6,1)\) 共 \(6\) 种；和为 \(6\) 的有 \(5\) 种；和为 \(2\) 只有 \((1,1)\)，和为 \(12\) 只有 \((6,6)\)。

刚才做了两件事：给 \(36\) 个结果每个配上一个数（点数和），再数出每个数的概率。前一件叫「随机变量」，后一件列成表叫「分布列」。这一节就讲这两样。

1. 先认识几个词

要用到：必修二 10.1 概率与样本空间（回看 10.1）；6.2 组合数（回看 6.2）。离散型随机变量是将随机试验的离散结果数值化。

课本用词：分布列中的概率都非负且总和为 1；随机变量是给结果赋值的函数，不是结果本身，先列全结果再合并同值取值。

随机变量 \(X\)（结果的实数化映射）：随机试验的结果往往是文字（如「正面」「反面」「红球」「中奖」），为了能用数学公式进行分析，我们将每个样本点映射为一个实数，这个变量就叫随机变量。

例：抛 2 枚硬币，结果有「正正、正反、反正、反反」4 种，设 \(X\) 为正面朝上的次数，则 \(X\) 的取值为 \(0, 1, 2\)。

离散型随机变量：所有可能取的值可以一一列举出来（有限个或可列无限个）的随机变量。

对比：射击命中的环数（\(0,1,\dots,10\)）是离散型；而灯泡的使用寿命（\([0, +\infty)\) 内任意实数）是连续型。

分布列（概率全貌表）：把随机变量 \(X\) 的全部可能取值与其对应发生的概率一一配对制成的表格。

两条不可逾越的铁律：
① 非负性：每个概率 \(p_i \ge 0\)；
② 归一性：所有取值的概率之和严格等于 \(1\)，即 \(\sum p_i = 1\)（无重无漏全覆盖）。

两点分布（0-1 分布） 非此即彼

场景：试验结果只有对立的两种（成功或失败、中奖或没中）。

分布列：\(P(X=1) = p,\; P(X=0) = 1-p\)。

特质：最基础的原子分布，是二项分布的砖瓦单元。

超几何分布（不放回抽样） 古典概型

场景：总数 \(N\) 件含 \(M\) 件特品，不放回随机抽 \(n\) 件，抽到特品数 \(X\)。

公式：\(P(X=k) = \dfrac{C_M^k C_{N-M}^{n-k}}{C_N^n}\)。

特质：古典概型组合数的标准化套用，注意极值边界。

2. 分布列表格形态与核心性质公式

分布列形态与两大铁律：

标准表格：

\(X\)\(\color{#1976d2}{x_1}\)\(\color{#1976d2}{x_2}\)\(\cdots\)\(\color{#1976d2}{x_n}\)
\(P\)\(\color{#2e7d32}{p_1}\)\(\color{#2e7d32}{p_2}\)\(\cdots\)\(\color{#2e7d32}{p_n}\)

① 非负性：\(\color{#2e7d32}{p_i \ge 0}\qquad (i = 1, 2, \dots, n)\)

② 归一性：\(\sum_{i=1}^n \color{#2e7d32}{p_i} = \color{#2e7d32}{p_1 + p_2 + \cdots + p_n = 1}\quad (\text{必查自检项！})\)

自己试试：掷一枚骰子，点数是奇数时记 \(X=1\)，是偶数时记 \(X=0\)。\(X\) 有几个可能的取值？

A。取值只有 \(0\) 和 \(1\)：\(1,3,5\) 三个样本点都对应 \(1\)，\(2,4,6\) 都对应 \(0\)。选 C 的同学数的是样本点，不是取值。

自己试试：\(X\) 的分布列中，\(X\) 取 \(-1,0,1\) 的概率分别是 \(0.2,\ a,\ 0.5\)。\(a=\)？

B。\(0.2+a+0.5=1\)，\(a=0.3\)。选 C 的同学只用 \(1\) 减了 \(0.5\)，漏了 \(0.2\)。

3. 三步破题思维链例题

典型例题：一个袋中装有 5 个大小质地完全相同的小球，其中 3 个红球，2 个白球。从中不放回地随机取出 3 个球，设取出红球的个数为 \(X\)。求 \(X\) 的分布列。

👀 第一眼破题信号： 不放回抽样中特定球的件数 \(\Longrightarrow\) 超几何分布！先确定总体参数：\(N = 5\)，红球总数 \(M = 3\)，抽取球数 \(n = 3\)。再排查 \(X\) 的可能取值范围：因为总共才 2 个白球，抽 3 个球必须至少含有 1 个红球（\(3 - 2 = 1\)），最多可抽到 3 个红球，因此 \(X\) 的取值只能是 \(\color{#2563eb}{1, 2, 3}\)（绝不可能为 0）！
🔧 第二步套用超几何公式逐点计算：
基本事件总数：\(C_5^3 = 10\) 种。
• \(P(X=1) = \dfrac{C_3^1 C_2^2}{C_5^3} = \dfrac{3 \times 1}{10} = \dfrac{3}{10} = 0.3\)；
• \(P(X=2) = \dfrac{C_3^2 C_2^1}{C_5^3} = \dfrac{3 \times 2}{10} = \dfrac{6}{10} = 0.6\)；
• \(P(X=3) = \dfrac{C_3^3 C_2^0}{C_5^3} = \dfrac{1 \times 1}{10} = \dfrac{1}{10} = 0.1\)。
🛡️ 第三步归一性自查与表格列出： 求和验证：\(0.3 + 0.6 + 0.1 = 1.0\)，不多不少正好归一！
列出完整分布列：
\(X\)123
\(P\)0.30.60.1

自己试试：掷两枚骰子，\(X\) 表示两个点数中较大的那个（相同就取它）。\(P(X=2)=\)？

C。较大点数是 \(2\) 的样本点：\((1,2),(2,1),(2,2)\)，共 \(3\) 个，\(P=\dfrac3{36}=\dfrac1{12}\)。选 B 的同学漏了 \((2,2)\)；选 A 的只想到了 \((2,2)\)。

4. 三大翻车现场红绿对比卡

翻车现场 1：盲目照抄惯性取值，写出不存在的边界值（\(X=0\) 陷阱）

❌ 翻车：5 球中有 3 红 2 白，抽 3 个球，不假思索认为红球数 \(X\) 可以取 \(0, 1, 2, 3\)。

✔ 正确：极端值必须做物理可行性检验！袋中总共只有 2 个白球，就算把白球全部抽走，第 3 个也必须是红球。因此红球数至少为 1，\(X\) 取值只有 \(\{1, 2, 3\}\)！若多写 \(X=0\) 会导致分布列整体错乱。

翻车现场 2：算完各点概率不做归一性检查，带着错误交卷

❌ 翻车：各点概率算出后，和为 0.9 或 1.1，未做自检直接下笔写后续期望方差，全盘连环扣分。

✔ 正确：\(\sum p_i = 1\) 是大题中免费的天然验算器！一旦求和不等于 1，立刻回溯是漏掉了某个取值，还是组合数分母算错，5 秒钟挽救整道大题！

翻车现场 3：把「样本点个数」与「随机变量取值个数」混淆

❌ 翻车：投掷一颗骰子，记出现奇数为 1，偶数为 0。认为 \(X\) 有 6 个可能取值。

✔ 正确：样本点有 6 个（\(1,2,3,4,5,6\)），但随机变量的取值是映射后的实数，只有 \(0\) 和 \(1\) 这 2 个值！多个样本点可以映射到同一个实数值。

反例微图解：概率归一性（各柱累加填满 100% 矩形）直觉
归一性检验：各概率条拼合必须严丝合缝填满高度为 1 的单位柱，若出现间隙（<1）或溢出（>1）则必有计算疏漏。

① 两枚骰子：选一个随机变量，看分布列

先选 \(X\) 是什么。方格是 \(36\) 个样本点，格里的数是这个样本点对应的 \(X\) 值。点一个格子（或拖着走，或选中方格后按方向键），同一个取值的格子会一起亮起来，下面对应的柱子也亮。柱子也能点。

② 进阶：对 \(X\) 做变换，相同取值合并

\(X\) 还是两枚骰子的点数和，上排是它的 \(11\) 个取值，下排是 \(Y\) 的取值，连线表示「这个 \(X\) 变成这个 \(Y\)」。数字是样本点个数（除以 \(36\) 就是概率）。点下排的点（或选中图后按左右键），看哪几个 \(X\) 合并到了一起。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(X\) 取 \(1,2,3,4\) 的概率分别是 \(0.1,\ 0.3,\ m,\ 0.2\)。\(P(X\ge3)=\)？

C。先由总和为 \(1\)：\(m=1-0.1-0.3-0.2=0.4\)。\(\{X=3\}\) 与 \(\{X=4\}\) 互斥，\(P(X\ge3)=0.4+0.2=0.6\)。选 B 的同学只算了 \(P(X=3)\)；选 A 的只算了 \(P(X=4)\)。

2. 抛三枚硬币，\(X\) 表示正面朝上的枚数。\(P(X\ge1)=\)？

D。共 \(8\) 个等可能样本点，\(X=0\) 只有「反反反」一个，\(P(X=0)=\dfrac18\)。\(P(X\ge1)=1-\dfrac18=\dfrac78\)。选 C 的同学把 \(0,1,2,3\) 四个取值当成等可能，算成了 \(\dfrac34\)。

易错

3. 盒里有标着 \(1,2,3,4\) 的四张卡片，一次抽两张，\(X\) 是两数之和。\(P(X=5)=\)？

C。样本点是 \(C_4^2=6\) 种抽法：\(\{1,2\},\{1,3\},\{1,4\},\{2,3\},\{2,4\},\{3,4\}\)，和分别是 \(3,4,5,5,6,7\)。和为 \(5\) 的有 \(2\) 个，\(P(X=5)=\dfrac26=\dfrac13\)。

选 B 的同学看到 \(X\) 有 \(3,4,5,6,7\) 五个取值，就当每个 \(\dfrac15\)：取值个数不是等可能样本点的个数。选 A 的同学只数到了一种抽法。

4. \(X\) 取 \(-2,-1,0,1,2\) 的概率分别是 \(0.1,\ 0.2,\ 0.4,\ 0.2,\ 0.1\)，\(Y=X^2\)。\(P(Y=1)=\)？

B。\(Y=1\) 来自 \(X=-1\) 和 \(X=1\) 两个取值，要合并：\(P(Y=1)=0.2+0.2=0.4\)。\(Y\) 的分布列只有三列：\(P(Y=0)=0.4\)，\(P(Y=1)=0.4\)，\(P(Y=4)=0.2\)，和为 \(1\)。选 A 的同学只抄了一个 \(0.2\)，没合并。

5. 下面四组数分别作为 \(X\) 取 \(1,2,3\) 的概率，哪一组能构成分布列？

C。两条都要查。A 加起来是 \(1.1\)；B 加起来是 \(1\)，但有负数 \(-0.1\)，只查总和就会误选它；D 都非负，但和只有 \(0.9\)。C：\(\dfrac36+\dfrac26+\dfrac16=1\)，都非负。

挑战

6. 小林投篮，每次命中的概率都是 \(0.6\)，各次互不影响。投中就停，最多投 \(3\) 次。\(X\) 表示投篮的次数，\(P(X=3)=\)？

B。先列全取值：\(X=1,2,3\)。\(P(X=1)=0.6\)；\(P(X=2)=0.4\times0.6=0.24\)；投到第 \(3\) 次，只要前两次都没中，第 \(3\) 次中不中都停，所以 \(P(X=3)=0.4\times0.4=0.16\)。

核查：\(0.6+0.24+0.16=1\)。选 A 的同学算的是「第 3 次才投中」\(0.4^2\times0.6\)，漏了第 3 次没中的情形，那样三项加起来只有 \(0.936\)，核查就能发现。选 D 是 \(0.4^3\)，那是「三次都没中」，只是 \(X=3\) 的一部分。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
