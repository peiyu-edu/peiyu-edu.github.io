为什么成立，边界在哪里

平方函数 f(x)=x² 在实数域上严格凸，f″(x)=2>0，所以任意接触点 a 的切线 Tₐ(x)=a²+2a(x−a) 给出下界：x² ≥ Tₐ(x)，等号仅当 x=a。图中截取 −2 ≤ x ≤ 2。

对数函数 f(x)=ln x 的定义域为 x>0，f″(x)=−1/x²<0，严格凹；切线 Tₐ(x)=ln a+(x−a)/a 给出上界：ln x ≤ Tₐ(x)，等号仅当 x=a。图中截取 0.25 ≤ x ≤ 4。

依据：f(x)−Tₐ(x) 是从 a 到 x 对 f′(t)−f′(a) 的积分；导数单调方向决定差的符号。一般函数若改变凸凹性，不能照搬全域单侧界。
