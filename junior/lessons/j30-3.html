机械工程师设计正六边形螺母截面，将一个圆周六等分，顺次连接各等分点得到正六边形。已知正六边形每个边所对的圆心角（中心角）等于（ ）

C。整个圆周角为 \(360^\circ\)。把圆周 \(n\) 等分，每个中心角的度数严格等于 \(\frac{360^\circ}{n}\)。

对于正六边形，中心角为 \(\frac{360^\circ}{6} = 60^\circ\)；正三角形中心角为 \(\frac{360^\circ}{3} = 120^\circ\)；正方形中心角为 \(\frac{360^\circ}{4} = 90^\circ\)。正多边形正是由圆周的完美等分自然孕育而生的！

在自然界与人类工程中，正六边形的蜂巢、正五边形的花瓣、正多边形螺母无处不在。 正多边形之所以具备最高级别的几何对称性，根本原因在于它与圆的密不可分： 任何一个正多边形，既有一个将它完美外包的“外接圆”，也有一个被它紧紧内夹的“内切圆”，并且这两个圆拥有同一个圆心！

1. 先认识几个词：中心、半径、中心角与边心距

外接圆半径

从多边形中心到顶点的距离。

边心距

从中心到一条边的距离，垂足在边上。

抓住关系： \(\color{#2F7A56}{\underbrace{S}_{\text{面积}}}=\frac12\color{#966524}{\underbrace{p}_{\text{周长}}}\,r\)

先检查条件，再使用关系；彩色标注帮助区分量。

研究正多边形与圆时，我们使用以下核心术语：

  • 正多边形（regular polygon）：各边相等、各内角也相等的多边形。
  • 中心（center）：正多边形外接圆与内切圆的公共圆心，通常记为 \(O\)。
  • 半径（radius）：正多边形外接圆的半径，即中心到各顶点的距离，记为 \(R\)。
  • 边心距（apothem）：正多边形内切圆的半径，即中心到各边的垂线段长，记为 \(r\)。
  • 中心角（central angle）：正多边形每一条边所对的外接圆圆心角，其度数为 \(\alpha = \frac{360^\circ}{n}\)。

直觉微图解 ①正多边形四要素与定义辨析

正 \(n\) 边形的中心角 \(\alpha = \frac{360^\circ}{n}\) 等于外角，与内角互补；各边相等且各角相等缺一不可（菱形、矩形均不是正多边形）。

直觉微图解 ②特征直角三角形 \(\text{Rt}\triangle OAH\) 与面积公式

连接半径 \(OA\) 与边心距 \(OH \perp AB\)，将正 \(n\) 边形化归为特征直角三角形 \(\text{Rt}\triangle OAH\)：斜边 \(R\)、直角边 \(r\) 与 \(\frac{a}{2}\)，满足 \(R^2 = r^2 + (\frac{a}{2})^2\)，总面积 \(S = \frac{1}{2}Pr\)。

直觉微图解 ③三类高频圆内接正多边形（\(n = 3, 4, 6\)）对比

在半径为 \(R\) 的同一个圆中，内接正三角形、正方形、正六边形的半中心角分别为 \(60^\circ, 45^\circ, 30^\circ\)，边长比 \(\sqrt{3}:\sqrt{2}:1\)，边心距比 \(1:\sqrt{2}:\sqrt{3}\)。

2. 核心公式与模型推演

掌握正多边形的直角三角形模型，边角计算畅行无阻：

自己试试 1：已知一个正八边形的中心角的度数是（ ）

B。正八边形的中心角公式：\(\alpha = \frac{360^\circ}{8} = 45^\circ\)。注意：\(135^\circ\) 是它的内角，不是中心角。

自己试试 2：已知正六边形的边长为 6，则其外接圆半径 \(R\) 为（ ）

D。正六边形的中心角为 \(\frac{360^\circ}{6} = 60^\circ\)，由中心和一边端点连线构成的三角形是等边三角形！因此外接圆半径严格等于边长，\(R = a = 6\)。

自己试试 3：已知正方形的边长为 4，则其边心距 \(r\) 为（ ）

A。边心距是中心到各边的垂线段长。正方形中心到各边的距离恰好是边长的一半，因此 \(r = \frac{4}{2} = 2\)（外接圆半径则为 \(R = 2\sqrt{2}\)）。

典例 1（波利亚四步法）：正六边形亭子地基的周长、边心距与面积

【例 1】有一个亭子，它的地基是半径为 \(R = 4\text{ m}\) 的正六边形，求地基的中心角、周长、边心距和面积。

  1. ① 读懂题意：已知正六边形（\(n = 6\)）的外接圆半径 \(R = 4\text{ m}\)，求中心角、周长 \(P\)、边心距 \(r\) 和面积 \(S\)。
  2. ② 想办法：连接相邻两条半径 \(OA, OB\) 得到等腰 \(\triangle OAB\)，过中心 \(O\) 作 \(OH \perp AB\) 于点 \(H\)，化归到特征直角三角形 \(\text{Rt}\triangle OAH\) 中用勾股定理求解。
  3. ③ 执行 + 执行中检查：中心角 \(\angle AOB = \frac{360^\circ}{6} = 60^\circ\)。因 \(OA = OB = 4\text{ m}\)，故 \(\triangle OAB\) 是等边三角形，边长 \(a = AB = 4\text{ m}\)，周长 \(P = 6 \times 4 = 24\text{ m}\)。在 \(\text{Rt}\triangle OAH\) 中，\(AH = \frac{1}{2}AB = 2\text{ m}\)，由勾股定理得边心距 \(r = OH = \sqrt{4^2 - 2^2} = 2\sqrt{3}\text{ m}\)（检查：\(r = \frac{\sqrt{3}}{2}R = 2\sqrt{3}\text{ m}\)）。面积 \(S = \frac{1}{2}Pr = \frac{1}{2} \times 24 \times 2\sqrt{3} = 24\sqrt{3}\text{ m}^2\)。
  4. ④ 回头看：正六边形由 6 个边长为 \(R\) 的全等等边三角形拼成，把握「\(a = R\)，\(r = \frac{\sqrt{3}}{2}R\)」可实现秒解。
典例 2（波利亚四步法）：同圆内接正三角形、正方形、正六边形的边长与边心距之比

【例 2】求同一个圆 \(\odot O\) 的内接正三角形、正方形、正六边形的：（1）边长之比 \(a_3 : a_4 : a_6\)；（2）边心距之比 \(r_3 : r_4 : r_6\)。

  1. ① 读懂题意：三个正多边形内接于同一个圆，说明它们的外接圆半径 \(R\) 相同。
  2. ② 想办法：设公共外接圆半径为 \(R\)，分别在 \(\angle AOH = 60^\circ, 45^\circ, 30^\circ\) 的特征直角三角形 \(\text{Rt}\triangle OAH\) 中用 \(R\) 表示出 \(a_n\) 和 \(r_n\)，再约去 \(R\)。
  3. ③ 执行 + 执行中检查：当 \(n=3\) 时，\(\angle OAH = 30^\circ\)，故 \(r_3 = \frac{1}{2}R\)，\(a_3 = 2\sqrt{R^2 - (\frac{R}{2})^2} = \sqrt{3}R\)；当 \(n=4\) 时，等腰 \(\text{Rt}\triangle OAH\) 得 \(r_4 = \frac{\sqrt{2}}{2}R\)，\(a_4 = \sqrt{2}R\)；当 \(n=6\) 时，\(a_6 = R\)，\(r_6 = \frac{\sqrt{3}}{2}R\)。因此 \(a_3 : a_4 : a_6 = \sqrt{3} : \sqrt{2} : 1\)，\(r_3 : r_4 : r_6 = 1 : \sqrt{2} : \sqrt{3}\)（检查：随着边数增加，边长递减而边心距递增逼近 \(R\)）。
  4. ④ 回头看：同圆问题以公共外接圆半径 \(R\) 为桥梁；若改为“同边长”问题，则以公共半边长 \(\frac{a}{2}\) 为桥梁反求 \(R\) 和 \(r\)。

为什么正多边形面积可以写成 \(S = \frac{1}{2}Pr\)？

将正 \(n\) 边形沿中心向 \(n\) 个顶点连线，分割为 \(n\) 个全等的等腰三角形。每一个等腰三角形的底都是边长 \(a\)，高都是边心距 \(r\)。
因此面积求和： \[S = n \times \left(\frac{1}{2} a r\right) = \frac{1}{2} (n a) r = \frac{1}{2} P r\] 当边数 \(n\) 趋于无穷大时，正多边形逼近圆，周长 \(P \to 2\pi R\)，边心距 \(r \to R\)，面积即为 \(\frac{1}{2} \times 2\pi R \times R = \pi R^2\)。古代刘徽“割圆术”求圆周率正是基于此！

尺规作图技法：如何用直尺和圆规作正六边形？

极简法则——“半径不变量”：

  1. 用圆规以任意长为半径画 \(\odot O\)；
  2. 在圆周上任取一点 \(A\)；
  3. 保持圆规两脚间距（半径 \(R\)）不变，以点 \(A\) 为圆心在圆周上截取点 \(B\)；
  4. 依次以新点为圆心截取，正好在圆周上得到 6 个等分点 \(A, B, C, D, E, F\)；
  5. 顺次连接这 6 个点，即得到严格精确的正六边形！连接间隔点 \(A, C, E\) 则得到正三角形。

练习 1：如果一个正多边形的一个中心角是 \(36^\circ\)，那么这个正多边形的边数是（ ）

C。由中心角公式 \(\alpha = \frac{360^\circ}{n} = 36^\circ\)，直接解得 \(n = \frac{360}{36} = 10\)。

练习 2：已知正六边形的边心距为 \(\sqrt{3}\)，则该正六边形的边长是（ ）

B。正六边形中，边长等于外接圆半径 \(R\)。在含 \(30^\circ\) 角的直角三角形中，三边比为 \(1:\sqrt{3}:2\)，故边心距 \(r = \frac{\sqrt{3}}{2} R\)。代入 \(\sqrt{3} = \frac{\sqrt{3}}{2} R \implies R = 2\)。因此边长为 2。

练习 3：同一个圆的外切正方形与内接正方形的面积之比为（ ）

D。设圆半径为 \(R\)：外切正方形边长为 \(2R\)，面积为 \((2R)^2 = 4R^2\)；内接正方形对角线为 \(2R\)，边长为 \(\sqrt{2}R\)，面积为 \((\sqrt{2}R)^2 = 2R^2\)。面积比为 \(4R^2 : 2R^2 = 2 : 1\)。

练习 4：已知圆内接正六边形的边长为 \(4\)，边心距为 \(2\sqrt{3}\)，则该正六边形的面积是（ ）

A。正六边形的周长 \(P = 6 \times 4 = 24\)，边心距 \(r = 2\sqrt{3}\)。直接应用正多边形面积公式：\(S = \frac{1}{2} P r = \frac{1}{2} \times 24 \times 2\sqrt{3} = 24\sqrt{3}\)。

练习 5：同一个圆的内接正三角形与内接正六边形的面积之比 \(S_3 : S_6\) 为（ ）

提示

设外接圆半径为 \(R\)，分别用 \(S_3 = \frac{3\sqrt{3}}{4}R^2\) 与 \(S_6 = \frac{3\sqrt{3}}{2}R^2\) 作比；或把正六边形分成 6 个小等边三角形观察！

A。设圆的半径为 \(R\)，则内接正三角形面积 \(S_3 = \frac{3\sqrt{3}}{4}R^2\)，内接正六边形面积 \(S_6 = \frac{3\sqrt{3}}{2}R^2\)，因此 \(S_3 : S_6 = 1 : 2\)。

易错提醒：中心角与内角、外角的关系决不能搞混

牢记两点：
1. 中心角 = 外角：度数都是 \(\frac{360^\circ}{n}\)；
2. 内角与外角（中心角）互补：内角 \(= 180^\circ - \frac{360^\circ}{n}\)；
例如正六边形：中心角是 \(60^\circ\)，内角是 \(120^\circ\)；正八边形中心角是 \(45^\circ\)，内角是 \(135^\circ\)。审题看清题目问的是哪个角！

巩固练习 1：正六边形 \(ABCDEF\) 内接于 \(\odot O\)，点 \(M\) 在劣弧 \(\widehat{AB}\) 上（不与点 \(A, B\) 重合），连接 \(MC, ME\)，则 \(\angle CME\) 的度数为（　）

C。连接 \(OC, OD, OE\)．因为正六边形 \(ABCDEF\) 内接于 \(\odot O\)，所以每一条边所对的中心角均为 \(\frac{360^\circ}{6} = 60^\circ\)，即 \(\angle COD = \angle DOE = 60^\circ\)，故劣弧 \(\widehat{CE}\) 所对的圆心角 \(\angle COE = \angle COD + \angle DOE = 120^\circ\)．因为点 \(M\) 在劣弧 \(\widehat{AB}\) 上，所以圆周角 \(\angle CME\) 所对的弧正是劣弧 \(\widehat{CE}\)，由圆周角定理得 \(\angle CME = \frac{1}{2}\angle COE = 60^\circ\)，故选 C．

巩固练习 2：若正方形的外接圆半径为 \(4\)，则该正方形的边长为（　）

C。设正方形 \(ABCD\) 内接于 \(\odot O\)，连接 \(OA, OB\)．正方形的中心角 \(\angle AOB = \frac{360^\circ}{4} = 90^\circ\)，且 \(OA = OB = 4\)，故 \(\triangle OAB\) 是等腰直角三角形．由勾股定理得正方形的边长 \(AB = \sqrt{OA^2 + OB^2} = \sqrt{4^2 + 4^2} = 4\sqrt{2}\)，故选 C．

巩固练习 3：已知正多边形的一个中心角为 \(60^\circ\)，则这个正多边形的边数为______．

查看答案与解析，自行核对

答案：\(6\)

正 \(n\) 边形的中心角都相等，且所有中心角的和为 \(360^\circ\)，即每个中心角为 \(\frac{360^\circ}{n}\)．由 \(\frac{360^\circ}{n} = 60^\circ\)，解得 \(n = 6\)．
