F5解答题函数综合

已知 a,b,c 为正整数，且满足 a<b<c，定义 f:Z+​→Z+​ 满足

f(n)={n−a,f(f(n+b)),​n>c,n≤c.​

求可能的 f 的不动点个数。

作答

这是解答题，请在纸上写出完整过程。写完后对照解答给自己评分。

解析

提示

先看阈值附近的递归会把输入平移多少，并尝试按这一平移长度的余数类组织函数值。

思路

候选式必须同时验证嵌套的两种分支，再证明向下确定函数时外层输入总是已经处理过的较大整数；否则形式递归可能仍有循环或多解。

解答

记 d=b−a>0，令 I={c−a+1,…,c−a+d}。这是含 d 个正整数的区间，每个模 d 余数恰有一个代表。设 r(n) 是 I 中满足 r(n)≡n−a(modd) 的唯一整数，考虑候选

F(n)={n−a,r(n),​n>c,n≤c.​

先验证递归。若 n≤c<n+b，则 F(n+b)=n+d。若 n+d≤c，由余数不变有 F(n+d)=r(n)；若 n+d>c，整数 n+d−a 位于 I 且同余于 n−a，所以仍有 F(n+d)=r(n)。

若 n+b≤c，令 z=r(n+b)∈I，则 z≡n(modd)。当 z≤c 时，F(z)=r(z)=r(n)；当 z>c 时，z−a≥c−a+1，且 z−a≤c−a+d，故 z−a∈I 并同余于 n−a，于是 F(z)=z−a=r(n)。两种大类都证明 F(F(n+b))=F(n)，候选确为正整数值解。

再证唯一性。高于 c 的值已确定，从 c 到1作向下归纳，假设大于 n 的函数值均等于候选。内层输入 n+b>n，其值若按高端分支算，是 n+d>n；若按余数分支算，因 n≤c−b<c−a，其值至少 c−a+1>n。所以外层也只调用已知的较大输入，归纳唯一确定 f(n)=F(n)。

高端 n>c 不可能为不动点。低端不动点必须属于 I，且由 r(n)≡n−a 知必须有 d∣a。若不整除则没有；若整除，d≤a，从而 I 上端 c−a+d≤c，I 的每个元素均满足 r(n)=n。故不动点数为

{b−a,0,​(b−a)∣a,(b−a)∤a.​​

任给正整数 h，取 (a,b,c)=(h,2h,2h+1) 得 h 个；取 (1,3,4) 得0个。因此参数变化时所有非负整数个数均可能。

复核

取 (a,b,c)=(10,11,100)，代表区间只含91，低端全部映到91，恰有一个不动点。取 (1,3,4)，低端四个值依次为4、5、4、5，确无不动点；其中低端值可能超过阈值，说明验证不能只处理代表区间完全位于低端的情形。显式式和向下归纳还分别负责存在性与唯一性，互不替代。

方法总结

阈值嵌套递归可以先寻找一个完整余数代表区间，但写出候选不等于已经解完递归。先逐分支验证，再用调用输入严格增大的向下归纳排除其他解，最后在真实代表区间里按同余条件数不动点。

为什么评为 F5（会透露解法方向）

需要发现长度为b-a的剩余类区间，证明嵌套递归存在唯一，并完成整除分类和全部构造。
