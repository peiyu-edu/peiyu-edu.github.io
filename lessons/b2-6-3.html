6.3 平面向量基本定理及坐标表示

给平面挑两个不共线的基准向量，任何向量都能被唯一分解；选单位正交基底，几何图形就彻底变成了有序数对——从此向量加减、求模、判定平行和垂直，全都可以由代数坐标代刀代劳。

方格棋盘上，巡检无人机停在基准点 \(O(0,0)\)。它接收两种基础位移指令：

  • 指令 \(\boldsymbol{e}_1\)：向东平移 \(1\) 格；
  • 指令 \(\boldsymbol{e}_2\)：向北平移 \(1\) 格。

现在目标设备在点 \(P\)（位于 \(O\) 点以东 \(4\) 格、以北 \(3\) 格）。怎样下达位移指令能让无人机准确抵达 \(P\)？

下面四种指令组合，哪一种能使无人机从 \(O\) 抵达 \(P\)？

B。向东 \(4\) 步加上向北 \(3\) 步，合位移就是 \(4\boldsymbol{e}_1 + 3\boldsymbol{e}_2\)。而且只要目标位置 \(P\) 确定，这组步数 \((4, 3)\) 是有且仅有一组的。

更巧妙的是：只要两个基准方向不共线（哪怕不是正东和正北，而是斜着交叉），平面上的任何一个点、任何一条向量，都能用它们唯一地表示出来！

这就是平面向量基本定理。借由这个定理，几何里的线段和夹角，就化作了一目了然的代数坐标。

1. 先认识几个词

要用到：向量加法的平行四边形法则、数乘向量与数量积（回看 6.2）；初中平面直角坐标系与勾股定理。

基底与基向量：同一平面内两个不共线的向量 \(\boldsymbol{e}_1, \boldsymbol{e}_2\) 叫作该平面的一组基底，\(\boldsymbol{e}_1, \boldsymbol{e}_2\) 叫作基向量。基向量绝不能共线，也不能是零向量。

例：向东 \(1\) 格的 \(\boldsymbol{e}_1\) 与向北 \(1\) 格的 \(\boldsymbol{e}_2\) 不共线，是一组基底；而 \((1, 0)\) 与 \((2, 0)\) 在同一直线上（共线），不能当基底。

线性表示（分解）：把平面内的任意向量 \(\boldsymbol{a}\) 写成基向量数乘相加的形式：\(\boldsymbol{a} = \lambda_1\boldsymbol{e}_1 + \lambda_2\boldsymbol{e}_2\)。实数对 \((\lambda_1, \lambda_2)\) 是唯一确定的。

例：\(\boldsymbol{a} = 3\boldsymbol{e}_1 - 2\boldsymbol{e}_2\)；若 \(\boldsymbol{a}\) 是零向量 \(\boldsymbol{0}\)，则对应唯一的一对实数 \((0, 0)\)。

单位正交基底：长度都为 \(1\)（单位）、夹角为 \(90^\circ\)（正交、互相垂直）的两个基向量，通常记为 \(\boldsymbol{i}, \boldsymbol{j}\)。直角坐标系就是建立在单位正交基底之上的。

例：平面直角坐标系中，\(x\) 轴正方向的单位向量 \(\boldsymbol{i}=(1,0)\) 与 \(y\) 轴正方向的单位向量 \(\boldsymbol{j}=(0,1)\) 是标准的单位正交基底。

向量的坐标：在单位正交基底下，若 \(\boldsymbol{a} = x\boldsymbol{i} + y\boldsymbol{j}\)，有序实数对 \((x, y)\) 就叫向量 \(\boldsymbol{a}\) 的坐标，记作 \(\boldsymbol{a} = (x, y)\)。

例：起点在原点 \(O(0,0)\)、终点在 \(P(3, 4)\) 的向量 \(\vec{OP}\)，坐标就是 \((3, 4)\)。

2. 平面向量基本定理

只要在平面内选定两个不共线的基准向量，任何向量都能用它们拼出来，而且拼法唯一：

如果 \(\boldsymbol{e}_1, \boldsymbol{e}_2\) 是同一平面内的两个不共线向量，那么对于这一平面内的任一向量 \(\boldsymbol{a}\)，有且只有一对实数 \(\lambda_1, \lambda_2\)，使
\[\boldsymbol{a} = \lambda_1\boldsymbol{e}_1 + \lambda_2\boldsymbol{e}_2\]

为什么存在且唯一：过向量 \(\boldsymbol{a}\) 的终点分别作基向量 \(\boldsymbol{e}_1, \boldsymbol{e}_2\) 所在直线的平行线。因为两基底不共线（两直线相交），这两条平行线必分别与两基底所在直线交于唯一的一点，由平行四边形法则，即可唯一分解出两个分量 \(\lambda_1\boldsymbol{e}_1\) 与 \(\lambda_2\boldsymbol{e}_2\)。

例 1（基底表示）

平行四边形 \(ABCD\) 中，对角线交于点 \(O\)，设 \(\vec{AB} = \boldsymbol{a}, \vec{AD} = \boldsymbol{b}\)。试用基底 \(\{\boldsymbol{a}, \boldsymbol{b}\}\) 表示：

(1) 对角线向量 \(\vec{AC}\)；(2) 向量 \(\vec{AO}\)；(3) 若 \(M\) 是边 \(BC\) 的中点，表示向量 \(\vec{AM}\)。

解：

(1) 由平行四边形法则，\(\vec{AC} = \vec{AB} + \vec{AD} = \boldsymbol{a} + \boldsymbol{b}\)；

(2) 对角线互相平分，\(O\) 是 \(AC\) 中点，故 \(\vec{AO} = \dfrac{1}{2}\vec{AC} = \dfrac{1}{2}\boldsymbol{a} + \dfrac{1}{2}\boldsymbol{b}\)；

(3) \(\vec{AM} = \vec{AB} + \vec{BM} = \vec{AB} + \dfrac{1}{2}\vec{BC} = \boldsymbol{a} + \dfrac{1}{2}\boldsymbol{b}\)。（因为 \(\vec{BC}=\vec{AD}=\boldsymbol{b}\)）

自己试试：在 \(\triangle ABC\) 中，点 \(D\) 是 \(BC\) 边上的中点。若设 \(\vec{AB} = \boldsymbol{c}, \vec{AC} = \boldsymbol{b}\)，则中线向量 \(\vec{AD} =\)？

A。因为 \(D\) 是中点，\(\vec{AD} = \vec{AB} + \vec{BD} = \boldsymbol{c} + \dfrac{1}{2}(\boldsymbol{b}-\boldsymbol{c}) = \dfrac{1}{2}\boldsymbol{b} + \dfrac{1}{2}\boldsymbol{c}\)。也可以看作以 \(AB, AC\) 为邻边的平行四边形对角线的一半。选 B 的同学漏除了 \(2\)；选 C 的正负号搞反了。

3. 向量的坐标表示与运算

在平面直角坐标系中，设单位正交基底为 \(\boldsymbol{i}, \boldsymbol{j}\)。向量 \(\boldsymbol{a} = (x_1, y_1), \boldsymbol{b} = (x_2, y_2)\)：

  • 加减法：横横相加减，纵纵相加减。
    \(\boldsymbol{a} + \boldsymbol{b} = (x_1 + x_2, y_1 + y_2)\)，\(\boldsymbol{a} - \boldsymbol{b} = (x_1 - x_2, y_1 - y_2)\)。
  • 数乘：实数乘进每个坐标。
    \(\lambda\boldsymbol{a} = (\lambda x_1, \lambda y_1)\)。
  • 终点坐标减起点坐标：若点 \(A(x_1, y_1), B(x_2, y_2)\)，则向量
    \(\vec{AB} = \vec{OB} - \vec{OA} = (x_2 - x_1, y_2 - y_1)\)。
  • 模长公式（由勾股定理）：
    \(|\boldsymbol{a}| = \sqrt{x_1^2 + y_1^2}\)；两点间距离 \(|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)。

例 2（坐标运算与模长）

已知点 \(A(1, 2), B(4, 6)\)，向量 \(\boldsymbol{c} = (-1, 3)\)。

(1) 求向量 \(\vec{AB}\) 的坐标及其模长 \(|\vec{AB}|\)；
(2) 求 \(2\vec{AB} - 3\boldsymbol{c}\) 的坐标。

解：

(1) 终点减起点：\(\vec{AB} = (4-1, 6-2) = (3, 4)\)；模长 \(|\vec{AB}| = \sqrt{3^2 + 4^2} = 5\)。

(2) \(2\vec{AB} = 2(3, 4) = (6, 8)\)，\(3\boldsymbol{c} = 3(-1, 3) = (-3, 9)\)，
故 \(2\vec{AB} - 3\boldsymbol{c} = (6 - (-3), 8 - 9) = (9, -1)\)。

自己试试：已知向量 \(\boldsymbol{a} = (2, -1), \boldsymbol{b} = (-3, 4)\)，则向量 \(2\boldsymbol{a} + \boldsymbol{b}\) 的模长等于？

A。先算坐标：\(2\boldsymbol{a} = (4, -2)\)，\(2\boldsymbol{a} + \boldsymbol{b} = (4 + (-3), -2 + 4) = (1, 2)\)。再算模长：\(\sqrt{1^2 + 2^2} = \sqrt{5}\)。选 C 的同学直接把两向量模长相加了（模长不满足 \(|2\boldsymbol{a}+\boldsymbol{b}|=2|\boldsymbol{a}|+|\boldsymbol{b}|\)）；选 B 的把横纵坐标算错了。

4. 数量积、垂直与共线的坐标公式

设 \(\boldsymbol{a} = (x_1, y_1), \boldsymbol{b} = (x_2, y_2)\)。由于单位正交基底满足 \(\boldsymbol{i}\cdot\boldsymbol{i} = 1\)，\(\boldsymbol{j}\cdot\boldsymbol{j} = 1\)，而 \(\boldsymbol{i}\cdot\boldsymbol{j} = 0\)（互相垂直积为 0）：

数量积坐标公式：\(\boldsymbol{a}\cdot\boldsymbol{b} = x_1x_2 + y_1y_2\)

从数量积出发，立刻得到几何位置关系的坐标判定：

  • 垂直充要条件：\(\boldsymbol{a}\perp\boldsymbol{b} \iff x_1x_2 + y_1y_2 = 0\)。
  • 共线充要条件：\(\boldsymbol{a}\parallel\boldsymbol{b} \iff x_1y_2 - x_2y_1 = 0\)（主对角乘积减副对角乘积，交叉相乘之差）。

例 3（位置关系判定）

已知向量 \(\boldsymbol{a} = (1, 2), \boldsymbol{b} = (m, -4)\)。

(1) 若 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，求实数 \(m\)；
(2) 若 \(\boldsymbol{a}\perp\boldsymbol{b}\)，求实数 \(m\)。

解：

(1) \(\boldsymbol{a}\parallel\boldsymbol{b} \iff 1\times(-4) - 2\times m = 0 \implies -4 - 2m = 0 \implies m = -2\)；

(2) \(\boldsymbol{a}\perp\boldsymbol{b} \iff 1\times m + 2\times(-4) = 0 \implies m - 8 = 0 \implies m = 8\)。

自己试试：已知向量 \(\boldsymbol{a} = (3, 4), \boldsymbol{b} = (x, -6)\)。若 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，则 \(x\) 的值为？

C。套用共线公式 \(x_1y_2 - x_2y_1 = 0\)：\(3\times(-6) - 4\times x = 0 \implies -18 - 4x = 0 \implies x = -\dfrac{9}{2}\)。选 A 的同学误用了垂直公式 \(3x + 4(-6) = 0\)；选 D 的算漏了负号。

5. 用之前，查三条红线

公式虽然整齐，但有三处极其容易踩坑的边界：

  1. 共线判定决不能直接作除法：
    很多同学喜欢记「坐标成比例 \(\dfrac{x_1}{x_2} = \dfrac{y_1}{y_2}\)」。但一旦遇到分母为 \(0\)，除法立即崩溃！
    反例：\(\boldsymbol{a}=(0, 2)\) 与 \(\boldsymbol{b}=(0, 4)\) 都在 \(y\) 轴上，显然共线。但若写成 \(\dfrac{0}{0}=\dfrac{2}{4}\) 完全无意义；而用交叉相乘 \(0\times 4 - 2\times 0 = 0\)，永远正确且不会漏解。
  2. 斜基底绝不能套勾股公式和点积公式：
    模长公式 \(|\boldsymbol{a}| = \sqrt{x^2+y^2}\) 和数量积 \(x_1x_2+y_1y_2\) 严格建立在单位正交基底上。
    反例：若基底 \(|\boldsymbol{e}_1|=1, |\boldsymbol{e}_2|=1\)，夹角为 \(60^\circ\)（斜基底）。向量 \(\boldsymbol{a} = \boldsymbol{e}_1 + \boldsymbol{e}_2\) 的系数是 \((1, 1)\)。若误套直角坐标勾股得模长 \(\sqrt{1^2+1^2} = \sqrt{2}\)；但真实模长是 \(\sqrt{|\boldsymbol{e}_1|^2 + 2\boldsymbol{e}_1\cdot\boldsymbol{e}_2 + |\boldsymbol{e}_2|^2} = \sqrt{1 + 2\cos 60^\circ + 1} = \sqrt{3}\)！在斜基底下必须老老实实用数量积展开。
  3. 向量共线不等于直线平行：
    两向量共线 \(\vec{AB}\parallel\vec{CD}\)，反映在几何直线上可能是平行，也可能是重合。
    反例：若 \(\vec{AB}\parallel\vec{AC}\)，两向量有公共点 \(A\)，此时直线 \(AB\) 与 \(AC\) 重合，即 \(A, B, C\) 三点共线，而不是两条平行线。
再深一点（可以先跳过）

为什么共线是交叉相乘之差：在解析几何与线性代数中，二阶行列式 \(\begin{vmatrix}x_1 & y_1\\ x_2 & y_2\end{vmatrix} = x_1y_2 - x_2y_1\) 的绝对值，正是以 \(\boldsymbol{a}, \boldsymbol{b}\) 为邻边的平行四边形的有向面积。面积等于 \(0\)，意味着平行四边形被压成了一条线段，两向量自然共线。

向量三点共线定理：若点 \(P\) 在直线 \(AB\) 上，且 \(O\) 是直线外一点，则必有 \(\vec{OP} = \lambda\vec{OA} + \mu\vec{OB}\)，且实数满足 \(\lambda + \mu = 1\)。当 \(\lambda, \mu > 0\) 时，\(P\) 在线段 \(AB\) 内部；一正一负时，\(P\) 在线段 \(AB\) 的延长线上。

物理里的正交分解：力学分析中把重力分解为沿斜面方向和垂直斜面方向，本质上就是选取了一组适合问题对称性的单位正交基底，从而让各个方向的代数方程互不干扰。

① 基础：平面直角坐标系中的双向量与判定器

拖动墨绿点 \(A(x_1, y_1)\) 改变向量 \(\boldsymbol{a}\)，拖动赤金点 \(B(x_2, y_2)\) 改变向量 \(\boldsymbol{b}\)。观察下方坐标、模长、数量积与判定式徽章的实时计算。键盘操作：Tab 选中端点，方向键每次移动 \(1\) 个单位。

坐标：(3, 2)，模长：\(\sqrt{13} \approx 3.61\)

② 进阶：斜基底 vs 直角基底（为什么斜基底不能套勾股？）

设单位基底 \(|\boldsymbol{e}_1|=1, |\boldsymbol{e}_2|=1\)，夹角为 \(\theta\)。观察合成向量 \(\boldsymbol{v} = 2\boldsymbol{e}_1 + 2\boldsymbol{e}_2\) 的真实模长与误套直角坐标勾股公式算出的假模长。拖动滑块改变夹角 \(\theta\)：

60°
真实模长 \(|\boldsymbol{v}|\)（余弦数量积求模）
\(\sqrt{8 + 8\cos 60^\circ} = \sqrt{12} \approx 3.46\)
误套直角勾股算出的假模长
\(\sqrt{2^2 + 2^2} = \sqrt{8} \approx 2.83\)

从易到难排好了。前两道直接用，中间三道是专题卡里的高频边界，最后一道是综合挑战。

直接用

1. 已知点 \(A(-1, 2), B(2, 6)\)，则向量 \(\vec{AB}\) 的模长 \(|\vec{AB}|\) 等于？

A。由终点减起点得 \(\vec{AB} = (2 - (-1), 6 - 2) = (3, 4)\)。由模长公式：\(|\vec{AB}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\)。选 C 的同学横坐标忘了减去负号（误算成了 \(2 - 1 = 1\)）；选 D 的同学忘了开平方。

2. 已知向量 \(\boldsymbol{a} = (2, 3), \boldsymbol{b} = (-6, x)\)。若 \(\boldsymbol{a}\perp\boldsymbol{b}\)，则实数 \(x =\)？

B。两非零向量垂直充要条件是数量积为 \(0\)：\(\boldsymbol{a}\perp\boldsymbol{b} \iff x_1x_2 + y_1y_2 = 0\)。代入得 \(2\times(-6) + 3\times x = 0 \implies -12 + 3x = 0 \implies x = 4\)。选 A 的同学混淆了共线与垂直公式（误算了 \(2x - 3(-6) = 0\)）；选 C 的符号算错。

易错

3. 已知向量 \(\boldsymbol{a} = (0, 3)\) 与 \(\boldsymbol{b} = (m, -6)\) 共线，则实数 \(m =\)？

B。牢记共线充要条件是交叉相乘之差为 0：\(x_1y_2 - x_2y_1 = 0\)。

代入得 \(0\times(-6) - m\times 3 = 0 \implies -3m = 0 \implies m = 0\)。此时 \(\boldsymbol{b} = (0, -6) = -2\boldsymbol{a}\)，两向量都在 \(y\) 轴上，完全共线。如果套用「坐标相除」\(\dfrac{0}{m} = \dfrac{3}{-6}\)，就会陷入分母为 0 的困境甚至误选 A。

4. 下列各组向量中，不能作为平面向量一组基底的是？

B。基底的数学前提是两个不共线的向量。检查 B 选项：\(2\times 6 - (-3)\times(-4) = 12 - 12 = 0\)，即 \(\boldsymbol{e}_2 = -2\boldsymbol{e}_1\)，两向量在同一直线上（共线），无法分解出垂直于该直线方向的分量，因此不能作为基底。其余三组交叉相乘之差均不为 \(0\)，两向量互不共线，都是合格基底。

5. 已知平面基底 \(\{\boldsymbol{e}_1, \boldsymbol{e}_2\}\) 满足 \(|\boldsymbol{e}_1| = 1, |\boldsymbol{e}_2| = 1\)，且 \(\boldsymbol{e}_1\) 与 \(\boldsymbol{e}_2\) 的夹角为 \(60^\circ\)。若向量 \(\boldsymbol{a} = \boldsymbol{e}_1 + \boldsymbol{e}_2\)，则模长 \(|\boldsymbol{a}| =\)？

B。选 A 的同学直接套用了直角坐标勾股公式 \(\sqrt{1^2 + 1^2} = \sqrt{2}\)，这是大忌！只有在单位正交基底（夹角为 \(90^\circ\)）下勾股公式才成立。这里夹角是 \(60^\circ\)，必须求模平方：\(|\boldsymbol{a}|^2 = (\boldsymbol{e}_1 + \boldsymbol{e}_2)^2 = |\boldsymbol{e}_1|^2 + 2\boldsymbol{e}_1\cdot\boldsymbol{e}_2 + |\boldsymbol{e}_2|^2 = 1 + 2\times 1\times 1\times\cos 60^\circ + 1 = 1 + 1 + 1 = 3\)，开方得 \(|\boldsymbol{a}| = \sqrt{3}\)。

挑战

6. 点 \(O\) 为平面内任一点，向量 \(\vec{OP} = x\vec{OA} + y\vec{OB}\)（其中 \(O, A, B\) 三点不共线）。则点 \(A, P, B\) 三点共线的充要条件是？

A。这是经典的向量三点共线定理。推导如下：

\(A, P, B\) 共线 \(\iff \vec{AP} = t\vec{AB}\) \(\iff \vec{OP} - \vec{OA} = t(\vec{OB} - \vec{OA})\) \(\iff \vec{OP} = (1-t)\vec{OA} + t\vec{OB}\)。令 \(x = 1-t, y = t\)，立得 \(x + y = 1\)。

反过来，只要基底前面的两个系数之和等于 \(1\)，终点 \(P\) 就必然落在过 \(A, B\) 的直线上。
