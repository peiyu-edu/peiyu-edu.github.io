3.2 双曲线

从声源定位的时间差到冷却塔的双曲面外形，双曲线以「距离差的绝对值恒定」刻画了两支无限延伸的对称曲线。正项定实轴、渐近线无限逼近、离心率大于 1 是洞悉双曲线本质的三把钥匙。

在海防导航中，两个相距 \(10\text{ km}\) 的监测站 \(F_1(-5,0), F_2(5,0)\) 同时记录到某处海域传来的爆炸声。\(F_1\) 站比 \(F_2\) 站晚了 \(2\) 秒听到声响（声速 \(3\text{ km/s}\)），意味着声源 \(P\) 到两站的距离差满足 \(|PF_1| - |PF_2| = 6\text{ km}\)。点按钮看声波传播与轨迹：

如果动点 \(P\) 满足条件 \(|PF_1| - |PF_2| = 6\text{ km}\)（注意：此处没有加绝对值！），那么声源 \(P\) 可能所在的轨迹是什么图形？

B。注意看式子：\(|PF_1| - |PF_2| = 6 > 0\)，这意味着 \(|PF_1| = |PF_2| + 6\)。

点 \(P\) 到 \(F_1\) 的距离永远比到 \(F_2\) 的距离大 \(6\text{ km}\)，因此点 \(P\) 必然更靠近 \(F_2\)，只能画出靠近 \(F_2\) 的单单一支（右支）！

只有当我们加上绝对值，写成 \(||PF_1| - |PF_2|| = 6\) 时，点 \(P\) 既可以更靠近 \(F_2\)（\(|PF_1| - |PF_2| = 6\)），也可以更靠近 \(F_1\)（\(|PF_2| - |PF_1| = 6\)），此时才是一左一右两支对称的完整双曲线！

这就是双曲线定义中最容易被忽略的第一道关键红线：距离差的「绝对值」！

1. 先认识几个词

要用到：两点间距离公式（回看 2.3）；椭圆的定义和 \(a,b,c\)（回看 3.1）。

课本用词：双曲线定义要求 \(0<2a<2c\)，并使用距离差的绝对值；\(2a=2c\) 是两条射线的退化情形。

伴读直觉微图解：双曲线定义、渐近线特征矩形与离心率

焦点与焦距：两定点叫焦点 \(F_1,F_2\)，焦距为 \(|F_1F_2|=2c\)（焦距是 \(2c\)，不是 \(c\)；\(c\) 为半焦距）。

例：\(F_1(-5,0), F_2(5,0)\)，焦距 \(2c=10, c=5\)。在双曲线中 \(c > a > 0\)。

实轴与虚轴：焦点所在轴上的两顶点连线叫实轴，长为 \(2a\)；垂直平分线上的线段叫虚轴，长为 \(2b\)。核心勾股式：\(c^2 = a^2 + b^2\)（\(c\) 最大）。

例：\(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\)，实轴长 \(2a=8\)，虚轴长 \(2b=6\)，\(c=\sqrt{16+9}=5\)。

参数对比 双曲线 \(c^2=a^2+b^2\) (\(c\) 最大) vs 椭圆 \(a^2=b^2+c^2\) (\(a\) 最大)

双曲线：焦点在两翼最外侧，\(c > a\)，勾股关系为 \(c^2 = a^2 + b^2\)（\(c\) 是斜边！）。离心率 \(e = \frac ca > 1\)。

椭圆：长轴端点在最外侧，\(a > c\)，勾股关系为 \(a^2 = b^2 + c^2\)（\(a\) 是斜边）。离心率 \(e = \frac ca \in (0, 1)\)。

切记：双曲线里允许 \(a < b\) 或 \(a = b\)（等轴双曲线），判定焦点必须看正项而非分母大小！

临界辨析 距离差绝对值 \(2a\) 与焦距 \(2c\) 的三态边界

三态蜕变：平面内到两焦点距离差的绝对值 \(\big||PF_1|-|PF_2|\big| = 2a\)：
① \(0 < 2a < 2c\) ⟹ 轨迹为双曲线（两支）；
② \(2a = 2c\) ⟹ 轨迹退化为两条射线；
③ \(2a > 2c\) ⟹ 两边之差不可能大于第三边，无轨迹（空集）；
④ \(2a = 0\) ⟹ 垂直平分线。

绝对值警示：无绝对值时仅表示双曲线的单单一支！

标准方程（正项定焦点）：\(\dfrac{x^2}{\color{#2563eb}{a^2}} - \dfrac{y^2}{\color{#059669}{b^2}} = 1 \quad (\color{#dc2626}{c^2} = \color{#2563eb}{a^2} + \color{#059669}{b^2}) \quad\Longrightarrow\quad \text{渐近线：} y = \pm \dfrac{\color{#059669}{b}}{\color{#2563eb}{a}}x\)
离心率与定义常数：\(e = \dfrac{\color{#dc2626}{c}}{\color{#2563eb}{a}} = \sqrt{1 + \dfrac{\color{#059669}{b^2}}{\color{#2563eb}{a^2}}} > 1;\quad \big||PF_1| - |PF_2|\big| = \color{#2563eb}{2a} < \color{#dc2626}{2c}\)

2. 定义：距离差的绝对值等于 \(2a\)

椭圆是「到两焦点距离的和一定」；把「和」换成「差」，就得到双曲线：

平面内到两个定点 \(F_1,F_2\) 的距离之差的绝对值等于常数 \(2a\)，并且 \(0<2a<|F_1F_2|=2c\)，这样的点的轨迹叫双曲线。$$\big||PF_1|-|PF_2|\big|=2a$$
  • 为什么要绝对值：\(|PF_1|-|PF_2|=2a\) 说明 \(P\) 离 \(F_2\) 更近，只得到靠近 \(F_2\) 的一支；\(|PF_1|-|PF_2|=-2a\) 是靠近 \(F_1\) 的另一支。加上绝对值，两支合起来才是整条双曲线。
  • 为什么要 \(2a<2c\)：三角形两边之差小于第三边，\(\big||PF_1|-|PF_2|\big|\) 最多等于 \(2c\)。等于 \(2c\) 时只剩两条射线，大于 \(2c\) 时一个点也没有。

例 1（两支都要想到）

双曲线 \(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\) 上一点 \(P\) 到右焦点 \(F_2\) 的距离是 \(10\)，求它到左焦点 \(F_1\) 的距离。

\(a=4\)，\(b=3\)，\(c=\sqrt{16+9}=5\)。由定义 \(\big||PF_1|-10\big|=2a=8\)，所以 \(|PF_1|=18\) 或 \(|PF_1|=2\)。

两个都要检查能不能取到：右支最小距为 \(c-a=1 \le 10\)（成立，\(|PF_1|=18\)）；左支到右焦点最小距为 \(a+c=9 \le 10\)（成立，\(|PF_1|=2\)）。

所以 \(|PF_1|=18\) 或 \(2\)。若题目指明 \(P\) 在右支上，则只取 \(18\)。

自己试试：\(P\) 在双曲线 \(\dfrac{x^2}{9}-\dfrac{y^2}{16}=1\) 的右支上，\(|PF_1|=10\)，那么 \(|PF_2|=\)？

A。\(a=3\)，\(2a=6\)。右支上的点离 \(F_2\) 更近，\(|PF_1|-|PF_2|=6\)，所以 \(|PF_2|=10-6=4\)。选 B 是把差的方向弄反了（那是左支）；选 C 是没用上「右支」这个条件；选 D 是把 \(c-a\) 当成了答案。

3. 标准方程：正项定焦点

焦点放在 \(x\) 轴上：\(F_1(-c,0)\)、\(F_2(c,0)\)。移项整理得到标准方程：

焦点在 \(x\) 轴：$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1,\quad F(\pm c,0)$$ 焦点在 \(y\) 轴：$$\frac{y^2}{a^2}-\frac{x^2}{b^2}=1,\quad F(0,\pm c)$$ 其中 \(a>0\)，\(b>0\)，\(c^2=a^2+b^2\)。

怎么看焦点在哪个轴：哪一项是正的，焦点就在哪个轴上，正项下面的分母是 \(a^2\)。这和椭圆「看分母谁大」不同：双曲线里 \(a\) 可以小于 \(b\)。

例 2

双曲线 \(\dfrac{y^2}{9}-\dfrac{x^2}{16}=1\)，求实轴长、虚轴长、焦距、焦点和顶点坐标。

正号在 \(y^2\) 项上，焦点在 \(y\) 轴上。\(a^2=9, a=3\)；\(b^2=16, b=4\)（允许 \(a<b\)）。

\(c^2=a^2+b^2=9+16=25, c=5\)。

实轴长 \(2a=6\)，虚轴长 \(2b=8\)，焦距 \(2c=10\)。焦点 \((0,\pm5)\)；顶点 \((0,\pm3)\)。

自己试试：方程 \(-\dfrac{x^2}{9}+\dfrac{y^2}{7}=1\) 表示的双曲线，焦点坐标是？

A。改写成 \(\dfrac{y^2}{7}-\dfrac{x^2}{9}=1\)，正项是 \(y^2\)，焦点在 \(y\) 轴上；\(c^2=7+9=16\)，\(c=4\)。选 B 是按「分母大的在哪个轴」判断，那是椭圆的做法；选 C、D 是用了椭圆的 \(c^2=a^2-b^2\)。

4. \(a,b,c\) 的关系和离心率

双曲线里 \(c^2=a^2+b^2\)，\(c\) 最大，像直角三角形的斜边。离心率

$$e=\frac ca=\sqrt{1+\Big(\frac ba\Big)^2}>1$$

\(e\) 越大，\(\dfrac ba\) 越大，双曲线开口越开阔。

例 3

双曲线的焦点在 \(x\) 轴上，虚轴长 \(6\)，离心率 \(e=\dfrac54\)，求它的标准方程。

虚轴长 \(2b=6, b=3\)。由 \(e=\dfrac ca=\dfrac54\) 得 \(c=\dfrac54a\)。代入 \(c^2=a^2+b^2\) 得 \(\dfrac{25}{16}a^2=a^2+9 \implies a^2=16\)。

方程是 \(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\)。

自己试试：双曲线 \(\dfrac{x^2}{4}-\dfrac{y^2}{5}=1\) 的离心率是？

A。\(a=2\)，\(c^2=4+5=9\)，\(c=3\)，\(e=\dfrac32\)。双曲线的 \(e\) 恒大于 \(1\)。

5. 渐近线

把标准方程右边的 \(1\) 换成 \(0\)，因式分解就得到两条渐近线：

\(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\) 的渐近线是 \(y=\pm\dfrac bax\)；\(\dfrac{y^2}{a^2}-\dfrac{x^2}{b^2}=1\) 的渐近线是 \(y=\pm\dfrac abx\)。

例 4

\(\dfrac{y^2}{9}-\dfrac{x^2}{16}=1\)：令右端为 \(0\)，得 \(y^2=\dfrac{9}{16}x^2\)，渐近线 \(y=\pm\dfrac34x\)。

对比 \(\dfrac{x^2}{9}-\dfrac{y^2}{16}=1\)：令右端为 \(0\)，得 \(y^2=\dfrac{16}{9}x^2\)，渐近线 \(y=\pm\dfrac43x\)。分母一样，正项换了，斜率倒置。

自己试试：已知双曲线方程为 \(\dfrac{x^2}{4} - \dfrac{y^2}{12} = 1\)，则该双曲线的离心率 \(e\) 和渐近线方程分别为：

A。正项是 \(x^2\)，\(a=2, b=2\sqrt{3}, c=4 \implies e=2\)。令右端为 \(0 \implies y=\pm\sqrt3x\)。

6. 三步破题思维链：双曲线标准解题动作

1
👀 第一眼破题信号

审清方程或几何条件：找准正项锁定焦点轴向（\(x^2\) 项为正，焦点在 \(x\) 轴；\(y^2\) 项为正，焦点在 \(y\) 轴），正项分母恒为 \(a^2\)。

2
🔧 第二步套公式/方法

① 参数关系：套用 \(c^2 = a^2 + b^2\)（\(c\) 最大）与 \(e = \frac ca > 1\)；
② 渐近线求解：直接把标准方程右边的 \(1\) 替换为 \(0\)，去分母分解得两条直线；
③ 若给出渐近线方程 \(y = \pm \frac ba x\)，可直接设双曲线系方程 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = \lambda\)（\(\lambda \ne 0\)）。

3
🛡️ 第三步必查防坑结论

① 焦点在 \(y\) 轴时渐近线斜率为 \(\pm\frac ab\) 绝非 \(\pm\frac ba\)！
② 题目若说明动点在「右支」或「左支」，脱绝对值时只能取单修正号，切勿保留双解。

7. 三大翻车现场与反例辨析

翻车现场 1：误套椭圆公式算 c²=a²-b²
❌ 对 \(\frac{x^2}{25}-\frac{y^2}{16}=1\)，套椭圆公式算 \(c^2=25-16=9 \Rightarrow c=3\)
✔ 双曲线 \(c\) 最大，正解为 \(c^2=a^2+b^2=25+16=41 \Rightarrow c=\sqrt{41}\)
翻车现场 2：y 轴焦点渐近线斜率倒错
❌ 对 \(\frac{y^2}{9}-\frac{x^2}{16}=1\)，死记硬套 \(y=\pm\frac ba x = \pm\frac 43 x\)
✔ 令右侧为 0 得 \(\frac{y^2}{9}=\frac{x^2}{16}\)，渐近线正解为 \(y=\pm\frac 34 x\)
翻车现场 3：漏掉绝对值把单支当全双曲
❌ 认为 \(|PF_1|-|PF_2|=2a\) 表示整条双曲线
✔ 不加绝对值仅表示靠近 \(F_2\) 的单单一支，全双曲线必须加绝对值
反例微图解：双支（加绝对值） vs 单支（无绝对值）对比
不加绝对值时，\(|PF_1| - |PF_2| = 2a\) 仅能描绘靠近 \(F_2\) 的右支；必须套上绝对值 \(\big||PF_1| - |PF_2|\big| = 2a\) 才是完整的双支双曲线！
再深一点（可以先跳过）

等轴双曲线：\(a=b\) 时方程是 \(x^2-y^2=a^2\)，渐近线 \(y=\pm x\) 互相垂直，离心率 \(e=\sqrt2\)。

共渐近线方程系：\(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=\lambda\)（\(\lambda\ne0\)）具有共同的渐近线 \(y=\pm\dfrac bax\)。

双曲线左右支与渐近线无限逼近微实验室

直接用

1. 双曲线 \(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1\) 的焦点坐标与渐近线方程分别为：

A。① 正项是 \(x^2\)，焦点在 \(x\) 轴上；\(a^2 = 9 \implies a = 3\)，\(b^2 = 16 \implies b = 4\)。

② 由 \(c^2 = a^2 + b^2\) 得 \(c^2 = 9 + 16 = 25 \implies c = 5\)，故焦点坐标为 \((\pm 5, 0)\)（选 D 错用成椭圆的 \(c^2 = a^2 - b^2\)）。

③ 令右端为 \(0\)：\(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 0 \implies \dfrac{y^2}{16} = \dfrac{x^2}{9} \implies y = \pm \dfrac{4}{3}x\)（选 C 倒置了渐近线斜率）。

2. 已知双曲线的中心在原点，焦点在 \(y\) 轴上，焦距为 \(8\)，离心率 \(e = \dfrac{4}{3}\)，则该双曲线的标准方程为：

A。焦距 \(2c = 8 \implies c = 4\)。由离心率 \(e = \dfrac{c}{a} = \dfrac{4}{a} = \dfrac{4}{3}\) 得 \(a = 3 \implies a^2 = 9\)。

再由 \(c^2 = a^2 + b^2\) 得 \(b^2 = c^2 - a^2 = 16 - 9 = 7\)。

因为焦点在 \(y\) 轴上，正项为 \(y^2\)，故标准方程为 \(\dfrac{y^2}{9} - \dfrac{x^2}{7} = 1\)。选 B 选错焦点轴，选 C 误把半焦距 \(c\) 当作实半轴 \(a\)。

易错

3. 双曲线 \(\dfrac{y^2}{4} - \dfrac{x^2}{25} = 1\) 的实轴长为：

A。专题卡核心红线：正项确定实轴，绝不能看分母大小！

方程中带正号的项是 \(y^2\) 项，因此实半轴平方 \(a^2 = 4 \implies a = 2\)，虚半轴平方 \(b^2 = 25 \implies b = 5\)。

实轴长为 \(2a = 2 \times 2 = 4\)（切记问的是实轴长 \(2a\)，不是实半轴 \(a\)！选 C 漏乘了 2；选 B 或 D 受椭圆思维定势误把较大的分母 25 当作 \(a^2\)）。

4. 平面内两定点 \(F_1(-3, 0), F_2(3, 0)\)，动点 \(P\) 满足条件 \(|PF_1| - |PF_2| = 6\)，则点 \(P\) 的轨迹是：

C。计算两定点距离：焦距 \(2c = |F_1F_2| = 3 - (-3) = 6\)。

题目条件为 \(|PF_1| - |PF_2| = 6 = |F_1F_2|\)。根据平面几何两边之差小于第三边，任意点 \(P\) 都有 \(|PF_1| - |PF_2| \le |F_1F_2| = 6\)。

当且仅当点 \(P\) 落在以 \(F_2\) 为端点且背离 \(F_1\) 的射线（即 \(x \ge 3, y = 0\)）上时，才有 \(|PF_1| - |PF_2| = (x + 3) - (x - 3) = 6\)！

因此轨迹退化为一条射线！只有当常数严格满足 \(0 < 2a < 2c\) 且有绝对值时，才是双曲线。

5. 与双曲线 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\) 具有公共渐近线，且经过点 \((4, 3\sqrt{2})\) 的双曲线，其离心率 \(e\) 为：

B。设共渐近线的双曲线系方程为 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = \lambda \; (\lambda \ne 0)\)。

代入点 \((4, 3\sqrt{2})\)：\(\dfrac{16}{16} - \dfrac{18}{9} = 1 - 2 = -1 \implies \lambda = -1\)。

因此双曲线方程为 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = -1\)，即 \(\dfrac{y^2}{9} - \dfrac{x^2}{16} = 1\)。

注意！焦点轴发生了转变：正项变成了 \(y^2\)，因此焦点在 \(y\) 轴上！此时实半轴 \(a = 3\)，虚半轴 \(b = 4\)，半焦距 \(c = \sqrt{9 + 16} = 5\)。

离心率 \(e = \dfrac{c}{a} = \dfrac{5}{3}\)（若误以为焦点仍为 \(x\) 轴算得 \(e = \dfrac{5}{4}\) 则选 A 掉入陷阱！）。

挑战

6. 点 \(P\) 是双曲线 \(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1\) 上一点，\(F_1, F_2\) 分别为其左、右焦点。若 \(\angle F_1PF_2 = 90^\circ\)，则 \(\triangle F_1PF_2\) 的面积为：

B。设 \(r_1 = |PF_1|, r_2 = |PF_2|\)。

① 根据双曲线定义：\(|r_1 - r_2| = 2a = 2 \times 3 = 6\)；两边平方得：\(r_1^2 + r_2^2 - 2r_1r_2 = 36\)。

② 在直角 \(\triangle F_1PF_2\) 中，勾股定理：\(r_1^2 + r_2^2 = |F_1F_2|^2 = (2c)^2 = 4c^2\)。

已知 \(c^2 = a^2 + b^2 = 9 + 16 = 25\)，所以 \(4c^2 = 100\)。

③ 代入得：\(100 - 2r_1r_2 = 36 \implies 2r_1r_2 = 64 \implies r_1r_2 = 32\)。

直角三角形面积 \(S = \dfrac{1}{2}r_1r_2 = \dfrac{1}{2} \times 32 = 16\)（经典通式：双曲线焦点三角形面积 \(S_{\triangle F_1PF_2} = \dfrac{b^2}{\tan(\theta/2)} = \dfrac{16}{\tan 45^\circ} = 16\)！）。
