的左、右焦点分别为 F1​,F2​，离心率为 2，焦点到渐近线的距离为 6​。 过 F2​ 作直线 l 交双曲线 C 的右支于 A,B 两点，若 H,G 分别为 △AF1​F2​ 与 △BF1​F2​ 的内心，则 ∣HG∣ 的取值范围为（ ）

双曲线 C 的方程为 x2−3y2​=1，左、右焦点分别为 F1​,F2​。 过点 F2​ 作一直线与双曲线 C 的右半支交于点 P,Q，使得 ∠F1​PQ=90∘，则 △F1​PQ 的内切圆半径是。

打开这道题

思路

再以右焦点为原点，按焦点弦方向 参数化两个交点；双曲线焦半径公式会把两个内心坐标大幅化简。

解答

由离心率 e=2，有

c=2a,b=c2−a2​=3​a.

渐近线为 3​x±y=0，焦点 (2a,0) 到任一渐近线的距离为

223​a​=3​a=6​,

故 a=2​。

以 F2​ 为原点，取直线 l 的一个单位方向向量

u=(p,q),p2+q2=1.

把两交点写成

A=F2​+ru,B=F2​−tu(r,t>0).

双曲线右支上的点 X 满足 XF1​−XF2​=2a。比较距离平方可得

r=1−2p3a​,t=1+2p3a​.

两交点都在右支当且仅当 ∣p∣<1/2。

在三角形 AF1​F2​ 中，三边长依次涉及

F1​F2​=4a,AF2​=r,AF1​=r+2a.

由内心的边长加权坐标，以 F2​ 为原点并记横轴单位向量为 e=(1,0)，有

F2​H​=r+3a2ar​(u−e).

同理

F2​G​=−t+3a2at​(u+e).

代入 r,t 后得到

GH=1−p22a​(u−pe),

因而

∣HG∣=1−p2​2a​.

当 ∣p∣<1/2 时，

2a≤∣HG∣<3​4a​.

取 a=2​，所求范围为

[22​,346​​).

因此选择 A​。

复核

p=0 对应过焦点的竖直弦，能取到左端点；当 ∣p∣→1/2 时直线趋近渐近方向， 一个交点趋于无穷远，故右端点只能逼近而不能取到。

方法总结

过焦点的双曲线弦适合用单位方向与焦半径参数化。三角形内心用边长加权坐标表示后， 双曲线的焦点差性质常会消去复杂根式。

为什么评为 F4（会透露解法方向）

需将右支条件与焦半径差转为方向参数的精确限制，再利用两侧三角形的边长权重使内心差向量简化，最终分清最小值可达和上界对应渐近方向。

前题分别研究两个焦点三角形的内心距离，需要保直线方向的真实范围；后题研究跨两个弦端的直角三角形，用直角内切圆公式，不能把两个三角形的内心直接当成同一个点。
