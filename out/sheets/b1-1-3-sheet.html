4. A={x∣x<2}A=\{x\mid x<2\}A={x∣x<2}。如果全集 U=ZU=\mathbf ZU=Z（全体整数），∁UA\complement_U A∁U​A 是什么？

□ A{x∣x≥2}\{x\mid x\ge 2\}{x∣x≥2}□ B{x∣x>2}\{x\mid x>2\}{x∣x>2}□ C{2,3,4,… }\{2,3,4,\dots\}{2,3,4,…}
参考答案与防坑要点：
(1) [B]

B。先把 AAA 列出来：A={1,3,5,7,9}A=\{1,3,5,7,9\}A={1,3,5,7,9}。和 BBB 都有的是 333、999。选 C 的同学把 666 也算进去了，可 666 不是奇数；D 是并集。

(2) [A]

A。画数轴：AAA 从 −2-2−2 盖到 333，BBB 从 111 往右一直盖下去，合起来是 −2-2−2 右边的全部。−2-2−2 两个集合都不含，取不到。B 是交集；C 把端点 −2-2−2 算进去了；D 漏了 333 右边那一段。

(3) [B]

B（端点）。这里的 xxx 没说是整数，所以 111 和 222 之间的 1.51.51.5、1.991.991.99 都在两个集合里。

选 A 或 C 的同学，是把它们当成了整数；选 D 的同学，是看到符号方向相反就以为没有交集。画一条数轴，两段一叠就看出来了：左端 111 取到（≥\ge≥），右端 222 取不到（<<<）。

(4) [C]

C（全集）。补集只能在全集里找。全集是整数，补集里就只有整数，是 {x∈Z∣x≥2}\{x\in\mathbf Z\mid x\ge 2\}{x∈Z∣x≥2}。A 是 U=RU=\mathbf RU=R 时的答案；B 把端点 222 弄丢了：AAA 取不到 222，补集就取到 222。
