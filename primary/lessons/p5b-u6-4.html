记住这句话 整数加法的交换律 a + b = b + a、结合律 (a + b) + c = a + (b + c)，对分数加法同样适用。简便计算时，先把分母相同、能凑成整数的分数结合起来。
对：同分母的先凑

分母相同的分数先加，常常能凑成 1。

错：看到括号就通分

先想想有没有更简便的结合方法。

对：加法定律对分数也适用

换位置、加括号，结果不变。

错：减法也能随便加括号

a − b − c 不等于 a − (b − c)。

为什么加法定律对分数也成立？

加法交换律、结合律说的是“数加起来”的规律，不管加数是整数还是分数，把量合在一起，先合哪部分结果都一样。

怎样简便计算 + + ？

① 读懂题意

三项都是加数，先找分母相同、能凑整的一对。

② 列式与算理

交换并结合：( + ) + = 1 + = 1 又 。

③ 检查结果

两项已凑成 1，再加不到 1 的数，结果在 1 和 2 之间。换位置时，每个加数都保留。
