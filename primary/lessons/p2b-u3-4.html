万以内数的读写

家长先看（30 秒）
  • 今天是全单元最核心的一课：万以内数的读法和写法，难点全在“0”上。
  • 读数记住两句话：从高位读起，中间有一个 0 或两个 0，只读一个“零”；末尾不管有几个 0，都不读（如 4080 读作四千零八十，6009 读作六千零九，2700 读作二千七百）。
  • 写数记住一句话：从高位写起，中间或末尾哪一位上一个也没有，就在那一位上写 0 占位（如“七千零八”，百位和十位都没有，必须写两个 0：7008，一定别写成 708）。

每个喇叭按钮都能把字读出来；孩子认不全字时，点一下就行。

容易错：七千零八写成 708，或 5006 读两个零

听到一个“零”字就只写一个 0，把七千零八写成三位数 708；或者把 5006 读成“五千零零六”。

用数字卡片 5、8、0、0 摆出一个四位数，如果要求只读一个「零」，可以怎么摆？

只要把一个 0 或两个 0 放在数中间（百位或十位），就都只读一个「零」！
