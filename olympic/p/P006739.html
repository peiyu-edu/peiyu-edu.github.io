F2填空题集合与简易逻辑

已知

A={x∣811​<3x−1≤3, x∈Z},B={x∣x−3x+2​<0, x∈N},

则集合 C={m∣m=xy, x∈A, y∈B} 的元素个数是。

作答

分数写 a/b，根号写 √ 或 sqrt，π 写 pi 也可以。

标准答案：7

解析

提示

先分别解指数不等式和分式不等式，再直接枚举两个有限集合的乘积。

思路

是否把 0 计入 N 不会影响最后的乘积集合。

解答

由 3−4<3x−1≤31，得 −3<x≤2，故

A={−2,−1,0,1,2}.

又 −2<x<3 且 x∈N，所以按 N={1,2,…} 的约定有 B={1,2}。于是

C={−4,−2,−1,0,1,2,4},

共有 7​ 个元素。若 0∈N，则 B 中多出 0，但 0 已在 C 中，答案仍为 7。

复核

两个不等式的端点分别为左开右闭和双开；逐项计算 A⋅{1,2}，没有遗漏 −4、4，重复的 −2,0,2 只计一次。

方法总结

有限集合的乘积计数不能把两个集合的基数直接相乘；应先解出元素，再利用集合自动去重。本题还需检查自然数是否含零这一约定是否改变结论。

为什么评为 F2（会透露解法方向）

先分别解两个初等不等式并限制整数，再枚举小集合乘积并去除重复；自然数是否含0不影响最终集合，完整性易核。
