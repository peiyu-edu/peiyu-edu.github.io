认识负数

冬天的早晨，气象站记下两个温度：

两个都是「5 ℃」，可是一个暖和，一个冰冷。怎么在纸上把它们分开写？

下面哪种办法能让大家一眼分清「零上」和「零下」？

零下 5 ℃ 写成 −5 ℃，前面的「−」是负号。这样的数叫负数，这就是今天要认识的新朋友。

自己试试

「−8 ℃」应该怎么读？

数前面的小横线是负号，读「负」。9 − 8 里的横线是减号，读「减」，它们长得像，意思不同。

自己试试

下面哪两个量是「相反意义的量」？

相反意义的量：同一件事，方向相反。收入和支出，一个增加、一个减少，所以可以一个记正、一个记负。

比 0 大的数是正数，比 0 小的数是负数，0 既不是正数也不是负数；负数前面写「−」，读「负」。

两个容易错的地方

✗ 把「−3」读成「减三」 看见小横线就读「减」，把 −3 ℃ 说成「减三摄氏度」。
✓ 数前面的横线是负号，读「负」 −3 读作「负三」。9 − 3 里夹在两个数中间的才读「减」。
✗ 把 0 ℃ 当成「零上」或「没有温度」 说「0 ℃ 就是没有温度」「0 是正数」。
✓ 0 ℃ 是一个刻度，是零上和零下的分界 0 ℃ 是零上和零下的分界，不算零上，也不算零下；0 既不是正数，也不是负数。

直接用

1. 「−7」读作（ ）。

−7 读作「负七」，是比 0 小 7 的数。

2. 冰箱冷冻室的温度是 −18 ℃，它比 0 ℃ 低多少摄氏度？

−18 ℃ 就是零下 18 ℃，比 0 ℃ 低 18 度，填 18。

容易错

3. 下面关于 0 的说法，对的是（ ）。

正数比 0 大，负数比 0 小，0 是它们的分界，两样都不是。

4. 约定「收入记正，支出记负」。小明先收入 35 元，又买本子支出 12 元，账本上应分别记作（ ）。

收入 35 元记 +35，支出 12 元记 −12。「+」可以省略，+35 也写作 35。

5. 规定「向东为正」。小亮向西走了 40 米，应记作（ ）。

向东为正，向西就是相反的方向，记作 −40 米。如果规定向西为正，同一段路就记 +40 米：谁为正是事先说好的。

想一想

6. 以海平面为 0 米。某个湖的湖面海拔是 −40 米，湖面比海平面低多少米？

−40 米表示在海平面下面 40 米，比海平面低 40 米，填 40。

7. 以银行存款账户为观察对象，约定「存入为正、取出为负」。小华说：「我存入了 20 元，应记作 −20 元。」他的想法（ ）。

记账先看基准：约定存入为正、取出为负，存了 20 元就是 +20 元，取了 20 元才是 −20 元。
