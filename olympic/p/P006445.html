F3填空题数列的和

已知 Sn​ 为数列 {an​} 的前 n 项和，且

Sn​=89​an​−83​⋅3n+83​.

则使

i=1∑n​ai​Si​​<2024

成立的最大正整数 n 的值为。

作答

分数写 a/b，根号写 √ 或 sqrt，π 写 pi 也可以。

标准答案：1799

解析

思路

先用 Sn​−Sn−1​=an​ 求出通项，再把 Si​/ai​ 化成等比修正项，最后比较相邻两个整数。

解答

由 S1​=a1​ 得 a1​=6。当 n≥2 时，将题给等式在 n 与 n−1 处相减，得

an​=9an−1​+2⋅3n.

由此归纳可得

an​=9n−3n.

于是

ai​Si​​=89​−8⋅3i3​,

从而

i=1∑n​ai​Si​​=1618n−3+31−n​.

当 n=1799 时，该值小于

1618⋅1799−2​=2023.75<2024;

当 n=1800 时，该值大于

1618⋅1800−3​=2024.8125>2024.

而上式随正整数 n 严格增大，故最大值为

1799​.

复核

an​=3n(3n−1)>0，各分式均有意义；临界两个整数分别满足严格小于和严格大于条件。

方法总结

同时给出前 n 项和与第 n 项的线性关系时，先作相邻差通常能得到一阶递推；求和后再专门核查严格不等号端点。
