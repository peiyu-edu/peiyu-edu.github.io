26.1 二次函数的概念

从均匀匀速的一次直线，跃迁到弯曲加速的二次曲线！从周长固定的花坛面积、单循环比赛场次与年产量连续增长出发，看清二次函数的三大硬核特征，掌握一般形式 \(y=ax^2+bx+c\) 与实际自变量取值范围。

学校打算用长为 \(40\text{ m}\) 的防护栏围成一个矩形花坛。设矩形的一边长为 \(x\text{ m}\)，花坛的面积为 \(y\text{ m}^2\)。随着这一边长度 \(x\) 的改变，面积 \(y\) 会怎样随之变化？它们之间有什么数量关系？

矩形周长为 \(40\text{ m}\)，两邻边之和为 \(20\text{ m}\)。若一边长为 \(x\text{ m}\)，则另一邻边长为 \((20-x)\text{ m}\)。面积 \(y = x(20-x)\)。展开整理后，自变量 \(x\) 的最高次数是几？

B。展开解析式：\(y = x(20-x) = -x^2 + 20x\)。这里自变量 \(x\) 的最高次数是 2！

在八年级，我们学习了一次函数 \(y = kx + b\)（描述均匀、线性的变化）。但现实中更多问题（如面积、速度二次方、经济利润、多次增长率）涉及两个变量的乘积，由此产生了自变量为二次方的全新函数——二次函数。

1. 先认识几个词：什么是二次函数？

前置知识：函数与一次函数（回看 22.1、回看 23.1）。我们来看看一个函数要成为「二次函数」，需要满足哪三个硬指标：

  • 整式函数：等号右边必须是关于自变量的整式（未知数不能在分母里，也不能在根号里）。
  • 单自变量：只含有一个自变量 \(x\)。
  • 二次：整理化简后，自变量的最高次数必须是 2。

直觉微图解 ①二次函数识别门禁：核验三道关卡

关键条件 1为什么坚决要求 \(a \ne 0\)？

如果 \(a = 0\)，二次项直接消失！当 \(b \ne 0\) 时，式子退化为 \(y = bx + c\)（一次函数）；当 \(b = 0\) 时，变成常数函数 \(y = c\)。唯有 \(a \ne 0\)，才能保证函数具备二次方的非线性本质特征。

关键条件 2先化简展开，再判定次数

绝对不能一看见括号里有平方就断定是二次函数！如 \(y = (x+2)^2 - x^2 = 4x + 4\)，展开后两项二次项抵消，最高次数是 1，是一次函数。必须整理成一般形式后再审视。

4. 自己试试与典例示范

【自测 1】下列关于 \(x\) 的函数中，一定是二次函数的是（ ）

C。A 为一次函数；B、D 中分母含未知数，不是整式；C 展开得 \(y = 3x^2 - 6x + 4\)，是整式且最高次数为 2，二次项系数 \(3 \ne 0\)，是标准的二次函数。

【自测 2】若函数 \(y = (m-2)x^{m^2-2} + 3x - 1\) 是关于 \(x\) 的二次函数，则常数 \(m\) 的值等于（ ）

B。必须同时满足：① 最高次数 \(m^2 - 2 = 2 \implies m^2 = 4 \implies m = \pm 2\)；② 二次项系数 \(m - 2 \ne 0 \implies m \ne 2\)。综合两条件，舍去 \(m = 2\)，唯有 \(m = -2\) 合法！

【自测 3】已知二次函数 \(y = -x^2 + 4x\)。当自变量 \(x = 3\) 时，函数值 \(y\) 等于（ ）

A。代入计算：\(y = -(3)^2 + 4 \times 3 = -9 + 12 = 3\)。注意负号在平方外面，\(-x^2 = -(x^2)\)！

【例题 1·波利亚示范】一般形式整理与提取各项系数

题目：将函数 \(y = (2x-1)(x+3) - 5\) 化为二次函数的一般形式，并写出二次项系数、一次项系数和常数项。

第一步（理解题意）：按多项式相乘展开式子，合并同类项排成降幂，再提取各项带符号的常数。

第二步（拟定计划）：利用乘法分配律展开 \((2x-1)(x+3) = 2x^2 + 6x - x - 3 = 2x^2 + 5x - 3\)，再减 5。

第三步（规范解答）：
\(y = 2x^2 + 5x - 3 - 5 = 2x^2 + 5x - 8\)。
其中：二次项系数 \(a = 2\)，一次项系数 \(b = 5\)，常数项 \(c = -8\)。

第四步（回顾反思）：常数项包含前面的负号，是 \(-8\)，不是 \(8\)！

【例题 2·波利亚示范】参数存在性与双重门槛方程组

题目：已知关于 \(x\) 的函数 \(y = (k^2-k-2)x^2 + (k-2)x + 3\)，当 \(k\) 取何值时，它是二次函数？当 \(k\) 取何值时，它是一次函数？

分析与解：
(1) 若它是二次函数，则二次项系数必须非零：
\(k^2 - k - 2 \ne 0 \implies (k-2)(k+1) \ne 0 \implies k \ne 2 \text{ 且 } k \ne -1\)。
(2) 若它是一次函数，则必须满足二次项系数为 0，且一次项系数非零：
\(\begin{cases} k^2 - k - 2 = 0 \\ k - 2 \ne 0 \end{cases} \implies \begin{cases} k = 2 \text{ 或 } k = -1 \\ k \ne 2 \end{cases} \implies k = -1\)。

【例题 3·波利亚示范】几何实际建模与自变量范围确定

题目：用总长为 \(18\text{ m}\) 的铝合金条制作“日”字形窗框（外框是一个长方形，中间再加一根横梁，共 3 根横梁、2 根竖边）。若窗框的横梁长为 \(x\text{ m}\)，窗框的总透光面积为 \(S\text{ m}^2\)。求 \(S\) 关于 \(x\) 的函数解析式，并写出自变量 \(x\) 的实际取值范围。

规范解答：“日”字形窗框包含 3 根横梁和 2 根竖立边框。
3 根横梁共耗材 \(3x\text{ m}\)，剩余 2 根立柱总长为 \((18 - 3x)\text{ m}\)，每根竖直立柱长为 \(\dfrac{18-3x}{2}\text{ m}\)。
总透光面积 \(S = x \cdot \dfrac{18-3x}{2} = -\dfrac{3}{2}x^2 + 9x\)。
由于边长必须为正数：\(x \gt 0\) 且 \(18 - 3x \gt 0 \implies x \lt 6\)。
∴ 自变量 \(x\) 的取值范围为 \(0 \lt x \lt 6\)。

【例题 4·波利亚示范】已知函数值反求自变量（转化一元二次方程）

题目：在二次函数 \(y = x^2 - 2x - 3\) 中，已知函数值 \(y = 5\)，求自变量 \(x\) 的值。

规范解答：令 \(y = 5\)，代入得一元二次方程：
\(x^2 - 2x - 3 = 5 \implies x^2 - 2x - 8 = 0\)。
因式分解得 \((x-4)(x+2) = 0\)，解得 \(x_1 = 4, x_2 = -2\)。
核心启示：一个二次函数值可能对应 两个不同的自变量取值，这在几何上意味着水平直线与抛物线有两个交点！

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）没化简就下结论
❌ 典型错解：「\(y=(x+1)^2-x^2\) 里有平方，是二次函数」。
✅ 先展开再数次数：\((x+1)^2-x^2=x^2+2x+1-x^2=2x+1\)，两个 \(x^2\) 抵消，最高次数是 1，是一次函数。
翻车现场 ②忘了二次项系数不能为 0
❌ 典型错解：「\(y=(k-1)x^2+2x-3\) 是二次函数，所以 \(k\) 可以取任何数」。
✅ 一眼看清：要求 \(k-1\ne 0\)，即 \(k\ne 1\)。当 \(k=1\) 时，式子变成 \(y=2x-3\)，是一次函数。
翻车现场 ③系数认读漏了负号、乱了顺序
❌ 典型错解：「\(y=5-2x^2+3x\) 的二次项系数是 \(2\)，常数项是 \(0\)」。
✅ 一眼看清：先按降幂排好：\(y=-2x^2+3x+5\)。二次项系数 \(-2\)（负号跟着数走），一次项系数 \(3\)，常数项 \(5\)。
再深一点（可以先跳过）：为什么实际问题一定要写自变量范围？

解析式 \(y=x(20-x)\) 单看代数，\(x\) 取 \(25\) 也能算出 \(y=-125\)；可「面积为 \(-125\)」在花坛里根本不存在。范围 \(0 \lt x \lt 20\) 是把「代数式」变成「这个问题的函数」的最后一步，后面 26.4 求最大值时，它还会决定答案取在哪里。

【巩固 1】二次函数 \(y = -2x^2 + 4x - 1\) 的二次项系数、一次项系数和常数项分别是（ ）

B。二次项系数是 \(-2\)，一次项系数是 \(4\)，常数项是 \(-1\)。系数不含字母 \(x\)，且负号必带。

【巩固 2】某品牌手机两年前售价为 \(3000\) 元，由于技术更新，连续两年降价，平均每年降价率为 \(x\)，则两年后该手机售价 \(y\)（元）关于 \(x\) 的函数解析式为（ ）

C。一年后售价为 \(3000(1-x)\)，两年后售价为 \(3000(1-x)(1-x) = 3000(1-x)^2\)。展开为 \(y = 3000x^2 - 6000x + 3000\)，是标准的二次函数。

【巩固 3·易错题】若关于 \(x\) 的函数 \(y = (a+1)x^{|a|+1} + 2x - 5\) 是二次函数，则常数 \(a\) 的值是（ ）

提示

两个条件缺一不可：自变量的指数 \(|a|+1 = 2\)；二次项系数 \(a + 1 \ne 0\)。

A。由指数 \(|a|+1 = 2\) 得 \(|a| = 1\)，\(a = \pm 1\)；由二次项系数 \(a + 1 \ne 0\) 得 \(a \ne -1\)。综合只能取 \(a = 1\)。错选 C 是漏了系数不为 0 的条件：\(a=-1\) 时 \(y = 2x - 5\)，是一次函数。

【巩固 4·挑战题】已知二次函数 \(y = ax^2 + bx + c\) 的图象经过点 \((1, 0)\)，则代数式 \(a + b + c + 2026\) 的值是（ ）

提示

将 \(x = 1\) 直接代入解析式得到 \(a+b+c\) 与对应函数值的关系。

A。把点 \((1, 0)\) 代入二次函数解析式：\(a(1)^2 + b(1) + c = 0 \implies a + b + c = 0\)。因此 \(a + b + c + 2026 = 0 + 2026 = 2026\)。

【易错挑战】含参数函数「是否为二次函数」的分类讨论陷阱

题目：已知函数 \(y = (a-1)x^{a^2} + 2x - 3\)。
（1）当 \(a\) 为何值时，它是关于 \(x\) 的二次函数？
（2）当 \(a\) 为何值时，它是关于 \(x\) 的一次函数？

易错剖析：很多同学只令最高次数等于 2，却忘了检验二次项系数是否被消为 0！
（1）要成为二次函数，必须同时满足 \(\begin{cases} a^2 = 2 \\ a - 1 \ne 0 \end{cases}\)，解得 \(a = \pm\sqrt{2}\)。
（2）要成为一次函数，分两类情况：① 二次项系数为 0：\(a - 1 = 0 \implies a = 1\)，此时原式化为 \(y = 2x - 3\)，是一次函数；② 指数为 1 且合并后一次项系数非零：\(a^2 = 1\) 且 \(a - 1 \ne 0 \implies a = -1\)，此时原式化为 \(y = -2x + 2x - 3 = -3\)（常数函数，一次项抵消了，舍去！）；③ 指数为 0：\(a = 0\)，原式为 \(y = 2x - 4\)，也是一次函数。故 \(a = 1\) 或 \(a = 0\)。

巩固练习 1：下列函数中，\(y\) 是 \(x\) 的二次函数的是（ ）

C。A 化简得 \((x+2)^2-x^2=4x+4\)，是一次函数；B 的 \(x\) 在分母里，不是整式；C 展开得 \(y=-x^2+6x\)，最高次数 2、二次项系数 \(-1\ne0\)，是二次函数；D 最高次数是 3。选 C。

巩固练习 2：已知函数 \(y=(k-2)x^2+kx-1\)（\(k\) 为常数）。当 \(k\) 满足 ______ 时，它是二次函数；当 \(k=\) ______ 时，它是一次函数。

查看答案与解析，自行核对

答案：\(k\ne2\)；\(2\)

二次项系数 \(k-2\ne0\)，即 \(k\ne2\) 时是二次函数。\(k=2\) 时二次项消失，\(y=2x-1\)，一次项系数 \(2\ne0\)，是一次函数。

巩固练习 3：用长为 \(60\text{ m}\) 的篱笆围成一个矩形菜地（不靠墙），设矩形的一边长为 \(x\text{ m}\)，面积为 \(y\text{ m}^2\)。 (1) 求 \(y\) 关于 \(x\) 的函数解析式，并写出自变量 \(x\) 的取值范围； (2) 判断它是不是二次函数；若是，写出二次项系数、一次项系数和常数项； (3) 当 \(x=12\) 时，求 \(y\) 的值。

查看答案与解析，自行核对

答案：(1) \(y=-x^2+30x\)，\(0<x<30\)；(2) 是二次函数，二次项系数 \(-1\)，一次项系数 \(30\)，常数项 \(0\)；(3) \(216\)

(1) 周长 60，两邻边之和为 30，另一边长为 \((30-x)\text{ m}\)，\(y=x(30-x)=-x^2+30x\)；两边都要为正，\(x>0\) 且 \(30-x>0\)，故 \(0<x<30\)。(2) 是整式、最高次数 2，二次项系数 \(-1\ne0\)，是二次函数，\(a=-1,b=30,c=0\)。(3) \(y=-12^2+30\times12=-144+360=216\)。

巩固练习 4：某商品原价 \(200\) 元，连续两次降价，每次降价的百分率都是 \(x\)（\(0<x<1\)），两次降价后的售价为 \(y\) 元。 (1) 写出 \(y\) 关于 \(x\) 的函数解析式，并化成一般式 \(y=ax^2+bx+c\)； (2) 写出 \(a,b,c\) 的值； (3) 当 \(x=0.1\) 时，求 \(y\) 的值。

查看答案与解析，自行核对

答案：(1) \(y=200(1-x)^2=200x^2-400x+200\)；(2) \(a=200,\ b=-400,\ c=200\)；(3) \(162\)

(1) 第一次降价后是 \(200(1-x)\)，第二次降价后是 \(200(1-x)(1-x)=200(1-x)^2\)，展开得 \(y=200x^2-400x+200\)。(2) \(a=200,b=-400,c=200\)。(3) \(x=0.1\) 时 \(y=200\times0.9^2=200\times0.81=162\)。
