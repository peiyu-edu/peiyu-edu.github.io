4.4 对数函数

把对数 \(\log_a x\) 看成随 \(x\) 变化的量，它的图象长什么样、怎么用来比大小和解不等式？它和同底的指数函数又是什么关系？先从一个翻倍的例子开始。

一个细胞每过 \(1\) 小时分裂一次，数量翻一倍：开始 \(1\) 个，\(1\) 小时后 \(2\) 个，\(2\) 小时后 \(4\) 个，\(3\) 小时后 \(8\) 个……点下面的按钮对照上下两排刻度尺，看看细胞数 \(N\) 翻倍暴涨时，时间 \(t=\log_2 N\) 怎么一步步慢慢走：

数量变成 \(1024\) 个，过了几小时？

A。接着翻倍：\(16,32,64,128,256,512,1024\)，正好是第 \(10\) 小时。也就是 \(2^{10}=1024\)。

反过来问「数量是 \(N\)，过了几小时」，答案就是 \(\log_2 N\)：\(N=8\) 时 \(3\)，\(N=1024\) 时 \(10\)。\(N\) 变，小时数跟着变，这就是一个函数 \(y=\log_2 x\)。

注意两件事：数量从 \(1\) 涨到 \(1024\)，涨了一千多倍，小时数才从 \(0\) 到 \(10\)，长得很慢；数量只能是正数。这一节就讲这个函数的样子和用法。

1. 先认识几个词：对数函数图象形态与关于 y = x 的镜像反函数

要用到：4.3 的对数概念（回看 4.3）；4.2 的指数函数（回看 4.2）；3.1 的定义域与 3.2 的单调性（回看 3.1、3.2）。先看下面这幅微图解：

直觉微图解 ①对数函数图象形态与指对镜像反函数

单调性命脉增减分水岭（底数 \(a>1\) vs \(0<a<1\)）

底数 \(a>1\) 严格递增，脱去 \(\log\) 不等号同向；底数 \(0<a<1\) 严格递减，脱去 \(\log\) 不等号必须强力反向！且无论哪种，真数必须追加 \(N>0\) 下限！

图象铁律过定点 \((1,0)\) 与主对角线 \(y=x\) 对称

指数函数过 \((0,1)\) 在 \(x\) 轴上方；对数函数过 \((1,0)\) 在 \(y\) 轴右侧！两者的定义域与值域完全互换，坐标 \((s,t)\leftrightarrow(t,s)\) 关于直线 \(y=x\) 轴对称！

2. 核心数学性质与脱底数解不等式法则

\(\color{#2F7A56}{\underbrace{\log_a f(x) > \log_a g(x) \iff \begin{cases} f(x) > g(x) > 0, & a>1 \\ 0 < f(x) < g(x), & 0<a<1 \end{cases}}_{\text{对数不等式双铁律：真数大于 0 + 底数定不等号方向}}}\) \(\color{#966524}{\underbrace{y=\log_a x \xleftrightarrow{\text{关于 } y=x \text{ 对称}} y=a^x}_{\text{指对反函数：坐标对调 }(s,t)\leftrightarrow(t,s)}}\) \(\color{#3E5C76}{\underbrace{\log_a 1 = 0,\quad x \in (0, +\infty)}_{\text{定点 }(1,0)\text{ 与定义域生命线}}}\)

例 1（对数函数定义域求解）

求 \(y=\log_2(x-1)+\sqrt{3-x}\) 的定义域。

真数严格大于 \(0\)：\(x-1>0 \implies x>1\)；偶次根式非负：\(3-x\ge0 \implies x\le3\)。取交集得定义域为 \((1,3]\)。

自己试试：\(y=\lg(5-x)\) 的定义域是？

A。真数 \(5-x>0 \implies x<5\)。选 C 的同学把「严格大于 0」错写成了「大于等于 0」：\(x=5\) 时真数等于 \(0\)，\(\lg 0\) 无意义！

例 2（恒过定点分析）

不管 \(a\) 取何值（\(a>0\) 且 \(a\ne1\)），\(y=\log_a(x-1)+2\) 的图象恒过哪个定点？

令真数等于 \(1\)：\(x-1=1 \implies x=2\)。代入得 \(y=\log_a 1 + 2 = 0+2=2\)。图象必过定点 \((2,2)\)。

自己试试：不管底数 \(a\) 取多少，\(y=\log_a x\) 的图象一定经过哪个点？

B。\(\log_a 1=0\)，图象恒过 \((1,0)\)。选 A 的同学混淆了指数函数（\(y=a^x\) 过 \((0,1)\)）。两者关于 \(y=x\) 对称，横纵坐标正好颠倒！

3. 三步破题思维链：对数不等式求解与单调性比大小

例 3（示范：对数不等式求解三步法思维链）

解不等式 \(\log_{0.5}(2x-1) \ge -2\)；并比较 \(\log_2 3\) 与 \(\log_3 2\) 的大小。

👀 第一步化同底并严列真数非负： 将常数化为同底对数：\(-2 = \log_{0.5}(0.5)^{-2} = \log_{0.5} 4\)；
命脉约束：真数必须为正，先列 \(2x-1 > 0 \implies x > \dfrac{1}{2}\)！
🔧 第二步看底数反转不等号或借中间量 1： 底数 \(a = 0.5 \in (0,1)\)，函数单调递减，脱去 \(\log\) 时不等号必须反转：
\(2x-1 \le 4 \implies 2x \le 5 \implies x \le 2.5\)；
比大小：\(\log_2 3 > \log_2 2 = 1\)，\(\log_3 2 < \log_3 3 = 1\)。
🛡️ 第三步双向求交防下限漏球： 对不等式求交集：\(\dfrac{1}{2} < x \le 2.5\)！（若漏写真数大于 0，解出 \(x \le 2.5\) 包含负数直接全错！）
比大小结论：\(\log_2 3 > 1 > \log_3 2\)！

自己试试：解不等式 \(\log_3 x < 2\)。

B。\(2=\log_3 9\)，底数 \(3>1\)，方向不变：\(x<9\)；但必须追加真数大于 0：\(x>0\)，得 \(0<x<9\)。选 A 的同学漏了真数大于 0 下限！

例 4（指对互为反函数）

\(y=a^x\) 的图象过 \((2,9)\)。求 \(a\)，并说出它的反函数在 \(x=27\) 处的值。

\(a^2=9 \implies a=3\)。反函数是 \(y=\log_3 x\)，它过对调点 \((9,2)\)。\(x=27\) 时 \(y=\log_3 27=3\)。

自己试试：\(y=\log_a x\) 的图象过 \((4,2)\)。那么 \(y=a^x\) 的图象过哪个点？

A。横纵坐标对调：\((4,2) \to (2,4)\)。验算：\(\log_a 4=2 \implies a^2=4 \implies a=2\)，代入指数函数 \(2^2=4\)，完全吻合！

4. 用之前必查：三大高频翻车现场

翻车现场 ①解对数不等式只脱 log，漏写真数大于 0 下限
❌ 典型错解：解 \(\log_2(x-1)<2\)，直接脱 \(\log\) 写出 \(x-1<4 \implies x<5\)。
✅ 看右图秒懂真相：漏写真数大于 0 会引入负数灾难！必须联立 \(x-1>0\)，正确交集为 \(1<x<5\)！
翻车现场 ②底数介于 0 到 1 时，脱对数忘记反转不等号
❌ 典型错解：由 \(\log_{0.3}(x+1) > \log_{0.3} 3\)，盲目同向写出 \(x+1 > 3 \implies x > 2\)。
✅ 一眼看清真相：\(0<0.3<1\) 单调递减！脱对数必须反转不等号：\(0 < x+1 < 3 \implies -1 < x < 2\)！
翻车现场 ③求复合对数定义域，忽视内层整块大于 0
❌ 典型错解：求 \(y=\log_2(\log_3 x)\) 的定义域只写 \(x>0\)。
✅ 一眼看清真相：外层对数真数是 \(\log_3 x\)！必须满足 \(\log_3 x > 0 \implies x > 1\)！内外层真数必须层层保正！
再深一点（可以先跳过）

增长很慢：\(a>1\) 时 \(y=\log_a x\) 一直在增，但越来越慢。\(y=\log_2x\)：\(x\) 从 \(1\) 涨到 \(1024\)，\(y\) 才从 \(0\) 涨到 \(10\)；再涨到约 \(100\) 万，\(y\) 也才 \(20\)。

比增长快慢，要说清比谁、在哪：\(y=2^x\) 和 \(y=2x\) 在 \(x=1\)、\(x=2\) 处相等，在 \(1<x<2\) 时 \(2x\) 反而大（\(x=1.5\)：\(2^{1.5}\approx2.83\)，\(2\times1.5=3\)）。不能说「指数函数处处比一次函数大」，只能说 \(x\) 足够大以后指数函数远远超过一次函数。

严格说的「对数函数」：只指 \(y=\log_a x\) 这个样子，系数是 \(1\)、真数就是 \(x\)。\(y=2\log_3x\)、\(y=\log_2(x+1)\) 是由它变出来的函数，研究方法一样。

\(\log_2(x^2)\) 怎么拆：明确 \(x\ne0\) 之后，可以写成 \(2\log_2|x|\)，绝对值不能丢。

反函数：本节只要知道「同底的指数函数和对数函数互为反函数」，会用对称看图、找点就够了，不要求给一般的函数求反函数。

拖底数、拖 \(x\)：看图象和对称点

绿色是 \(y=\log_a x\)，橙色是 \(y=a^x\)，虚线是 \(y=x\)。拖金色点（它总在 \((a,1)\)）改底数；拖蓝色点（在 \(x\) 轴上）选一个 \(x\)，看曲线上的 \(P\) 和它关于 \(y=x\) 的对称点 \(P'\)。键盘：Tab 选中圆点，方向键移动。

试试：① 把底数从 \(2\) 拖到 \(5\)，看 \(x>1\) 那段怎么贴近 \(x\) 轴；② 把底数拖过 \(1\)，看图象从递增翻成递减；③ 把金色点拖到正好 \(a=1\) 会怎样？

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 函数 \(y=\log_{0.5}(x+2)\) 的定义域和单调性是？

A。真数 \(x+2>0\)，得 \(x>-2\)。底数 \(0.5<1\)；\(x\) 变大时真数 \(x+2\) 变大，对数值变小，所以递减。选 C 是解 \(x+2>0\) 时符号弄反了；选 D 是忘了真数要大于 \(0\)。

2. \(a=\log_3 0.5\)，\(b=\log_3 2\)，\(c=\log_2 3\)。大小关系是？

A。用中间量 \(0\) 和 \(1\)：\(a=\log_3 0.5<\log_3 1=0\)；\(0=\log_31<b=\log_3 2<\log_33=1\)；\(c=\log_2 3>\log_2 2=1\)。所以 \(a<0<b<1<c\)。

易错

3. \(y=\log_2(x^2)\) 和 \(y=2\log_2 x\) 是同一个函数吗？

B。「真数」这一条：\(\log_2(x^2)\) 只要 \(x^2>0\)，即 \(x\ne0\)；\(2\log_2x\) 要 \(x>0\)。定义域一个是 \(\{x\mid x\ne0\}\)，一个是 \((0,+\infty)\)，不是同一个函数。

比如 \(x=-2\)：\(\log_2 4=2\) 有意义，\(2\log_2(-2)\) 没意义。法则 \(\log_a M^r=r\log_aM\) 要求 \(M>0\)；\(x\) 可能是负数时，只能写成 \(\log_2(x^2)=2\log_2|x|\)。

4. 比较 \(\log_2 5\) 和 \(\log_3 5\) 的大小。

A。「同底才能用单调性」这一条：单调性说的是同一个底下 \(x\) 变大时 \(y\) 怎么变，这里底数变了，函数都换了。

找中间量 \(2\)：\(\log_2 5>\log_2 4=2\)，\(\log_3 5<\log_3 9=2\)。所以 \(\log_2 5>2>\log_3 5\)。

在「动手」的图里也看得出：\(x>1\) 时底数越大，图象越贴近 \(x\) 轴，同一个 \(x=5\) 处的值越小。

5. 解不等式 \(\log_{\frac12}(x-1)>-1\)，结果是：

C。「底和 1 比」这一条：\(-1=\log_{\frac12}2\)，不等式是 \(\log_{\frac12}(x-1)>\log_{\frac12}2\)。底数 \(\tfrac12\) 在 \(0\) 和 \(1\) 之间，函数递减，去掉 \(\log\) 时不等号反向：\(x-1<2\)。忘了反向就得到 A。

再加上真数 \(x-1>0\)，得 \(1<x<3\)。只反向、忘了真数，就得到 B——比如 \(x=0\) 时 \(\log_{\frac12}(-1)\) 根本没有意义。

挑战

6. \(\log_a\dfrac23<1\)（\(a>0\) 且 \(a\ne1\)），\(a\) 的取值范围是？

C。底数里有字母，分两种情况。把 \(1\) 写成 \(\log_a a\)：

\(a>1\)：递增，要 \(\dfrac23<a\)，而 \(a>1\) 时这总成立（其实这时 \(\log_a\dfrac23<0<1\)），所以 \(a>1\) 都行。

\(0<a<1\)：递减，不等号反向，要 \(\dfrac23>a\)，即 \(0<a<\dfrac23\)。

两种合起来是 C。只算了一种情况就会得到 A 或 B；D 是在 \(0<a<1\) 时忘了反向。
