为什么交换分子、分母能配成一对？

① 看 与 ：相乘后，分子是 3 × 7，分母是 7 × 3。

② 分子、分母的乘积相同，所以 = 1。换成别的非零分子、分母，这个理由仍成立。

③ 这说明“互为倒数”说的是两个数的配对关系，不是两个数相等。整数先写成分母为 1 的分数；小数先化成分数，就能用同样的办法。

④ 检查边界：1 × 1 = 1，所以 1 的倒数是 1；0 乘任何数都是 0，不能得 1，所以 0 没有倒数。

乘积是 1 的两个数互为倒数；求一个数（0 除外）的倒数，只要把分子、分母交换位置；1 的倒数是 1，0 没有倒数。

两个容易错的地方

✗ 用等号连接原数与倒数，或单独说某数是倒数 写成“ = ”，或说“ 是倒数”。
✓ 倒数是相互依存关系，原数与倒数不一定相等 写“ 的倒数是 ”，或“ 和 互为倒数”。
✗ 以为 0 的倒数是 0 误以为所有数都有倒数，说“0 的倒数还是 0”。
✓ 0 乘任何数都得 0，所以 0 没有倒数 只有 1 的倒数是它本身（1），0 没有倒数。
