小数的读法和写法

以小数点为界，左边按整数读写，右边一个数字一个数字读写。数位上没有数，就用 0 占位。

本单元按旧版教材编排。

小路用运动手环记下今天走了 6.08 千米。这个数应该怎么读？

对，读作「六点零八」。小数点后的每个数字，包括 0，都要从左到右按顺序读出来。这一课我们学会又快又准地读写小数。

1. 数位顺序表：以小数点为界

小数点左边是整数部分：个位、十位……；小数点右边是小数部分：十分位、百分位、千分位。点“▲”“▼”改变数字，选一选要显示几位小数，看它怎么写、怎么读。

2. 读：整数部分照整数读，点后一个一个读

例：25.403。整数部分 25 读“二十五”，小数点读“点”，小数部分依次读 4、0、3。

读作：二十五点四零三。注意不能读成“四百零三”，小数部分不当整数读。

整数部分是 0 的小数，也要读出“零”：0.76 读作零点七六。

自己试试

在教具里拨出 2.305，再看一看读法。下面哪一个读对了？

对。点后是 3、0、5，按顺序读「三、零、五」。

3. 写：先写整数部分，再点点，再写小数部分

写“十四点零二”：整数部分 14，写小数点，再依次写 0、2，得到 14.02。

写“零点九”：整数部分是 0，0 要写出来，是 0.9，不是 .9。

小数部分有空位时，用 0 占住数位：十分位是 0，百分位是 2，就要写 0 再写 2。

自己试试

在数位顺序表里，个位是 5，十分位是 0，百分位是 4。这个小数写作多少？

5.04。读作五点零四。

读小数：小数点左边按整数读，小数点读“点”，右边从左到右一个数字一个数字读。写小数：整数部分是 0 也要写 0，空着的数位用 0 占位。

两个容易错的地方

✗ 把小数部分当整数读

0.62 读成“零点六十二”。

✓ 点后数字逐个读

0.62 读作“零点六二”：十分位 6，百分位 2，不能合起来读。

✗ 漏掉数位上的 0

“七点零四”写成 7.4。十分位的 0 不见了，数变大了。

✓ 用 0 占位，整数部分也写 0

写成 7.04；“零点九”写成 0.9，不是 .9。

直接用

1. 4.27 怎么读？

B。整数部分 4 读「四」，小数点读「点」，再读 2、7。

2. 把「九点零六」写成小数。

9.06。

3. 把「零点二零五」写成小数。

0.205。

容易错

4. 在 8.634 里，数字 6 在哪一位上？

A。小数点后第 1 位是十分位，第 2 位是百分位，第 3 位是千分位。

5. 一个小数的整数部分是 12，十分位是 0，百分位是 7。写出这个小数。

12.07，读作十二点零七。

6. 15.409 的正确读法是哪一个？

B。点后三个数字逐个读：四、零、九。

想一想

7. 数位顺序表里，个位是 2，十分位是 0，百分位是 0，千分位是 5。这个小数写作多少？

2.005，读作二点零零五。

8. 在 4.093 里，百分位上的数字是几？

9。点后依次是 0（十分位）、9（百分位）、3（千分位）。
