30.1 直线与圆

从日出海平面到车轮着地！系统掌握直线与圆的三种位置关系（相交、相切、相离），吃透圆心到直线距离 \(d\) 与半径 \(r\) 的核心判据，攻克切线的性质定理与判定定理两大核心辅助线模型（“见切点连半径证垂直”、“无切点作垂直证半径”）。

  4. 理解切线的判定定理：经过半径的外端并且垂直于这条半径的直线是圆的切线；
  5. 攻克证明切线的两大经典辅助线黄金法则；
  6. 动手交互实验：直线与圆位置关系测算台、进阶切线性质与判定联动台（含重置按钮）；
  7. 中考真题演练，吃透切线几何证明与边角勾股计算。

设太阳的半径为 \(r = 70\text{ px}\)，地平线为水平直线 \(l\)，太阳圆心到海平面的距离为 \(d\)。当太阳刚好与海平面相切时，圆心到地平线的距离 \(d\) 与半径 \(r\) 的数量关系是（ ）

B。当直线与圆有且只有一个公共点时，直线与圆相切，此时圆心到直线的垂直距离恰好等于圆的半径，即 \(d = r\)。

若太阳还在海面下方一部分，直线与圆有两个公共点（相交），此时 \(d \lt r\)；若太阳完全升入空中，与海平面没有公共点（相离），此时 \(d \gt r\)。

在研究了点与圆的位置关系后，我们自然将视线拓展到直线与圆。 直线的无限延伸与圆的封闭曲线相遇，可能穿透、可能擦肩而过，也可能产生最奇妙的几何契合——相切。 切线是初中几何证明与几何综合题中出现频率最高、技巧性最强的核心载体。

1. 先认识几个词：割线、切线与切点

切线

与圆只有一个公共点；该点是切点。

割线

与圆有两个不同公共点，穿过圆内部。

抓住关系： \(\color{#2F7A56}{\underbrace{d}_{\text{圆心到直线距离}}}=\color{#966524}{\underbrace{r}_{\text{半径}}}\)

先检查条件，再使用关系；彩色标注帮助区分量。

为了精确刻画直线与圆的几何交互，数学上严格定义了以下词汇：

  • 割线（secant line）：与圆有两个公共点的直线叫作圆的割线，两公共点之间的线段即为圆的弦。
  • 切线（tangent line）：与圆有且只有一个公共点的直线叫作圆的切线。
  • 切点（point of contact / tangency）：切线与圆唯一的那个公共点叫作切点。
  • 圆心到直线的距离 \(d\)：从圆心向直线引垂线，垂线段的长度即为距离 \(d\)。

直觉微图解 ①直线与圆的三种位置关系（数形等价）

设 \(\odot O\) 的半径为 \(r\)，圆心 \(O\) 到直线 \(l\) 的距离为 \(d\)：相交 \(\iff d \lt r\)（2 个公共点）；相切 \(\iff d = r\)（1 个公共点）；相离 \(\iff d \gt r\)（0 个公共点）。

直觉微图解 ②切线的性质定理：“见切点，连半径，得垂直”

圆的切线垂直于经过切点的半径：若直线 \(l\) 切 \(\odot O\) 于点 \(A\)，则必有 \(OA \perp l\)（\(\angle OAP = 90^\circ\)），在 \(\text{Rt}\triangle OAP\) 中直接锁住勾股定理与互余关系。

直觉微图解 ③切线的判定定理与两大辅助线口诀

经过半径的外端并且垂直于这条半径的直线是圆的切线。已知公共点时“有交点，连半径，证垂直”；未知公共点时“无交点，作垂直，证半径（\(d=r\)）”。

2. 核心定理与辅助线推演

切线的判定与性质构成了初中几何互逆的两大支柱：

自己试试 1：已知 \(\odot O\) 的半径 \(r = 5\)，圆心 \(O\) 到直线 \(l\) 的距离 \(d = 4\)，则直线 \(l\) 与 \(\odot O\) 的位置关系是（ ）

A。因为 \(d = 4\)，\(r = 5\)，满足 \(d \lt r\)，所以直线与圆相交，有两个公共点。

自己试试 2：参照上方微图 2，已知 \(PA\) 是 \(\odot O\) 的切线，切点为 \(A\)，点 \(P\) 在 \(\odot O\) 外，连接 \(OP, OA\)。若 \(\angle OPA = 30^\circ\)，则 \(\angle AOP\) 的度数是（ ）

C。由切线性质定理，\(OA \perp PA\)，即 \(\angle OAP = 90^\circ\)。在 \(\text{Rt}\triangle OAP\) 中，\(\angle AOP = 90^\circ - \angle OPA = 90^\circ - 30^\circ = 60^\circ\)。

自己试试 3：点 \(A\) 在 \(\odot O\) 上，直线 \(l\) 经过点 \(A\)，要判定直线 \(l\) 是 \(\odot O\) 的切线，还必须补充的条件是（ ）

B。切线判定定理明确要求：“经过半径外端并且垂直于这条半径”。已知点 \(A\) 在圆上，只需证明 \(OA \perp l\) 即可断定直线 \(l\) 是切线。

典例 1（波利亚四步法）：“有交点，连半径，证垂直”证明圆的切线

【例 1】在 \(\triangle ABC\) 中，\(AB = AC\)，以 \(AB\) 为直径的 \(\odot O\) 交 \(BC\) 于点 \(D\)，过点 \(D\) 作 \(DE \perp AC\) 于点 \(E\)。求证：\(DE\) 是 \(\odot O\) 的切线。

  1. ① 读懂题意：已知等腰 \(\triangle ABC\)（\(AB=AC\)），\(AB\) 为 \(\odot O\) 直径，点 \(D\) 在 \(\odot O\) 上且在 \(BC\) 上，\(DE \perp AC\)。求证 \(DE\) 切 \(\odot O\) 于点 \(D\)。
  2. ② 想办法：直线 \(DE\) 与 \(\odot O\) 已有明确公共点 \(D\)！按口诀“有交点，连半径，证垂直”，第一步连接半径 \(OD\)；由于已知 \(DE \perp AC\)，只需证 \(OD \parallel AC\) 即可得 \(OD \perp DE\)。
  3. ③ 执行 + 执行中检查：连接 \(OD\)。在 \(\odot O\) 中，\(OB = OD\)，故 \(\angle ODB = \angle B\)；又在等腰 \(\triangle ABC\) 中，\(AB = AC\)，故 \(\angle C = \angle B\)。因此 \(\angle ODB = \angle C\)，由同位角相等得 \(OD \parallel AC\)（检查：也可连 \(AD\) 用直径所对圆周角 \(\angle ADB=90^\circ\) 及三线合一证 \(D\) 为 \(BC\) 中点，得中位线 \(OD \parallel AC\)）。因 \(DE \perp AC\)，故 \(OD \perp DE\)。又点 \(D\) 在 \(\odot O\) 上，所以 \(DE\) 是 \(\odot O\) 的切线。
  4. ④ 回头看：凡题目明确指出“交 \(\odot O\) 于点 \(D\)”或“过 \(\odot O\) 上一点 \(D\)”，第一步永远是连接半径 \(OD\)，再通过平行线或互余角转化证 \(90^\circ\)。
典例 2（波利亚四步法）：“无交点，作垂直，证半径”证明圆的切线

【例 2】在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(BD\) 平分 \(\angle ABC\) 交 \(AC\) 于点 \(D\)，以点 \(D\) 为圆心、\(DC\) 为半径作 \(\odot D\)。判断直线 \(AB\) 与 \(\odot D\) 的位置关系，并证明你的结论。

  1. ① 读懂题意：圆心为点 \(D\)，半径 \(r = DC\)，\(BD\) 是 \(\angle ABC\) 的平分线，\(\angle C = 90^\circ\)。要判断斜边 \(AB\) 与 \(\odot D\) 的位置关系。
  2. ② 想办法：题目未说明直线 \(AB\) 与 \(\odot D\) 是否有公共点！按口诀“无交点，作垂直，证半径”，过圆心 \(D\) 作 \(DH \perp AB\) 于点 \(H\)，再证 \(DH = DC = r\)。
  3. ③ 执行 + 执行中检查：过点 \(D\) 作 \(DH \perp AB\)，垂足为 \(H\)。因为 \(\angle C = 90^\circ\)，所以 \(DC \perp BC\)。又因为 \(BD\) 平分 \(\angle ABC\)，且 \(DC \perp BC, DH \perp AB\)，由角的平分线的性质定理得 \(DH = DC\)（检查：圆心 \(D\) 到直线 \(AB\) 的距离 \(d = DH\)，半径 \(r = DC\)，满足 \(d = r\)）。因此直线 \(AB\) 与 \(\odot D\) 相切。
  4. ④ 回头看：对比典例 1 与典例 2：已知公共点时“连半径证垂直”，未知公共点时“作垂直证 \(d=r\)”，两句口诀分工明确，切忌在未知公共点时凭空臆造“切点”连线。
逻辑剖析：切线判定定理中的两个条件为什么缺一不可？

1. 只垂直，不经过半径外端：例如过半径的中点作半径的垂线，它穿过圆内部，是割线而非切线！
2. 只经过外端，但不垂直：例如过圆上一点引一条与半径夹角为 \(60^\circ\) 的斜直线，它同样穿透了圆，有两个公共点，是割线而非切线。
只有同时满足“在圆上（半径外端）”且“垂直于半径”，直线才被牢牢锁定在唯一切点处！

中考经典：切线与角平分线的黄金搭档证明模型

在中考几何综合题中，经常出现如下经典模型：已知 \(OP\) 平分 \(\angle APB\)，\(OA \perp PA\)（即 \(PA\) 是切线）。要求证 \(PB\) 也是切线。
证明策略：过 \(O\) 作 \(OB \perp PB\) 于 \(B\)。由角平分线性质（角平分线上的点到角两边的距离相等），直接得出 \(OB = OA = r\)。由于垂线段等于半径，立即判定 \(PB\) 也是切线！

用之前必查：三大翻车现场

翻车 1
错误：垂直半径的直线一定相切
核对：过半径中点作垂线得到割线；还需经过半径外端。
翻车 2
错误：圆上一个点到直线距离等于半径
核对：判断位置关系要用圆心到直线的距离。
翻车 3
错误：已知圆上点就可认定直线相切
核对：直线还须经过该点并垂直过该点的半径。

练习 1：已知 \(\odot O\) 的直径为 10，直线 \(l\) 与 \(\odot O\) 相切，则圆心 \(O\) 到直线 \(l\) 的距离为（ ）

B。直径为 10，所以半径 \(r = 5\)。直线与圆相切时，圆心到直线的距离等于半径，即 \(d = r = 5\)。

练习 2：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ, AC = 3, BC = 4\)。以 \(C\) 为圆心，\(r\) 为半径作圆。若 \(\odot C\) 与斜边 \(AB\) 相切，则半径 \(r\) 等于（ ）

A。斜边 \(AB = \sqrt{3^2 + 4^2} = 5\)。利用等面积法求斜边上的高：\(\frac{1}{2}AC \times BC = \frac{1}{2}AB \times h \implies 3 \times 4 = 5 \times h \implies h = 2.4\)。圆与斜边相切时，半径等于圆心到直线的距离，即 \(r = h = 2.4\)。

练习 3：参照讲清楚微图 2 第 3 档（圆周角联动），已知直线 \(PA\) 是 \(\odot O\) 的切线，切点为 \(A\)，线段 \(PO\) 交 \(\odot O\) 于点 \(C\)，延长 \(PO\) 交 \(\odot O\) 于点 \(B\)，连接 \(AB\)。若 \(\angle OPA = 40^\circ\)，则 \(\angle ABO\) 的度数是（ ）

C。连接 \(OA\)，由切线性质定理得 \(OA \perp PA\)，所以 \(\angle AOP = 90^\circ - 40^\circ = 50^\circ\)。因为 \(OA = OB\)，\(\triangle OAB\) 是等腰三角形，且外角 \(\angle AOP = \angle ABO + \angle OAB = 2\angle ABO\)（或由同弧所对圆周角等于圆心角的一半），所以 \(\angle ABO = \frac{50^\circ}{2} = 25^\circ\)。

练习 4：已知点 \(P\) 是圆外一点，从点 \(P\) 引圆的切线，最多可以引（ ）条切线

D。过圆外任意一点，最多并且恰好可以向圆引 2 条切线，这两条切线具备优美的轴对称性，引出了下一个核心定理——切线长定理。

练习 5：已知直线 \(PA\) 切 \(\odot O\) 于点 \(A\)，线段 \(PO\) 交 \(\odot O\) 于点 \(C\)。若切线线段长 \(PA = 4\)，圆外线段 \(PC = 2\)，则 \(\odot O\) 的半径 \(r\) 为（ ）

提示

连接 \(OA\) 构造 \(\text{Rt}\triangle OAP\)，设半径 \(OA = OC = r\)，则斜边 \(OP = r + 2\)，列勾股定理方程求解！

C。连接 \(OA\)，由切线的性质定理得 \(\angle OAP = 90^\circ\)。设 \(\odot O\) 的半径 \(OA = OC = r\)，则 \(\text{Rt}\triangle OAP\) 的斜边 \(OP = OC + PC = r + 2\)。由勾股定理得 \(r^2 + 4^2 = (r + 2)^2\)，展开得 \(r^2 + 16 = r^2 + 4r + 4\)，解得 \(4r = 12 \implies r = 3\)。

易错辨析：切线与割线的公共点表述细节

“直线与圆有公共点”包含了两种可能：相交（2个公共点）或相切（1个公共点），因此此时满足 \(d \le r\)。只有题目强调“有且仅有一个公共点”或“有唯一点接触”时，才是相切（\(d = r\)）。审题切忌漏掉临界相切的情况！

巩固练习 1：\(\odot O\) 的半径为 \(3\)，直线 \(PA\) 与 \(\odot O\) 相切于点 \(A\)，点 \(P\) 在直线 \(PA\) 上且 \(PA = 4\)，连接 \(PO\)，则线段 \(PO\) 的长为（　）

C。连接切点与圆心得到半径 \(OA\)．因为直线 \(PA\) 与 \(\odot O\) 相切于点 \(A\)，根据切线的性质定理，切线垂直于过切点的半径，所以 \(OA \perp PA\)，即 \(\angle OAP = 90^\circ\)．在 \(\text{Rt}\triangle OAP\) 中，\(OA = 3\)，\(PA = 4\)，由勾股定理得斜边 \(PO = \sqrt{OA^2 + PA^2} = \sqrt{3^2 + 4^2} = 5\)，故选 C．

巩固练习 2：直线 \(AB\) 与 \(\odot O\) 相切于点 \(A\)，点 \(C\) 在 \(\odot O\) 上（不与点 \(A\) 重合），线段 \(BC\) 经过圆心 \(O\) 且与射线 \(AB\) 相交于点 \(B\)．若 \(\angle B = 40^\circ\)，连接 \(AC\)，则 \(\angle ACB\) 的度数为（　）

B。连接 \(OA\)．因为 \(AB\) 与 \(\odot O\) 相切于点 \(A\)，所以 \(OA \perp AB\)，即 \(\angle OAB = 90^\circ\)．在 \(\text{Rt}\triangle OAB\) 中，\(\angle B = 40^\circ\)，故 \(\angle AOB = 90^\circ - 40^\circ = 50^\circ\)．因为线段 \(BC\) 经过圆心 \(O\)，且 \(OA = OC\)，由圆周角定理（或三角形外角性质 \(\angle AOB = \angle OAC + \angle ACB = 2\angle ACB\)）得 \(\angle ACB = \frac{1}{2}\angle AOB = 25^\circ\)，故选 B．

巩固练习 3：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 6\)，\(BC = 8\)．以点 \(C\) 为圆心，\(4.8\) 为半径作 \(\odot C\)，则斜边 \(AB\) 所在的直线与 \(\odot C\) 的位置关系是______（填“相交”“相切”或“相离”）．

查看答案与解析，自行核对

答案：\(\text{相切}\)

在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 6\)，\(BC = 8\)，由勾股定理得斜边 \(AB = \sqrt{6^2 + 8^2} = 10\)．设圆心 \(C\) 到直线 \(AB\) 的距离（即斜边上的高）为 \(d\)，由等面积法 \(\frac{1}{2} AC \cdot BC = \frac{1}{2} AB \cdot d\) 得 \(d = \frac{6 \times 8}{10} = 4.8\)．因为圆心到直线的距离 \(d = 4.8\) 恰好等于 \(\odot C\) 的半径 \(r = 4.8\)，所以直线 \(AB\) 与 \(\odot C\) 相切．
