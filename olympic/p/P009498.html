F2选择题集合与简易逻辑

已知集合

A={(x,y)∣x+a2y+6=0},B={(x,y)∣(a−2)x+3ay+2a=0}.

若 A∩B=∅，则 a 的值是（ ）。

  1. (A)

    3 或 −1

  2. (B)

    0

  3. (C)

    −1

  4. (D)

    0 或 −1

作答

标准答案：D

解析

提示

两个平面点集都是直线。

思路

无交点要求系数行列式为零，还必须排除两条直线重合的参数。

解答

两方程关于 x,y 的系数行列式为

Δ=​1a−2​a23a​​=3a−a2(a−2)=−a(a−3)(a+1).

若 Δ=0，方程组有唯一解，交集不为空。因此只需检查 a=0,3,−1。

a=0 时，两直线为 x=−6 与 x=0，无交点；a=3 时，两式都是 x+9y+6=0，交集不为空；a=−1 时，两直线为 x+y=−6 与 x+y=−2/3，无交点。故所求为 a=0 或 a=−1，选 D​。

复核

a=3 时不仅系数成比例，常数项也相同，不能把它当作两条不同的平行线。a=0,−1 时，化简后的右端常数确实不同。

方法总结

行列式为零只是可能平行或重合。求交集为空时，必须逐一检查退化参数及常数项。

为什么评为 F2（会透露解法方向）

两直线无交点先要求系数行列式为零，再逐一检验退化参数下的常数项；平行与重合必须分开，不能把行列式为零直接当作交集为空。
