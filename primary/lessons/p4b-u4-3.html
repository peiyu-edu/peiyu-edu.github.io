小数的性质

0.6 和 0.60 写法不同，是不是同样大？用米尺把分的格子变细，看涂色的长度有没有变。

旧版目录，待新版核对

两段彩带，红的长 0.6 米，蓝的长 0.60 米。下面是它们的涂色米尺。哪一段长？

对，一样长。红的是 6 格，蓝的是 60 格，格子变小了、变多了，涂的长度没变。0.6 = 0.60 吗？下面用米尺来看。

1. 把格子变细，涂色不动

选一个涂色的长度，再点「10 份」「100 份」「1000 份」，看同一段要数多少份、怎么写。

涂几个 0.1 5

1000 份太密，图上只画每 10 份一条刻线。

2. 为什么大小没变

0.4 是 4 个 0.1。把每个 0.1 再平均分成 10 份，每份是 0.01，4 个 0.1 就变成 40 个 0.01，所以 0.4 = 0.40。再分一次，是 400 个 0.001，0.4 = 0.400。

涂的长度没变，只是换了更小的单位来数，个数变多。写出来，就是在小数的末尾添了 0；反过来，去掉末尾的 0，是换回大一点的单位。

自己试试

自己试试：把尺分成 100 份，涂 0.4 米，涂了多少份？

0.4 米 = 0.40 米，是 40 个 0.01，涂了 40 份。

自己试试

自己试试：小丽在 0.4 的前面添一个 0，写成 0.04。大小还一样吗？

B。0 添在前面，把 4 推到了百分位，数变小了。小数的性质说的是末尾。

小数的末尾添上 0 或者去掉 0，小数的大小不变。

两个容易错的地方

✗ 位数多就大

0.50 有两位，0.5 只有一位，所以 0.50 比 0.5 大。

✓ 末尾添 0，大小不变

0.5 是 5 个 0.1，0.50 是 50 个 0.01，涂的长度一样。

✗ 所有的 0 都能去，或者能添

600 去掉 0 变 6；7.08 去掉中间的 0 变 7.8；0.7 前面添 0 变 0.07。

✓ 只有小数末尾的 0 可以去、可以添

整数末尾的 0 和小数中间、前面的 0 都占着位置，动了数就变。

直接用

1. 下面哪个数和 0.9 的大小相同？

B。0.9 末尾添一个 0 得 0.90：9 个 0.1 就是 90 个 0.01，大小不变。

2. 把 4.60 化简（去掉末尾的 0），下面哪一个是化简后的结果？

4.60 末尾的 0 去掉，得 4.6，大小不变。

3. 2.4 里有 24 个 0.1。把它写成 2.400 以后，它里面有多少个 0.001？

24 × 100 = 2400，所以 2.400 里有 2400 个 0.001。大小没变，只是换了更小的单位来数，个数变多了。

容易错

4. 下面哪一个数去掉某个 0 以后，大小不变？

C。只有小数末尾的 0 可以去；中间的 0、整数末尾的 0 都是占位的，不能去。

5. 两瓶果汁，一瓶 2.5 升，一瓶 2.50 升。哪瓶多？

C。2.5 末尾添一个 0 是 2.50，大小不变，两瓶一样多。

6. 把 9.030 化简，下面哪一个是化简后的结果？

末尾的 0 去掉，得 9.03；9 和 3 中间的 0 要留着。

想一想

7. 3.5 末尾添一个 0 写成 3.50 以后，数字 5 所在的数位变了吗？

B。末尾添 0 是在最右边多了一位，前面的数字位置不动。添在前面才会把数字推到别的位去。

8. 把 1 米平均分成 1000 份。0.8 米等于多少份？

0.8 米 = 0.800 米，是 800 个 0.001 米，也就是 800 份。
