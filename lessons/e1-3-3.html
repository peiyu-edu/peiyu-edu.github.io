3.3 抛物线

到定点的距离等于到定直线的距离。抓住「到焦点的距离转化成到准线的垂直距离」，公式、几何性质与最值问题就全通了。

你一定见过这些神奇的生活场景：

  • 汽车远光灯与探照灯：光源只是一个小灯珠，经过后面的金属反射碗，射出来的却是一道笔直平行、照射数百米的光柱；
  • 卫星电视“大锅”与射电望远镜：面向深空，把来自遥远星系极其微弱的平行电磁波，全部反射汇聚在悬在前方的小盒子里；
  • 奥运圣火采集镜：太阳光平行照在凹面聚光镜上，所有光线瞬间聚焦于火炬尖端，引燃圣火。

它们不约而同采用了「抛物面」。这里的秘密究竟藏在哪里？

卫星接收天线（截面为抛物线）收集来自太空微弱的平行无线电波。高频接收器应该精准安装在哪个位置，才能接收到最集中的聚焦信号？

B。卫星天线的截面是一条抛物线，它的焦点就是所有平行入射波经反射后汇聚的共同点！反过来，探照灯把灯珠放在焦点，反射出的就是平行的强聚光束。

这一切神奇的光学与物理性质，都源于抛物线最纯粹的几何定义：平面内到定点（焦点）与到定直线（准线）的距离严格相等。这一节就从这个定义出发，弄清它的标准方程、性质和用法。

1. 先认识几个词

要用到：两点间距离公式、点到直线的距离（回看 2.3）。下面几个词都拿同一组例子说：定点 \(F(1,0)\)，定直线 \(l:\ x=-1\)。

课本用词：正统抛物线要求焦点不在准线上；若焦点落在准线上，轨迹退化为一条直线，不能直接套用抛物线标准方程。

焦点 \(F\)、准线 \(l\)：抛物线定义里的那个定点叫焦点，那条定直线叫准线。焦点不在准线上。

例：\(F(1,0)\) 不在 \(x=-1\) 上，可以做焦点和准线。

点到准线的距离：从点向准线作垂线，垂线段的长。准线是竖直线 \(x=a\) 时，就是横坐标之差的绝对值 \(|x_0-a|\)。

例：点 \((4,4)\) 到 \(x=-1\) 的距离是 \(|4-(-1)|=5\)。

焦准距 \(p\) 与焦半径 \(|PF|\)：焦点到准线的距离为 \(p\)（\(p>0\)）；顶点在正中间，离焦点、准线各 \(\dfrac{p}{2}\)。抛物线上一点 \(P\) 到焦点的距离叫焦半径，根据定义恒等于它到准线的距离。

例：\(F(1,0)\) 到 \(x=-1\) 的距离 \(p=2\)，点 \(P(4,4)\) 到准线距离 \(5\)，则焦半径 \(|PF|=5\)。

抛物线核心几何特征与焦半径拉直
定义临界 定点与定直线关系
  • \(F \notin l\)（正统抛物线）：到焦点距离等于到准线距离，离心率 \(e=1\)。
  • \(F \in l\)（临界退化）：轨迹退化为过 \(F\) 垂直于 \(l\) 的一条直线。
  • 顶点位置：恒在焦点与准线的正中点，到焦点与到准线距离均为 \(\dfrac{p}{2}\)。
方程定位 一次项定轴与除以4定点
  • 一次项定轴：一次项是 \(x\) 则轴为 \(x\) 轴；一次项是 \(y\) 则轴为 \(y\) 轴。
  • 符号定开口：正数开口向正半轴；负数开口向负半轴。
  • 系数除以4定焦点：一次项系数为 \(2p\)，焦点坐标非零项等于系数除以 4。

2. 定义与色彩语义主公式

平面内，到定点 \(F\) 和到定直线 \(l\)（\(F\) 不在 \(l\) 上）距离相等的点的轨迹叫抛物线。

\(P\) 在抛物线上 \(\iff |PF| = d(P, l)\)（焦半径等于准线距）
\(y^2 = \color{#0284c7}{2p}x \iff F\left(\color{#0284c7}{\frac{p}{2}}, 0\right),\quad l:\ x = -\color{#0284c7}{\frac{p}{2}}\quad (|PF| = x_0 + \color{#0284c7}{\frac{p}{2}})\)
\(x^2 = \color{#16a34a}{2p}y \iff F\left(0, \color{#16a34a}{\frac{p}{2}}\right),\quad l:\ y = -\color{#16a34a}{\frac{p}{2}}\quad (|PF| = y_0 + \color{#16a34a}{\frac{p}{2}})\)

例 1（看一遍怎么写）

到点 \(F(0,2)\) 和到直线 \(y=-2\) 距离相等的点，轨迹方程是什么？

设 \(P(x,y)\)。到 \(F\) 距离 \(\sqrt{x^2+(y-2)^2}\)；到直线 \(y=-2\) 距离 \(|y+2|\)。令两式相等并平方：

\(x^2+y^2-4y+4=y^2+4y+4 \implies x^2=8y\)。焦点在上方，开口向上。

自己试试：到点 \(F(0,1)\) 和到直线 \(y=-1\) 距离相等的点，轨迹方程是？

A。\(\sqrt{x^2+(y-1)^2}=|y+1|\)，平方得 \(x^2-2y+1=2y+1\)，即 \(x^2=4y\)。选 B 是把焦点到原点距离当成了 \(p\)；选 C 是轴搞反了；选 D 是开口方向反了。

3. 四种标准方程与三步破题链

🧩 典型例题：求抛物线焦点准线与标准方程
👀 信号
观察方程中一次项是谁（决定对称轴）以及系数正负（决定开口朝向）；已知焦点反推标准方程。
🔧 步骤
1. 化二次项为 1：确保标准形式；
2. 除以 4 得焦点：一次项系数绝对值是 \(2p\)，焦点坐标为系数除以 4；
3. 准线与焦点反号：如焦点为 \((0, \frac{p}{2})\) 则准线为 \(y = -\frac{p}{2}\)。
🛡️ 防坑
焦点坐标是系数除以 4，切忌误除以 2；平方项系数不为 1 时必须先移项化简。

例 2（正反双向练习）

（1）求 \(y^2 = 12x\) 的焦点和准线。

一次项是 \(x\)，系数 \(12>0\)，开口向右。\(2p=12 \implies \dfrac{p}{2}=3\)。故焦点 \(F(3,0)\)，准线 \(x=-3\)。

（2）焦点是 \((0,-3)\)，求抛物线的标准方程。

焦点在 \(y\) 轴负半轴，开口向下，设 \(x^2=-2py\)。由 \(\dfrac{p}{2}=3\) 得 \(2p=12\)，方程为 \(x^2=-12y\)。

自己试试：抛物线 \(x^2 = -8y\) 的焦点坐标是？

B。一次项是 \(y\)，对称轴是 \(y\) 轴；系数 \(-8<0\)，开口向下。\(2p=8 \implies \dfrac p2=2\)，焦点 \((0,-2)\)。

选 A 是轴搞错了；选 C 是只除了 \(2\)；选 D 是直接抄了一次项系数。

4. 焦半径转化与折线拉直

抛物线上的点，到焦点的距离要开根号算，到准线的距离只需做减法。把到焦点的距离换成到准线的距离，常常能把复杂的折线求最值变成垂线段最短。

例 3（折线拉直经典题）

点 \(A(3,2)\)，抛物线 \(y^2=4x\)，焦点是 \(F(1,0)\)，准线 \(l:\ x=-1\)。抛物线上一点 \(P\)，求 \(|PA|+|PF|\) 的最小值。

依定义，\(|PF|\) 等于 \(P\) 到准线的距离 \(|PH|\)，故 \(|PA| + |PF| = |PA| + |PH|\)。

先看 \(A\) 在哪：\(y_A^2=4 < 4\times 3=12\)，\(A\) 在抛物线内部。从 \(A\) 经 \(P\) 走到准线的折线长，不小于 \(A\) 到准线的垂直距离：\(3 - (-1) = 4\)。取等条件为 \(A, P, H\) 三点共线，此时 \(P(1,2)\)，故最小值为 \(4\)。

自己试试：抛物线 \(y^2 = 6x\) 上一点 \(P\) 到焦点的距离是 \(5\)，\(P\) 的横坐标是？

A。\(2p=6 \implies p=3\)，准线 \(x=-\dfrac32\)。焦半径 \(|PF|=x_0+\dfrac32=5 \implies x_0=\dfrac72\)。选 B 是减了 \(p=3\)；选 C 是加反了；选 D 是把距离直接当横坐标。

5. 三大翻车现场红绿对比卡

⚠️ 误区一：系数除以2当焦点
❌ 错误：\(y^2 = 12x\) 误得焦点 \((6, 0)\)
✅ 正确：一次项系数为 \(2p\)，焦点坐标为一次项系数除以 4！焦点为 \((3,0)\)。
⚠️ 误区二：平方项系数非 1 未化简
❌ 错误：\(y = \dfrac{1}{4}x^2\) 直接将 \(\dfrac{1}{4}\) 除以 4 得 \(\dfrac{1}{16}\)
✅ 正确：标准方程二次项系数必为 1！必须先化为 \(x^2 = 4y\)，再定焦点 \((0, 1)\)。
⚠️ 误区三：折线拉直忽略点A在外部
❌ 错误：求 \(|PA|+|PF|\) 最小值一律直接做准线垂线
✅ 正确：若 \(A\) 在抛物线外部，垂线段交不到抛物线；此时由 \(|PA|+|PF| \ge |AF|\)，最小值为 \(|AF|\)！
🔍 反例微图解：点 A 在内部 vs 外部的破题分流
点 \(A\) 在内部时，折线 \(A o P o H\) 可拉直为垂直准线的线段（最小值 \(x_A + \frac{p}{2}\)）；点 \(A\) 在外部时，直线 \(AF\) 与抛物线相交取到最小值 \(|AF|\)。
一句话：抛物线上点到焦点的距离，等于到准线的距离。定方程看开口和 \(p\)，算距离换成到准线。
再深一点（可以先跳过）

离心率：抛物线到焦点距离与到准线距离相等，故 \(e=1\)。

通径：过焦点且垂直于对称轴的弦，长为 \(2p\)。\(p\) 越大，开口越宽。

光学性质（阅读）：平行于对称轴射来的光，在抛物线上反射后都经过焦点；反之焦点光源反射后成平行光（探照灯原理）。

① 焦半径与准线等距折射微实验室

拖动抛物线上的动点 \(P\)（或选中后按键盘方向键），观察焦半径 \(PF\) 与到准线的垂线段 \(PH\)。切换 4 种开口方向或调节焦准距 \(p\)，体会等距性质。开启「光路演示」可查看平行光反射会聚于焦点 \(F\) 的动态光束。

从易到难排好了。前两道直接用，后三道防掉坑。

直接用

1. 已知抛物线方程为 \(y^2 = 8x\)，则该抛物线的焦点坐标与准线方程分别为？

A。一次项为 \(x\)，系数为 \(8 > 0\)，开口向右，焦点在 \(x\) 轴正半轴。

牢记核心法则：一次项系数除以 4 得到焦点坐标，\(\dfrac{8}{4} = 2\)，因此焦点为 \((2, 0)\)；除以 2 得到焦准距 \(p = 4\)，因此准线方程为 \(x = -2\)。

选 B 的同学除以了 2；选 C 搞错了坐标轴；选 D 则是直接抄了一次项系数。

2. 已知抛物线 \(x^2 = 4y\) 上有一点 \(P(x_0, 3)\)，则点 \(P\) 到该抛物线焦点的距离 \(|PF|\) 为？

B。直接用焦半径公式与准线转化！抛物线 \(x^2 = 4y\) 中 \(2p = 4 \implies p = 2\)，\(\dfrac{p}{2} = 1\)。准线方程为 \(y = -1\)。

由抛物线定义，曲线上点 \(P\) 到焦点的距离直接等于它到准线的垂直距离：\(|PF| = d(P, l) = y_0 - (-1) = 3 + 1 = 4\)。完全不需要求出 \(x_0\) 的具体数值！

易错

3. 抛物线 \(y = 2x^2\) 的焦点坐标是？

B。易错陷阱：非标准方程先化标！绝不能直接把 \(2\) 除以 4！标准方程中平方项系数必须是 1：将 \(y = 2x^2\) 两边同除以 2，化为标准形式 \(x^2 = \dfrac{1}{2}y\)。

此时一次项是 \(y\)，系数为 \(\dfrac{1}{2}\)，开口向上，焦点在 \(y\) 轴上。再将一次项系数除以 4：\(\dfrac{1/2}{4} = \dfrac{1}{8}\)，焦点坐标为 \(\left(0, \dfrac{1}{8}\right)\)。选 A 是直接拿 2 除以 4；选 C 是搞错了焦点所在轴。

4. 平面内到定点 \(F(1, 0)\) 的距离等于到定直线 \(l: x = 1\) 的距离的点的轨迹是？

C。易错陷阱：定点在定直线上时的轨迹退化！抛物线定义严格要求定点不在定直线上（\(F \notin l\)）。

本题中定点 \(F(1, 0)\) 恰好就在直线 \(l: x = 1\) 上！设动点 \(P(x, y)\)，它到直线 \(l\) 的垂足为 \(H(1, y)\)。由 \(|PF| = |PH|\) 得 \(\sqrt{(x-1)^2 + y^2} = |x-1|\)，两边平方即得 \((x-1)^2 + y^2 = (x-1)^2 \implies y^2 = 0 \implies y = 0\)。轨迹是过点 \(F\) 且垂直于 \(l\) 的一条直线（即 \(x\) 轴），并不存在抛物线！

5. 已知抛物线 \(C: y^2 = 4x\) 的焦点为 \(F\)，点 \(A(4, 2)\)，\(P\) 为抛物线 \(C\) 上的动点，则 \(|PA| + |PF|\) 的最小值是？

B。解题神器：准线转化破最值！抛物线 \(y^2 = 4x\) 的焦点为 \(F(1, 0)\)，准线为 \(l: x = -1\)。由定义，\(|PF| = d(P, l)\)（\(P\) 到准线的距离）。

所以 \(|PA| + |PF| = |PA| + d(P, l)\)。由垂线段最短，当过 \(A\) 作准线 \(l\) 的垂线交抛物线于 \(P\) 时，折线段化为直线段，取得最小值，最小值为点 \(A\) 到准线的距离：\(x_A - (-1) = 4 - (-1) = 5\)。

若误连 \(AF\) 算两点距离 \(\sqrt{(4-1)^2 + 2^2} = \sqrt{13} \approx 3.6\)（选 D），由于点 \(A\) 在抛物线内部，线段 \(AF\) 根本不与抛物线相交，动点 \(P\) 绝不可能落在线段 \(AF\) 上！
