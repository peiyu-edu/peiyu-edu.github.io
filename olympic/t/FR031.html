本专题核心公式速查

极限初步先要求把“越来越接近”写成可核查的尾部条件，再选择适合题型的接口。本专题配备9道练习题（8道竞赛真题、1道自编训练题）。P009775的三进距离对照、P014041的柯西尾项检验和P014054的有限等比求和例证是解答后的自写延伸，不增加原题条件或小问。

1. 先修与破题直觉：把“足够接近”翻成同一个尾部阈值，而不是为每个下标另选条件。先比较 1/n 与 (−1)n/n 的绝对误差。

2. 核心条件辨析：商的极限法则要求分母极限非零；柯西条件要求任意两尾项都近；任意两不同点的距离有统一正下界时，足够近会迫使尾项完全相等。

3. 典型误区对比：读下方零比零与距离约定两组卡，再做自测。每次先声明采用通常距离还是题目定义的新距离。

4. 方法迁移带练：在通常绝对值距离下，(−1)n/n 的误差不超过 1/n，所以趋零；整数值柯西列则取误差 1/2 推出尾部恒定，不能把这条结论搬给任意实数列。

5. 分级真题实战：先练“柯西尾项与统一误差”，再练“有限望远镜与端点极限”；涉及进距离时进入“将进距离翻译成整除”，最后用上下和夹逼核极限是否取到。

知识要点

极限要求同一个尾部阈值

实数列趋于 L，是指每个 ε>0 都能找到正整数 N，使全部 n≥N 满足 ∣xn​−L∣<ε。阈值可以依赖误差，却不能随尾项另选。例如 xn​=1/n、误差 1/10 时，选 N=11 即够；证明一般误差时可选整数 N>1/ε。有限次接近不能代替整个尾部接近。

柯西条件比较尾项彼此

柯西条件不预先指定极限点，而是要求每个 ε>0 都有共同阈值，使任意 m,n≥N 的距离小于误差。若两实数列各自柯西，分别把误差限为 ε/2，再取两个阈值的最大值，三角不等式便控制和序列。这里无需先求两列的极限，也不能分别用两个阈值却忘了让两种估计同时成立。

距离有正间隔时接近会变成相等

若不同点之间的距离总不小于某个固定 δ>0，柯西条件中取 ε=δ 就迫使尾项间距离为零，因此尾部恒定。通常汉明距离统计不同坐标的个数，如二进制字 0101 与 0111 的距离为 1，与 1100 的距离为 2。此时可取误差一。一般度量空间未必有这样的正间隔，不能照搬结论。

先说清楚采用哪一种距离

对素数 p，若非零有理数 r=psu/v 且 p 不整除 uv，定义 ∣r∣p​=p−s；零的范数为零。比如 ∣18/5∣3​=1/9，而 ∣5/9∣3​=9。于是 3n 到零的三进距离趋于零，通常实数距离却增大。要区分两种距离是否等价，可检验同一个序列对同一个候选极限的收敛判断是否一致。

整除幂次给出距离上界

若整数差被 ps 整除，其 p 进范数就不超过 p−s；精确赋值不一定必需。二项式展开可证明：ps∣u−1、s≥1 时，ps+1∣up−1。归纳时包括 p=2 的空中间和。例如 32−1=8 的二进赋值为 3，高于只要求至少为 2 的下界，不能把整除下界误写成精确等式。

先求有限式，再让下标趋于无穷

相邻因子经常能约消，但必须先保留有限乘积与起止下标。例如 ∏k=24​(1−1/k2)=5/8；分成两条相邻整数比的乘积后，可以推广出有限端点式。对数求和可先合并成正数的乘积，再做同样约消。最后应用极限运算或对数连续性；不能因每个远端因子趋于一，就断言整个乘积趋于一。

固定有限个幂逐项分类

对固定实数 r，∣r∣<1 时 rn→0；r=1 时恒为一，r=−1 时随奇偶振荡。这三类在幂的有限和中必须先分清。绝对值大于一的底数另需分析，不能套入这三类。例如 (−1/2)n 虽变号仍趋零，而 (−1)n 不收敛。只有求和项数固定时，才可直接逐项取极限；若有 n 项、每项均为 1/n，总和一直为一，不能把各项趋零当作和趋零。

用上下和的宽度证明唯一

连续非负递减函数的等分右端点和不大于曲线下面积，左端点和不小于面积；若严格递减，每个有限分割的两侧都严格。两和之差是 [f(0)−f(1)]/n。例如 f(x)=1−x、n=4 时，两和为 3/8、5/8，面积为 1/2。若一个固定数也落在所有这样收缩的区间中，它到面积的距离小于区间宽度，因而只能等于面积。

柯西尾项与统一误差

柯西条件要用同一个阈值控制任意两个尾项。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

在距离 d 下，序列柯西指每个 ε>0 都有 N，使任意 m,n≥N 满足 d(xm​,xn​)<ε。

为什么这样做

若不同点间距离至少为固定 δ>0，取误差 δ 就迫使尾项相同。通常实数距离没有这种统一间隔。

先看一道例题

例 1：倒数列

用柯西条件证明实数列 xn​=1/n 柯西，并给误差 1/10 的阈值。

怎么看出来：

任意尾项的差不超过较大的倒数。

解：

取整数 N>1/ε，则 m,n≥N 时 ∣1/m−1/n∣<1/N<ε。误差 1/10 可取 N=11。

答案：

柯西；可取 N=11。

二、什么时候想到它

题目里看到应该想到
需要写柯西定义，证明序列运算保持柯西，或利用离散距离判断尾部是否稳定。柯西条件要用同一个阈值控制任意两个尾项。
用柯西条件证明实数列 xn​=1/n 柯西，并给误差 1/10 的阈值。任意尾项的差不超过较大的倒数。

三、怎么用

  1. 写明距离和任意误差。
  2. 选一个共同阈值。
  3. 对任意两个尾项估计距离。
  4. 检查是仅接近还是因离散间隔而必须相等。

四、再做一道

例 2：整数列

通常距离下，整数值柯西列是否必定尾部恒定？

怎么看出来：

不同整数距离至少为一。

解：

取误差 1，有共同阈值后任意两尾项距离小于 1，整数差只能是 0，故尾部恒定。

答案：

必定尾部恒定。

五、容易错在哪

  • 只估计相邻项差趋零不能证明柯西，必须控制任意两个尾项。

将进距离翻译成整除

进距离中的趋近，取决于差被素数幂整除得多深。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

对素数 p 和非零有理数 r，设 r=pku/v 且 p 不整除 uv，定义 ∣r∣p​=p−k；∣0∣p​=0。距离为 ∣a−b∣p​。

为什么这样做

若 pk 整除整数差，则距离至多 p−k。实数绝对值很大的数，进距离却可能很小。

先看一道例题

例 1：幂列趋零

比较 3n 在通常距离和三进距离下是否趋于零。

怎么看出来：

计算同一数的两种范数。

解：

通常距离为 3n，不趋零；三进距离 ∣3n∣3​=3−n 趋零。

答案：

仅在三进距离下趋零。

二、什么时候想到它

题目里看到应该想到
题目指定素数的进距离，要求判断距离是否等价或证明幂序列收敛。进距离中的趋近，取决于差被素数幂整除得多深。
比较 3n 在通常距离和三进距离下是否趋于零。计算同一数的两种范数。

三、怎么用

  1. 明确采用哪个素数的进距离。
  2. 分解差中的素因数指数。
  3. 把指数下界改写为距离上界。
  4. 让上界趋零，不用实数大小代替。

四、再做一道

例 2：差的距离

求 82 与 1 的三进距离，再求它们的二进距离。

怎么看出来：

先算差八十一。

解：

82−1=81=34，故三进距离为 1/81。81 是奇数，二进赋值为 0，二进距离为 1。

答案：

分别为 1/81 和 1。

五、容易错在哪

  • 整除下界只给距离上界，不能无理由写成精确赋值。

有限望远镜与端点极限

先在有限范围精确约消，再对留下的端点式取极限。

完整讲解 · 例题 · 可练 4 题

一、是什么

先认识这些量

望远镜式是中间项相互抵消的和或积。乘积可先拆成相邻因子的比值，保留起点与终点。

为什么这样做

有限等式每步合法，才可应用极限运算。各因子趋于一，并不说明越来越长的乘积趋于一。

先看一道例题

例 1：平方因子积

求 ∏k=2n​(1−1/k2) 及其极限，n≥2。

怎么看出来：

拆为前后相邻整数比。

解：

通项为 ((k−1)/k)((k+1)/k)，两段积分别为 1/n 与 (n+1)/2，故总积 (n+1)/(2n)，极限 1/2。

答案：

(n+1)/(2n)；极限 1/2。

二、什么时候想到它

题目里看到应该想到
乘积中出现相邻因子，或对数项之和可先还原为可约消的正数乘积。先在有限范围精确约消，再对留下的端点式取极限。
求 ∏k=2n​(1−1/k2) 及其极限，n≥2。拆为前后相邻整数比。

三、怎么用

  1. 因式分解通项。
  2. 写出首尾几个因子看清抵消。
  3. 得到有限下标的精确式并核首项。
  4. 对端点式取极限，核分母与对数真数。

四、再做一道

例 2：对数和

求 ∑k=1n​ln((k+1)/k)−lnn 的极限。

怎么看出来：

真数全正，可以先并成乘积。

解：

有限和为 ln(n+1)，所求为 ln(1+1/n)，趋于 0。

答案：

0。

五、容易错在哪

  • 不要把有限端点项也约掉，尤其检查最小下标。

固定幂和的边界项筛查

固定有限个幂，先按底数绝对值小于一、等于一或等于负一分类。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

固定底数 r 满足 ∣r∣<1 时，rn→0；1n=1；(−1)n 随奇偶变化。

为什么这样做

有限项可逐项取极限；若负一项的振荡未抵消，和通常没有极限。项数随 n 增长时必须另证。

先看一道例题

例 1：有极限

求 1+(1/2)n+(−1/3)n 的极限。

怎么看出来：

两个底数绝对值都小于一。

解：

后两项分别趋于零，项数固定为三，故极限为 1。

答案：

1。

二、什么时候想到它

题目里看到应该想到
固定有限多个绝对值不超过一的常数的高次幂相加，尤其底数由三角函数或整除条件决定。 有限等比求和式仅剩固定底数的幂作余项时，也先核底数范围再取极限。固定有限个幂，先按底数绝对值小于一、等于一或等于负一分类。
求 1+(1/2)n+(−1/3)n 的极限。两个底数绝对值都小于一。

三、怎么用

  1. 列出每个固定底数。
  2. 先排绝对值大于一的其他情形。
  3. 保留一的贡献，处理负一振荡，舍去趋零项。
  4. 用奇偶子列核对结论。

四、再做一道

例 2：振荡

(−1)n+(1/2)n 有极限吗？

怎么看出来：

分别考察偶数与奇数下标。

解：

偶数子列趋于 1，奇数子列趋于 −1，两个不同，故原列无极限。

答案：

无极限。

五、容易错在哪

  • 负底数绝对值小于一仍然趋零；负一才保留大小不衰减的振荡。

上下和夹逼与严格可达

先证候选值始终在上下和之间，再用区间宽度趋零证明唯一。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

等分区间后，左端点和与右端点和分别取每小段左、右端点函数值乘段长。递减函数的左和较大。

为什么这样做

在 [0,1] 上两和之差为 [f(0)−f(1)]/n。固定数若在全部缩小区间内，与积分的距离只能为零。

先看一道例题

例 1：线性上下和

固定数 c 对每个正整数 n 都在 f(x)=1−x 的右和与左和之间，求 c。

怎么看出来：

两和围住面积二分之一。

解：

右和为 (n−1)/(2n)，左和为 (n+1)/(2n)，两者趋于 1/2，所以 c=1/2，并且每个有限 n 都严格夹住它。

答案：

1/2。

二、什么时候想到它

题目里看到应该想到
某固定数对每个分割数都位于两个相邻求和式之间，且两式的差趋于零。先证候选值始终在上下和之间，再用区间宽度趋零证明唯一。
固定数 c 对每个正整数 n 都在 f(x)=1−x 的右和与左和之间，求 c。两和围住面积二分之一。

三、怎么用

  1. 辨认左和与右和。
  2. 证明积分夹在其中。
  3. 算两和精确差并令其趋零。
  4. 若原条件严格，另核每个有限分割都严格。

四、再做一道

例 2：平方函数

f(x)=x2 在 [0,1] 的左、右等分和差是多少？两和共同极限为何？

怎么看出来：

函数递增，右和更大。

解：

差为 (12−02)/n=1/n。右和由平方和公式为 (n+1)(2n+1)/(6n2)，趋于 1/3；左和也趋于 1/3。

答案：

差 1/n；共同极限 1/3。

五、容易错在哪

  • 仅证明若存在则唯一不够，还要验证候选值确在每个规定区间中。

误区对照

容易误以为

1/n→0，所以 (1/n)/(1/n) 的极限是 0/0=0。

应当这样想

每一项分母都非零，商恒为一，极限为一。零比零不是可直接代入的数值，商法则要求分母的极限不为零。

为什么

分母逐项非零只保证商有定义，不保证可用非零分母极限的运算法则。

容易误以为

在集合 {0,1} 的通常距离下，柯西列只表示相邻项最终很近，因此可以永远交替零和一。

应当这样想

柯西要求任意两尾项距离都小；取 ε=1/2，不同的零和一相距一，不可同时出现在尾部，所以必须最终恒定。

为什么

必须同时核量词“任意两尾项”和距离的最小正间隔，不能只看某个相邻或子序列。
