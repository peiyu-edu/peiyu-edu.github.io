7.2 复数的四则运算

把 \(i\) 当作字母像多项式一样加减乘，唯独记住 \(i^2=-1\)；除法借共轭把分母实数化。

初中我们做多项式运算时，遇到含字母的式子如 \((2 + 3x) + (4 - x)\)，只需要把同类项合并，就得到 \(6 + 2x\)。

在复数中，复数由实部和虚部组成。如果把两个复数加起来，运算法则也是这样自然：

入门题：计算 \((1 + 2i) + (3 + 4i)\)，实部和实部相加、虚部和虚部相加，结果是？

A。很自然！实部 \(1+3=4\)，虚部 \(2+4=6\)，合起来就是 \(4+6i\)。

复数的加减法，跟多项式合并同类项一模一样：实部与实部算，虚部与虚部算。

那如果遇到两个虚数相乘（会出现 \(i^2\)），或者除法（分母上有 \(i\)），该怎么算？这一节我们就把复数的加、减、乘、除四则运算与几何意义一次讲透。

1. 先认识几个词

要用到：7.1 复数的概念与复平面（回看 7.1）；初中多项式乘法与平方差公式；平面向量的加减法则。

虚数单位 \(i\)：定义 \(i^2 = -1\)。加减乘时把它当成多项式中的字母，唯独在遇到 \(i^2\) 时替换为 \(-1\)。

例：\(3i \times 2i = 6i^2 = 6 \times (-1) = -6\)。

共轭复数：实部相同、虚部互为相反数的两个复数互为共轭。若 \(z = a + bi\)（\(a,b\in\mathbf{R}\)），其共轭记为 \(\overline{z} = a - bi\)。复平面上它们关于实轴对称。

例：\(3 + 2i\) 的共轭是 \(3 - 2i\)；纯虚数 \(5i\) 的共轭是 \(-5i\)；实数 \(4\) 的共轭就是它本身 \(4\)。

分母实数化：复数除法中，分子分母同乘分母的共轭复数，利用 \((c+di)(c-di) = c^2 + d^2\) 把分母变成非零正实数。

例：\(\dfrac{1}{1+i} = \dfrac{1-i}{(1+i)(1-i)} = \dfrac{1-i}{1^2 - i^2} = \dfrac{1-i}{2} = \dfrac{1}{2} - \dfrac{1}{2}i\)。

2. 加法与减法：实部虚部分别算，对应向量平行四边形法则

设 \(z_1 = a + bi\)，\(z_2 = c + di\)（\(a,b,c,d\in\mathbf{R}\)）：

加法：\((a+bi) + (c+di) = (a+c) + (b+d)i\)
减法：\((a+bi) - (c+di) = (a-c) + (b-d)i\)

几何意义：在复平面内，复数 \(z_1, z_2\) 对应向量 \(\overrightarrow{OZ_1} = (a,b)\)，\(\overrightarrow{OZ_2} = (c,d)\)。

  • 加法 \(z_1 + z_2\) 对应的向量是 \(\overrightarrow{OZ_1} + \overrightarrow{OZ_2}\)，完全符合平面向量的平行四边形法则（或三角形法则）。
  • 减法 \(z_1 - z_2\) 对应的向量是 \(\overrightarrow{Z_2Z_1}\)（从 \(Z_2\) 指向 \(Z_1\)）。它的模长 \(|z_1 - z_2|\) 就是复平面上点 \(Z_1\) 与 \(Z_2\) 之间的距离！

例 1（加减法示范）

已知 \(z_1 = 3 - 2i\)，\(z_2 = -1 + 4i\)，求 \(z_1 + z_2\) 与 \(z_1 - z_2\)。

解：

\(z_1 + z_2 = [3 + (-1)] + [-2 + 4]i = 2 + 2i\)。

\(z_1 - z_2 = [3 - (-1)] + [-2 - 4]i = 4 - 6i\)。

自己试试：已知 \(z_1 = 2 + 3i\)，\(z_2 = 4 - i\)，则 \(z_1 - z_2\) 等于？

B。实部相减：\(2 - 4 = -2\)；虚部相减：\(3 - (-1) = 4\)，所以结果为 \(-2 + 4i\)。

选 A 的同学把虚部算成了 \(3 - 1 = 2\)（漏掉了负负得正）；选 C 的同学把实部 \(2-4\) 错算成了 \(2\)。

3. 乘法与共轭：像多项式展开，遇见 \(i^2\) 换成 \(-1\)

两个复数相乘，不需要死记公式，直接按多项式乘法展开：

\((a+bi)(c+di) = ac + adi + bci + bdi^2\)

因为 \(i^2 = -1\)，最后两项合并整理得到：

\((a+bi)(c+di) = (ac - bd) + (ad + bc)i\)

共轭复数相乘的神奇性质：

\(z \cdot \overline{z} = (a+bi)(a-bi) = a^2 - b^2 i^2 = a^2 + b^2 = |z|^2\)

两个互为共轭的复数相乘，虚部相消，结果永远是一个非负实数，且正好等于该复数模长的平方！这是解决除法分母实数化的核心工具。

例 2（乘法与共轭示范）

计算：(1) \((2 + i)(3 - 2i)\)；(2) \((2 - 3i)(2 + 3i)\)。

解：

(1) 展开：\(2\times 3 + 2\times(-2i) + i\times 3 - 2i^2 = 6 - 4i + 3i - 2(-1) = (6+2) + (-4+3)i = 8 - i\)。

(2) 利用共轭乘积性质：\(2^2 + (-3)^2 = 4 + 9 = 13\)。

自己试试：计算 \((1 + 2i)(2 - i)\) 的结果是？

A。展开多项式：\(1\times 2 - 1\times i + 2i\times 2 - 2i^2 = 2 - i + 4i - 2(-1) = (2+2) + (-1+4)i = 4 + 3i\)。

选 B 的同学漏算了实部常数项；选 D 的同学把 \(i^2\) 当作 \(0\) 扔掉了。

4. 除法：分子分母同乘分母的共轭，将分母实数化

复数除法是乘法的逆运算。只要除数不为 0（即 \(c+di \ne 0\)，\(c^2+d^2 \ne 0\)），通过分子分母同乘分母的共轭复数 \(c-di\)：

\(\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{(c+di)(c-di)} = \dfrac{(ac+bd) + (bc-ad)i}{c^2+d^2} = \dfrac{ac+bd}{c^2+d^2} + \dfrac{bc-ad}{c^2+d^2}i\)

分母乘完变成了实数 \(c^2+d^2\)，之后把实部与虚部分开写成代数形式 \(A + Bi\) 即可。

例 3（除法示范）

计算 \(\dfrac{5+5i}{2+i}\)。

解：分子分母同乘 \(2-i\)：

\(\dfrac{5+5i}{2+i} = \dfrac{(5+5i)(2-i)}{(2+i)(2-i)} = \dfrac{10 - 5i + 10i - 5i^2}{2^2 - i^2} = \dfrac{15 + 5i}{4 - (-1)} = \dfrac{15 + 5i}{5} = 3 + i\)。

自己试试：化简 \(\dfrac{2}{1+i}\) 的结果是？

D。分子分母同乘 \(1-i\)：\(\dfrac{2(1-i)}{(1+i)(1-i)} = \dfrac{2(1-i)}{1 - i^2} = \dfrac{2(1-i)}{2} = 1 - i\)。

选 B 的同学分子乘了共轭，分母却忘了乘以共轭；选 A 的同学直接把分母移到分子变号，没有做分母实数化。

5. 用之前要注意（专题卡 M2-07-B 关键边界）

  1. 虚数单位 \(i\) 的周期性（周期为 4）：
    \(i^1 = i\)，\(i^2 = -1\)，\(i^3 = -i\)，\(i^4 = 1\)；接着 \(i^5 = i\)，\(i^6 = -1\dots\)
    任何正整数指数除以 4 看余数：连续 4 个连续整数次幂的和为零：\(i + i^2 + i^3 + i^4 = i - 1 - i + 1 = 0\)。
    提示：遇到高次幂时先除以 4，如 \(i^{100} = (i^4)^{25} = 1\)，\(i^{103} = i^3 = -i\)。
  2. 负数根式乘法绝对不能套用实数乘法公式：
    实数中当 \(a, b \ge 0\) 时才有 \(\sqrt{a}\cdot\sqrt{b} = \sqrt{ab}\)。如果两个都是负数，必须先化成虚数单位 \(i\) 的形式再相乘！
    \(\sqrt{-2}\cdot\sqrt{-3} = (\sqrt{2}i)\cdot(\sqrt{3}i) = \sqrt{6}i^2 = -\sqrt{6}\)。
    常见致命错误：直接写成 \(\sqrt{(-2)\times(-3)} = \sqrt{6}\)，符号完全相反！
  3. 复数没有大小顺序：
    实数可以在数轴上排大小（如 \(3 > 2\)），但复平面是二维的，虚数不能比较大小！我们不能写 \(2+3i > 1+4i\) 或 \(i > 0\)。
    只有实数或复数的模（模是非负实数）才可以比较大小（如 \(|2+3i| = \sqrt{13} < \sqrt{17} = |1+4i|\)）。
  4. 不能无条件搬用实数不等式与绝对值性质：
    实数中 \(|a+b| = |a| + |b|\)（当同号时）；但在复数中，\(|z_1 + z_2|\) 对应三角形的第三边，\(|z_1|\) 和 \(|z_2|\) 对应两边，一般满足向量三角不等式：
    \(||z_1| - |z_2|| \le |z_1 \pm z_2| \le |z_1| + |z_2|\)，等号当且仅当对应向量同向（或反向）共线时才取到。
  5. 实系数一元二次方程在复数集的根：
    若实系数方程 \(ax^2 + bx + c = 0\)（\(a\ne 0\)）的判别式 \(\Delta = b^2 - 4ac < 0\)，方程在实数范围无解，但在复数集内有一对互为共轭的虚根：
    \(x = \dfrac{-b \pm \sqrt{|\Delta|}i}{2a}\)。解题时必须明确指出是在复数范围内求解。
再深一点：高频简算结构与模的运算技巧（可以先跳过）

高考与模拟高频结构：

  • \((1+i)^2 = 2i\)，\((1-i)^2 = -2i\)（计算高次幂时常先平方）。
  • \(\dfrac{1+i}{1-i} = \dfrac{(1+i)^2}{2} = i\)；\(\dfrac{1-i}{1+i} = -i\)。
  • 模的乘除法性质：\(|z_1 \cdot z_2| = |z_1| \cdot |z_2|\)；\(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\)（\(z_2\ne 0\)）。很多题目只求模长时，先取模再乘除，比先化简复数再求模快数倍！

① 复平面的四则运算与几何向量

复平面上实轴为横轴，虚轴为纵轴。拖动圆点 \(z_1\)（松绿）或 \(z_2\)（赤金）（或选中后用键盘方向键操作），切换上方运算按钮，观察代数运算式与几何向量的动态对应。

方向键微调选中点坐标；拖动可自由改变位置。

从易到难排好了。前两道直接用，中间三道是典型易错陷阱，最后一道是挑战。

直接用

1. 计算 \((2 + i)(1 - 2i)\) 的结果是？

A。展开得 \(2 - 4i + i - 2i^2 = 2 - 3i - 2(-1) = 4 - 3i\)。

选 B 的同学漏算了 \(-2i^2 = +2\)；选 C 的同学虚部符号搞反。

2. 已知复数 \(z = \dfrac{3+i}{1-i}\)，则 \(z\) 的共轭复数 \(\overline{z}\) 是？

B。先化简 \(z\)：分子分母同乘 \(1+i\)，得 \(z = \dfrac{(3+i)(1+i)}{(1-i)(1+i)} = \dfrac{3+3i+i+i^2}{1-(-1)} = \dfrac{2+4i}{2} = 1 + 2i\)。

注意题目问的是共轭复数 \(\overline{z}\)，虚部变号，得 \(\overline{z} = 1 - 2i\)。选 A 的同学直接选了 \(z\) 而忘了求共轭！

易错

3. 计算 \(\sqrt{-3} \times \sqrt{-12}\) 的结果是？

B。在复数范围内，负数根式乘法不能套用实数乘法公式 \(\sqrt{a}\cdot\sqrt{b} = \sqrt{ab}\)！

必须先提虚数单位 \(i\)：\(\sqrt{-3} = \sqrt{3}i\)，\(\sqrt{-12} = 2\sqrt{3}i\)。相乘得 \((\sqrt{3}i)(2\sqrt{3}i) = 6i^2 = -6\)。

若直接算 \(\sqrt{(-3)\times(-12)} = \sqrt{36} = 6\) 就中了经典负号陷阱！

4. 计算 \(i + i^2 + i^3 + \dots + i^{2026}\) 的值是？

C。因为 \(i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1\)，连续四项之和 \(i + i^2 + i^3 + i^4 = 0\)。以 4 为周期循环。

一共有 2026 项，\(2026 \div 4 = 506\) 余 \(2\)。因此前 \(506\times 4 = 2024\) 项全部抵消为 0，只剩下最后两项：\(i^{2025} + i^{2026} = i^1 + i^2 = i + (-1) = -1 + i\)。

5. 设 \(z_1 = 3 + 4i\)，\(z_2 = 1 + 2i\)，下列结论正确的是？

B。复数没有本章意义下的大小顺序，只要含有非零虚部，两个复数就绝不能写大于号或小于号！A、C、D 都是严重的概念错误。

但是，模长 \(|z_1| = \sqrt{3^2+4^2}=5\)，\(|z_2| = \sqrt{1^2+2^2}=\sqrt{5}\)，模长是实数，可以比较大小，\(|z_1| > |z_2|\)。

挑战

6. 已知复数 \(z\) 满足 \((1+i)z = |3 - 4i| + 3i\)，则复数 \(z\) 的模 \(|z|\) 是？

A。注意 \(|3-4i| = \sqrt{3^2+(-4)^2} = 5\) 是实数，所以等式为 \((1+i)z = 5 + 3i\)。

方法一（速算模长）：两边同时取模，\(|(1+i)z| = |1+i| \cdot |z| = \sqrt{2}|z|\)。右边模长 \(|5+3i| = \sqrt{5^2+3^2} = \sqrt{34}\)。所以 \(|z| = \dfrac{\sqrt{34}}{\sqrt{2}} = \sqrt{17}\)。

方法二（先求 \(z\)）：\(z = \dfrac{5+3i}{1+i} = \dfrac{(5+3i)(1-i)}{2} = \dfrac{8-2i}{2} = 4-i\)，则 \(|z| = \sqrt{4^2+(-1)^2} = \sqrt{17}\)。
