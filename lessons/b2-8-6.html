8.6 空间直线、平面的垂直

从线线垂直、线面垂直推进到面面垂直。牢牢抓住判定定理的「两条相交直线」红线，理清线面角（范围0°至90°）与二面角（可钝角）的本质差异与转化链条。

3D 舞台：线面垂直的判定、线面角与二面角在长方体里现场作图，角度长度实时现算 →

在建筑工地上，工人师傅准备竖立一根垂直于地面的水泥立柱 \(l\)。他拿一把直角尺紧贴地面，发现立柱与地面画出的某一条施工墨线 \(m\) 完全成 \(90^\circ\) 直角。先点下面的按钮，看看只垂直一条墨线时立柱会发生什么：

仅凭「立柱与地面上的这一条墨线垂直」，这根立柱就一定垂直于地面吗？

B。不一定垂直！

看上方的实验图：把墨线 \(m\) 当作转轴，立柱 \(l\) 绕着 \(m\) 向左或向右歪倒 \(25^\circ\) 时，它和墨线 \(m\) 之间始终保持 \(90^\circ\) 直角，但整根柱子已经明显斜着歪倒了！

要想让立柱稳稳垂直于地面（点上方第 3 个按钮），工人师傅必须在地面上画两条相交的墨线 \(m, n\)，使立柱与这两条相交线都垂直！这种从「线线垂直」迈向「线面垂直」，再到「面面垂直」的严密转化，就是本节要系统掌握的核心思想。

1. 先认识几个词

要用到：8.4 空间位置关系、8.5 空间平行、直角三角形与正射影。

直观微图解
线面垂直必须垂直于面内两条相交直线；面面垂直性质必须垂直于两平面交线！
线面垂直 空间全向正交（线线 ⇄ 线面）

判定要件：一条直线垂直于平面内两条相交直线（\(l \perp a, l \perp b, a \cap b = P\)）。

性质威力：若 \(l \perp \alpha\)，则它垂直于该平面内的任意一条直线！

线面角：相交斜线与正射影所成的锐角；含于面内或平行时规定为0°，垂直时为90°，总体范围 \([0^\circ, 90^\circ]\)。

面面垂直 二面角直角（交线做桥梁）

本质定义：两平面相交所成的二面角为直二面角（平面角为 \(90^\circ\)）。

性质铁律：在面内必须垂直于交线的直线，才垂直于另一平面！

二面角范围：\([0^\circ, 180^\circ]\)（注意：二面角完全可以为钝角！）。

正射影与线面角：从平面外一点向平面引垂线，垂足叫正射影；斜线上所有点的正射影构成的直线叫斜线的射影。斜线和它在平面上的正射影所成的角叫做直线与平面所成的角，范围 \([0^\circ, 90^\circ]\)。

二面角的平面角：在二面角的棱上任取一点，在两个半平面内分别作垂直于棱的两条射线，这两条射线所成的角叫二面角的平面角，范围 \([0^\circ, 180^\circ]\)。

2. 线面垂直的判定与性质：线线垂直 ⇌ 线面垂直

$$\color{#0284c7}{\text{判定定理（相交线）：} \left.\begin{aligned} &l \perp a, \ l \perp b \\ &a \subset \alpha, \ b \subset \alpha \\ &a \cap b = P \end{aligned}\right\} \implies l \perp \alpha} \qquad \color{#059669}{\text{性质定理（任意线）：} \left.\begin{aligned} &l \perp \alpha \\ &c \subset \alpha \end{aligned}\right\} \implies l \perp c}$$
平行线推论：垂直于同一个平面的两条直线互相平行（\(a \perp \alpha, b \perp \alpha \implies a \parallel b\)）。

例 1（鳖臑模型 · 看一遍怎么写）

在三棱锥 \(P-ABC\) 中，\(PA \perp \text{底面 } ABC\)，底面满足 \(\angle ABC = 90^\circ\)（即 \(AB \perp BC\)）。证明：\(BC \perp PB\)。

① 因为 \(PA \perp \text{底面 } ABC\)，且 \(BC \subset \text{底面 } ABC\)，由线面垂直性质得 \(PA \perp BC\)，即 \(BC \perp PA\)。

② 又已知 \(BC \perp AB\)，且 \(PA \cap AB = A\)，由判定定理得 \(BC \perp \text{平面 } PAB\)。

③ 因为 \(PB \subset \text{平面 } PAB\)，由线面垂直性质，即证得 \(BC \perp PB\)。

自己试试：在上述三棱锥 \(P-ABC\)（\(PA \perp \text{底面 } ABC\)，\(\angle ABC = 90^\circ\)）中，它的 4 个面 \(\triangle ABC, \triangle PAB, \triangle PAC, \triangle PBC\) 中，直角三角形的个数是：

D。4 个面全都是直角三角形！

① 底面 \(\triangle ABC\)：已知 \(\angle ABC = 90^\circ\)；

② 侧面 \(\triangle PAB\)：\(PA \perp \text{底面 } ABC \implies PA \perp AB\)，\(\angle PAB = 90^\circ\)；

③ 侧面 \(\triangle PAC\)：同理 \(PA \perp AC\)，\(\angle PAC = 90^\circ\)；

④ 侧面 \(\triangle PBC\)：由例 1 已证 \(BC \perp PB\)，\(\angle PBC = 90^\circ\)。

《九章算术》称这种四个面全为直角三角形的四面体为「鳖臑」（biē nào），是立体几何中最基础、最高频的垂直模型。

3. 线面角：找垂足、连射影、解直角三角形

① 找垂足：过斜线上一点向平面引垂线，定出垂足；
② 连射影：连接斜足与垂足，得到斜线在平面上的正射影；
③ 解直角三角形：斜线、垂线段、射影构成直角三角形，斜线与射影的夹角就是线面角 \(\theta\)，满足 \(\sin\theta = \dfrac{\text{垂线段长}}{\text{斜线段长}}\)。

例 2（正方体体对角线与底面线面角）

正方体 \(ABCD-A_1B_1C_1D_1\) 棱长为 \(1\)。求体对角线 \(A_1C\) 与底面 \(ABCD\) 所成角的正切值 \(\tan\theta\)。

\(A_1A \perp \text{底面 } ABCD\)，垂足为 \(A\)。斜足为 \(C\)，所以 \(AC\) 是 \(A_1C\) 在底面的正射影，\(\angle A_1CA\) 即为所求线面角。在 \(\text{Rt}\triangle A_1AC\) 中，\(A_1A = 1\)，\(AC = \sqrt{2}\)，所以 \(\tan\theta = \dfrac{A_1A}{AC} = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}\)。

自己试试：在棱长为 \(1\) 的正方体 \(ABCD-A_1B_1C_1D_1\) 中，体对角线 \(A_1C\) 与侧面 \(BCC_1B_1\) 所成角的正弦值为：

A。体对角线长 \(A_1C = \sqrt{1^2+1^2+1^2} = \sqrt{3}\)。

从 \(A_1\) 向侧面 \(BCC_1B_1\) 引垂线，垂足为 \(B_1\)（\(A_1B_1 \perp\) 侧面），垂线段长 \(A_1B_1 = 1\)。斜足为 \(C\)，射影为 \(B_1C\)。在 \(\text{Rt}\triangle A_1B_1C\) 中，线面角为 \(\angle A_1CB_1\)，正弦值为：

$$\sin\angle A_1CB_1 = \frac{A_1B_1}{A_1C} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

选 B 是算成了余弦值；选 D 误把面对角线当成了体对角线。

4. 面面垂直与三步思维链

$$\color{#d97706}{\text{面面垂直判定（线面推面面）：} \left.\begin{aligned} &l \perp \beta \\ &l \subset \alpha \end{aligned}\right\} \implies \alpha \perp \beta} \qquad \color{#ec4899}{\text{面面垂直性质（垂直于交线）：} \left.\begin{aligned} &\alpha \perp \beta, \ \alpha \cap \beta = l \\ &a \subset \alpha, \ a \perp l \end{aligned}\right\} \implies a \perp \beta}$$
核心铁律：面面垂直性质是立体几何中最关键的立高引线工具！必须牢记“面内垂直于交线”才能推出垂直底面。
典型题三步思维链：面面垂直性质导出线面垂直（正交破题）

题目：如图，平面 \(PAC \perp \text{平面 } ABC\)，\(\triangle PAC\) 是等边三角形，\(D\) 为 \(AC\) 的中点，底面 \(\triangle ABC\) 中 \(AB = BC\)。证明：① \(PD \perp \text{平面 } ABC\)；② 平面 \(PBD \perp \text{平面 } PAC\)。

1
👀 第一眼破题信号： 两平面垂直（\(PAC \perp ABC\)），它们的交线是 \(AC\)！面 \(PAC\) 内有等边三角形中点 \(D\)，三线合一必有 \(PD \perp AC\)。这是启动面面垂直性质定理的核心触媒。
2
🔧 第二步套公式/方法（面面性质推线面）：

① 证 \(PD \perp \text{平面 } ABC\)：
在面 \(PAC\) 内，因为 \(\triangle PAC\) 是等边三角形且 \(D\) 为 \(AC\) 中点，所以 \(PD \perp AC\)。
又因为平面 \(PAC \perp\) 平面 \(ABC\)，两平面交线为 \(AC\)，且 \(PD \subset\) 平面 \(PAC\)。
由面面垂直性质定理，直接得出 \(PD \perp \text{平面 } ABC\)！

② 证平面 \(PBD \perp \text{平面 } PAC\)：
底面 \(\triangle ABC\) 中，\(AB = BC\)，\(D\) 是底边 \(AC\) 中点，所以 \(BD \perp AC\)。
由 ① 知 \(PD \perp \text{平面 } ABC\)，而 \(BD \subset\) 平面 \(ABC\)，所以 \(PD \perp BD\)，即 \(BD \perp PD\)。
因为 \(AC \cap PD = D\)，且 \(AC, PD \subset\) 平面 \(PAC\)，由线面垂直判定定理，得 \(BD \perp \text{平面 } PAC\)！
又 \(BD \subset\) 平面 \(PBD\)，由面面垂直判定定理，得 平面 \(PBD \perp \text{平面 } PAC\)。

3
🛡️ 第三步必查防坑结论： ① 严禁用「面内任意直线垂直底面」来写证明！面内直线若不垂直于交线，绝不可能垂直底面；
② 要证面面垂直，首选在其中一个面内找一条线垂直于另一平面。

自己试试：已知平面 \(\alpha \perp \text{平面 } \beta\)，\(\alpha \cap \beta = l\)，直线 \(a \subset \alpha\)。若要得出 \(a \perp \beta\)，还需要补充的充要条件是：

D。面面垂直的性质定理明确要求：线必须垂直于交线，才能推出线面垂直。选 C 把面面垂直的性质误当成了「面内任意直线都垂直另一平面」，这是极高频的经典误区。

5. 二面角平面角的构造与计算

例 3（正四面体的二面角）

正四面体 \(P-ABC\) 的所有棱长都为 \(a\)，求二面角 \(P-AB-C\) 的平面角的余弦值 \(\cos\theta\)。

取棱 \(AB\) 的中点 \(D\)，连接 \(PD\) 和 \(CD\)。由等边三角形三线合一得 \(PD \perp AB\)，\(CD \perp AB\)。所以 \(\angle PDC\) 即为二面角 \(P-AB-C\) 的平面角 \(\theta\)。

在 \(\triangle PDC\) 中，\(PD = \dfrac{\sqrt{3}}{2}a\)，\(CD = \dfrac{\sqrt{3}}{2}a\)，\(PC = a\)。由余弦定理：

$$\cos\theta = \frac{PD^2+CD^2-PC^2}{2 \cdot PD \cdot CD} = \frac{\frac{3}{4}a^2+\frac{3}{4}a^2-a^2}{2 \cdot \frac{\sqrt{3}}{2}a \cdot \frac{\sqrt{3}}{2}a} = \frac{1}{3}$$

自己试试：将边长为 \(2\) 的正方形 \(ABCD\) 沿对角线 \(AC\) 向上折起，使平面 \(ABC \perp \text{平面 } ADC\)（折成直二面角）。折起后线段 \(BD\) 的长度为：

A。设对角线交于点 \(O\)。在原正方形中，\(BO \perp AC\)，\(DO \perp AC\)，且 \(BO = DO = \sqrt{2}\)。折成直二面角后，\(\angle BOD = 90^\circ\) 就是二面角的平面角。在 \(\text{Rt}\triangle BOD\) 中：\(BD = \sqrt{BO^2+DO^2} = \sqrt{2+2} = 2\)。

6. 三大翻车现场与反例微图解

翻车点 1 线面判定漏掉“相交”

❌ 直线垂直于平面内两条平行线，就断定直线垂直于平面。

✔ 必须双轴锁死：两条平行线方向单一，直线依然可以左右晃动倾斜！必须是两条相交直线。

翻车点 2 面面性质漏写“垂直于交线”

❌ \(\alpha \perp \beta\)，在 \(\alpha\) 内任取一条直线 \(a\)，直接写 \(a \perp \beta\)。

✔ 必须垂于交线：面内唯有垂直于交线的直线才垂直于另一面！平行或倾斜于交线的直线绝不垂直另一面。

翻车点 3 二面角平面角垂足错位

❌ 在棱上两不同点分别作棱的垂线，把连线夹角当二面角。

✔ 同一点出发：二面角平面角必须以棱上的同一点为垂足作两条垂直射线；异点作垂线时须沿棱平移到同一点，才能构成平面角。

反例微图解：异点射线须平移到共同顶点

二面角平面角必须以棱上的同一点为顶点。两射线垂足错开时，方向夹角仍保持不变，但不能直接组成平面角；沿棱平移到同一点后即可构造。

再深一点（可以先跳过）

射影面积公式：若平面多边形面积为 \(S\)，它在平面 \(\alpha\) 上的正射影面积为 \(S'\)，多边形所在平面与 \(\alpha\) 所成的二面角为 \(\theta\)（\(0^\circ \le \theta < 90^\circ\)），则：\(S' = S \cdot \cos\theta\)。

直接用

1. 设 \(l\) 是一条直线，\(\alpha\) 是一个平面。下列条件中，能够充分判定 \(l \perp \alpha\) 的是：

B。线面垂直判定定理的核心条件是垂直于平面内的「两条相交直线」。梯形的两底边互相平行，无数条平行线在方向上等价于一条线，直线可绕平行线倾斜而与平面不垂直。只有相交的两条直线才能唯一确定平面方向，从而锁定垂直。

2. 在正方体 \(ABCD-A_1B_1C_1D_1\) 中，体对角线 \(A_1C\) 与底面 \(ABCD\) 所成角的正切值 \(\tan\theta\) 等于：

A。设正方体棱长为 \(1\)。点 \(A_1\) 在底面 \(ABCD\) 上的正射影为点 \(A\)，所以斜线 \(A_1C\) 在底面上的正射影为对角线 \(AC\)。

在直角三角形 \(\triangle A_1AC\) 中，\(\angle A_1AC = 90^\circ\)，垂直高 \(A_1A = 1\)，射影长 \(AC = \sqrt{1^2+1^2} = \sqrt{2}\)。因此线面角的正切值 \(\tan\theta = \dfrac{A_1A}{AC} = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}\)。

易错

3. 若平面 \(\alpha \perp \text{平面 } \beta\)，直线 \(m \subset \alpha\)，直线 \(n \subset \beta\)，则直线 \(m\) 与 \(n\) 的位置关系：

C。高频易错！「面面垂直」绝不等于「两个面内的任意两条直线互相垂直」！

反例与分类：设两平面的交线为 \(l\)。

① 若 \(m \parallel l\) 且 \(n \parallel l\)，则根据平行公理 \(m \parallel n\)（两直线可以互相平行）；

② 若 \(m \perp l\) 且垂足为 \(P\)，\(n\) 经过点 \(P\) 且不垂直 \(l\)，则 \(m\) 与 \(n\) 相交；

③ 若两条线不共面，则是异面直线（可垂直也可斜交）。

只有当面内直线垂直于交线时，它才垂直于另一个平面，从而垂直于另一个平面内的任意直线。

4. 设 \(m, n\) 是两条不同的空间直线，\(\alpha, \beta\) 是两个不同的平面。下列命题中真命题是：

A。逐项辨析：

A. 正确：垂直于同一条直线的两个平面互相平行（线面垂直的重要推论）；

B. 错误：必须 \(m\) 垂直于两平面的交线，才能推得 \(m \perp \beta\)；

C. 错误：直线 \(m\) 可以在 \(\alpha\) 内，也可以与 \(\alpha\) 平行（\(m \parallel \alpha\)）；

D. 错误：直线 \(n\) 可以在平面 \(\alpha\) 内（由 \(m \perp \alpha\) 知 \(m\) 垂直于 \(\alpha\) 内任意直线，若 \(n \subset \alpha\) 同样有 \(m \perp n\)）。

挑战进阶

5. 在空间四边形 \(ABCD\) 中，已知对棱互相垂直，即 \(AB \perp CD\) 且 \(AC \perp BD\)。则另一对对棱 \(AD\) 与 \(BC\) 的位置关系是：

B。四面体对棱垂直的优美对称性质：若四面体的两对对棱互相垂直，则第三对对棱也必然互相垂直！

几何证明：过点 \(A\) 作底面 \(BCD\) 的垂线 \(AH \perp \text{面 } BCD\)，垂足为 \(H\)。

先处理垂足重合的边界：若H=D，则AD垂直底面BCD，直接有AD⊥BC。若H=B，则AB垂直底面；结合AC⊥BD得BD垂直平面ABC，故BD⊥BC，再结合AB⊥BC可得BC垂直平面ABD，故AD⊥BC。H=C时交换B、C同理。以下讨论H与B、C、D均不同的情形。

由 \(AH \perp CD\) 且已知 \(AB \perp CD\)，可知 \(CD \perp \text{面 } ABH\)，从而 \(CD \perp BH\)（\(H\) 在 \(\triangle BCD\) 边 \(CD\) 的高线上）。

同理，由 \(AC \perp BD\) 可推得 \(BD \perp CH\)（\(H\) 在边 \(BD\) 的高线上）。

因此垂足 \(H\) 是底面 \(\triangle BCD\) 的垂心！

由三角形垂心性质，必有连线 \(DH \perp BC\)。又 \(AH \perp BC\)，所以 \(BC \perp \text{面 } ADH\)，最终得到 \(AD \perp BC\)！
