5.3 导数在研究函数中的应用

导数是正还是负，告诉我们函数在往上走还是往下走。这一节用导数的符号判断单调性，找极大值、极小值，并在闭区间上求最大值和最小值。

设想两条登山步道：每一步的坡度（切线斜率 \(f'(x)\)）都大于等于 \(0\)（绝不下坡）。但如果其中一条步道在半山腰修了一段长长的水平观景平台（在这段区间上斜率恒为 \(f'(x)\equiv 0\)），点下面的按钮对比两条路线：

如果可导函数 \(f(x)\) 在区间 \((a, b)\) 上满足 \(f'(x) \ge 0\)，能不能直接断言函数 \(f(x)\) 在 \((a, b)\) 上严格单调递增？

B。必须排除局部常数区间！

例如常数函数 \(f(x) = 5\)，其导数 \(f'(x) \equiv 0 \ge 0\)，但函数值始终是 5，没有发生任何递增。

严格的数学定理是：若 \(f'(x) > 0\)，则函数必定单调递增；而当 \(f'(x) \ge 0\) 时，还需排除任何恒为常数的小区间。导数为 0 的点只是孤立点（如 \(f(x)=x^3\) 的 \(x=0\)）是一个常用的充分情形，不能说它是唯一可能情形。

这一节我们就来系统建立单调性判定法则、极值点搜寻机制与闭区间最值求解标准程序。

1. 先认识几个词

要用到：5.1 导数的意义（导数是切线斜率，回看 5.1）；5.2 求导公式（回看 5.2）；必修一里函数单调性的定义。

课本用词：导数为 0 只是驻点，不保证是极值；闭区间最值必须把所有内部临界点和两个端点一起比较。

单调区间：函数在这一段上一直增（或一直减），这一段就是它的单调递增（递减）区间。

例：\(f(x)=x^2\) 在 \((-\infty,0)\) 上递减，在 \((0,+\infty)\) 上递增。

驻点：使导数 \(f'(x)=0\) 的点，切线在此处于水平状态。

例：\(f(x)=x^2-4x\)，\(f'(x)=2x-4\)，令其为 \(0\) 得驻点 \(x=2\)。

极值点与极值：在 \(x_0\) 附近，\(f(x_0)\) 比周围的值都大（都小），\(x_0\) 叫极大（极小）值点（横坐标），\(f(x_0)\) 叫极大（极小）值（纵坐标）。

例：\(f(x)=(x-1)^2+3\) 的极小值点是 \(x=1\)，极小值是 \(f(1)=3\)。

最值：整个给定闭区间上绝对最大（最小）的函数值。极值看局部山头，最值看全域绝顶。

例：\(f(x)=x^2\) 在 \([-1,2]\) 上，极小值 \(f(0)=0\) 也是最小值；而最大值是端点值 \(f(2)=4\)。

导数应用核心直觉：符号定升降、变号定极值、端点争最值
驻点辨析 驻点 vs 极值点（必要非充分）
  • 驻点 \(f'(x)=0\)：切线水平，仅是可导函数极值的候选点。
  • 导数变号判定：对本节可导且驻点两侧导数分别保持固定符号的函数，正变负得极大值，负变正得极小值；不能只凭导数为 0 下结论。
  • 经典反例：\(y=x^3\) 在 \(x=0\) 处 \(f'(0)=0\)，但两侧导数均为正，非极值点！
层级对比 极值（局部） vs 最值（全域）
  • 极值属局部：只与邻近局部点比；极大值未必大于极小值（如 \(x+\frac1x\) 极大值 \(-2 <\) 极小值 \(2\)）。
  • 最值属全局：在整个给定闭区间上比较，必须包含所有内部极值与两侧端点值。
  • 端点参与度：本节把极值点定义在函数定义域的内点；闭区间端点另列为最值候选。

2. 单调性、极值与最值主公式

单调判定：\(\color{#0284c7}{f'(x) > 0 \implies \text{单调递增}};\quad \color{#dc2626}{f'(x) < 0 \implies \text{单调递减}}\)
极值变号：\(f'(x_0)=0\) 且两侧 \(\begin{cases} \color{#0284c7}{+} \to \color{#dc2626}{-} \implies x_0 \text{ 为极大值点} \\ \color{#dc2626}{-} \to \color{#0284c7}{+} \implies x_0 \text{ 为极小值点}\end{cases}\)
闭区间最值：\(\max_{[a,b]} f(x) = \max\{f(a),\, f(b),\, f(x_{\text{极大}})\}\)

例 1（看一遍怎么写）

求 \(f(x)=x-2\ln x\) 的单调区间。

定义域：\(\ln x\) 要求 \(x>0\)，即 \((0,+\infty)\)。

求导：\(f'(x)=1-\dfrac{2}{x}=\dfrac{x-2}{x}\)。

判号：在 \((0,+\infty)\) 上分母 \(x>0\)，符号由 \(x-2\) 决定。当 \(0<x<2\) 时 \(f'(x)<0\)；当 \(x>2\) 时 \(f'(x)>0\)。

结论：单调递减区间为 \((0,2)\)，单调递增区间为 \((2,+\infty)\)。

自己试试：函数 \(f(x)=x-\mathrm{e}^x\) 的单调递增区间是？

A。\(f'(x)=1-\mathrm{e}^x\)。\(f'(x)>0\iff \mathrm{e}^x<1\iff x<0\)。选 B 是递减区间；选 C 是把 \(\mathrm{e}^x<1\) 误当成 \(x<1\)。

3. 极值最值与三步破题思维链

🧩 典型例题：求三次函数在闭区间上的极值与最值（如 \(f(x)=x^3-12x\) 在 \([-3,5]\)）
👀 信号
题目给出连续函数及其闭区间 \([a,b]\)，要求求解极值与全区间最大最小值。
🔧 步骤
1. 求导解驻点：令 \(f'(x)=3x^2-12=0 \implies x=\pm2\)，筛选落入区间的驻点；
2. 做表格看变号：驻点两侧导数符号左正右负得极大值 \(f(-2)=16\)，左负右正得极小值 \(f(2)=-16\)；
3. 端点全比对：计算端点值 \(f(-3)=9, f(5)=65\)；比对 \(\{9, 16, -16, 65\}\) 得最大值 \(65\)，最小值 \(-16\)。
🛡️ 防坑
闭区间最值万不可漏算区间端点（本题最大值在端点 \(x=5\) 处高达 65，远超局部极大值 16）！

例 2（求极值）

求 \(f(x)=2x^3-3x^2-12x+5\) 的极值。

求导并因式分解：\(f'(x)=6x^2-6x-12=6(x+1)(x-2)\)。令 \(f'(x)=0\) 得驻点 \(x=-1\) 和 \(x=2\)。

做变号判定表：

  • \(x<-1\) 时 \(f'(x)>0\)；\(x=-1\) 处 \(f'=0\)；\(-1<x<2\) 时 \(f'(x)<0\)（左正右负 \(\implies\) 极大值点）。极大值 \(f(-1)=12\)。
  • \(-1<x<2\) 时 \(f'(x)<0\)；\(x=2\) 处 \(f'=0\)；\(x>2\) 时 \(f'(x)>0\)（左负右正 \(\implies\) 极小值点）。极小值 \(f(2)=-15\)。

自己试试：函数 \(f(x)=x^3-3x\) 的极小值点是？

A。\(f'(x)=3(x-1)(x+1)\)，驻点 \(\pm1\)。\(x=1\) 左边 \(f'<0\)、右边 \(f'>0\)，是极小值点。问的是「点」（横坐标），选 C 是把极小值 \(f(1)=-2\) 当成了点；选 B 是极大值点。

4. 闭区间上的最值

在闭区间 \([a,b]\) 上，连续函数必有最大值和最小值。最值只可能在两处出现：内部的极值点，或者区间的端点。

例 3（求最值）

求 \(f(x)=x^3-12x\) 在 \([-3,5]\) 上的最大值和最小值。

\(f'(x)=3x^2-12=3(x+2)(x-2)\)，驻点 \(\pm2\) 均在区间内：\(f(-2)=16, f(2)=-16\)。

端点：\(f(-3)=-27+36=9\)，\(f(5)=125-60=65\)。

全盘比对 \(\{9, 16, -16, 65\}\)：最大值 \(65\)（在端点 \(x=5\) 取到），最小值 \(-16\)（在极小值点 \(x=2\) 取到）。

自己试试：\(f(x)=x^3-12x\) 在区间 \([-3,5]\) 上的最值是？

B。驻点值 \(16, -16\) 与端点值 \(9, 65\) 汇总比对：最大为 \(65\)，最小为 \(-16\)。选 A 漏算了端点！

5. 三大翻车现场红绿对比卡

⚠️ 误区一：驻点直接当极值点
❌ 错误：求出 \(f'(x)=0\) 立即断言必为极值点
✅ 正确：本节用导数两侧变号判定极值，不能只看驻点！\(y=x^3\) 在 \(x=0\) 导数为 0 但两侧皆正，非极值点。
⚠️ 误区二：闭区间最值遗漏端点
❌ 错误：求闭区间最值只算极值点，不顾区间端点
✅ 正确：端点极常产生全区最高峰（如本课例 3 中端点 65 远超极大值 16）！
⚠️ 误区三：单调区间用并集 ∪ 连接
❌ 错误：因为 \(1/x\) 在两边分别递减，就断言它在整个非零实数集上递减
✅ 正确：对 \(1/x\)，跨零比较 \(-1<1\)，却有 \(f(-1)<f(1)\)，所以只能分别说两段递减。其他函数是否能合并，仍需按单调定义另验。
🔍 反例微图解：拐点驻点单调上升 vs 反比例并集跨断点违例
左图：\(y=x^3\) 在原点导数为 0 但全程单调递增；右图：\(y=1/x\) 在 \(x=-1\) 与 \(x=1\) 处值从 \(-1\) 升到 \(1\)，并集不递减。

自己试试：下列关于极值与最值的说法中，正确的是：

C。极值只和邻域比，\(x+\dfrac1x\) 就是反例（极大值 \(-2 <\) 极小值 \(2\)）。B 选项后半句错（如 \(x^3\) 在 0 处）；D 选项端点不可充当极值点。

再深一点（可以先跳过）

用单调性证明不等式：例如证明 \(\mathrm{e}^x\ge x+1\)。构造辅助函数 \(g(x)=\mathrm{e}^x-x-1\)，通过求导判定在 \(x=0\) 处取得最小值 \(0\)，从而获证恒大于等于 0。

最优化实际问题建模：先根据物理几何背景设立自变量定义域，再通过导数寻找驻点求解最值。

三次多项式单调性与极值全景透视仪

考察函数 \(f(x) = \dfrac{1}{3}x^3 - a x\)（\(a > 0\) 时导数有两个零点 \(x = \pm\sqrt{a}\)）。调节参数 \(a\) 观察峰谷开合，拖动区间滑块观察极大值、极小值与端点值如何竞争全局最值：

直接用

1. 函数 \(f(x) = x^3 - 3x\) 的单调递减区间是：

A。求导：\(f'(x) = 3x^2 - 3 = 3(x+1)(x-1)\)。令 \(f'(x) < 0 \implies x^2 < 1 \implies -1 < x < 1\)。因此单调递减区间为 \((-1, 1)\)。

2. 函数 \(f(x) = x^3 - 12x + 1\) 的极大值等于：

B。求导：\(f'(x) = 3x^2 - 12 = 3(x+2)(x-2)\)。当 \(x < -2\) 时 \(f'(x) > 0\)，当 \(-2 < x < 2\) 时 \(f'(x) < 0\)。因此 \(x = -2\) 是极大值点。极大值为 \(f(-2) = (-2)^3 - 12(-2) + 1 = -8 + 24 + 1 = 17\)。

易错

3. 函数 \(f(x) = x^3\) 在 \(\mathbf{R}\) 上满足 \(f'(0) = 0\)，则点 \(x = 0\)：

D。求导 \(f'(x) = 3x^2\)。当 \(x \ne 0\) 时恒有 \(f'(x) > 0\)。\(x = 0\) 两侧导数均为正数，导数并没有发生变号！因此函数在 \(x=0\) 处一直在递增爬升，不是极值点。本题应检查驻点两侧的导数符号，不能只看 \(f'(0)=0\)。

4. 函数 \(f(x) = x^3 - 3x\) 在闭区间 \([0, 2]\) 上的最大值和最小值分别是：

C。求导 \(f'(x) = 3x^2 - 3 = 0 \implies x = 1 \in [0, 2]\)。极小值 \(f(1) = 1 - 3 = -2\)。计算两端点值：左端点 \(f(0) = 0\)；右端点 \(f(2) = 2^3 - 3(2) = 8 - 6 = 2\)。比对候选池 \(\{f(0)=0, \; f(1)=-2, \; f(2)=2\}\)：最大值为 \(2\)，最小值为 \(-2\)。

挑战进阶

5. 已知函数 \(f(x) = x^3 + ax\) 在 \(\mathbf{R}\) 上单调递增，则实数 \(a\) 的取值范围是：

A。函数在 \(\mathbf{R}\) 上递增，则其导数恒满足 \(f'(x) = 3x^2 + a \ge 0\)。对任意实数 \(x\)，\(3x^2 \ge 0\)，因此只需 \(a \ge 0\)。注意 \(a = 0\) 时 \(f(x) = x^3\) 依然严格递增，所以等号必须取到！范围为 \([0, +\infty)\)。
