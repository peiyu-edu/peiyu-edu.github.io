8.4 空间点、直线、平面之间的位置关系

从二维平面走向三维空间：四大基本事实构建几何大厦，两直线不相交不一定是平行（异面直线），等角定理谨记互补，平移化异面为共面求夹角。

在初中平面几何里，我们熟悉一个经验：“在同一个平面内，两条直线如果不相交，就一定互相平行”。

但抬头观察真实的三维世界：高架桥上一辆汽车自西向东飞驰，桥下地面上一列地铁自北向南穿行。先点下面的按钮切换视角看看：

高架桥上的公路与地面上的铁轨，这两条直线既永远不会相交，也显然不平行。在空间中，它们属于什么位置关系？

B。这两条直线既不相交，也不平行，它们分别处于不同的高度和方向，不同在任何一个平面内，数学上称之为异面直线。

初中的“不相交即平行”有一个至关重要的前提——“在同一平面内”。迈入三维空间，无公共点的两条直线完全可能是异面直线。这一节我们就来系统建立空间点、线、面的位置关系体系，掌握确定平面的四大基本事实。

1. 先认识几个词

要用到：8.1 正方体的棱与面（回看 8.1），8.2 直观图（回看 8.2）；初中平面内「两直线不相交就平行」。

直观微图解
空间两直线位置：相交（共面有交点）、平行（共面无交点）、异面（不同在任一平面且无交点）。
平行直线 共面无交点（传递律成立）

空间共面性：一定存在某一个确定的平面 \(\alpha\)，使两条直线同时在该平面内。

传递性：基本事实 4 明确保证：\(a \parallel b,\ b \parallel c \implies a \parallel c\) 严格成立。

夹角定义：同向或反向平行，方向相同夹角为 \(0^\circ\)。

异面直线 不同面无交点（无传递律）

空间异面性：不同在任何一个平面内，绝对找不到包含两线的平面。

无传递性：\(a\) 与 \(b\) 异面、\(b\) 与 \(c\) 异面，\(a\) 与 \(c\) 完全可能平行或相交！

夹角定义：平移至同一公共点相交所成的锐角或直角：\(0^\circ < \theta \le 90^\circ\)。

平面：平的、无厚度、向四周无限延展。记作平面 \(\alpha\)、平面 \(ABCD\)。

共线与共面：点落在同一直线上叫共线；点或直线落在同一平面内叫共面。

异面直线判定：平面外一点与平面内一点连成的直线，与平面内不过该点的直线必为异面直线。

2. 四大基本事实：公理化推演基石

$$\color{#0284c7}{\text{事实 1：过不在同一直线上的三点，有且只有一个平面（三点定面）}}$$ $$\color{#d97706}{\text{事实 2：若直线上有两点在平面内，整条直线必全在该平面内}}$$ $$\color{#059669}{\text{事实 3：两不重合平面只要有一个公共点，必有且只有一条过该点的公共交线}}$$ $$\color{#ec4899}{\text{事实 4：平行于同一条直线的两条直线平行（空间平行传递性：} a\parallel b, b\parallel c \implies a\parallel c)}$$

例 1（看一遍怎么写：共线判定）

\(\triangle ABC\) 不在平面 \(\alpha\) 内，直线 \(AB,\ BC,\ CA\) 分别交平面 \(\alpha\) 于点 \(P,\ Q,\ R\)。证明 \(P,Q,R\) 三点共线。

证：\(A,B,C\) 不共线，由基本事实 1 确定唯一平面 \(ABC\)。

\(P \in AB \subset\) 平面 \(ABC\)，故 \(P \in\) 平面 \(ABC\)；又 \(P \in \alpha\)，所以 \(P\) 是两平面的公共点。同理 \(Q,\ R\) 也是公共点。

由基本事实 3，两不重合平面相交必有一条唯一交线 \(l\)，所有公共点必在 \(l\) 上。因此 \(P,Q,R\) 都在 \(l\) 上，三点共线。

自己试试：空间中有四个点，其中三个点在同一条直线上。这四个点：

A。设 \(A,B,C\) 在直线 \(l\) 上。第四点 \(D\) 若不在 \(l\) 上，「直线和直线外一点」定一个平面，四点都在里面；若 \(D\) 也在 \(l\) 上，四点共线，当然也共面。选 C 的同学把它和「四点中任意三点不共线」弄混了，那种情况才可能不共面。

3. 空间两条直线的三种位置

关系是否共面公共点个数能否传递
相交是恰有 1 个否

自己试试：直线 \(a\) 与 \(b\) 异面，\(b\) 与 \(c\) 异面。那么 \(a\) 与 \(c\)：

D。在正方体里取 \(b=AB\)：\(a=CC_1\)、\(c=DD_1\) 时 \(a\parallel c\)；\(a=CC_1\)、\(c=B_1C_1\) 时相交于 \(C_1\)；\(a=CC_1\)、\(c=A_1D_1\) 时异面。选 A 的同学把「异面」当成像平行一样能传递，其实只有平行能传递。

4. 异面直线所成的角与三步思维链

$$\color{#0284c7}{\text{异面直线所成角定义：任意平移使其相交，两线所成的锐角或直角}}$$ $$\color{#ec4899}{\text{取值范围：} 0^\circ < \theta \le 90^\circ \quad (\text{垂直时 } \theta=90^\circ \iff a \perp b)}$$
典型题三步思维链：正方体中异面直线夹角求法

题目：在棱长为 \(1\) 的正方体 \(ABCD-A_1B_1C_1D_1\) 中，求异面直线 \(A_1B\) 与 \(B_1C\) 所成的角。

1
👀 第一眼破题信号： \(A_1B\) 在左正面，\(B_1C\) 在右侧面，两条线在空间互不相交且不平行，是典型异面直线！求异面直线角的第一步是构造平行线将它们平移到同一个点相交。
2
🔧 第二步套公式/方法（平移构造法）：

① 寻找平行线平移：在正方体中，后侧对角线 \(D_1C \parallel A_1B\) 且长度相等（因为 \(A_1D_1 \parallel BC\) 且相等，四边形 \(A_1BCD_1\) 是平行四边形）。

② 化异面为相交：将 \(A_1B\) 平移为 \(D_1C\)，两条相交直线汇聚于点 \(C\)，所求夹角转化为 \(\angle B_1CD_1\)（或其补角）。

③ 放入三角形求解：连结 \(B_1D_1\)，在 \(\triangle B_1CD_1\) 中：
\(B_1C = \sqrt{2}\)（右侧面对角线），\(D_1C = \sqrt{2}\)（后侧面对角线），\(B_1D_1 = \sqrt{2}\)（顶面对角线）。
三边长度完全相等，因此 \(\triangle B_1CD_1\) 是等边三角形！
\(\angle B_1CD_1 = 60^\circ\)。

3
🛡️ 第三步必查防坑结论： ① 异面直线夹角绝对不能为钝角！若平移后在三角形内解出的角是钝角（如 \(120^\circ\)），最终答案必须取其补角 \(180^\circ - 120^\circ = 60^\circ\)；
② 夹角范围是 \((0^\circ, 90^\circ]\)，不能是 \(0^\circ\)（若为 \(0^\circ\) 则两线平行，不是异面）。

自己试试：在正方体 \(ABCD-A_1B_1C_1D_1\) 中，异面直线 \(A_1B_1\) 与 \(BC_1\) 所成的角是：

C。\(A_1B_1\parallel AB\)，所以所求角就是 \(AB\) 与 \(BC_1\) 的夹角 \(\angle ABC_1\)。设棱长为 \(1\)，在 \(\triangle ABC_1\) 中，\(AB=1\)，\(BC_1=\sqrt2\)（面对角线），\(AC_1=\sqrt3\)（体对角线），\(1^2+(\sqrt2)^2=(\sqrt3)^2\)，由勾股定理的逆定理，\(\angle ABC_1=90^\circ\)。

选 B 的同学看到 \(BC_1\) 是面对角线，就以为和棱成 \(45^\circ\)；可 \(45^\circ\) 是它和同一面里的棱 \(BC\) 的夹角，\(AB\) 不在那个面里。

5. 三大翻车现场与反例微图解

翻车点 1 误以为“异面”具有传递性

❌ \(a\) 与 \(b\) 异面，\(b\) 与 \(c\) 异面，就认定 \(a\) 与 \(c\) 也是异面。

✔ 平行才传递：正方体里 \(CC_1\) 与 \(AB\) 异面，\(DD_1\) 与 \(AB\) 也异面，但 \(CC_1 \parallel DD_1\) 却互相平行！

翻车点 2 异面直线夹角写出钝角

❌ 平移成相交后，算出三角形内角为 \(135^\circ\)，直接答 \(135^\circ\)。

✔ 锐角或直角：异面直线夹角范围严格为 \((0^\circ, 90^\circ]\)。算得钝角必须取其补角 \(180^\circ - 135^\circ = 45^\circ\)！

翻车点 3 空间中“不相交”就断定“平行”

❌ 看到两条直线没有公共点，立刻下结论判定它们互相平行。

✔ 必须先确认共面：空间中无交点包含平行与异面两种截然不同的位置关系！只有在同一平面内，无交点才是平行。

反例微图解：立交桥投影相交 vs 空间异面

二维平面俯视投影显示两条道路交叉相交，但空间实际一上一下具有垂直间隙 \(h\)，毫无公共点，是标准的异面直线！

再深一点（可以先跳过）

三线共点：要证三条直线交于一点，先说明其中两条交于点 \(P\)，再说明 \(P\) 在第三条线上——常常第三条线是两个平面的交线，而 \(P\) 正好是这两个平面的公共点。

判断异面的常用说法：平面外一点和平面内一点连成的直线，与平面内不过后一点的直线异面。

直接用

1. 在正方体 \(ABCD-A_1B_1C_1D_1\) 的 12 条棱中，与棱 \(AB\) 既不相交也不平行的棱（即异面棱）共有几条？

B。正方体共有 12 条棱。与棱 \(AB\) 的关系分类如下：

  • 与 \(AB\) 平行的棱有 3 条：\(A_1B_1, CD, C_1D_1\)；
  • 与 \(AB\) 相交的棱有 4 条：\(AA_1, BB_1, AD, BC\)；
  • 排除 \(AB\) 本身及上述 7 条棱，剩下的 4 条棱与 \(AB\) 既不相交也不平行，全部是异面直线，它们是：\(CC_1, DD_1, A_1D_1, B_1C_1\)。

2. 空间中三条直线 \(a, b, c\)。若 \(a \parallel b\) 且 \(b \parallel c\)，则直线 \(a\) 与 \(c\) 的位置关系是：

A。由立体几何基本事实 4（平行公理）：平行于同一条直线的两条直线互相平行。该性质在三维空间中依然具有严格的传递性，因此只要 \(a \parallel b\) 且 \(b \parallel c\)，必有 \(a \parallel c\)。

3. 在正四面体（四个面均为正三角形的三棱锥）\(P-ABC\) 中，棱 \(PA\) 与对棱 \(BC\) 所成的角的大小为：

D。取 \(BC\) 的中点 \(D\)，连结 \(PD, AD\)。

因为 \(\triangle PBC\) 与 \(\triangle ABC\) 都是等边三角形，所以中线也是高：\(PD \perp BC\) 且 \(AD \perp BC\)。

因为 \(PD \cap AD = D\)，所以 \(BC \perp\) 平面 \(PAD\)。

又因为 \(PA \subset\) 平面 \(PAD\)，所以 \(BC \perp PA\)，即异面直线 \(PA\) 与 \(BC\) 所成的角是 \(90^\circ\)（互相异面垂直）。

结论推广：正四面体的任意一组对棱都互相垂直，这是高考的高频几何特征！

易错

4. 空间中两个角 \(\angle A\) 和 \(\angle B\) 的两边分别对应平行。已知 \(\angle A = 55^\circ\)，则 \(\angle B\) 的度数为：

C。易错警示：根据等角定理，空间中如果两个角的两边分别对应平行，那么这两个角相等或互补！

当两组对应边方向均相同或均相反时，\(\angle B = \angle A = 55^\circ\)；当一组方向相同、另一组方向相反时，\(\angle B = 180^\circ - 55^\circ = 125^\circ\)。未给定图形时必须保留两解，切莫漏掉“互补”！

5. 下列关于空间点、线、面位置关系的命题中，正确的是：

C。逐项剖析：

  • A 错误：基本事实 1 明确要求“不共线的三点”。若三点在同一直线上，经过它们的平面有无数个；
  • B 错误：空间中没有公共点的两直线可能是平行直线，也可能是异面直线；
  • C 正确：设对角线相交于点 \(O\)，两对角线是两条相交直线，由基本事实 1 的推论“两条相交直线确定一个平面”，该平面的四个顶点必同在这一平面内；
  • D 错误：反例为普通平面凸四边形（如矩形），四个顶点任意三点不共线，但它们完全共面。
