亿以内数的读法

含有万级和个级的大数怎样读？数里的“0”哪些不读、哪些要读？

个级上的数 3682 读作「三千六百八十二」。如果把 3682 移到万级，变成整万数 36820000，怎样读最简便？

对！万级的数表示多少个「万」，所以按照个级的数的读法来读，再在后面加上一个「万」字，读作「三千六百八十二万」。

1. 分级线与“0”的读法高亮器

点下面的不同例数，或者直接点某一位数字改变它，开关“分级线”和“0 的读法剖析”，看清楚哪些 0 静音不读、哪些 0 读一个“零”。

含有两级的数的读法：
1. 先读万级，再读个级（先从右往左每 4 位画一条分级线）；
2. 万级的数，要按照个级的数的读法来读，再在后面加上一个“万”字；
3. 每级末尾不管有几个 0，都不读；其他数位上有一个 0 或连续几个 0，都只读一个零。

自己试试

先分级：480|6000。万级末尾有一个 0，个级末尾有三个 0，这个数应该怎么读？

A。480 的 0 在万级末尾，6000 的三个 0 在个级末尾；每级末尾的 0 都不读，所以读作四百八十万六千。

自己试试

再看 2005|0070：万级中间有两个 0，个级开头也有两个 0，一共要读几个「零」？

C。万级「2005」连续两个 0 只读一个零（二千零五万）；个级「0070」千位百位连续两个 0 只读一个零，个位末尾的 0 不读（零七十），合起来读作二千零五万零七十。

读亿以内的数，先从右往左每四位分级：先读万级（加“万”字），再读个级；每级末尾不管有几个 0 都不读，其他数位有一个 0 或连续几个 0 都只读一个零。

两个容易错的地方

✗ 把万级末尾的 0 当成“中间的 0”读出来 750|9000 错读成“七百五十万零九千”。
✓ 万位上的 0 属于万级末尾，一律不读 750|9000 读作“七百五十万九千”（一个零也不读）。
✗ 个级千位上的 0 漏读，或连续 0 读好几个零 360|0400 错读成“三百六十万四百”。
✓ 万级末尾 0 不读，但个级开头的 0 必须读一个零 360|0400 读作“三百六十万零四百”。

直接用

1. 整万数 60900000 应该读作什么？

B。先分级 6090|0000，万级「6090」读作六千零九十，加上「万」字就是六千零九十万。

2. 读出含两级的数 8504200（分级：850|4200）：

A。850 的 0 在万级末尾，4200 的两个 0 在个级末尾，全都不读，读作八百五十万四千二百。

容易错

3. 下面三个数中，一个零也不读的是哪一个？

C。分级后是 360|5000，所有的 0 都在万级末尾或个级末尾，读作「三百六十万五千」，一个零也不读。

4. 读 50080030 这个数时，一共要读出（ ）个「零」。

分级 5008|0030，读作「五千零八万零三十」，一共读出 2 个零。

想一想

5. 对比 7200400 和 7204000 的读法，下面说法正确的是？

B。画分级线一看就明白：720|0400 的千位有 0，读作「七百二十万零四百」；720|4000 的 0 全在每级末尾，读作「七百二十万四千」。

6. 用 3 个「6」和 4 个「0」组成的七位数中，要读出两个零的是哪一个？

C。分级后是 606|0060，万级「606」读作六百零六万，个级「0060」读作零六十，正好读出两个零。
