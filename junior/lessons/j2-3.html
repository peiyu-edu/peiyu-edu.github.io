2.3 有理数的乘方

几个相同的因数相乘，有一种简写：乘方。认清底数、定好符号、排好运算顺序，再用它写很大的数、写近似数。

本节导读　先修：2.2 有理数的乘法与除法 · 本节路线

要用到：有理数的乘法和「数负因数个数定符号」（回看 2.2）、加减法（回看 2.1）；小学的「保留几位小数」。

  1. 从「一传三」的消息进入：几个相同的因数相乘。
  2. 认识乘方、幂、底数、指数；先认清底数是谁。
  3. 幂的符号：负数的奇次幂为负、偶次幂为正。
  4. 加入乘方后的运算顺序：先乘方，再乘除，最后加减。
  5. 用 \(10\) 的乘方写大数（科学记数法）；近似数和精确度。
  6. 练习与中考真题，回看最容易错的三处。

小明把一条消息告诉了 \(3\) 个同学，算第 \(1\) 轮；下一轮，每个新知道的同学再各告诉 \(3\) 个还没听说的同学……点下面的按钮，数一数每一轮新知道消息的人：

照这样，第 \(4\) 轮新知道消息的有多少人？

C。每一轮都是上一轮的 \(3\) 倍：\(3\times3\times3\times3=81\)，是 \(4\) 个 \(3\) 相乘。选 A 是算成了 \(3\times4\)；选 B 是 \(4\times4\times4\)，把相乘的数和个数弄反了；选 D 是第 \(3\) 轮的人数。

\(4\) 个 \(3\) 相乘写成 \(3\times3\times3\times3\) 太长，简记为 \(3^4\)。这一节就来研究这种几个相同因数相乘的运算：乘方。

1. 先认识几个词：乘方、幂、底数、指数

前置知识：有理数的乘法和符号法则（回看 2.2）。乘方最容易错的是认错「底数是谁」。先看四个长得很像的式子，方框里的才是相乘的因数：

直觉微图解 ①方框里的才是底数

乘方：\(n\) 个相同的因数 \(a\) 相乘，记作 \(a^n\)，即 \(a\cdot a\cdot\cdots\cdot a=a^n\)（左边共 \(n\) 个 \(a\)，中间的省略号表示没写出来的那些 \(a\)）。求 \(n\) 个相同因数的积的运算叫乘方，乘方的结果叫幂。\(a\) 叫底数，\(n\) 叫指数；\(a^n\) 读作「\(a\) 的 \(n\) 次方」，看作结果时也读作「\(a\) 的 \(n\) 次幂」。本章的 \(n\) 都是正整数；一个数就是它自己的 \(1\) 次方，指数 \(1\) 通常不写。

书写约定：底数是负数或分数时，要连同符号整个用括号括起来：\((-2)^4\)、\(\left(\tfrac23\right)^2\)。

核心概念 ②乘方是运算，幂是结果

就像加法的结果叫「和」、乘法的结果叫「积」，乘方的结果叫「幂」。\(3^4=81\)：底数 \(3\)，指数 \(4\)，幂是 \(81\)。\(3^4\) 是 \(4\) 个 \(3\) 相乘，不是 \(3\times4\)。

核心概念 ③\((-3)^2\) 和 \(-3^2\) 不一样

\((-3)^2\) 的底数是 \(-3\)：\((-3)\times(-3)=9\)，读作「\(-3\) 的平方」。\(-3^2\) 的底数只是 \(3\)：\(-(3\times3)=-9\)，读作「\(3\) 的平方的相反数」。先读出来，再算。

2. 核心点：幂的符号

乘方是乘法的特殊情形：\(n\) 个相同因数相乘，符号就看负因数的个数。底数是负数时，指数是几，就有几个负因数。

负数的偶数次幂为正。

负数的奇数次幂为负。

正数的任何次幂都是正数；\(0\) 的任何正整数次幂都是 \(0\)。

直觉微图解 ②指数从 1 数到 6，看幂的符号怎么跳

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

计算：(1) \((-4)^3\)；(2) \(\left(-\tfrac23\right)^4\)。

① 读懂题意：两道都是乘方。先别急着乘，第一件事是认什么？

提示 1：先认底数，再看指数的奇偶

(1) 底数是 \(-4\)，指数 \(3\)；(2) 底数是 \(-\tfrac23\)（括号把负号和分数一起括住了），指数 \(4\)。

看完整示范
② 想办法：先定符号：(1) \(3\) 个负因数，奇数个，为负；(2) \(4\) 个负因数，偶数个，为正。再算绝对值：几个相同因数相乘。
③ 执行：(1) \((-4)^3=-(4\times4\times4)=-64\)；(2) \(\left(-\tfrac23\right)^4=\tfrac{2\times2\times2\times2}{3\times3\times3\times3}=\tfrac{16}{81}\)。
执行中检查：\(4^3\) 是 \(3\) 个 \(4\) 相乘，得 \(64\)，不是 \(4\times3=12\)；分数的乘方，分子、分母都要乘方，\(\tfrac{16}{81}\) 而不是 \(\tfrac{16}{3}\) ✓。

④ 回头看：乘方和连乘一样，「先定符号，再算绝对值」；底数是谁，由括号决定。

自己试试：\((-1)^{100}\) 等于多少？

C。\(100\) 个 \(-1\) 相乘：负因数 \(100\) 个，偶数个，为正；绝对值 \(1\) 不管乘多少个都是 \(1\)。A、B 是把乘方当成了 \((-1)\times100\) 一类的乘法；D 是奇数次幂的结果。

再试一个：\(-4^2\) 等于多少？

B。没有括号，底数只是 \(4\)：\(-4^2=-(4\times4)=-16\)。选 A 是把底数看成了 \(-4\)；C、D 是把平方当成了乘 \(2\)。

3. 核心点：加入乘方后，先算什么

先乘方（第三级）

再乘除（第二级）

最后加减（第一级）

同级运算从左到右；有括号先算括号里的，按小括号、中括号、大括号依次进行。

直觉微图解 ③一步只做一级：\(-2^2+3\times(-1)^3\)

例 2（示范）

计算：\(-3^2\times2-(-2)^3\div4\)。

① 读懂题意：有两个乘方、一个乘、一个除、一个减。先扫一遍，标出乘方。

提示：两个乘方的底数分别是谁？

\(-3^2\) 的底数是 \(3\)；\((-2)^3\) 的底数是 \(-2\)。

看完整示范
② 想办法：按级别：先乘方，再乘除，最后减。
③ 执行：乘方：\(-3^2=-9\)，\((-2)^3=-8\)，原式 \(=(-9)\times2-(-8)\div4\)；乘除：\(=-18-(-2)\)；减法：\(=-18+2=-16\)。
执行中检查：每一步只动同一级的运算，其余照抄；\(-(-2)\) 变成 \(+2\)，用的是减法法则 ✓。

④ 回头看：两个乘方最容易出错：\(-3^2\) 不是 \(9\)，\((-2)^3\) 不是 \(-6\)。

自己试试：\(2\times(-3)^2\) 等于多少？

A。先乘方：\((-3)^2=9\)；再乘：\(2\times9=18\)。选 B 是先算 \(2\times(-3)=-6\) 再平方，顺序错了；选 C 是把 \((-3)^2\) 算成了 \(-9\)。

4. 核心点：用 10 的乘方写大数（科学记数法）

\(10\) 的乘方很好算：\(10^2=100\)，\(10^5=100\,000\)——指数是几，\(1\) 后面就有几个 \(0\)。利用这一点写很大的数：

\(\color{#2F7A56}{\underbrace{a}_{1\,\le\, a\,\lt\, 10}}\times10^{\color{#966524}{n}}\)

对正整数，指数 \(n\) 等于整数部分的位数减 \(1\)。

把一个绝对值大于 \(10\) 的数写成 \(a\times10^n\) 的形式（\(1\le a\lt10\)，\(n\) 是正整数），叫科学记数法。负数先对它的绝对值这样写，再在前面添上负号。

直觉微图解 ④小数点从末尾往左搬，搬到第一个数字后面

例 3（示范）

某快递公司一年的派件量约为 \(2\,360\,000\,000\) 件，用科学记数法表示。

提示：先数整数位数

三位一组地数：\(2\,|\,360\,|\,000\,|\,000\)，一共几位？

看完整示范
想办法：一共 \(10\) 位，所以 \(n=10-1=9\)；小数点点在第一个数字后面，\(a=2.36\)。
执行：\(2\,360\,000\,000=2.36\times10^9\)。
检查：\(a=2.36\) 在 \(1\) 和 \(10\) 之间 ✓；展开：\(2.36\times1\,000\,000\,000=2\,360\,000\,000\) ✓。

自己试试：\(-70\,500\) 用科学记数法表示是哪个？

B。先写绝对值：\(70\,500\) 是 \(5\) 位数，\(70\,500=7.05\times10^4\)，再添负号。A 的值相等，但 \(70.5\) 不在 \(1\) 到 \(10\) 之间；C 丢了负号；D 把指数写成了位数。

5. 近似数：精确到哪一位

量出来、估出来的数，和准确数很接近，叫近似数。近似数接近准确数的程度，用精确度表示：说它精确到哪一位（个位、十分位即 \(0.1\)、百分位即 \(0.01\)……）。取近似数用四舍五入，只看要保留那一位的下一位数字，只做一次。例如 \(0.6375\) 精确到 \(0.01\) 是 \(0.64\)，精确到 \(0.1\) 是 \(0.6\)。近似数末尾的 \(0\) 不能随便去掉：\(3.50\) 精确到百分位，\(3.5\) 只精确到十分位。

自己试试：把 \(4.0952\) 精确到 \(0.01\)，结果是哪个？

B。保留到百分位，看千分位：是 \(5\)，进 \(1\)，\(4.09\) 变成 \(4.10\)。末尾的 \(0\) 要留着，它说明精确到了百分位；写成 A 的 \(4.1\) 就只精确到 \(0.1\) 了。C 是没有进位；D 保留到了千分位。

6. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）认错底数
❌ 典型错解：\(-3^2=9\)，\((-3)^2=-9\)。
✅ 看图秒懂：方框里的才是底数。\(-3^2\) 只让 \(3\) 平方，再取相反数，得 \(-9\)；\((-3)^2\) 是两个 \(-3\) 相乘，得 \(9\)。
翻车现场 ②把乘方当成乘法
❌ 典型错解：\(2^5=2\times5=10\)。
✅ 一眼看清：指数表示有几个相同因数相乘：\(2^5\) 是 \(5\) 个 \(2\) 相乘，\(2\times2\times2\times2\times2=32\)。
翻车现场 ③科学记数法的 \(a\)、\(n\) 写错
❌ 典型错解：\(2\,400\,000=24\times10^5\)，或 \(=2.4\times10^7\)。
✅ 一眼看清：\(a\) 必须满足 \(1\le a\lt10\)，\(24\) 不行；\(7\) 位数的指数是 \(7-1=6\)。正确：\(2.4\times10^6\)。
再深一点（可以先跳过）：倒过来问，和「三级运算」

什么数的平方等于 \(25\)？\(5^2=25\)，\((-5)^2=25\)，所以有两个：\(5\) 和 \(-5\)，它们互为相反数。有没有哪个有理数的平方是 \(-25\)？正数、负数、\(0\) 的平方都不是负数，所以没有。这类「倒过来问」的问题，七年级下册还会再研究。

加减是第一级运算，乘除是第二级，乘方是第三级（以后学的开方也是第三级），级别高的先算。算完可以用计算器验算；如果想换一种算法，必须先依据学过的运算律作等值变形，不能随意改变运算顺序。

① 幂的符号：一正一负地跳

拖动两个圆点（或点一下再用方向键）改变底数 \(a\) 和指数 \(n\)。上一排是 \(n\) 个相同因数 \(a\)，下一排是乘到这里为止的幂 \(a^1, a^2, \dots, a^n\)。

② \((-a)^n\) 和 \(-a^n\)：底数不同

拖动圆点改变 \(a\)（正整数）和 \(n\)。上一行底数是 \(-a\)；下一行底数是 \(a\)，算完再取相反数。

③ 进阶：给小数点搬家（科学记数法）

先选一个数，再拖动圆点（或用方向键）改变 \(n\)：小数点向左移 \(n\) 位，这个数就写成 \(a\times10^n\)。找出唯一让 \(1\le a\lt10\) 的 \(n\)。

从易到难排好了。卡住时先展开提示。

直接用

1. 计算 \((-3)^4\)。

A。\(4\) 个 \(-3\) 相乘，负因数偶数个，为正；\(3^4=81\)。B 是把底数认成了 \(3\) 再取相反数；C、D 是把乘方当成了乘法。

2. 一座水库的库容约为 \(405\,000\,000\) m³，用科学记数法表示是多少？

A。\(9\) 位数，指数 \(9-1=8\)，\(a=4.05\)。B 把指数写成了位数；C、D 的值虽然相等，但 \(a\) 不在 \(1\) 到 \(10\) 之间。

易错

3. 下面计算正确的是哪一个？

提示

每个式子先读出底数是谁、几个相同因数相乘。

B。\(3\) 个 \(-2\) 相乘，奇数个负因数，得 \(-8\)。A：底数是 \(2\)，\(-2^2=-4\)；C：只有分子平方，\(\tfrac{3^2}{4}=\tfrac94\)，要得 \(\tfrac{9}{16}\) 得写 \(\left(\tfrac34\right)^2\)；D：\(2^3=8\)，是 \(3\) 个 \(2\) 相乘。

4. 计算 \(-3^2+(-2)^3\div4\)。

提示

先乘方（两个底数分别是 \(3\) 和 \(-2\)），再除，最后加。

A。乘方：\(-3^2=-9\)，\((-2)^3=-8\)；除：\((-8)\div4=-2\)；加：\(-9+(-2)=-11\)。B 是把 \(-3^2\) 算成了 \(9\)；C 是先做了加法再除；D 是把 \((-2)^3\) 算成了 \(8\)。

5. 把 \(0.3449\) 精确到 \(0.01\)，结果是哪个？

提示

只看百分位的下一位（千分位）数字，四舍五入只做一次。

B。千分位是 \(4\)，舍去，得 \(0.34\)。A 是从最后一位开始一位一位往前进：\(0.3449\to0.345\to0.35\)，这样做是错的；C 只精确到了 \(0.1\)；D 保留到了千分位。

挑战

6. 一列数：\(-2\)，\(4\)，\(-8\)，\(16\)，\(-32\)，……按这个规律，第 \(7\) 个数是多少？

提示 1：把每个数写成乘方

\(-2=(-2)^1\)，\(4=(-2)^2\)，\(-8=(-2)^3\)……第 \(7\) 个数是 \((-2)\) 的几次方？

提示 2：先定符号

\(7\) 个 \(-2\) 相乘，负因数是奇数个还是偶数个？

B。第 \(k\) 个数是 \((-2)^k\)，第 \(7\) 个是 \((-2)^7\)：\(7\) 个负因数，为负；\(2^7=128\)。所以是 \(-128\)。也可以发现每个数都是前一个的 \(-2\) 倍：第 \(6\) 个是 \(64\)，第 \(7\) 个是 \(64\times(-2)=-128\)。A 符号错了；C 是 \((-2)\times7\)；D 是第 \(6\) 个数。

科学记数法几乎每年都考，常放在选择题前几题。选择题点选项自动判对错，做完看解析。
