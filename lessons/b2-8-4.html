8.4 空间点、直线、平面之间的位置关系

从二维平面走向三维空间：四大基本事实构建几何大厦，两直线不相交不一定是平行（异面直线），等角定理谨记互补，平移化异面为共面求夹角。

在初中平面几何里，我们熟悉一个经验：“在同一个平面内，两条直线如果不相交，就一定互相平行”。

但抬头观察真实的三维世界：高架桥上一辆汽车自西向东飞驰，桥下地面上一列地铁自北向南穿行；或者教室天花板上的日光灯管，与地面上一条斜穿的瓷砖拼缝——

高架桥上的公路与地面上的铁轨，这两条直线既永远不会相交，也显然不平行。在空间中，它们属于什么位置关系？

B。这两条直线既不相交，也不平行，它们分别处于不同的高度和方向，不同在任何一个平面内，数学上称之为异面直线。

初中的“不相交即平行”有一个至关重要的前提——“在同一平面内”。迈入三维空间，无公共点的两条直线完全可能是异面直线。这一节我们就来系统建立空间点、线、面的位置关系体系，掌握确定平面的四大基本事实。

1. 先认识几个词

要用到：8.1 基本立体图形里的正方体、棱和面（回看 8.1），8.2 怎么画直观图（回看 8.2）；初中的「同一平面内，两直线不相交就平行」。

平面：平的、没有厚度、向四周无限伸展。画的时候用一个平行四边形代表它，记作平面 \(\alpha\)、平面 \(ABCD\) 等。

例：正方体 \(ABCD-A_1B_1C_1D_1\) 的底面画出来只是一块正方形，但「平面 \(ABCD\)」指的是把这块正方形无限延展开的那整张平面。

属于、在……内：点在平面内写 \(A\in\alpha\)；直线在平面内写 \(l\subset\alpha\)（直线是点的集合，所以用「包含」）。

例：在正方体里，\(A\in\) 平面 \(ABCD\)，\(A_1\notin\) 平面 \(ABCD\)，直线 \(AB\subset\) 平面 \(ABCD\)。

共线、共面：几个点在同一条直线上叫共线；几个点（或几条线）在同一个平面内叫共面。

例：正方体的 \(A,B,C,D\) 四点共面；\(A,B,C_1,D_1\) 也共面（它们组成一个长方形截面）；而 \(A,B,C,C_1\) 不共面。

异面直线：不同在任何一个平面内的两条直线。它们没有公共点，但也不平行。

例：正方体里棱 \(AB\) 是「前后」方向，棱 \(CC_1\) 是「上下」方向，两条棱没有公共点，也找不到一个平面同时装下它们。

2. 三条基本事实：平面怎么定、线怎么放、面怎么交

立体几何的推理从下面三条出发，它们是大家公认、不再证明的事实：

基本事实 1：过不在一条直线上的三个点，有且只有一个平面。
基本事实 2：一条直线上有两个点在一个平面内，这条直线就在这个平面内。
基本事实 3：两个不重合的平面有一个公共点，就有且只有一条过这个点的公共直线（交线）。

为什么这样说：三脚架放在不平的地上也不晃，三个脚尖总能定下一个面；拿直尺贴在桌面，两端都贴住了，整条边就都贴住了；翻开的书，两页只在书脊那条线上相交。

由基本事实 1 还能推出三种定平面的方式：一条直线和直线外一点；两条相交直线；两条平行直线。

怎么用：要证几个点共线，常说明它们都是两个平面的公共点——两个平面的公共点都落在唯一的交线上。要证共面，先用其中几个元素定一个平面，再说明其余的也在里面。

例 1（看一遍怎么写）

\(\triangle ABC\) 不在平面 \(\alpha\) 内，直线 \(AB,\ BC,\ CA\) 延长后分别与平面 \(\alpha\) 交于点 \(P,\ Q,\ R\)。证明 \(P,Q,R\) 三点共线。

证：\(A,B,C\) 不共线，由基本事实 1，它们确定一个平面，记作平面 \(ABC\)。

\(P\) 在直线 \(AB\) 上，而 \(AB\subset\) 平面 \(ABC\)，所以 \(P\in\) 平面 \(ABC\)；又 \(P\in\alpha\)。所以 \(P\) 是两个平面的公共点。同理 \(Q,\ R\) 也是公共点。

平面 \(ABC\) 与 \(\alpha\) 不重合（\(\triangle ABC\) 不在 \(\alpha\) 内），又有公共点，由基本事实 3，它们交于一条直线 \(l\)，并且所有公共点都在 \(l\) 上。

所以 \(P,Q,R\) 都在 \(l\) 上，三点共线。

自己试试：空间中有四个点，其中三个点在同一条直线上。这四个点：

A。设 \(A,B,C\) 在直线 \(l\) 上。第四点 \(D\) 若不在 \(l\) 上，「直线和直线外一点」定一个平面，四点都在里面；若 \(D\) 也在 \(l\) 上，四点共线，当然也共面。选 C 的同学把它和「四点中任意三点不共线」弄混了，那种情况才可能不共面。

3. 空间两条直线的三种位置

在平面里，两条直线不是相交就是平行。到了空间，多出一种：异面。

关系在同一平面内？公共点
相交是恰 1 个
平行是0 个
异面否0 个
没有公共点，可能平行也可能异面。先确认两条线在同一平面内，才能说「不相交就平行」。

空间里平行仍能传递（基本事实 4）：平行于同一条直线的两条直线平行，即 \(a\parallel b,\ b\parallel c\Rightarrow a\parallel c\)。但「异面」不能传递，下面就看到。

例 2

在正方体 \(ABCD-A_1B_1C_1D_1\) 中，判断：① \(AD_1\) 与 \(BC_1\)；② \(AB\) 与 \(C_1D_1\)；③ \(AB\) 与 \(CC_1\) 的位置关系。

① \(AB\parallel D_1C_1\) 且 \(AB=D_1C_1\)（都和 \(DC\) 平行且相等），所以 \(ABC_1D_1\) 是平行四边形，对边 \(AD_1\parallel BC_1\)：平行。

② \(AB\parallel DC\)，\(DC\parallel D_1C_1\)，由基本事实 4，\(AB\parallel C_1D_1\)：平行。（它们不在同一个面上，但仍平行。）

③ 平面 \(BCC_1B_1\) 包含 \(CC_1\)，\(B\) 在这个平面内但不在 \(CC_1\) 上，\(A\) 不在这个平面内。如果 \(AB\) 与 \(CC_1\) 共面，这个平面就含有 \(CC_1\) 和 \(B\)，只能是平面 \(BCC_1B_1\)，可 \(A\) 不在其中，矛盾。所以是异面。

自己试试：直线 \(a\) 与 \(b\) 异面，\(b\) 与 \(c\) 异面。那么 \(a\) 与 \(c\)：

D。在正方体里取 \(b=AB\)：\(a=CC_1\)、\(c=DD_1\) 时 \(a\parallel c\)；\(a=CC_1\)、\(c=B_1C_1\) 时相交于 \(C_1\)；\(a=CC_1\)、\(c=A_1D_1\) 时异面。选 A 的同学把「异面」当成像平行一样能传递，其实只有平行能传递。

4. 等角定理与异面直线所成的角

等角定理：空间中两个角的两边分别对应平行，这两个角相等或互补。两组边方向都相同（或都相反）时相等，一组同向、一组反向时互补。

有了它，就能给异面直线定一个「夹角」：过空间任一点 \(O\) 作 \(a'\parallel a,\ b'\parallel b\)，\(a'\) 与 \(b'\) 相交，所成的锐角或直角叫异面直线 \(a,b\) 所成的角。由等角定理，换一个点 \(O\) 角也不变，所以通常把 \(O\) 取在其中一条直线上，只平移另一条。

异面直线所成角 \(\theta\) 的范围：\(0^\circ<\theta\le90^\circ\)。等于 \(90^\circ\) 时称两直线互相垂直，记 \(a\perp b\)（异面也可以垂直）。
求法三步：平移成相交 → 在三角形里算角 → 若算出钝角，取它的补角。

例 3（看一遍怎么写）

正方体 \(ABCD-A_1B_1C_1D_1\) 的棱长为 \(1\)。求：① \(A_1B\) 与 \(CC_1\) 所成的角；② \(A_1B\) 与 \(B_1C\) 所成的角。

① \(CC_1\parallel BB_1\)，所以所求角就是 \(A_1B\) 与 \(BB_1\) 的夹角 \(\angle A_1BB_1\)。在正方形 \(ABB_1A_1\) 中，对角线平分直角，\(\angle A_1BB_1=45^\circ\)。所求角为 \(45^\circ\)。

② 平移 \(A_1B\)：\(A_1D_1\parallel BC\) 且 \(A_1D_1=BC\)，所以 \(A_1BCD_1\) 是平行四边形，\(A_1B\parallel D_1C\)。所求角就是 \(D_1C\) 与 \(B_1C\) 的夹角 \(\angle B_1CD_1\)。

连 \(B_1D_1\)。\(\triangle B_1CD_1\) 的三边 \(B_1C,\ D_1C,\ B_1D_1\) 都是面对角线，长都是 \(\sqrt2\)，是等边三角形，\(\angle B_1CD_1=60^\circ\)。所求角为 \(60^\circ\)。

自己试试：在正方体 \(ABCD-A_1B_1C_1D_1\) 中，异面直线 \(A_1B_1\) 与 \(BC_1\) 所成的角是：

C。\(A_1B_1\parallel AB\)，所以所求角就是 \(AB\) 与 \(BC_1\) 的夹角 \(\angle ABC_1\)。设棱长为 \(1\)，在 \(\triangle ABC_1\) 中，\(AB=1\)，\(BC_1=\sqrt2\)（面对角线），\(AC_1=\sqrt3\)（体对角线），\(1^2+(\sqrt2)^2=(\sqrt3)^2\)，由勾股定理的逆定理，\(\angle ABC_1=90^\circ\)。

选 B 的同学看到 \(BC_1\) 是面对角线，就以为和棱成 \(45^\circ\)；可 \(45^\circ\) 是它和同一面里的棱 \(BC\) 的夹角，\(AB\) 不在那个面里。

5. 边界条件：各配一个反例

① 三点必须不共线。反例：三点在一条直线上时，过它们的平面有无数个，像翻开的书，每一页都过书脊。

② 两个平面必须不重合，才谈得上交线。反例：平面 \(ABCD\) 与它自己有无数公共点，却说不上「交线」。

③ 「不相交就平行」只在同一平面内成立。反例：正方体的 \(AB\) 与 \(CC_1\) 不相交，但不平行，是异面。

④ 图上相交不等于空间相交。反例：从上往下看立交桥，两条路在图上交叉，实际上一上一下，是异面直线。画出的图只是投影，相交要靠推理确认。

⑤ 等角定理是「相等或互补」。反例：\(\angle AOB=50^\circ\)，把 \(OB\) 反向延长成射线 \(OB'\)，\(\angle AOB'\) 的两边与 \(\angle AOB\) 的两边分别平行（同一直线），但它等于 \(130^\circ\)。

⑥ 异面直线所成角不取钝角。反例：平移后在三角形里算出的内角是 \(120^\circ\)，所成角应写 \(180^\circ-120^\circ=60^\circ\)，不能写 \(120^\circ\)。另外它也不能是 \(0^\circ\)：夹角为 \(0^\circ\) 意味着平行，就不是异面了。

再深一点（可以先跳过）

三线共点：要证三条直线交于一点，先说明其中两条交于点 \(P\)，再说明 \(P\) 在第三条线上——常常第三条线是两个平面的交线，而 \(P\) 正好是这两个平面的公共点。

判断异面的常用说法（例 2 ③ 就是这样）：平面外一点和平面内一点连成的直线，与平面内不过后一点的直线异面。

这一章用什么工具：本章只用基本事实和平面几何推理。平面向量只能在已经确认的同一个平面里用；平面方程、法向量这些后面选必一才学，这里不用。

直接用

1. 在正方体 \(ABCD-A_1B_1C_1D_1\) 的 12 条棱中，与棱 \(AB\) 既不相交也不平行的棱（即异面棱）共有几条？

B。正方体共有 12 条棱。与棱 \(AB\) 的关系分类如下：

  • 与 \(AB\) 平行的棱有 3 条：\(A_1B_1, CD, C_1D_1\)；
  • 与 \(AB\) 相交的棱有 4 条：\(AA_1, BB_1, AD, BC\)；
  • 排除 \(AB\) 本身及上述 7 条棱，剩下的 4 条棱与 \(AB\) 既不相交也不平行，全部是异面直线，它们是：\(CC_1, DD_1, A_1D_1, B_1C_1\)。

2. 空间中三条直线 \(a, b, c\)。若 \(a \parallel b\) 且 \(b \parallel c\)，则直线 \(a\) 与 \(c\) 的位置关系是：

A。由立体几何基本事实 4（平行公理）：平行于同一条直线的两条直线互相平行。该性质在三维空间中依然具有严格的传递性，因此只要 \(a \parallel b\) 且 \(b \parallel c\)，必有 \(a \parallel c\)。

3. 在正四面体（四个面均为正三角形的三棱锥）\(P-ABC\) 中，棱 \(PA\) 与对棱 \(BC\) 所成的角的大小为：

D。取 \(BC\) 的中点 \(D\)，连结 \(PD, AD\)。

因为 \(\triangle PBC\) 与 \(\triangle ABC\) 都是等边三角形，所以中线也是高：\(PD \perp BC\) 且 \(AD \perp BC\)。

因为 \(PD \cap AD = D\)，所以 \(BC \perp\) 平面 \(PAD\)。

又因为 \(PA \subset\) 平面 \(PAD\)，所以 \(BC \perp PA\)，即异面直线 \(PA\) 与 \(BC\) 所成的角是 \(90^\circ\)（互相异面垂直）。

结论推广：正四面体的任意一组对棱都互相垂直，这是高考的高频几何特征！

易错

4. 空间中两个角 \(\angle A\) 和 \(\angle B\) 的两边分别对应平行。已知 \(\angle A = 55^\circ\)，则 \(\angle B\) 的度数为：

C。易错警示：根据等角定理，空间中如果两个角的两边分别对应平行，那么这两个角相等或互补！

当两组对应边方向均相同或均相反时，\(\angle B = \angle A = 55^\circ\)；当一组方向相同、另一组方向相反时，\(\angle B = 180^\circ - 55^\circ = 125^\circ\)。未给定图形时必须保留两解，切莫漏掉“互补”！

5. 下列关于空间点、线、面位置关系的命题中，正确的是：

C。逐项剖析：

  • A 错误：基本事实 1 明确要求“不共线的三点”。若三点在同一直线上，经过它们的平面有无数个；
  • B 错误：空间中没有公共点的两直线可能是平行直线，也可能是异面直线；
  • C 正确：设对角线相交于点 \(O\)，两对角线是两条相交直线，由基本事实 1 的推论“两条相交直线确定一个平面”，该平面的四个顶点必同在这一平面内；
  • D 错误：反例为普通平面凸四边形（如矩形），四个顶点任意三点不共线，但它们完全共面。
