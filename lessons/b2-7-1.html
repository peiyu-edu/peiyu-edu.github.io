7.1 复数的概念

在实数范围内，负数没有平方根。引入虚数单位 \(i\)，数从一维数轴扩充到二维复平面。实部、虚部、模长与几何意义，一次搞明白。

回顾数系的扩充历程，每一次都是因为「现有的数不够用了」：

  • 小减大减不出来，引入了负数，扩充到整数；
  • 整数相除（除数非零）不一定得到整数，例如 \(1\div2\)，引入分数，扩充到有理数；
  • 正方形边长 \(\sqrt{2}\) 无法表示为分数，引入了无理数，扩充到实数。

在实数范围内，任何数的平方都不能是负数（\(x^2 \ge 0\)）。可如果解下面这个方程呢？

方程 \(x^2 + 1 = 0\) 在实数范围内有解吗？

B。移项得到 \(x^2 = -1\)。因为任何实数的平方都 \(\ge 0\)，所以在实数范围内不存在平方等于 \(-1\) 的数，该方程无实数解。

为了让这类方程也能求解，数学家规定了一个新数 \(i\)，叫做虚数单位，并规定 \(i^2 = -1\)。这样方程 \(x^2 = -1\) 就有了新解 \(x = \pm i\)。

把虚数单位 \(i\) 与实数结合起来相加相乘，就得到了更广阔的数系——复数。从此，数不再只排在一条一维数轴上，而是铺开成了整整一个复平面！

1. 先认识几个词

要用到：实数与平方根（初中学过）；平面向量与坐标表示（必修第二册第 6 章）。

直觉微图解

分类判定 ①实数、虚数与纯虚数

设 \(z = a + bi\)（\(a, b \in \mathbf{R}\)）：
• \(b = 0 \implies\) 实数（包括 \(0 = 0 + 0i\)！）；
• \(b \ne 0 \implies\) 虚数；
• \(a = 0\) 且 \(b \ne 0 \implies\) 纯虚数（原点 \(0\) 是实数绝不是纯虚数！）。

本质区别 ②实数可以比较大小，一般复数不沿用这种顺序

本章不规定一般复数的大小顺序：不能把实数的大小关系直接用于 \(2+3i\) 与 \(1+2i\)。实数之间仍可比较大小；复数的模长 \(|z|\) 是非负实数，也可以比较大小。

虚数单位 \(i\)：规定 \(i^2 = -1\)。在复数范围内，方程 \(x^2=-4\) 有两个解 \(x=\pm2i\)，因为 \((\pm2i)^2=-4\)。

复数的代数形式 \(z = a + bi\)：\(a, b \in \mathbf{R}\)。\(a\) 叫做实部，实数 \(b\) 叫做虚部（特别注意：虚部是实数 \(b\)，绝不是 \(bi\)！）。

复平面与向量对应：横轴为实轴，纵轴为虚轴。复数 \(z = a + bi\) 一一对应复平面内的点 \(Z(a, b)\)，也一一对应平面向量 \(\overrightarrow{OZ} = (a, b)\)。

2. 核心公式与复数相等定理

① 复数代数式：\(z = a + bi\)（\(a, b \in \mathbf{R}\)，实部 \(a\)，虚部 \(b\) 为实数）；
② 复数相等充要条件（\(a,b,c,d\in\mathbf{R}\)）：\(a + bi = c + di \iff a = c \text{ 且 } b = d\)（实部对实部，虚部对虚部，一个等式拆两个方程）；
③ 模长公式：\(|z| = \sqrt{a^2 + b^2} = |\overrightarrow{OZ}|\)（几何意义为点到原点的欧氏距离，非负实数）；
④ 共轭复数：\(\bar{z} = a - bi\)（复平面关于实轴上下镜像，且 \(z\bar{z} = a^2 + b^2 = |z|^2\)）。

例 1（复数相等与方程）

已知实数 \(x, y\) 满足 \((x + 2) + (y - 3)i = 0\)，求 \(x, y\) 的值。

解：因为 \(0 = 0 + 0i\)，由复数相等的充要条件得：

\(\begin{cases} x + 2 = 0 \\ y - 3 = 0 \end{cases} \implies \begin{cases} x = -2 \\ y = 3 \end{cases}\)

所以 \(x = -2\)，\(y = 3\)。

自己试试：已知复数 \(z = (2x - 4) + (x + 1)i\)（\(x \in \mathbf{R}\)）是纯虚数，则实数 \(x\) 的值是？

B。纯虚数必须同时满足两件事：

  • 实部等于 \(0\)：\(2x - 4 = 0 \implies x = 2\)；
  • 虚部不等于 \(0\)：\(x + 1 \ne 0 \implies x \ne -1\)。

检验：将 \(x = 2\) 代入得虚部为 \(2 + 1 = 3 \ne 0\)，符合条件。选 C 的同学忽略了纯虚数的虚部不能为 \(0\)：若 \(x = -1\)，复数为 \(-6 + 0i = -6\)，是实数而不是纯虚数！

视频例题：二次参数的复数分类

设 \(m\in\mathbf{R}\)，\(z=(m^2+m-2)+(m-1)i\)。分别求 \(z\) 为实数、虚数、纯虚数时 \(m\) 的取值。

实数要求虚部为零：\(m-1=0\)，即 \(m=1\)；虚数要求虚部非零，即 \(m\ne1\)。

纯虚数还要求实部为零：\((m+2)(m-1)=0\)，且 \(m-1\ne0\)。舍去使 \(z=0\) 的 \(m=1\)，得到 \(m=-2\)，此时 \(z=-3i\)。下方视频讲解这三类；上方线性参数题用于自己练习。

3. 典型例题：三步思维链精讲

例 2（高频综合·参数分类与象限判定）

已知复数 \(z = (m^2 - m - 2) + (m^2 - 1)i\)（\(m \in \mathbf{R}\)）。
① 若 \(z\) 为实数，求 \(m\) 的值；
② 若 \(z\) 为纯虚数，求 \(m\) 的值；
③ 若 \(z\) 对应复平面上的点位于第二象限，求 \(m\) 的取值范围。

👀 第一眼·破题信号
看到「实数/纯虚数/象限」关键词 → 核心破题信号：先分离实部 \(a(m)\) 与虚部 \(b(m)\)，列对应方程或不等式组；本题的二次式可因式分解，便于求解！
🔧 第二步·套公式拆解
拆分实部与虚部：实部 \(a = m^2 - m - 2 = (m-2)(m+1)\)，虚部 \(b = m^2 - 1 = (m-1)(m+1)\)；
① 若 \(z\) 为实数 \(\iff\) 虚部 \(b = 0 \implies (m-1)(m+1) = 0 \implies\) \(m = 1\) 或 \(m = -1\)；
② 若 \(z\) 为纯虚数 \(\iff\) 实部 \(a = 0\) 且 虚部 \(b \ne 0\)：
    由 \(a = 0 \implies m = 2\) 或 \(m = -1\)；但 \(m = -1\) 会导致虚部 \(b = 0\)（\(z=0\) 成为实数），必须舍去！
    故唯一解为 \(m = 2\)（此时 \(z = 3i\)）；
③ 位于第二象限 \(\iff\) 实部 \(a < 0\) 且 虚部 \(b > 0\)：
    \((m-2)(m+1) < 0 \implies -1 < m < 2\)；
    \(m^2 - 1 > 0 \implies m > 1\) 或 \(m < -1\)；
    求交集得 \(1 < m < 2\)。
🛡️ 第三步·必查防坑点
① 纯虚数判定是「实部为零 且 虚部非零」双重条件，漏掉虚部非零检验必扣分；
② 象限点不含坐标轴，不等式严格取大于号或小于号，不能带等号。

下方视频逐步讲解上面的例 2：实数、纯虚数与第二象限的参数分类。

自己试试：已知复数 \(z = a - 2i\)（\(a \in \mathbf{R}\)），且 \(|z| = \sqrt{13}\)，在复平面内对应的点在第四象限，则 \(a\) 的值是？

A。由模长公式：\(|z| = \sqrt{a^2 + (-2)^2} = \sqrt{a^2 + 4} = \sqrt{13}\)，两边平方得 \(a^2 + 4 = 13 \implies a^2 = 9 \implies a = \pm 3\)。

因为点落在第四象限，横坐标（实部）必须为正，即 \(a > 0\)，因此 \(a = 3\)。选 C 的同学漏看了象限对符号的正负约束。

4. 这三种情况最容易翻车

翻车现场 ①把虚部错误写成带 i 的项
错解

认为复数 \(z = 3 + 4i\) 的虚部是 \(4i\)。

正解

实部是实数 \(3\)，虚部是实数 \(4\)！实部和虚部本身都是实数，绝不带字母 \(i\)。

翻车现场 ②虚数妄图比较大小
错解

写出 \(3i > 2i\) 或 \(2 + 3i > 1 + 2i\)。

正解

本章不为一般复数规定实数式的大小顺序，因此不写 \(3i>2i\)。但模长是实数，可以写 \(|3i|=3>2=|2i|\)。

翻车现场 ③纯虚数漏检「虚部不为 0」
错解

只令实部等于 \(0\)，误把 \(0 = 0 + 0i\) 当作纯虚数。

正解

\(0\) 的虚部也是 \(0\)，所以 \(0\) 是实数！纯虚数必须同时满足实部为 \(0\) 且 虚部不为 \(0\)。

再深一点（可以先跳过）

共轭复数与模的联系：实部相等、虚部互为相反数的两复数互为共轭，记作 \(\bar{z} = a - bi\)。它们在复平面上关于实轴对称，且乘积为实数：\(z\bar{z} = (a+bi)(a-bi) = a^2 + b^2 = |z|^2\)。这是下一节除法分母实数化的核心武器。

复数加减的向量本质：复数加减对应平面向量加减，模长满足三角不等式：\(||z_1| - |z_2|| \le |z_1 \pm z_2| \le |z_1| + |z_2|\)。非退化三角形满足严格的两边关系；退化为共线情形时可取等号，所以这里写不等号 \(\le\)。

① 复平面：拖动点 Z，观察实部、虚部、模长与状态

拖动点 \(Z(a, b)\)（或选中后按方向键移动）。观察复数代数形式、实虚部分解、模长 \(\sqrt{a^2 + b^2}\) 以及点落在坐标轴上的类型变化。

从易到难排好了。前两道直接用，中间三道是高频易错红线，最后一道是几何综合挑战。

直接用

1. 复数 \(z = 2 - 3i\) 的虚部是？

A。在代数形式 \(z = a + bi\) 中，虚部是 \(i\) 前面的实数系数 \(b\)，带符号是 \(-3\)，不能带 \(i\)。选 B 的同学混淆了「虚数项」与「虚部」；选 D 是实部。

2. 复数 \(z = -1 + \sqrt{3}i\) 的模长 \(|z|\) 等于？

B。模长公式为 \(|z| = \sqrt{a^2 + b^2} = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2\)。选 C 的同学算出了 \(a^2 + b^2 = 4\) 却忘了开平方。

易错

3. 已知复数 \(z = (m^2 - 1) + (m - 1)i\)（\(m \in \mathbf{R}\)）是纯虚数，则实数 \(m\) 的值是？

B。纯虚数必须满足两个条件：实部为 \(0\) 且 虚部不为 \(0\)。

  • 由实部 \(m^2 - 1 = 0\) 得 \(m = 1\) 或 \(m = -1\)；
  • 由虚部 \(m - 1 \ne 0\) 得 \(m \ne 1\)。

两者综合只能取 \(m = -1\)。若 \(m = 1\)，则 \(z = 0\) 是实数，绝不是纯虚数！这是高频陷阱。

4. 下列关于复数的说法中，正确的是？

C。本章不把实数的大小关系用于一般复数，因此 A、B 的比较没有本章定义的含义，D 也不成立。但模长是实数，可以比较大小：\(|2 + 3i| = \sqrt{2^2 + 3^2} = \sqrt{13}\)，\(|1 + 2i| = \sqrt{1^2 + 2^2} = \sqrt{5}\)，因为 \(\sqrt{13} > \sqrt{5}\)，所以 C 正确。

5. 已知实数 \(a \in \mathbf{R}\)，复数 \(z = (a - 1) + (a^2 - 4)i\) 在复平面内对应的点位于第二象限，则 \(a\) 的取值范围是？

B。点在第二象限要求横坐标（实部）小于 \(0\) 且纵坐标（虚部）大于 \(0\)：

  • 实部：\(a - 1 < 0 \implies a < 1\)；
  • 虚部：\(a^2 - 4 > 0 \implies a < -2\) 或 \(a > 2\)。

求交集得 \(a < -2\)。选 C 的同学将二次不等式 \(a^2 - 4 > 0\) 误解成了夹在两根之间。

挑战

6. 在复平面内，已知复数 \(z\) 满足 \(|z - (3 + 4i)| = 2\)，则 \(|z|\) 的最大值是？

C。从几何意义理解：\(|z_1 - z_2|\) 表示两点间的距离。\(|z - (3 + 4i)| = 2\) 表示动点 \(Z\) 到定点 \(P(3, 4)\) 的距离恒等于 \(2\)，即点 \(Z\) 的轨迹是以 \(P(3, 4)\) 为圆心、半径 \(R = 2\) 的圆。

\(|z|\) 表示点 \(Z\) 到原点 \(O(0, 0)\) 的距离。圆心到原点的距离为 \(|OP| = \sqrt{3^2 + 4^2} = 5\)。

因此圆上的点到原点的最大距离为 \(|OP| + R = 5 + 2 = 7\)（最小值为 \(5 - 2 = 3\)）。选 C。
