1.3 空间向量及其运算的坐标表示

建好空间直角坐标系，点和向量都写成三个数。求长度、夹角，判断垂直、平行，就变成按公式算这几个数。

一艘货运飞船正向空间站核心舱实施无人自主交会对接。在激光雷达建立的三维导航坐标系中，空间站接口为原点 \(O(0,0,0)\)，传感器测得飞船对接机构相对于 \(O\) 的空间位置为：向前（\(x\) 轴）\(2\,\text{m}\)、向右（\(y\) 轴）\(3\,\text{m}\)、向上（\(z\) 轴）\(6\,\text{m}\)，即空间点 \(P(2, 3, 6)\)。先点下面的按钮查看三维坐标盒与体对角线：

从原点 \(O\) 直线连接到对接靶心 \(P\)，位移向量 \(\overrightarrow{OP}\) 的空间直线距离（即向量模长 \(|\overrightarrow{OP}|\)）是多少米？

B。答案是 \(7\,\text{m}\)。

在空间长方体中，以 \(O\) 为一个顶点、\(P(x,y,z)\) 为对角顶点的体对角线长，由两次勾股定理可得：底面长宽构成投影对角线长 \(\sqrt{x^2+y^2}\)，再与竖直高 \(z\) 做勾股定理，体对角线长即为：

$$|\overrightarrow{OP}| = \sqrt{(\sqrt{x^2+y^2})^2 + z^2} = \sqrt{x^2+y^2+z^2} = \sqrt{4+9+36} = \sqrt{49} = 7\,\text{m}$$

通过建立空间直角坐标系，立体几何中点的位置、线段的长度、异面直线的夹角与垂直关系，都可以完全转化为代数算式一样精准可靠的坐标运算！

1. 先认识几个词

要用到：1.2 空间向量基本定理（单位正交基底）；必修二 6.3 平面向量的坐标表示。

课本用词：建立空间直角坐标系要保证三轴两两垂直；坐标向量按终点减起点，平行判定不能在分量为零时乱用比例式。

伴读直觉微图解：空间右手直角坐标系、投影盒与正交数量积

空间直角坐标系 \(O\text{-}xyz\)：选一点 \(O\) 当原点，过 \(O\) 作三条两两垂直、单位长度相同的数轴：\(x\) 轴、\(y\) 轴、\(z\) 轴。高中默认用右手系：右手四指从 \(x\) 轴正向握向 \(y\) 轴正向，大拇指指的就是 \(z\) 轴正向。

例：教室的一个墙角当原点，地面上沿两面墙的墙根分别是 \(x\) 轴、\(y\) 轴，竖直向上的墙缝是 \(z\) 轴。

单位正交基底 \(\{\boldsymbol{i}, \boldsymbol{j}, \boldsymbol{k}\}\)：沿 \(x, y, z\) 轴正向、长度为 \(1\) 的三个向量。它们两两垂直，所以 \(\boldsymbol{i}\cdot\boldsymbol{j} = \boldsymbol{j}\cdot\boldsymbol{k} = \boldsymbol{k}\cdot\boldsymbol{i} = 0\)，而 \(\boldsymbol{i}\cdot\boldsymbol{i} = \boldsymbol{j}\cdot\boldsymbol{j} = \boldsymbol{k}\cdot\boldsymbol{k} = 1\)。

例：\(\boldsymbol{a} = 2\boldsymbol{i} - \boldsymbol{j} + 3\boldsymbol{k}\)，它的坐标就是 \((2, -1, 3)\)。

投影点、对称点：对点 \(P(x, y, z)\)，

  • 投影：在谁上面就留谁，别的变 \(0\)。投到 \(xOy\) 面是 \((x, y, 0)\)，投到 \(x\) 轴是 \((x, 0, 0)\)。
  • 对称：关于谁对称谁不变，别的变相反数。关于 \(xOy\) 面是 \((x, y, -z)\)，关于 \(z\) 轴是 \((-x, -y, z)\)，关于原点是 \((-x, -y, -z)\)。

例：\(P(2, -3, 4)\) 投到 \(xOy\) 面得 \((2, -3, 0)\)；关于 \(z\) 轴的对称点是 \((-2, 3, 4)\)；关于原点的对称点是 \((-2, 3, -4)\)。

本质区别 点的坐标（绝对位置） vs 向量的坐标（相对位移）

点的坐标 \(P(x,y,z)\)：固定空间点相对于原点的位置；把这个点平移后，其坐标会改变。

向量坐标 \(\overrightarrow{AB}\)：终点减起点，表示位移增量。自由平移后向量坐标恒定不变！

提醒：只有当向量起点位于原点 \(O\) 时，向量坐标才恰好等于终点坐标！

判定陷阱 平行判定比例式 vs 实数倍充要式

分式比例式：\(\frac{x_2}{x_1} = \frac{y_2}{y_1} = \frac{z_2}{z_1}\) 仅在分母全不为 0 时有效，遇 0 分母直接崩溃！

实数倍充要式：当 \(\boldsymbol{a}\ne\boldsymbol0\) 时，\(\boldsymbol{b} = \lambda\boldsymbol{a}\)（分量逐一对应），遇到 0 分量时对应分量必同为 0，不需要除以该分量。规定零向量与任意向量平行；若基准向量本身为零，须另行处理。

铁律：有分量为 0 时严禁写比例式，务必写成方程组 \(\boldsymbol{b} = \lambda\boldsymbol{a}\)！

向量坐标定义：\(\overrightarrow{AB} = (x_2 - x_1, y_2 - y_1, z_2 - z_1) = \color{#2563eb}{\text{终点}} - \color{#059669}{\text{起点}}\)
数量积坐标公式：\(\boldsymbol{a}\cdot\boldsymbol{b} = \color{#2563eb}{x_1x_2} + \color{#059669}{y_1y_2} + \color{#d97706}{z_1z_2}\)  （两向量非零时，垂直充要条件为该式 \(= 0\)）
空间两点距离公式：\(d = |\overrightarrow{AB}| = \sqrt{\color{#2563eb}{(x_2-x_1)^2} + \color{#059669}{(y_2-y_1)^2} + \color{#d97706}{(z_2-z_1)^2}}\)

2. 建系，写出点和向量的坐标

点的坐标：若 \(\overrightarrow{OP} = x\boldsymbol{i} + y\boldsymbol{j} + z\boldsymbol{k}\)，就说点 \(P\) 的坐标是 \((x, y, z)\)，它表示一个确定的位置。向量的坐标：若 \(\boldsymbol{a} = x\boldsymbol{i} + y\boldsymbol{j} + z\boldsymbol{k}\)，就记 \(\boldsymbol{a} = (x, y, z)\)；向量平移后坐标不变。

两者的联系：\(\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}\)，所以

\(A(x_1, y_1, z_1)\)，\(B(x_2, y_2, z_2)\)： $$\overrightarrow{AB} = (x_2 - x_1,\ y_2 - y_1,\ z_2 - z_1)$$ 终点减起点。

建系前先找三条两两垂直、交于一点的线（长方体、正方体的一个顶点处最常见），说明它们垂直，再标原点、方向和单位。

例 1（长方体里写坐标）

长方体 \(ABCD-A_1B_1C_1D_1\) 中，\(AB = 4\)，\(AD = 2\)，\(AA_1 = 3\)，\(M\) 是棱 \(C_1D_1\) 的中点。建立坐标系，写出 \(C_1\)、\(M\) 的坐标和 \(\overrightarrow{BM}\) 的坐标。

解：长方体的棱 \(AB, AD, AA_1\) 交于 \(A\) 且两两垂直。以 \(A\) 为原点，\(AB, AD, AA_1\) 方向分别为 \(x, y, z\) 轴正向，单位长度为 \(1\)。

\(B(4, 0, 0)\)，\(C_1(4, 2, 3)\)，\(D_1(0, 2, 3)\)。

\(M\) 是 \(C_1D_1\) 中点，坐标取平均：\(M\left(\dfrac{4+0}{2}, \dfrac{2+2}{2}, \dfrac{3+3}{2}\right) = (2, 2, 3)\)。

终点减起点：\(\overrightarrow{BM} = (2-4,\ 2-0,\ 3-0) = (-2, 2, 3)\)。

自己试试：棱长为 \(2\) 的正方体 \(ABCD-A_1B_1C_1D_1\)，以 \(D\) 为原点，\(DA, DC, DD_1\) 为 \(x, y, z\) 轴。\(E\) 是棱 \(BB_1\) 的中点，\(\overrightarrow{D_1E}\) 的坐标是：

A。\(B(2, 2, 0)\)，\(B_1(2, 2, 2)\)，所以 \(E(2, 2, 1)\)；\(D_1(0, 0, 2)\)。

\(\overrightarrow{D_1E} = (2-0,\ 2-0,\ 1-2) = (2, 2, -1)\)。

常见算错：B 是用起点减终点，得到的是 \(\overrightarrow{ED_1}\)；C 是把点 \(E\) 的坐标直接当成了向量坐标，只有起点在原点时才可以这样；D 是把减号写成了加号。

3. 坐标运算：加减、数乘、数量积

设 \(\boldsymbol{a} = (x_1, y_1, z_1)\)，\(\boldsymbol{b} = (x_2, y_2, z_2)\)，\(\lambda \in \mathbf{R}\)。加减和数乘都是逐个分量做：

$$\boldsymbol{a} \pm \boldsymbol{b} = (x_1 \pm x_2,\ y_1 \pm y_2,\ z_1 \pm z_2)$$

$$\lambda\boldsymbol{a} = (\lambda x_1,\ \lambda y_1,\ \lambda z_1)$$

数量积为什么是「对应相乘再相加」：把 \(\boldsymbol{a} = x_1\boldsymbol{i} + y_1\boldsymbol{j} + z_1\boldsymbol{k}\) 和 \(\boldsymbol{b}\) 展开相乘，共 9 项。\(\boldsymbol{i}\cdot\boldsymbol{j}\) 这类交叉项都是 \(0\)，\(\boldsymbol{i}\cdot\boldsymbol{i}\) 这类都是 \(1\)，只剩三项：

$$\boldsymbol{a}\cdot\boldsymbol{b} = x_1x_2 + y_1y_2 + z_1z_2$$

注意：数量积的结果是一个数，不是向量。

例 2（坐标运算）

已知 \(\boldsymbol{a} = (2, -1, 3)\)，\(\boldsymbol{b} = (1, 4, -2)\)。求 (1) \(2\boldsymbol{a} - 3\boldsymbol{b}\)；(2) \(\boldsymbol{a}\cdot\boldsymbol{b}\)；(3) \((\boldsymbol{a} + \boldsymbol{b})\cdot(\boldsymbol{a} - \boldsymbol{b})\)。

解：

(1) \(2\boldsymbol{a} = (4, -2, 6)\)，\(3\boldsymbol{b} = (3, 12, -6)\)，

$$2\boldsymbol{a} - 3\boldsymbol{b} = (4-3,\ -2-12,\ 6-(-6)) = (1, -14, 12)$$

(2) \(\boldsymbol{a}\cdot\boldsymbol{b} = 2\times 1 + (-1)\times 4 + 3\times(-2) = 2 - 4 - 6 = -8\)。

(3) \(\boldsymbol{a} + \boldsymbol{b} = (3, 3, 1)\)，\(\boldsymbol{a} - \boldsymbol{b} = (1, -5, 5)\)，

$$(\boldsymbol{a} + \boldsymbol{b})\cdot(\boldsymbol{a} - \boldsymbol{b}) = 3 - 15 + 5 = -7$$

验算：它也等于 \(|\boldsymbol{a}|^2 - |\boldsymbol{b}|^2 = 14 - 21 = -7\)，两种算法一致。

自己试试：\(\boldsymbol{a} = (1, -2, 3)\)，\(\boldsymbol{b} = (2, -1, -1)\)，\(\boldsymbol{a}\cdot\boldsymbol{b}\) 等于：

A。\(1\times 2 + (-2)\times(-1) + 3\times(-1) = 2 + 2 - 3 = 1\)。

常见算错：B 是把 \((-2)\times(-1)\) 算成了 \(-2\)，负负没得正；C 把三个乘积写成了向量，数量积是一个数；D 是把三项都当正数加了。

4. 模长、两点距离、夹角

模长就是「自己和自己的数量积」开根号，两点距离就是 \(\overrightarrow{AB}\) 的模：

$$|\boldsymbol{a}| = \sqrt{\boldsymbol{a}\cdot\boldsymbol{a}} = \sqrt{x_1^2 + y_1^2 + z_1^2}$$ $$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

这和开头的题一样：长方体体对角线，用两次勾股定理就得到三个平方和。两个非零向量的夹角，用数量积除以两个模长：

$$\cos\langle\boldsymbol{a}, \boldsymbol{b}\rangle = \frac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}|\,|\boldsymbol{b}|}$$ $$= \frac{x_1x_2 + y_1y_2 + z_1z_2}{\sqrt{x_1^2+y_1^2+z_1^2}\,\sqrt{x_2^2+y_2^2+z_2^2}}$$

两个非零向量：当 \(0<\cos\theta<1\) 时为锐角，\(-1<\cos\theta<0\) 时为钝角，\(\cos\theta=0\) 时为直角；\(\cos\theta=1\) 对应同向的 \(0^\circ\)，\(\cos\theta=-1\) 对应反向的 \(180^\circ\)。

例 3（距离与夹角）

已知空间三点 \(A(1, 1, 0)\)、\(B(0, 2, 1)\)、\(C(2, 0, 1)\)。

(1) 求 \(\overrightarrow{AB}\)、\(\overrightarrow{AC}\) 的坐标；(2) 求 \(|\overrightarrow{AB}|\) 和 \(\overrightarrow{AB}\cdot\overrightarrow{AC}\)；(3) 求 \(\langle\overrightarrow{AB}, \overrightarrow{AC}\rangle\)；(4) 求 \(B, C\) 两点间的距离。

解：

(1) 终点减起点：\(\overrightarrow{AB} = (0 - 1, 2 - 1, 1 - 0) = (-1, 1, 1)\)；\(\overrightarrow{AC} = (2 - 1, 0 - 1, 1 - 0) = (1, -1, 1)\)。

(2) \(|\overrightarrow{AB}| = \sqrt{(-1)^2 + 1^2 + 1^2} = \sqrt{3}\)，同理 \(|\overrightarrow{AC}| = \sqrt{3}\)；

\(\overrightarrow{AB}\cdot\overrightarrow{AC} = (-1)\times 1 + 1\times(-1) + 1\times 1 = -1\)。

(3) $$\cos\langle\overrightarrow{AB}, \overrightarrow{AC}\rangle = \frac{-1}{\sqrt{3}\times\sqrt{3}} = -\frac{1}{3}$$

余弦为负，夹角是钝角：\(\langle\overrightarrow{AB}, \overrightarrow{AC}\rangle = \pi - \arccos\dfrac{1}{3}\)。

(4) \(\overrightarrow{BC} = (2, -2, 0)\)，\(|BC| = \sqrt{4 + 4 + 0} = 2\sqrt{2}\)。

自己试试：已知空间点 \(A(2, 1, -1)\)，\(B(1, 3, 1)\)，则 \(|\overrightarrow{AB}|\) 等于：

A。\(\overrightarrow{AB} = (1-2, 3-1, 1-(-1)) = (-1, 2, 2)\)，\(|\overrightarrow{AB}| = \sqrt{1 + 4 + 4} = 3\)。

常见算错：C 是忘了开根号；B 是漏了竖坐标的变化，只算了前两个分量；竖坐标 \(1-(-1)\) 算成 \(0\) 也会得到 B。

5. 垂直与平行的坐标条件

夹角为直角 \(\iff\) 余弦为 \(0\) \(\iff\) 数量积为 \(0\)；平行就是一个向量是另一个的倍数。设 \(\boldsymbol{a}, \boldsymbol{b}\) 都不是零向量：

垂直：\(\boldsymbol{a} \perp \boldsymbol{b} \iff x_1x_2 + y_1y_2 + z_1z_2 = 0\)
平行：\(\boldsymbol{a} \parallel \boldsymbol{b} \iff\) 有实数 \(\lambda\) 使 \(\boldsymbol{b} = \lambda\boldsymbol{a}\)，即 $$x_2 = \lambda x_1,\quad y_2 = \lambda y_1,\quad z_2 = \lambda z_1$$

分量都不为 \(0\) 时，平行也可以写成 \(\dfrac{x_2}{x_1} = \dfrac{y_2}{y_1} = \dfrac{z_2}{z_1}\)；有分量为 \(0\) 时只能用 \(\boldsymbol{b} = \lambda\boldsymbol{a}\)，不能除以 \(0\)。

例 4（由平行、垂直求参数）

已知 \(\boldsymbol{a} = (2, -1, 3)\)，\(\boldsymbol{b} = (-4, 2, t)\)。(1) 若 \(\boldsymbol{a} \parallel \boldsymbol{b}\)，求 \(t\)；(2) 若 \(\boldsymbol{a} \perp \boldsymbol{b}\)，求 \(t\)。(3) 另有 \(\boldsymbol{c} = (1, 0, -2)\)，\(\boldsymbol{d} = (3, y, z)\)，且 \(\boldsymbol{c} \parallel \boldsymbol{d}\)，求 \(y, z\)。

解：

(1) 设 \(\boldsymbol{b} = \lambda\boldsymbol{a}\)：\(-4 = 2\lambda\)，\(2 = -\lambda\)，\(t = 3\lambda\)。前两式都给出 \(\lambda = -2\)，所以 \(t = -6\)。

(2) \(\boldsymbol{a}\cdot\boldsymbol{b} = 2\times(-4) + (-1)\times 2 + 3t = -10 + 3t = 0\)，所以 \(t = \dfrac{10}{3}\)。

(3) \(\boldsymbol{c}\) 的 \(y\) 分量是 \(0\)，不能写比例式。设 \(\boldsymbol{d} = \lambda\boldsymbol{c}\)：\(3 = \lambda\)，\(y = 0\cdot\lambda = 0\)，\(z = -2\lambda = -6\)。

自己试试：已知 \(\boldsymbol{a} = (1, 2, -1)\)，\(\boldsymbol{b} = (m, 1, 4)\)。若 \(\boldsymbol{a} \perp \boldsymbol{b}\)，则 \(m\) 等于：

C。\(\boldsymbol{a}\cdot\boldsymbol{b} = m + 2 - 4 = m - 2 = 0\)，所以 \(m = 2\)。

常见算错：A 是移项时符号弄反；D 是把 \(2\times 1\) 也当成减项，得 \(m - 6 = 0\)。也有人把垂直和平行记混，去列比例式。

6. 三步破题思维链：空间向量坐标解题标准动作

1
👀 第一眼破题信号

立体几何问题中存在显然或易证的三条两两垂直棱线（如正方体、长方体；一般棱柱或棱锥还须另证选定三线两两垂直，不能只凭几何体名称或底面直角），果断建立空间直角坐标系 \(O\text{-}xyz\)，选定原点并标明轴向与单位长。

2
🔧 第二步套公式/方法

① 写出关键点坐标，遇中点用加和除以 2；
② 终点减起点求向量坐标：\(\overrightarrow{AB} = (x_B-x_A, y_B-y_A, z_B-z_A)\)；
③ 判定垂直算数量积 \(x_1x_2+y_1y_2+z_1z_2 = 0\)；求夹角套余弦公式 \(\cos\theta = \frac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}\)；求距离套三维勾股公式。

3
🛡️ 第三步必查防坑结论

严格检查建系三轴是否两两垂直；向量坐标计算必须严格为终点减起点；判平行含 0 分量时绝不写除法比例式；异面直线夹角必取锐角或直角（\(\cos\theta \ge 0\) 取绝对值）。

翻车现场 1：终点减起点颠倒成起点减终点
❌ \(A(1,2,3), B(4,0,5)\)，误求 \(\overrightarrow{AB} = (1-4, 2-0, 3-5) = (-3, 2, -2)\)
✔ 终点减起点：\(\overrightarrow{AB} = (4-1, 0-2, 5-3) = (3, -2, 2)\)，减反方向完全相反！
翻车现场 2：未证三轴两两垂直便强行套公式

✔ 坐标公式成立的基础是单位正交基底（\(\boldsymbol{i}\cdot\boldsymbol{j}=0\)），非直角系必须走基底展开式

直接用

1. 已知空间向量 \(\boldsymbol{a} = (1, 2, -2)\)，\(\boldsymbol{b} = (-2, 0, 1)\)，则向量 \(2\boldsymbol{a} + \boldsymbol{b}\) 的模长等于：

A。先算坐标线性组合：\(2\boldsymbol{a} = (2, 4, -4)\)，\(2\boldsymbol{a} + \boldsymbol{b} = (2 + (-2), 4 + 0, -4 + 1) = (0, 4, -3)\)。再利用模长公式：\(|2\boldsymbol{a} + \boldsymbol{b}| = \sqrt{0^2 + 4^2 + (-3)^2} = \sqrt{16 + 9} = \sqrt{25} = 5\)。注意模长不能直接把各向量模长相加。

2. 已知空间两点 \(A(1, 2, 3)\)、\(B(3, -2, 1)\)，点 \(M\) 是线段 \(AB\) 的中点，则中点 \(M\) 的坐标以及线段 \(AB\) 的长度 \(|AB|\) 分别为：

A。中点坐标为各对应坐标算术平均数：\(M\left(\dfrac{1+3}{2}, \dfrac{2+(-2)}{2}, \dfrac{3+1}{2}\right) = (2, 0, 2)\)。两点间距离为两点式向量模长：\(|AB| = \sqrt{(3-1)^2 + (-2-2)^2 + (1-3)^2} = \sqrt{4 + 16 + 4} = \sqrt{24} = 2\sqrt{6}\)。

3. 【边界 5：含 0 分量共线判定】已知空间向量 \(\boldsymbol{a} = (2, 0, -4)\)，\(\boldsymbol{b} = (-1, y, z)\)。若 \(\boldsymbol{a} \parallel \boldsymbol{b}\)，则实数对 \((y, z)\) 的值为：

A。根据空间向量平行的充要条件：存在实数 \(\lambda\) 使得 \(\boldsymbol{b} = \lambda\boldsymbol{a}\)。

即 \((-1, y, z) = \lambda(2, 0, -4) \implies -1 = 2\lambda \implies \lambda = -\dfrac{1}{2}\)。

代入其余分量：\(y = -\dfrac{1}{2}\times 0 = 0\)，\(z = -\dfrac{1}{2}\times(-4) = 2\)。

警示：很多同学误以为分量含 0 时“不能平行”或“比例无意义”，其实分母为 0 只是提醒我们不能写成坐标相除，而必须严格用数乘方程 \(\boldsymbol{b}=\lambda\boldsymbol{a}\) 求解！

4. 【边界 1：直角坐标轴必须正交】在空间几何体中建立空间直角坐标系，下列选轴做法中合规且正确的是：

C。空间直角坐标系必须依赖「单位正交基底」（三条坐标轴必须两两垂直）。

长方体从同一顶点出发的三条棱两两互相垂直，符合建系条件；而正三棱柱底面是正三角形，\(\angle BAC = 60^\circ \ne 90^\circ\)；正四面体各面都是等边三角形，侧棱两两夹角也为 \(60^\circ\)；斜四棱柱的棱更不是直角。绝不能随意把斜棱当作坐标轴，建系前必须先证明轴的两两垂直！

5. 【边界 2：终点减起点与垂直判定】已知空间三点 \(A(1, 0, 2)\)、\(B(2, 1, 3)\)、\(C(x, 2, 1)\)。若向量 \(\overrightarrow{AB} \perp \overrightarrow{AC}\)，则实数 \(x\) 的值为：

A。两点式向量必须用「终点坐标减去起点坐标」：

\(\overrightarrow{AB} = (2-1, 1-0, 3-2) = (1, 1, 1)\)；

\(\overrightarrow{AC} = (x-1, 2-0, 1-2) = (x-1, 2, -1)\)。

两非零向量垂直充要条件是数量积为 0：

\(\overrightarrow{AB}\cdot\overrightarrow{AC} = 1\times(x-1) + 1\times 2 + 1\times(-1) = x - 1 + 2 - 1 = x = 0\)。

本题把某个向量反向只会让整个数量积变号，不改变“数量积为0”的条件，因此仍得x=0。向量坐标应按终点减起点；若只把部分分量符号改错或把常数项加错，才会改变方程。

挑战

6. 已知非零向量 \(\boldsymbol{a} = (1, 1, 0)\)，\(\boldsymbol{b} = (0, 1, 1)\)。若空间非零向量 \(\boldsymbol{n} = (x, y, 1)\) 同时垂直于 \(\boldsymbol{a}\) 和 \(\boldsymbol{b}\)，则向量 \(\boldsymbol{n}\) 的模长 \(|\boldsymbol{n}|\) 等于：

A。这正是立体几何中求「平面法向量」的经典代数方程组：

\(\boldsymbol{n}\perp\boldsymbol{a} \iff x\times 1 + y\times 1 + 1\times 0 = 0 \implies x + y = 0\)；

\(\boldsymbol{n}\perp\boldsymbol{b} \iff x\times 0 + y\times 1 + 1\times 1 = 0 \implies y + 1 = 0 \implies y = -1\)。

解得 \(y = -1\)，代入得 \(x = -y = 1\)。因此公垂向量为 \(\boldsymbol{n} = (1, -1, 1)\)。

其模长为 \(|\boldsymbol{n}| = \sqrt{1^2 + (-1)^2 + 1^2} = \sqrt{3}\)。
