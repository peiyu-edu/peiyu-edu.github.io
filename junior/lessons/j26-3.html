26.3 二次函数与一元二次方程

数与形的巅峰融合！令函数值 \(y = 0\)，平面抛物线与 \(x\) 轴的交点瞬间降维为一维数轴上的方程实数根。看透判别式 \(\Delta\) 的几何裁决、领悟二分法逐步逼近无理根，借助图象直观秒解二次不等式。

本节导读　先修：25.2 根的判别式 · 26.2 抛物线图象 · 本节路线

要用到：一元二次方程求根公式与判别式（回看 25.2）、二次函数的顶点与对称轴（回看 26.2）。

  1. 从喷泉水流触地切入：水流落回地面时的高度是多少？令 \(y=0\) 转化为方程。
  2. 确立核心等价性：抛物线与 \(x\) 轴公共点的横坐标 = 对应一元二次方程的实数根。
  3. 判别式 \(\Delta\) 的几何裁决：两交点（\(\Delta \gt 0\)）、一个切点（\(\Delta = 0\)）、无交点（\(\Delta \lt 0\)）。
  4. 掌握二分法求近似根：用逐步对半夹逼逼近无理根的现代计算思维。
  5. 数形结合解二次不等式：看上方取区间还是看下方取两边。
  6. 动手实验与巩固练习，全面贯通方程与函数的双向转换。

公园喷水池喷出的水流沿抛物线运行，水流高度 \(y\text{ (m)}\) 与喷出水平距离 \(x\text{ (m)}\) 的关系式为 \(y = -x^2 + 4x\)（\(x \ge 0\)）。我们想知道水流在多远处落回水面？

水流落回水面时，高度 \(y = 0\)。将 \(y = 0\) 代入函数表达式，得到方程 \(-x^2 + 4x = 0\)。解这个一元二次方程，水流落回水面的水平距离 \(x\) 是多少米？

C。解方程：\(-x(x - 4) = 0 \implies x_1 = 0, x_2 = 4\)。\(x = 0\) 是喷水初发点，\(x = 4\) 是水流落回水面点，距离为 \(4\text{ m}\)。

这个事实揭示了数学中极其深刻的规律：抛物线与 \(x\) 轴交点的横坐标，正好就是令 \(y=0\) 得到的一元二次方程的实数根！

1. 先认识几个词：交点横坐标、零点与判别式判据

将几何图象与代数方程联通，牢记以下三个核心概念：

  • 函数的零点（交点横坐标）：使函数值 \(y = 0\) 的自变量 \(x\) 的值。在图象上，就是抛物线与 \(x\) 轴公共点的横坐标。
  • 判别式 \(\Delta = b^2 - 4ac\) 的几何高度：判别式决定了抛物线顶点相对于 \(x\) 轴的高低位置，从而绝对主宰交点个数。
  • 二分法（bisection method）：在连续函数图象穿过 \(x\) 轴的异号区间内，通过不断取中点对半分割、缩小区间，从而求得方程近似根的数值算法。

直觉微图解 ①降维投影：二维曲线交点与一维方程实数根的完全同构

核心定理：二次函数 \(y = ax^2 + bx + c\) 的图象与 \(x\) 轴公共点的横坐标，就是一元二次方程 \(ax^2 + bx + c = 0\) 的实数根。

4. 自己试试与典例示范

【自测 1】抛物线 \(y = x^2 - 4x + 4\) 与 \(x\) 轴的公共点个数是（ ）

A。计算判别式：\(\Delta = b^2 - 4ac = (-4)^2 - 4(1)(4) = 16 - 16 = 0\)。\(\Delta = 0\)，方程有两个相等的实数根，抛物线与 \(x\) 轴只有 1 个公共点（即顶点 \((2, 0)\)），抛物线与 \(x\) 轴相切。

【自测 2】二次函数 \(y = x^2 - 2x - 8\) 的图象与 \(x\) 轴的交点坐标是（ ）

C。令 \(y = 0\)，得 \(x^2 - 2x - 8 = 0 \implies (x-4)(x+2) = 0 \implies x_1 = 4, x_2 = -2\)。交点在 \(x\) 轴上，纵坐标必须为 0，坐标是 \((4, 0)\) 与 \((-2, 0)\)。选 D 是误求了与 \(y\) 轴的交点。

【自测 3】已知抛物线 \(y = ax^2 + bx + c\) 开口向上，与 \(x\) 轴交于 \((-1, 0)\) 和 \((3, 0)\)，则不等式 \(ax^2 + bx + c \lt 0\) 的解集为（ ）

B。抛物线开口向上，位于两交点之间的部分处于 \(x\) 轴的下方，对应函数值 \(y \lt 0\)。因此解集为 \(-1 \lt x \lt 3\)。若求 \(y \gt 0\)，则取两侧 \(x \lt -1\) 或 \(x \gt 3\)。

【例题 1·波利亚示范】根据交点求方程根与对称轴

题目：已知二次函数 \(y = ax^2 + bx + c\) 的图象与 \(x\) 轴交于点 \(A(-2, 0)\)，\(B(6, 0)\)。
(1) 写出方程 \(ax^2 + bx + c = 0\) 的根；
(2) 求抛物线的对称轴。

规范解答：
(1) 抛物线与 \(x\) 轴交点的横坐标就是方程的实数根，因此方程的解为 \(x_1 = -2, x_2 = 6\)。
(2) 抛物线上的交点 \(A, B\) 关于对称轴对称，对称轴为线段 \(AB\) 的中垂线：
\(x = \dfrac{x_1 + x_2}{2} = \dfrac{-2 + 6}{2} = 2\)。
∴ 抛物线的对称轴为直线 \(x = 2\)。

【例题 2·波利亚示范】由交点情况求参数范围（判别式法）

题目：若二次函数 \(y = x^2 - 4x + k\) 的图象与 \(x\) 轴有两个不同的公共点，求 \(k\) 的取值范围。

规范解答：
令 \(y = 0\)，得到一元二次方程 \(x^2 - 4x + k = 0\)。
因为抛物线与 \(x\) 轴有两个不同的公共点，所以对应方程有两个不相等的实数根，必须满足判别式 \(\Delta \gt 0\)：
\(\Delta = (-4)^2 - 4 \times 1 \times k = 16 - 4k \gt 0 \implies 4k \lt 16 \implies k \lt 4\)。
∴ 常数 \(k\) 的取值范围为 \(k \lt 4\)。

【例题 3·波利亚示范】图象法求解一元二次不等式

题目：画出函数 \(y = -x^2 + 2x + 3\) 的简图，并结合图象写出当 \(x\) 取何值时，\(-x^2 + 2x + 3 \ge 0\)。

解答思路：
① 令 \(y = 0\)，\(-x^2 + 2x + 3 = 0 \implies x^2 - 2x - 3 = 0 \implies (x-3)(x+1) = 0\)，交点为 \((-1, 0)\) 和 \((3, 0)\)。
② \(a = -1 \lt 0\)，开口向下，顶点最高在上方。
③ 要求 \(y \ge 0\)，即图象位于 \(x\) 轴上方或刚好在 \(x\) 轴上的部分。
由图象直观可得：自变量取值范围为 \(-1 \le x \le 3\)。

【例题 4·波利亚示范】二分法求一元二次方程无理近似根

题目：求方程 \(x^2 - 2x - 1 = 0\) 在区间 \([2, 3]\) 内的正近似根（精确到 0.1）。

二分法四步拆解：设 \(f(x) = x^2 - 2x - 1\)。
① \(f(2) = 4 - 4 - 1 = -1 \lt 0\)；\(f(3) = 9 - 6 - 1 = 2 \gt 0\)。两端异号，说明根在 \([2, 3]\) 内。
② 取中点 \(x_1 = 2.5\)，\(f(2.5) = 6.25 - 5 - 1 = 0.25 \gt 0\)。根落在 \([2, 2.5]\) 内。
③ 再取中点 \(x_2 = 2.25\)，\(f(2.25) = 5.0625 - 4.5 - 1 = -0.4375 \lt 0\)。根落在 \([2.25, 2.5]\) 内。
④ 类似继续逼近可得近似根约为 \(2.4\)（精确根为 \(1+\sqrt{2} \approx 2.414\)）。体会区间不断减半逼近的数学思想！

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）把“交点”和“方程的根”混为一谈
❌ 典型错解：“抛物线 \(y=x^2-2x-3\) 与 \(x\) 轴的交点是 \(-1\) 和 \(3\)”。
✅ 看图秒懂：交点是平面上的点，要写坐标 \((-1,0)\)、\((3,0)\)；方程 \(x^2-2x-3=0\) 的根才是数：\(x=-1\) 或 \(x=3\)。
翻车现场 ②解“大于 0”还是“小于 0”，取区间看错开口
❌ 典型错解：“\(x^2-2x-3 \gt 0\) 的解集是 \(-1 \lt x \lt 3\)”。
✅ 一眼看清：\(a=1 \gt 0\)，开口向上，两根 \(-1,3\) 之间的图象在 \(x\) 轴下方。要 \(y \gt 0\)，取两边：\(x \lt -1\) 或 \(x \gt 3\)。验算：\(x=0\) 时 \(y=-3\)，不满足 \(\gt 0\)，所以 \(0\) 不在解集里。
翻车现场 ③“没有交点”当成“函数没有值”
❌ 典型错解：“\(y=x^2+1\) 与 \(x\) 轴没有交点，所以 \(x\) 取什么都算不出 \(y\)”。
✅ 一眼看清：每个 \(x\) 都能算出 \(y\)（如 \(x=0\) 时 \(y=1\)）；“没有交点”只说明 \(y\) 永远不等于 \(0\)——整条抛物线都悬在 \(x\) 轴上方，方程 \(x^2+1=0\) 没有实数根。
再深一点（可以先跳过）：两根之和为什么就是对称轴的 2 倍？

交点 \((x_1,0),(x_2,0)\) 关于对称轴对称，所以对称轴 \(x=\dfrac{x_1+x_2}{2}\)。也就是说，只要知道两个交点，对称轴不用公式就能一眼写出；反过来，知道对称轴和一个交点，另一个交点的横坐标就是 \(2\times\text{对称轴}-x_1\)。

【巩固 1】已知二次函数 \(y = x^2 - 2x + m\) 的图象与 \(x\) 轴有两个交点，则 \(m\) 的取值范围是（ ）

B。两个不同交点对应方程有两个不相等实数根，必须满足 \(\Delta = (-2)^2 - 4(1)(m) = 4 - 4m \gt 0 \implies m \lt 1\)。不带等号！

【巩固 2】抛物线 \(y = ax^2 + bx + c\) 与 \(x\) 轴的两个交点坐标为 \((-2, 0)\) 和 \((4, 0)\)，则一元二次方程 \(ax^2 + bx + c = 0\) 的解是（ ）

C。抛物线与 \(x\) 轴交点的横坐标直接就是方程的两个根，即 \(x_1 = -2, x_2 = 4\)。

【巩固 3·易错题】二次函数 \(y = -x^2 + 4x - 3\) 的图象在 \(x\) 轴上方的部分对应的自变量 \(x\) 的取值范围是（ ）

提示

令 y = 0 解方程求两根，开口向下，图象在上方对应函数值 y > 0。

A。解方程 \(-x^2 + 4x - 3 = 0 \implies x^2 - 4x + 3 = 0 \implies (x-1)(x-3)=0\)，两交点为 1 和 3。开口向下，在 \(x\) 轴上方的部分在两根之间，且不含交点本身（\(y \gt 0\)），故解集为 \(1 \lt x \lt 3\)。

【巩固 4·挑战题】若关于 \(x\) 的一元二次方程 \(x^2 - 2x + k = 0\) 没有实数根，则二次函数 \(y = x^2 - 2x + k\) 的图象位于（ ）

提示

方程无实根说明抛物线与 x 轴无交点，再看开口方向向上。

D。方程无实根说明抛物线与 \(x\) 轴没有公共点；二次项系数 \(a = 1 \gt 0\)，抛物线开口向上，因此整个抛物线必须完全悬浮在 \(x\) 轴上方。

【易错挑战】交点距离与韦达定理的综合变形

题目：抛物线 \(y = x^2 - (m+2)x + 2m\) 与 \(x\) 轴交于点 \(A(x_1, 0)\)，\(B(x_2, 0)\)。若 \(AB = 3\)，求 \(m\) 的值。

正解剖析：令 \(y = 0\)，得 \(x^2 - (m+2)x + 2m = 0\)。因式分解得 \((x-m)(x-2) = 0 \implies x_1 = m, x_2 = 2\)。
两点间距离为 \(AB = |x_1 - x_2| = |m - 2| = 3\)。
解绝对值方程：\(m - 2 = 3 \implies m = 5\)；或 \(m - 2 = -3 \implies m = -1\)。
很多同学常漏掉绝对值只算得 \(m = 5\)，牢记距离必须带绝对值！

巩固练习 1：若二次函数 \(y=x^2-4x+c\) 的图象与 \(x\) 轴有交点，则常数 \(c\) 的取值范围是 ______。

查看答案与解析，自行核对

答案：\(c\le4\)

图象与 \(x\) 轴有交点，等价于方程 \(x^2-4x+c=0\) 有实数根，\(\Delta=16-4c\ge0\)，得 \(c\le4\)。

巩固练习 2：在平面直角坐标系中，将二次函数 \(y=5(x-1)^2\) 的图象向下平移 \(5\) 个单位长度，所得抛物线与 \(x\) 轴有两个公共点 \(P,Q\)，则线段 \(PQ\) 的长为 ______。

查看答案与解析，自行核对

答案：\(2\)

平移后 \(y=5(x-1)^2-5\)，令 \(y=0\)：\((x-1)^2=1\)，\(x=0\) 或 \(x=2\)，\(P,Q\) 的横坐标为 \(0,2\)，\(PQ=2\)。

巩固练习 3：已知二次函数 \(y=ax^2+bx+c\)（\(a>0\)）的图象与 \(x\) 轴交于 \(A(-1,0)\)，\(B(3,0)\) 两点，则下列说法正确的是（ ）

A。交点横坐标就是方程的根，A 正确；对称轴 \(x=\dfrac{-1+3}{2}=1\)，B 错；\(a>0\) 时开口向上，\(x=0\) 在两根之间，图象在 \(x\) 轴下方，\(y<0\)，C 错；\(x>3\) 在对称轴右侧，\(y\) 随 \(x\) 增大而增大，D 错。选 A。

巩固练习 4：已知二次函数 \(y=ax^2+bx+c\)（\(a\ne0\)）的图象开口向下，与 \(x\) 轴的一个交点坐标为 \((-1,0)\)，对称轴为直线 \(x=1\)。则不等式 \(ax^2+bx+c>0\) 的解集为（ ）

B。由对称性，另一交点为 \((3,0)\)。开口向下，图象在两交点之间位于 \(x\) 轴上方，所以 \(y>0\) 的解集为 \(-1<x<3\)。选 B。
