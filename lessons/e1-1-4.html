1.4 空间向量的应用

将立体图形放置在空间直角坐标系中，平行与垂直被转化为向量的共线与数量积，点到平面的距离化为投影向量的模长，空间三大夹角更可通过法向量与方向向量的代数运算直接求解，免去繁杂的辅助线构造。

在立体几何综合大题中，求「点 \(P\) 到平面 \(\alpha\) 的距离」是一道常见压轴问。在传统综合几何法中，求点面距离必须先在平面内准确找出点 \(P\) 的垂足 \(H\)，常常需要复杂的线面垂直证明和繁琐的几何作图。

如果引入空间向量坐标法，并求得了平面 \(\alpha\) 的一个法向量 \(\boldsymbol{n}\)，我们还需要在图中费劲寻找垂足 \(H\) 的确切空间位置吗？

选 B。这就是空间向量法最强大的地方：免去作垂线与找垂足！

无论垂足 \(H\) 落在平面的哪个角落甚至图形外部，在法向量 \(\boldsymbol{n}\) 的指引下，平面内任意一点 \(A\) 与 \(P\) 构成的斜向量 \(\overrightarrow{AP}\)，在法向量上的投影长度恰好恒等于垂线段的长度 \(d\)。

几何的辅助线构图被彻底转化为向量数量积的代数运算。这一节我们就来系统掌握空间向量在平行与垂直判定、空间距离以及三大夹角（线线角、线面角、二面角）计算中的核心公式与解题程序。

1. 先认识几个词

要用到：空间向量的坐标运算、数量积、模长、夹角（回看 1.3）。

直线的方向向量：和直线平行（或就在直线上）的非零向量 \(\boldsymbol{u}\)。一条直线的方向向量有无数个，彼此共线。

例：直线过 \(P(1,0,0)\) 和 \(Q(3,1,2)\)，\(\overrightarrow{PQ}=(2,1,2)\) 是它的一个方向向量；\((4,2,4)\)、\((-2,-1,-2)\) 也是。

平面的法向量：和平面垂直的非零向量 \(\boldsymbol{n}\)。平面里的任何向量 \(\boldsymbol{v}\) 都满足 \(\boldsymbol{n}\cdot\boldsymbol{v}=0\)。一个点加一个法向量，就定下一个平面。

例：\(xOy\) 平面的一个法向量是 \((0,0,1)\)。面里的向量 \((3,5,0)\)：\((3,5,0)\cdot(0,0,1)=0\)，确实垂直。

投影长度：向量 \(\boldsymbol{a}\) 在 \(\boldsymbol{n}\) 方向上「影子」的长，等于 \(\dfrac{|\boldsymbol{a}\cdot\boldsymbol{n}|}{|\boldsymbol{n}|}\)。

例：\(\boldsymbol{a}=(1,2,2)\)，\(\boldsymbol{n}=(0,0,1)\)，投影长度 \(\dfrac{|2|}{1}=2\)，正好是 \(\boldsymbol{a}\) 的「竖直高度」。

向量夹角和几何角不是一回事：两个向量的夹角在 \([0^\circ,180^\circ]\)；两条直线所成的角只取不大于 \(90^\circ\) 的那个。

例：\(\boldsymbol{u}=(1,0,0)\)，\(\boldsymbol{v}=(-1,1,0)\)，向量夹角是 \(135^\circ\)；但以它们为方向的两条直线所成角是 \(45^\circ\)。所以后面的公式里常有绝对值。

下面四块都用同一个正方体举例：棱长为 \(2\) 的正方体 \(ABCD-A_1B_1C_1D_1\)，以 \(D\) 为原点，\(DA, DC, DD_1\) 分别为 \(x, y, z\) 轴。各点坐标：

\(D(0,0,0)\)，\(A(2,0,0)\)，\(B(2,2,0)\)，\(C(0,2,0)\)，
\(A_1(2,0,2)\)，\(B_1(2,2,2)\)，\(C_1(0,2,2)\)。

2. 求平面的法向量

法向量要和平面里每一个向量垂直。只要和面里两个不共线的向量都垂直就够了（两条相交直线定下一个平面）。于是设 \(\boldsymbol{n}=(x,y,z)\)，列两个数量积为 \(0\) 的方程。两个方程三个未知数，解出来是一串成比例的解，取其中一个非零的就行。

面内取两个不共线向量 \(\boldsymbol{v}_1,\boldsymbol{v}_2\)：\(\begin{cases}\boldsymbol{n}\cdot\boldsymbol{v}_1=0\\ \boldsymbol{n}\cdot\boldsymbol{v}_2=0\end{cases}\)，取一个非零解。

例 1（看一遍怎么写）

求平面 \(A_1BD\) 的一个法向量。

\(\overrightarrow{DA_1}=(2,0,2)\)，\(\overrightarrow{DB}=(2,2,0)\)，两者不共线。设 \(\boldsymbol{n}=(x,y,z)\)：

\[\begin{cases}\boldsymbol{n}\cdot\overrightarrow{DA_1}=2x+2z=0\\ \boldsymbol{n}\cdot\overrightarrow{DB}=2x+2y=0\end{cases}\]

得 \(z=-x\)，\(y=-x\)。令 \(x=1\)（方程没逼 \(x=0\)，可以这么取），得 \(\boldsymbol{n}=(1,-1,-1)\)，\(|\boldsymbol{n}|=\sqrt3\)。

验算：\((1,-1,-1)\cdot(2,0,2)=0\)，\((1,-1,-1)\cdot(2,2,0)=0\)。✓

自己试试：平面内有两个向量 \(\boldsymbol{v}_1=(1,1,0)\)，\(\boldsymbol{v}_2=(0,1,1)\)。下面哪个是这个平面的法向量？

A。\(x+y=0\)，\(y+z=0\)。令 \(x=1\)，得 \(y=-1\)，\(z=1\)。

C 只和 \(\boldsymbol{v}_1\) 垂直（\(-1+1+0=0\)），和 \(\boldsymbol{v}_2\) 的数量积是 \(2\)：只验了一个方程就收手，是最常见的错。D 虽然满足两个方程，但法向量必须非零。

3. 用向量证平行与垂直

直线看方向向量 \(\boldsymbol{u}\)，平面看法向量 \(\boldsymbol{n}\)。「平行、垂直」就翻译成「共线、数量积为 \(0\)」：

线线平行：\(\boldsymbol{u}_1=\lambda\boldsymbol{u}_2\)；线线垂直：\(\boldsymbol{u}_1\cdot\boldsymbol{u}_2=0\)。
线面平行：\(\boldsymbol{u}\cdot\boldsymbol{n}=0\)，且直线不在面内；
线面垂直：\(\boldsymbol{u}=\lambda\boldsymbol{n}\)。
面面平行：\(\boldsymbol{n}_1=\lambda\boldsymbol{n}_2\)（且不重合）；面面垂直：\(\boldsymbol{n}_1\cdot\boldsymbol{n}_2=0\)。

为什么线面平行是「数量积为 \(0\)」、线面垂直反而是「共线」？法向量本身就垂直于平面：直线和法向量垂直，就躺在平面的方向上；直线和法向量同向，就竖着穿过平面。

例 2

接例 1，平面 \(A_1BD\) 的法向量 \(\boldsymbol{n}=(1,-1,-1)\)。证明：(1) \(CB_1\parallel\) 平面 \(A_1BD\)；(2) \(AC_1\perp\) 平面 \(A_1BD\)。

(1) \(\overrightarrow{CB_1}=(2,0,2)\)，\(\overrightarrow{CB_1}\cdot\boldsymbol{n}=2+0-2=0\)，所以 \(CB_1\) 和平面平行或在面内。再看点 \(C\)：\(\overrightarrow{DC}=(0,2,0)\)，\(\overrightarrow{DC}\cdot\boldsymbol{n}=-2\ne0\)，\(C\) 不在平面里。所以 \(CB_1\parallel\) 平面 \(A_1BD\)。

(2) \(\overrightarrow{AC_1}=(-2,2,2)=-2(1,-1,-1)=-2\boldsymbol{n}\)，方向向量和法向量共线，所以 \(AC_1\perp\) 平面 \(A_1BD\)。

自己试试：直线 \(l\) 的方向向量 \(\boldsymbol{u}=(2,-4,2)\)，平面 \(\alpha\) 的法向量 \(\boldsymbol{n}=(1,-2,1)\)。\(l\) 与 \(\alpha\) 的关系是？

B。\(\boldsymbol{u}=2\boldsymbol{n}\)，方向向量和法向量共线，直线垂直于平面。

选 A 的同学看到「两个向量平行」就写「线面平行」——可这里一个是法向量，和法向量平行恰好是垂直。线面平行要的是 \(\boldsymbol{u}\cdot\boldsymbol{n}=0\)，这里 \(\boldsymbol{u}\cdot\boldsymbol{n}=2+8+2=12\)。

4. 求点到平面的距离

不用找垂足。在平面里随便取一点 \(A\)，连出 \(\overrightarrow{AP}\)。垂线段 \(PH\) 和法向量同方向，所以 \(\overrightarrow{AP}\) 在 \(\boldsymbol{n}\) 方向上的投影长度就是 \(|PH|\)。

\[d=\frac{|\overrightarrow{AP}\cdot\boldsymbol{n}|}{|\boldsymbol{n}|}\]分子的绝对值不能漏：数量积可能是负的，距离不会。

例 3

求点 \(C_1\) 到平面 \(A_1BD\) 的距离。

面内取 \(D\)，\(\overrightarrow{DC_1}=(0,2,2)\)，\(\overrightarrow{DC_1}\cdot\boldsymbol{n}=0-2-2=-4\)。

\[d=\frac{|-4|}{\sqrt3}=\frac{4\sqrt3}{3}\]

换成面内的 \(B\) 来算：\(\overrightarrow{BC_1}=(-2,0,2)\)，\(\overrightarrow{BC_1}\cdot\boldsymbol{n}=-2-2=-4\)，结果一样。

自己试试：平面 \(\alpha\) 过点 \(A(1,0,0)\)，法向量 \(\boldsymbol{n}=(2,-1,2)\)。点 \(P(0,3,0)\) 到 \(\alpha\) 的距离是？

A。\(\overrightarrow{AP}=(-1,3,0)\)，\(\overrightarrow{AP}\cdot\boldsymbol{n}=-2-3+0=-5\)，\(|\boldsymbol{n}|=\sqrt{4+1+4}=3\)，\(d=\dfrac{|-5|}{3}=\dfrac53\)。

B 漏了绝对值；C 忘了除以 \(|\boldsymbol{n}|\)（\(\boldsymbol{n}\) 不是单位向量）；D 除成了 \(|\boldsymbol{n}|^2\)。

5. 求角：线线角、线面角、二面角

三种角都先算一个向量夹角的余弦 \(\dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}\)，再翻译回要的几何角。翻译各不相同：

  • 线线角 \(\theta\in(0^\circ,90^\circ]\)：直线所成角不超过 \(90^\circ\)，加绝对值： \[\cos\theta=\frac{|\boldsymbol{u}\cdot\boldsymbol{v}|}{|\boldsymbol{u}||\boldsymbol{v}|}\]
  • 线面角 \(\theta\in[0^\circ,90^\circ]\)：法向量和平面垂直，直线与法向量所成的（锐）角和线面角加起来是 \(90^\circ\)，所以算出来的是正弦： \[\sin\theta=\frac{|\boldsymbol{u}\cdot\boldsymbol{n}|}{|\boldsymbol{u}||\boldsymbol{n}|}\]
  • 二面角 \(\theta\in[0^\circ,180^\circ]\)：它和两个法向量的夹角相等或互补，可能是钝角。先算 \(\cos\langle\boldsymbol{n}_1,\boldsymbol{n}_2\rangle\)，再看图判断二面角是锐角还是钝角，定正负号。
    若题目问的是「两平面的夹角」，按定义取不大于 \(90^\circ\) 的那个，才直接加绝对值。

例 4

接例 1，\(E(2,1,2)\) 是棱 \(A_1B_1\) 的中点。求：(1) 直线 \(DE\) 与 \(A_1B\) 所成角的余弦；(2) 直线 \(DE\) 与平面 \(A_1BD\) 所成角的正弦；(3) 二面角 \(A_1-BD-C\) 的余弦。

(1) \(\overrightarrow{DE}=(2,1,2)\)，\(|\overrightarrow{DE}|=3\)；\(\overrightarrow{A_1B}=(0,2,-2)\)，\(|\overrightarrow{A_1B}|=2\sqrt2\)。\(\overrightarrow{DE}\cdot\overrightarrow{A_1B}=0+2-4=-2\)。

\[\cos\theta=\frac{|-2|}{3\times2\sqrt2}=\frac{\sqrt2}{6}\]

(2) \(\overrightarrow{DE}\cdot\boldsymbol{n}=2-1-2=-1\)。

\[\sin\theta=\frac{|-1|}{3\times\sqrt3}=\frac{\sqrt3}{9}\]

(3) 平面 \(BDC\) 就是底面，法向量取 \(\boldsymbol{n}_0=(0,0,1)\)。\(\boldsymbol{n}\cdot\boldsymbol{n}_0=-1\)，

\[\cos\langle\boldsymbol{n},\boldsymbol{n}_0\rangle=\frac{-1}{\sqrt3\times1}=-\frac{\sqrt3}{3}\]

定正负：\(A_1\) 在 \(A\) 的正上方，\(A\) 和 \(C\) 在 \(BD\) 两侧。半平面 \(A_1BD\) 斜着「靠向」\(A\) 那一侧，和 \(C\) 那一侧的底面张开的角大于 \(90^\circ\)，是钝二面角。所以 \(\cos\theta=-\dfrac{\sqrt3}{3}\)。

若问的是二面角 \(A_1-BD-A\)，就是锐角，余弦为 \(\dfrac{\sqrt3}{3}\)。同一组法向量，问哪个二面角，答案的符号不同。

自己试试：直线 \(l\) 的方向向量 \(\boldsymbol{u}\) 与平面 \(\alpha\) 的法向量 \(\boldsymbol{n}\) 的夹角为 \(30^\circ\)。\(l\) 与 \(\alpha\) 所成的角是？

B。法向量垂直于平面，直线和法向量的夹角与线面角互余：\(90^\circ-30^\circ=60^\circ\)。用公式也一样：\(\sin\theta=|\cos30^\circ|=\dfrac{\sqrt3}{2}\)，\(\theta=60^\circ\)。

选 A 的同学把「和法向量的夹角」直接当成了线面角，也就是把公式里的 \(\sin\) 当成了 \(\cos\)。线面角不超过 \(90^\circ\)，C、D 不可能。

6. 用之前要注意

  1. 法向量要非零，「令某分量为 1」要看方程允不允许。
    反例：面内向量 \((1,0,0)\) 和 \((0,1,2)\)，第一个方程就是 \(x=0\)。这时再「令 \(x=1\)」就矛盾了；应令 \(z=1\)，得 \(\boldsymbol{n}=(0,-2,1)\)。
  2. \(\boldsymbol{u}\cdot\boldsymbol{n}=0\) 只说明「平行或在面内」；方向向量共线只说明「平行或重合」；法向量共线也要区分两平面平行还是重合。
    反例：平面 \(z=0\)，法向量 \((0,0,1)\)；直线过 \((0,0,0)\)，方向 \((1,0,0)\)。数量积为 \(0\)，可这条直线就是 \(x\) 轴，躺在平面里。要再验一点在不在面内。
  3. 距离公式分子带绝对值；相交的两个对象距离是 \(0\)。
    反例：直线和平面相交时，在直线上随便取一点代入点面距离公式，一般会得到一个正数，可二者的距离是 \(0\)。「任取一点」的算法只对平行的线面、面面成立，先确认平行。
  4. 二面角可能是钝角，不能一律加绝对值。
    反例：例 4 的二面角 \(A_1-BD-C\)，加了绝对值就会写成 \(\dfrac{\sqrt3}{3}\)，而它其实是钝角，余弦为 \(-\dfrac{\sqrt3}{3}\)。
再深一点（可以先跳过）

用法向量的朝向定二面角正负：两个法向量都从棱出发画。若两个都指向二面角内部（或都指向外部），法向量夹角与二面角互补；若一个指向内部、一个指向外部，二者相等。最后仍要和图上看到的张口大小对一下。

点到直线的距离：\(A\) 在直线 \(l\) 上，\(\boldsymbol{e}\) 是 \(l\) 的单位方向向量，则

\[d=\sqrt{|\overrightarrow{AP}|^2-(\overrightarrow{AP}\cdot\boldsymbol{e})^2}\]

这是勾股定理：\(|\overrightarrow{AP}|\) 是斜边，\(|\overrightarrow{AP}\cdot\boldsymbol{e}|\) 是沿直线方向的那条直角边，剩下的直角边就是距离。

直接用

1. 在棱长为 1 的正方体 \(ABCD-A_1B_1C_1D_1\) 中，以 \(D\) 为坐标原点建立空间直角坐标系，平面 \(A_1BD\) 的一个法向量为 \(\boldsymbol{n} = (1, -1, -1)\)。则点 \(C_1(1, 1, 1)\) 到平面 \(A_1BD\) 的距离 \(d\) 为：

选 A。平面 \(A_1BD\) 经过点 \(D(0, 0, 0)\)，则 \(\overrightarrow{DC_1} = (1, 1, 1)\)。

计算数量积：\(\overrightarrow{DC_1}\cdot\boldsymbol{n} = 1\times 1 + 1\times(-1) + 1\times(-1) = -1\)。

法向量模长：\(|\boldsymbol{n}| = \sqrt{1^2 + (-1)^2 + (-1)^2} = \sqrt{3}\)。

套用点面距离公式：\(d = \dfrac{|\overrightarrow{DC_1}\cdot\boldsymbol{n}|}{|\boldsymbol{n}|} = \dfrac{|-1|}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}\)。

2. 已知直线 \(l\) 的方向向量为 \(\boldsymbol{u} = (0, 1, 1)\)，平面 \(\alpha\) 的法向量为 \(\boldsymbol{n} = (1, 1, 0)\)。则直线 \(l\) 与平面 \(\alpha\) 所成角 \(\theta\) 的大小为：

选 B。套用线面角正弦公式：

\(\boldsymbol{u}\cdot\boldsymbol{n} = 0\times 1 + 1\times 1 + 1\times 0 = 1\)。

\(|\boldsymbol{u}| = \sqrt{0^2 + 1^2 + 1^2} = \sqrt{2}\)，\(|\boldsymbol{n}| = \sqrt{1^2 + 1^2 + 0^2} = \sqrt{2}\)。

因此 \(\sin\theta = \dfrac{|\boldsymbol{u}\cdot\boldsymbol{n}|}{|\boldsymbol{u}||\boldsymbol{n}|} = \dfrac{1}{\sqrt{2}\times\sqrt{2}} = \dfrac{1}{2}\)。

因线面角 \(\theta \in [0, 90^\circ]\)，所以 \(\theta = 30^\circ\)。千万不要误将结果当作 \(\cos\theta = \dfrac{1}{2}\) 而误选 \(60^\circ\)！

易错

3. 某几何体中，观察直观图可知二面角 \(\alpha-l-\beta\) 是一个钝二面角。若求得平面 \(\alpha\) 的法向量为 \(\boldsymbol{n}_1 = (1, 2, 2)\)，平面 \(\beta\) 的法向量为 \(\boldsymbol{n}_2 = (2, -1, 2)\)，则该二面角的余弦值 \(\cos\theta\) 为：

选 C。高频命题陷阱！绝不能机械取绝对值！

计算法向量夹角余弦值：

\(\boldsymbol{n}_1\cdot\boldsymbol{n}_2 = 1\times 2 + 2\times(-1) + 2\times 2 = 2 - 2 + 4 = 4\)。

\(|\boldsymbol{n}_1| = \sqrt{1+4+4} = 3\)，\(|\boldsymbol{n}_2| = \sqrt{4+1+4} = 3\)。

\(\cos\langle\boldsymbol{n}_1,\boldsymbol{n}_2\rangle = \dfrac{4}{3\times 3} = \dfrac{4}{9}\)。

因为题目已明确指明该二面角为钝二面角，其余弦值必为负值！故 \(\cos\theta = -\dfrac{4}{9}\)。若盲目填 \(\dfrac{4}{9}\)，则直接把钝角误判为锐角。

4. 在空间直角坐标系中求平面 \(\alpha\) 的法向量 \(\boldsymbol{n} = (x, y, z)\)，已知平面内有两个不共线向量 \(\boldsymbol{a} = (1, 0, 0)\) 和 \(\boldsymbol{b} = (0, 1, 2)\)。某同学解方程组时直接写“令 \(x = 1\)”，这种解法的问题在于：

选 D。专题卡 E1-01-B 严格明确：某一分量可否设为 1 由方程决定，不能无条件指定！

由 \(\boldsymbol{n}\cdot\boldsymbol{a} = 1\cdot x + 0\cdot y + 0\cdot z = 0 \implies x = 0\)。

此平面的法向量在 \(x\) 轴上的分量必须严格等于 0！若盲目强行令 \(x = 1\)，立刻出现 \(1 = 0\) 的逻辑矛盾。正确做法是令 \(z = 1\)，由 \(\boldsymbol{n}\cdot\boldsymbol{b} = y + 2z = 0\) 解得 \(y = -2\)，得到法向量 \(\boldsymbol{n} = (0, -2, 1)\)。

5. 点 \(P(0, 0, 2)\)，平面 \(\alpha\) 经过点 \(A(1, 1, 3)\)，平面 \(\alpha\) 的法向量为 \(\boldsymbol{n} = (1, 1, 1)\)。若某同学在计算点 \(P\) 到平面 \(\alpha\) 的距离时，公式中漏写了绝对值符号：\(d = \dfrac{\overrightarrow{AP}\cdot\boldsymbol{n}}{|\boldsymbol{n}|}\)，他算得的错误结果是：

选 A。\(\overrightarrow{AP} = (0-1, 0-1, 2-3) = (-1, -1, -1)\)。

\(\overrightarrow{AP}\cdot\boldsymbol{n} = (-1)\times 1 + (-1)\times 1 + (-1)\times 1 = -3\)。

\(|\boldsymbol{n}| = \sqrt{1^2+1^2+1^2} = \sqrt{3}\)。

若漏写分子绝对值，算得 \(d = \dfrac{-3}{\sqrt{3}} = -\sqrt{3} < 0\)。距离作为几何长度必须是非负数！

正确的点面距离必加绝对值：\(d = \dfrac{|\overrightarrow{AP}\cdot\boldsymbol{n}|}{|\boldsymbol{n}|} = \dfrac{|-3|}{\sqrt{3}} = \sqrt{3}\)。
