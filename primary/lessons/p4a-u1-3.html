亿以内数的写法

听到或看到汉字大数，怎样写出正确的数字、不漏掉占位「0」？

博物馆里一件青铜器上铸了「三十六万零二百四十五」个字的信息。写这个数时，千位上一个单位也没有，应该怎么写？

对！先圈出「万」字分两级：万级写 36，个级千位上一个也没有，就在千位写 0 占位，个级写满 4 位是 0245，合起来是 360245。

1. 圈出「万」字分级写数台

点下面的汉字大数，再点「圈出『万』字」和「补齐占位 0」，看一看万级和个级怎样对准数位格子落子；你也可以点格子里的数字改一改。

含有两级的数的写法：
1. 先写万级，再写个级（先找「万」字，「万」字前面写万级，「万」字后面写个级）；
2. 哪个数位上一个单位也没有，就在那个数位上写 0（个级必须写满 4 位！）。

自己试试

写「四百零八万五千」时，个级写 5000，那么万级应该写多少？

万级写 408，个级写 5000，合起来写作 4085000。

自己试试

小心陷阱：七万零六十 写作多少？

读数里虽然只读了一个「零」，但个级的千位和百位都是空的，必须写两个 0 占位：7|0060，写作 70060。

写亿以内的数，先圈出「万」字分两级，先写万级再写个级；哪个数位上一个单位也没有，就在那个数位上写 0（个级一定写满 4 位）。

两个容易错的地方

✗ 听到一个「零」就只写一个 0 把「五万零八十」写成 5080（少了一位，成了五千零八十）。
✓ 个级必须占满 4 位，缺几位就补几个 0 万级写 5，个级千位、百位都补 0 写成 0080 → 50080。
✗ 漏写万级末尾的 0 把「三千零五十万零四百」写成 3050400（万位漏了 0）。
✓ 万级也要对准数位：「三千零五十万」是 3050 万 万级写 3050，个级写 0400 → 30500400。

直接用

1. 写出下面这个数：六万三千八百五十。

万级写 6，个级写 3850，写作 63850。

2. 写出整万数「八千四百万」，下面哪个写法是对的？

C。万级写 8400，个级写 0000，合起来写作 84000000。

容易错

3. 「九万零五」写作多少？

万级写 9，个级千、百、十位都写 0 占位（0005），写作 90005。

4. 「六千零三十万零七百」应该写作哪个数？

B。万级「六千零三十」写作 6030，个级「零七百」写作 0700，合起来是 60300700。

想一想

5. 由 8 个万、6 个百和 3 个一 组成的五位数是多少？

万位是 8，千位和十位都没有写 0 占位，百位是 6，个位是 3，写作 80603。

6. 看算式写数：30000000 + 500000 + 6000 + 9 = ？

C。3 个千万和 5 个十万组成万级 3050；6 个千和 9 个一组成个级 6009，合起来是 30506009。
