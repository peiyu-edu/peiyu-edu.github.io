18.3 分式的加法与减法

分母相同，分子相加减；分母不同，先通分。和分数一样。难的是两件小事：减去一个多项式分子要加括号；化简求值时，代进去的数要让原式有意义。

本节导读　先修：18.1 通分、18.2 乘除 · 本节路线

要用到：通分、最简公分母（回看 18.1）；分式的乘除和乘方（回看 18.2）；去括号、合并同类项（回看 4.2）。

  1. 从两根水管注水进入：\(\dfrac12+\dfrac13\) 为什么不是 \(\dfrac25\)？
  2. 同分母相加减：分母不变，分子相加减；减式的分子要加括号。
  3. 异分母相加减：先找最简公分母通分，再按同分母算。
  4. 混合运算：先乘方，再乘除，然后加减；有括号先算括号里。
  5. 化简求值：代入的数要让原式所有分母、除式都不为 0。
  6. 练习与中考真题，回看“哪一步最容易错”。

给一个水池注水：甲管单独开 \(2\) 小时注满，乙管单独开 \(3\) 小时注满。两管一起开 \(1\) 小时，注了水池的几分之几？点按钮看：

两管一起开 \(1\) 小时，注了水池的几分之几？

B。甲每小时注 \(\dfrac12\)，乙每小时注 \(\dfrac13\)：\(\dfrac12+\dfrac13=\dfrac36+\dfrac26=\dfrac56\)。选 A 是分子加分子、分母加分母，\(\dfrac25\) 比甲一根管注的 \(\dfrac12\) 还少，显然不对；选 C 是做成了减法。

把 \(2\)、\(3\) 换成字母：甲管 \(a\) 小时注满，乙管 \(b\) 小时注满，一起 \(1\) 小时注 \(\dfrac1a+\dfrac1b\)。这一节要回答：分式怎样相加减？

1. 先认识几个词：同分母、异分母、通分

前置知识：通分和最简公分母（回看 18.1）。分数加法要先把每一份切成一样大，看下面的条形图：

直觉微图解 ①\(\dfrac1a+\dfrac1b\)：先切成同样大的小格，再数格子

同分母分式相加减：分母不变，把分子相加减，\(\dfrac{a}{c}\pm\dfrac{b}{c}=\dfrac{a\pm b}{c}\)。异分母分式相加减：先通分，变为同分母的分式，再加减。一般形式是 \(\dfrac ab\pm\dfrac cd=\dfrac{ad\pm bc}{bd}\)，实际计算用最简公分母更省事。结果要化成最简分式或整式。

核心概念 ②分母不能相加

分母说的是“每份多大”，只有每份一样大，份数（分子）才能相加。所以 \(\dfrac1a+\dfrac1b\ne\dfrac{2}{a+b}\)，取 \(a=b=1\)：左边 \(2\)，右边 \(1\)。

核心概念 ③化简不是解方程

\(\dfrac{1}{x}+\dfrac{2}{x+1}\) 是一个式子，没有等号。只能通分，不能“两边同乘公分母”把分母去掉，那会把式子的值改掉。

2. 核心点：同分母——减式的分子是一个整体

\(\dfrac{3x+2}{x-1}-\dfrac{x+4}{x-1}=\dfrac{3x+2\color{#B5452F}{\underbrace{-(x+4)}_{\text{先加括号}}}}{x-1}=\dfrac{2x-2}{x-1}=\color{#2F7A56}{\underbrace{2}_{\text{别忘约分}}}\)

直觉微图解 ②加不加括号，取 \(x=3\) 一验就知道

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

计算：(1) \(\dfrac{a^2}{a-b}-\dfrac{b^2}{a-b}\)；(2) \(\dfrac{3}{x-2}+\dfrac{x+1}{2-x}\)。

① 读懂题意：(1) 分母相同；(2) 分母一个是 \(x-2\)，一个是 \(2-x\)，看着不同。它们是什么关系？

提示 1：互为相反数的分母

\(2-x=-(x-2)\)。所以 \(\dfrac{x+1}{2-x}=-\dfrac{x+1}{x-2}\)，加法变成减法，分母就相同了。

看完整示范
② 想办法：(1) 分子相减后用平方差公式分解，再约分。(2) 先把 \(2-x\) 化成 \(x-2\)，变号后按同分母相减。
③ 执行：(1) \(\dfrac{a^2-b^2}{a-b}=\dfrac{(a+b)(a-b)}{a-b}=a+b\)。(2) \(\dfrac{3}{x-2}-\dfrac{x+1}{x-2}=\dfrac{3-(x+1)}{x-2}=\dfrac{2-x}{x-2}=-1\)。
执行中检查：(2) 取 \(x=3\)：\(\dfrac31+\dfrac{4}{-1}=3-4=-1\) ✓。

④ 回头看：结果能约分就要约到底；(2) 的分子 \(2-x\) 和分母 \(x-2\) 互为相反数，约分得 \(-1\)。

自己试试：\(\dfrac{2x+1}{x+3}-\dfrac{x-2}{x+3}\) 等于？

A。\(\dfrac{2x+1-(x-2)}{x+3}=\dfrac{x+3}{x+3}=1\)。B 是没加括号，\(-2\) 没变成 \(+2\)；C 是把减号做成了加号；D 是以为分子分母「消掉」就是 \(0\)，其实分子分母相同，商是 \(1\)。

3. 核心点：异分母——用最简公分母通分

\(\color{#966524}{\underbrace{\text{分解各分母}}_{①}}\to\color{#2F7A56}{\underbrace{\text{写最简公分母}}_{②}}\to\color{#B5452F}{\underbrace{\text{各乘“缺的因式”}}_{③\ \text{分子分母同乘}}}\to\underbrace{\text{合并分子、约分}}_{④}\)

直觉微图解 ③每个分母缺哪几块，就给它（连同分子）补上哪几块

例 2（示范）

计算：\(\dfrac{2}{x^2-4}-\dfrac{1}{x^2-2x}\)。

提示：先分解两个分母

\(x^2-4=(x+2)(x-2)\)，\(x^2-2x=x(x-2)\)。最简公分母是什么？各缺哪个因式？

基础示范（可收起）
想办法：最简公分母 \(x(x+2)(x-2)\)。第一个分式缺 \(x\)，第二个缺 \(x+2\)。
执行：原式 \(=\dfrac{2x}{x(x+2)(x-2)}-\dfrac{x+2}{x(x+2)(x-2)}=\dfrac{2x-(x+2)}{x(x+2)(x-2)}=\dfrac{x-2}{x(x+2)(x-2)}=\dfrac{1}{x(x+2)}\)。
检查：减式分子 \(x+2\) 加了括号 ✓；分子 \(x-2\) 和分母有公因式，约掉了 ✓。取 \(x=1\)：\(\dfrac{2}{-3}-\dfrac{1}{-1}=\dfrac13\)，\(\dfrac{1}{1\times3}=\dfrac13\) ✓。

回头看：合并分子后再看一眼能不能约分，这一步常被忘掉。

自己试试：\(\dfrac{a}{a-1}-\dfrac{1}{a^2-a}\) 等于？

A。\(a^2-a=a(a-1)\)，最简公分母 \(a(a-1)\)：\(\dfrac{a\cdot a-1}{a(a-1)}=\dfrac{(a+1)(a-1)}{a(a-1)}=\dfrac{a+1}{a}\)。B 是第一个分式的分子没乘 \(a\)，得 \(\dfrac{a-1}{a(a-1)}\)；C 是分母里的 \(a-1\) 丢了。

4. 核心点：混合运算与化简求值

运算顺序和数一样：先乘方，再乘除，然后加减；有括号先算括号里面。化简求值先化简，再代入；代入的数要使原式中所有分母（包括除式的分母）都不为 \(0\)，除式本身也不能为 \(0\)，不能只看化简后的式子。

直觉微图解 ④\(\left(1-\dfrac{2}{x+1}\right)\div\dfrac{x-1}{x^2+x}\) 化简得 \(x\)。哪些数能代？逐个查

例 3（示范：先化简，再选数代入）

先化简 \(\left(\dfrac{x}{x-2}-\dfrac{4}{x^2-2x}\right)\div\dfrac{x+2}{x^2}\)，再从 \(-2,\ 0,\ 2,\ 3\) 中选一个合适的数代入求值。

提示 1：括号里先通分

\(x^2-2x=x(x-2)\)，最简公分母 \(x(x-2)\)。

看完整示范
括号里：\(\dfrac{x\cdot x-4}{x(x-2)}=\dfrac{(x+2)(x-2)}{x(x-2)}=\dfrac{x+2}{x}\)。
除化乘：\(\dfrac{x+2}{x}\cdot\dfrac{x^2}{x+2}=x\)。
选数：原式中 \(x-2\ne0\)、\(x^2-2x\ne0\)、\(x^2\ne0\)，除式不为 0 又要 \(x+2\ne0\)：\(x\) 不能取 \(2\)、\(0\)、\(-2\)。只能取 \(x=3\)，原式 \(=3\)。

回头看：用原式验：\(\left(3-\dfrac43\right)\div\dfrac59=\dfrac53\times\dfrac95=3\) ✓。化简结果 \(x\) 对哪个数都能算，正因如此才更要回原式查。

自己试试：\(\dfrac{m}{m-3}-\dfrac{9}{m^2-3m}\) 化简得 \(\dfrac{m+3}{m}\)。小明取 \(m=3\) 代入化简结果，得 \(2\)。他做得对吗？

B。原式的分母 \(m-3\) 和 \(m^2-3m\) 在 \(m=3\) 时都是 \(0\)，原式没有意义。化简时约去了 \(m-3\)，化简结果就「看不出」这个限制了。化简本身没错：\(\dfrac{m^2-9}{m(m-3)}=\dfrac{m+3}{m}\)。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）化简求值，代入了让原式无意义的数
❌ 典型错解：\(\dfrac{x^2-1}{x+2}\div\dfrac{x-1}{x+2}\) 化简得 \(x+1\)，“取 \(x=1\)，原式 \(=2\)”。
✅ 回原式查：\(x=1\) 时除式 \(\dfrac{x-1}{x+2}=0\)，要除以 \(0\)；\(x=-2\) 时分母为 \(0\)。这两个数都不能取，在数轴上避开 ✕。
翻车现场 ②分子加分子，分母加分母
❌ 典型错解：\(\dfrac1a+\dfrac1b=\dfrac{2}{a+b}\)。
✅ 一眼看清：先通分：\(\dfrac{b}{ab}+\dfrac{a}{ab}=\dfrac{a+b}{ab}\)。取 \(a=2,b=3\)：\(\dfrac56\)，错解得 \(\dfrac25\)。
翻车现场 ③减式的分子没加括号
❌ 典型错解：\(\dfrac{5}{x}-\dfrac{x-2}{x}=\dfrac{5-x-2}{x}=\dfrac{3-x}{x}\)。
✅ 一眼看清：\(\dfrac{5-(x-2)}{x}=\dfrac{7-x}{x}\)。减去的是整个分子 \(x-2\)，后面的 \(-2\) 要变成 \(+2\)。
再深一点（可以先跳过）：把一个分式拆成两个

减法法则倒过来用：\(\dfrac1n-\dfrac{1}{n+1}=\dfrac{n+1-n}{n(n+1)}=\dfrac{1}{n(n+1)}\)。于是 \(\dfrac{1}{1\times2}+\dfrac{1}{2\times3}+\dfrac{1}{3\times4}+\dfrac{1}{4\times5}=\left(1-\dfrac12\right)+\left(\dfrac12-\dfrac13\right)+\left(\dfrac13-\dfrac14\right)+\left(\dfrac14-\dfrac15\right)=1-\dfrac15=\dfrac45\)，中间的项一正一负全抵消了。加到第 \(n\) 项，和是 \(\dfrac{n}{n+1}\)，总比 \(1\) 小。

① 异分母相加：先切成一样大的小格

拖动上面两条的圆点（或点圆点后用方向键）改 \(a\)、\(b\)。第三条是和，它被切成最简公分母那么多格。

② 同分母相减：加括号的结果永远是 2

\(\dfrac{3x+2}{x-1}-\dfrac{x+4}{x-1}\)：拖动 \(x\)，比较原式的值、加括号算出的 \(2\)、不加括号算出的 \(\dfrac{2x+6}{x-1}\)。

③ 进阶：化简求值，一步步代进原式

\(\left(1+\dfrac{1}{x-1}\right)\div\dfrac{x}{x^2-1}\) 化简得 \(x+1\)。拖动 \(x\)，看原式每一步算出什么，在哪些地方算不下去。

从易到难排好了。卡住时先展开提示。

直接用

1. 计算 \(\dfrac{3}{2a}+\dfrac{1}{a^2}\)。

A。最简公分母 \(2a^2\)：\(\dfrac{3a}{2a^2}+\dfrac{2}{2a^2}=\dfrac{3a+2}{2a^2}\)。B 是分子、分母各自相加；C 是第二个分式的分子忘乘 \(2\)；D 是两个分子都没乘。

2. 小周骑车去 \(12\) 千米外的图书馆，去时速度是 \(v\) 千米/时，回来顺风，速度比去时快 \(2\) 千米/时。往返一共用了多少小时？

A。时间 = 路程 ÷ 速度：去时 \(\dfrac{12}{v}\)，回来 \(\dfrac{12}{v+2}\)。\(\dfrac{12}{v}+\dfrac{12}{v+2}=\dfrac{12(v+2)+12v}{v(v+2)}=\dfrac{24(v+1)}{v(v+2)}\)。B 是分子分母各自相加：\(\dfrac{24}{2v+2}\)；C 是做成了减法；D 是做成了乘法。

易错

3. 计算 \(\dfrac{x}{x-y}-\dfrac{y}{y-x}\)。

提示

\(y-x=-(x-y)\)，所以 \(-\dfrac{y}{y-x}=+\dfrac{y}{x-y}\)。

A。\(\dfrac{x}{x-y}+\dfrac{y}{x-y}=\dfrac{x+y}{x-y}\)。B 是把分母直接当成相同，没变号，算成 \(\dfrac{x-y}{x-y}\)；C、D 是符号处理乱了。

4. 计算 \(\dfrac{x^2+4}{x+2}-x+2\)。

提示

后面两项合起来是 \(-(x-2)\)，不是 \(-(x+2)\)。把 \(x-2\) 看成分母为 \(1\) 的式子，通分：\(\dfrac{(x-2)(x+2)}{x+2}\)。

A。原式 \(=\dfrac{x^2+4}{x+2}-(x-2)=\dfrac{x^2+4-(x^2-4)}{x+2}=\dfrac{8}{x+2}\)。B 是把 \(-x+2\) 当成了 \(-(x+2)\)：\(\dfrac{x^2+4-(x+2)^2}{x+2}=\dfrac{-4x}{x+2}\)；C 是 \(-x+2\) 没乘 \(x+2\) 就直接放到分子上；D 是把 \((x-2)(x+2)\) 算成了 \(x^2+4\)。

5. 先化简 \(\left(1-\dfrac{1}{x+1}\right)\div\dfrac{x}{x^2-1}\)，再从 \(-1,\ 0,\ 1,\ 2\) 中选一个合适的数代入求值，结果是？

提示

化简得 \(x-1\)。再回原式查：哪些数让分母 \(x+1\)、\(x^2-1\) 为 \(0\)？哪个数让除式 \(\dfrac{x}{x^2-1}\) 为 \(0\)？

A。\(\dfrac{x}{x+1}\cdot\dfrac{(x+1)(x-1)}{x}=x-1\)。\(-1\)、\(1\) 让分母为 \(0\)，\(0\) 让除式为 \(0\)，只能取 \(x=2\)，值为 \(1\)。B、C、D 分别是代了 \(-1\)、\(0\)、\(1\)，这些数都让原式没有意义（翻车现场 ①）。

挑战

6. 计算 \(\dfrac{1}{x(x+1)}+\dfrac{1}{(x+1)(x+2)}\)。

提示 1：通分

最简公分母是 \(x(x+1)(x+2)\)，第一个缺 \(x+2\)，第二个缺 \(x\)。

提示 2：或者拆开

\(\dfrac{1}{x(x+1)}=\dfrac1x-\dfrac{1}{x+1}\)，第二个也这样拆，中间两项会抵消。

A。\(\dfrac{(x+2)+x}{x(x+1)(x+2)}=\dfrac{2(x+1)}{x(x+1)(x+2)}=\dfrac{2}{x(x+2)}\)。也可以拆：\(\dfrac1x-\dfrac1{x+1}+\dfrac1{x+1}-\dfrac1{x+2}=\dfrac1x-\dfrac1{x+2}=\dfrac{2}{x(x+2)}\)。B 是两个分子都没乘缺的因式；C 是拆开后算成了 \(\dfrac1x\cdot\dfrac1{x+2}\)。

“先化简，再求值”几乎是每年中考的必考题，选数代入时别忘了回原式查分母和除式。
