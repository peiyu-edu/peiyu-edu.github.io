6.2 平面向量的运算

从位移合成到力的做功：非零向量既有大小又有确定方向。加法首尾相接、减法指向被减、数乘拉伸反转、数量积投影视角。几何直观与代数运算在这里交融。

小船在平直的河道中渡河。船头垂直指向对岸（正北方向），自身的动力让船以 \(4\text{ m/s}\) 的速度行驶；同时河水由西向东以 \(3\text{ m/s}\) 的流速冲刷小船。点下面的按钮看看两个速度怎样合成：

站在岸上看，小船实际前进的速度大小是多少？

B。小船实际的位移既向北又向东，实际运动是船速与水速的合成。

因为正北与正东互相垂直，两个速度构成了直角三角形的两条直角边，根据勾股定理，合速度大小为 \(\sqrt{4^2+3^2}=\sqrt{25}=5\text{ m/s}\)。

如果水流也是正北方向，速度才是 \(4+3=7\text{ m/s}\)；如果水流正南顺流反冲，速度是 \(4-3=1\text{ m/s}\)。这说明：两个有方向的量相加，绝不能只把数字加在一起，而要由方向决定几何法则。

这一节我们就来系统搞清平面向量的四种核心运算：加法、减法、数乘以及数量积（内积）。

要用到：向量的模与方向（回看 6.1）；初中平面几何勾股定理；三角函数余弦（回看 5.2）。

1. 先认识几个词

直觉微图解

运算族 ①线性运算（加减与数乘）→ 结果是向量

结果仍是向量：\(\boldsymbol{a}\pm\boldsymbol{b}\) 与 \(\lambda\boldsymbol{a}\) 的结果可能是零向量，零向量没有确定方向。向量加法满足交换律、结合律；减法按加上相反向量处理，不能套用加法的这两条律。数乘满足分配律。

运算族 ②数量积（点乘）→ 结果是实数（标量）

纯数值与无结合律：对非零向量，\(\boldsymbol{a}\cdot\boldsymbol{b}=|\boldsymbol{a}||\boldsymbol{b}|\cos\theta\)；含零向量时数量积为 \(0\)。结果都是没有方向的实数。数量积无结合律，是说 \((\boldsymbol{a}\cdot\boldsymbol{b})\boldsymbol{c}\) 与 \(\boldsymbol{a}(\boldsymbol{b}\cdot\boldsymbol{c})\) 并不恒等，个别取值下仍可相等。

向量的模与方向：向量有大小，非零向量有确定方向。模 \(|\boldsymbol{a}|\) 是长度，是一个非负实数。向量不能比较大小，但模可以比较大小（例：\(|\boldsymbol{a}| < |\boldsymbol{b}|\)，绝不能写 \(\boldsymbol{a} < \boldsymbol{b}\)）。

零向量与相反向量：模为 \(0\) 的向量叫零向量 \(\boldsymbol{0}\)，没有确定方向，规定与任意向量平行。对非零向量 \(\boldsymbol{a}\)，与它长度相等且方向相反的向量叫相反向量 \(-\boldsymbol{a}\)；零向量的相反向量仍是零向量，即 \(-\boldsymbol{0}=\boldsymbol{0}\)。\(\boldsymbol{a}+(-\boldsymbol{a})=\boldsymbol{0}\)（注意结果是向量 \(\boldsymbol{0}\) 不是实数 \(0\)）。

两向量的夹角：同起点射线所成较小非负角 \(\theta\in[0,\pi]\)。同向夹角 \(0\)，反向夹角 \(\pi\)，垂直时夹角 \(\dfrac{\pi}{2}\)。注意：零向量不参与夹角讨论。

2. 核心公式与运算口诀

① 加法口诀：首尾相连“首指向尾”（\(\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}\)）或同起点对角线；
② 减法口诀：同起点终点连线“指向被减向量”（\(\overrightarrow{OA}-\overrightarrow{OB}=\overrightarrow{BA}\)）；
③ 数量积核心公式：\(\boldsymbol{a}\cdot\boldsymbol{b} = |\boldsymbol{a}||\boldsymbol{b}|\cos\theta\)（\(\theta\in[0,\pi]\)；锐角正、垂直 \(0\)、钝角负）；
④ 模长与夹角：\(|\boldsymbol{a}| = \sqrt{\boldsymbol{a}^2}\)，\(\cos\theta = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}\)；非零垂直充要条件：\(\boldsymbol{a}\perp\boldsymbol{b} \iff \boldsymbol{a}\cdot\boldsymbol{b}=0\)。

例 1（看一遍怎么写）

在平行四边形 \(ABCD\) 中，对角线交于点 \(O\)。已知 \(\overrightarrow{AB}=\boldsymbol{a}\)，\(\overrightarrow{AD}=\boldsymbol{b}\)。用 \(\boldsymbol{a},\boldsymbol{b}\) 表示 \(\overrightarrow{AC}\) 和 \(\overrightarrow{DB}\)。

由平行四边形法则，对角线 \(\overrightarrow{AC}=\overrightarrow{AB}+\overrightarrow{AD}=\boldsymbol{a}+\boldsymbol{b}\)。

由减法法则（共起点 \(A\)），\(\overrightarrow{DB}=\overrightarrow{AB}-\overrightarrow{AD}=\boldsymbol{a}-\boldsymbol{b}\)。

自己试试：化简 \(\overrightarrow{AB}-\overrightarrow{AC}+\overrightarrow{BD}\) 的结果是？

A。根据向量减法：\(\overrightarrow{AB}-\overrightarrow{AC}=\overrightarrow{CB}\)（共起点，指向被减向量）。

再做加法：\(\overrightarrow{CB}+\overrightarrow{BD}=\overrightarrow{CD}\)（首尾相接，首指向尾）。

选 B 的同学减法终点指反了；选 C 的同学把相反向量和被减向量搞混了。

本视频题目：用线性表示证三点共线

已知不共线向量 \(\boldsymbol a,\boldsymbol b\)，\(\overrightarrow{AB}=\boldsymbol a+\boldsymbol b\)，\(\overrightarrow{BC}=\boldsymbol a+3\boldsymbol b\)，\(\overrightarrow{CD}=\boldsymbol a-\boldsymbol b\)。证明 \(A,B,D\) 三点共线，并判断 \(A,B,C\) 是否共线。

3. 数乘向量与共线定理

实数 \(\lambda\) 与向量 \(\boldsymbol{a}\) 相乘，结果仍是一个向量，记作 \(\lambda\boldsymbol{a}\)：\(|\lambda\boldsymbol{a}|=|\lambda||\boldsymbol{a}|\)。当 \(\boldsymbol{a}\ne\boldsymbol{0}\) 时，\(\lambda > 0\) 的结果与它同向，\(\lambda < 0\) 的结果与它反向；\(\lambda=0\) 或 \(\boldsymbol{a}=\boldsymbol{0}\) 时，结果为零向量 \(\boldsymbol{0}\)。

非零向量 \(\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 共线（平行）当且仅当存在唯一实数 \(\lambda\)，使得 \(\boldsymbol{b}=\lambda\boldsymbol{a}\)。必须强调基准向量 \(\boldsymbol{a}\ne\boldsymbol{0}\)。

例 2

已知非零不共线向量 \(\boldsymbol{e}_1,\boldsymbol{e}_2\)。若 \(\boldsymbol{a}=2\boldsymbol{e}_1-\boldsymbol{e}_2\)，\(\boldsymbol{b}=k\boldsymbol{e}_1+2\boldsymbol{e}_2\)，且 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，求实数 \(k\)。

因为 \(\boldsymbol{a}\parallel\boldsymbol{b}\) 且 \(\boldsymbol{a}\ne\boldsymbol{0}\)，由共线定理存在实数 \(\lambda\) 使得 \(\boldsymbol{b}=\lambda\boldsymbol{a}\)：\(k\boldsymbol{e}_1+2\boldsymbol{e}_2 = 2\lambda\boldsymbol{e}_1-\lambda\boldsymbol{e}_2\)。

因 \(\boldsymbol{e}_1,\boldsymbol{e}_2\) 不共线，对应系数必相等：\(2=-\lambda \implies \lambda=-2\)，从而 \(k=2\lambda=2\times(-2)=-4\)。

自己试试：点 \(C\) 在线段 \(AB\) 上，且 \(AC=2CB\)。以任意点 \(O\) 为起点，\(\overrightarrow{OC}=\)？

A。因为 \(C\) 在线段 \(AB\) 上且 \(AC=2CB\)，所以 \(\overrightarrow{AC}=\dfrac23\overrightarrow{AB}=\dfrac23(\overrightarrow{OB}-\overrightarrow{OA})\)。

代入 \(\overrightarrow{OC}=\overrightarrow{OA}+\overrightarrow{AC}=\dfrac13\overrightarrow{OA}+\dfrac23\overrightarrow{OB}\)。

直观技巧：点 \(C\) 更靠近 \(B\)，所以 \(\overrightarrow{OB}\) 权重更大（\(\dfrac23\)）。选 B 的同学把分比记混了。

本视频题目：平行四边形中的两个系数

非退化平行四边形 \(ABCD\) 中，\(M\) 为 \(BC\) 中点，\(N\) 在边 \(CD\) 上且 \(DN=\frac13DC\)。若 \(\overrightarrow{AC}=x\overrightarrow{AM}+y\overrightarrow{AN}\)，求 \(x,y\)。本题利用不共线向量表示的唯一性；系统的基底定理在 6.3 学习。

4. 典型例题：三步思维链精讲

例 3（高频考法·求模长与数量积）

已知 \(|\boldsymbol{a}|=2\)，\(|\boldsymbol{b}|=3\)，向量 \(\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 夹角为 \(120^\circ\)。求：① \(|2\boldsymbol{a}-\boldsymbol{b}|\)；② \((2\boldsymbol{a}-\boldsymbol{b})\cdot\boldsymbol{a}\)。

👀 第一眼·破题信号
看到求模长 \(|2\boldsymbol{a}-\boldsymbol{b}|\)，无法直接算几何长度 → 核心破题信号：必须先平方转化为数量积展开（\(|\boldsymbol{v}|^2=\boldsymbol{v}^2\)），求出数值后再开方！
🔧 第二步·套公式拆解
① 基底数量积：\(\boldsymbol{a}\cdot\boldsymbol{b} = |\boldsymbol{a}||\boldsymbol{b}|\cos 120^\circ = 2\times 3\times\left(-\dfrac12\right) = -3\)；
② 平方展开求模：\(|2\boldsymbol{a}-\boldsymbol{b}|^2 = 4|\boldsymbol{a}|^2 - 4\boldsymbol{a}\cdot\boldsymbol{b} + |\boldsymbol{b}|^2 = 4(4) - 4(-3) + 9 = 16 + 12 + 9 = 37\)；故 \(|2\boldsymbol{a}-\boldsymbol{b}| = \sqrt{37}\)；
③ 展开数量积：\((2\boldsymbol{a}-\boldsymbol{b})\cdot\boldsymbol{a} = 2|\boldsymbol{a}|^2 - \boldsymbol{a}\cdot\boldsymbol{b} = 2(4) - (-3) = 8 + 3 = 11\)。
🛡️ 第三步·必查防坑点
① 钝角余弦值为负（\(\cos 120^\circ = -\frac12\)），交叉项 \(-4\boldsymbol{a}\cdot\boldsymbol{b}\) 负负得正变 \(+12\)，绝不能算成 \(16 - 12 + 9\)；
② 算完模长平方后千万别忘了开平方根，模长非负取正根 \(\sqrt{37}\)。

自己试试：已知 \(|\boldsymbol{a}|=1\)，\(|\boldsymbol{b}|=2\)，且 \(\boldsymbol{a}\cdot\boldsymbol{b}=-1\)，则两向量的夹角 \(\theta=\)？

B。由夹角公式：\(\cos\theta = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|} = \dfrac{-1}{1\times 2} = -\dfrac12\)。

因为向量夹角 \(\theta\in[0^\circ,180^\circ]\)，余弦为 \(-\dfrac12\) 的角只有 \(120^\circ\)。选 A 的同学算丢了负号，把钝角当成了锐角。

5. 投影向量与投影长度

设 \(\boldsymbol{e}=\dfrac{\boldsymbol{b}}{|\boldsymbol{b}|}\) 为与 \(\boldsymbol{b}\) 同方向的单位向量：

① 投影向量：\((\boldsymbol{a}\cdot\boldsymbol{e})\boldsymbol{e} = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{b}|^2}\boldsymbol{b}\)（是一个落在 \(\boldsymbol{b}\) 所在直线上的向量）；
② 有向投影（投影值）：\(|\boldsymbol{a}|\cos\theta = \boldsymbol{a}\cdot\boldsymbol{e}\)（是一个实数：锐角为正，钝角为负，垂直为 \(0\)）；
③ 投影长度（投影模长）：\(||\boldsymbol{a}|\cos\theta|\)（是几何线段模长，必须非负）。

6. 这三种情况最容易翻车

翻车现场 ①数量积狂用“结合律”
错解

认为 \((\boldsymbol{a}\cdot\boldsymbol{b})\boldsymbol{c} = \boldsymbol{a}(\boldsymbol{b}\cdot\boldsymbol{c})\)。

正解

取互相垂直的单位向量 \(\boldsymbol{e}_1,\boldsymbol{e}_2\)。令 \(\boldsymbol{a}=\boldsymbol{b}=\boldsymbol{e}_1,\boldsymbol{c}=\boldsymbol{e}_2\)，左边为 \(\boldsymbol{e}_2\)，右边为 \(\boldsymbol{0}\)，所以该等式不恒成立。但若 \(\boldsymbol{a}=\boldsymbol{b}=\boldsymbol{c}=\boldsymbol{e}_1\)，两边都为 \(\boldsymbol{e}_1\)。无结合律不等于每次都不相等。

翻车现场 ②数量积随意“两边约分消去”
错解

由 \(\boldsymbol{a}\cdot\boldsymbol{b}=\boldsymbol{a}\cdot\boldsymbol{c}\)（\(\boldsymbol{a}\ne\boldsymbol{0}\)）误得出 \(\boldsymbol{b}=\boldsymbol{c}\)。

正解

移项得 \(\boldsymbol{a}\cdot(\boldsymbol{b}-\boldsymbol{c})=0\)，只能得出 \(\boldsymbol{a}\perp(\boldsymbol{b}-\boldsymbol{c})\)。只要 \(\boldsymbol{b},\boldsymbol{c}\) 在 \(\boldsymbol{a}\) 上投影相等即可，两向量完全可以不同！

翻车现场 ③混淆投影向量、投影值与投影长度
错解

问「投影向量」写成了数字，或问「投影长度」写出了负号。

正解

投影向量是向量（带基向量），有向投影是实数（钝角为负），投影长度是模长（绝对值必非负）。

再深一点（可以先跳过）

向量回路法：在任意封闭多边形 \(A_1A_2\cdots A_n\) 中，\(\overrightarrow{A_1A_2}+\overrightarrow{A_2A_3}+\cdots+\overrightarrow{A_nA_1}=\boldsymbol{0}\)。求几何中多段线段向量和时，把它们首尾连成环，往往一步出答案。

分配律的几何直观：为什么 \((\boldsymbol{a}+\boldsymbol{b})\cdot\boldsymbol{c}=\boldsymbol{a}\cdot\boldsymbol{c}+\boldsymbol{b}\cdot\boldsymbol{c}\)？从投影看，\(\boldsymbol{a}+\boldsymbol{b}\) 在 \(\boldsymbol{c}\) 上的有向投影，正好等于 \(\boldsymbol{a}\) 和 \(\boldsymbol{b}\) 在 \(\boldsymbol{c}\) 上各自有向投影的代数和，两边乘 \(|\boldsymbol{c}|\) 自然相等。

极化恒等式（秒杀利器）：\(\boldsymbol{a}\cdot\boldsymbol{b}=\dfrac14(|\boldsymbol{a}+\boldsymbol{b}|^2-|\boldsymbol{a}-\boldsymbol{b}|^2)\)。设平行四边形邻边为 \(\boldsymbol{a},\boldsymbol{b}\)，两条对角线分别为 \(\boldsymbol{a}+\boldsymbol{b}\) 和 \(\boldsymbol{a}-\boldsymbol{b}\)，数量积直接等于两对角线平方差的 \(\dfrac14\)，在解析几何与极值题中极为常用。

从易到难排好了。前两道直接用，中间三道紧扣专题卡边界，最后一道是综合挑战。

直接用

1. 化简 \(\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CA}\) 的结果是？

B。由三角形加法法则，\(\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}\)，再加上 \(\overrightarrow{CA}\)，首尾相接绕回起点 \(A\)，位移为零向量 \(\boldsymbol{0}\)。

注意：向量运算的结果依然是向量，必须写成零向量 \(\boldsymbol{0}\)，而不能写成实数 \(0\)！选 A 的同学混淆了向量与标量。

2. 已知 \(|\boldsymbol{a}|=3\)，\(|\boldsymbol{b}|=4\)，向量 \(\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 的夹角为 \(60^\circ\)，则 \(\boldsymbol{a}\cdot\boldsymbol{b}=\)？

A。直接代入数量积定义：\(\boldsymbol{a}\cdot\boldsymbol{b}=|\boldsymbol{a}||\boldsymbol{b}|\cos 60^\circ=3\times 4\times\dfrac12=6\)。

选 B 的同学错用了正弦 \(\sin 60^\circ\)（把数量积当成了三角形面积公式）；选 C 的同学漏乘了余弦值 \(\cos 60^\circ\)。

易错

3. 已知非零向量 \(\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}\)，若 \(\boldsymbol{a}\cdot\boldsymbol{b}=\boldsymbol{a}\cdot\boldsymbol{c}\)，则下列结论必定成立的是？

B。将等式移项：\(\boldsymbol{a}\cdot\boldsymbol{b}-\boldsymbol{a}\cdot\boldsymbol{c}=0 \implies \boldsymbol{a}\cdot(\boldsymbol{b}-\boldsymbol{c})=0\)。

由数量积为 \(0\) 的充要条件，说明 \(\boldsymbol{a}\perp(\boldsymbol{b}-\boldsymbol{c})\)（或者 \(\boldsymbol{b}-\boldsymbol{c}=\boldsymbol{0}\) 即 \(\boldsymbol{b}=\boldsymbol{c}\)）。

边界提醒：向量数量积没有消去律，绝不能像实数乘法一样两边除以 \(\boldsymbol{a}\) 得出 \(\boldsymbol{b}=\boldsymbol{c}\)！只要 \(\boldsymbol{b}-\boldsymbol{c}\) 与 \(\boldsymbol{a}\) 垂直，\(\boldsymbol{b}\) 和 \(\boldsymbol{c}\) 就可以完全不相等。选 A 是把向量当成了实数。

4. 设 \(\boldsymbol{a},\boldsymbol{b}\) 为平面向量。命题甲：「存在唯一实数 \(\lambda\)，使得 \(\boldsymbol{b}=\lambda\boldsymbol{a}\)」；命题乙：「\(\boldsymbol{a}\parallel\boldsymbol{b}\)」。则甲是乙的什么条件？

B。充分性：若存在实数 \(\lambda\) 使得 \(\boldsymbol{b}=\lambda\boldsymbol{a}\)，则两向量必定共线平行，甲能推出乙。

必要性：若 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，当 \(\boldsymbol{a}=\boldsymbol{0}\) 且 \(\boldsymbol{b}\ne\boldsymbol{0}\) 时（零向量与任何向量平行），不存在任何实数 \(\lambda\) 能满足 \(\boldsymbol{b}=\lambda\boldsymbol{0}=\boldsymbol{0}\)！因此乙推不出甲。

边界提醒：向量共线定理充要成立的红线是基准向量非零（\(\boldsymbol{a}\ne\boldsymbol{0}\)）。忽略零向量就会误选 A。

5. 已知 \(|\boldsymbol{a}|=4\)，\(|\boldsymbol{b}|=2\)，\(\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 的夹角为 \(120^\circ\)。则 \(\boldsymbol{a}\) 在 \(\boldsymbol{b}\) 上的「投影长度」和「有向投影值」分别为？

A。有向投影值（投影值）为 \(|\boldsymbol{a}|\cos 120^\circ = 4\times\left(-\dfrac12\right) = -2\)。

而投影长度是投影向量的模长（几何上线段的长度），绝不能为负，必须取绝对值：\(|-2|=2\)。

边界提醒：长度必非负，有向投影钝角为负。选 B 错在把长度写成了负数；选 C 错在把有向投影的符号丢了。

挑战

6. 已知非零向量 \(\boldsymbol{a},\boldsymbol{b}\) 满足 \(|\boldsymbol{a}|=1\)，\(|\boldsymbol{b}|=2\)，且 \(\boldsymbol{a}\perp(\boldsymbol{b}-\boldsymbol{a})\)，则向量 \(\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 的夹角 \(\theta=\)？

C。垂直即数量积为 \(0\)：\(\boldsymbol{a}\cdot(\boldsymbol{b}-\boldsymbol{a}) = \boldsymbol{a}\cdot\boldsymbol{b}-|\boldsymbol{a}|^2 = 0\)，所以 \(\boldsymbol{a}\cdot\boldsymbol{b} = |\boldsymbol{a}|^2 = 1^2 = 1\)。

代入夹角公式：\(\cos\theta = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|} = \dfrac{1}{1\times 2} = \dfrac12\)。因为 \(\theta\in[0^\circ,180^\circ]\)，所以 \(\theta=60^\circ\)。

几何直观：\(\boldsymbol{a}\)、\(\boldsymbol{b}-\boldsymbol{a}\) 与 \(\boldsymbol{b}\) 构成以 \(\boldsymbol{b}\) 为斜边的直角三角形，直角边 \(|\boldsymbol{a}|=1\)，斜边 \(|\boldsymbol{b}|=2\)，夹角正是 \(60^\circ\)。
