加、减法各部分的关系

家长先看（30 秒）
  • 今天借助「部分与总数」的示意图，把加法和减法各部分之间的关系梳理清楚，并明确减法是加法的逆运算。
  • 加法关系：和 = 加数 + 加数；反过来求其中一个加数：加数 = 和 − 另一个加数。
  • 减法关系：差 = 被减数 − 减数；反过来求减数：减数 = 被减数 − 差；求被减数（最大的总数）：被减数 = 减数 + 差！孩子做填空题 ( ) − 135 = 240 最容易拿 240 减 135，一定要先问「括号里的是总数还是部分」。

在家玩：一张纸条图变三道算式

准备：在纸上画一条长纸条，分成左右两段：左段写 180，右段写 250，总长写 430。

  1. 家长拿一枚硬币盖住总长 430，让孩子说出求总数的加法算式：180 + 250 = 430（和 = 加数 + 加数，或被减数 = 减数 + 差）。
  2. 再把硬币移过去盖住右段 250，让孩子说出求部分的减法算式：430 − 180 = 250。
  3. 最后盖住左段 180，说出另一道减法算式：430 − 250 = 180。

夸孩子「你用硬币一盖就看清谁是总数、谁是部分，加减关系一点不乱」，不说「真聪明」。
