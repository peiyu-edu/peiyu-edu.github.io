3.3 抛物线

到定点的距离等于到定直线的距离。抓住「到焦点的距离转化成到准线的垂直距离」，公式、几何性质与最值问题就全通了。

你一定见过这些神奇的生活场景：

  • 汽车远光灯与探照灯：光源只是一个小灯珠，经过后面的金属反射碗，射出来的却是一道笔直平行、照射数百米的光柱；
  • 卫星电视“大锅”与射电望远镜：面向深空，把来自遥远星系极其微弱的平行电磁波，全部反射汇聚在悬在前方的小盒子里；
  • 奥运圣火采集镜：太阳光平行照在凹面聚光镜上，所有光线瞬间聚焦于火炬尖端，引燃圣火。

它们不约而同采用了「抛物面」。这里的秘密究竟藏在哪里？

卫星接收天线（截面为抛物线）收集来自太空微弱的平行无线电波。高频接收器应该精准安装在哪个位置，才能接收到最集中的聚焦信号？

B。卫星天线的截面是一条抛物线，它的焦点就是所有平行入射波经反射后汇聚的共同点！反过来，探照灯把灯珠放在焦点，反射出的就是平行的强聚光束。

这一切神奇的光学与物理性质，都源于抛物线最纯粹的几何定义：平面内到定点（焦点）与到定直线（准线）的距离严格相等。这一节就从这个定义出发，弄清它的标准方程、性质和用法。

1. 先认识几个词

要用到：两点间距离公式、点到直线的距离（回看 2.3）。下面几个词都拿同一组例子说：定点 \(F(1,0)\)，定直线 \(l:\ x=-1\)。

焦点 \(F\)、准线 \(l\)：抛物线定义里的那个定点叫焦点，那条定直线叫准线。焦点不在准线上。

例：\(F(1,0)\) 不在 \(x=-1\) 上，可以做焦点和准线。

点到准线的距离：从点向准线作垂线，垂线段的长。准线是竖直线 \(x=a\) 时，就是横坐标之差的绝对值 \(|x_0-a|\)。

例：点 \((4,4)\) 到 \(x=-1\) 的距离是 \(|4-(-1)|=5\)。

焦准距 \(p\)：焦点到准线的距离，总是正数。顶点在焦点和准线正中间，到两边各 \(\dfrac p2\)。

例：\(F(1,0)\) 到 \(x=-1\) 的距离 \(p=2\)，顶点是原点，离焦点、离准线各 \(1\)。

焦半径 \(|PF|\)：抛物线上一点 \(P\) 到焦点的距离。

例：点 \(P(4,4)\) 在这条抛物线上，\(|PF|=\sqrt{(4-1)^2+4^2}=5\)，正好等于它到准线的距离 \(5\)。这不是巧合，下一块就讲。

2. 定义：到焦点的距离 = 到准线的距离

平面内，到定点 \(F\) 和到定直线 \(l\)（\(F\) 不在 \(l\) 上）距离相等的点，组成的曲线叫抛物线。

\(P\) 在抛物线上 \(\iff\) \(|PF|=d\)，\(d\) 是 \(P\) 到准线的距离。

为什么是这个形状：离准线越远的点，也要离焦点越远，所以曲线一边往外张开、一边远离准线，开口朝焦点那一侧；最靠近准线的点在焦点和准线正中间，就是顶点。

求方程就照定义列式：设 \(P(x,y)\)，把两个距离写出来，令它们相等，再化简。

例 1（看一遍怎么写）

到点 \(F(0,2)\) 和到直线 \(y=-2\) 距离相等的点，轨迹方程是什么？

设 \(P(x,y)\)。到 \(F\) 的距离 \(\sqrt{x^2+(y-2)^2}\)；到直线 \(y=-2\) 的距离 \(|y+2|\)。令它们相等：

\(\sqrt{x^2+(y-2)^2}=|y+2|\)。

两边都不是负数，平方不会多出解：

\(x^2+y^2-4y+4=y^2+4y+4\)，

化简得 \(x^2=8y\)。焦点在准线上方，开口向上，和方程对得上。

自己试试：到点 \(F(0,1)\) 和到直线 \(y=-1\) 距离相等的点，轨迹方程是？

A。\(\sqrt{x^2+(y-1)^2}=|y+1|\)，平方得 \(x^2-2y+1=2y+1\)，即 \(x^2=4y\)。选 B 是把焦点到原点的距离 \(1\) 当成了 \(p\)；\(p\) 是焦点到准线的距离 \(2\)，所以 \(2p=4\)。选 C 是轴搞反了；选 D 是开口方向反了，焦点在上方，开口向上。

3. 四种标准方程：先定开口，再定 \(p\)

让顶点在原点、对称轴是坐标轴，按开口方向有四种标准方程（\(p>0\) 是焦准距）：

标准方程 开口 焦点 准线
\(y^2 = 2px\) 向右 \(\left(\dfrac{p}{2}, 0\right)\) \(x = -\dfrac{p}{2}\)
\(y^2 = -2px\) 向左 \(\left(-\dfrac{p}{2}, 0\right)\) \(x = \dfrac{p}{2}\)
\(x^2 = 2py\) 向上 \(\left(0, \dfrac{p}{2}\right)\) \(y = -\dfrac{p}{2}\)
\(x^2 = -2py\) 向下 \(\left(0, -\dfrac{p}{2}\right)\) \(y = \dfrac{p}{2}\)

为什么是 \(\dfrac p2\)：顶点在焦点和准线正中间，焦点和准线到顶点各占焦准距的一半。四种只是把坐标轴换了方向，道理都一样。

① 看一次项定轴和开口：一次项是 \(x\)，对称轴是 \(x\) 轴；一次项是 \(y\)，对称轴是 \(y\) 轴。系数正，开口朝正方向；系数负，朝负方向。
② 一次项系数是 \(\pm2p\)：除以 \(2\) 得 \(p\)，除以 \(4\) 得焦点坐标里那个数 \(\pm\dfrac p2\)。
③ 先把平方项系数化成 \(1\) 再看。

例 2

（1）求 \(y^2 = 12x\) 的焦点和准线。

一次项是 \(x\)，系数 \(12>0\)，开口向右。\(2p=12\)，\(p=6\)，\(\dfrac p2=3\)。焦点 \(F(3,0)\)，准线 \(x=-3\)。

（2）反过来：焦点是 \((0,-3)\)，求抛物线的标准方程。

焦点在 \(y\) 轴负半轴，开口向下，形如 \(x^2=-2py\)。\(\dfrac p2=3\)，\(p=6\)，所以 \(x^2=-12y\)。

自己试试：抛物线 \(x^2 = -8y\) 的焦点坐标是？

B。一次项是 \(y\)，对称轴是 \(y\) 轴；系数 \(-8<0\)，开口向下。\(2p=8\)，\(\dfrac p2=2\)，焦点 \((0,-2)\)。

选 A 是轴搞错了；选 C 是只除了 \(2\)，把 \(p\) 当成了焦点坐标；选 D 是直接抄了一次项系数。

4. 焦半径：到焦点的距离换成到准线的距离

抛物线上的点，到焦点的距离要开根号算，到准线的距离只要坐标相减。定义说两者相等，所以遇到 \(|PF|\)，先换成到准线的距离。

\(y^2=2px\) 上的点 \(P(x_0,y_0)\)：\(|PF|=x_0+\dfrac p2\)。
其余三种同理：\(P\) 到准线的距离就是 \(|PF|\)。

为什么：准线是 \(x=-\dfrac p2\)，抛物线上的点 \(x_0\ge0\)，到准线的距离是 \(x_0-\left(-\dfrac p2\right)=x_0+\dfrac p2\)。

求 \(|PA|+|PF|\) 这类最小值也靠它：换成「\(A\) 到 \(P\)，再到准线」，一条折线，拉直了最短。

例 3

\(y^2 = 4x\) 的焦点为 \(F\)，点 \(A(3, 2)\)，\(P\) 在抛物线上动。求 \(|PA| + |PF|\) 的最小值。

\(2p=4\)，\(p=2\)，焦点 \(F(1, 0)\)，准线 \(x=-1\)。设 \(P\) 到准线的垂足为 \(H\)，由定义 \(|PF|=|PH|\)，所以

\(|PA| + |PF| = |PA| + |PH|\)。

先看 \(A\) 在哪：\(x=3\) 时抛物线上 \(y^2=12\)，而 \(2^2=4<12\)，\(A\) 在抛物线里面（焦点那一侧）。

\(|PA|+|PH|\) 是从 \(A\) 经 \(P\) 走到准线的折线长，不会短于 \(A\) 到准线的距离 \(3-(-1)=4\)。过 \(A\) 作准线的垂线 \(y=2\)，交抛物线于 \(P(1,2)\)，这时 \(A,P,H\) 在一条直线上，\(|PA|+|PH|=2+2=4\)，取到了。

所以最小值是 \(4\)，在 \(P(1,2)\) 时取到。

自己试试：抛物线 \(y^2 = 6x\) 上一点 \(P\) 到焦点的距离是 \(5\)，\(P\) 的横坐标是？

A。\(2p=6\)，\(p=3\)，准线 \(x=-\dfrac32\)。\(|PF|=x_0+\dfrac32=5\)，\(x_0=\dfrac72\)。选 B 是减了 \(p=3\)，该减的是 \(\dfrac p2\)；选 C 是加反了；选 D 是把到焦点的距离直接当成了横坐标。

5. 用之前要注意

  1. 定点不能在定直线上，否则得不到抛物线。
    反例：到 \(F(0,0)\) 和到直线 \(y=0\) 距离相等：\(\sqrt{x^2+y^2}=|y|\)，平方得 \(x^2=0\)，轨迹是直线 \(x=0\)（过 \(F\) 垂直于 \(l\) 的直线），不是抛物线。
  2. \(2p\) 不是焦点坐标，\(p\) 也不是，焦点离顶点 \(\dfrac p2\)。
    反例：\(y^2=12x\) 的焦点是 \((3,0)\)，不是 \((12,0)\)，也不是 \((6,0)\)。
  3. 平方项系数不是 \(1\) 时先化。
    反例：\(y=\dfrac14x^2\)，直接拿 \(\dfrac14\) 除以 \(4\) 会得到 \(\dfrac1{16}\)；先化成 \(x^2=4y\)，焦点是 \((0,1)\)。
  4. 焦半径公式随开口变，算出来必须是正数。
    反例：\(x^2=-8y\) 上 \(y_0=-3\) 的点，准线 \(y=2\)，\(|PF|=2-(-3)=5\)；照搬「\(y_0+\dfrac p2\)」得 \(-1\)，距离不会是负的。
  5. 求 \(|PA|+|PF|\) 的最小值，先看 \(A\) 在抛物线里面还是外面。
    反例：\(y^2=4x\)，\(A(1,4)\)：\(4^2=16>4\times1\)，\(A\) 在外面。从 \(A\) 到准线的垂线段碰不到抛物线，最小值不是 \(A\) 到准线的距离 \(2\)。这时直接用 \(|PA|+|PF|\ge|AF|=4\)，\(P\) 取线段 \(AF\) 与抛物线的交点 \((1,2)\) 时取到。
  6. 由距离列方程，平方前看两边是否都不是负数。例 1 里两边都是距离，平方不会多出解；绝对值里的式子要保留，不能随手去掉。
一句话：抛物线上点到焦点的距离，等于到准线的距离。定方程看开口和 \(p\)，算距离换成到准线。
再深一点（可以先跳过）

离心率：椭圆、双曲线上的点到焦点的距离与到对应准线的距离之比是定值 \(e\)。抛物线这两个距离相等，所以 \(e=1\)。

通径：过焦点、垂直于对称轴的弦。对 \(y^2=2px\)，把 \(x=\dfrac p2\) 代入得 \(y^2=p^2\)，\(y=\pm p\)，通径长 \(2p\)。\(p\) 越大，开口越宽。

光学性质（阅读）：平行于对称轴射来的光，在抛物线上反射后都经过焦点；反过来，焦点处的光源反射出去是平行光。这就是开头卫星天线、车灯的道理。它的证明要用到切线，本节不要求。

① 焦半径与准线等距折射微实验室

拖动抛物线上的动点 \(P\)（或选中后按键盘方向键），观察焦半径 \(PF\) 与到准线的垂线段 \(PH\)。切换 4 种开口方向或调节焦准距 \(p\)，体会等距性质。开启「光路演示」可查看平行光反射会聚于焦点 \(F\) 的动态光束。

从易到难排好了。前两道直接用，后三道防掉坑。

直接用

1. 已知抛物线方程为 \(y^2 = 8x\)，则该抛物线的焦点坐标与准线方程分别为？

A。一次项为 \(x\)，系数为 \(8 > 0\)，开口向右，焦点在 \(x\) 轴正半轴。

牢记核心法则：一次项系数除以 4 得到焦点坐标，\(\dfrac{8}{4} = 2\)，因此焦点为 \((2, 0)\)；除以 2 得到焦准距 \(p = 4\)，因此准线方程为 \(x = -2\)。

选 B 的同学除以了 2；选 C 搞错了坐标轴；选 D 则是直接抄了一次项系数。

2. 已知抛物线 \(x^2 = 4y\) 上有一点 \(P(x_0, 3)\)，则点 \(P\) 到该抛物线焦点的距离 \(|PF|\) 为？

B。直接用焦半径公式与准线转化！抛物线 \(x^2 = 4y\) 中 \(2p = 4 \implies p = 2\)，\(\dfrac{p}{2} = 1\)。准线方程为 \(y = -1\)。

由抛物线定义，曲线上点 \(P\) 到焦点的距离直接等于它到准线的垂直距离：\(|PF| = d(P, l) = y_0 - (-1) = 3 + 1 = 4\)。完全不需要求出 \(x_0\) 的具体数值！

易错

3. 抛物线 \(y = 2x^2\) 的焦点坐标是？

B。易错陷阱：非标准方程先化标！绝不能直接把 \(2\) 除以 4！标准方程中平方项系数必须是 1：将 \(y = 2x^2\) 两边同除以 2，化为标准形式 \(x^2 = \dfrac{1}{2}y\)。

此时一次项是 \(y\)，系数为 \(\dfrac{1}{2}\)，开口向上，焦点在 \(y\) 轴上。再将一次项系数除以 4：\(\dfrac{1/2}{4} = \dfrac{1}{8}\)，焦点坐标为 \(\left(0, \dfrac{1}{8}\right)\)。选 A 是直接拿 2 除以 4；选 C 是搞错了焦点所在轴。

4. 平面内到定点 \(F(1, 0)\) 的距离等于到定直线 \(l: x = 1\) 的距离的点的轨迹是？

C。易错陷阱：定点在定直线上时的轨迹退化！抛物线定义严格要求定点不在定直线上（\(F \notin l\)）。

本题中定点 \(F(1, 0)\) 恰好就在直线 \(l: x = 1\) 上！设动点 \(P(x, y)\)，它到直线 \(l\) 的垂足为 \(H(1, y)\)。由 \(|PF| = |PH|\) 得 \(\sqrt{(x-1)^2 + y^2} = |x-1|\)，两边平方即得 \((x-1)^2 + y^2 = (x-1)^2 \implies y^2 = 0 \implies y = 0\)。轨迹是过点 \(F\) 且垂直于 \(l\) 的一条直线（即 \(x\) 轴），并不存在抛物线！

5. 已知抛物线 \(C: y^2 = 4x\) 的焦点为 \(F\)，点 \(A(4, 2)\)，\(P\) 为抛物线 \(C\) 上的动点，则 \(|PA| + |PF|\) 的最小值是？

B。解题神器：准线转化破最值！抛物线 \(y^2 = 4x\) 的焦点为 \(F(1, 0)\)，准线为 \(l: x = -1\)。由定义，\(|PF| = d(P, l)\)（\(P\) 到准线的距离）。

所以 \(|PA| + |PF| = |PA| + d(P, l)\)。由垂线段最短，当过 \(A\) 作准线 \(l\) 的垂线交抛物线于 \(P\) 时，折线段化为直线段，取得最小值，最小值为点 \(A\) 到准线的距离：\(x_A - (-1) = 4 - (-1) = 5\)。

若误连 \(AF\) 算两点距离 \(\sqrt{(4-1)^2 + 2^2} = \sqrt{13} \approx 3.6\)（选 D），由于点 \(A\) 在抛物线内部，线段 \(AF\) 根本不与抛物线相交，动点 \(P\) 绝不可能落在线段 \(AF\) 上！
