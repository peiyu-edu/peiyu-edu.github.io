2.1 直线的倾斜角与斜率

一条直线有多「斜」？可以用一个角说，也可以用一个数说。有了这个数，两条直线平不平行、垂不垂直，算一算就知道。先从坡道开始。

四段坡道，量了每段「水平走了多远」和「升高了多少」：

哪一段最陡？

比一比「每水平走 \(1\) 米升高多少」：A 是 \(\dfrac{2}{10}=0.2\)，B 是 \(\dfrac14=0.25\)，C 是 \(\dfrac25=0.4\)，D 是 \(\dfrac18=0.125\)。C 最陡。

只看升高多少不行（A 和 C 都升 \(2\) 米），要看「升高 ÷ 水平」这个比。坡越陡，这个比越大，坡和地面的夹角也越大。

把坡道换成坐标系里的直线：那个夹角叫倾斜角，那个比叫斜率。这一节讲这两样，再用斜率判断两条直线平行、垂直。

1. 先认识几个词

要用到：任意角和正切 \(\tan\alpha\)，以及 \(30^\circ,45^\circ,60^\circ,120^\circ,135^\circ,150^\circ\) 的正切值（回看 5.2 三角函数的概念）；坐标系里两点的坐标差（回看 6.3 向量的坐标表示）。

倾斜角：直线和 \(x\) 轴相交时，从 \(x\) 轴的正方向出发，绕交点逆时针转，转到和直线重合，转过的最小角叫倾斜角，记作 \(\alpha\)。和 \(x\) 轴平行或重合的直线，规定 \(\alpha=0^\circ\)。

例：\(y=x\) 这条线往右上走，倾斜角 \(45^\circ\)；\(y=-x\) 往右下走，从 \(x\) 轴正方向逆时针转 \(135^\circ\) 才和它重合，倾斜角是 \(135^\circ\)，不是 \(45^\circ\)。

转半圈 \(180^\circ\) 直线就回到原样了，所以倾斜角只在 \(0^\circ\le\alpha<180^\circ\) 里取，即 \(\alpha\in[0,\pi)\)。

正切：\(\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}\)，在 \(\cos\alpha\ne0\) 时才有意义。

例：\(\tan45^\circ=1\)，\(\tan60^\circ=\sqrt3\)，\(\tan120^\circ=-\sqrt3\)，\(\tan135^\circ=-1\)。而 \(\cos90^\circ=0\)，\(\tan90^\circ\) 没有意义。

竖直线、水平线：所有点横坐标都一样的直线是竖直线，倾斜角 \(90^\circ\)；所有点纵坐标都一样的是水平线，倾斜角 \(0^\circ\)。

例：过 \((2,1)\) 和 \((2,5)\) 的直线是竖直线（横坐标都是 \(2\)）；过 \((-1,3)\) 和 \((4,3)\) 的是水平线（纵坐标都是 \(3\)）。

2. 斜率：倾斜角的正切

倾斜角 \(\alpha\ne90^\circ\) 时，把 \(\tan\alpha\) 叫这条直线的斜率，记作 \(k\)。

\(k=\tan\alpha\)（\(\alpha\ne90^\circ\)）。\(\alpha=90^\circ\) 的竖直线，斜率不存在。

为什么用正切：在直线上往右走 \(1\)，竖直方向变了多少，就是 \(\tan\alpha\)——这正是坡道里「升高 ÷ 水平」的那个比。\(\alpha\) 在 \(0^\circ\) 到 \(90^\circ\) 之间，直线往右上走，\(k>0\)；在 \(90^\circ\) 到 \(180^\circ\) 之间，往右下走，\(k<0\)；水平线 \(k=0\)。

例 1（看一遍怎么写）

(1) 倾斜角 \(120^\circ\) 的直线，斜率是多少？(2) 斜率为 \(1\) 的直线，倾斜角是多少？

(1) \(k=\tan120^\circ=-\tan60^\circ=-\sqrt3\)。

(2) 要 \(\tan\alpha=1\)，且 \(0^\circ\le\alpha<180^\circ\)。在这个范围里只有 \(\alpha=45^\circ\)（\(225^\circ\) 的正切也是 \(1\)，但不在范围里）。所以 \(\alpha=45^\circ\)。

自己试试：倾斜角为 \(150^\circ\) 的直线，斜率是？

B。\(\tan150^\circ=-\tan30^\circ=-\dfrac{\sqrt3}{3}\)。\(150^\circ\) 比 \(90^\circ\) 大，直线往右下走，斜率一定是负的，A 不对；C 是 \(\tan120^\circ\)，把 \(30^\circ\) 和 \(60^\circ\) 记混了。

3. 已知两点，求斜率

直线过 \(P_1(x_1,y_1)\)、\(P_2(x_2,y_2)\)，从 \(P_1\) 走到 \(P_2\)，横向走了 \(x_2-x_1\)，竖向走了 \(y_2-y_1\)。两者的比就是斜率：

\(k=\dfrac{y_2-y_1}{x_2-x_1}\)，要求 \(x_1\ne x_2\)。

两个点谁当 \(P_1\) 都行：分子分母同时变号，比不变。但分子、分母里的点要同一个顺序。

例 2

求过 \(A(-1,3)\)、\(B(2,0)\) 的直线的斜率和倾斜角。

\(x_1=-1\ne2=x_2\)，可以用公式：\(k=\dfrac{0-3}{2-(-1)}=\dfrac{-3}{3}=-1\)。

要 \(\tan\alpha=-1\)，\(0^\circ\le\alpha<180^\circ\)，得 \(\alpha=135^\circ\)。检查：从 \(A\) 到 \(B\) 往右走、往下降，确实是往右下走的直线。

自己试试：过 \(P(2,-1)\)、\(Q(-1,5)\) 的直线，斜率是？

B。\(k=\dfrac{5-(-1)}{-1-2}=\dfrac{6}{-3}=-2\)。选 A 的同学分子用了 \(Q\) 减 \(P\)、分母用了 \(P\) 减 \(Q\)，顺序没对齐；选 C 是把横纵坐标的差上下放反了。

4. 用斜率判断平行

两条直线平行，它们的倾斜角相等；倾斜角都不是 \(90^\circ\) 时，正切也相等，就是斜率相等。反过来，斜率相等则倾斜角相等，两条线方向一样——但方向一样的可能是同一条线。

两条直线斜率都存在且不重合：\(l_1\parallel l_2\iff k_1=k_2\)。
两条都是竖直线且不重合，也平行。

例 3

\(l_1\) 过 \(A(0,1)\)、\(B(2,5)\)，\(l_2\) 过 \(C(1,0)\)、\(D(3,4)\)。\(l_1\) 与 \(l_2\) 平行吗？

\(k_1=\dfrac{5-1}{2-0}=2\)，\(k_2=\dfrac{4-0}{3-1}=2\)，斜率相等。

再排除重合：看 \(C\) 在不在 \(l_1\) 上。\(A\)、\(C\) 连线的斜率 \(\dfrac{0-1}{1-0}=-1\ne2\)，所以 \(C\) 不在 \(l_1\) 上，两条线不重合。结论：\(l_1\parallel l_2\)。

自己试试：\(l_1\) 过 \((0,0)\)、\((2,2)\)，\(l_2\) 过 \((0,3)\)、\((3,6)\)。两条直线是？

A。\(k_1=\dfrac{2-0}{2-0}=1\)，\(k_2=\dfrac{6-3}{3-0}=1\)。\((0,3)\) 不在 \(l_1\) 上（\(l_1\) 上横坐标为 \(0\) 的点是原点），不重合，所以平行。常见的漏洞：算出 \(k_1=k_2\) 就写「平行」，忘了查重合——这题碰巧对了，练一练里有一道碰不巧的。

5. 用斜率判断垂直

斜率为 \(k\) 的直线，往右走 \(1\)、往上走 \(k\)，方向可以用向量 \((1,k)\) 表示。两条直线垂直，就是两个方向向量垂直，数量积为 \(0\)：\((1,k_1)\cdot(1,k_2)=1+k_1k_2=0\)。

两条直线斜率都存在：\(l_1\perp l_2\iff k_1k_2=-1\)。
一条竖直、一条水平：也垂直（这时没法写 \(k_1k_2\)）。

例 4

\(l_1\) 的斜率是 \(2\)，\(l_2\) 过 \(O(0,0)\)、\(M(2,-1)\)。两条直线垂直吗？

\(k_2=\dfrac{-1-0}{2-0}=-\dfrac12\)，\(k_1k_2=2\times\left(-\dfrac12\right)=-1\)，所以 \(l_1\perp l_2\)。

自己试试：\(l_1\) 的斜率是 \(-3\)，\(l_2\perp l_1\)，\(l_2\) 的斜率是？

B。\(-3\cdot k_2=-1\)，\(k_2=\dfrac13\)。垂直的斜率是「倒数再变号」：选 C 只取了倒数，选 A 只变了号，选 D 是平行时的斜率。

6. 用之前，查这几件事

  1. 倾斜角只在 \([0^\circ,180^\circ)\) 里。
    反例：「水平线的倾斜角是 \(180^\circ\)」不对，规定是 \(0^\circ\)；\(\tan\alpha=1\) 也只能得 \(\alpha=45^\circ\)，不能写 \(225^\circ\)。
  2. 每条直线都有倾斜角，但不一定有斜率：\(\alpha=90^\circ\) 时斜率不存在。
    反例：竖直线 \(x=2\) 倾斜角是 \(90^\circ\)，\(\tan90^\circ\) 没有意义，它没有斜率。说「斜率无穷大」也不对，是「不存在」。
  3. 两点公式要 \(x_1\ne x_2\)。
    反例：\((2,1)\)、\((2,5)\) 代进去分母是 \(2-2=0\)，算不出来——这条线是竖直的，斜率不存在，先看横坐标再套公式。
  4. 斜率相等不一定平行，可能重合。
    反例：过 \((0,0)\)、\((1,1)\) 和过 \((2,2)\)、\((3,3)\) 的两条线，斜率都是 \(1\)，其实是同一条线 \(y=x\)。要再取一条线上的点，看它在不在另一条上。
  5. \(k_1k_2=-1\) 只管两条都有斜率的情形。
    反例：竖直线 \(x=1\) 和水平线 \(y=2\) 垂直，可前者没有斜率，乘不出 \(-1\)。不能因为「算不了 \(k_1k_2\)」就说不垂直。
判断两条直线的关系，先看有没有竖直线：都竖直 → 平行或重合；一竖一横 → 垂直；一竖一斜 → 相交不垂直。都不竖直，再比 \(k_1\)、\(k_2\)。
再深一点（可以先跳过）

倾斜角越大，斜率不一定越大：\(\alpha\) 从 \(0^\circ\) 增到 \(90^\circ\)，\(k\) 从 \(0\) 一直变大；一过 \(90^\circ\)，\(k\) 变成负数，再增到 \(180^\circ\) 时回到 \(0\)。例如 \(\alpha=30^\circ\) 时 \(k\approx0.58\)，\(\alpha=120^\circ\) 时 \(k\approx-1.73\)。只在同一段（都锐角或都钝角）里才是「角大斜率大」。

三点共线：\(A\)、\(B\)、\(C\) 横坐标两两不同时，「\(AB\) 的斜率 \(=AC\) 的斜率」就说明三点在同一条线上（两条线方向一样又都过 \(A\)，只能重合）。例 3 查重合用的就是这个。

方向向量：直线上任取两点 \(P_1\)、\(P_2\)，\(\overrightarrow{P_1P_2}=(x_2-x_1,y_2-y_1)\) 叫它的一个方向向量。斜率存在时，\((1,k)\) 也是方向向量。竖直线的方向向量是 \((0,1)\)，用方向向量判断平行、垂直，竖直线不用单独处理。

① 拖两个点，看倾斜角和斜率

拖动 \(A\)、\(B\)（或选中后按方向键，每次一格），直线跟着变。金色角是倾斜角 \(\alpha\)，三角形两条直角边是横向差 \(\Delta x\)、竖向差 \(\Delta y\)。把 \(B\) 拖到 \(A\) 正上方看看。

② 进阶：两条直线，平行、垂直还是重合

\(l_1\) 过 \(A\)、\(B\)（绿），\(l_2\) 过 \(C\)、\(D\)（金棕）。四个点都能拖、都能用方向键。试着摆出平行、垂直、重合，也试试一条竖直、一条水平。下面的按钮直接摆好一种。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 过 \(A(-2,1)\)、\(B(1,4)\) 的直线，斜率和倾斜角是？

A。\(k=\dfrac{4-1}{1-(-2)}=\dfrac33=1\)，\(\tan\alpha=1\) 且 \(0^\circ\le\alpha<180^\circ\)，\(\alpha=45^\circ\)。B 的角和斜率对不上（\(\tan135^\circ=-1\)）；D 只算了 \(4-1\)，忘了除以横向差。

2. 直线 \(l_1\) 的斜率是 \(2\)，\(l_2\) 过 \(P(1,1)\)、\(Q(3,a)\)。\(l_1\perp l_2\)，则 \(a=\)？

A。\(P\)、\(Q\) 横坐标不同，\(k_2=\dfrac{a-1}{3-1}=\dfrac{a-1}{2}\)。垂直要 \(2\cdot\dfrac{a-1}{2}=-1\)，\(a-1=-1\)，\(a=0\)。选 C 的同学按平行算了（\(\dfrac{a-1}{2}=2\)）。

易错

3. 下面说法正确的是？

C。A 错：竖直线倾斜角 \(90^\circ\)，没有斜率——每条直线都有倾斜角，不一定有斜率。B 错：要 \(x_1\ne x_2\)，比如 \((2,1)\)、\((2,5)\) 分母是 \(0\)。D 错：\(30^\circ\) 的斜率约 \(0.58\)，\(120^\circ\) 的斜率约 \(-1.73\)，角大了斜率反而小。

4. \(l_1\) 过 \(A(0,1)\)、\(B(1,3)\)，\(l_2\) 过 \(C(2,5)\)、\(D(3,7)\)。\(l_1\) 与 \(l_2\) 的关系是？

B。\(k_1=\dfrac{3-1}{1-0}=2\)，\(k_2=\dfrac{7-5}{3-2}=2\)，斜率相等。但 \(A\)、\(C\) 连线的斜率 \(\dfrac{5-1}{2-0}=2\)，也是 \(2\)，说明 \(C\) 在 \(l_1\) 上：四个点在同一条线上，是重合，不是平行。斜率相等只说明方向一样，还要排除重合。在「动手」②里点「重合」看一看。

5. \(l_1\) 过 \((2,1)\)、\((2,5)\)，\(l_2\) 过 \((-1,3)\)、\((4,3)\)。\(l_1\) 与 \(l_2\) 的关系是？

B。\(l_1\) 横坐标都是 \(2\)，是竖直线；\(l_2\) 纵坐标都是 \(3\)，是水平线。一竖一横，垂直。\(k_1k_2=-1\) 只管两条都有斜率的情形，算不了它不代表不垂直，要先看有没有竖直线。

挑战

6. \(l_1\) 过 \(A(m,1)\)、\(B(-1,m)\)，\(l_2\) 过 \(P(1,2)\)、\(Q(-5,0)\)。\(l_1\parallel l_2\)，则 \(m=\)？

A。\(k_2=\dfrac{0-2}{-5-1}=\dfrac13\)，\(l_2\) 有斜率，所以 \(l_1\) 也得有：\(m\ne-1\)（\(m=-1\) 时 \(A(-1,1)\)、\(B(-1,-1)\) 竖直，不可能和 \(l_2\) 平行，C 错在这里）。

\(k_1=\dfrac{m-1}{-1-m}=\dfrac13\)，交叉相乘 \(3m-3=-1-m\)，\(m=\dfrac12\)。再排除重合：\(A\left(\dfrac12,1\right)\)，\(P\)、\(A\) 连线斜率 \(\dfrac{1-2}{\frac12-1}=2\ne\dfrac13\)，\(A\) 不在 \(l_2\) 上，确实平行。选 B 的同学按垂直列了式（\(\dfrac{m-1}{-1-m}=-3\)）。
