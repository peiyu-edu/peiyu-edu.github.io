01 · 核心定理、公式与阶段边界
先梳理等式，再类比不等式：等式可以交换两边：a=b  ⟺  b=aa=b\iff b=aa=b⟺b=a；也有传递性：a=b, b=c⇒a=ca=b,\ b=c\Rightarrow a=ca=b, b=c⇒a=c。若 a=ba=ba=b，两边同加同减一个数仍相等，a±c=b±ca\pm c=b\pm ca±c=b±c；同乘任意实数也有 ac=bcac=bcac=bc。同除则必须 c≠0c\ne0c=0，才有 ac=bc\dfrac ac=\dfrac bcca​=cb​。后面研究不等式时，重点检查这些运算怎样影响大小顺序。

a−b>0  ⟺  a>ba - b > 0 \iff a > ba−b>0⟺a>b：从 bbb 往右走到 aaa。

a−b=0  ⟺  a=ba - b = 0 \iff a = ba−b=0⟺a=b：两点重合。

a−b<0  ⟺  a<ba - b < 0 \iff a < ba−b<0⟺a<b：从 bbb 往左走到 aaa。

不等式三大黄金法则：
• 同加、同减：方向永远不变\color{#2F7A56}{\text{方向永远不变}}方向永远不变（两边加任何正数、负数或零，相对距离一点不变）。
• 同乘、同除：必须先看这个数的符号！ - 乘正数（c>0c>0c>0）：方向不变\color{#2F7A56}{\text{方向不变}}方向不变；
- 乘负数（c<0c<0c<0）：方向必须反过来！\color{#B5452F}{\text{方向必须反过来！}}方向必须反过来！
- 乘零（c=0c=0c=0）：两边都变成 000 相等，原来的严格大于号或小于号不能保留；除数绝不能为 000。
