1. 先试一题

实数数列 {an​} 的前 n 项和为 Sn​=2n2+5n+4，此式对每个正整数 n 成立。哪一项给出了完整通项？

相邻差公式给出了后续项，但不能把只对正整数有效的 Sn​ 表达式代到零；首项应直接由 S1​ 得到。

正确。首项直接算，后续项用相邻差；还应把它们加回去验证原前缀。

常数项不是首项。首项是 S1​=2+5+4。

这里混淆了前缀和与单项；从第二项起应取相邻两个前缀的差。

卡住了，给我一点提示

先写 a1​=S1​，再在 n≥2 的范围计算 Sn​−Sn−1​。

写完了，对照完整解答与条件

a1​=S1​=2+5+4=11。当 n≥2 时，n−1≥1，题给表达式可用于两个前缀，故 an​=[2n2+5n+4]−[2(n−1)2+5(n−1)+4]=4n+3。验证：∑k=1n​(4k+3)=2n2+5n，而实际首项比该统一公式在 k=1 的值 7 大 4，故实际前缀为 2n2+5n+4，包括 n=1。前缀值唯一确定每项，因此没有其他通项。

作差得到的公式先写适用范围，能否覆盖首项要另验。

2. 换条件应用

另一实数数列的前 n 项和为 Sn​=2n2+5n，对所有正整数 n 成立。它的完整通项是哪一项？

正确。相邻差不变，但这次首项也符合差分公式，所以可以统一。

上一题首项比这里多 4；条件改变后应重新计算 S1​，不能沿用首项。

展开相邻平方之差时，2[n2−(n−1)2]=4n−2，再加 5，常数应为 3。

把 Sn​ 除以 n 得到的是前 n 项的平均值，通常不是第 n 项。

卡住了，给我一点提示

比较两题：相邻差里的常数抵消，首项却会变化。检验 n=1 能否并入。

写完了，对照完整解答与条件

直接得到 a1​=S1​=7。对 n≥2，相邻差为 an​=2[n2−(n−1)2]+5=4n+3。把 n=1 代入这个候选式也得 7，所以可统一为 an​=4n+3，n≥1。反向求和得 4⋅n(n+1)/2+3n=2n2+5n，对所有正整数都与条件一致。

统一通项需要首项验证通过；不能因为式子简洁便自动推广指标范围。

回到学习路线继续：辨析条件差异

3. 辨析条件差异

设 c∈R，某实数数列的前 n 项和满足 Sn​=2n2+5n+c（所有正整数 n）。“an​=4n+3 对所有正整数 n 成立”的充要条件是哪一项？

常数抵消只用于 n≥2。首项是 7+c，必须和统一式在 n=1 的值比较。

非负并不能使首项自动等于 7；例如 c=1 时首项为 8。

正确。首项给必要条件 7+c=7；取 c=0 后求和验证给充分性。

首项总要检查，但检查后可能与后续公式一致；c=0 正是可以统一的情形。

卡住了，给我一点提示

先只看 n=1 推出必要条件，再说明该条件确实保证所有指标成立。

写完了，对照完整解答与条件

无论 c 为何，a1​=S1​=7+c；n≥2 时相邻差总为 4n+3。若所有正整数指标都满足同一公式，特别在 n=1 时必须有 7+c=7，故 c=0。反之，取 c=0，前一题已逐项得到首项为 7，后续为 4n+3；求和也得 Sn​=2n2+5n，所以条件充分。任意实数 c 都能定义一个合法实数数列，只是 c=0 时首项必须单列；这不是数列不存在。

前缀表达式加常数只改变首项；“可定义数列”和“可统一通项”是两个判断。

4. 换题验证

实数数列满足 Tn​=∑k=1n​kak​=n(n+2)+6，对每个正整数 n 成立。a1​ 与 a3​ 分别是多少？

后续项的处理对了，但把前缀常数在首项中也消去了。应直接使用 T1​=a1​。

首项对了。相邻差 T3​−T2​=7 等于 3a3​，还要除以权重 3。

首项对了，但 T3​=21、T2​=14，差是 7；常数 6 在相邻差中抵消。

正确。先取首项，再认清加权差分抽出的是 nan​，而非 an​。

卡住了，给我一点提示

把 Tn​−Tn−1​ 左边也展开，看看相消后末项是否带系数。

写完了，对照完整解答与条件

T1​=1⋅a1​=1(1+2)+6=9，所以 a1​=9。对 n≥2，两相邻加权前缀相减得到 nan​=Tn​−Tn−1​=(n2+2n+6)−[(n−1)2+2(n−1)+6]=2n+1。由于 n>0，可除以 n，得 an​=2+1/n，故 a3​=7/3。直接核对：T2​=14、T3​=21，所以 3a3​=7。完整回代：若全体指标先取 kak​=2k+1，其和为 n(n+2)；实际首项由 3 增至 9，加回 6 后正好是 n(n+2)+6。此回代对 n=1 也成立。

加权前缀仍用相邻差，但差分先得到加权末项；除去权重后，再与首项拼接。
