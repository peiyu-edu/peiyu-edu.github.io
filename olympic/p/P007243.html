F4解答题解析几何综合

如图所示，在平面直角坐标系 xOy 中，F 是 x 轴正半轴上的一个动点。以 F 为焦点、O 为顶点作抛物线 C。 设 P 是第一象限内 C 上的一点，Q 是 x 轴负半轴上一点，使得 PQ 为 C 的切线，且 ∣PQ∣=2。 圆 C1​,C2​ 均与直线 OP 相切于点 P，且均与 x 轴相切。 求点 F 的坐标，使圆 C1​ 与 C2​ 的面积之和取得最小值。

作答

解析

提示

先用抛物线切线确定 Q 与 P 的横坐标关系，再用 ∣PQ∣=2 消去焦点参数。

思路

两圆均在 x 轴上方，其圆心纵坐标等于半径；切于 OP 的条件随后统一给出两个半径。

解答

设 F=(h,0)，h>0，则抛物线为 y2=4hx。记 P=(u,v)，其中 u,v>0，于是 v2=4hu。 抛物线在 P 处的切线为 vy=2h(x+u)，与 x 轴交于 Q=(−u,0)。由 ∣PQ∣=2，

4u2+v2=4,0<u<1,h=u1−u2​.(1)

记 L=OP=u2+v2​。任一所求圆过第一象限的点 P 且与 x 轴相切，所以圆心在 x 轴上方；可将圆心写为 (X,R)，其中 R>0 是半径。 该圆与 OP 相切于 P，故圆心到 P 的向量垂直于 (u,v)，并且 P 在圆上，从而

uX+vR=L2,(X−u)2+(R−v)2=R2.

利用第一式消去第二式中的 vR，得到 X2=L2。因此两圆的半径分别为

R1​=vL(L+u)​,R2​=vL(L−u)​.(2)

因为 L>u>0、v>0，两者均为正；代回两式可知它们确实给出所求的两个圆，没有引入多余解。 两圆面积和为 π(R12​+R22​)，由 (1)、(2)，

R12​+R22​=v22(u2+v2)(2u2+v2)​=1−u2(4−3u2)(2−u2)​.

令 t=1−u2∈(0,1)，则

R12​+R22​=4+3t+t1​≥4+23​.

等号当且仅当 t=1/3​，它属于 (0,1)。此时

h=1−t​t​=3−3​​1​.

反过来，取该 t，再按 u=1−t​、v=2t​ 及 (1)、(2) 构造抛物线和两圆，全部正性、切线及 ∣PQ∣=2 条件均成立。 所以所求点为

F=(3−3​​1​,0)​.

此时面积和的最小值为 (4+23​)π。

复核

式 (2) 给出的圆心分别为 (−L,R1​) 与 (L,R2​)，相应半径向量均与 OP 垂直，且圆心高度等于半径，故同时满足两种相切条件。图中取 h=u=1/2​、v=2​，是满足题设的示意构型；求最值使用的是完整参数范围。

方法总结

一个点同时是圆与固定直线的切点时，先用半径垂直切线表示圆心。再结合圆心到另一切线的距离等于半径，往往能统一求出两个圆；求最值后要把等号变量还原为原始焦点。

为什么评为 F4（会透露解法方向）

先由抛物线切线和定长约束消去焦点参数，再完整刻画两圆半径，最后在合法参数区间求最值并回代构造，多项实质判断相互依赖。

核心工具：参数族消元、定点与精确轨迹、切点与一阶接触的线性方程
