直线与圆的综合题，常要在方程、距离和角度之间选择最省变量的表达。先把圆心、半径、交点是否不同和动点范围写清，再用对称、根的和积、点积或圆族消去多余坐标。最值不仅要估计，还要找出满足原构型的等号点；切线极限也不一定属于割线题的可取范围。

知识要点

配方与直径先固定圆心半径

圆 x2+y2+Dx+Ey+F=0 的圆心为 (−D/2,−E/2)，半径平方为 (D2+E2)/4−F，须为正才是通常的圆。例：x2+y2−4x+6y−12=0 的圆心为 (2,−3)、半径为 5。直径端点已知时取其中点与半端点距；也可直接用 (X−A)⋅(X−B)=0 写圆。

点到圆先分清最近与最远

半径为 r>0 的圆与点 P 的圆心距为 d 时，最近距离是 ∣d−r∣，最远距离是 d+r。例：半径 2、圆心原点，P=(3,0) 时两值为 1,5；P=(1,0) 时为 1,3。若两个圆上的动点可分别选择，应先固定 P 各自取极值，再处理 P 的限制，并检查能否同时取等。

交点用根的和积，割线用严格判别式

把直线写成 X=X0​+tv 后代入圆，可将两交点变成同一个二次方程的根；目标只含坐标和或乘积时无需分别求根。例：从 (2,0) 沿 (−1,k) 交单位圆，参数方程为 (1+k2)t2−4t+3=0，两根不同要求 ∣k∣<1/3​。切线对应等号，应与真割线的开区间区别。

点幂依赖同一直线及有向次序

若方向向量为单位向量，圆心为 O、半径为 r，过 P 的交点参数满足 t1​t2​=PO2−r2。例：单位圆外 P=(2,0) 向左割线的参数为 1,3，乘积为 3；过圆心的两根为 −1,1，有向乘积为 −1。改用无向长度时要辨圆内外；三点不共线的距离积不能直接视作点幂。

切点弦与圆族定点都可比较系数

圆 (x−h)2+(y−k)2=r2 的外点 (u,v) 所引切点弦满足 (u−h)(x−h)+(v−k)(y−k)=r2，须先保证确有两条切线。例：圆 x2+(y−1)2=4，外点 (u,−3) 的切点弦为 ux−4y=0，恒过原点。含参数的圆或直线族若写成 F(X)+tG(X)=0，定点应同时满足 F=G=0。

对称要保持距离，降维要证明取等

定点关于限制直线反射后，折线路径可用三角不等式变成直线距离。例：A=(1,2),B=(3,4)，P 在 x 轴上，将 A 反射到 (1,−2)，得 PA+PB≥210​，在 P=(5/3,0) 取等。对称的距离和也是凸函数：一点与其镜像取中点可不增目标，才可把最值限制到对称轴上。

角度先辨点积符号，再用正切或余弦

两条非零向量的点积符号决定锐角、直角、钝角；正切可由叉积绝对值除以点积得到，但跨过直角时不能直接比较正切。例：从 (0,3​) 看 (−1,0),(1,0)，点积为 2、长度积为 4，夹角为 60∘。角度方程平方后须恢复点积符号；非等比伸缩也不保持欧氏角度。

相切、正交与直线相切是不同条件

两个不重合的圆相切用圆心距等于半径和或半径差绝对值；内切还要求半径不同且圆心距为正；相交处切线垂直则用 d2=r12​+r22​。例：半径 1,2 的两圆外切距离为 3、内切距离为 1，正交距离则为 5​，确落在两圆相交范围内。圆与直线相切用圆心到直线的距离等于半径；三条边所在直线的公共切圆还包括旁切圆。

圆心半径与径向距离

圆上点到定点的距离最值，先算定点到圆心的距离。

完整讲解 · 例题 · 可练 8 题

一、是什么

先认识这些量

圆心为 O、半径为 r，定点为 P，记 d=OP。圆上点 X 满足 OX=r。

为什么这样做

三角不等式与反三角不等式给 ∣d−r∣≤PX≤d+r。当 P=O，圆心与定点连线上的两个径向点取到两界。

先看一道例题

例 1：圆外定点

圆 x2+y2=4 上的点到 P=(5,0) 的最近和最远距离？

怎么看出来：

圆心距五、半径二。

解：

最近为 5−2=3，在 (2,0)；最远为 5+2=7，在 (−2,0)。

答案：

3 与 7。

二、什么时候想到它

题目里看到应该想到
已知直径求圆系数，或目标可化成定点到圆上点的最近、最远距离。圆上点到定点的距离最值，先算定点到圆心的距离。
圆 x2+y2=4 上的点到 P=(5,0) 的最近和最远距离？圆心距五、半径二。

三、怎么用

  1. 把圆方程配成标准式。
  2. 求圆心距。
  3. 用半径与圆心距求两界。
  4. 检查径向点是否还满足其他限制。

四、再做一道

例 2：圆内定点

圆 (x−1)2+y2=9 上的点到原点的最近和最远距离？

怎么看出来：

圆心距小于半径，要取差的绝对值。

解：

圆心距为 1，半径 3，最近 ∣1−3∣=2，在 (−2,0)；最远 4，在 (4,0)。

答案：

2 与 4。

五、容易错在哪

  • 圆内点的最近距离是半径减圆心距，不能写成负数。

圆与切点弦的参数系数消元

把圆族方程写成常数部分加参数部分，公共点同时使两部分为零。

完整讲解 · 例题 · 可练 3 题

一、是什么

先认识这些量

圆族是随参数变化的一组圆。一般圆 x2+y2+Dx+Ey+F=0 有实圆的条件为半径平方 (D2+E2)/4−F>0。

为什么这样做

一个点若对每个参数都满足一次参数式，参数系数与常数项必须分别为零。两圆方程相减则消掉二次项得到公共弦直线。

先看一道例题

例 1：公共点

圆族 x2+y2+λx−1=0，求所有公共点。

怎么看出来：

点坐标不能随参数变化。

解：

参数系数给 x=0，常数部分给 y2=1，所以为 (0,1),(0,−1)。半径平方 1+λ2/4>0。

答案：

(0,±1)。

二、什么时候想到它

题目里看到应该想到
动圆恒过定点，或外点沿直线运动而切点弦需要找定点。把圆族方程写成常数部分加参数部分，公共点同时使两部分为零。
圆族 x2+y2+λx−1=0，求所有公共点。点坐标不能随参数变化。

三、怎么用

  1. 整理为参数一次式。
  2. 将参数系数与常数项同时置零。
  3. 解公共点并检验每个圆非退化。
  4. 若只求公共弦，可用两圆相减。

四、再做一道

例 2：公共弦

圆 x2+y2=5 与 x2+y2−2x=1 的公共弦所在直线？

怎么看出来：

相减消二次项。

解：

两式相减得 2x=4，所以 x=2。代回得 y=±1，确有两个交点。

答案：

x=2。

五、容易错在哪

  • 方程相减得到的是公共点所在直线，仍需验证两圆确实有两个交点。

反射、中心对称与对称降维

反射保距离，可将受直线约束的折线长度转成两定点间距离。

完整讲解 · 例题 · 可练 10 题

一、是什么

先认识这些量

关于 x 轴反射把 (u,v) 变成 (u,−v)。轴上点到一对镜像点距离相等。等距变换保持长度。

为什么这样做

将一端反射后，折线和至少为反射点到另一端的直线距离。等号要求轴上的折点确实落在连接线段上。

先看一道例题

例 1：同侧两点

A=(0,1),B=(4,1)，X 在 x 轴上，求 AX+XB 最小值。

怎么看出来：

反射其中一个定点。

解：

A′=(0,−1)，A′B 与轴交于 (2,0)。最小为 A′B=20​=25​。

答案：

25​。

二、什么时候想到它

题目里看到应该想到
动点限制在直线上求距离和，反射像落在指定圆上，截线中点已知，或绝对值曲线按象限对称。反射保距离，可将受直线约束的折线长度转成两定点间距离。
A=(0,1),B=(4,1)，X 在 x 轴上，求 AX+XB 最小值。反射其中一个定点。

三、怎么用

  1. 选择反射轴与被反射点；中心对称时，中心 C 是原像 P 与像点 P′ 的中点，即 P′=2C−P。
  2. 用等距性替换一段距离。
  3. 对新折线用三角不等式。
  4. 求真实交点，核线段次序和其他限制。

四、再做一道

例 2：中心对称

P=(3,−2) 关于 C=(1,1) 的对称点是什么？

怎么看出来：

中心 C 是原像 P=(3,−2) 与像点 P′ 的中点。

解：

P′=2C−P=(−1,4)，两点到中心距离同为 13​。

答案：

(−1,4)。

五、容易错在哪

  • 如果折点只允许在线段上，反射后的交点必须在线段内。

割线参数、根的和积与点幂

圆与直线联立时，用交点参数的根和根积求所需长度。

完整讲解 · 例题 · 可练 4 题

一、是什么

先认识这些量

直线写成 X=P+td。若方向是单位向量，参数差的绝对值就是距离；否则还要乘 ∣d∣。

为什么这样做

代入圆方程得到二次式，韦达定理直接给根和积。参数有正负，长度必须按点序取绝对值。

先看一道例题

例 1：水平弦

直线 y=1 与圆 x2+y2=5 交于两点，求弦长及两横坐标之积。

怎么看出来：

横坐标就是单位水平方向参数。

解：

x2−4=0，两根 −2,2，乘积 −4，弦长 4。

答案：

弦长 4，积 −4。

二、什么时候想到它

题目里看到应该想到
同一直线上的两交点只以向量和、距离积、定比关系出现，或圆外两条垂直割线需要消去近远端点。圆与直线联立时，用交点参数的根和根积求所需长度。
直线 y=1 与圆 x2+y2=5 交于两点，求弦长及两横坐标之积。横坐标就是单位水平方向参数。

三、怎么用

  1. 选择非零方向参数化直线。
  2. 代入圆方程核判别式。
  3. 用根和积计算目标。
  4. 恢复实际长度，检查点序和单位方向。

四、再做一道

例 2：外点割线

P=(3,0) 沿方向 (−1,0) 截圆 x2+y2=1，求两交点到 P 距离的乘积。

怎么看出来：

单位参数根都为正。

解：

(3−t)2=1 得 t2−6t+8=0，根为 2,4，乘积 8，与点幂 9−1 一致。

答案：

8。

五、容易错在哪

  • 非单位方向的参数不是距离，不能直接把根差当弦长。

动点看线段的张角：用点积判锐钝，用叉积求最大

PA⋅PB 的正负告诉你 ∠APB 是锐角、直角还是钝角。要比较两个锐角的大小，光看点积不够，还要用正切。

完整讲解 · 例题 · 可练 2 题

一、是什么

向量和点积

从 P(x,y) 到 A(xA​,yA​) 的向量是 PA=(xA​−x, yA​−y)，也就是终点减起点。向量 (a,b) 和 (c,d) 的点积定义为 ac+bd，结果是一个数。例如 (1,2) 和 (3,−1) 的点积是 3−2=1。

点积的正负判断角

设 u,v 是非零向量，夹角是 θ（0∘≤θ≤180∘）。用坐标展开可得 ∣u−v∣2=∣u∣2+∣v∣2−2u⋅v，而 ∣u−v∣ 正是以 u,v 为两边的三角形的第三边。点积为 0 时恰好是勾股定理，θ=90∘。两边长度不变时，夹角越大第三边越长，所以点积大于 0 时 θ<90∘，点积小于 0 时 θ>90∘。P 与 A 或 B 重合时向量是零向量，角没有意义，要排除。

和中点的关系

设 M 是 AB 的中点，则 PA⋅PB=∣PM∣2−4∣AB∣2​。例如 A(−1,0), B(3,0)，M(1,0)，直接算得点积 =(x−1)2+y2−4，正好是这个式子。所以 P 在以 AB 为直径的圆内时是钝角（在线段 AB 上时是 180∘），在圆上（不含 A,B）时是直角，在圆外时是锐角（在直线 AB 上、线段外时是 0∘）。

圆上的点：二次项可以消掉

点积展开后总含 x2+y2。若 P 在圆上，圆方程能把 x2+y2 换成一次式。例如 x2+y2=4 上，A(1,0),B(3,0) 的点积 x2+y2−4x+3 变成 7−4x，只需看 x 的范围。

先看一道例题

例 1：直线上的最大角

A(−1,0), B(3,0)，P 在直线 y=2 上。求 ∠APB 的最大值和此时 P 的坐标。

怎么看出来：

若点积总是非负，且有一个点等于 0，那么角最大就是 90∘，不用求正切。

解：

设 P(x,2)，向量非零。点积 =(−1−x)(3−x)+4=x2−2x−3+4=(x−1)2≥0，所以 ∠APB≤90∘。x=1 时点积为 0，∠APB=90∘，取到了。检查：P(1,2)，PA=(−2,−2)，PB=(2,−2)，点积 =−4+4=0。也可以看中点：M(1,0)，以 AB 为直径的圆半径是 2，直线 y=2 恰好与它相切于 (1,2)。

答案：

最大值 90∘，此时 P(1,2)。

二、什么时候想到它

题目里看到应该想到
动点 P 看两个定点，问 ∠APB 是锐角、钝角还是直角写出点积，看正负
P 在圆上，点积含 x2+y2用圆方程消去二次项
问 ∠APB 的最大值，点积看起来总不为负说明点积 ≥0，再找点积为 0 的点；找得到，最大值就是 90∘
圆上的一次式 ax+by 的范围平移圆心，再用配方不等式（见进阶“圆上一次式”）
P 在直线上，问张角最大时的位置写叉积和点积之比，分正负比较（见进阶“叉积与正切”）

三、怎么用

  1. 写出向量。例如 A(−1,0), B(1,0)，P(x,2) 在直线 y=2 上：PA=(−1−x,−2)，PB=(1−x,−2)。
  2. 算点积并化简。(−1−x)(1−x)+4=x2−1+4=x2+3。
  3. 看正负。x2+3≥3>0，点积总是正的。
  4. 确认向量非零并下结论。P 的纵坐标是 2，不会和 A,B 重合，所以这条直线上 ∠APB 总是锐角。代 x=0 检查：(−1,−2)⋅(1,−2)=−1+4=3，与 x2+3 一致。

四、再做一道

例 2：圆上哪些点看成钝角

P(x,y) 在圆 x2+y2=4 上，A(1,0), B(3,0)。求 ∠APB 为钝角时 x 的范围。

怎么看出来：

圆方程能把 x2+y2 消掉，点积变成一次式。还要留意 P 落在线段 AB 上的情况。

解：

点积 =(1−x)(3−x)+y2=x2+y2−4x+3=7−4x。圆上有 −2≤x≤2，且 P 不会与 A,B 重合（A 在圆内，B 在圆外）。点积小于 0 时 x>47​。但 x=2 时 P(2,0) 在线段 AB 上，∠APB=180∘，是平角，不算钝角。检查：x=47​ 时 y2=4−1649​=1615​，点积 =(−43​)(45​)+1615​=0，是直角。

答案：

47​<x<2。

五、容易错在哪

  • 点积只能判断锐角、直角、钝角。两个锐角比大小时，点积小的角不一定大，因为边长也在变。
  • 钝角的正切是负数，把它和锐角的正切直接比会得出错误结论。比正切之前先说明点积大于 0。
  • P 与 A 或 B 重合时向量为零，角没有意义，要排除。P 在线段 AB 内部时点积为负，但角是 180∘，不是通常说的钝角。
  • 求最大值时要看直线上的所有位置，包括参数的两侧和走向无穷远的情况。
  • 把坐标伸缩成圆以后，点积和角度都变了，不能在伸缩后的坐标里用普通点积算原来的角。
进阶：圆上一次式 · 先修：三角函数

圆上一次式的范围

设 u2+v2=r2（r>0），a,b 不全为 0。由 (a2+b2)(u2+v2)−(au+bv)2=(av−bu)2≥0 得 ∣au+bv∣≤ra2+b2​。等号在 (u,v)=±a2+b2​r​(a,b) 时取到，所以这就是最大值和最小值。圆心不在原点时，先写 x=h+u, y=k+v 平移过去。

例 3：点积最小不等于角最大

P 在圆 (x−3)2+(y−3)2=2 上，A(−1,0), B(1,0)。求 PA⋅PB 的最小值，并判断此时 ∠APB 是否最大。

怎么看出来：

先消二次项求最小值。角的大小还和两条边的长度有关，要另外比较。

解：

点积 =x2+y2−1。圆方程展开得 x2+y2=6x+6y−16，所以点积 =6x+6y−17。设 x=3+u, y=3+v，u2+v2=2，则点积 =6u+6v+19。由配方不等式 ∣6u+6v∣≤2​⋅72​=12，所以点积的最小值是 7，在 u=v=−1，即 P(2,2) 时取到。此时 PA=(−3,−2), PB=(−1,−2)，叉积 =6−2=4，由正切公式（见进阶“叉积与正切”）得 tan∠APB=74​。再取圆上的点 Q(58​,514​)（u=−57​, v=−51​）：点积 =547​，大于 7；叉积绝对值 =528​，tan∠AQB=4728​。因为 28⋅7=196>188=4⋅47，所以 4728​>74​，Q 处的角更大。

答案：

最小值 7；此时 ∠APB 不是最大。

进阶：叉积与正切 · 先修：三角函数

叉积与正切

(a,b) 和 (c,d) 的叉积定义为 ad−bc。展开可验证 (ac+bd)2+(ad−bc)2=(a2+b2)(c2+d2)。又点积 =∣u∣∣v∣cosθ，于是叉积的绝对值 =∣u∣∣v∣sinθ（sinθ≥0）。所以点积大于 0 时，tanθ=点积∣叉积∣​。tan 在 0∘ 到 90∘ 之间递增，所以在都是锐角的范围里，比 tan 就是比角。钝角的正切是负数，不能和锐角这样比。

直线上的动点：分正负再比较

沿直线写 P 的坐标，用一个参数表示点积和叉积。叉积带绝对值时按正负分开。要说明最大值，还要看 P 在直线 AB 上以及 P 走向无穷远（tanθ 趋于 0）时的情况。P 在直线 AB 上时叉积为 0：在线段 AB 外角为 0∘，在线段内部角为 180∘（此时点积为负，正切公式不适用），与端点重合时角没有意义。形如 at+tb​（a,b,t>0）的最小值用配方：at+tb​−2ab​=(at​−tb​​)2≥0，等号在 at=tb​ 时成立。

例 4：垂直于线段的直线

A(0,1), B(0,4)，P(x,0) 在 x 轴上。求 tan∠APB 的最大值和此时的 x。

怎么看出来：

A,B 都在 y 轴正半轴上，点积总是正的，所以可以比正切。

解：

PA=(−x,1), PB=(−x,4)。点积 =x2+4>0，角都是锐角或 0∘。叉积 =−4x+x=−3x，所以 tan∠APB=x2+43∣x∣​。x=0 时 P 在直线 AB 上，角为 0∘。x=0 时分子分母同除以 ∣x∣，得 ∣x∣+∣x∣4​3​。由 ∣x∣+∣x∣4​−4=∣x∣(∣x∣−2)2​≥0，分母至少是 4，等号在 ∣x∣=2 时成立。所以最大值是 43​。检查：x=2 时 PA=(−2,1), PB=(−2,4)，点积 8，叉积 −6，比值 43​。

答案：

最大值 43​，此时 x=±2。

例 5：斜直线：两侧要比较

A(−1,0), B(1,0)，P 在直线 y=x+2 上。求 tan∠APB 的最大值。

怎么看出来：

设 P(t,t+2)，点积恒正。t+2 有正有负，叉积的绝对值要分情况。

解：

点积 =t2+(t+2)2−1=2t2+4t+3=2(t+1)2+1>0，所以都是锐角或 0∘。叉积：PA=(−1−t,−t−2), PB=(1−t,−t−2)，叉积 =(1+t)(t+2)+(1−t)(t+2)=2(t+2)。令 s=t+2，则点积 =2s2−4s+3，tan∠APB=2s2−4s+32∣s∣​。s=0 时角为 0∘。s>0 时比值 =2s+s3​−42​；因为 2s+s3​≥26​，等号在 s=23​​ 时成立，且 26​−4>0，所以最大值是 26​−42​=26​+2​。s<0 时设 w=−s>0，比值 =2w+w3​+42​≤26​+42​，更小。∣s∣ 很大时比值趋于 0，不影响最大值。

答案：

最大值 26​+2​。

一、是什么

目标是单位方向投影。

(x+y)2≤2(x2+y2)=2，所以 x+y≤2​；在 x=y=1/2​ 取等。

相切与正交的圆心距离条件

圆相切用圆心距等于半径和或差；正交用圆心距平方等于半径平方和。

完整讲解 · 例题 · 可练 4 题

一、是什么

先认识这些量

相切是只有一个公共点，分外切和内切。两圆正交指交点处切线互相垂直，也等价于两条交点半径垂直。

为什么这样做

交点两半径和圆心连线组成三角形。外切、内切对应退化三角形，正交对应直角三角形。

先看一道例题

例 1：外切与内切

两圆半径为 2,1，当圆心距分别为 3,1 时，是什么位置关系？

怎么看出来：

分别比较半径和与差。

解：

3=2+1 时外切；1=2−1>0 时内切，两半径不同，不是重合圆。

答案：

分别外切、内切。

二、什么时候想到它

题目里看到应该想到
两圆只有一个交点、三条直线的公共切圆，或两圆交点处切线垂直。圆相切用圆心距等于半径和或差；正交用圆心距平方等于半径平方和。
两圆半径为 2,1，当圆心距分别为 3,1 时，是什么位置关系？分别比较半径和与差。

三、怎么用

  1. 求两圆圆心与正半径。
  2. 相切时分别检查半径和与差。
  3. 正交时列勾股关系。
  4. 排除重合圆并核真实交点。

四、再做一道

例 2：正交圆

圆 x2+y2=1 与 (x−2​)2+y2=1 是否正交？

怎么看出来：

圆心距平方为两半径平方和。

解：

d2=2=1+1。交点为 (1/2​,±1/2​)，两半径点积 −1/2+1/2=0，确实正交。

答案：

正交。

五、容易错在哪

  • 圆心重合且半径相等是重合圆，不能称为内切。

误区对照

容易误以为

过点 P(2,3) 作圆 x2+y2=4 的切线：设 y−3=k(x−2)，由 1+k2​∣3−2k∣​=2 得 k=125​，所以只有一条切线 5x−12y+26=0。

应当这样想

点斜式不能表示竖直直线。直线 x=2 到圆心距离为 2，等于半径，也是切线。圆外一点恰有两条切线：5x−12y+26=0 与 x=2。

为什么

关于 k 的方程平方后二次项抵消，说明另一条切线的斜率不存在；设斜率前必须单查竖直线。

容易误以为

点 P(1,0) 到圆 x2+y2=9 上点的最短距离为 ∣OP∣−r=1−3=−2，所以“最短距离”不存在。

应当这样想

P 在圆内。圆上点 Q 满足 ∣PQ∣≥r−∣OP∣=2，在射线 OP 与圆的交点 (3,0) 处取等；最长距离为 r+∣OP∣=4，在 (−3,0) 取到。

为什么

点到圆的最近、最远距离沿过圆心的直线取到，公式是 ​∣OP∣−r​ 与 ∣OP∣+r；先判断点在圆内还是圆外。

容易误以为

方程 x2+y2+2x−4y+6=0 配方得 (x+1)2+(y−2)2=−1，它表示圆心 (−1,2) 的圆。

应当这样想

右端 −1<0，没有实数点满足，方程表示空集。一般式 x2+y2+Dx+Ey+F=0 表示圆当且仅当 D2+E2−4F>0；这里 4+16−24=−4<0。

为什么

圆心坐标总能配方读出，但半径平方必须严格为正；等于零只是一点，小于零没有图形。
