25.3 实际问题与一元二次方程

数学的真正生命力在于解决现实问题。从道路平移修绿化、两年平均增长率，到病毒传播与循环赛场次，一元二次方程如何精准建模？更重要的是：解出的数学根，必须通过“双重检验”！

本节导读　先修：25.2 降次解法 · 5.3 实际问题 · 本节路线

要用到：一元二次方程的四种解法（回看 25.2）、一元一次方程的应用与列方程四步（回看 5.3）。

  1. 从树状传播进入：为什么现实增长会以二次幂爆发？
  2. 建立建模全流程：审、设、列、解、检（双重检验）、答。
  3. 核心模型一：平均变化率模型 \(a(1 \pm x)^2 = b\)。
  4. 核心模型二：几何图形与面积模型（巧用“道路平移法”）。
  5. 核心模型三：比赛循环与网络互联场次模型。
  6. 动手试验：在草坪修路与复利增长试验台中直观检验模型。
  7. 练习与中考真题演练，破除舍根与列式的三大翻车陷阱。

某种传染性较强的流感在人群中扩散：最初有 \(1\) 个人患病，经过第一轮传染，平均每人传染了 \(x\) 个人；第二轮中，所有感染者再各传染 \(x\) 个人。点下面按钮，看两轮传播的人数如何迅速扩散：

如果最初有 \(1\) 人患病，经过两轮传染后共有 \(64\) 个人患病，那么平均每个人传染了多少人？

C。第 0 轮有 \(1\) 人；第 1 轮后共有 \(1 + x\) 人；第 2 轮这 \(1+x\) 个人每人再传 \(x\) 人，两轮后总人数为 \(1 + x + x(1+x) = (1+x)^2\)。

列方程：\((1 + x)^2 = 64 \implies 1 + x = \pm 8\)：解得 \(x_1 = 7, x_2 = -9\)。因为每人传染的人数不能为负数，舍去 \(x_2 = -9\)，所以平均每个人传染了 7 人！选 A 是开方后忘了减 1。

1. 先认识几个词：建模六步法与“双重检验”

前置知识：列方程解应用题步骤（回看 5.3）。解一元二次方程实际应用题，最关键的特征是可能解出两个数学根，必须经过严格的双重检验！

直觉微图解 ①实际问题建模漏斗：数学检验 + 实际意义检验

第一重检验数学检验（是否为方程的解）

解出的 \(x_1, x_2\) 是否满足原一元二次方程？代入原方程左边与右边，排查计算过程中的移项、配方或公式法符号失误。

第二重检验实际意义检验（是否符合现实物理界限）

几何边长不能为负；人数、比赛场次必须为正整数；降价率不能超过 100%；纸板裁切尺寸 \(2x\) 不能超过总宽（不能切穿！）。不合实际的根必须注明“舍去”。

2. 核心模型一：平均变化率模型（增长率与降低率）

在经济、人口、产量与科技投入中，经过两次等比例变化后的数量关系极其常见：

基期量为 \(a\)，每期的平均变化率为 \(x\)，经过两期后得到 \(b\)：

\(\mathbf{a(1 \pm x)^2 = b}\)

增长取“加号”：\(a(1+x)^2 = b\)；降低取“减号”：\(a(1-x)^2 = b\)（注意：降低率必有 \(0 \lt x \lt 1\)）。

直觉微图解 ②单利累计 vs 复利爆发：为什么不是 \(a(1+2x)\)？

示范例题 1：工业产值平均增长率问题

题目：某新能源汽车厂 2022 年的年产值为 \(20\) 亿元，随着技术革新，2024 年的年产值增长到 \(28.8\) 亿元。求该厂产值的年平均增长率。

① 读懂题意：基期量 \(a = 20\)，期末量 \(b = 28.8\)，经过两年（两期），求年平均增长率 \(x\)。

② 想办法：设年平均增长率为 \(x\)，2023 年产值为 \(20(1+x)\)，2024 年产值为 \(20(1+x)^2\)。根据 2024 年产值列方程求解。

③ 执行与检查：
设该厂产值的年平均增长率为 \(x\)．
根据题意，得：\(20(1 + x)^2 = 28.8\)．
两边同除以 20，得：\((1 + x)^2 = 1.44\)．
两边开平方，得：\(1 + x = \pm 1.2\)．
解得：\(x_1 = 0.2 = 20\%,\ x_2 = -2.2\)．
因为增长率不能为负数，所以舍去 \(x_2 = -2.2\)．
答：该厂产值的年平均增长率为 \(20\%\)．

④ 回头看：检验：2022 年 20 亿；2023 年 \(20\times 1.2 = 24\) 亿；2024 年 \(24\times 1.2 = 28.8\) 亿，完全吻合！

自己试试 1：某数码产品经过两次连续降价，售价由原来的每台 \(2500\) 元降到每台 \(1600\) 元。设平均每次降价的百分率为 \(x\)，则满足的方程是（　）

B。基期售价为 2500 元，每次降价后的价格为原价的 \((1 - x)\)，两次降价后价格为 \(2500(1 - x)^2 = 1600\)。解得 \(1 - x = 0.8 \implies x = 20\%\)。

3. 核心模型二：几何图形与面积模型（道路平移法）

在长方形场地中修筑纵横等宽的道路，分散的草坪面积计算常常让人头疼。道路平移法是解决此类几何问题的神来之笔：

\(\text{道路平移至两边} \implies \text{草坪净面积 } S = (\mathbf{长 - x})(\mathbf{宽 - x})\)

直觉微图解 ③道路平移魔法：把碎块草坪聚拢为单一长方形

示范例题 2：绿化道路与平移法建模（含尺寸边界检验）

题目：一块长方形绿地长 \(30\text{ m}\)，宽 \(20\text{ m}\)。要在绿地中间开辟两条等宽且互相垂直的小路，使剩余草坪的总面积为 \(504\text{ m}^2\)。求小路的宽度。

① 读懂题意：原场地长 30m，宽 20m；两条纵横道路宽均为 \(x\text{ m}\)；草坪总面积为 504m²。

② 想办法：采用道路平移法，将横竖道路推到绿地最右侧和最下侧。剩余草坪拼合成一个完整的长方形，长为 \((30 - x)\text{ m}\)，宽为 \((20 - x)\text{ m}\)。根据矩形面积公式列方程。

③ 执行与检查：
设小路的宽度为 \(x\text{ m}\)（根据实际，必有 \(0 \lt x \lt 20\)）．
由平移法，剩余草坪的长为 \((30 - x)\text{ m}\)，宽为 \((20 - x)\text{ m}\)．
根据题意，列方程得：\((30 - x)(20 - x) = 504\)．
展开，得：\(600 - 50x + x^2 = 504\)．
移项整理成一般式：\(x^2 - 50x + 96 = 0\)．
因式分解得：\((x - 2)(x - 48) = 0\)．
解得：\(x_1 = 2,\ x_2 = 48\)．
实际意义检验：因为绿地的总宽只有 \(20\text{ m}\)，小路的宽度不可能达到 \(48\text{ m}\)（\(48 > 20\) 不合实际），所以舍去 \(x_2 = 48\)．
答：小路的宽度应为 \(2\text{ m}\)．

④ 回头看：当 \(x = 2\) 时，草坪长 \(30-2=28\text{ m}\)，宽 \(20-2=18\text{ m}\)，面积 \(28\times 18 = 504\text{ m}^2\)，完全符合！若不检验就会保留荒谬的 48 米。

自己试试 2：长方形相框长 \(25\text{ cm}\)，宽 \(20\text{ cm}\)。在内侧四周留出等宽为 \(x\text{ cm}\) 的白边，使中间照片面积为 \(300\text{ cm}^2\)，则 \(x\) 满足的方程是（　）

A。相框四周各留白边 \(x\)，故长和宽两端各减去 \(x\)，照片的长为 \((25 - 2x)\)，宽为 \((20 - 2x)\)，面积为 \((25 - 2x)(20 - 2x) = 300\)。选 B 是忘记了两侧都要减去 \(x\)。

4. 核心模型三：比赛循环与商业营销模型

示范例题 3：单循环比赛场次问题

题目：某校举办初三年级三人制篮球赛，赛制为单循环制（每两队之间都要赛一场）。组委会统计赛程总场次共需进行 \(28\) 场比赛，问一共有多少支球队参赛？

① 读懂题意：单循环比赛，总场次为 28 场，求球队数 \(n\)。

② 想办法：设共有 \(n\) 支队伍参赛，每支队伍要与其余 \((n-1)\) 支队伍各赛一场，两两比赛不重复计算需除以 2，总场次为 \(\dfrac{1}{2}n(n-1)\)。

③ 执行与检查：
设参赛球队共有 \(n\) 支（\(n\) 为正整数且 \(n \ge 2\)）．
根据单循环赛制场次公式列方程：\(\dfrac{1}{2}n(n - 1) = 28\)．
两边乘 2，得：\(n(n - 1) = 56 \implies n^2 - n - 56 = 0\)．
因式分解得：\((n - 8)(n + 7) = 0\)．
解得：\(n_1 = 8,\ n_2 = -7\)．
因为球队数量不能为负数，舍去 \(n_2 = -7\)．
答：一共有 8 支球队参赛．

④ 回头看：8 支队伍，每队赛 7 场，总场次 \(8\times 7 / 2 = 28\) 场，完全吻合！

示范例题 4：商业营销利润问题（让利顾客双解决策）

题目：某文创店购进一批特色书签，进价为每件 \(10\) 元。若按每件 \(15\) 元出售，每天可售出 \(40\) 件。市场调查发现：每件售价每降价 \(1\) 元，日销售量就会增加 \(20\) 件。若店家希望每天获得 \(240\) 元利润，且尽可能让利给顾客，每件书签应降价多少元？

① 读懂题意：进价 10 元，原价 15 元；降价 \(x\) 元，销量增加 \(20x\) 件；目标利润 240 元；要求「尽可能让利给顾客」（降价越多越好）。

② 想办法：单件利润 \(\times\) 销售数量 \(=\) 总利润。单件利润为 \((15 - x - 10) = (5 - x)\) 元，销售量为 \((40 + 20x)\) 件。

③ 执行：
设每件书签降价 \(x\) 元（\(0 \lt x \lt 5\)）．
列方程：\((5 - x)(40 + 20x) = 240\)．
两边同除以 20，得：\((5 - x)(2 + x) = 12\)．
展开整理得：\(10 + 3x - x^2 = 12 \implies x^2 - 3x + 2 = 0\)．
因式分解得：\((x - 1)(x - 2) = 0\)．
解得：\(x_1 = 1,\ x_2 = 2\)．
两根都在 \(0 \lt x \lt 5\) 的合理区间内；但题目明确要求「尽可能让利给顾客」，降价幅度应尽量大，故取 \(x = 2\) 元．
答：每件书签应降价 2 元。

④ 回头看：若降 1 元，单件赚 4 元，卖 60 件，利润 \(4\times 60 = 240\) 元；若降 2 元，单件赚 3 元，卖 80 件，利润 \(3\times 80 = 240\) 元。两种方案利润相同，但降 2 元销量更高、顾客更满意！

自己试试 3：一个凸多边形共有 \(20\) 条对角线，它是几边形？（提示：从 \(n\) 边形一个顶点可引 \(n-3\) 条对角线，共有 \(\dfrac{1}{2}n(n-3)\) 条对角线）

A。列方程：\(\dfrac{1}{2}n(n-3) = 20 \implies n^2 - 3n - 40 = 0 \implies (n - 8)(n + 5) = 0\)。解得 \(n_1 = 8, n_2 = -5\)（舍去）。故为八边形。

翻车现场 ①求出正数就以为全对，忽略几何上限

解出的两个根如果都是正数（如道路题算得 \(x_1 = 2, x_2 = 48\)），绝不能全都当成答案！绿地宽只有 20m，道路宽 48m 意味着道路比绿地还要宽，必须严格对照几何尺寸舍去。

翻车现场 ②平均增长率把两年复利误写成单利

很多同学列方程顺手写成 \(a(1 + 2x) = b\)。增长是按年利滚利连续乘法，第一年是 \(a(1+x)\)，第二年是在第一年的基础上再乘 \((1+x)\)，必须是 \(a(1+x)^2\)！

翻车现场 ③传染病传播漏掉第 0 轮传染源

传染问题中，最初的 1 人也是感染者！两轮后的总感染人数是 \(1 + x + x(1+x) = (1+x)^2\)。若把最初的 1 人漏掉，列成 \(x + x^2 = N\)，会导致全题皆错。

再深一点：从方程到决策：“让利”背后的优化

我们在利润问题中看到的“在保持目标利润的前提下让利顾客”，是企业决策的典型雏形。本节只求“利润恰好等于某个值”的方程；至于“利润最多能到多少”，要等九年级学了二次函数才能回答。

如何用代数说明定位与精度？

原方程可写为 \((x+1)^2=11\)。在正区间，\(x+1\) 为正，数增大时平方增大；在负区间，\(x+1\) 为负，数增大时绝对值变小，平方变小。把两端的平方与11比较，就能用平方根的大小定位所研究的根。也可用 \(u^2-v^2=(u-v)(u+v)\) 说明平方的比较，不需要二次函数或微积分。

同号的两行不能独自构成夹住根的两端。缩小区间时保留异号两端；表格并非“任意方程异号就一定有根”的一般证明。若要四舍五入到百分位，检查区间两端是否舍入成同一个数；只看区间宽不足0.01未必够。近似值必须用“约”或 \(\approx\)，不能冒充精确根。

活动二 · 自主建模与完整设列解验答

一张长18 cm、宽12 cm的长方形卡纸，在内侧四周留出同样宽的边框，中间照片的面积为112 cm²。求边框宽度。先画草图标量（可在纸上画并在下方描述），从文字逐步抽象关系，不套旧例的数值。

下面三格只作有限数值核对，不代表上面的过程已经正确。

对照阅读：设边框宽为 \(x\) cm，需 \(0<x<6\)。照片的长、宽为 \(18-2x\)、\(12-2x\)（cm），面积相等给出 \((18-2x)(12-2x)=112\)。展开得 \(4x^2-60x+104=0\)，除以4得 \(x^2-15x+26=0\)，即 \((x-2)(x-13)=0\)，所以数学根为2和13。

代回：\(x=2\) 时 \(14\times8=112\)；\(x=13\) 时 \((-8)\times(-14)=112\)，两者都是方程的根。但13使照片两边长为负，超过实际上限，应舍去；2符合实际。答：边框宽为2 cm。负边长相乘面积虽为正，也不能据此认定几何设计可行。

选读拓展 · 黄金分割：代数正根怎样回到几何比例？

本项是 enrichment（拓展阅读），不作新必修前置。点C在线段AB内部，AC为较长段，BC为较短段。黄金分割要求“较长段与全长的比”等于“较短段与较长段的比”。取AB的长度为1个单位，设AC长为x个单位。画出 A—C—B 并标出三段，写下你的阅读推导。

AC=x、BC=1−x、AB=1（同一长度单位），所以 \(\frac{x}{1}=\frac{1-x}{x}\)。因为 \(x>0\)，交叉相乘得 \(x^2=1-x\)，整理为 \(x^2+x-1=0\)。用25.2的配方法或公式法得 \(x=\frac{-1\pm\sqrt5}{2}\)。负根不是长度；正根 \(\frac{\sqrt5-1}{2}\approx0.618\)，由 \(2<\sqrt5<3\) 知它大于 \(\frac12\)、小于1，符合较长段与内部点条件。

由 \(x^2=1-x\) 且 \(x>0\)，再除以x得 \(x=\frac{1-x}{x}\)。因此这个正根表示AC/AB，也表示BC/AC；并不是BC/AB（后者为1−x）。若全长为 \(L>0\)，较长段为xL，短段为(1−x)L，两比值仍为x，比例与单位选择无关。这是线段比例阅读，不需要九下相似或三角函数。数值残差小只能帮助检查近似，根式推导才说明精确比例。

机器核对接受的封闭语法

方程只收 ASCII 的 x、十进制数字、+ - * / ^2 ( ) =，恰有一个等号；整数部分和小数部分各至多6位。允许数字接x或左括号、右括号接x或左括号、x接左括号表示乘法；其余乘法请写 *。除数化简后须为非零常数，中间式不得超过二次；不收单位、百分号、指数记数、根式、全角字符或其他字母。空白只分隔词元，不会把分开的数字拼起来；不作字符兼容归一化。等价的非零倍方程可核对，但机器不检查文字解释或是否写成原生模型。

数值格只收带正负号的普通十进制或单个分数（分子分母各可带符号，分母非零），每个数的整数与小数部分各至多6位。黄金分割的根式推导写在文字区，数值格填近似数。表格采用有理数精确计算，不把浮点误差当作正误标准。

1. 直接用：某工厂一月份产值为 \(100\) 万元，第一季度总产值累计为 \(364\) 万元。设二、三月份产值的月平均增长率为 \(x\)，则列出的方程是（　）

B。第一季度总产值是「一月 + 二月 + 三月」三月总和！一月为 100，二月为 \(100(1+x)\)，三月为 \(100(1+x)^2\)，三者相加等于 364。选 A 是误把三月份单月的产值当成了整季总和。

2. 直接用：参加一次足球友谊赛的球队进行单循环比赛，共赛了 \(15\) 场。参加比赛的球队共有（　）

C。列方程：\(\dfrac{1}{2}n(n-1) = 15 \implies n(n-1) = 30 \implies n^2 - n - 30 = 0 \implies (n-6)(n+5)=0\)。解得 \(n = 6\)（负根舍去）。

3. 易错题：在宽为 \(24\text{ m}\)，长为 \(36\text{ m}\) 的长方形广场上修两条等宽为 \(x\text{ m}\) 的横竖交叉小路，若使余下铺草面积为 \(748\text{ m}^2\)，列方程 \((36-x)(24-x)=748\) 解得 \(x_1 = 2, x_2 = 58\)，本题的最终答案应取（　）

提示

广场的宽只有 24 米，小路的宽度能超过 24 米吗？

D。广场总宽仅 24 米，小路宽度必须满足 \(0 \lt x \lt 24\)。根 \(x = 58\) 明显超出广场尺寸，不合物理实际，必须舍去，故答案只能取 \(x = 2\)。

4. 易错题：一种药品经过两次降价，由每盒 \(64\) 元降至每盒 \(49\) 元。设平均每次降价的百分率为 \(x\)，则 \(x\) 的值为（　）

提示

列方程 \(64(1-x)^2 = 49\)，两边开平方时注意 \(1-x\) 为正数。

A。方程：\(64(1-x)^2 = 49 \implies (1-x)^2 = \dfrac{49}{64} \implies 1 - x = \dfrac{7}{8} = 0.875 \implies x = 0.125 = 12.5\%\)（舍去负根 \(1-x = -7/8\)）。

5. 挑战题：一个直角三角形的三边长恰好是三个连续的偶数，则这个直角三角形的面积是（　）

提示

设三边为 \(x, x+2, x+4\)，由勾股定理列方程 \(x^2 + (x+2)^2 = (x+4)^2\)。

C。设三边为 \(x, x+2, x+4\)（\(x\) 为正偶数）。由勾股定理：\(x^2 + (x+2)^2 = (x+4)^2 \implies x^2 + x^2 + 4x + 4 = x^2 + 8x + 16 \implies x^2 - 4x - 12 = 0 \implies (x-6)(x+2)=0\)。解得 \(x = 6\)（负根舍去）。直角边为 6 和 8，斜边为 10。面积为 \(\dfrac{1}{2}\times 6\times 8 = 24\)。
