5.2 导数的运算

按定义求导数每次都要算极限，太慢。这一节记住几个基本函数的导数，再学加减乘除和 \(f(ax+b)\) 的求导规则，大多数函数就能直接写出导数。

两个函数的和，求导只需各自求导再相加：\((u+v)' = u' + v'\)。那么遇到两个函数的乘积 \((uv)'\) 时：

乘积的导数 \([u(x)v(x)]'\) 是否等于它们导数的乘积 \(u'(x)v'(x)\)？

B。反例一目了然：

设 \(u(x) = x, v(x) = x\)，它们的乘积是 \(f(x) = x^2\)。根据定义已知 \((x^2)' = 2x\)。

若按 A 选项的算法：\(u'(x)v'(x) = 1 \times 1 = 1\)。显然 \(2x \ne 1\)！

而按 B 选项公式：\(u'v + uv' = 1 \cdot x + x \cdot 1 = 2x\)，完全吻合！

这一节我们就来系统建立基本初等函数的导数公式表、四则运算律以及简单复合函数的求导规则。

1. 先认识几个词

要用到：5.1 导数的概念和几何意义（回看 5.1）；必修一的幂、指数、对数函数，弧度制和三角函数。

导函数：每个 \(x\) 处的导数 \(f'(x)\) 本身又是 \(x\) 的函数，叫导函数，简称导数。求出导函数，任意一点的切线斜率代进去就有。

例：\(f(x)=x^2\)，按 5.1 的定义算得 \(f'(x)=2x\)。于是 \(f'(3)=6\)，\(f'(-1)=-2\)，不用每个点重算一次极限。

把根式、分式写成幂：幂函数公式只认 \(x^\alpha\) 的样子，用之前先改写。

例：\(\dfrac1x=x^{-1}\)，\(\sqrt x=x^{\frac12}\)，\(\dfrac{1}{\sqrt x}=x^{-\frac12}\)，\(x^2\sqrt x=x^{\frac52}\)。

内层、外层：\(y=\sin(3x+1)\) 可以看成两步：先算 \(u=3x+1\)（内层），再算 \(y=\sin u\)（外层）。本节只处理内层是一次式 \(ax+b\) 的情形。

例：\(e^{2x-5}\) 的内层是 \(2x-5\)（\(a=2\)），外层是 \(e^u\)；\(\ln(4-x)\) 的内层是 \(4-x\)（\(a=-1\)），外层是 \(\ln u\)。

2. 基本初等函数的导数

常用函数的导数用 5.1 的定义都能算出来，算一次记成表，以后直接查。表里的公式有条件：对数要 \(x>0\)，指数、对数的底 \(a>0\) 且 \(a\ne1\)，三角函数的 \(x\) 用弧度。

\(f(x)\)\(f'(x)\)
\(C\)（常数）\(0\)
\(x^\alpha\)\(\alpha x^{\alpha-1}\)
\(\sin x\)\(\cos x\)
\(\cos x\)\(-\sin x\)（带负号）
\(a^x\)\(a^x\ln a\)；特别地 \((e^x)'=e^x\)
\(\log_a x\)\(\dfrac{1}{x\ln a}\)；特别地 \((\ln x)'=\dfrac1x\)

为什么常数是 \(0\)：函数值不变，图像是水平直线，切线斜率处处是 \(0\)。幂函数「指数拿下来，指数减 \(1\)」，例如 \((x^2)'=2x\)、\((x^3)'=3x^2\)，和 5.1 用定义算出的一致。

例 1（看一遍怎么写）

求导：① \(y=\dfrac{1}{x^3}\)；② \(y=x\sqrt x\)；③ \(y=2^x\)；④ \(y=\log_3 x\)；⑤ \(f(x)=\sin x\)，求 \(f'\!\left(\dfrac\pi3\right)\)。

① 改写 \(y=x^{-3}\)，\(y'=-3x^{-4}=-\dfrac{3}{x^4}\)。

② 改写 \(y=x^{\frac32}\)，\(y'=\dfrac32x^{\frac12}=\dfrac32\sqrt x\)。

③ \(y'=2^x\ln2\)。（\(\ln2\) 是常数，不要丢。）

④ \(y'=\dfrac{1}{x\ln3}\)（\(x>0\)）。

⑤ \(f'(x)=\cos x\)，\(f'\!\left(\dfrac\pi3\right)=\cos\dfrac\pi3=\dfrac12\)。

自己试试：\(y=\dfrac{1}{x^2}\) 的导数是？

A。\(y=x^{-2}\)，\(y'=-2x^{-3}=-\dfrac{2}{x^3}\)。选 B 是把分母 \(x^2\) 直接换成了它的导数 \(2x\)；选 C 丢了指数 \(-2\) 的负号；选 D 是指数没减 \(1\)（\(-2-1=-3\)，不是 \(-1\)）。

3. 导数的四则运算法则

函数加减乘除拼起来以后，导数怎么算：

  • 和、差：各自求导再加减，\([f(x)\pm g(x)]'=f'(x)\pm g'(x)\)。常数因子可以提出来：\([cf(x)]'=cf'(x)\)。
  • 积：轮流求导再相加，不是导数相乘：
$$[u(x)v(x)]'=u'(x)v(x)+u(x)v'(x)$$
  • 商：分母不为 \(0\) 时，
$$\left[\frac{u(x)}{v(x)}\right]'=\frac{u'(x)v(x)-u(x)v'(x)}{[v(x)]^2}$$

\(v(x)\ne0\)；分子是减号，先「分子的导数乘分母」

为什么积要「轮流」：长 \(u\)、宽 \(v\) 的长方形面积 \(uv\)。\(u\) 变一点、\(v\) 变一点，面积多出来的主要是两条长边 \(v\cdot\Delta u\) 和 \(u\cdot\Delta v\)，角上那一小块 \(\Delta u\Delta v\) 小得可以忽略。开头 \(x\cdot x\) 的例子就是这样：\(1\cdot x+x\cdot1=2x\)。

例 2

求导：① \(f(x)=x^3-4x+\dfrac1x\)；② \(g(x)=x^2e^x\)；③ \(h(x)=\dfrac{\ln x}{x}\)。

① 逐项求导：\(f'(x)=3x^2-4-\dfrac{1}{x^2}\)。

② 积的法则，\(u=x^2\)，\(v=e^x\)：

$$g'(x)=2x\cdot e^x+x^2\cdot e^x=(x^2+2x)e^x$$

含 \(e^x\) 的乘积，把 \(e^x\) 提到外面，以后判断导数正负更方便。

③ 定义域 \(x>0\)。商的法则，\(u=\ln x\)，\(v=x\)：

$$h'(x)=\frac{\frac1x\cdot x-\ln x\cdot1}{x^2}$$

$$=\frac{1-\ln x}{x^2}$$

自己试试：求 \(y=\dfrac{x}{\cos x}\) 的导数，分子化简后是？

D。分子 \(=(x)'\cos x-x(\cos x)'=\cos x-x(-\sin x)=\cos x+x\sin x\)，所以 \(y'=\dfrac{\cos x+x\sin x}{\cos^2x}\)（\(\cos x\ne0\)）。

选 A 忘了 \((\cos x)'=-\sin x\) 的负号；选 B 是分子、分母各自求导再相除；选 C 是分子的减法顺序颠倒，正负号整个反了。

4. 简单复合函数 \(f(ax+b)\) 的导数

内层是一次式 \(ax+b\) 时，先按外层求导（括号里原样不动），再乘内层的系数 \(a\)：

$$[f(ax+b)]'=a\,f'(ax+b)$$

为什么乘 \(a\)：\(x\) 走一小步 \(\Delta x\)，内层 \(ax+b\) 走了 \(a\Delta x\)，是 \(x\) 的 \(a\) 倍，外层跟着变化的量也就放大到 \(a\) 倍。

例 3

求导：① \(y=e^{3x-1}\)；② \(y=\cos\left(2x+\dfrac\pi3\right)\)；③ \(y=\ln(1-2x)\)；④ \(y=(2x+1)^3\)。

① \(a=3\)：\(y'=3e^{3x-1}\)。

② \(a=2\)，外层 \((\cos u)'=-\sin u\)：\(y'=-2\sin\left(2x+\dfrac\pi3\right)\)。

③ 定义域 \(1-2x>0\)，即 \(x<\dfrac12\)。\(a=-2\)：\(y'=-2\cdot\dfrac{1}{1-2x}=\dfrac{2}{2x-1}\)。

④ \(a=2\)，外层 \((u^3)'=3u^2\)：\(y'=2\cdot3(2x+1)^2=6(2x+1)^2\)。

验算④：展开 \(y=8x^3+12x^2+6x+1\)，\(y'=24x^2+24x+6=6(2x+1)^2\)，一样。多项式展开后逐项求导也完全可以。

自己试试：\(f(x)=e^{-2x}\)，\(f'(0)\) 等于？

B。\(a=-2\)，\(f'(x)=-2e^{-2x}\)，\(f'(0)=-2e^0=-2\)。选 A 是以为 \(e\) 的指数函数求导不变、忘了乘内层系数；选 C 丢了系数的负号；选 D 是把 \(e^0\) 当成了 \(e\)。

5. 用之前要注意

  1. 积的导数不是导数的积。
    反例：\(x\cdot x=x^2\)，导数是 \(2x\)；导数相乘得 \(1\times1=1\)。
  2. 商的法则：分母 \(v\ne0\)，分子顺序是 \(u'v-uv'\)，颠倒了正负号全反。
    反例：\(\left(\dfrac{\ln x}{x}\right)'\) 写成 \(\dfrac{\ln x-1}{x^2}\)，在 \(0<x<e\) 上本来为正，算出来却为负。
  3. 复合 \(f(ax+b)\) 一定乘内层系数 \(a\)，\(a\) 是负数时连负号一起乘。
    反例：\((e^{3x})'=3e^{3x}\)，不是 \(e^{3x}\)；\([\ln(4-x)]'=\dfrac{-1}{4-x}\)，不是 \(\dfrac{1}{4-x}\)。
  4. 先查定义域，端点处公式不一定能用。
    反例：\(\sqrt x\) 在 \(x=0\) 有定义，但 \((\sqrt x)'=\dfrac{1}{2\sqrt x}\) 在 \(x=0\) 没有意义，\(\sqrt x\) 在 \(0\) 处没有导数；\(\ln x\) 和它的导数都只在 \(x>0\) 上谈。
  5. 三角函数按弧度求导。
    反例：如果 \(x\) 用度，\(x^\circ=\dfrac{\pi x}{180}\)，那么 \((\sin x^\circ)'=\dfrac{\pi}{180}\cos x^\circ\)，不再是 \(\cos x^\circ\)。
  6. 本节的复合只到 \(f(ax+b)\)；多项式形式的可以展开再求导（例 3 ④）。内层不是一次式的（如 \(\ln(x^2+1)\)），不当作本节已学的方法，见下面「再深一点」。
先写定义域 → 认清结构（和差、积、商，还是 \(f(ax+b)\)）→ 查表、套法则 → 化简。
再深一点（可以先跳过）

内层不是一次式怎么办：一般的复合函数 \(y=f(g(x))\) 有更一般的规则 \(y'=f'(g(x))\cdot g'(x)\)，\(f(ax+b)\) 是它在 \(g(x)=ax+b\) 时的特例。例如 \([\ln(x^2+1)]'=\dfrac{2x}{x^2+1}\)。教材展示过这种关系，但课程要求只到 \(f(ax+b)\)，考试中遇到更复杂的内层，题目一般会另给条件或换别的路子。

商的法则可以从积的法则推：\(\dfrac uv=u\cdot\dfrac1v\)，而 \(\left(\dfrac1v\right)'=-\dfrac{v'}{v^2}\)，代进积的法则：\(\dfrac{u'}{v}-\dfrac{uv'}{v^2}=\dfrac{u'v-uv'}{v^2}\)。记不住顺序时，可以这样推一遍。

1.0

直接用

1. 已知函数 \(f(x) = x^2 - 3x + \ln x\)，则导数值 \(f'(1)\) 的值为：

B。求导函数：\(f'(x) = 2x - 3 + \dfrac{1}{x}\)。代入 \(x = 1\)：\(f'(1) = 2(1) - 3 + \dfrac{1}{1} = 2 - 3 + 1 = 0\)。此时曲线在点 \((1, f(1))\) 处的切线为水平切线！

2. 函数 \(f(x) = \sin(2x - 1)\) 的导函数 \(f'(x)\) 等于：

A。根据线性内层复合函数求导法则 \([f(ax+b)]' = a f'(ax+b)\)：内层 \(u = 2x-1\) 的导数为 2，外层正弦导数为余弦。因此 \(f'(x) = 2\cos(2x - 1)\)。

易错

3. 函数 \(f(x) = \dfrac{x}{e^x}\) 的导函数 \(f'(x)\) 化简后的形式为：

C。商的法则：\(f'(x) = \dfrac{(x)'e^x - x(e^x)'}{(e^x)^2} = \dfrac{1\cdot e^x - x e^x}{e^{2x}} = \dfrac{e^x(1 - x)}{e^{2x}} = \dfrac{1 - x}{e^x}\)。严防分子减法次序颠倒写成 \(x - 1\)！

4. 曲线 \(y = e^x + x\) 在点 \((0, 1)\) 处的切线方程为：

D。求导 \(y' = e^x + 1\)。在点 \((0, 1)\) 处的导数值（切线斜率）为 \(k = y'|_{x=0} = e^0 + 1 = 1 + 1 = 2\)。由点斜式：\(y - 1 = 2(x - 0) \implies y = 2x + 1\)。

挑战进阶

5. 若直线 \(y = kx\) 是曲线 \(y = \ln x\) 的一条切线，则斜率 \(k\) 的值为：

B。直线 \(y = kx\) 过原点 \((0, 0)\)，这是典型的「过原点切线」问题！设切点为 \((t, \ln t)\)。求导 \(y' = \dfrac{1}{x} \implies\) 切线斜率 \(k = \dfrac{1}{t}\)。切线方程为 \(y - \ln t = \dfrac{1}{t}(x - t)\)。代入原点 \((0, 0)\)：\(-\ln t = -1 \implies \ln t = 1 \implies t = e\)。因此斜率 \(k = \dfrac{1}{t} = \dfrac{1}{e}\)（极度经典的对数过原点切线结论！）。
