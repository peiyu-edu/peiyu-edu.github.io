29.1 圆的有关概念

一切平面图形中最美的是圆！从车轮为什么是圆的、石子击水波纹到平面几何中的动静结合，掌握圆的动态旋转与静态集合双重定义，理解弦、直径、弧与等弧的严格内涵，通晓点与圆的三种位置关系，掌握三点确定圆与三角形外心。

本节导读　先修：6.2 直线、射线、线段 · 15.1 线段的垂直平分线 · 本节路线

要用到：线段的长度与两点间距离（回看 6.2）、线段垂直平分线的性质（回看 15.1）、平面直角坐标系中的点坐标（回看 9.1）。

  1. 从自行车车轮平稳前行切入：为什么圆心到地面高度恒定？
  2. 圆的双重定义：动态旋转与平面内到定点距离等于定长的所有点的集合；
  3. 圆的要素清单：弦、直径、弧（优弧与劣弧）、等圆与等弧辨析；

  5. 确定圆的条件与三角形外心：不在同一直线上的三点确定一个圆，外心位置的三态跃迁；
  6. 动手交互实验：点圆动态探针台与进阶三角形外接圆三态跃迁台（含重置按钮）；
  7. 巩固练习与真题演练，吃透点圆位置不等式与三角形外接圆半径计算。

古希腊哲学家毕达哥拉斯曾说：“一切立体图形中最美的是球，一切平面图形中最美的是圆。”日常生活中，大到摩天轮、汽车轮子，小到硬币、钟表，几乎所有需要平稳转动的部件都制成圆形。如果把车轮做成正方形或椭圆形，汽车行驶起来会怎样？

为什么圆形车轮在平地上滚动时，坐在车上的人感觉非常平稳，没有丝毫上下颠簸？根本原因在于（ ）

C。车轴安装在圆心位置。当车轮在地面滚动时，车轮接触地面的点永远在圆周上，而圆周上任意一点到圆心的距离恒等于半径 \(r\)。

因此车轴到地面的垂直距离永远保持为 \(r\)，车身在水平直线上匀速前行，绝不会上下颠簸。这正是圆最朴素也是最本质的几何特征——到定点的距离等于定长。

1. 先认识几个词：什么是圆与它的核心要素？

圆

到定点距离等于半径的点组成圆。

圆内

到圆心距离小于半径的点组成圆内部，不包括圆周。

抓住关系： \(\color{#2F7A56}{\underbrace{d}_{\text{到圆心距离}}}\lt\color{#966524}{\underbrace{r}_{\text{半径}}}\)

先检查条件，再使用关系；彩色标注帮助区分量。

前置知识：旋转的定义（回看 28.1）。在初中阶段，我们从“运动”与“集合”两个视角完整理解圆：

  • 动态形成观点：在平面内，线段 \(OP\) 绕它固定的一个端点 \(O\) 旋转一周，另一个端点 \(P\) 所形成的封闭曲线叫作圆（circle）。定点 \(O\) 叫作圆心，线段 \(OP\) 的长 \(r\) 叫作半径。记作“\(\odot O\)”，读作“圆 \(O\)”。
  • 静态集合观点：圆是平面内到定点（圆心）的距离等于定长（半径）的所有点的集合。
  • 弦与直径：连接圆上任意两点的线段叫作弦（chord）。经过圆心的弦叫作直径（diameter）。直径是圆中最长的弦，直径长等于 \(2r\)。
  • 弧（圆弧）：圆上任意两点间的部分叫作弧（arc）。小于半圆的弧叫劣弧（用两字母表示如 \(\widehat{AB}\)）；大于半圆的弧叫优弧（用三字母表示如 \(\widehat{ACB}\)）；等于半圆周的弧叫半圆。
  • 等圆与等弧：半径相等的两个圆叫作等圆；在同圆或等圆中，能够互相重合的弧叫作等弧（等弧不仅长度相等，所对圆心角也相等）。

直觉微图解 ①圆的基础构件剖析：圆心、半径、弦、优劣弧

自己试试 1：下列关于圆的基础概念中，表述正确的是（ ）

D。逐项辨析：

  • A 直径是特殊的弦（过圆心），但一般的弦不是直径；
  • B 等弧的定义是在「同圆或等圆中」能够完全重合的弧，若两弧在不同大小的圆中，即便长度相等弯曲度也不同，不能重合；
  • C 半圆是一段圆弧（曲线），不是直线；
  • D 正确，直径两端在圆上且过圆心，是圆中长度最大的弦。
深挖：为什么“等弧”必须强调在“同圆或等圆中”？

日常生活中，很多同学容易把“弧长相等”误当成“等弧”。

例如：小圆半径为 1，半圆弧长是 \(\pi\)；大圆半径为 2，四分之一圆弧长也是 \(\frac{1}{4} \times 4\pi = \pi\)。虽然这两条弧长度完全一样（都是 \(\pi\)），但把它们叠放在一起，小圆弧弯曲得更厉害，大圆弧更平缓，根本无法完全重合！因此，只有在半径相等的圆里，弯曲度与长度都完全一致的弧才叫等弧。

2. 点与圆的位置关系：三种状态的严格数量等价

设 \(\odot O\) 的半径为 \(r\)，点 \(P\) 到圆心 \(O\) 的距离为 \(d = OP\)：

  • 点在圆内 \(\iff d \lt r\)（点位于圆所围成的内部区域）；
  • 点在圆上 \(\iff d = r\)（点恰好位于圆周边界曲线上）；
  • 点在圆外 \(\iff d \gt r\)（点位于圆周外部区域）。

直觉微图解 ②点与圆位置判定：距离 d 与半径 r 的三种对比

自己试试 2：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 3\)，\(BC = 4\)。以点 \(C\) 为圆心，\(r = 3\) 为半径作 \(\odot C\)，则点 \(B\) 与 \(\odot C\) 的位置关系是（ ）

B。圆心为点 \(C\)，点 \(B\) 到圆心 \(C\) 的距离为 \(BC = 4\)。

圆的半径为 \(r = 3\)。因为距离 \(d = 4 \gt 3 = r\)，点 \(B\) 到圆心的距离大于半径，所以点 \(B\) 落在 \(\odot C\) 的外部。

典例 1（波利亚四步法）：由点与圆的位置关系求半径取值范围

【例 1】在矩形 \(ABCD\) 中，\(AB = 3\)，\(AD = 4\)。以点 \(A\) 为圆心作 \(\odot A\)，若点 \(B, D\) 中至少有一个点在 \(\odot A\) 内，且至少有一个点在 \(\odot A\) 外，求 \(\odot A\) 的半径 \(r\) 的取值范围。

  1. ① 读懂题意：圆心是顶点 \(A\)，已知矩形邻边 \(AB = 3, AD = 4\)，要求点 \(B, D\) 一点在圆内、一点在圆外，求半径 \(r\) 的范围。
  2. ② 想办法：先算出点 \(B, D\) 到圆心 \(A\) 的距离 \(d_B = AB = 3\)，\(d_D = AD = 4\)。因为 \(d_B \lt d_D\)，所以只能是距离较近的点 \(B\) 在圆内、距离较远的点 \(D\) 在圆外。
  3. ③ 执行 + 执行中检查：由点 \(B\) 在 \(\odot A\) 内得 \(r \gt AB = 3\)；由点 \(D\) 在 \(\odot A\) 外得 \(r \lt AD = 4\)（检查：当 \(r=3\) 时点 \(B\) 在圆上，当 \(r=4\) 时点 \(D\) 在圆上，均不满足“在圆内/外”，故不能取等号）。因此 \(3 \lt r \lt 4\)。
  4. ④ 回头看：如果题目问的是「矩形的三个顶点 \(B, C, D\) 中至少有一点在圆内、至少有一点在圆外」，则需算出最远点 \(AC = \sqrt{3^2+4^2} = 5\)，范围就变为 \(3 \lt r \lt 5\)。

3. 确定圆的条件与三角形的外接圆

几个点可以确定一个圆？这是尺规作图与几何解析的基石：

  • 过一个点：可以作无数个圆（圆心在平面任意位置，半径任意）；
  • 过两个点：可以作无数个圆（圆心在线段 \(AB\) 的垂直平分线上）；
  • 过三个点：不在同一直线上的三点确定一个圆（圆心是任意两边垂直平分线的交点，有且只有一个）；
  • 三角形外接圆与外心：经过三角形三个顶点的圆叫作外接圆，外接圆的圆心叫作三角形的外心。外心到三角形三个顶点距离相等（\(OA = OB = OC = R\)）。

直觉微图解 ③三角形外心三态跃迁：锐角、直角、钝角

自己试试 3：一个直角三角形的两条直角边长分别为 6 和 8，则该直角三角形的外接圆半径为（ ）

A。在直角三角形中，斜边为 \(\sqrt{6^2 + 8^2} = 10\)。

直角三角形的外心是斜边的中点，外接圆的直径恰好等于斜边，因此外接圆半径等于斜边的一半，即 \(R = \frac{10}{2} = 5\)。这是中考极高频的经典考点！

思考：为什么同一直线上的三点不能确定一个圆？

若三点 \(A, B, C\) 在同一直线上，作线段 \(AB\) 的垂直平分线 \(l_1\) 和线段 \(BC\) 的垂直平分线 \(l_2\)。

因为 \(l_1 \perp AC\) 且 \(l_2 \perp AC\)，所以在同一平面内，垂直于同一直线的两直线互相平行（\(l_1 \parallel l_2\)）。两条平行线永远不会相交，因此找不到到三点距离都相等的点作为圆心！所以“不在同一直线上”是确定圆不可或缺的数学前提。

典例 2（波利亚四步法）：坐标系中求直角三角形的外心坐标与半径

【例 2】在平面直角坐标系中，点 \(A(0, 4), B(6, 0), O(0, 0)\)，求经过 \(A, B, O\) 三点的圆的圆心坐标与半径。

  1. ① 读懂题意：已知坐标原点 \(O(0,0)\) 与坐标轴上的两点 \(A(0,4), B(6,0)\)，\(\angle AOB = 90^\circ\)，求 \(\triangle AOB\) 外接圆的圆心与半径。
  2. ② 想办法：因为 \(\angle AOB = 90^\circ\)，\(\triangle AOB\) 是直角三角形，斜边为 \(AB\)。根据直角三角形外心性质，外心即为斜边 \(AB\) 的中点，半径为斜边长的一半。
  3. ③ 执行 + 执行中检查：斜边 \(AB\) 的中点坐标为 \(M\left(\frac{0+6}{2}, \frac{4+0}{2}\right) = (3, 2)\)；由勾股定理得斜边长 \(AB = \sqrt{6^2 + 4^2} = \sqrt{52} = 2\sqrt{13}\)，故外接圆半径 \(R = \frac{1}{2}AB = \sqrt{13}\)（检查：\(MO = \sqrt{3^2+2^2} = \sqrt{13}\)，\(MA = \sqrt{3^2+(2-4)^2} = \sqrt{13}\)）。
  4. ④ 回头看：见到 \(90^\circ\) 直角顶点，立即锁定「斜边中点即外心」，免去繁琐的两条垂直平分线联立计算。

用之前必查：三大翻车现场

翻车 1
错误：圆内包含圆周
核对：d=r 表示点在圆上，不属于圆内。
翻车 2
错误：三点总能确定一个圆
核对：三点不共线才确定一个圆；共线三点无法同在一个圆上。
翻车 3
错误：外心总在三角形内部
核对：钝角三角形的外心在外部，直角三角形在斜边中点。

练习 1：已知 \(\odot O\) 的半径为 5，点 \(P\) 到圆心 \(O\) 的距离为 4，则点 \(P\) 与 \(\odot O\) 的位置关系是（ ）

C。因为 \(OP = 4 \lt 5 = r\)，距离小于半径，所以点 \(P\) 在圆内。

练习 2：直角三角形的三边长分别为 5、12、13，则该三角形的外接圆半径是（ ）

D。直角三角形斜边为最长边 13。外心在斜边中点，外接圆半径等于斜边的一半，即 \(R = \frac{13}{2} = 6.5\)。

练习 3：在同一平面内有四个点，其中任意三点都不在同一直线上，且这四个点不在同一个圆上。经过其中任意三点作圆，一共可以作出的不同圆的个数是（ ）

B。从四个点中任选三个点共有 4 种选法（每次留下一个点不选）。因为任意三点不共线，每组三点都能确定一个圆；又因为这四个点不在同一个圆上，所以这 4 组三点所确定的圆互不重合，共能作出 4 个不同的圆（注：若四点恰好共圆，则只能作出 1 个圆）。

练习 4：已知 \(\odot O\) 的直径为 10，点 \(P\) 在 \(\odot O\) 外，则线段 \(OP\) 的长度 \(d\) 必须满足（ ）

C。直径为 10，所以半径 \(r = 5\)。点在圆外的充要条件是点到圆心的距离严格大于半径，即 \(d \gt 5\)。

练习 5：已知 \(\odot O\) 的半径为 \(4\text{ cm}\)，点 \(A\) 到圆心 \(O\) 的距离为 \(3\text{ cm}\)，点 \(P\) 为 \(\odot O\) 上的一个动点，则线段 \(AP\) 的最小值为（ ）

提示

先判断点 \(A\) 在圆内还是圆外，再连接 \(OA\) 并延长交 \(\odot O\) 于近端点，最小距离为 \(r - d\)。

C。因为 \(d = OA = 3\text{ cm} \lt r = 4\text{ cm}\)，所以点 \(A\) 在 \(\odot O\) 内。过点 \(O, A\) 作直径，当动点 \(P\) 位于射线 \(OA\) 与 \(\odot O\) 的交点时，\(AP\) 取得最小值 \(r - d = 4 - 3 = 1\text{ cm}\)（最大值为 \(r + d = 7\text{ cm}\)）。

易错提醒：直径与半径陷阱

审题时务必看清题干给出的是“半径”还是“直径”！点与圆位置的判定标准是 \(d\) 与半径 \(r\) 比较，若题中给出直径，必须先除以 2 求出半径，切勿直接用直径判断。

巩固练习 1：已知 \(\odot O\) 的半径为 \(3\)，若点 \(P\) 在 \(\odot O\) 上，则点 \(P\) 到圆心 \(O\) 的距离为______．

查看答案与解析，自行核对

答案：3

因为点 \(P\) 在 \(\odot O\) 上，根据点与圆的位置关系可知，点 \(P\) 到圆心 \(O\) 的距离 \(d\) 等于半径 \(r = 3\)．

巩固练习 2：下列说法中，正确的是（　）

C。逐项辨析：A 项，必须在“同圆或等圆中”，能够互相重合的弧才是等弧，仅长度相等但半径不同的弧不是等弧，故 A 错误；B 项，半圆是弧，但它是曲线段而非连接两点的线段，不是弦，故 B 错误；C 项，直径是经过圆心的弦，是圆中最长的弦，故 C 正确；D 项，经过“不在同一直线上的三点”才确定一个圆，共线三点不能作圆，故 D 错误．故选 C．

巩固练习 3：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 3\)，\(BC = 4\)．以点 \(A\) 为圆心，\(r\) 为半径作 \(\odot A\)，若点 \(C\) 在 \(\odot A\) 内，且点 \(B\) 在 \(\odot A\) 外，则半径 \(r\) 的取值范围是（　）

C。在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 3\)，\(BC = 4\)，由勾股定理得斜边 \(AB = \sqrt{AC^2 + BC^2} = \sqrt{3^2 + 4^2} = 5\)．以点 \(A\) 为圆心时，点 \(C\) 到圆心 \(A\) 的距离为 \(AC = 3\)，点 \(B\) 到圆心 \(A\) 的距离为 \(AB = 5\)．因为点 \(C\) 在 \(\odot A\) 内，所以 \(r > AC = 3\)；因为点 \(B\) 在 \(\odot A\) 外，所以 \(r < AB = 5\)．综上，\(3 < r < 5\)，故选 C．

巩固练习 4：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 6\)，\(BC = 8\)，则 \(\triangle ABC\) 的外接圆半径为（　）

B。在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 6\)，\(BC = 8\)，由勾股定理得斜边 \(AB = \sqrt{AC^2 + BC^2}\)，即 \(AB = \sqrt{6^2 + 8^2} = 10\)．因为直角三角形的外心是斜边的中点，外接圆半径等于斜边的一半，所以外接圆半径 \(R = \frac{1}{2}AB = 5\)，故选 B．
