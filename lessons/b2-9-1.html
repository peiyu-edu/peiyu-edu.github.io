9.1 随机抽样

想知道一大群人的情况，往往只能问其中一部分人。问谁、怎么挑，才能让这一部分「像」整体？先从一锅汤说起。

一大锅汤煮好了，想知道它咸不咸。先点下面的按钮试试三种尝汤办法：

下面哪种做法最合适？

B。喝完整锅当然最准，可汤也没了；只尝一勺就够，前提是先搅匀，让锅里每个地方都有同样的机会进到勺子里。C 尝到的只是上面一层，代表不了整锅。

这就是本节的两件事：全部检查还是只看一部分；只看一部分时，怎么「搅匀」——也就是随机抽样。

1. 先认识几个词

要用到：初中平均数、普查与抽样调查的现实意义。统计学第一课，核心在于「用局部样本科学推断总体」。

直观微图解
简单随机抽样铁律：总体容量 N 中抽取样本量 n，每个个体入样概率恒为 n/N。
简单随机抽样 总体均质无显著差异

适用条件：总体中各对象个体差异不大、无明显分块类别。

核心机制：不放回抽样中，每一次未被抽到的个体机会均等，全过程每个个体入样概率均为 \(\frac{n}{N}\)。

实施手段：抽签法（编号、做签、搅匀）、随机数法（计算机/随机数表）。

分层随机抽样 总体类别差异显著

适用条件：总体内部差异明显（如不同年级、城乡、年龄段对指标有显著区别）。

核心机制：按比例分配（每层抽样比 \(\frac{n_i}{N_i} = \frac{n}{N}\) 恒定一致）。

估计优势：样本结构严格等比复刻总体结构，大幅降低系统抽样方差与误差！

总体与个体：研究对象的全体叫总体（容量 \(N\)），其中每一个对象叫个体。

样本与样本量：从总体抽出的子集叫样本，包含的个体数叫样本量（\(n\)）。

全面调查 vs 抽样调查：破坏性检验（如测灯泡寿命、测导弹命中）或总体过大时绝对只能抽样调查！仅在关乎生命安全或个体量很小且必须全员覆盖时采用全面普查。

2. 全面调查与抽样调查的决策

例 1（看一遍怎么判断）

下面四件事，各用哪种调查？

  1. 火箭发射前检查每个关键零件。——全面调查：零缺陷要求，必须个个查。
  2. 了解全国中学生的视力健康状况。——抽样调查：总人数过大，成本无法承受。
  3. 检测一批袋装牛奶的细菌指标。——抽样调查：破坏性检测，拆袋即损耗。
  4. 统计全班 40 人的校服尺码。——全面调查：一人一服，样本量小且需精确对齐。

自己试试：工厂想知道一批 \(5000\) 只灯泡平均能亮多少小时。应该用哪种调查？

B。破坏性测试：测完 5000 只灯泡全部报废，无货可卖！选 A 的同学只想到了理论准确性，忽视了工程代价。

3. 简单随机抽样与等可能概率

$$\color{#0284c7}{P(\text{任何个体被抽进样本}) = \frac{n}{N} \quad (\text{机会绝对均等})}$$ $$\color{#d97706}{\text{样本均值: } \bar{y} = \frac{y_1 + y_2 + \cdots + y_n}{n} \quad \implies \text{用于无偏估计总体均值 } \bar{Y}}$$
不放回抽样第 1 次被抽到的概率是 \(\frac{1}{N}\)，但累计被抽中概率仍是 \(\frac{n}{N}\)，人人平等！

例 2（抽签法与均值估计）

全班 40 人，用抽签法抽取 5 人调查每周运动时长，样本数据为 \(3, 6, 4, 8, 4\) 小时。求样本均值并解释其统计意义。

解：样本均值 \(\bar{y} = \dfrac{3+6+4+8+4}{5} = \dfrac{25}{5} = 5\) 小时。以此估计全班平均每周运动约为 5 小时。注意：换一组抽签样本，\(\bar{y}\) 会围绕总体均值波动，这正是随机抽样的抽样误差本质。

自己试试：从 \(60\) 名同学中，不放回地简单随机抽取 \(6\) 人。小明被抽中的可能性是多少？

C。第 1 次未抽到为 \(\frac{59}{60}\)，第 2 次在剩下 59 人中未抽到为 \(\frac{58}{59}\)……连乘得一直未被抽中概率为 \(\frac{54}{60} = \frac{9}{10}\)。因此小明被抽中的总概率为 \(1 - \frac{9}{10} = \frac{1}{10} = \frac{6}{60}\)！选 A 错在只算了第 1 次抽取。

4. 分层抽样与三步思维链

$$\color{#d97706}{\text{按比例分配公式: } n_i = n \cdot \frac{N_i}{N} \iff \frac{n_i}{N_i} = \frac{n}{N} = k \quad (\text{抽样比恒定})}$$ $$\color{#059669}{\text{总体均值加权估计: } \bar{y} = \sum_{i=1}^k \frac{N_i}{N}\bar{y}_i = \frac{n_1\bar{y}_1 + n_2\bar{y}_2 + \cdots + n_k\bar{y}_k}{n}}$$
典型题三步思维链：分层抽样配比与加权总均值计算

题目：某高中共有学生 1500 人，其中高一 600 人、高二 500 人、高三 400 人。现采用分层随机抽样抽取 60 人调查每周运动时长。若三层样本均值分别为 6.5 小时、5.0 小时、3.5 小时，求各层抽样人数及全校平均时长的估计值。

1
👀 第一眼破题信号： 总体由高中三个年级构成（年级差异极大），总容量 \(N=1500\)，抽取样本总量 \(n=60\)。必须采用按比例分层随机抽样！
2
🔧 第二步套公式/方法（配比与加权）：

① 统一抽样比：\(k = \dfrac{n}{N} = \dfrac{60}{1500} = \dfrac{1}{25}\)。

② 各层样本量分配：
高一年级抽：\(n_1 = 600 \times \dfrac{1}{25} = 24\) 人；
高二年级抽：\(n_2 = 500 \times \dfrac{1}{25} = 20\) 人；
高三年级抽：\(n_3 = 400 \times \dfrac{1}{25} = 16\) 人。
（校验：\(24 + 20 + 16 = 60\) 人，总数严格吻合！）

③ 加权平均数估计总体均值：
\(\bar{y} = \dfrac{24 \times 6.5 + 20 \times 5.0 + 16 \times 3.5}{60} = \dfrac{156 + 100 + 56}{60} = \dfrac{312}{60} = 5.2\) 小时。

3
🛡️ 第三步必查防坑结论： ① 这里不能直接简单平均各层样本均值（\(\frac{6.5+5.0+3.5}{3} = 5.0\)），因为各层总体人数不同；按各层总体比例加权，估计总体均值为 5.2；
② 核算各层抽取人数必须全为整数，且总和等于 60。

自己试试：公司有男职工 \(120\) 人、女职工 \(80\) 人，按性别分层、按比例抽 \(30\) 人。女职工抽几人？

A。女职工占 \(\dfrac{80}{200}=\dfrac25\)，抽 \(30\times\dfrac25=12\) 人（男职工 \(18\) 人）。选 B 是两层平分，不是按比例；选 C 是把男职工的人数当成了女职工的。

5. 获取数据的四种途径

例 4（途径选择辨析）

  • 调查：通过问卷、访谈直接收集对象信息（如中学生作息问卷）。
  • 试验：人工控制变量做对照比较（如农业双盲施肥增产对照试验）。
  • 观察：不干涉对象自然状态进行追踪记录（如每天记录气象雷达数据）。
  • 查询：检索官方或公开数据库（如查阅国家统计局年鉴）。

自己试试：想知道一种新肥料能不能让番茄增产，最合适的获取数据途径是？

A。必须人工设置单一变量对照（同土质同水肥对照组），方能排除土壤等干扰。选 B 无法确定收成好是否源自该肥料。

6. 三大翻车现场与反例微图解

翻车点 1 分层抽样总均值胡乱简单平均

❌ 各层样本均值分别为 \(a, b, c\)，总均值直接算 \(\frac{a+b+c}{3}\)。

✔ 必须按比例加权：各层人数不同权重不同！必须用 \(\sum \frac{N_i}{N}\bar{y}_i\)，否则大层被稀释、小层被虚夸！

翻车点 2 把“随意街采”当成“随机抽样”

❌ 在商场门口、网吧门口随便拦人调查，声称是简单随机抽样。

✔ 机会均等才是随机：特定地点街采存在巨大自选择偏差，完全剥夺了不在场人群的入样概率，属于严重有偏样本！

翻车点 3 以为“样本量够大就能消除偏差”

❌ 在网上发问卷收集了 10 万份数据，就认定结论必然代表全体国民。

✔ 抽法偏，数据再多也白搭：网民群体偏年轻、爱表达，10 万份自填问卷依然存在系统性幸存者偏差，无法代表全量总体！

反例微图解：简单平分 vs 加权平均（均值天平失衡陷阱）

大层（900人，均值2）与小层（100人，均值10），若错用简单平分算得均值 6.0，实际真值仅为 2.8！直接平均会导致天平严重失衡！

再深一点（可以先跳过）

抽样框偏差：抽样名单本身若有遗漏（如用固定电话簿做民调，漏掉无座机年轻人），再完美的抽样算法也无法修正基础偏差。

分层抽样方差：分层抽样不仅能保证结构代表性，且当各层间差异较大、层内方差较小时，分层估计量的抽样方差显著小于简单随机抽样。

① 简单随机与分层：各抽几次比一比

全校 \(200\) 人，圆越大表示每周运动越久；高一多、高三少（\(100:60:40\)）。选样本量 \(n\)，点按钮抽样：抽到的人会加粗，下面的数轴上记一道样本均值。多抽几次，看哪一行的竖线挤得更紧。

② 进阶：人多救不了抽法偏

换成 \(1000\) 人的学校。两种抽法各抽 \(12\) 次：绿点是随机抽样，红点是只在操场上拉人问（越爱运动越容易被问到）。横轴是样本量。拖动滑块看某个样本量下两种抽法的样本均值落在哪里。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 某校高一 \(900\) 人、高二 \(800\) 人、高三 \(700\) 人，按年级分层、按比例抽 \(48\) 人。高二应抽几人？

B。总人数 \(2400\)，抽样比例 \(\dfrac{48}{2400}=\dfrac1{50}\)，高二抽 \(800\times\dfrac1{50}=16\) 人（高一 \(18\)、高三 \(14\)，合计 \(48\)）。选 A、C 是看错了年级；选 D 是把 \(48\) 平分成了 \(4\) 份，可只有 \(3\) 个年级，而且不该平分。

2. 某年级男生 \(300\) 人、女生 \(200\) 人，按性别分层、按比例抽样。男生样本的平均身高 \(172\) cm，女生样本的平均身高 \(162\) cm。估计全年级平均身高是？

A。男生占 \(\dfrac{300}{500}=0.6\)，女生占 \(0.4\)：\(0.6\times172+0.4\times162=103.2+64.8=168\)。选 B 是把两个均值直接平均，忘了男生人数多、权重大。

易错

3. 学校想了解学生每天睡几小时，在校园网上挂了问卷，一周收到 \(800\) 份。下面说法对的是？

B。「没人指定」不等于「随机」：随机是每个人被抽到的机会相等，而这里只有看到问卷、又愿意花时间填的人才进了样本，比如熬夜上网的人可能更容易看到。C 错在以为人多就行，抽法偏了，人再多也不行。

4. 某区城区学生 \(800\) 人、郊区学生 \(200\) 人，两层各随机抽 \(50\) 人。城区样本每周阅读时间平均 \(4\) 小时，郊区样本平均 \(9\) 小时。估计全区学生平均每周阅读时间是？

C。两层各抽 \(50\) 人，不是按比例分配：郊区只占总体的 \(\dfrac{200}{1000}=0.2\)，在样本里却占了一半。要按总体比例加权：\(0.8\times4+0.2\times9=3.2+1.8=5\)。选 A 是把 \(100\) 人直接平均。

5. 想估计全市成年人每周运动多久。甲在几家健身房门口问了 \(2000\) 人；乙从全市居民名单中随机抽了 \(200\) 人。哪个结果更可信？

B。健身房门口的人大多爱运动，甲的抽法本身偏高，问 \(2000\) 人还是偏高，样本量修不了这种偏差。乙的样本小一些，误差来自运气，有时高有时低，不会一直偏向一边。（也不是说乙每一次都比任何样本准，只是它没有系统偏差。）

挑战

6. 学校要了解学生每天用手机的时长，已知住校生和走读生差别很大，男生女生差别不大。全校住校生 \(480\) 人、走读生 \(720\) 人，要抽 \(50\) 人。最合适的方案是？

B。分层要按和研究的量有关的特征分：手机时长和住不住校关系大，和男女关系小，所以 A 分了作用不大。

按比例：\(50\times\dfrac{480}{1200}=20\)，\(50\times\dfrac{720}{1200}=30\)。C 两层各 \(25\) 人不是按比例，住校生被多抽了，直接平均会偏向住校生；要用 C 的数据，得按 \(0.4\) 和 \(0.6\) 加权。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
