02 / 一层一层数 p

vp(n!) 是 n! 中素数 p 的指数。图中的每一行是一层额外的 p；先预测总数再展开。

提交整数预测后，查看逐层计数与整点图。

为什么这样数？

取整：朝负无穷方向

⌊x⌋ = k 当且仅当 k ≤ x < k + 1，其中 k 是整数。因此小数部分 {x} = x − ⌊x⌋ 满足 0 ≤ {x} < 1。

截断是朝 0 去掉小数。非负数的截断与取整相同；负的非整数应先找到左侧的整数，不能把截断当成取整。可改变横坐标，核对后比较两种运算的读数。

在整数 k 处：左极限是 k − 1，函数值和右极限都是 k。图像每一级是 [k, k + 1)，故取整函数右连续，整数处不连续。

勒让德：按整除的层数计数

n 是非负整数且 p 是素数时，vp(n!) = ∑j≥1⌊n / pj⌋。

对每个整数 m（1 ≤ m ≤ n），设 m 中有 e 个因子 p。它恰好被 p、p²、…、pᵉ 整除，所以在前 e 层各贡献 1。把有限个 m 的贡献按层相加，第 j 层就是 1 到 n 中 pʲ 的倍数个数，等于 ⌊n / pʲ⌋。当 pʲ > n 后各层均为 0，因此求和有限。

当 p = 2 时，第一层数偶数，第二层再数 4 的倍数，第三层再数 8 的倍数。这种重复恰好反映各数含有多个 2。提交预测后可以查看当前 n 的完整分层。

边界：0! = 1；p > n 时，1 到 n 中没有 p 的正倍数。用这两个事实判断计数，再提交预测查看各层。p 必须是素数：若把 p = 4 代入上述和式，n = 6 得 1，但 6! = 720 可被 4² 整除而不能被 4³ 整除，最高指数是 2，公式失效。

精确范围与显示范围

取整控件使用有限精度 JavaScript Number；若输入细小差别已被浮点舍入为整数，按舍入后的实际 x 计算，不用容差把近整数吸附到跳点。此处只观察 −6 到 6。n 以十进制文本转为 BigInt，不先转 Number；上限为 100 位，p 的上限为 1 000 000。指数和幂也用 BigInt。每轮把商整除 p，正商严格变小，最终归零，不会溢出或死循环。

n ≤ 100 时显示完整倍数整点；更大的 n 只显示各层精确计数与相对条形长度，不把截取的点阵冒充全体。滑条只控制小范围；大整数请使用文本框。改变条件会清空旧预测与反馈。所有运算在本页进行，不写学习记录。
