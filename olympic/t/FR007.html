本专题核心公式速查

解不等式首先是在原定义域内做等价变形。分母符号、根式非负、对数底数和量词，决定下一步能否同乘、平方或取交并。参数题要同时证明必要性与充分性；求得区间后，还须把严格等号点、禁值和退化参数逐一放回原式检查。

先修（培玉高中数学）：等式性质与不等式性质二次函数与一元二次方程、不等式函数的基本性质对数全称量词与存在量词
知识要点方法卡误区对照概念自测真题

知识要点

定义域先于代数运算

根号内要非负，分母不能为零，对数真数须为正，底数还要正且不等于 1。这些条件要贯穿全过程，化简后有定义不代表原式也有定义。例：log2​(x−1)+4−x​/(x−2) 的定义域为 (1,2)∪(2,4]；分母禁值 2 不能因后续不等式恰好允许它就补回。

分式与因式符号由临界点控制

先移到一边并通分，再将分子零点、分母零点共同标在数轴上。分母根始终排除，分子根是否保留取决于严格性。例：(x−1)/(x+2)≤0 的解集是 (−2,1]。不能直接同乘符号未知的分母；可分区间定号，或乘其平方并保留原来的非零条件。

平方只有在符号允许时才等价

∣A∣≥∣B∣ 等价于 (A−B)(A+B)≥0，因为两边本来非负。A​≥B 则先要求 A≥0，再按 B 的符号判断是否需要平方。例：x+2​≥x 在 −2≤x≤0 自动成立；x>0 时平方得 x+2≥x2，最终解集为 [−2,2]。严格不等号还需单查零值。

绝对值是距离，也有精确统一界

当 r>0，∣x−a∣<r 等价于 a−r<x<a+r；若 r≤0 则严格不等式无解。三角不等式还给 ∣x−a∣−∣x−b∣≤∣a−b∣，在 x=b 时达到右端。例：∣x−2∣−∣x+1∣≤3 对所有实数 x 成立，x=−1 取等；这类界可以直接把全称条件化成参数条件。

单调函数把比较转回自变量

严格递增函数保持不等号方向，严格递减函数反向；使用反函数还须确认输入属于原函数值域。例：f(t)=3t−3−t 在实轴严格递增且值域为实轴，所以 ∣f−1(y)∣<1 等价于 −8/3<y<8/3。偶函数常只需研究正半轴，但按绝对值比较时仍不能忘记原函数的禁值。

对数底数决定方向

解 loga​(9−x)≥1 时，先有 a>0,a=1 与 x<9。当 a>1，条件变为 9−x≥a，解为 x≤9−a；当 0<a<1，则为 0<9−x≤a，解为 9−a≤x<9。真数正性不能只在第一种底数情形检查，也不能把参数分段后的公式混用。

全称取交，存在取并

要求所有输入都成立，相当于对各输入给出的参数条件取交集；只需存在一个输入时则取并集。例：对所有 x∈[−1,2] 都有 m≥x2，等价于 m≥4；若仅要求存在这样的 x，则等价于 m≥0。两个条件“至少一个成立”对应真值集合的并集，不能擅自换成两条件同时成立。

临界参数先核退化与严格端点

参数可能让最高次项消失、零点重合或碰到定义域端点，应单独代回判断。例：mx2−1<0 对所有实数 x 成立，当且仅当 m≤0；其中 m=0 仍给常数 −1，不能因二次项消失就排除。严格不等式的参数端点还取决于输入能否达到最坏点：m>x 对所有 x∈(0,1) 成立允许 m=1，改为闭区间则不允许。

方法卡

解分式不等式：标数轴，逐段判正负用单调性去掉 f：解函数不等式奇偶函数和分段函数：先补全，再分段根式方程：整体设元、平方差，再分情况恒成立求参数：找最不利的情况绝对值：看成距离，用三角不等式求范围

解分式不等式：标数轴，逐段判正负

把不等式移成“一个分式和 0 比较”，标出分子、分母的零点，每一段试一个数就知道正负。

完整讲解 · 例题 · 可练 30 题

一、是什么

只需要知道正负

分式 x+2x−1​≤0 只问这个分式是正还是负，不需要它的具体值。分式的正负只取决于分子和分母各自的正负。

什么是零点，为什么每段试一个数就够

使分子等于 0 的 x 叫分子零点，使分母等于 0 的 x 叫分母零点。x+2x−1​ 的分子零点是 1，分母零点是 −2，这两点把数轴切成 3 段。x+2 只在 x=−2 处变号，x−1 只在 x=1 处变号，所以在同一段里两个因子的符号都不变，分式的符号也不变。

分母的零点永远不能取

分子为零且分母不为零时，分式才等于 0，是否可取看不等号有没有等号。分母为零时，式子没有意义，有等号也不能取；约分后也要保留这个限制。

先看一道例题

例 1：最基本的分式不等式

解不等式 x+2x−1​≤0。

怎么看出来：

已经是分式和 0 比较，直接标零点，列一张符号表。

解：

分子零点是 1，分母零点是 −2。

段x<−2−2<x<1x>1
试值−302
分子 x−1−4，负−1，负1，正
分母 x+2−1，负2，正4，正
分式4，正−21​，负41​，正

要 ≤0，选中间一段。端点：x=1 时值为 0，可取；x=−2 时分母为零，不可取。

答案：

−2<x≤1。

二、什么时候想到它

题目里看到应该想到
不等式的分母里有未知数，如 x−11​>x+11​移项通分，不要两边直接乘分母
几个因式相乘后和 0 比较标零点，逐段判断正负
已知解集，如 x2+ax+b<0 的解集是 (1,3)解集端点就是根，写成 (x−1)(x−3) 再比较系数（见进阶“含参数与反求系数”）

三、怎么用

  1. 把所有项移到一边，通分，让另一边是 0。例如 1−x+14​≥0，通分得 x+1x−3​≥0。
  2. 因式分解，找出所有零点。这里分子零点是 3，分母零点是 −1。
  3. 把零点标在数轴上，每一段任取一个数代入。x<−1 取 −2，值为 5>0；−1<x<3 取 0，值为 −3<0；x>3 取 4，值为 51​>0。
  4. 按不等号选出需要的段。这里要 ≥0，选 x<−1 和 x>3 两段。
  5. 逐个检查端点。x=3 时值为 0，有等号，可取；x=−1 是分母零点，不可取。解是 x<−1 或 x≥3。

四、再做一道

例 2：不能直接乘分母

解不等式 x−11​>x+11​。

怎么看出来：

x−1、x+1 可能是负数，两边直接乘会弄错不等号方向，所以移项通分。

解：

移项得 x−11​−x+11​>0，通分时分子是 (x+1)−(x−1)=2，所以 (x−1)(x+1)2​>0。零点是 −1,1，都在分母上。取 x=−2，分母为 3，值为正；取 x=0，分母为 −1，值为负；取 x=2，分母为 3，值为正。要 >0，选两边，两个零点都不能取。

答案：

x<−1 或 x>1。

五、容易错在哪

  • 不知道分母正负时，不能两边同乘分母。
  • 有等号时也不能取分母的零点。
  • 不要机械地认为每过一个零点都变号，偶次因式经过零点不变号。每段都试一个数。
进阶：偶次因式

偶次因式经过零点不变号

(x−1)2 在 x=1 两侧都是正的，所以整个式子经过 x=1 时不变号。不必背这条，每段照常试一个数就不会错。

例 3：有偶次因式

解不等式 x−3(x−1)2(x+2)​≤0。

怎么看出来：

有三个零点，其中 x=1 来自平方，经过它不变号。

解：

零点是 −2,1,3。取 x=−3 得 −616⋅(−1)​>0；取 x=0 得 −31⋅2​<0；取 x=2 得 −11⋅4​<0；取 x=4 得 19⋅6​>0。所以 −2<x<1 和 1<x<3 符合。x=−2, x=1 时值为 0，可取；x=3 不可取。

答案：

−2≤x<3。

进阶：含参数与反求系数

含参数时先比较零点的大小

若零点里有参数，如 (x−1)(x−a)<0，要先比较 1 和 a 的大小。a>1 时解是 1<x<a，a<1 时解是 a<x<1，a=1 时左边是 (x−1)2，不会小于 0，无解。

例 4：由解集反求系数

若 x2+ax+b<0 的解集是 (1,3)，求 a,b。

怎么看出来：

开口向上的二次式小于零的部分在两根之间，解集端点就是两根。

解：

两根是 1,3，首项系数是 1，所以 x2+ax+b=(x−1)(x−3)=x2−4x+3。检查：(x−1)(x−3)<0 时两因子异号，解是 1<x<3。

答案：

a=−4, b=3。

用单调性去掉 f：解函数不等式

函数单调时，比较函数值就等于比较自变量。先确认单调方向和定义域，再把 f 去掉。

完整讲解 · 例题 · 可练 21 题

一、是什么

增函数保持方向，减函数反向

在一段范围上，x 变大时函数值一定变大，叫增函数；x 变大时函数值一定变小，叫减函数。所以 f 是增函数时，f(a)<f(b) 等价于 a<b；f 是减函数时，等价于 a>b。

自变量都要落在定义域内

f(2x−1) 里 2x−1 才是 f 的自变量。如果 f 只在 [−1,3] 上有定义，就要求 −1≤2x−1≤3。去掉 f 之后，这个范围不能丢，最后要和解取交集。题目写“在 R 上”时，R 表示全体实数，这条限制自动满足。

先看一道例题

例 1：增函数直接去 f

f 是 R 上的增函数，解 f(2x−1)<f(3)。

怎么看出来：

两边是同一个增函数，方向不变。定义域是全体实数，没有额外限制。

解：

由单调性得 2x−1<3，所以 2x<4，x<2。

答案：

x<2。

二、什么时候想到它

题目里看到应该想到
不等式两边是同一个函数，如 f(2x−1)<f(3)判断单调方向，去掉 f
函数只在一段范围上有定义每个自变量都要落在这段范围内，最后取交集
两边结构相同，如 x3+x 和 (2−x)3+(2−x)把相同结构定义成一个函数，证明它单调（见进阶“自己构造单调函数”）
未知数在几个指数或根式里，方程解不出来，如 2x+3x>13看成一个递增函数，先找出等号成立的点（见同一进阶）
函数是偶函数，只知道正半轴上的单调性两边的自变量加绝对值（见进阶“正半轴单调的偶函数”）
不等式含对数，底数不确定或小于 1先定方向，并保留真数大于零（见进阶“对数”）
不等式含反函数 f−1用原函数把它送回去，注意值域（见进阶“反函数”）

三、怎么用

  1. 写出自变量的范围。例如 f 是 [0,4] 上的增函数，解 f(x+1)<f(3)，要求 0≤x+1≤4，即 −1≤x≤3；3 也在 [0,4] 内。
  2. 确认两边是同一个函数。这里都是 f，自变量分别是 x+1 和 3。
  3. 去掉 f：增函数方向不变，减函数方向相反。这里得 x+1<3，即 x<2。
  4. 把解和第 1 步的范围取交集。x<2 与 −1≤x≤3 的交集是 −1≤x<2。

四、再做一道

例 2：减函数，还要管定义域

f 是定义在 [−1,3] 上的减函数，解 f(2x−1)<f(x)。

怎么看出来：

减函数去掉 f 要反向。两个自变量都要落在 [−1,3] 内。

解：

范围：−1≤2x−1≤3 得 0≤x≤2；−1≤x≤3。两者的交集是 0≤x≤2。去掉 f：减函数，方向相反，得 2x−1>x，即 x>1。与 0≤x≤2 取交集，得 1<x≤2。检查端点：x=2 时 2x−1=3，仍在定义域内；x=1 时两个自变量相等，两边相等，不满足严格不等号。

答案：

1<x≤2。

五、容易错在哪

  • 只去掉 f，忘记自变量要落在定义域内。
  • 减函数去掉 f 时不等号要反向。
  • 偶函数在正半轴递增，不代表在整条数轴上递增，别忘了绝对值。
  • 反函数的自变量必须在原函数的值域内。
进阶：正半轴单调的偶函数

偶函数要加绝对值

偶函数满足 f(−x)=f(x)。它在 [0,+∞) 上递增，并不代表在整条数轴上递增。因为 f(a)=f(∣a∣)，所以先写成 f(∣a∣)<f(∣b∣)，∣a∣,∣b∣ 都在 [0,+∞) 上，再去掉 f，得 ∣a∣<∣b∣。

例 3：偶函数加绝对值

偶函数 f 在 [0,+∞) 上严格递增，解 f(x−1)<f(2)。

怎么看出来：

x−1 可能是负数，不在已知单调的范围里，所以先加绝对值。

解：

f(x−1)=f(∣x−1∣)，所以 f(∣x−1∣)<f(2)。∣x−1∣ 和 2 都在 [0,+∞) 上，得 ∣x−1∣<2，即 −2<x−1<2。

答案：

−1<x<3。

进阶：自己构造单调函数 · 先修：指数函数

题目没给单调函数时，自己找一个

先把不等式整理成同一个函数在两个位置的值。例如 x3+x<(2−x)3+(2−x)，两边都是 H(t)=t3+t，所以它就是 H(x)<H(2−x)。然后证明 H 单调：当 v>u 时，H(v)−H(u)=(v−u)(v2+uv+u2+1)。这里 uv 可能是负数，不能逐项说非负，要配方：v2+uv+u2=(v+2u​)2+43​u2≥0。所以后一个因子至少是 1，差为正。另外，几个递增函数相加仍然递增：u<v 时每一项都变大，和也变大。

例 4：先找等号成立的点

解不等式 2x+3x>13。

怎么看出来：

解不出 x 的精确表达式，但 2x,3x 都递增，它们的和也递增。

解：

设 g(x)=2x+3x。x 变大时两项都变大，所以 g 严格递增。又 g(2)=4+9=13，所以 g(x)>g(2) 等价于 x>2。

答案：

x>2。

例 5：自己构造单调函数

解不等式 x3+x<(2−x)3+(2−x)。

怎么看出来：

两边结构完全一样，设 H(t)=t3+t。直接展开反而麻烦。

解：

不等式就是 H(x)<H(2−x)。当 v>u 时，H(v)−H(u)=(v−u)(v2+uv+u2+1)，其中 v−u>0，v2+uv+u2+1=(v+2u​)2+43​u2+1>0，所以 H 严格递增。于是 x<2−x，即 2x<2。

答案：

x<1。

进阶：对数 · 先修：对数函数

对数的方向看底数

loga​x 在 a>1 时递增，在 0<a<1 时递减。去掉对数时，还要保留真数大于零。

例 6：底数小于 1 的对数

解不等式 log1/2​(x−1)>1。

怎么看出来：

底数 21​<1，函数递减，去掉对数时不等号反向。

解：

因为 (21​)1=21​，所以 1=log1/2​21​，不等式就是 log1/2​(x−1)>log1/2​21​。由递减得 x−1<21​，再加上真数条件 x−1>0，得 1<x<23​。

答案：

1<x<23​。

进阶：反函数 · 先修：反函数、指数函数

反函数送回原函数

反函数把输出还原成输入，不是倒数。例如 f(x)=2x 有 f(3)=8，它的反函数就有 f−1(8)=3：输入 8，还原出 3。增函数 f 的反函数 f−1 也是增函数。遇到 f−1(x)<3，当 x 在 f 的值域内、3 在 f 的定义域内时，可以两边用 f 作用，变成 x<f(3)。

例 7：反函数

f(x)=2x，解 f−1(x)<3。

怎么看出来：

f 是增函数，用它作用两边，方向不变。

解：

f 的输出 2x 总是正数，所以 f−1(x) 只在 x>0 时有定义。两边用增函数 f 作用，方向不变；f(f−1(x))=x，所以得 x<f(3)=8。与 x>0 取交集。

答案：

0<x<8。

奇偶函数和分段函数：先补全，再分段

先用奇偶性把函数写完整，再按每一段的范围分别解，每段的结果都要和这一段的范围取交集。

完整讲解 · 例题 · 可练 10 题

一、是什么

用奇偶性补全函数

奇函数满足 f(−x)=−f(x)，偶函数满足 f(−x)=f(x)。若 f 是奇函数，且 x≥0 时 f(x)=x2，那么 x<0 时 −x>0，可以把 −x 代入已知表达式：f(−x)=(−x)2=x2。所以 f(x)=−f(−x)=−x2。

按绝对值的零点分段

∣x−1∣ 在 x=1 处改变写法：x≥1 时是 x−1，x<1 时是 1−x。在哪一段解出的结果，就要回到哪一段取交集，解到段外的部分不算数。

先看一道例题

例 1：奇函数补全后分段

f 是 R 上的奇函数（R 表示全体实数），x≥0 时 f(x)=x2。解 f(x)>x。

怎么看出来：

只知道 x≥0 的表达式，要先写出 x<0 的部分。

解：

x<0 时 f(x)=−f(−x)=−x2。当 x≥0：x2>x，即 x(x−1)>0。两因子同号，解是 x<0 或 x>1。回到这一段，与 x≥0 取交集，只剩 x>1，x<0 那一支舍掉。当 x<0：−x2>x，即 x2+x<0，x(x+1)<0。两因子异号，解是 −1<x<0，都在这一段内。合并两段。

答案：

−1<x<0 或 x>1。

二、什么时候想到它

题目里看到应该想到
只给了一半的解析式，如 x≥0 时的表达式用奇偶性写出另一半
含绝对值或分段函数找分界点，逐段解，再取并集
一个奇函数和一个偶函数的和或差把 x 换成 −x，列两个式子联立（见进阶“奇偶联立”）
连续不等式，如 a<a3<∣a∣先按变量正负分类，再逐个不等式解（见进阶“连续不等式”）

三、怎么用

  1. 先用奇偶性把函数写完整。例如偶函数 f 在 x≥0 时 f(x)=x−1，解 f(x)<1。x<0 时 f(x)=f(−x)=−x−1。
  2. 找出所有分界点：绝对值的零点、分段函数的分段点。这里分界点是 x=0。
  3. 在每一段写出式子，分别求解。x≥0：x−1<1，得 x<2。x<0：−x−1<1，得 x>−2。
  4. 每段的结果和这一段的范围取交集。第 1 段得 0≤x<2，第 2 段得 −2<x<0。
  5. 把各段结果取并集，单独检查分界点。并集是 −2<x<2；x=0 时 f(0)=−1<1，确实是解。

四、再做一道

例 2：绝对值分段

解不等式 ∣x−1∣<2x。

怎么看出来：

绝对值在 x=1 处换写法，所以分 x≥1 和 x<1 两段。

解：

当 x≥1：x−1<2x，得 x>−1，与 x≥1 取交集得 x≥1。当 x<1：1−x<2x，得 x>31​，与 x<1 取交集得 31​<x<1。两段的并集是 x>31​。

答案：

x>31​。

五、容易错在哪

  • 函数没有补全就代入负的自变量，会用错表达式。
  • 复合函数要看里层的值落在哪一段，不只看最外层。
  • 不等式两边除以负数时要变号。
  • 分界点既不要漏掉，也不要算进不该属于它的一段。

根式方程：整体设元、平方差，再分情况

把反复出现的式子看成一个数，或用平方差把根式差变简单。乘积等于零时，分别令一个因子为零求解，再合并结果。只要平方过，最后一定检查。

完整讲解 · 例题 · 可练 26 题

一、是什么

整体设元：把重复的式子打包

式子 (x2−x)2−(x2−x)−2 里 x2−x 出现了两次。设 t=x2−x，它就变成 t2−t−2=(t−2)(t+1)。设元时要同时记下 t 的取值范围：配方得 t=(x−21​)2−41​，所以 t≥−41​。

平方差：把根式差变简单

(A​−B​)(A​+B​)=A−B。两个被开方式相减很简单时，乘上“根式和”，根号就消失了。例如 (x+5​−x​)(x+5​+x​)=(x+5)−x=5。

零因子：乘积为零时分开解

乘积 MN=0 时，分别令一个因子为零求解，再合并结果，并不要求两个因子同时为零。解出的值必须让所有因子都有意义。例如 (x−2)x−3​=0：令 x−2=0 得 x=2，但此时 x−3​ 没有意义，舍去；令 x−3​=0 得 x=3，保留。所以只有 x=3。

为什么平方后要检查

A=B 和 A=−B 平方后是同一个式子，所以平方可能多出解。例如 x+2​=x，平方得 x2−x−2=0，即 x=2 或 x=−1。代回去，x=−1 时左边是 1、右边是 −1，不成立，只有 x=2 是解。这种多出来的解叫增根。

先看一道例题

例 1：整体设元

解方程 (x2−x)2−(x2−x)−2=0。

怎么看出来：

x2−x 出现两次，直接展开会得到四次式，所以先打包。

解：

没有根号和分母，定义域是全体实数。设 t=x2−x，由配方得 t≥−41​。方程变为 t2−t−2=0，即 (t−2)(t+1)=0，所以 t=2 或 t=−1。t=−1 小于 −41​，舍去。由 t=2 得 x2−x−2=0，即 (x−2)(x+1)=0，所以 x=2 或 x=−1。检查：这两个值都使 x2−x=2，原式等于 4−2−2=0。

答案：

x=2 或 x=−1。

二、什么时候想到它

题目里看到应该想到
同一个式子反复出现，如 x2−x整体设为 t，并写出 t 的范围
两个根式相减，被开方式的差很简单，如 x+5​−x​乘上根式和，用平方差去根号
方程写成乘积等于零，如 (x+y−1)x−1​=0先看定义域，分别令一个因子为零求解，再合并结果
三个根式，被开方式之间有线性关系，如 3x+15=2(x+7)+(x+1)设 a,b 为两个根式，把第三个写成 a,b 的式子（见进阶“三个根式”）
根式和另一个式子比较大小，如 x+2​>x按另一边的正负分情况，再决定能否平方（见进阶“根式不等式与绝对值比较”）
两个绝对值比较大小，如 ∣x−1∣<∣x+3∣平方后写成乘积，判断因子的正负（见同一进阶）

三、怎么用

  1. 写定义域：根号里非负，分母不为零。例如解 x−x​−2=0，要求 x≥0。
  2. 找重复的式子，设元并写出新变量的范围。这里 x=(x​)2，设 t=x​，则 t≥0，方程变为 t2−t−2=0。
  3. 把所有项移到一边，用十字相乘、提公因式或平方差写成乘积。这里 t2−t−2=(t−2)(t+1)，所以 (t−2)(t+1)=0。
  4. 分别令一个因子为零求解，再用范围筛选并合并。t=2 符合 t≥0；t=−1 不符合，舍去。由 x​=2 得 x=4。
  5. 代回原式检查。x=4 时 4−2−2=0，成立。平方过或换过元都要做这一步，相同的解只算一个。

四、再做一道

例 2：平方差去根号

两个被开方式相差常数 5，乘上根式和后左边只剩 5。

  • 约去一个可能为零的式子会丢解。约之前先讨论它等于零的情况。
  • 平方后解出的结果不一定是原方程的解，要代回原式。
  • a​ 表示非负的那个根，x2​=∣x∣，不是 x。

恒成立求参数：找最不利的情况

“对所有 x 都成立”就是最不利的 x 也成立。把参数分离出来，求另一边的最大值或最小值。

完整讲解 · 例题 · 可练 26 题

一、是什么

恒成立就看最值

当 g(x) 的最小值存在时，a≤g(x) 对范围内所有 x 成立，等价于 a 不超过这个最小值。当最大值存在时，a≥g(x) 恒成立，等价于 a 不小于这个最大值。

集合包含也是恒成立

A⊆B 表示 A 的每个元素都满足 B 的条件。例如 [1,2]⊆{x∣x2+m≤0} 就是：[1,2] 里每个 x 都满足 x2+m≤0。这正是一句恒成立，例 2 把它解完。

先看一道例题

例 1：分离参数

x2−ax+1≥0 对所有 x∈[1,2] 成立，求 a 的范围。

怎么看出来：

x>0，可以把 a 单独放到一边。

解：

x>0，两边除以 x，方向不变，得 a≤x+x1​。下面求右边的最小值：x+x1​−2=xx2−2x+1​=x(x−1)2​≥0，所以 x+x1​≥2，且 x=1 时取等号，x=1 在 [1,2] 内。最小值是 2，所以 a≤2。检查：a=2 时原式是 (x−1)2≥0，成立。

答案：

a≤2。

二、什么时候想到它

题目里看到应该想到
“对任意 x 成立”“恒成立”分离参数，求最值
一个集合包含于另一个解集，如 A⊆BA 中每个元素都要满足 B 的条件
含参数的二次式恒为正或恒为负先讨论首项系数，再看开口和 Δ（见进阶“含参二次式”）
“对任意 x，P 或 Q 成立”P 不成立的 x，都必须满足 Q（见进阶“‘或’的恒成立”）

三、怎么用

  1. 写清楚 x 的范围，以及是“所有”还是“存在”。例如 2x+a≥0 对所有 x∈[1,3] 成立。
  2. 把参数单独放到一边。这里得 a≥−2x。
  3. 找最不利的 x，求另一边的最值，并判断能否取到。a 要不小于所有 −2x，−2x 在 x=1 时最大，等于 −2，能取到。
  4. 写出参数范围。a≥−2。
  5. 检查临界值和范围外的值。a=−2 时 2x−2≥0 在 [1,3] 上成立；a=−3, x=1 时式子等于 −1，不成立。

四、再做一道

例 2：集合包含

若 [1,2]⊆{x∣x2+m≤0}，求 m 的范围。

怎么看出来：

[1,2] 中每个 x 都要满足不等式，x 越大越不利。

解：

条件就是 m≤−x2 对所有 x∈[1,2] 成立。1≤x≤2 时 x2≤4，所以 −x2≥−4，且 x=2 时取等号。−x2 的最小值是 −4，所以 m≤−4。检查：m=−4, x=2 时 4−4=0≤0，成立。

答案：

m≤−4。

五、容易错在哪

  • 只试几个 x 不能说明恒成立，要求出最值或给出证明。
  • “恒成立”看最值，“存在”的方向相反，不要写反。
  • “或”不是两个条件都要成立。
  • 首项系数含参数时，别漏掉系数为零的情况。
进阶：边界取不到

边界取不到时，看严格不严格

有时 g(x) 只能接近某个值，却取不到。例如 x∈(0,1) 时，x 能接近 0，但取不到 0。这时要单独判断参数能否等于这个边界。

怎么看出来：

a=0 时，每个 x∈(0,1) 都大于 0，成立。a<0 时，每个 x∈(0,1) 都大于 0，也大于 a，成立。a>0 时，取 x 为 a 和 21​ 中较小的那个，它在 (0,1) 内且 x≤a，不满足 a<x，不成立。

答案：

a≤0。

怎么看出来：

a 在首项系数上，要先看 a=0。

解：

a=0 时式子为 2x+1，取 x=−1 得负值，不成立。a<0 时抛物线开口向下，∣x∣ 很大时式子为负，不成立。a>0 时要求没有实根，Δ=4−4a<0，所以 a>1。检查：a=2 时 2x2+2x+1=2(x+21​)2+21​>0。

答案：

a>1。

进阶：“或”的恒成立

“或”只需要盯住另一半

“每个 x 都满足 P 或 Q”，等价于不满足 P 的 x 都满足 Q。先求简单条件，再看它管不到的部分。

例 5：“或”的问题

对任意实数 x，都有 x<1 或 m−x<0。求 m 的范围。

怎么看出来：

x<1 管不到的是 x≥1，这部分必须满足 m−x<0。

解：

需要 m<x 对所有 x≥1 成立。x 的最小值是 1，且可以取到，所以 m<1。检查临界值：m=1, x=1 时两个条件都不成立。

答案：

m<1。

绝对值：看成距离，用三角不等式求范围

∣x−a∣ 就是数轴上 x 到 a 的距离。很多绝对值问题，看成距离后不用分段就能解。

完整讲解 · 例题 · 可练 13 题

一、是什么

绝对值就是距离

∣x−a∣<r（r>0）表示 x 到 a 的距离小于 r，也就是 a−r<x<a+r。注意 ∣x+1∣=∣x−(−1)∣ 是 x 到 −1 的距离。

两边都是绝对值可以平方

∣A∣<∣B∣ 等价于 A2<B2，因为两边都非负。也可以先看成“x 离哪个点更近”，再用平方验证。

先看一道例题

例 1：单个绝对值

解不等式 ∣x−2∣<3。

怎么看出来：

表示 x 到 2 的距离小于 3。

解：

从 2 向两边各走 3，得 2−3<x<2+3。端点处距离正好是 3，不能取。检查：x=0 时 ∣0−2∣=2<3，成立。

答案：

−1<x<5。

二、什么时候想到它

题目里看到应该想到
∣x−a∣<r 这样的单个绝对值写成两侧的区间，先确认 r>0
不等式两边都是绝对值看成距离比较，或者平方
两个绝对值之差或之和，要求对所有 x 成立用三角不等式求最值，再说明能取到（见进阶“三角不等式”）
∣x−a∣<r 对一段 x 都成立，求 a闭区间就把两个端点代入后取交集；开区间的端点要单独判断（见进阶“对一段 x 都成立”）

三、怎么用

  1. 把绝对值写成距离。例如 ∣x+1∣<2，∣x+1∣ 是 x 到 −1 的距离。
  2. 确认半径是正数，写成两侧的区间。半径 2>0，所以 −1−2<x<−1+2，即 −3<x<1。
  3. 严格不等号时检查端点。x=1 时距离正好是 2，不小于 2，不能取；x=−3 也一样。
  4. 取一个内部的数代回。x=0 时 ∣0+1∣=1<2，成立。

四、再做一道

例 2：比较两个距离

解不等式 ∣x−1∣<∣x+3∣。

怎么看出来：

表示 x 离 1 比离 −3 近，分界点是这两点的中点 −1，答案应在它的右边。

解：

用平方验证：(x−1)2<(x+3)2，展开得 x2−2x+1<x2+6x+9，消去 x2 并移项得 −8<8x，所以 x>−1。

答案：

x>−1。

五、容易错在哪

  • 写成两侧区间之前要确认半径是正数；r≤0 时 ∣x−a∣<r 无解。
  • 三角不等式只给出界，还要找到取等的 x，才能说它是最值。
  • 严格不等号时，距离正好相等的点不能算进去。
进阶：三角不等式

绕路不会更短：三角不等式

在数轴上从 x 走到 a，直接走的路程不会比先到 b 再到 a 更长，所以 ∣x−a∣≤∣x−b∣+∣b−a∣。移项得 ∣x−a∣−∣x−b∣≤∣a−b∣。取 x=b 时左边正好等于 ∣a−b∣，所以 ∣a−b∣ 就是差的最大值。

两个绝对值之和有下界

∣x−a∣+∣x−b∣ 是 x 到两点的距离之和。x 在 a,b 之间时，这两段正好拼成 a,b 之间的线段；x 在外面时还要多走一段。所以 ∣x−a∣+∣x−b∣≥∣a−b∣，x 在 a,b 之间时取等号。

例 3：绝对值之差恒成立

∣x−a∣−∣x∣≤3 对所有实数 x 成立，求 a 的范围。

怎么看出来：

两个绝对值之差，用三角不等式求左边的最大值。

解：

从 x 到 a，绕 0 走不会更短：∣x−a∣≤∣x∣+∣a∣，所以 ∣x−a∣−∣x∣≤∣a∣。取 x=0 时左边等于 ∣a∣，所以最大值就是 ∣a∣。最大值不超过 3 才能恒成立，需要 ∣a∣≤3。

答案：

−3≤a≤3。

进阶：对一段 x 都成立

例 4：对一段 x 都成立

∣x−a∣<1 对所有 x∈[2,3] 成立，求 a 的范围。

怎么看出来：

即 a−1<x<a+1，区间 [2,3] 要整个落在里面。

解：

[2,3] 的最小数和最大数都要在 (a−1,a+1) 内，需要 a−1<2 且 3<a+1，所以 a<3 且 a>2。这时 [2,3] 中间的数也都在里面。

答案：

2<a<3。

误区对照

容易误以为

解 (x−2)/(x+1)≥0 时同乘 x+1，直接得到 x≥2。

应当这样想

分母可能为负。按临界点 −1,2 分段，解集为 (−∞,−1)∪[2,+∞)；例如 x=−2 时原式为 4>0，也应在解集中。

为什么

同乘未知符号量不能固定不等号方向；分母零点始终排除，分子零点在非严格不等式中可以保留。

容易误以为

由 x+6​≥x 两边平方，得 x+6≥x2，解集为 [−2,3]。

应当这样想

先有 x≥−6。当 −6≤x≤0，左边非负、右边非正，原式自动成立；当 x>0 才可等价平方，得到 0<x≤3。最终解集是 [−6,3]。

为什么

平方保持大小的等价性需要两边非负；右边为负的分支不能被平方后的更强条件误删。例如 x=−5 时 1≥−5 成立。

容易误以为

若 ax2+1>0 对所有实数 x 成立，因是二次函数，所以必须有 a>0。

应当这样想

a=0 时原式恒为 1>0，也成立。a>0 时由 ax2≥0 成立；a<0 时取 ∣x∣>1/−a​ 即失败。因此准确条件为 a≥0。

为什么

参数使最高次项消失时，要回原式检查常数分支，不能把“按二次式讨论”的前提当成题目额外限制。

概念自测

先想清楚，再确认判断。这些自测只帮助辨清概念，不计入真题做对率。

1. 不等式 (x−2)/(x+1)≥0 的解集为：

同乘分母时擅自假定它为正，漏掉分子分母同时为负的区间；x=−2 就是反例。

分母非零仅是定义域条件，不保证商非负；例如 x=0 时商为 −2。

正确。三个开区间的商符号依次为正、负、正；x=2 给零可取，x=−1 无定义不可取。

把分母零点当成普通可取边界；x=−1 在原式中无定义。

2. 实数不等式 x+6​≥x 的解集为：

在右边为负时不等价平方，漏掉 [−6,−2)；例如 x=−5 时原式为 1≥−5。

正确。定义域中 x≤0 自动成立，x>0 平方后给 x≤3，两支合并为 [−6,3]。

根号允许被开方式等于零；x=−6 时 0≥−6 成立，不能漏端点。

只检查了定义域和负数分支，漏掉正数还需比较大小；x=4 时 10​<4。

3. ax2+1>0 对所有实数 x 成立的实参数 a 的范围为：

漏掉退化参数 a=0，此时原式恒为 1>0，完全合法。

负二次项在大输入下使式子变负；例如 a=−1,x=2 时为 −3。

少数输入处成立不足以推出全称结论；任何 a<0 都会在足够大的 ∣x∣ 处失败。

正确。a≥0 直接保证 ax2+1≥1；a<0 可取 ∣x∣>1/−a​ 构造反例。

4. 分别求使“对所有 x∈(0,2)，m>x”成立的 m，以及使“存在 x∈(0,2)，m>x”成立的 m。对应两范围为：

正确。全称允许 m=2，因输入取不到 2；存在条件当且仅当 m>0，可取 x=min{m/2,1} 作见证。

输入上端为开端点，因此 m=2 时仍对每个合法 x 严格大于，不能机械把参数也写成严格不等式。

m=0 不大于任何正输入；把不可达的输入下端零误当成存在性见证。

把全称与存在的取交/取并关系反了；存在只须找到一个小于 m 的合法输入，全称却须覆盖整个区间。
