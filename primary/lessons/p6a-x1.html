生活中的负数

零上 3 ℃ 和零下 3 ℃ 都有一个「3」，但一个是暖和、一个是结冰——用正号「+」和负号「−」把相反方向清清楚楚分开！

寒冬的一天，北京最高气温是零上 3 ℃（记作 +3 ℃ 或 3 ℃），最低气温是零下 3 ℃（记作 −3 ℃）。这一天最高气温和最低气温相差多少摄氏度？

对！以 0 ℃（淡水开始结冰的温度）为分界线，零下 3 ℃ 到 0 ℃ 相差 3 格，0 ℃ 到零上 3 ℃ 又相差 3 格，合起来相差 3 + 3 = 6（℃）。

自己试试

同一天，海口的气温是 +12 ℃，沈阳的气温是 −4 ℃。两地气温相差多少摄氏度？

从 −4 ℃ 到 0 ℃ 是 4 ℃，从 0 ℃ 到 +12 ℃ 是 12 ℃，两地相差 4 + 12 = 16（℃）。

2. 相反意义的量与「0」的身份

· 相反意义的量：零上与零下、收入与支出、海平面以上与海平面以下、电梯地上楼层与地下楼层，都可以用正数（如 +500、+8848.86）和负数（如 −85、−154.31）来表示。
· 0 的特殊身份：0 既不是正数，也不是负数，它是正数和负数的分界点。
· 比大小：在横向数轴上，从左往右的数越来越大。所有的负数 < 0 < 正数；两个负数相比，离 0 越远（负号后面的数越大），温度反而越低、数值越小（例如 −8 < −3）。

自己试试

冬天早晨，哈尔滨是 −18 ℃，长春是 −12 ℃，北京是 −4 ℃。哪个城市最冷（温度最低）？

C。在 0 ℃ 以下，往下数得越多越冷，所以 −18 ℃ < −12 ℃ < −4 ℃，哈尔滨最冷。

正数和负数用来表示两种相反意义的量；0 既不是正数也不是负数，是它们的分界点；数轴上越靠左的数越小，负数比大小，负号后面的数越大反而越小。

两个容易错的地方

✗ 以为 −10 比 −2 大只看负号后面的 10 > 2，就写 −10 > −2。
✓ 想到温度计或数轴：−10 < −2零下 10 ℃ 比零下 2 ℃ 更冷，在数轴上 −10 在 −2 的左边，所以 −10 < −2。
✗ 把 0 归入正数或负数认为「所有数不是正数就是负数」。
✓ 0 既不是正数也不是负数0 是正数与负数的分界线，正数都大于 0，负数都小于 0。

直接用

1. 妈妈的手机账单里，收到红包 200 元记作「+200.00 元」，那么在超市付款 85 元应该记作什么？

B。收入记作正，支出就记作负，付款 85 元记作 −85 元。

2. 在 −7、+2.5、0、−12、8 这五个数中，负数有几个？正数有几个？

C。带负号的是负数（2 个），大于 0 的是正数（2 个），0 独立在中间。

3. 某天泰山山顶白天的最高气温是 +8 ℃，夜间的最低气温降到了 −3 ℃。这一天最高气温与最低气温相差多少摄氏度？

从 −3 ℃ 到 0 ℃ 相差 3 ℃，从 0 ℃ 到 +8 ℃ 相差 8 ℃，一共相差 3 + 8 = 11（℃）。

容易错

4. 把 −5、−1、0、+3 按从小到大的顺序排列，正确的是哪一项？

A。数轴上从左到右依次是 −5、−1、0、+3。

5. 商场电梯里，地上 5 层记作 +5 层，地下 2 层记作 −2 层（注意：电梯没有 0 层，−1 层上面直接是 +1 层）。王阿姨从地下 2 层坐电梯到地上 5 层，电梯一共上升了多少层？

从 −2 层到 −1 层（1 层），从 −1 层到 +1 层（1 层），再从 +1 层到 +5 层（4 层），一共上升了 1 + 1 + 4 = 6（层）。

想一想

6. 一袋牛奶的包装袋上印着「净含量：200 ± 2 克」，意思是比 200 克多 2 克以内（+2 克）或少 2 克以内（−2 克）都算合格。一袋合格的牛奶最少重多少克？

200 − 2 = 198（克），合格范围是 198 克～202 克。

7. 六年级一分钟跳绳达标线定为 40 个（本次小测试的标准），超过的个数记为正，不足的记为负。5 名同学的记录分别是：+5、−2、0、+4、+3。这 5 名同学平均每人跳了多少个？

还原每人实际次数：45、38、40、44、43（个）。总数是 45 + 38 + 40 + 44 + 43 = 210（个），平均每人 210 ÷ 5 = 42（个）。
