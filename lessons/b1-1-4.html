1.4 充分条件与必要条件

一件事能不能保证另一件事？学会用「推得出 / 推不出 + 反例」说清楚两个条件的关系。先从一个地名开始。

杭州是浙江省的一个城市。宁波、温州也在浙江。

下面哪句话一定对？

A。杭州整个在浙江里面，人在杭州，就一定在浙江。

反过来不一定：在宁波的人也在浙江，却不在杭州。像「在宁波的人」这样，说明一句话不成立的具体例子，叫反例。

数学上这样说：「在杭州」足够保证「在浙江」，所以「在杭州」是「在浙江」的充分条件；想在杭州，「在浙江」少不了，所以「在浙江」是「在杭州」的必要条件。这一节就讲：两个条件之间，谁能推出谁，怎么说，怎么查。

1. 先认识几个词

要用到：初中学过的「命题」（能判断对错的话）；1.1 用描述法写集合（回看 1.1）；1.2 的子集、真子集（回看 1.2）。

「若 \(p\)，则 \(q\)」：很多命题能写成这个样子，\(p\) 是前提，\(q\) 是结论。对的叫真命题，错的叫假命题。

例：「若 \(x=2\)，则 \(x^2=4\)」是真命题；「若 \(x^2=4\)，则 \(x=2\)」是假命题。前提和结论换了位置，真假就可能变。

推出 \(\Rightarrow\)：「若 \(p\)，则 \(q\)」是真命题，就写 \(p\Rightarrow q\)，读作「\(p\) 推出 \(q\)」；是假命题，就写 \(p\nRightarrow q\)。

例：\(x=2\Rightarrow x^2=4\)；\(x^2=4\nRightarrow x=2\)。

反例：满足 \(p\)、却不满足 \(q\) 的一个具体例子。有一个反例，「若 \(p\)，则 \(q\)」就是错的。

例：\(x=-2\) 满足 \(x^2=4\)，却不满足 \(x=2\)，它就是「若 \(x^2=4\)，则 \(x=2\)」的反例。

子集和真子集：\(A\subseteq B\) 是说 \(A\) 的每个元素都在 \(B\) 里；如果 \(B\) 里还有不在 \(A\) 里的元素，就是真子集 \(A\subsetneqq B\)。

例：\(\{x\mid x>2\}\subsetneqq\{x\mid x>1\}\)。\(3\) 在两个集合里都有；\(1.5\) 只在后一个里。

2. 充分条件和必要条件

拿到两个条件 \(p\)、\(q\)，先问一句：「若 \(p\) 成立，\(q\) 一定成立吗？」如果一定成立，就是 \(p\Rightarrow q\)。这时我们说：

\(p\Rightarrow q\) 时，\(p\) 是 \(q\) 的充分条件，\(q\) 是 \(p\) 的必要条件。
两句话说的是同一件事，只是站的角度不同。

为什么叫「充分」？有了 \(p\) 就足够保证 \(q\)，不用再加别的。

为什么叫「必要」？想让 \(p\) 成立，\(q\) 是少不了的：一旦 \(q\) 不成立，\(p\) 也不可能成立（否则就推出 \(q\) 了）。

例 1（看一遍怎么写）

对整数 \(n\)，说明「\(n\) 能被 \(4\) 整除」\(\Rightarrow\)「\(n\) 是偶数」，并用「充分」「必要」各说一句。

\(n\) 能被 \(4\) 整除，就是 \(n=4k\)（\(k\) 是整数）。于是 \(n=2\times(2k)\)，\(2k\) 是整数，\(n\) 是偶数。所以「能被 \(4\) 整除」\(\Rightarrow\)「是偶数」。

说法一：「能被 \(4\) 整除」是「是偶数」的充分条件。

说法二：「是偶数」是「能被 \(4\) 整除」的必要条件——不是偶数（比如 \(7\)），就不可能被 \(4\) 整除。

自己试试：「若一个四边形是正方形，则它是矩形」是真命题。那么「是矩形」是「是正方形」的？

B。正方形 \(\Rightarrow\) 矩形，箭头后面的「矩形」是必要条件：想当正方形，先得是矩形。选 A 的同学看到「是矩形」写在问句前面，就当成了充分条件。先找出谁推谁，再看问的是哪一个。

3. 两个方向都要查

只查 \(p\Rightarrow q\) 还不够。要说清楚关系，\(q\Rightarrow p\) 也得看：

\(p\Rightarrow q\)？\(q\Rightarrow p\)？结论：\(p\) 是 \(q\) 的……
成立不成立充分不必要条件
不成立成立必要不充分条件
成立成立充要条件，记 \(p\Leftrightarrow q\)
不成立不成立既不充分也不必要条件
推得出：要对所有满足 \(p\) 的情况说明 \(q\) 成立，是一个证明。
推不出：只要找到一个反例就够了。

例 2

对整数 \(n\)，「\(n\) 能被 \(4\) 整除」是「\(n\) 是偶数」的什么条件？

前推后：例 1 已经说明，成立。

后推前：找反例。\(n=6\) 是偶数，可 \(6\div4=1.5\) 不是整数，不能被 \(4\) 整除。推不出。

结论：前推后成立、后推前不成立，「能被 \(4\) 整除」是「是偶数」的充分不必要条件。说「不必要」，一定要拿出 \(n=6\) 这样的反例。

自己试试：「\(x=1\)」是「\(x^2=1\)」的什么条件？

A。\(x=1\Rightarrow x^2=1\)，成立；反过来 \(x=-1\) 也满足 \(x^2=1\)，却不是 \(1\)，是反例，推不出。选 C 的同学只查了一个方向，或者忘了 \(x=-1\)。

4. 用集合看：小范围推大范围

如果 \(p\)、\(q\) 说的是同一个变量（比如都在说实数 \(x\)），可以把满足它们的 \(x\) 收集成集合：\(P=\{x\mid p\}\)，\(Q=\{x\mid q\}\)。那么

\(p\Rightarrow q\) 就是 \(P\subseteq Q\)：小范围推得出大范围。
\(P\subsetneqq Q\)：\(p\) 是 \(q\) 的充分不必要条件；\(P=Q\)：充要条件。

例 3

\(p\)：\(-1<x<3\)，\(q\)：\(0<x<2\)。\(p\) 是 \(q\) 的什么条件？

\(P=\{x\mid -1<x<3\}\)，\(Q=\{x\mid 0<x<2\}\)。在数轴上，\(Q\) 那一段整个落在 \(P\) 里面，\(P\) 还多出两头，所以 \(Q\subsetneqq P\)。

\(q\Rightarrow p\)：\(0<x<2\) 的数一定满足 \(-1<x<3\)，成立。

\(p\nRightarrow q\)：反例 \(x=2.5\)，满足 \(-1<x<3\)，不满足 \(0<x<2\)。

结论：\(p\) 是 \(q\) 的必要不充分条件（换个角度：\(q\) 是 \(p\) 的充分不必要条件）。

自己试试：「\(x>2\)」是「\(x>1\)」的什么条件？

A。\(\{x\mid x>2\}\subsetneqq\{x\mid x>1\}\)：\(x>2\) 那一段整个在 \(x>1\) 那一段里面，是小的那段，小推大成立；反过来，\(x=1.5\) 满足 \(x>1\)、不满足 \(x>2\)，是反例。

选 B 的同学常这样想：「\(2\) 比 \(1\) 大，所以 \(x>2\) 管的范围更大」。正好反了：要求越严（范围越小）的那个，越容易当充分条件。

5. 定义、判定、性质

学过的很多结论，其实都在说条件关系：

  • 定义是充要条件：「\(n\) 是偶数」\(\Leftrightarrow\)「\(n\) 能被 \(2\) 整除」，两边可以互相替换。
  • 判定一类的结论（「只要……，就是……」）给的是充分条件：「整数 \(n\) 的末位是 \(0\)」\(\Rightarrow\)「\(n\) 能被 \(5\) 整除」。它必要不必要要另外查，这里不必要，\(n=15\) 是反例。
  • 性质一类的结论（「是……，就有……」）给的是必要条件：有这个身份，就一定有这个性质。

例 4

「对顶角相等」是一条性质。「两个角相等」是「两个角是对顶角」的什么条件？

性质说的是：两个角是对顶角 \(\Rightarrow\) 两个角相等。所以「相等」是「对顶角」的必要条件。

反过来：一个三角形里的两个 \(60^\circ\) 角相等，却不是对顶角，是反例，推不出。

结论：必要不充分条件。

自己试试：由等式的性质，\(x=y\Rightarrow x^2=y^2\)。「\(x^2=y^2\)」是「\(x=y\)」的什么条件？

B。\(x=y\Rightarrow x^2=y^2\)，所以 \(x^2=y^2\) 是必要条件；反过来 \(x=1\)，\(y=-1\) 时 \(x^2=y^2=1\)，可 \(x\ne y\)，推不出。选 C 的同学把「平方相等」当成「本身相等」，忘了还可能 \(x=-y\)。

6. 用之前，查这几件事

  1. 变量和范围先统一。
    反例：「\(x^2=4\)」和「\(x=2\)」，在全体实数里 \(x=-2\) 是反例，\(x^2=4\nRightarrow x=2\)；如果题目先说了 \(x>0\)，\(-2\) 不在考虑范围里，两者就能互相推出，结论变成充要。端点也一样：\(\{x\mid 0\le x\le 2\}\) 和 \(\{x\mid 0<x\le 2\}\) 只差一个 \(0\)，这一个点就是反例。
  2. 两个方向分开说明：证了 \(p\Rightarrow q\)（充分性），不等于证了 \(q\Rightarrow p\)（必要性）。
    反例：\(x=1\Rightarrow x^2=1\) 成立，可 \(x^2=1\nRightarrow x=1\)（\(x=-1\)）。
  3. 举几个例子不是证明：试了几个数都对，不等于推得出；一个反例却能推翻「推得出」。
    反例：「若 \(x>0\)，则 \(x^2>x\)」，试 \(x=2,3,10\) 都对；可 \(x=0.5\) 时 \(x^2=0.25<0.5\)，这句话是错的。
  4. 先还原成「若……则……」，别背口诀：同一个意思有好几种说法。
    反例：「偶数的充分条件是能被 \(4\) 整除」听着像「偶数 \(\Rightarrow\) 能被 \(4\) 整除」，其实说的是「能被 \(4\) 整除 \(\Rightarrow\) 偶数」。
「A 是 B 的充分条件」＝「B 的充分条件是 A」＝ A \(\Rightarrow\) B
「A 是 B 的必要条件」＝「B 的必要条件是 A」＝ B \(\Rightarrow\) A
再深一点（可以先跳过）

两个变量：条件说的是 \(x\)、\(y\) 两个数时，集合里的元素是点 \((x,y)\)，要在平面上比，不能只看一条数轴。例：「\(x>0\) 且 \(y>0\)」\(\Rightarrow\)「\(xy>0\)」成立；反过来 \(x=y=-1\) 是反例。

当且仅当：\(p\) 是 \(q\) 的充要条件，也说成「\(p\) 当且仅当 \(q\)」。「当」是 \(q\Rightarrow p\)，「仅当」是 \(p\Rightarrow q\)。

能接起来：\(p\Rightarrow q\)，\(q\Rightarrow r\)，就有 \(p\Rightarrow r\)。例：能被 \(4\) 整除 \(\Rightarrow\) 是偶数 \(\Rightarrow\) 末位是 \(0,2,4,6,8\) 之一。

两个条件都说同一个实数 \(x\)：\(p\)：\(x\in P\)，\(q\)：\(x\in Q\)。拖动端点改区间；点一下端点（或选中后按回车）在实心「含端点」和空心「不含端点」之间切换。键盘：Tab 选中端点，左右方向键移动。

挑战：四种结论都拖出来一次。再试试只差一个端点时会怎样。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(a\)、\(b\) 是实数。「\(a=0\)」是「\(ab=0\)」的什么条件？

A。\(a=0\) 时 \(ab=0\times b=0\)，成立；反过来 \(a=1\)，\(b=0\) 时 \(ab=0\)，可 \(a\ne0\)，是反例。选 C 的同学忘了 \(ab=0\) 也可能是 \(b=0\)。

2. 「\(|x|=2\)」是「\(x=2\)」的什么条件？

B。\(x=2\Rightarrow|x|=2\)；反过来 \(x=-2\) 时 \(|x|=2\)，却不是 \(2\)，推不出。问的是「\(|x|=2\)」：它被推出，是必要条件，不充分。选 A 的同学把方向看反了。

易错

3. 下面哪句话是对的？

只有 \(x=3\Rightarrow x^2=9\) 成立（反过来 \(x=-3\) 是反例）。

C 说「\(x^2=9\) 的充分条件是 \(x=3\)」，等于说「\(x=3\) 是 \(x^2=9\) 的充分条件」，就是 \(x=3\Rightarrow x^2=9\)，对。

A 和 B 其实是同一句话，都在说 \(x^2=9\Rightarrow x=3\)，错；D 也在说 \(x^2=9\Rightarrow x=3\)，错。换个说法、换个语序，先还原成「若……则……」再判断。

4. 已知 \(x>0\)。在这个前提下，「\(x^2>1\)」是「\(x>1\)」的什么条件？

答案 C。很多同学条件反射选 B，因为记得「\(x=-2\) 是反例」。

但题目已经限定 \(x>0\)，\(-2\) 根本不在考虑范围里。在 \(x>0\) 时，\(x^2>1\) 和 \(x>1\) 能互相推出，是充要条件。

用集合比大小之前，先看清变量和范围：范围变了，集合变了，结论也会变。

5. 小明判断「\(x^3>x\)」和「\(x>1\)」的关系：他试了 \(x=2,3,10\)，两个条件都成立，于是说它们互为充要条件。他说得对吗？

答案 B。试几个数只是举例，不是证明。

\(x>1\) 时 \(x^2>1\)，两边乘正数 \(x\) 得 \(x^3>x\)，前推后成立（这是对所有 \(x>1\) 的说明）。

反过来，取 \(x=-\tfrac12\)：\(x^3=-\tfrac18>-\tfrac12\)，满足 \(x^3>x\)，却不满足 \(x>1\)。一个反例就说明推不出。所以「\(x>1\)」是「\(x^3>x\)」的充分不必要条件。

挑战

6. \(p\)：\(x>a\)，\(q\)：\(x>2\)。如果 \(p\) 是 \(q\) 的充分不必要条件，实数 \(a\) 的取值范围是？

A。充分不必要就是 \(P\subsetneqq Q\)，\(P=\{x\mid x>a\}\)，\(Q=\{x\mid x>2\}\)。

\(P\subseteq Q\) 要 \(a\ge2\)：比如 \(a=1\) 时 \(x=1.5\) 在 \(P\) 里、不在 \(Q\) 里。可 \(a=2\) 时 \(P=Q\)，是充要条件，不是「不必要」，要去掉。所以 \(a>2\)。选 B 的同学没单独查端点 \(a=2\)。

这一节的真题还在整理。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
