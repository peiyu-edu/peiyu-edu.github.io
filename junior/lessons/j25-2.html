25.2 降次——解一元二次方程

二次方程看似高不可攀，只要抓住「降次」这把金钥匙，把二次转化为一次，四种绝技——直接开平方法、配方法、公式法、因式分解法，加上神奇的判别式与韦达定理，便能迎刃而解。

本节导读　先修：25.1 概念 · 19.1 二次根式 · 本节路线

要用到：一元二次方程的一般形式（回看 25.1）、平方根与二次根式的化简（回看 19.1）、完全平方公式与因式分解（回看 17.2）。

  1. 从最简单的开平方进入：感受由平方还原到一次的「降次」快感。
  2. 配方法：用割补拼图的几何直观，将任意一般式配成完全平方。
  3. 公式法：配方法的一般化结晶，根的判别式 \(\Delta = b^2 - 4ac\) 的三态定乾坤。
  4. 因式分解法与韦达定理：\(AB=0\) 的精妙拆解，以及两根之和与积的对称之美。
  5. 动手试验：在几何拼图与数轴根位动态演示中看清解法的本质。
  6. 自检与巩固练习，突破三大典型翻车雷区。

一个正方形的面积如果是 \(9\text{ cm}^2\)，它的边长是 \(3\text{ cm}\)；但在代数方程中，未知数 \(x^2 = 9\) 的解却有两个：\(x_1 = 3, x_2 = -3\)。如果把方程变成 \((x - 1)^2 = 4\)，未知数该怎么求？

对于方程 \((x - 3)^2 = 16\)，根据平方根的意义两边开平方，它的两个实数根是（　）

B。两边开平方，得 \(x - 3 = \pm 4\)：当 \(x - 3 = 4\) 时，\(x_1 = 7\)；当 \(x - 3 = -4\) 时，\(x_2 = -1\)。选 A 是忘记把括号里的 \(-3\) 移项变号。

这种通过平方根的意义，把一个二次方程转化为两个一次方程的思想，就叫作「降次」！

1. 先认识几个词：配方法的几何本质与五步法

前置知识：完全平方公式 \((a \pm b)^2 = a^2 \pm 2ab + b^2\)（回看 16.3）。如果一个方程不是现成的完全平方（如 \(x^2 + 6x + 4 = 0\)），我们能不能手动把它「凑」成完全平方呢？

直觉微图解 ①几何配方拼图：把 \(x^2 + 6x\) 补全为一个大正方形

核心法则两边加一次项系数一半的平方

对于 \(x^2 + bx\)，一次项系数是 \(b\)，一半是 \(\dfrac{b}{2}\)，平方就是 \(\left(\dfrac{b}{2}\right)^2\)。在两边同时加上它，左边立刻配成 \(\left(x + \dfrac{b}{2}\right)^2\)！

避坑硬核二次项系数必须先化为 1

如果二次项系数不是 1（如 \(2x^2 - 8x + 1 = 0\)），必须先两边同除以 2，化为 \(x^2 - 4x = -\dfrac{1}{2}\) 后，再加 \((-2)^2 = 4\)。切忌直接配方！

示范例题 1：用配方法解一元二次方程（标准五步）

题目：用配方法解方程 \(2x^2 - 6x - 1 = 0\)．

① 读懂题意：二次项系数是 2，不是 1；常数项是 \(-1\)。要求用配方法求解。

② 想办法：移项把常数项移到右边 \(\to\) 两边除以 2 化二次项系数为 1 \(\to\) 两边加一次项系数一半的平方 \(\to\) 开平方降次求解。

③ 执行与检查：
移项，得：\(2x^2 - 6x = 1\)．
二次项系数化为 1，方程两边同时除以 2，得：\(x^2 - 3x = \dfrac{1}{2}\)．
配方，两边同时加上 \(\left(-\dfrac{3}{2}\right)^2 = \dfrac{9}{4}\)，得：
\(x^2 - 3x + \dfrac{9}{4} = \dfrac{1}{2} + \dfrac{9}{4}\)，即 \(\left(x - \dfrac{3}{2}\right)^2 = \dfrac{11}{4}\)．
开平方降次，得：\(x - \dfrac{3}{2} = \pm\dfrac{\sqrt{11}}{2}\)．
解得：\(x_1 = \dfrac{3 + \sqrt{11}}{2},\ x_2 = \dfrac{3 - \sqrt{11}}{2}\)．

④ 回头看：检查配方时是否两边同时加上了 \(\dfrac{9}{4}\)；开方后分母 \(\sqrt{4}=2\) 必须化简。

自己试试 1：将方程 \(x^2 - 8x + 3 = 0\) 用配方法转化为 \((x + m)^2 = n\) 的形式，则 \(m\) 和 \(n\) 的值分别为（　）

D。移项得 \(x^2 - 8x = -3\)；两边加 \(4^2 = 16\)，得 \(x^2 - 8x + 16 = -3 + 16 \implies (x - 4)^2 = 13\)。对比 \((x+m)^2 = n\)，得 \(m = -4, n = 13\)。

2. 核心点一：公式法与根的判别式 \(\Delta\)

对一般形式 \(ax^2 + bx + c = 0\)（\(a \ne 0\)）实施配方法，两边除以 \(a\) 得 \(x^2 + \dfrac{b}{a}x = -\dfrac{c}{a}\)，两边加 \(\left(\dfrac{b}{2a}\right)^2\)，得到惊天结论：

\(\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2} \implies \mathbf{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}} \quad (\Delta \ge 0)\)

分子的根号内式子 \(\mathbf{\Delta = b^2 - 4ac}\) 叫作根的判别式。它是方程根的「指挥官」！

直觉微图解 ②判别式 \(\Delta\) 三态透视镜：决定根的命运

示范例题 2：用公式法解方程并判断根的情况

题目：用公式法解一元二次方程 \(2x^2 + 5x - 3 = 0\)．

① 读懂题意：方程已是一般形式，\(a = 2, b = 5, c = -3\)．

② 想办法：先计算判别式 \(\Delta = b^2 - 4ac\) 的值，确认非负后再代入求根公式。

③ 执行与检查：
这里 \(a = 2, b = 5, c = -3\)．
\(\Delta = b^2 - 4ac = 5^2 - 4\times 2\times (-3) = 25 - (-24) = 49 > 0\)．
因为 \(\Delta > 0\)，所以原方程有两个不相等的实数根：
\(x = \dfrac{-b \pm \sqrt{\Delta}}{2a} = \dfrac{-5 \pm \sqrt{49}}{2\times 2} = \dfrac{-5 \pm 7}{4}\)．
解得：\(x_1 = \dfrac{-5 + 7}{4} = \dfrac{1}{2},\ x_2 = \dfrac{-5 - 7}{4} = -3\)．

④ 回头看：检查分母是 \(2a = 4\)，绝不是 2；算 \(-4ac\) 时负负得正为 \(+24\)。

自己试试 2：不解方程，下列一元二次方程中有两个不相等的实数根的是（　）

A。A 选项 \(\Delta = (-3)^2 - 4\times 1\times 1 = 9 - 4 = 5 > 0\)，有两个不相等的实数根；B 选项 \(\Delta = 16 - 16 = 0\)（两相等实根）；C 选项 \(\Delta = 1 - 8 = -7 \lt 0\)（无实根）；D 选项 \(\Delta = 4 - 8 = -4 \lt 0\)（无实根）。

3. 核心点二：因式分解法与根与系数的关系（韦达定理）

当方程能迅速分解为两个一次因式相乘时，因式分解法是最快、最优雅的方法：

\(A \cdot B = 0 \iff A = 0 \quad \text{或} \quad B = 0\)

不仅如此，若一元二次方程有两个实数根 \(x_1, x_2\)，把求根公式相加相乘，就能得出韦达定理：

\(\mathbf{x_1 + x_2 = -\frac{b}{a}}, \quad \mathbf{x_1 x_2 = \frac{c}{a}} \quad (\Delta \ge 0)\)

直觉微图解 ③因式分解法降次直观：两路分支一分为二

示范例题 3：利用根与系数的关系（韦达定理）求代数式的值

题目：已知 \(x_1, x_2\) 是关于 \(x\) 的一元二次方程 \(x^2 - 4x + 2 = 0\) 的两个实数根，求代数式 \(x_1^2 + x_2^2\) 的值。

① 读懂题意：题目不要求我们具体解出 \(x_1\) 和 \(x_2\)，而是求平方和。

② 想办法：根据完全平方公式，\(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2\)。利用韦达定理，直接写出两根之和与两根之积，整体代入。

③ 执行与检查：
这里 \(a = 1, b = -4, c = 2\)．
首先检验判别式：\(\Delta = (-4)^2 - 4\times 1\times 2 = 16 - 8 = 8 > 0\)，方程确有两个实根．
由根与系数的关系，得：
\(x_1 + x_2 = -\dfrac{-4}{1} = 4\)，\(x_1 x_2 = \dfrac{2}{1} = 2\)．
所以：\(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 4^2 - 2\times 2 = 16 - 4 = 12\)．

④ 回头看：牢记两根之和带负号 \(-b/a\)；必须写出判别式 \(\Delta \ge 0\) 的有效性保障。

示范例题 4：四种解法如何选用？（解法最优策略对比）

题目：解方程：(1) \(3x(x - 2) = x - 2\)；(2) \(x^2 - 6x - 7 = 0\)．

① 读懂题意：根据方程特征选择最简便的解法，不走弯路。

② 想办法：
(1) 两边都有公因式 \((x - 2)\)，必须移项提取公因式，绝不能两边直接约掉 \((x-2)\)！
(2) 虽可用公式法，但常数项 \(-7\) 与一次项系数 \(-6\) 很容易因式分解为 \((x - 7)(x + 1) = 0\)，因式分解法秒杀。

③ 执行：
(1) 移项得：\(3x(x - 2) - (x - 2) = 0 \implies (x - 2)(3x - 1) = 0\)，解得 \(x_1 = 2, x_2 = \dfrac{1}{3}\)．
(2) 因式分解得：\((x - 7)(x + 1) = 0\)，解得 \(x_1 = 7, x_2 = -1\)．

④ 策略总结：直接开平、因式分解能用先用；二次项为 1 且一次项为偶数可用配方法；其余用公式法保底。

自己试试 3：已知方程 \(x^2 - 5x + 3 = 0\) 的两根为 \(x_1, x_2\)，则 \(\dfrac{1}{x_1} + \dfrac{1}{x_2}\) 的值为（　）

B。通分：\(\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2}\)。由韦达定理，\(x_1 + x_2 = 5, x_1 x_2 = 3\)，代入得 \(\dfrac{5}{3}\)。选 A 是两根之和符号弄错。

翻车现场 ①两边同除以含未知数式子导致丢根！

解 \(x(x - 3) = 2(x - 3)\) 时，顺手两边同时除以 \((x - 3)\)，得出 \(x = 2\)。丢掉了 \(x - 3 = 0 \implies x = 3\) 这个根！必须移项提公因式：\((x-3)(x-2)=0\)。

翻车现场 ②公式法求根中负负得正翻车

若 \(b = -4\)，代入求根公式时分子前面是 \(-b\)，很多同学写成 \(-4\)；应为 \(-(-4) = +4\)！算 \(\Delta\) 时 \((-4)^2 = 16\)，负数的平方必须是非负数。

翻车现场 ③韦达定理忘查判别式产生伪解

利用 \(x_1 + x_2\) 和 \(x_1 x_2\) 求参数值时，求出的参数必须检验是否满足 \(\Delta \ge 0\)。若原方程在实数范围内根本无根，韦达定理就不存在实数立足点！

再深一点：韦达定理与代数符号化革命

法国数学家弗朗索瓦·韦达（1540–1603）是历史上第一个系统使用字母代表已知数和未知数的数学家。在他之前，方程全是用冗长的文字叙述。韦达引入字母后，不仅推导出了根与系数的优美关系，更直接开启了近代符号代数的大门，被誉为「现代代数学之父」。

动手实验 ②（进阶）根的判别式与求根数轴全景图：观察两根聚散合离

对于方程 \(x^2 - 4x + c = 0\)（\(a=1, b=-4\)），拖动常数项 \(c\) 的大小，观察判别式 \(\Delta = 16 - 4c\) 的正负如何操控两根在数轴上的聚拢、重合与消失：

1. 直接用：用直接开平方法解方程 \((x - 2)^2 = 9\)，它的实数根是（　）

B。两边开平方得 \(x - 2 = \pm 3 \implies x_1 = 2 + 3 = 5,\ x_2 = 2 - 3 = -1\)。

2. 直接用：一元二次方程 \(x^2 - 2x - 3 = 0\) 的两根之和与两根之积分别是（　）

C。由韦达定理，\(x_1 + x_2 = -\dfrac{b}{a} = -\dfrac{-2}{1} = 2\)，\(x_1 x_2 = \dfrac{c}{a} = \dfrac{-3}{1} = -3\)。

3. 易错题：用因式分解法解方程 \(x(x - 5) = x - 5\)，正确的解是（　）

提示

切忌两边同时除以 \((x - 5)\)！把右边移到左边并提取公因式。

D。移项得 \(x(x - 5) - (x - 5) = 0 \implies (x - 5)(x - 1) = 0 \implies x_1 = 1, x_2 = 5\)。选 A 是直接约掉 \((x-5)\) 丢掉了根 \(x=5\)。

4. 易错题：若关于 \(x\) 的一元二次方程 \(x^2 - 2x + k = 0\) 有两个不相等的实数根，则 \(k\) 的取值范围是（　）

提示

有两个不相等的实数根要求判别式 \(\Delta > 0\)。注意常数项符号。

A。方程有两个不相等的实数根，\(\Delta = (-2)^2 - 4\times 1\times k = 4 - 4k > 0 \implies 4 > 4k \implies k \lt 1\)。选 B 是混淆了「有两个实数根（\(\Delta \ge 0\)）」与「有两个不相等实数根（\(\Delta > 0\)）」。

5. 挑战题：已知关于 \(x\) 的一元二次方程 \(x^2 - 3x + m = 0\) 的两根为 \(x_1, x_2\)，且满足 \(x_1^2 + x_2^2 = 7\)，则 \(m\) 的值是（　）

提示

变形为 \(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2\)，求出 \(m\) 后记得验证 \(\Delta \ge 0\)。

C。由韦达定理，\(x_1 + x_2 = 3, x_1 x_2 = m\)。\(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 3^2 - 2m = 9 - 2m = 7 \implies 2m = 2 \implies m = 1\)。检验判别式：\(\Delta = (-3)^2 - 4\times 1\times 1 = 9 - 4 = 5 > 0\)，符合题意，选 C。

巩固练习 1：用配方法解一元二次方程 \(x^2 - 2x - 2023 = 0\) 时，将它转化为 \((x + a)^2 = b\) 的形式，则 \(a^b\) 的值为（　）

D。移项得 \(x^2 - 2x = 2023\)；两边同时加上一次项系数一半的平方 \(1^2\)，得 \(x^2 - 2x + 1 = 2023 + 1\)，即 \((x - 1)^2 = 2024\)．对比 \((x + a)^2 = b\)，得 \(a = -1, b = 2024\)．因此 \(a^b = (-1)^{2024} = 1\)，故选 D．
