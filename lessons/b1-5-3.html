5.3 诱导公式

\(\pi\pm\alpha\)、\(-\alpha\)、\(\dfrac{\pi}{2}\pm\alpha\) 的三角函数值，可由单位圆上的反射、旋转或整圈变化读出来。分清坐标如何变化，再判断函数名与符号。

把圆形观景盘（或摩天轮）的中心当作原点，半径算 \(1\)。你的座舱在 \(30^\circ\) 的位置，坐标约是 \((0.87,\ 0.5)\)。先点下面的对称按钮，看看三个对称位置上的座舱坐标怎么变符号：

你的朋友坐在正对面的座舱（隔着中心，转过半圈到 \(210^\circ\)）。他的坐标近似是？

B。正对面就是关于中心（原点）对称：往左多远就变成往右多远，往上多高就变成往下多深，两个坐标都变号。

换成角来说：你在 \(30^\circ\)，朋友在 \(30^\circ+180^\circ=210^\circ\)。单位圆上点的坐标就是 \((\cos,\sin)\)，所以

\(\cos210^\circ=-\cos30^\circ\)，\(\sin210^\circ=-\sin30^\circ\)。

这一节会用反射、旋转与整圈终边不变，读出新角的函数值与原角的关系。这样的式子叫诱导公式。

1. 先认识几个词：对称几何本质与奇变偶不变口诀

要用到：5.1 的任意角与弧度制（回看 5.1）；5.2 的单位圆定义与四象限正负符号口诀（回看 5.2）。先看下面这幅微图解：

直觉微图解 ①对称翻折几何本质与奇变偶不变法则

口诀心法「符号看象限」看原函数，不看新函数

化简 \(\cos\left(\dfrac{\pi}{2}+\alpha\right)\) 时，视 \(\alpha\) 为锐角，角在第二象限。符号取决于原本的余弦函数 \(\cos\) 在第二象限为负，取负号得 \(-\sin\alpha\)！绝不能看新名字 \(\sin\) 误以为正！

理解认知「暂当锐角」仅为定号，公式实数全普适

把 \(\alpha\) 暂时当作锐角纯粹是为了快速排查正负符号；等式是基于单位圆几何对称推导出来的，正余弦公式对任意实数都成立；含正切或倒数的公式，必须先确保两边都有定义。

2. 核心诱导公式全景矩阵

以下 \(k\in\mathbb Z\)。正弦、余弦关系对所有实角成立；正切所在列须满足最后一列的条件。

角正弦余弦正切正切条件
\(2k\pi+\alpha\)\(\sin\alpha\)\(\cos\alpha\)\(\tan\alpha\)\(\cos\alpha\ne0\)
\(\pi+\alpha\)\(-\sin\alpha\)\(-\cos\alpha\)\(\tan\alpha\)\(\cos\alpha\ne0\)
\(-\alpha\)\(-\sin\alpha\)\(\cos\alpha\)\(-\tan\alpha\)\(\cos\alpha\ne0\)
\(\pi-\alpha\)\(\sin\alpha\)\(-\cos\alpha\)\(-\tan\alpha\)\(\cos\alpha\ne0\)
\(\dfrac\pi2-\alpha\)\(\cos\alpha\)\(\sin\alpha\)\(\dfrac{\cos\alpha}{\sin\alpha}\)\(\sin\alpha\ne0\)
\(\dfrac\pi2+\alpha\)\(\cos\alpha\)\(-\sin\alpha\)\(-\dfrac{\cos\alpha}{\sin\alpha}\)\(\sin\alpha\ne0\)

统一写成 \(k\pi/2\pm\alpha\) 时，先看整数 \(k\) 的奇偶，判断正弦、余弦是否换名；定公式符号时暂当 \(\alpha\) 为锐角，查原函数在新角象限的正负。\(\pi/2+\alpha\) 是90°旋转，不是一次 \(y=x\) 反射。

例 1（特殊角负角化锐角求值）

求 \(\cos 150^\circ\)、\(\sin 225^\circ\)、\(\tan(-60^\circ)\)。

\(\cos 150^\circ = \cos(180^\circ - 30^\circ) = -\cos 30^\circ = -\dfrac{\sqrt{3}}{2}\)；
\(\sin 225^\circ = \sin(180^\circ + 45^\circ) = -\sin 45^\circ = -\dfrac{\sqrt{2}}{2}\)；
\(\tan(-60^\circ) = -\tan 60^\circ = -\sqrt{3}\)（正切奇函数吐出负号）。

自己试试：\(\cos 120^\circ\) 等于？

D。\(\cos 120^\circ = \cos(180^\circ - 60^\circ) = -\cos 60^\circ = -\dfrac{1}{2}\)。选 A 的同学漏了第二象限余弦为负；选 C 的同学记混了 \(\cos 60^\circ\) 与 \(\sin 60^\circ\)。

例 2（化简与正负抵消）

化简 \(\cos\left(\dfrac{\pi}{2}+\alpha\right) + \sin(\pi-\alpha)\)。

由奇变偶不变，\(\dfrac{\pi}{2}+\alpha\) 是奇数倍换名，二象限余弦为负，得 \(-\sin\alpha\)；
\(\pi-\alpha\) 是偶数倍留名，二象限正弦为正，得 \(\sin\alpha\)；
两项相加：原式 \(= -\sin\alpha + \sin\alpha = 0\)。

自己试试：\(\cos\left(\dfrac{\pi}{2}+\alpha\right)\) 等于什么？

B。奇变名：\(\cos \to \sin\)；视 \(\alpha\) 为锐角，\(\dfrac{\pi}{2}+\alpha\) 落在第二象限，原函数 \(\cos\) 在第二象限为负，取负号得 \(-\sin\alpha\)。选 A 的同学误看了新函数正弦在第二象限为正！

3. 三步破题思维链：复杂代数式化简与负角整圈归化

例 3（示范：多项诱导公式化简求值三步思维链）

求值与化简：(1) 求 \(\cos(-1140^\circ)\)；(2) 化简 \(\dfrac{\sin(\pi+\alpha)\cos(2\pi-\alpha)\tan(\pi-\alpha)}{\cos\left(\dfrac{\pi}{2}+\alpha\right)\sin\left(\dfrac{3\pi}{2}-\alpha\right)}\)。

👀 第一步大角去整圈与负角化正： 对 (1)：\(\cos(-1140^\circ) = \cos(1140^\circ)\)（余弦偶函数吞负号）；
剥离整数圈：\(1140^\circ = 3\times 360^\circ + 60^\circ\)，故 \(\cos 1140^\circ = \cos 60^\circ = \dfrac{1}{2}\)！
🔧 第二步逐项依「奇变偶不变，符号看原函数」精准定名定号： 分子逐项：\(\sin(\pi+\alpha) = -\sin\alpha\)；\(\cos(2\pi-\alpha) = \cos(-\alpha) = \cos\alpha\)；\(\tan(\pi-\alpha) = -\tan\alpha\)；
分母逐项：\(\cos\left(\dfrac{\pi}{2}+\alpha\right) = -\sin\alpha\)；\(\sin\left(\dfrac{3\pi}{2}-\alpha\right) = -\cos\alpha\)（奇倍变名，三象限原正弦为负）。
🛡️ 第三步符号总清点与弦切化简防丢负号： 原式须 \(\sin\alpha\cos\alpha\ne0\)。在这个定义域内代回原分式：\(\dfrac{(-\sin\alpha)\cdot \cos\alpha \cdot (-\tan\alpha)}{(-\sin\alpha)\cdot (-\cos\alpha)} = \dfrac{\sin\alpha\cos\alpha\tan\alpha}{\sin\alpha\cos\alpha} = \tan\alpha\)！
清点负号：分子含 2 个负号得正，分母含 2 个负号得正，正正相除得正，干脆利落！

自己试试：\(\sin(-750^\circ)\) 等于？

A。\(\sin(-750^\circ) = -\sin 750^\circ = -\sin(30^\circ + 2\times 360^\circ) = -\sin 30^\circ = -\dfrac{1}{2}\)。选 B 的同学第一步丢了正弦吐出的负号！

4. 用之前必查：三大高频翻车现场

翻车现场 ①「符号看象限」误看成新函数，符号全反
❌ 典型错解：化简 \(\cos\left(\dfrac{\pi}{2}+\alpha\right)\)，看第二象限正弦为正，写出 \(+\sin\alpha\)。
✅ 一眼看清真相：口诀必须看原函数！原本是 \(\cos\)，余弦在第二象限为负，铁定是 \(-\sin\alpha\)！
翻车现场 ②负角任意吞负号，正弦正切负号凭空蒸发
❌ 典型错解：\(\sin(-60^\circ) = \sin 60^\circ = \dfrac{\sqrt{3}}{2}\)。
✅ 看右图秒懂真相：只有余弦是偶函数吞负号 \(\cos(-\alpha)=\cos\alpha\)；正弦和正切都是奇函数，负号必须吐出来：\(\sin(-\alpha)=-\sin\alpha\)！
翻车现场 ③π 与 π/2 混淆，函数名胡乱篡改
❌ 典型错解：将 \(\sin(\pi-\alpha)\) 盲目换名为 \(\cos\alpha\)。
✅ 一眼看清真相：含 \(\pi, 2\pi\) 是 \(\dfrac{\pi}{2}\) 的偶数倍，函数名绝对不变！只有含 \(\dfrac{\pi}{2}, \dfrac{3\pi}{2}\) 奇数倍才换名！\(\sin(\pi-\alpha) = \sin\alpha\)！
再深一点（可以先跳过）

为什么诱导公式不需要死记：只要牢记单位圆上点的四种对称模式（关于原点、关于 \(x\) 轴、关于 \(y\) 轴、关于直线 \(y=x\)），配合整圈终边不变及90°旋转，就能逐项核对公式；含正切时另查定义域。

分式化简中的定义域红线：逐项检查原式各函数有定义、分母不为零，再约去非零公因式。例3(2)须同时有 \(\sin\alpha\ne0\) 与 \(\cos\alpha\ne0\)；化成正切后仍保留原限制。

单位圆：拖点 P，看 P′ 跑到哪

拖动单位圆上的点 \(P\) 改变角 \(\alpha\)（Tab 选中后用方向键，每次 \(5^\circ\)）；点上面的按钮换一个角，看点 \(P'\) 跑到哪、坐标怎么变。

试试把 \(\alpha\) 拖到第二、三象限：公式照样成立。再把 \(\alpha\) 拖到 \(90^\circ\)，看正切那一行。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(\tan\dfrac{4\pi}{3}\) 等于？

A。\(\dfrac{4\pi}{3}=\pi+\dfrac{\pi}{3}\)，由半圈关系 \(\tan\left(\pi+\dfrac{\pi}{3}\right)=\tan\dfrac{\pi}{3}=\sqrt3\)。关于原点对称，\(x\)、\(y\) 同时变号，\(\dfrac yx\) 不变。选 B 的同学以为加 \(\pi\) 都要变号，那是 sin 和 cos；第三象限 tan 是正的。

2. 已知 \(\sin\alpha=\dfrac14\)，则 \(\cos\left(\dfrac{\pi}{2}+\alpha\right)\) 等于？

B。由90°旋转关系 \(\cos\left(\dfrac{\pi}{2}+\alpha\right)=-\sin\alpha=-\dfrac14\)，直接代，不用开平方。选 A 是忘了负号；选 C、D 是没换名，去求了 \(\cos\alpha\)。

易错

3. 若 \(\alpha\) 是第二象限角，\(\sin(\pi-\alpha)\) 等于什么？

A。有同学以为「口诀里把 \(\alpha\) 当锐角」，所以 \(\alpha\) 是钝角时公式会变号。

不会。\(\pi-\alpha\) 和 \(\alpha\) 的终边关于 \(y\) 轴对称，纵坐标相同，这对任何 \(\alpha\) 都对。比如 \(\alpha=150^\circ\)，\(\pi-\alpha=30^\circ\)，两边都是 \(\dfrac12\)。

「当成锐角」只是用来定公式里的符号的办法，公式本身对所有角成立。可以在「动手」的图里把 \(P\) 拖到第二象限亲眼看看。

4. \(\sin\left(\dfrac{3\pi}{2}-\alpha\right)\) 等于什么？

B。分开判断函数名和符号：

函数名：\(\dfrac{3\pi}{2}\) 是 \(\dfrac{\pi}{2}\) 的 3 倍，奇数倍，sin 变 cos。选 C、D 是没变名。

符号：把 \(\alpha\) 当锐角，\(\dfrac{3\pi}{2}-\alpha\) 在第三象限，原函数 sin 在第三象限为负。选 A 是忘了看符号，或者去看了 cos 的符号。

也可以一步步推：\(\sin\left(\dfrac{3\pi}{2}-\alpha\right)=\sin\left(\pi+\left(\dfrac{\pi}{2}-\alpha\right)\right)=-\sin\left(\dfrac{\pi}{2}-\alpha\right)=-\cos\alpha\)。

5. 已知 \(\cos(\pi+\alpha)=-\dfrac35\)，则 \(\sin(\pi-\alpha)\) 等于什么？

C。由半圈关系，\(\cos\alpha=\dfrac35\)；由补角关系，\(\sin(\pi-\alpha)=\sin\alpha\)。

可 \(\cos\alpha=\dfrac35>0\) 只说明 \(\alpha\) 在第一或第四象限，\(\sin\alpha=\pm\sqrt{1-\dfrac{9}{25}}=\pm\dfrac45\)，两种都可能。只写 \(\dfrac45\) 是默认了 \(\alpha\) 是锐角。

如果题目再加一句「\(\alpha\) 是第四象限角」，答案才是 \(-\dfrac45\)。开平方的正负，一定要由角的范围来定。

例题视频：先剥诱导公式，再弦化切

已知 \(\tan(\pi+\alpha)=2\)，求 \(\dfrac{2\sin(\pi-\alpha)-\cos(-\alpha)}{\sin(\pi+\alpha)+3\cos(2\pi-\alpha)}\)。

先得 \(\tan\alpha=2\)，故 \(\cos\alpha\ne0\)。原分母 \(\cos\alpha(3-\tan\alpha)=\cos\alpha\ne0\)，可以同除余弦，原式为 \((2\tan\alpha-1)/(3-\tan\alpha)=3\)。若改求 \(\sin\alpha+\cos\alpha\)，它虽是一次齐次式，却不能由正切唯一确定。

挑战

6. 化简 \(\dfrac{\sin(2\pi-\alpha)\cos(\pi+\alpha)}{\cos\left(\dfrac{\pi}{2}-\alpha\right)\sin\left(\dfrac{3\pi}{2}+\alpha\right)}\)（式子有意义）。

B。逐个化：\(\sin(2\pi-\alpha)=-\sin\alpha\)，\(\cos(\pi+\alpha)=-\cos\alpha\)，分子是 \(\sin\alpha\cos\alpha\)。

\(\cos\left(\dfrac{\pi}{2}-\alpha\right)=\sin\alpha\)；\(\sin\left(\dfrac{3\pi}{2}+\alpha\right)=-\cos\alpha\)（例 3），分母是 \(-\sin\alpha\cos\alpha\)。

「式子有意义」说明分母不为 \(0\)，即 \(\sin\alpha\cos\alpha\ne0\)，才能约分，结果是 \(-1\)。常见错：\(\sin\left(\dfrac{3\pi}{2}+\alpha\right)\) 少了负号，得 A。代 \(\alpha=30^\circ\) 核对：\(\dfrac{(-\frac12)(-\frac{\sqrt3}{2})}{\frac12\cdot(-\frac{\sqrt3}{2})}=-1\)。

例题视频：逐项化简与给值求值

化简 \(f(\alpha)=\dfrac{\sin(\pi-\alpha)\cos(2\pi-\alpha)\tan(\pi+\alpha)}{\cos(\frac\pi2+\alpha)\tan(-\alpha)}\)（原式有意义）；若 \(\alpha\) 是第三象限角，且 \(\cos(\frac{3\pi}2-\alpha)=3/5\)，求值。

原定义域为 \(\sin\alpha\cos\alpha\ne0\)。在此范围约分得 \(f(\alpha)=\cos\alpha\)；条件给 \(\sin\alpha=-3/5\)，结合第三象限取 \(\cos\alpha=-4/5\)，所以 \(f(\alpha)=-4/5\)。定号示意暂取锐角，实际求值仍按题设象限。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
