7.5 正态分布

身高、零件尺寸、测量误差……很多量的直方图都是「中间高、两边低、左右对称」。这一节用一条钟形曲线描述它们：概率就是曲线下的面积。

一台机器往袋子里装大米，每袋标的是 \(500\) 克。抽了 \(100\) 袋称重，结果如下（每组含左端、不含右端）：

重量（克）袋数
低于 \(496\)\(2\)
\(496\sim498\)\(14\)
\(498\sim500\)\(34\)
\(500\sim502\)\(34\)
\(502\sim504\)\(14\)
\(504\) 及以上\(2\)

再随手拿一袋，重量在 \(498\sim502\) 克之间的可能性，用这组数据估计大约是多少？

C。\(498\sim500\) 有 \(34\) 袋，\(500\sim502\) 有 \(34\) 袋，合起来 \(68\) 袋，频率 \(0.68\)，用它估计概率约 \(68\%\)。

再看整张表：中间多、两边少，左右差不多对称。画成直方图就是一个「钟」。袋数再多、分组再细，直方图的上沿会越来越像一条光滑的钟形曲线。

这一节就讲这条曲线——正态曲线：落在某一段的概率，就是这一段曲线下面的面积。那个 \(68\%\) 也不是巧合，后面会看到。

1. 先认识几个词

要用到：均值、方差、标准差（回看 7.3）；频率分布直方图（回看必修二 9.2）。

均值和标准差：均值说「中心在哪」；方差说「散得多开」，标准差是方差的算术平方根，和原数据同一个单位。

例：大米重量均值 \(500\) 克，方差 \(4\)，那么标准差是 \(\sqrt4=2\) 克，不是 \(4\) 克。

直方图里，面积才是频率：频率分布直方图的纵轴是「频率 ÷ 组距」，小长方形的面积 \(=\) 组距 \(\times\) 高 \(=\) 这一组的频率，所有长方形面积加起来是 \(1\)。

例：上面 \(498\sim500\) 这组，组距 \(2\)，频率 \(0.34\)，长方形的高是 \(0.34\div2=0.17\)。高 \(0.17\) 不是频率，面积 \(2\times0.17=0.34\) 才是。

取值连成一片的量：前几节的随机变量（次数、个数）只取 \(0,1,2,\dots\) 这样一个一个的值，能列分布列。重量、身高可以取一段里的任何数，列不完，只能问「落在某一段里」的概率。

例：问「一袋恰好重 \(500.000\cdots\) 克」没有意义，秤再准也碰不上；问「在 \(499.5\sim500.5\) 克之间」才有意义。

2. 正态曲线和 \(N(\mu,\sigma^2)\)

样本越来越多、组距越来越小，钟形直方图的上沿贴近一条光滑曲线。如果随机变量 \(X\) 落在任一区间 \([a,b]\) 的概率，都等于这条曲线在 \(a\) 到 \(b\) 之间、\(x\) 轴上方的面积，就说 \(X\) 服从正态分布，记作

\(X\sim N(\mu,\sigma^2)\)，其中 \(\mu\) 是均值，\(\sigma^2\) 是方差，\(\sigma>0\) 是标准差。

曲线长这样（在「动手」里可以拖）：

  • 整条曲线在 \(x\) 轴上方，关于直线 \(x=\mu\) 对称，在 \(x=\mu\) 处最高；
  • 曲线和 \(x\) 轴之间的总面积是 \(1\)；
  • \(\mu\) 管位置：\(\mu\) 变，曲线整条左右平移，形状不变；
  • \(\sigma\) 管胖瘦：\(\sigma\) 越小越「瘦高」，越大越「矮胖」——总面积要保持 \(1\)，变窄了就只能变高。

例 1（看一遍怎么读）

\(X\sim N(3,4)\)。说出均值、标准差，并比较 \(P(X>5)\) 和 \(P(X<1)\)。

对照 \(N(\mu,\sigma^2)\)：\(\mu=3\)，\(\sigma^2=4\)，所以标准差 \(\sigma=2\)。

曲线关于 \(x=3\) 对称，\(5\) 和 \(1\) 离 \(3\) 都是 \(2\)，一个在右、一个在左，两块尾巴面积一样：\(P(X>5)=P(X<1)\)。另外 \(P(X<3)=P(X>3)=0.5\)。

自己试试：\(X\sim N(10,9)\)，\(X\) 的标准差是？

B。括号里第二个数是方差 \(\sigma^2=9\)，标准差 \(\sigma=\sqrt9=3\)。选 A 是把方差当成了标准差，这是最常见的错；\(10\) 是均值。

3. 区间概率 = 面积，用对称性求

正态分布下，求 \(P(a<X<b)\) 就是求一块面积。高中不用积分算它，靠三样东西：对称性、总面积 \(1\)、题目给的或下面要讲的几个数。

例 2

\(X\sim N(2,\sigma^2)\)，已知 \(P(X>4)=0.1\)。求 \(P(X<0)\)、\(P(0<X<4)\)、\(P(2<X<4)\)。

对称轴是 \(x=2\)，\(0\) 和 \(4\) 关于它对称，所以 \(P(X<0)=P(X>4)=0.1\)。

中间一块 \(=\) 总面积减两边：\(P(0<X<4)=1-0.1-0.1=0.8\)。

它被 \(x=2\) 平分：\(P(2<X<4)=0.8\div2=0.4\)。

自己试试：\(X\sim N(1,\sigma^2)\)，\(P(X<-1)=0.2\)。\(P(1<X<3)\) 是？

B。\(-1\) 和 \(3\) 关于 \(x=1\) 对称，\(P(X>3)=0.2\)；\(P(-1<X<3)=1-0.4=0.6\)；\(1\) 到 \(3\) 是它的一半，\(0.3\)。选 C 的同学停在了 \(0.6\)，忘了只要右半边。

4. 三个要记的数

不管 \(\mu\)、\(\sigma\) 是多少，离均值「几个标准差」以内的面积都一样：

\(P(\mu-\sigma\le X\le\mu+\sigma)\approx0.6827\)
\(P(\mu-2\sigma\le X\le\mu+2\sigma)\approx0.9545\)
\(P(\mu-3\sigma\le X\le\mu+3\sigma)\approx0.9973\)

开头大米那题的 \(68\%\) 就是第一个数：那批大米大约是 \(N(500,2^2)\)，\(498\sim502\) 正好是 \(\mu\pm\sigma\)。

例 3

袋装大米重量 \(X\sim N(500,2^2)\)（单位：克）。求 \(P(496\le X\le504)\) 和 \(P(X>504)\)；\(1000\) 袋里大约有几袋超过 \(504\) 克？

\(\mu=500\)，\(\sigma=2\)。\(496\sim504\) 是 \(\mu\pm2\sigma\)，所以 \(P(496\le X\le504)\approx0.9545\)。

两边尾巴合起来约 \(1-0.9545=0.0455\)，左右对称各一半：\(P(X>504)\approx0.0455\div2\approx0.0228\)。

\(1000\times0.0228\approx23\)，大约 \(23\) 袋。

自己试试：\(X\sim N(80,25)\)，\(P(X>85)\) 约是？

A。\(\sigma=\sqrt{25}=5\)，\(85=\mu+\sigma\)。\(\mu\pm\sigma\) 外面一共约 \(1-0.6827=0.3173\)，右边一半约 \(0.1587\)。选 B 忘了除以 \(2\)；选 D 是错用了 \(2\sigma\) 那一行。

5. 用之前要注意

  1. 高度不是概率，面积才是。曲线的高度可以比 \(1\) 还大：\(\sigma=0.2\) 时最高点约 \(2\)，概率不可能是 \(2\)。
    单独一个点没有宽度，面积是 \(0\)：\(P(X=\mu)=0\)，哪怕 \(\mu\) 处曲线最高。所以 \(P(a\le X\le b)=P(a<X<b)\)，端点带不带等号都一样。
  2. 先问：正态是题目给的，还是数据支持的假设？题目写了「服从正态分布」才能直接用；拿真实数据，要先看直方图是不是单峰、大致对称，并说明这是一个近似的假设。
    反例：居民收入的直方图常常是左边一个高峰、右边拖着长尾巴，不对称，用正态去算会出错。大致对称的钟形，也不一定就是正态。
  3. \(3\sigma\) 外很少，但不是 \(0\)。\(\mu\pm3\sigma\) 外大约占 \(1-0.9973=0.0027\)，即 \(1000\) 次里平均约 \(2.7\) 次。
    反例：一台正常的机器生产 \(10000\) 个零件，平均约 \(27\) 个会落在 \(\mu\pm3\sigma\) 外。看到一个就断定「机器一定坏了」是错的；该说「这种情况很少见，值得停下来检查」。
  4. 别的区间：靠对称性、题目给的数据、或者查表、用计算器，不用自己积分。
区间概率 \(=\) 曲线下面积；单点概率 \(=0\)。「几乎不可能」\(\ne\)「绝不会发生」。
再深一点（可以先跳过）

曲线的式子：\(f(x)=\dfrac{1}{\sigma\sqrt{2\pi}}\,\mathrm{e}^{-\frac{(x-\mu)^2}{2\sigma^2}}\)。认得它就行，高中不拿它算面积。最高点在 \(x=\mu\)，高 \(\dfrac{1}{\sigma\sqrt{2\pi}}\)：\(\sigma\) 越小越高，\(\sigma=0.2\) 时约 \(1.99\)。

标准正态分布：\(\mu=0\)，\(\sigma=1\) 的 \(N(0,1)\)。很多书后面的「正态分布表」就是按它列的。

为什么误差、身高常像正态：大致说，它受很多个小因素共同影响、每个影响都不大时，常常接近正态。严格的说法要到大学学，这里不当作已知结论用。

质量控制里的「\(3\sigma\)」：工厂常把 \(\mu\pm3\sigma\) 定为控制线，超出就报警、去查原因。报警是「值得查」，不是「已经证明出了问题」。

① 正态曲线：调 \(\mu\)、\(\sigma\)，拖 \(a\)、\(b\) 看面积

拖横轴上的圆点 \(a\)、\(b\)（或选中后按方向键），阴影面积就是 \(P(a<X<b)\)。点下面的按钮一键设成 \(\mu\pm\sigma\)、\(\mu\pm2\sigma\)、\(\mu\pm3\sigma\)，再调 \(\mu\)、\(\sigma\)：面积不变。把 \(\sigma\) 调到最小，看最高点有多高。

② 进阶：样本越多，直方图越贴近曲线；\(3\sigma\) 外仍会出现

下面的大米重量是电脑按 \(N(500,2^2)\) 模拟出来的（所以我们知道它是正态；真实数据要先看图再决定能不能用正态）。拖动样本量，看直方图怎样贴近曲线；红点是落在 \(\mu\pm3\sigma\)（\(494\sim506\) 克）外面的袋子。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(X\sim N(\mu,\sigma^2)\)，且 \(P(X<1)=P(X>5)\)。\(\mu=\)？

B。左边 \(x<1\) 的尾巴和右边 \(x>5\) 的尾巴一样大，说明 \(1\) 和 \(5\) 关于对称轴 \(x=\mu\) 对称，\(\mu=\dfrac{1+5}{2}=3\)。选 D 是把 \(1+5\) 忘了除以 \(2\)。

2. 某次考试 \(1000\) 人参加，题目给出成绩 \(X\sim N(100,10^2)\)。\(120\) 分以上的大约有多少人？

A。\(\sigma=10\)，\(120=\mu+2\sigma\)。\(\mu\pm2\sigma\) 外约 \(1-0.9545=0.0455\)，右边一半约 \(0.0228\)，\(1000\times0.0228\approx23\)。选 B 没除以 \(2\)；选 C 用的是 \(\mu+\sigma\) 那一行；选 D 用的是 \(3\sigma\)。

易错

3. \(X\sim N(0,0.2^2)\)，它的曲线在 \(x=0\) 处最高，高约 \(1.99\)。\(P(X=0)\) 是？

C。概率是面积，不是高度。\(1.99\) 比 \(1\) 还大，本来就不可能是概率。「\(X=0\)」只是一个点，没有宽度，面积为 \(0\)。

B 是 \(P(X\le0)\)，D 是 \(P(-0.2\le X\le0.2)\)，都是一段，不是一个点。

4. 某市居民月收入的直方图：左边一个高峰，右边拖着很长的尾巴。小明说：「收入服从正态分布，所以收入低于平均数的人正好占一半。」

B。用正态之前先问：是题目给的，还是数据支持的假设？这张图左右不对称，正态的「关于均值对称」不成立。少数很高的收入会把平均数往上拉，低于平均数的人往往超过一半。

C 也错：样本再多，也只是把原来的形状看得更清楚，歪的还是歪的。

5. 一条生产线上零件长度 \(X\sim N(\mu,\sigma^2)\)，一直运行正常。今天抽检，有一个零件落在 \(\mu\pm3\sigma\) 外。下面哪个说法对？

B。\(\mu\pm3\sigma\) 外的概率约 \(0.0027\)，很小但不是 \(0\)：正常机器做 \(10000\) 个，平均也有二三十个落在外面。「几乎不可能」不等于「绝不发生」，一次异常是警报，不是证明。在「动手」②里把样本量拉到最大，就能看到红点。

挑战

6. 某种灯泡的寿命 \(X\sim N(1000,50^2)\)（单位：小时，题设）。买一只，寿命在 \(950\sim1100\) 小时之间的概率约是？

A。\(\sigma=50\)：\(950=\mu-\sigma\)，\(1100=\mu+2\sigma\)，左右不一样宽，以 \(\mu=1000\) 为界拆成两块：

左块 \(950\sim1000\) 是 \(\mu\pm\sigma\) 的一半，约 \(0.6827\div2=0.34135\)；右块 \(1000\sim1100\) 是 \(\mu\pm2\sigma\) 的一半，约 \(0.9545\div2=0.47725\)。合计约 \(0.8186\)。

B、C 只用了一边的数；D 是 \(P(X<1050)\approx0.5+0.34135\)，区间看错了。
