第六单元 小数的加法和减法

小数加减法的关键是“小数点对齐”，也就是相同数位对齐。算完还要检查：得数的小数点位置对不对，末尾的 0 要不要去掉。

本单元按旧版教材编排。

一张图看懂本单元

加减小数，先把小数点对齐；顺序和整数一样；整数的运算定律对小数也适用。

本单元容易错的地方

✗ 加减时末位对齐

4.5 + 2.36，把 5 和 6 对齐。

✓ 小数点对齐

4.50 + 2.36 = 6.86。

✗ 有括号还从左往右算

15.6 − (4.8 + 3.5) 先算 15.6 − 4.8。

✓ 先算括号里的

15.6 − 8.3 = 7.3。

一共 10 关，把这一单元的 4 课合在一起考一考。

直接用

1. 计算：3.46 + 2.75。

6.21。小数点对齐，从最低位加起，满十向前一位进 1：3.46 + 2.75 = 6.21。

2. 计算：8.20 − 3.47。

4.73。8.20 − 3.47：百分位 0 不够减，向十分位借 1；十分位 1 不够减，向个位借 1。得 4.73。

3. 用竖式计算 4.5 + 2.36，下面哪种写法是对的？

B。加减小数要把小数点对齐，也就是相同数位对齐。

4. 计算：6.4 + 2.85。

9.25。6.4 看成 6.40，小数点对齐：6.40 + 2.85 = 9.25。

5. 计算：10 − 3.76。

6.24。10 看成 10.00，10.00 − 3.76 = 6.24。

6. 计算：15.6 − (4.8 + 3.5)。

7.3。先算括号：4.8 + 3.5 = 8.3，再算 15.6 − 8.3 = 7.3。

7. 计算：9.5 − 2.7 + 1.4。

8.2。同级运算从左往右：9.5 − 2.7 = 6.8，6.8 + 1.4 = 8.2。

8. 简便计算：1.25 + 3.7 + 2.75。

7.7。1.25 + 2.75 = 4 凑整，4 + 3.7 = 7.7。

9. 要简便计算 1.4 + 3.86 + 0.6，应该先算哪两个数？

A。1.4 + 0.6 = 2 凑整，所以先算它们，再加 3.86，得 5.86。

10. 妈妈带了 20 元，买了 8.5 元的面包和 6.25 元的牛奶，应找回多少元？

5.25。8.5 + 6.25 = 14.75（元），20 − 14.75 = 5.25（元）。

到了后面会怎样

五年级：学习更多的小数运算，小数点的位置要看清。

本单元 4 课回顾

第 1 课 · 位数相同的小数加减法：小数点对齐，从低位算起，满十进 1，不够借 1。

第 2 课 · 位数不同的小数加减法：位数不够的，在末尾补 0，再对齐计算。

第 3 课 · 小数加减混合运算：顺序和整数一样：同级从左往右，有括号先算括号。

第 4 课 · 整数加法运算定律推广到小数：加法交换律、结合律对小数同样成立，用来凑整。
