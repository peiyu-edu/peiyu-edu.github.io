1. 集合的概念3 个核心点

条件核对：核对入选规则、同一元素的不同写法、描述法的对象类型和论域。

范围与起点：从初中整数、实数和简单方程进入；不预设函数图像或形式化集合论。

  • 集合的含义与属于关系
  • 元素互异性与列举顺序
  • 列举法与描述法

2. 集合间的基本关系4 个核心点

条件核对：核对属于与包含、空集、真包含的方向和相等的双向证据。

范围与起点：可从小型有限集合逐项检查；不能只凭元素个数判断包含或相等。

  • 空集与“集合中的集合”
  • 子集与包含关系
  • 真子集
  • 集合相等与双向包含

3. 集合的基本运算4 个核心点

条件核对：核对“至少一个”与“同时”、重复元素、全集内外和补集前提。

范围与起点：Venn图只表达给定关系；不凭面积推人数或概率，不把拓展定律当必背要求。

  • Venn图与文字、符号互译
  • 并集：至少属于一个
  • 交集：同时属于两者
  • 全集与补集

4. 充分条件与必要条件2 个核心点

条件核对：核对同一对象、同一论域，以及正向、反向分别是否成立。

范围与起点：用已学的数与集合判断；一个成功实例不能证明一般蕴含，反方向须另查。

  • 充分条件与必要条件
  • 充要条件与双向论证

5. 全称量词与存在量词4 个核心点

条件核对：核对论域、反例与实例资格；否定时量词、断言和等号是否同时处理。

范围与起点：初学诊断采用非空论域和单个量词；不默认空论域或交错量词训练。

  • 全称量词命题及反例
  • 存在量词命题及实例
  • 全称命题的否定
  • 存在命题的否定

本轮核心范围之外有 3 个拓展点：有限集、无限集与空集的分类；德摩根定律的逐元素推导；二集合有限计数的容斥。需要时可在知识库开启拓展，本轮不要求学生逐一完成。

二、3–5 名学生，每人 15–20 分钟

请教师按学校日常安排征得参与意愿，选择起点不同的学生，逐个观察或让每人独立使用。告诉学生：“我们在检查页面哪里需要改，按你真实的想法答；不会也可以说。”不排名，不需要评分，也不要求录音录像。

  1. 0–2 分钟｜找到正在学的一课。

    从课程目录进入熟悉的课，读一小段说明。请学生自己找到相关知识点和练习入口；观察者先不指路。

  2. 2–5 分钟｜先独立作答，说出理由。

    选择一个已学过、但仍可能拿不准的知识点。提交前先让学生按真实想法选择，并说一句理由；此时不提示正确选项或条件。记录是否已有同题接触，不能把记住旧答案当成首次独立作答。

  3. 5–9 分钟｜从真实错误或疑问回看条件。

    优先使用这名学生刚答错、或真实不确定的一题。让学生读所选答案的反馈，打开“回看适用条件与常见误解”，用自己的话说：“我刚才漏看了哪一个条件？”教师只用中性追问。

    不要要求学生故意答错。如果本次没有真实错误或疑问，可换一个确实不确定的点；仍没有就如实记“错误修正路径未观察到”，保留现有正确作答观察。

  4. 9–13 分钟｜换一道题，再检查理由。

    在题后选择“换一道已审核变式”，先独立解释新题条件再作答。若只是重做同一道题，应记为反馈后重做；若变式以前见过，不能作为新的独立证据。不要在作答前展示新题答案。

  5. 13–17 分钟｜回到课程，再看学习记录。

    用页面内“回到原课时”返回，确认仍在原来的课程与步骤；若从某道课内题进入，也应找回原题。再打开我的学习，请学生分清首次作答、反馈后重做、自评与待复习。让学生说一句下一步要做什么。

  6. 17–20 分钟｜结束前问两句。

    “刚才哪个地方让你停住？”“下次想回到这道题，你会从哪里找？”如前面已用满 20 分钟，可以停止，未观察到的步骤保持空白。

可选样板：补集的一条往返

已学过补集的学生可从《集合的基本运算》第 2 步进入，找“全集与补集”并练习。需要直接定位时可用补集诊断题；它会保留返回这课第 2 步的入口。

观察重点：真实作答 → 指出漏掉的条件 → 未见过的平行变式 → 回到原课。整条链是否出现，以实际观察为准。集合其他核心点也可使用，如空集、子集、并集、交集或量词否定。

函数的可选路径：每次只选已学过的一项

必修基础：从函数概念课进入定义域诊断，重点观察变形后是否仍保留原来的输入限制。

必修三角：已学过图象变换的学生可从正弦型函数课进入平移与伸缩诊断，重点观察是否说清括号内的变换顺序。

选择性必修导数：只给已学过导数的学生使用导数应用课与极值与驻点诊断，观察能否检查两侧变化，而非只看导数为零。

概率统计的可选路径：保留原课时回返

必修概率：从事件独立性课进入独立性诊断，看学生如何区别独立与互斥。

必修统计：从随机抽样课进入分层抽样诊断，看学生是否识别总体权重而非平均两个组均值。

选择性必修计数：已学过排列组合的学生可用排列组合课与无序选择诊断，观察“交换顺序是否算新结果”的解释。

3–5 名学生可按已学范围分散选择上述路径；不要求每名学生试完全部专题，也不为了凑覆盖而提示答案。每条路径都沿用“真实作答 → 回看条件 → 未见变式 → 回原课 → 查看记录”的相同观察步骤。

课程与练习会把学习记录保存在当前浏览器。试用前告知学生这一点；尽量一人一个独立浏览器资料或单独设备，避免多人记录混在一起。不要清除别人已有的学习记录。无需导出学生的完整作答历史。

其余专题：按当前已学范围选一条

每人只选一条：诊断后解释条件，再做变式，次日做对应复习题。路径是试用建议，不要求一次完成所有专题。

  • 平面解析几何：圆锥曲线 / 平面解析几何：直线与圆：从“椭圆定和定义与退化边界”试起，再核对使用条件，按反馈选择变式与复习题。
  • 复数：从“用方程认识虚数单位与复数扩充”试起，再核对使用条件，按反馈选择变式与复习题。
  • 相等关系、不等式与二次关系：从“实数大小与等式的基本性质”试起，再核对使用条件，按反馈选择变式与复习题。
  • 建模、探究与数学表达：从“建模的问题、变量、单位与假设”试起，再核对使用条件，按反馈选择变式与复习题。
  • 平面向量及其应用：从“向量、模与零向量”试起，再核对使用条件，按反馈选择变式与复习题。
  • 数列：从“数列的顺序、项与正整数索引”试起，再核对使用条件，按反馈选择变式与复习题。
  • 立体几何初步：从“棱柱的结构与直棱柱条件”试起，再核对使用条件，按反馈选择变式与复习题。
  • 空间向量与立体几何：从“空间向量、相等向量与零向量”试起，再核对使用条件，按反馈选择变式与复习题。

空间几何先明确已知位置关系、坐标或标号；数列先核项数与初值；建模先核对象、单位和假设。选学与拓展39点仍可从知识库按需查看，另行决定教学安排。

三、次日用 3–5 分钟回看

条件允许时，请同一名学生在原设备打开“我的学习”，先找到昨天需要再看的知识点，不先看答案。让学生说出关键条件，再从该点题后选择“做一道复习题”，确认它是否尚未接触；未见过才记为新题，已接触就明确记录为复习重做。不要为了进入新复习题而把昨天原题的待复习状态当作已完成。

观察能否自己找回复习入口，以及换题后是否仍能说明条件。次日未到场、入口未找到、题已接触等情况如实记“未观察”或具体原因，不补写通过。
