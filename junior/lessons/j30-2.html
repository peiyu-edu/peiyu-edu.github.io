30.2 三角形的内切圆

从圆外一点引两条切线的优美对称，到藏在三角形内部的“心”！掌握切线长定理（切线长相等、平分夹角），吃透三角形内切圆与内心（角平分线交点，到三边距离相等），掌握面积公式 \(S = \frac{1}{2}pr\) 与直角三角形内切圆半径速算公式 \(r = \frac{a+b-c}{2}\)。

  1. 从测量圆形工件的外径切入：过圆外一点引两条切线，切线段有什么特殊对称性质？
  2. 明确切线长定义与切线长定理：\(PA = PB\)，\(PO\) 平分 \(\angle APB\)；
  3. 掌握三角形内切圆与内心：三条内角平分线的交点，内心到三边的垂直距离等于内切圆半径 \(r\)；
  4. 对比外心与内心：外心（三边垂直平分线交点，到顶点等距） vs 内心（三条角平分线交点，到边等距）；
  5. 掌握通用面积公式 \(S = \frac{1}{2}pr\) 与直角三角形内切圆半径公式 \(r = \frac{a+b-c}{2}\)；
  6. 动手交互实验：切线长对称测算台、进阶三角形内切圆动态联动台（含重置按钮）；
  7. 中考真题演练，吃透切线长计算与内切圆几何综合。

工人师傅用 V 形卡尺检测圆形零件，卡尺两边 \(PA, PB\) 与圆盘分别相切于点 \(A, B\)。若测得 \(PA = 8\text{ cm}\)，那么切线段 \(PB\) 的长是（ ）

B。连接 \(OA, OB, OP\)。因为 \(PA, PB\) 是切线，所以 \(OA \perp PA, OB \perp PB\)。在 \(\text{Rt}\triangle OAP\) 和 \(\text{Rt}\triangle OBP\) 中，斜边 \(OP = OP\)，直角边 \(OA = OB = r\)，由 HL 判定两直角三角形全等！

全等对应边相等：\(PA = PB = 8\text{ cm}\)；对应角相等：\(\angle APO = \angle BPO\)。无论夹角如何变动，过圆外一点引圆的两条切线段长永远严格相等，这就是著名的切线长定理。

上一节我们研究了一条直线与圆的切点垂直性质。 如果从圆外一点出发向圆引切线，恰好能引两条；如果三角形的三条边都与一个圆相切，这个圆就被紧紧包络在三角形内部。 这就是内切圆与三角形的“内心”——初中平面几何最美妙的内蕴几何中心之一。

1. 先认识几个词：切线长、内切圆与内心

内心

三角形内角平分线交点，到三边距离相等。

外心

三边垂直平分线交点，到三个顶点距离相等。

抓住关系： \(\color{#2F7A56}{\underbrace{S}_{\text{面积}}}=\frac12\color{#966524}{\underbrace{p}_{\text{周长}}}\,r\)

先检查条件，再使用关系；彩色标注帮助区分量。

在探索具体定理与公式之前，先辨析三组核心概念：

  • 切线长（tangent length）：经过圆外一点引圆的切线，这点和切点之间的线段的长叫作这点到圆的切线长。
  • 三角形的内切圆（inscribed circle）：与三角形三条边都相切的圆叫作三角形的内切圆。
  • 三角形的内心（incenter）：三角形内切圆的圆心叫作三角形的内心，它是三角形三条内角平分线的交点。

直觉微图解 ①切线长定理：HL 全等与轴对称三合一

从圆外一点引圆的两条切线，它们的切线长相等（\(PA = PB\)），这一点和圆心的连线平分两条切线的夹角（\(\angle APO = \angle BPO\)），且 \(OP\) 垂直平分切点弦 \(AB\)。

直觉微图解 ②三角形的内心与切线长拆边模型

三角形的内心 \(I\) 是三条内角平分线的交点，恒在三角形内部，到三边的距离相等（\(ID = IE = IF = r\)）；从三顶点引出的三组切线长分别相等（\(x, y, z\) 模型）。

直觉微图解 ③内切圆半径的两大黄金公式

任意三角形等面积三分得 \(S = \frac{1}{2}(a+b+c)r = \frac{1}{2}pr\)；直角三角形（\(\angle C = 90^\circ\)）在直角顶点处围成正方形得 \(r = \frac{a+b-c}{2}\)。

2. 核心定理与对比推演

掌握切线长定理与内切圆，解题时需熟练辨析几何关系：

自己试试 1：已知 \(PA, PB\) 分别与 \(\odot O\) 相切于 \(A, B\)。若 \(PA = 7\)，则 \(PB\) 的长为（ ）

C。直接由切线长定理：从圆外一点引圆的两条切线，切线长相等，故 \(PB = PA = 7\)。

自己试试 2：在 \(\text{Rt}\triangle ABC\) 中，两直角边长分别为 3 和 4，斜边长为 5，则其内切圆半径为（ ）

A。使用直角三角形专享速算公式：\(r = \frac{a+b-c}{2} = \frac{3+4-5}{2} = \frac{2}{2} = 1\)。

自己试试 3：若 \(\triangle ABC\) 的周长为 24，面积为 24，则其内切圆的半径 \(r\) 是（ ）

B。应用面积公式：\(S = \frac{1}{2}pr\)，得 \(24 = 12r\)，所以 \(r = 2\)。边长 6、8、10 的直角三角形满足题设。

典例 1（波利亚四步法）：切线长三段设元法求切线长

【例 1】\(\triangle ABC\) 的内切圆 \(\odot O\) 与 \(BC, CA, AB\) 分别相切于点 \(D, E, F\)，且 \(AB = 9\)，\(BC = 14\)，\(CA = 13\)。求 \(AF, BD, CE\) 的长。

  1. ① 读懂题意：已知三边 \(c = AB = 9, a = BC = 14, b = CA = 13\)，内切圆切三边于 \(D, E, F\)，求从三个顶点引出的切线长。
  2. ② 想办法：由切线长定理，设 \(AF = AE = x\)，\(BD = BF = y\)，\(CE = CD = z\)，每条边由两段切线长拼成，列三元一次方程组先求半周长 \(x+y+z\)。
  3. ③ 执行 + 执行中检查：由 \(\begin{cases} x + y = 9 \\ y + z = 14 \\ z + x = 13 \end{cases}\)，三式相加除以 2 得 \(x + y + z = \frac{9 + 14 + 13}{2} = 18\)。分别相减得 \(AF = x = 18 - 14 = 4\)，\(BD = y = 18 - 13 = 5\)，\(CE = z = 18 - 9 = 9\)（检查：\(4+5=9, 5+9=14, 9+4=13\)，完全吻合！）。
  4. ④ 回头看：通用规律——顶点 \(A\) 处的切线长等于半周长减去对边 \(a\)，即 \(AF = AE = \frac{b + c - a}{2}\)。当 \(\angle C = 90^\circ\) 时，顶点 \(C\) 处的切线长恰好等于内切圆半径 \(r\)，故 \(r = \frac{a + b - c}{2}\)！
典例 2（波利亚四步法）：直角三角形外接圆半径 \(R\)、内切圆半径 \(r\) 与内心张角

【例 2】在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ\)，\(AC = 6\)，\(BC = 8\)。求：（1）\(\triangle ABC\) 的外接圆半径 \(R\) 与内切圆半径 \(r\)；（2）若点 \(I\) 为内心，求 \(\angle AIB\) 的度数。

  1. ① 读懂题意：已知直角三角形两直角边 \(b = 6, a = 8\)，求外接圆半径 \(R\)、内切圆半径 \(r\) 及内心对斜边的张角 \(\angle AIB\)。
  2. ② 想办法：先由勾股定理求斜边 \(c = AB = 10\)；用 \(R = \frac{c}{2}\) 求外接圆半径，用 \(r = \frac{a+b-c}{2}\) 求内切圆半径；用角平分线性质求 \(\angle AIB\)。
  3. ③ 执行 + 执行中检查：（1）斜边 \(AB = \sqrt{6^2+8^2} = 10\)，故 \(R = \frac{10}{2} = 5\)，\(r = \frac{6+8-10}{2} = 2\)（检查：等面积法 \(r = \frac{2S}{a+b+c} = \frac{48}{24} = 2\)，完全一致）。（2）因 \(IA, IB\) 平分 \(\angle CAB, \angle CBA\)，故 \(\angle IAB + \angle IBA = \frac{1}{2}(180^\circ - 90^\circ) = 45^\circ\)，从而 \(\angle AIB = 180^\circ - 45^\circ = 135^\circ\)。
  4. ④ 回头看：任意三角形内心张角公式 \(\angle BIC = 90^\circ + \frac{1}{2}\angle A\)；直角三角形斜边对的内心张角恒为 \(90^\circ + 45^\circ = 135^\circ\)。
深度对决：三角形的“外心”与“内心”九大维度全景对比

比较维度外心（外接圆圆心）内心（内切圆圆心）
交点来源三边垂直平分线的交点三条内角平分线的交点
几何位置锐角在内；直角在斜边中点；钝角在外部永远恒在三角形内部
等距对象到三角形三个顶点的距离相等到三角形三条边的距离相等
半径对应\(OA = OB = OC = R\)垂线段 \(OD = OE = OF = r\)

公式探源：直角三角形内切圆半径 \(r = \frac{a+b-c}{2}\) 是怎么来的？

在 \(\text{Rt}\triangle ABC\)（\(\angle C = 90^\circ\)）中，设内切圆切三边于 \(D, E, F\)：
由切线性质，四边形 \(CDIE\) 有三个角为直角，且邻边 \(ID = IE = r\)，故四边形 \(CDIE\) 是正方形！因此切线长 \(CD = CE = r\)。
由切线长定理：\(AD = AF = b - r\)，\(BE = BF = a - r\)。
斜边 \(c = AF + BF = (b - r) + (a - r) = a + b - 2r\)。
移项整理立即得出：\(2r = a + b - c \implies r = \frac{a + b - c}{2}\)！优美而简洁。

中考高频角结论：内心与顶角关系公式 \(\angle BIC = 90^\circ + \frac{1}{2}\angle A\)

点 \(I\) 是 \(\triangle ABC\) 的内心，\(BI, CI\) 分别平分 \(\angle B, \angle C\)。
在 \(\triangle BIC\) 中，\(\angle BIC = 180^\circ - (\frac{1}{2}\angle B + \frac{1}{2}\angle C)\)。
又因为 \(\angle B + \angle C = 180^\circ - \angle A\)，所以： \[\angle BIC = 180^\circ - \frac{1}{2}(180^\circ - \angle A) = 90^\circ + \frac{1}{2}\angle A\] 例如当 \(\angle A = 60^\circ\) 时，\(\angle BIC = 90^\circ + 30^\circ = 120^\circ\)，秒杀角度计算选择题！

练习 1：从圆外一点 \(P\) 向 \(\odot O\) 引两条切线，切点分别为 \(A, B\)。若 \(\angle APB = 60^\circ, PA = 6\)，则弦 \(AB\) 的长为（ ）

B。由切线长定理知 \(PA = PB\)，所以 \(\triangle PAB\) 是等腰三角形。因为顶角 \(\angle APB = 60^\circ\)，有一个角是 \(60^\circ\) 的等腰三角形是等边三角形！所以弦 \(AB = PA = 6\)。

练习 2：在 \(\text{Rt}\triangle ABC\) 中，\(\angle C = 90^\circ, AC = 6, BC = 8\)，则其内切圆的半径 \(r\) 是（ ）

A。斜边 \(c = \sqrt{6^2 + 8^2} = 10\)。利用直角三角形内切圆半径公式：\(r = \frac{a+b-c}{2} = \frac{6+8-10}{2} = 2\)。

练习 3：已知点 \(I\) 是 \(\triangle ABC\) 的内心，\(\angle A = 80^\circ\)，则 \(\angle BIC\) 的度数是（ ）

D。直接套用内心角公式：\(\angle BIC = 90^\circ + \frac{1}{2}\angle A = 90^\circ + 40^\circ = 130^\circ\)。

练习 4：已知一个等边三角形的边长为 6，则其内切圆的半径是（ ）

C。等边三角形高为 \(6 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}\)。等边三角形的内心与外心重合，内心将高分为 \(1:2\) 两部分，内切圆半径为高的 \(\frac{1}{3}\)，即 \(r = \frac{1}{3} \times 3\sqrt{3} = \sqrt{3}\)；外接圆半径为 \(R = 2\sqrt{3}\)。

练习 5：已知 \(PA, PB\) 分别切 \(\odot O\) 于点 \(A, B\)，\(PA = 10\text{ cm}\)。在劣弧 \(\widehat{AB}\) 上任取一点 \(C\)（不含端点 \(A, B\)），过点 \(C\) 作 \(\odot O\) 的切线分别交 \(PA, PB\) 于点 \(D, E\)，则 \(\triangle PDE\) 的周长为（ ）

提示

对第三条切线 \(DE\) 应用切线长定理：\(DC = DA\)，\(EC = EB\)，把 \(DE\) 拆成两段折回到 \(PA, PB\) 上！

C。由切线长定理得 \(PA = PB = 10\text{ cm}\)，且 \(DC = DA\)，\(EC = EB\)。因此 \(\triangle PDE\) 的周长 \(= PD + DE + PE = PD + (DC + CE) + PE = (PD + DA) + (PE + EB) = PA + PB = 20\text{ cm}\)。

易错总结：直角三角形内切圆半径与外接圆半径的对应关系

直角三角形斜边为 \(c\)，直角边为 \(a, b\)：
• 外接圆半径 \(R = \frac{c}{2}\)（斜边的一半）；
• 内切圆半径 \(r = \frac{a+b-c}{2}\)；
两式相加得 \(R + r = \frac{a+b}{2}\)，即两直角边的和等于外接圆直径与内切圆直径的和！这个结论在中考压轴填空中经常可以直接秒杀答题。

巩固练习 1：\(PA, PB\) 分别与 \(\odot O\) 相切于 \(A, B\) 两点，连接 \(AB\)．若 \(\angle P = 50^\circ\)，则 \(\angle PAB\) 的度数为（　）

B。因为 \(PA, PB\) 分别与 \(\odot O\) 相切于 \(A, B\) 两点，根据切线长定理得 \(PA = PB\)，所以 \(\triangle PAB\) 是等腰三角形．已知顶角 \(\angle P = 50^\circ\)，故底角 \(\angle PAB = \frac{180^\circ - \angle P}{2}\)，即 \(\angle PAB = \frac{180^\circ - 50^\circ}{2} = 65^\circ\)，故选 B．

巩固练习 2：点 \(I\) 是 \(\triangle ABC\) 的内心，若 \(\angle A = 70^\circ\)，则 \(\angle BIC\) 的度数是（　）

C。在 \(\triangle ABC\) 中，\(\angle A = 70^\circ\)，故 \(\angle ABC + \angle ACB = 180^\circ - 70^\circ = 110^\circ\)．因为点 \(I\) 是 \(\triangle ABC\) 的内心，所以 \(IB, IC\) 分别平分 \(\angle ABC\) 和 \(\angle ACB\)，得 \(\angle IBC + \angle ICB\) 等于 \(\frac{1}{2}(\angle ABC + \angle ACB)\)，得 \(55^\circ\)．在 \(\triangle IBC\) 中，\(\angle BIC = 180^\circ - 55^\circ = 125^\circ\)（即内心张角公式 \(90^\circ + \frac{1}{2}\angle A = 125^\circ\)），故选 C．

巩固练习 3：已知 \(\triangle ABC\) 的周长为 \(16\)，面积为 \(12\)，则其内切圆半径为______．

查看答案与解析，自行核对

答案：\(1.5\)

设内切圆半径为 r，面积 S = 周长 × r ÷ 2，故 12 = 16r ÷ 2，得 r = 1.5。
