两个容易错的地方

✗ 用等号连接原数与倒数，或单独说某数是倒数 写成「 = 」，或说「 是倒数」。
✓ 倒数是相互依存关系，原数与倒数不相等 写「 的倒数是 」，或「 和 互为倒数」。
✗ 以为 0 的倒数是 0 误以为所有数都有倒数，说「0 的倒数还是 0」。
✓ 0 乘任何数都得 0，所以 0 没有倒数 只有 1 的倒数是它本身（1），0 没有倒数。
为什么把分子和分母交换位置，得到的两个数相乘一定等于 1？

因为把分子和分母交换位置后，新分数的分子正是原分数的分母，新分数的分母正是原分数的分子；两个分数相乘时，分子乘积与分母乘积完全相等，约分后一定等于 1。
