26.4 实际问题与二次函数

从生活中的最优化决策到抛物线数学模型！怎么围栅栏面积最大？怎么定价利润最高？拱门隧道怎样保障车辆通行？掌握二次函数实际建模的完整闭环，看透自变量取值范围对极值的绝对决定权。

  2. 确立建模标准五步法：设元、列式、定范围、求极值、答题检验。
  3. 几何图形面积最值：特别盯准「墙长有限」对自变量形成的硬性边界。
  4. 商业销售最大利润模型：单价与销量的反向变动如何孕育最大商机。
  5. 抛物线轨迹与建筑模型：选对直角坐标系将问题化为最简解析式。
  6. 动手实验台与巩固练习，彻底扫除端点与顶点混淆的失分隐患。

在一次跳水比赛中，运动员起跳后的运动路线是一条抛物线。运动员的重心离水面的高度 \(h\text{ (m)}\) 与起跳后的时间 \(t\text{ (s)}\) 满足关系式：\(h = -5t^2 + 10t + 10\)。

把二次函数解析式配方：\(h = -5(t - 1)^2 + 15\)。运动员在起跳后多长时间达到最高点？最高点离水面的高度是多少米？

B。二次项系数 \(a = -5 \lt 0\)，抛物线开口向下，顶点为最高点。由顶点式 \(h = -5(t-1)^2 + 15\) 知：当 \(t = 1\text{ s}\) 时取得最大值 \(15\text{ m}\)。

在现实生活中，抛体运动、面积最大、利润最高、用料最省等大量优化极值问题，都可以抽象为二次函数模型来求解！

1. 先认识几个词：建模、约束条件与可行域

二次函数解决实际问题的完整五步标准闭环：

  • 建立函数关系：通过几何公式（长乘宽）、商业规律（每件利润乘销售量）或物理公式列出二次函数。
  • 约束条件与可行域（自变量范围）：绝对不能漏！现实中的长度必须大于 0、靠墙不能长于墙、销量非负，这些条件划定了自变量的“有效区间”。
  • 极值判断准则：
    • 若顶点横坐标落在可行域内，函数在顶点处取得最大（或最小）值；
    • 若顶点横坐标超出了可行域，函数在有效区间上单调递增或递减，最值必须在区间的端点处取得！

直觉微图解 ①墙长是道生死线：顶点在域内 vs 顶点超限取端点

模型一几何面积最大模型

设垂直边长为 \(x\)，由周长表示邻边，\(S = x(L - 2x) = -2x^2 + Lx\)。牢记二次项系数必然为负（开口向下），当两邻边比例得当时面积达到极大值。

模型二商业经济最大利润模型

总利润 \(W = (\text{每件利润}) \times (\text{销售量})\)。涨价时单利增加但销量减少，降价时薄利多销，相乘得到的二次函数在对称轴处取得黄金平衡点。

4. 自己试试与典例示范

【自测 1】用长为 \(24\text{ m}\) 的细铁丝围成一个矩形，当矩形的长和宽分别为多少时，围成的矩形面积最大？最大面积是多少？（ ）

B。设宽为 \(x\text{ m}\)，则长为 \((12-x)\text{ m}\)。面积 \(S = x(12-x) = -(x-6)^2 + 36\)。当长和宽相等（\(x = 6\text{ m}\)）围成正方形时，面积最大为 36 平方米。

【自测 2】某商品的日销售利润 \(W\)（元）与销售单价 \(x\)（元）的函数关系为 \(W = -10(x-20)^2 + 800\)。若受物价管控，规定销售单价最高不得超过 18 元（即 \(x \le 18\)），则最大日销售利润为（ ）

C。抛物线对称轴为 \(x = 20\)，开口向下。但在有效范围 \(x \le 18\) 内，单价无法达到 20 元！此时利润随 \(x\) 的增大而增大，因此最大值必须在端点 \(x = 18\) 处取得：\(W_{\max} = -10(18-20)^2 + 800 = -10(4) + 800 = 760\text{ 元}\)。选 A 是彻底忽视定义域的典型翻车！

【自测 3】一座抛物线型拱桥的跨度为 \(20\text{ m}\)，拱高为 \(4\text{ m}\)。以拱顶为原点，以对称轴为 \(y\) 轴建立直角坐标系，抛物线的函数解析式为（ ）

A。顶点为原点 \((0, 0)\)，设解析式为 \(y = ax^2\)。跨度为 20m，半跨为 10m，水面两侧点坐标为 \((10, -4)\) 和 \((-10, -4)\)。代入得 \(-4 = a(10)^2 \implies a = -\dfrac{4}{100} = -\dfrac{1}{25}\)。解析式为 \(y = -\dfrac{1}{25}x^2\)。

【例题 1·波利亚示范】靠墙围矩形试验田最值（顶点落在域内）

题目：用总长为 \(80\text{ m}\) 的栅栏靠墙围成矩形，墙长为 \(45\text{ m}\)。求围成矩形的最大面积。

第一步（设元列式）：设与墙垂直的边长为 \(x\text{ m}\)，则平行于墙的边长为 \((80 - 2x)\text{ m}\)。
面积 \(S = x(80 - 2x) = -2x^2 + 80x = -2(x - 20)^2 + 800\)。
第二步（定自变量范围）：两边均为正数且靠墙边不超过墙长：
\(\begin{cases} x \gt 0 \\ 80 - 2x \gt 0 \\ 80 - 2x \le 45 \end{cases} \implies \begin{cases} x \gt 0 \\ x \lt 40 \\ 2x \ge 35 \implies x \ge 17.5 \end{cases} \implies 17.5 \le x \lt 40\)。
第三步（求最值与检验）：顶点横坐标 \(x = 20\) 落在 \([17.5, 40)\) 内，因此当 \(x = 20\) 时取得最大值 \(800\text{ m}^2\)。

【例题 2·波利亚示范】靠墙围矩形（墙长受限，顶点超限取端点）

题目：若上题中墙的最大可用长度改为只有 \(30\text{ m}\)，此时最大面积是多少？

深刻对比剖析：由墙长约束 \(80 - 2x \le 30 \implies 2x \ge 50 \implies x \ge 25\)！
自变量有效范围变为 \(25 \le x \lt 40\)。
顶点横坐标 \(x = 20\) 根本不在这个区间内！
抛物线对称轴为 \(x = 20\)，开口向下，在 \(x \ge 25\) 时，函数值随 \(x\) 的增大而减小。
因此，当 \(x\) 尽可能小即 \(x = 25\text{ m}\) 时取得最大面积：
\(S_{\max} = 25 \times (80 - 2 \times 25) = 25 \times 30 = 750\text{ m}^2\)。
结论启示：不可盲目代公式，必须看顶点是否在有效区间内！

【例题 3·波利亚示范】商场销售定价与最大利润决策模型

题目：进价 10 元/件，按 15 元出售日销 100 件。单价每涨 1 元日销减少 10 件。求最大日销售利润及最佳售价。

规范解答：设每件涨价 \(x\) 元（售价为 \(15 + x\) 元），则每件利润为 \((15 + x - 10) = (5 + x)\) 元。
日销售量为 \((100 - 10x)\) 件（要求 \(100 - 10x \ge 0 \implies x \le 10\) 且 \(x \ge -5\)）。
日销售利润 \(W = (5 + x)(100 - 10x) = -10x^2 + 50x + 500\)。
配方得：\(W = -10(x^2 - 5x) + 500 = -10(x - 2.5)^2 + 562.5\)。
当 \(x = 2.5\) 时，最佳售价为 \(15 + 2.5 = 17.5\) 元，最大日销售利润为 \(562.5\) 元。

【例题 4·波利亚示范】隧道截面抛物线与大型车辆限高模型

题目：单孔抛物线形隧道，底部宽 \(10\text{ m}\)，拱顶离地 \(5\text{ m}\)。一辆货车宽 \(4\text{ m}\)，居中通过，车顶与隧道顶之间要留至少 \(0.3\text{ m}\) 的安全距离，求这辆货车允许的最大车高。

坐标法四步解法：
① 建立坐标系：以地面中心为原点，对称轴为 \(y\) 轴，顶点为 \((0, 5)\)，地面右端点为 \((5, 0)\)。
② 设解析式为 \(y = ax^2 + 5\)。代入 \((5, 0)\) 得 \(25a + 5 = 0 \implies a = -\dfrac{1}{5}\)。
③ 车居中、宽 \(4\text{ m}\)，车身边缘在 \(x = \pm 2\)，隧道在这里最矮：\(y = -\dfrac{1}{5}\times 4 + 5 = 4.2\text{ m}\)。
④ 扣减安全距离：允许最大车高为 \(4.2 - 0.3 = 3.9\text{ m}\)。
回头看：车宽 \(4\text{ m}\) 的一半才是 \(x=2\)，别把整个车宽 \(4\) 当成横坐标。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）不看自变量范围，直接代顶点公式
❌ 典型错解：墙长只有 \(30\text{ m}\)，仍写「\(x=20\) 时 \(S\) 最大，为 \(800\)」。
✅ 看图秒懂：\(x=20\) 时靠墙边是 \(40>30\)，墙不够长，这个点根本取不到。可取的是 \(x\ge25\)，这一段 \(S\) 在下降，最大值在端点 \(x=25\)：\(S=750\)。
翻车现场 ②把售价当成每件利润
❌ 典型错解：进价 \(4\) 元，售价 \(6\) 元时日销 \(40\) 件，每涨 \(1\) 元少卖 \(5\) 件，写成 \(W=(6+x)(40-5x)\)。
✅ 一眼看清：每件利润是「售价 − 进价」\(=(6+x)-4=2+x\)，所以 \(W=(2+x)(40-5x)\)。验算：\(x=0\) 时每天赚 \(2\times40=80\) 元，错解会算出 \(240\) 元。
翻车现场 ③列出面积函数就收笔，漏写自变量范围
❌ 典型错解：「\(S=x(80-2x)\)」后直接去求最大值，没有写范围。
✅ 一眼看清：先写「\(x>0\)，\(80-2x>0\)，（墙长 \(45\) 时）\(80-2x\le45\)」，得 \(17.5\le x \lt 40\)，再去判断顶点 \(x=20\) 在不在范围里。
再深一点（可以先跳过）：为什么一次函数的最值总在端点，二次函数不一定？

一次函数在整个范围里只上升或只下降，所以最大、最小值必在两端。二次函数有一个「拐点」（顶点）：拐点在范围里，最值就在拐点；拐点跑到范围外，范围内就只剩上升或下降的一段，最值才回到端点。

【巩固 1】用总长为 \(36\text{ m}\) 的篱笆靠一面足够长的墙围成一个矩形鸡舍（墙作为一边），则鸡舍的最大面积是（ ）

B。设与墙垂直的边为 \(x\text{ m}\)，则靠墙平行边为 \((36 - 2x)\text{ m}\)。面积 \(S = x(36-2x) = -2x^2 + 36x = -2(x-9)^2 + 162\)。当 \(x = 9\text{ m}\) 时，平行边为 18m，面积最大为 \(162\text{ m}^2\)。选 A 是误当作不靠墙的四边周长 36 计算。

【巩固 2】某文具店进价每件 4 元，售价为 6 元时每天可卖 40 件。若每涨价 1 元每天少卖 5 件，设每件涨价 \(x\) 元，每天销售利润 \(W\)（元）关于 \(x\) 的函数为（ ）

A。原单件利润为 \(6 - 4 = 2\) 元，涨价 \(x\) 元后单件利润为 \((2+x)\) 元；日销量减少为 \((40 - 5x)\) 件。总利润为两者乘积 \(W = (2+x)(40-5x)\)。

【巩固 3·易错题】二次函数 \(y = -(x-3)^2 + 10\)，当 \(0 \le x \le 2\) 时，函数 \(y\) 的最大值和最小值分别是（ ）

提示

对称轴 x = 3 不在区间 [0, 2] 内，函数在 [0, 2] 上单调递增，最值在端点取得。

C。对称轴为 \(x = 3\)，开口向下。当 \(x \le 3\) 时，\(y\) 随 \(x\) 增大而增大。在区间 \([0, 2]\) 内：当 \(x = 2\) 时取得最大值 \(y = -(2-3)^2 + 10 = 9\)；当 \(x = 0\) 时取得最小值 \(y = -(0-3)^2 + 10 = 1\)。选 A 又是盲目看顶点的错误！

【巩固 4·挑战题】抛物线型拱门的地面宽度为 4 米，最高点为 4 米。若一辆宽 2 米的厢式货车要通过该拱门，货车的最高高度不能超过（ ）

提示

以地面中心为原点，解析式为 y = -x² + 4，货车宽 2 米对应两侧 x = ±1。

B。以地面中心为原点，顶点为 \((0, 4)\)，地面两端点为 \((-2, 0)\) 和 \((2, 0)\)。设 \(y = ax^2 + 4\)，代入 \((2, 0)\) 得 \(4a + 4 = 0 \implies a = -1\)，即 \(y = -x^2 + 4\)。车宽 2 米居中通过时，车边缘横坐标为 \(x = 1\)，此时拱高为 \(y = -(1)^2 + 4 = 3\text{ 米}\)。故车高不能超过 3 米。

【易错挑战】动轴定区间与实际最值决策的深坑

题目：某农场生产某种绿色蔬菜，每千克成本 3 元。若售价为 \(x\) 元（\(4 \le x \le 8\)），每天销量为 \((12 - x)\) 千克。若受政府调控，销售单价最高限定为 7 元，求每天的最大利润。

正解剖析：利润 \(W = (x - 3)(12 - x) = -x^2 + 15x - 36 = -(x - 7.5)^2 + 20.25\)。
对称轴为 \(x = 7.5\) 元。但受到政策管控限制：\(x \le 7\)，即自变量可行域变为 \(4 \le x \le 7\)！
在 \(x \le 7.5\) 区间内，抛物线单调递增，故最值只能在限定端点 \(x = 7\) 处取得：
\(W_{\max} = (7 - 3)(12 - 7) = 4 \times 5 = 20\) 元。
若无视限定代入 7.5 会得出 20.25 元而扣分！

巩固练习 1：某学校劳动基地用总长为 \(60\text{ m}\) 的栅栏围成一块一边靠墙的矩形试验田，墙的最大可用长度为 \(24\text{ m}\)（栅栏无重叠、无损耗）。设与墙垂直的一边长为 \(x\text{ m}\)，与墙平行的一边长为 \(y\text{ m}\)，试验田面积为 \(S\text{ m}^2\)。 (1) 求 \(y\) 关于 \(x\) 的函数解析式，并写出自变量 \(x\) 的取值范围； (2) 当 \(x\) 为何值时，面积 \(S\) 最大？最大面积是多少？

查看答案与解析，自行核对

答案：(1) \(y=60-2x\)，\(18\le x<30\)；(2) 当 \(x=18\) 时，\(S\) 最大，为 \(432\text{ m}^2\)

(1) 两条垂直边加一条平行边共 \(60\)：\(2x+y=60\)，\(y=60-2x\)。需 \(y>0\) 且 \(y\le24\)：\(60-2x\le24\Rightarrow x\ge18\)，\(60-2x>0\Rightarrow x<30\)，故 \(18\le x<30\)。(2) \(S=x(60-2x)=-2x^2+60x=-2(x-15)^2+450\)，对称轴 \(x=15\) 不在 \([18,30)\) 内；在 \(x\ge18\) 的范围，\(S\) 随 \(x\) 增大而减小，所以 \(x=18\) 时最大，\(S=18\times24=432\)。

巩固练习 2：某超市购进一批进价为 \(8\) 元/盒的点心。试销发现：日销售量 \(y\)（盒）与销售单价 \(x\)（元/盒，\(x\ge8\)）满足一次函数关系，且 \(x=10\) 时 \(y=140\)；\(x=12\) 时 \(y=100\)。 (1) 求 \(y\) 关于 \(x\) 的函数解析式； (2) 设日销售利润为 \(W\) 元，求 \(W\) 关于 \(x\) 的函数解析式； (3) 销售单价定为多少元时，日销售利润最大？最大利润是多少？

查看答案与解析，自行核对

答案：(1) \(y=-20x+340\)（\(8\le x\le17\)）；(2) \(W=-20x^2+500x-2720\)；(3) 单价定为 \(12.5\) 元时，最大日销售利润为 \(405\) 元

(1) 设 \(y=kx+b\)，\(10k+b=140\)，\(12k+b=100\)，解得 \(k=-20,b=340\)，\(y=-20x+340\)；\(y\ge0\) 得 \(x\le17\)，故 \(8\le x\le17\)。(2) \(W=(x-8)(-20x+340)=-20x^2+500x-2720\)。(3) \(W=-20(x-12.5)^2+405\)，\(12.5\) 在 \([8,17]\) 内，所以 \(x=12.5\) 时 \(W\) 最大，为 \(405\)。

巩固练习 3：某公路隧道截面轮廓可近似看作一段抛物线，隧道底部宽 \(16\text{ m}\)，最高点离地面 \(8\text{ m}\)。以地面所在直线为 \(x\) 轴，抛物线的对称轴为 \(y\) 轴建立平面直角坐标系。 (1) 求该抛物线的函数解析式； (2) 一辆货车宽 \(4\text{ m}\)，沿隧道中线居中通过，要求车顶与隧道顶之间至少留 \(0.5\text{ m}\) 的空隙，求这辆货车允许的最大车高。

查看答案与解析，自行核对

答案：(1) \(y=-\dfrac18x^2+8\)；(2) \(7\text{ m}\)

(1) 顶点 \((0,8)\)，设 \(y=ax^2+8\)；过 \((8,0)\)：\(64a+8=0\)，\(a=-\dfrac18\)，\(y=-\dfrac18x^2+8\)。(2) 货车居中，车身边缘在 \(x=\pm2\)，隧道此处高度 \(y=-\dfrac18\times4+8=7.5\)，再留 \(0.5\) m 空隙，车高最大 \(7.5-0.5=7\) m。

巩固练习 4：从地面竖直向上抛出一小球，小球离地面的高度 \(h\)（单位：m）与运动时间 \(t\)（单位：s）的关系式为 \(h=-5t^2+20t\)（\(t\ge0\)）。下列结论中正确的是（ ）

B。\(h=-5(t-2)^2+20\)：\(t=2\) s 时最高，最大高度 \(20\) m，A 错、B 对；令 \(h=0\)：\(-5t(t-4)=0\)，\(t=4\) s 落地，C 错；\(t=3\) 时 \(h=-45+60=15\) m，D 错。选 B。
