用万、亿作单位改写

整万、整亿的数末尾有好多个 0，怎样改写得既简短好读、又一点不改变它的大小？

一小滴血液里大约含有红细胞 26000000 个。末尾有这么多 0，写起来很容易数错。如果把它改写成用「万」作单位的数，应该写成多少？

对！先分级 2600|0000，把个级的 4 个 0 去掉，换成一个「万」字，就是 26000000 = 2600 万。改写前后数的大小完全相等，用「=」连接。

1. 整万、整亿分级折叠改写器

点下面的整万数或整亿数，再点“改写成万 / 亿（折起末尾的 0）”，看清楚去掉的是哪几个 0、哪些 0 在万级或亿级里面绝对不能去掉。

把整万、整亿的数改写成用“万”或“亿”作单位的数：
1. 先分级（从右边起每 4 位一级）；
2. 改写成用“万”作单位：去掉个级的 4 个 0，加上“万”字；
3. 改写成用“亿”作单位：去掉万级和个级的 8 个 0，加上“亿”字；
4. 改写只改变了计数单位，数的大小不变，一律用“=”连接。

自己试试

把整万数改写成用「万」作单位的数：48000000 = （ ）万。

分级 4800|0000，去掉个级的 4 个 0，万级里的两个 0 要保留，得 4800 万。

自己试试

把整亿数改写成用「亿」作单位的数：605000000000 = （ ）亿。

分级 6050|0000|0000，去掉后两级的 8 个 0，亿级是 6050 亿。

整万数改写成“万”作单位：先分级，去掉个级的 4 个 0 加“万”字；整亿数改写成“亿”作单位：去掉万级和个级的 8 个 0 加“亿”字。改写后大小不变，用“=”连接。

两个容易错的地方

✗ 不分级，看到末尾有 0 就统统砍掉 把 72000000 改写成“72 万”；把 3000000000 改写成“3 亿”。
✓ 严格按级去 0：换“万”只去 4 个 0，换“亿”只去 8 个 0 7200|0000 = 7200 万；30|0000|0000 = 30 亿。
✗ 改写后漏写“万”“亿”字，或把“=”写成“≈” 写成 500000 = 50，或 500000 ≈ 50 万。
✓ 去掉的 0 变身成单位“万”或“亿”，准确改写用“=” 500000 = 50 万。

直接用

1. 把下面整万数改写成用「万」作单位的数：390000 = （ ）万。

39|0000 去掉个级的 4 个 0，等于 39 万。

2. 把整亿数改写成用「亿」作单位的数：8000000000 = （ ）亿。

80|0000|0000 去掉万级和个级的 8 个 0，等于 80 亿。

容易错

3. 把 90600000 改写成用「万」作单位的数，下面哪个写法完全正确？

C。分级后是 9060|0000，去掉个级 4 个 0 换成「万」字，大小不变用「=」：90600000 = 9060 万。

4. 小心别多去 0：70000000000 = （ ）亿。

分级 700|0000|0000，去掉后两级 8 个 0，亿级保留两个 0，是 700 亿。

想一想

5. 比较 4500000000 和 45 亿 的大小，怎样比最快？结果是什么？

A。给 45|0000|0000 画上分级线，去掉 8 个 0 就是 45 亿，所以两个数完全相等。

6. 把九位数 320000000 改写成用「万」作单位的数：320000000 = （ ）万。

改写成用「万」作单位，只去掉个级的 4 个 0：32000|0000 = 32000 万。
