本专题核心公式速查

函数综合题往往不要求先求出整个函数。先读清定义域和量词，再看目标在平移、反射、伸缩或复合下会经过哪些点；严格单调、整数性和有界误差能把看似自由的函数压缩成很少的选择。根数和最值问题则要同时跟踪每个分支的值域、不同原像及边界。

知识要点

复合定义域不能被化简后的公式覆盖

计算 f(g(x)) 时，先要有 x∈Dg​，再要求 g(x)∈Df​。例如 f(x)=(2x−1)/(x+2)，二次复合化为 (3x−4)/(4x+3)，但仍须排除 x=−2 和 x=−3/4。虽然化简式在 −2 处有值，原第一步却无定义；后续迭代不能擅自把这个点补回来。

特殊代值与结合律能在无连续性下定结构

先试零、相反数或把三变量按两种顺序合并，但每次代入都须合法。例：整数域上 F(x+y)=F(x)+F(y)+2xy，令 G(x)=F(x)−x2 后便有加法关系。若 F(1)=3，则 G(1)=2、G(n)=2n，故 F(2)=8。这个线性结论使用整数域，不能无条件搬到全体实数上的加法函数。

严格单调给单射，但递减函数可有非平凡二周期

严格单调函数满足同值即同输入。若严格递增的 H 满足 H(H(x))=x，比较 H(x) 与 x 可排除大于或小于，故 H(x)=x。递减情形不同：正数域上 H(x)=1/x 满足 H(H(x))=x，但 H(2)=1/2=2。遇到反函数交点或复合恒等式，应先确认单调方向。

目标点的变换轨道比全函数更容易封闭

把输入看成节点，允许的平移、反射或伸缩关系看成边；闭环就给函数值的有限方程组。例：若 F(x+2)=F(x)+4、F(x+3)=F(x)+6，比较 F(x+3) 与 F(x+1)+4 得 F(x+1)=F(x)+2。已知 F(0)=1，便有 F(5)=11；这些关系并不单独确定所有非整数处的值。

复合方程根数按不同原像累加

先解外层方程的不同函数值，再数每个值的合法原像。例：f(x)=x2 时，(f(x)−1)(f(x)−4)=0 有四根 ±1,±2；若改为 f(x)(f(x)−1)=0，则只有 0,±1 三根。零值只有一个原像，不能照搬非零值的成对计数；不同分支的公共端点也要去重。

整数域的间隙和有限状态有额外约束

严格递增且取整数的函数，若 F(2)=5,F(5)=8，则中间两值只能为 F(3)=6,F(4)=7，不能只当作普通实数不等式。有限集函数也可转为状态约束：从 {1,2} 到自身且满足 G(G(x))=G(x) 的函数恰有三个，分别是两个常值函数与恒等函数；交换两点的函数不符合。

有界误差可用重复迭代放大到矛盾

先减去一个已知解，把剩余量写成可重复的等式，再核放大后的输入一直合法。例：若 G 在实数上可加且 ∣G(x)∣≤1，则 G(nx)=nG(x) 迫使 G(x)=0。若猜 G(2)=1/10，取 n=11 就违反全局界。近似等式的误差若也随次数增长，必须先精确累计，不能直接当作零误差。

必要测试后仍需给量词要求的构造

“任意输入、存在另一些量”不能只靠几个测试值证明。例：对每个 a∈[−1,2]，取 b=1−a，就有 b∈[−1,2] 且 a+b=1。这里 b 随 a 改变；若把输入扩大到 a∈[−1,3] 而 b 仍限原区间，a=3 就无法实现。连续性构造也须先找到合法的两端值并覆盖等号。

方法卡

只求几个点的函数值：沿着变换走，回到起点就列方程代值、结合律与和差解耦复合再代入与单射消外层值域、分支原像与断点方程左右对称：根成对出现，中心上的根单独算整数间隙、有限状态与误差主项量词与参数的必要充分构造减去基准后的残差刚性

只求几个点的函数值：沿着变换走，回到起点就列方程

不用求出整个函数。从要求的点出发，按题目给的关系一步步算出下一个点，把路过的函数值当未知数。走到已知点或回到起点时列方程，再看方程能不能解出来。

完整讲解 · 例题 · 可练 41 题

一、是什么

一条关系把两个点连起来

关系 f(x)+f(1−x1​)=x（x=0,1）说的是：每个 x 都把 f 在 x 和 1−x1​ 这两点的值连起来。取 x=2，因为 1−21​=−1，得到 f(2)+f(−1)=2。这是一条只含具体函数值的普通方程。

回到起点才有足够的方程

继续走：−1 的下一个点是 1−(−1)1​=21​，21​ 的下一个点是 1−21​1​=2，回到了起点。路线是 2→−1→21​→2，一共 3 个未知数、3 条方程。如果既走不回来，也碰不到已知的点，又没有值域、有界这类其他条件，只靠这些等式，每走一步都多一个未知数，方程就不够。

每一步都要在关系成立的范围内

关系只在写明的范围内能用。若 f(2x)=3f(x) 只对 0≤x≤1 成立，那么 f(3) 不能写成 3f(1.5)，因为 x=1.5 超出了范围。所以每走一步都要核对这一步代入的 x 是否在范围内。

走不回来时，看能否沿点列前进

有的关系每次都走向新的点，但总能用前一个值算下一个。例如 g(n)+g(n+1)=n 对所有整数 n 成立，它把 n 和 n+1 连起来。这种情况要有一个已知的起始值，再用递推算到目标。写下标时要先看清从 0 还是从 1 开始。

回到起点也可能解不出来

f(x)+f(x1​)=x 对 x=0 成立时，从 2 出发得 f(2)+f(21​)=2，从 21​ 出发得 f(21​)+f(2)=21​。同一个和等于两个不同的数，所以这样的函数不存在。如果涉及两个不同的点，而两条方程完全相同，就只能得到这两个值的和，分不出每个值。因此要把方程组真正解完，不能认为回到起点就一定有答案。

先看一道例题

例 1：带系数的闭环

函数 f 对所有 x=0,1 满足 f(x)+2f(1−x1​)=3x。求 f(2)。

怎么看出来：

只问一个点，变换和步骤里相同，走 3 步回到起点。系数不同，所以不能再用三式相加。

解：

路线是 2→−1→21​→2，三个点都不是 0,1。设 a=f(2), b=f(−1), c=f(21​)。分别取 x=2,−1,21​，得 a+2b=6，b+2c=−3，c+2a=23​。由第三式 c=23​−2a，代入第二式得 b+3−4a=−3，即 b=4a−6。代入第一式得 a+8a−12=6，a=2。于是 b=2，c=−25​。检查：2+4=6，2−5=−3，−25​+4=23​，都成立。

答案：

f(2)=2。

二、什么时候想到它

题目里看到应该想到
只问 f(2) 这样的具体值，关系里同时有 f(x) 和变换后的点上的值从 2 出发算下一个点，看能否回到起点
关系只在某个区间内成立，如“0≤x≤1 时”每一步都核对代入的 x 是否在区间内
关系连接 n 和 n+1，并给了起始值写成递推，必要时隔项相减
同一个分式变换反复作用查每一步的分母，倒着找不能取的值（见进阶“分式变换的禁值”）
f(x+a)≥⋯ 和 f(x+b)≤⋯ 方向相反走到 a,b 的公倍数处比较（见进阶“函数不等式的夹逼”）
f(3x)=3f(x) 这样的倍数关系，又给了一段区间上的式子除以 3k 搬回这段区间（见进阶“伸缩关系和基础区间”）

三、怎么用

  1. 写下关系和它成立的范围。例如 f(x)+f(1−x1​)=x，范围是 x=0,1。
  2. 从目标点出发算下一个点，直到回到起点或走到已知点。求 f(2) 时路线是 2→−1→21​→2，这三个数都不是 0,1，每一步都能用。
  3. 设路过的函数值为未知数，每一步写一条方程。设 a=f(2), b=f(−1), c=f(21​)，得 a+b=2，b+c=−1，c+a=21​。
  4. 解方程组。三式相加除以 2，得 a+b+c=43​。减去 b+c=−1，得 a=47​。
  5. 代回每条方程检查。b=41​，c=−45​，三条方程都成立。这里没有假设 f 的整个式子，只用了这三个点。

四、再做一道

例 2：沿点列隔项相减

函数 g 定义在全体整数上，g(n)+g(n+1)=n 对所有整数 n 成立，g(0)=1。求 g(2024)。

怎么看出来：

关系连接相邻两点，一步步算要 2024 步。相邻两条方程相减，可以把中间的值消掉。

解：

写出 g(n)+g(n+1)=n 和 g(n+1)+g(n+2)=n+1。后式减前式得 g(n+2)−g(n)=1，所以每隔 2 增加 1。从 0 到 2024 要走 1012 个“隔 2”，所以 g(2024)=g(0)+1012=1013。检查前几项：由 g(0)=1 依次得 g(1)=−1，g(2)=2，g(3)=0，g(4)=3。可见 g(2)=g(0)+1，g(4)=g(0)+2，与隔项规律一致。

答案：

g(2024)=1013。

五、容易错在哪

  • 关系只在某个区间内成立时，代入的 x 跑出区间就不能再用这条关系。
  • 化简后得到 T(T(T(x)))=x，不代表所有 x 都能这样走，还要除掉中间分母为 0 的值。
  • 下标从 0 开始和从 1 开始，走的步数相差 1，要用前几项核对。
  • 只求几个点时，不要先假设 f 是一次函数或其他形式。凑出一个满足条件的式子，只能用来检查，不能代替推导。
  • 回到起点后方程组可能矛盾，也可能只给出和，要解完才能下结论。
进阶：分式变换的禁值 · 先修：分式运算

分式变换的周期要核对不能取的值

设 T(x)=1−x1​。连续做两次得 T(T(x))=xx−1​，做三次化简后等于 x。这个等式只在中间每一步都有意义时成立。x=1 时 T(1) 没有意义；x=0 时 T(0)=1，下一步就没有意义。所以 x=0,1 都要除掉。

倒着找不能取的值

反复做分式变换时，不能取的值要倒着找。先看哪个值使最后一步的分母为 0，再解“哪个 x 经过一次变换变成这个值”，一步步往回推。对 T(x)=1−x1​：T 在 x=1 没有意义；由 T(x)=1 得 x=0，所以 x=0 走一步后也会卡住。化简后的式子看不出这些值，因为分母可能已经约掉了。

例 3：哪些起点走不完

设 T(x)=3−x2​。从 x 出发连续做 3 次 T，哪些实数 x 中途会没有意义？

怎么看出来：

问的不是结果，而是哪些起点不能走完。T 只在 0 处没有意义，所以倒着找哪些点会走到 0。

解：

第 1 次卡住：x=0。第 2 次卡住：T(x)=0，即 3=x2​，x=32​。第 3 次卡住：T(x)=32​，即 x2​=37​，x=76​。每一步的方程都只有一个解，所以没有别的起点。检查 x=76​：T(76​)=3−37​=32​，T(32​)=3−3=0，第 3 次 T(0) 没有意义。

答案：

x=0, 32​, 76​。

进阶：函数不等式的夹逼 · 先修：不等式的传递

方向相反的不等式：走到公倍数处夹住

f(x+2)、f(x+3) 这样步长不同的不等式，无法直接比较。连续使用后走到步长的公倍数 6，两条不等式就都在说 f(x+6)，一条给下界，一条给上界。这里只反复使用题给的不等式，不需要 f 连续或单调。

例 4：由夹逼定参数

函数 f 对所有实数 x 满足 f(x+2)≥f(x)+3，f(x+3)≤f(x)+c。求常数 c 的最小可能值。

怎么看出来：

步长 2 和 3 的公倍数是 6，走到 f(x+6) 比较。这里不问函数值，问的是参数。

解：

连用 3 次第一式：f(x+6)≥f(x+4)+3≥f(x+2)+6≥f(x)+9。连用 2 次第二式：f(x+6)≤f(x+3)+c≤f(x)+2c。所以 f(x)+9≤f(x)+2c，得 c≥29​。再看 c=29​ 能否做到：取 f(x)=23​x，则 f(x+2)=f(x)+3，f(x+3)=f(x)+29​，两式都成立。

答案：

c 的最小值是 29​。

进阶：伸缩关系和基础区间 · 先修：指数和对数，余弦函数的周期

伸缩关系：把点搬回基础区间

若 x>0 时 f(3x)=3f(x)，用 k 次得 f(x)=3kf(3kx​)，k 是正整数。已知 f 在 [1,3) 上的式子时，[3k,3k+1) 上的点除以 3k 后就落回 [1,3)。对数函数也会产生伸缩关系：h(x)=xcos(2πlog2​x)（x>0）满足 h(2x)=2h(x)，因为 log2​(2x)=1+log2​x，余弦每过 2π 重复一次。

例 5：搬回基础区间再数解

函数 f 定义在 x≥1 上，f(3x)=3f(x) 对 x≥1 成立；当 1≤x<3 时 f(x)=1−∣x−2∣。方程 f(x)=1 在 [1,81) 上有几个解？

怎么看出来：

[1,81) 恰好分成 [1,3),[3,9),[9,27),[27,81) 这 4 段，每段都能除以 3k 搬回基础区间。

解：

记 k=0,1,2,3。x 在 [3k,3k+1) 时，u=3kx​ 在 [1,3)，并且 f(x)=3k(1−∣u−2∣)。方程变成 1−∣u−2∣=3k1​，即 ∣u−2∣=1−3k1​。k=0 时 ∣u−2∣=0，只有 u=2，即 x=2。k=1,2,3 时，右边在 0 和 1 之间，u=2±(1−3k1​) 都在 (1,3) 内，各有 2 个解。例如 k=1 时 u=34​,38​，x=4,8，f(4)=3(1−32​)=1。合计 1+2+2+2=7。

答案：

7 个解。

进阶：两个变量的函数关系 · 先修：本卡基础部分

两个变量的关系：先代值变成平移关系

对两个变量都成立的关系，可以固定一个变量。若 f(x+y)=f(x)+f(y)+2xy 对所有实数成立，f(1)=1，令 y=1 得 f(x+1)−f(x)=1+2x。令 x=y=0 得 f(0)=2f(0)，即 f(0)=0。于是 f(5)=1+3+5+7+9=25。

进阶：选点形成点列 · 先修：分式运算

例 6：选点让下标变整齐

函数 f 对 x>0 满足 f(1+xx​)=(1+x)f(x)，f(1)=2。求 f(1001​)。

怎么看出来：

x=n1​ 时 1+xx​=n+11​，分母正好加 1，所以只看 n1​ 这列点。

解：

设 bn​=f(n1​)，n 从 1 开始，b1​=2。x=n1​>0 在范围内，代入得 bn+1​=(1+n1​)bn​=nn+1​bn​。连乘时中间的因子相消：b100​=12​⋅23​⋯99100​⋅b1​=100×2=200。检查：f(x)=x2​ 满足全部条件，并且 f(1001​)=200。但题目只要求这个值，解答过程没有用到 f 的整个式子。

答案：

f(1001​)=200。

代值、结合律与和差解耦

什么时候想到它

函数方程含和、积、双线性交叉项，或两个函数满足对称的加法公式。

怎么用 · 小心 · 例题 · 可练 51 题
怎么用

先代零与相反数，保留可能为零的分支。三变量和按两种结合顺序展开以消去高阶函数项；双函数可试和与差，使关系解耦。给出一个零点时，也可代入扩大零点集合，再用非零区域反推自变量范围。得到候选后代回原式证充分。

小心

没有连续性却把实数加法函数直接写成线性；除以未证非零函数值；只猜到一个多项式解就称全部；忘掉定义域。

方程左右对称：根成对出现，中心上的根单独算

如果把 x 换成 2a−x 后方程不变，那么不在 x=a 上的根成对出现，每对的和是 2a，x=a 本身最多是一个根。只要定义域也关于 a 对称，就能用这条规律数根和求根的和。

完整讲解 · 例题 · 可练 16 题

一、是什么

什么叫关于 x=a 对称

x 和 2a−x 在数轴上关于 a 对称，因为它们的平均数是 a。若 g(2a−x)=g(x) 对定义域内所有 x 成立，x0​ 是 g(x)=0 的根，那么 2a−x0​ 也是根。例如 g(x)=x2−6x+1，a=3：(6−x)2−6(6−x)+1=x2−6x+1。

用半径写根

令 t=∣x−a∣≥0，它表示 x 到中心的距离，叫半径，则 x=a+t 或 x=a−t。半径 t>0 时这是两个不同的数，它们的和是 2a。半径 t=0 时两者重合，只对应 x=a 一个根，不能算一对。

根的个数是奇数，中心一定是根

不在中心的根两两配对，个数是偶数。所以当根的个数有限且为奇数时，多出来的那个只能是中心。例如方程恰有一个根，这个根一定是 x=a。但这只是必要条件：解出参数后，还要代回去确认根的个数确实符合要求。

找中心的办法

若式子里所有含 x 的部分都能写成 ∣x−a∣ 的式子，且定义域关于 a 对称，中心就是 x=a。只是含有 ∣x−a∣ 还不够：∣x−1∣+x=2 的根是 23​，它关于 1 的对称点 21​ 不是根。二次式 x2+px+q 配方为 (x+2p​)2+q−4p2​，中心是 x=−2p​。找到后把 x 换成 2a−x 代入验证。

先看一道例题

例 1：恰有 3 个根

方程 ∣x2−4∣=k 恰有 3 个不同的实根。求 k，并写出这 3 个根。

怎么看出来：

左边把 x 换成 −x 不变，中心是 x=0。根的个数是奇数，所以中心一定是根。

解：

非中心的根成对出现，3 是奇数，所以 x=0 是根。代入得 k=∣0−4∣=4。这只说明 k 必须等于 4，还要代回去确认根数。k=4 时 x2−4=4 或 x2−4=−4，即 x2=8 或 x2=0。所以根是 x=±22​ 和 x=0，恰好 3 个。

答案：

k=4，根是 −22​, 0, 22​。

二、什么时候想到它

题目里看到应该想到
方程含 ∣x∣ 或 ∣x−a∣，其余部分也只依赖它以 x=a 为中心，设半径 t=∣x−a∣≥0
二次式外面套一层，如 ∣x2−6x+5∣先配方找中心 x=3。内层值高于二次式的最小值时给一对根，等于时给一个，低于时没有
问方程恰有奇数个根，尤其恰有一个根中心一定是根，由此求参数，再验证根数
问所有根的和先数有几对，每对的和是 2a
四个根成等差半径之比是 1:3（见进阶“等差根”）
三个共线点等距中间点坐标是平均数，分情况试（见进阶“共线等距”）
两个式子形状相同，右边互为相反数找奇函数和中心，可能得到两个未知数的和（见进阶“中心对称”）

三、怎么用

  1. 找中心并验证。解 (x−1)2−2∣x−1∣=3，把 x 换成 2−x，式子不变，中心是 x=1。
  2. 设半径。令 t=∣x−1∣≥0，因为 (x−1)2=t2，方程变为 t2−2t−3=0，即 (t−3)(t+1)=0。
  3. 按半径还原。t=−1 不符合 t≥0，舍去。t=3>0 给一对根，x=4 和 x=−2。t=0 不是解，所以中心不是根。
  4. 代回检查。x=4 时 9−6=3，x=−2 时 9−6=3，都成立。
  5. 按问题收尾。这里共 2 个根，和是 2×1=2，确实等于 4+(−2)。

四、再做一道

例 2：中心不在原点时求根的和

求方程 ∣x2−6x+5∣=2 所有实根的和。

怎么看出来：

配方 x2−6x+5=(x−3)2−4，它只依赖 (x−3)2，所以中心是 x=3。内层可以取 2 或 −2，每种取值都要看。

解：

设 t=∣x−3∣≥0，则内层等于 t2−4，方程为 ∣t2−4∣=2。t2−4=2 时 t=6​；t2−4=−2 时 t=2​；负半径舍去。两个半径都大于 0，各给一对根：3±6​，3±2​。检查：(3+6​) 处内层是 6−4=2，(3+2​) 处内层是 2−4=−2，绝对值都是 2。中心 x=3 处绝对值是 4，不是根。共 2 对，每对和为 6。

答案：

所有根的和是 12。

五、容易错在哪

  • 半径为 0 只有一个根，不能算一对。t=0 也满足方程时，根的总数是奇数。
  • 由唯一根或奇数个根算出参数，只是必要条件，还要代回去确认根数。
  • 对称只说明根成对，不说明有多少对，根数还要靠解方程或分段判断。
  • 不同的情况解出同一个 x 时，这个根只算一次。
  • 共线等距题没有说谁在中间时，每一点都可能是中点。
进阶：等差根 · 先修：等差数列的定义

四根成等差：半径之比是 1:3

若四个根关于中心对称，按大小写成 a−q, a−p, a+p, a+q（0<p<q）。相邻差要相等，所以 q−p=2p，即 q=3p。这里用到等差数列的定义：相邻两项的差相同。

例 3：四根成等差，反求参数

方程 x4−10x2+m=0 有 4 个不同的实根，且这些根按大小排列成等差数列。求 m。

怎么看出来：

只含 x2，中心是 0。根写成 ±p, ±q，等差给出 q=3p。

解：

设 s=x2，方程变为 s2−10s+m=0。要有 4 个不同实根，这个二次方程要有两个不同的正根 p2, q2，其中 0<p<q。根依次为 −q,−p,p,q，相邻差相等给出 q−p=2p，即 q=3p。两根之和等于一次项系数的相反数：把 s2−10s+m=(s−p2)(s−q2) 展开比较系数，得 p2+q2=10，p2q2=m。代入 q=3p，得 10p2=10，p=1，q=3，m=9。检查：x4−10x2+9=(x2−1)(x2−9)，根 −3,−1,1,3 成等差。

答案：

m=9。

例 4：中间根代回定参数

方程 x3−6x2+mx−6=0 的 3 个实根成等差数列。求 m。

怎么看出来：

3 个根成等差，中间的根是另两个的平均数。三次方程根的和可以比较系数得到。

解：

设根为 r−d, r, r+d。把 (x−r+d)(x−r)(x−r−d) 展开，x2 项系数是 −3r，与 −6 比较得 r=2。所以 x=2 是根，代入得 8−24+2m−6=0，m=11。检查：x3−6x2+11x−6=(x−1)(x−2)(x−3)，根 1,2,3 成等差，确实符合。

答案：

m=11。

进阶：共线等距 · 先修：坐标平面上的距离

三个共线点等距：先确定谁在中间

A,B,C 互不相同、共线且 ∣AB∣=∣BC∣，B 就是 AC 的中点。直线不竖直时，B 的横坐标是另两点横坐标的平均数；直线竖直时，改用纵坐标。题目常常没有说哪一点在中间。例如横坐标 1,4,r 的三点共线等距，r 可能是 −2、25​ 或 7，3 种都要试。

进阶：中心对称 · 先修：立方的展开，函数的单调性

中心对称和奇函数

若 g(a+t)+g(a−t)=2b 对定义域内所有 t 成立，图象关于点 (a,b) 对称。例如 g(x)=x−1x​，t=0 时 g(1+t)+g(1−t)=t1+t​+−t1−t​=2，中心是 (1,1)。奇函数 h 满足 h(−t)=−h(t)，再加上严格递增时，由 h(u)=−h(v) 能推出 u=−v，这是因为 h(u)=h(−v) 且严格递增的函数不同的输入给出不同的输出。没有严格递增时，这一步不成立：h(t)=t3−t 是奇函数，h(0)=−h(1)=0，但 0=−1。

例 5：从两数之和反求右边

实数 a,b 满足 a3+3a2+5a=1，b3+3b2+5b=m，且 a+b=−2。求 m。

怎么看出来：

左边都是同一个式子，a+b=−2 说明 a,b 关于 −1 对称，所以把式子平移到 x=−1。

解：

由 (x+1)3=x3+3x2+3x+1，得 x3+3x2+5x=(x+1)3+2(x+1)−3。设 h(t)=t3+2t，它是奇函数，于是 h(a+1)−3=1，得 h(a+1)=4。由 a+b=−2 得 b+1=−(a+1)，所以 h(b+1)=−h(a+1)=−4。因此 m=h(b+1)−3=−7。

答案：

m=−7。

误区对照

容易误以为

令 g(x)=1/(x−2)，化简得 g(g(x))=(x−2)/(5−2x)，所以复合函数只须排除 x=5/2。

应当这样想

第一步 g(x) 要求 x=2，第二步还要求 g(x)=2，即 x=5/2。准确的复合定义域是 R∖{2,5/2}；化简式虽在 2 有值，原复合没有。

为什么

复合函数要求每一步输入都合法；代数约分不能把第一步已经没有定义的点补回。

容易误以为

只要 H 严格单调且 H(H(x))=x，就必有 H(x)=x。

应当这样想

若 H:R→R 严格递增，此结论成立：H(x)>x 会推出 x=H(H(x))>H(x)，反之也矛盾。但严格递减的 H(x)=3−x 满足复合恒等式，且 H(0)=3=0。

为什么

单射只能消去同一个外层函数，不能让任意二周期都缩成不动点；排除非平凡二周期需要严格递增的方向。

容易误以为

检验函数方程时，只要在 x=0,1 两点算对，就能认定对所有实数都成立。

应当这样想

有限代值只能给必要测试。例如 F(x)=x(x−1) 与零函数都在 0,1 取零，但 F(2)=2。若要声称 F(x)=0 对一切实数成立，必须覆盖任意输入。

全称命题不能由几个样本证明；特殊代值适合寻找约束，充分性仍须把候选解代回原方程并核全域。
