位数不同的小数加减法

两个小数，一个一位，一个两位，竖式怎么摆？空着的地方怎么算？

本单元按旧版教材编排。

把一根 2.5 米的绳子和一根 1.34 米的绳子首尾接起来，一共有多长？

对，3.84 米。2.5 只有一位小数，1.34 有两位，竖式怎么写才不乱？下面自己摆。

1. 小数点对齐，空位补 0

选一道题。先点“末位对齐”，看看哪些数字不在自己的数位上；再点“小数点对齐”，再点“补 0”，最后“算出得数”。

2. 为什么空位可以补 0

用钱来想。6.4 元是 6 元 4 角，2.38 元是 2 元 3 角 8 分。加的时候，元加元，角加角，分加分，所以小数点要上下对齐，同一列才是同一个数位。

6.4 元只有角，没有分，分的那一格空着，就是 0 分。6.4 和 6.40 大小一样，所以空位可以补 0，也可以不补，算的时候当 0 就行。

整数也一样：8 的小数点在末尾，8 就是 8.00。退位时，空位当 0，不够减就向前一位借 1。

自己试试

7.3 + 2.15 = ？

7.30 + 2.15 = 9.45。

自己试试

6 − 1.74 = ？

6.00 − 1.74 = 4.26。

位数不同的小数加减，小数点对齐，位数不够的地方空着当 0（也可以补 0）。整数的小数点在末尾。得数末尾的 0 可以去掉。

两个容易错的地方

✗ 末位对齐

6.4 + 2.38，把 4 和 8 对在一起相加。

✓ 小数点对齐

4 在十分位，要和 3 对齐；8 在百分位，对着空位（当 0）。

✗ 整数对到最右边

8 − 1.45，把 8 和 5 对齐。

✓ 整数的小数点在末尾

8 = 8.00，8 在个位，要和 1 对齐。

直接用

1. 4.7 + 3.26 = ？

4.70 + 3.26 = 7.96。

2. 9 − 2.58 = ？

9.00 − 2.58 = 6.42。

3. 0.85 + 2.9 = ？

B。0.85 + 2.90 = 3.75。

容易错

4. 15 − 6.208 = ？

15.000 − 6.208 = 8.792。

5. 3.65 + 1.35 = ？

3.65 + 1.35 = 5.00，末尾的 0 去掉，写 5。

想一想

6. 5.98 + 3.04，得数大约是多少？（先看成接近的整数再估）

B。5.98 约 6，3.04 约 3，大约 9。算准是 9.02。

7. 一个数加上 6.35，正好是 10。这个数是多少？

10.00 − 6.35 = 3.65。检查：6.35 + 3.65 = 10.00。

8. 甲、乙两条彩带一共长 7.1 米，甲长 3.85 米，乙长多少米？

7.10 − 3.85 = 3.25，乙长 3.25 米。检查：3.85 + 3.25 = 7.10。
