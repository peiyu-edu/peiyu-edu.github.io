2.4 圆的方程

圆就是「到一个点距离一样」的所有点。把这句话用两点距离公式写出来，就得到圆的方程；再学会从方程里读出圆心和半径。

草地上钉一根木桩，小狗用 \(5\) 米长的绳子拴在上面。以木桩为原点建坐标系，单位是米。点下面的按钮，试试把绳子牵向四个不同的点：

小狗把绳子拉直时，它可能站在下面哪个点？

算到原点的距离：\((3,4)\) 是 \(\sqrt{9+16}=5\)；\((4,4)\) 是 \(\sqrt{32}\approx5.66\)；\((5,5)\) 是 \(\sqrt{50}\approx7.07\)；\((2,3)\) 是 \(\sqrt{13}\approx3.61\)。只有 A 正好是 \(5\)。

绳子拉直时，小狗到木桩的距离总是 \(5\)，它能站的点连起来是一个圆。点 \((x,y)\) 在这个圆上，就是 \(\sqrt{x^2+y^2}=5\)，也就是 \(x^2+y^2=25\)。

这一节就讲：怎样用一个方程表示圆，怎样从方程看出圆心、半径，以及什么样的方程不是圆。

1. 先认识几个词

要用到：两点间的距离公式 \(|AB|=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\)（回看 2.3）；初中学过的配方。

课本用词：一般方程表示真正的圆必须满足 \(D^2+E^2-4F>0\)；等于 0 只有一个点，小于 0 没有实点。

伴读直觉微图解：圆的标准方程、一般方程与判别式三态

圆、圆心、半径：平面上到一个定点距离等于定长的所有点组成的闭合曲线。定点叫圆心 \(C(a,b)\)，定长叫半径 \(r\)（\(r>0\)）。

例：到 \((1,2)\) 距离为 \(3\) 的点，满足 \((x-1)^2+(y-2)^2=9\)。点 \((1,5)\) 满足 \(0+9=9\)，在圆上；\((1,2)\) 到自身距离为 \(0\)，在圆内。

配方法：对二次式凑成完全平方：\(x^2+px = (x+\frac p2)^2 - \frac{p^2}{4}\)。配方是连接一般方程与标准方程的桥梁。

例：\(x^2-6x=(x-3)^2-9\)；\(y^2+4y=(y+2)^2-4\)。

形式辨析 标准方程 \((a,b,r)\) vs 一般方程 \((D,E,F)\)

标准方程：\((x-a)^2+(y-b)^2=r^2\)。几何要素一目了然，圆心 \((a,b)\)、半径 \(r\) 直读，判别点圆位置极其便利。

一般方程：\(x^2+y^2+Dx+Ey+F=0\)。展开齐次形式，最适合已知不共线三点代入解三元一次线性方程组。

设方程准则：已知几何特征（圆心、弦长、相切）设标准式；已知三个点坐标设一般式。

判别式辨析 \(D^2+E^2-4F\) 几何三态判别

充要条件：\(x^2+y^2+Dx+Ey+F=0\) 表示圆的充要条件是 \(\Delta = D^2+E^2-4F > 0\)！

三态蜕变：\(\Delta > 0\) 为圆；\(\Delta = 0\) 蜕化为单点 \((-\frac D2, -\frac E2)\)；\(\Delta < 0\) 无实数点。

警惕：方程含参数求为圆时，必须严格解不等式 \(D^2+E^2-4F > 0\)！

圆的标准方程：\((x - \color{#2563eb}{a})^2 + (y - \color{#2563eb}{b})^2 = \color{#059669}{r^2} \quad (r > 0)\)
圆的一般方程：\(x^2 + y^2 + \color{#2563eb}{D}x + \color{#2563eb}{E}y + \color{#dc2626}{F} = 0 \quad (\color{#dc2626}{D^2+E^2-4F > 0})\)

2. 圆的标准方程

圆心 \(C(a,b)\)，半径 \(r\)。点 \(P(x,y)\) 在圆上，就是 \(|PC|=r\)，用距离公式写出来是 \(\sqrt{(x-a)^2+(y-b)^2}=r\)。两边都不是负数，平方后意思不变：

\((x-a)^2+(y-b)^2=r^2\)　（\(r>0\)）
圆心 \((a,b)\)，半径 \(r\)。

读方程时注意符号：括号里是「减圆心」。\((x+1)^2\) 就是 \((x-(-1))^2\)，圆心横坐标是 \(-1\)。右边是 \(r^2\)，半径要开方。

点和圆的位置也靠它看：把点代进左边，和 \(r^2\) 比，大于就在圆外，等于在圆上，小于在圆内（其实就是比点到圆心的距离和 \(r\)）。

例 1（看一遍怎么写）

圆心是 \((2,-1)\)，圆经过点 \((5,3)\)，求圆的方程。

半径就是圆心到这个点的距离：\(r^2=(5-2)^2+(3-(-1))^2=9+16=25\)，\(r=5\)。

所以方程是 \((x-2)^2+(y+1)^2=25\)。

顺便判断原点在哪：\((0-2)^2+(0+1)^2=5<25\)，原点在圆内。

自己试试：圆 \((x-1)^2+(y+2)^2=9\) 的圆心和半径是？

A。\((y+2)^2=(y-(-2))^2\)，圆心纵坐标是 \(-2\)；\(r^2=9\)，\(r=3\)。选 B 是把两个符号都弄反了；选 C 忘了开方，\(9\) 是 \(r^2\)。

3. 圆的一般方程

把标准方程展开：\(x^2+y^2-2ax-2by+(a^2+b^2-r^2)=0\)。记 \(D=-2a\)，\(E=-2b\)，\(F=a^2+b^2-r^2\)，就是

\(x^2+y^2+Dx+Ey+F=0\)

反过来，拿到这样一个方程，对 \(x\)、\(y\) 分别配方：

\(\left(x+\dfrac D2\right)^2+\left(y+\dfrac E2\right)^2=\dfrac{D^2+E^2-4F}{4}\)

左边是两个平方的和，不会是负数。所以要看右边：

\(D^2+E^2-4F>0\)：是圆，圆心 \(\left(-\dfrac D2,-\dfrac E2\right)\)，半径 \(\dfrac{\sqrt{D^2+E^2-4F}}{2}\)。
\(D^2+E^2-4F=0\)：只有一个点 \(\left(-\dfrac D2,-\dfrac E2\right)\)。
\(D^2+E^2-4F<0\)：没有一个实数点满足它。

例 2

方程 \(x^2+y^2-4x+6y-3=0\) 表示什么图形？

配方：\((x^2-4x+4)+(y^2+6y+9)=3+4+9\)，即 \((x-2)^2+(y+3)^2=16\)。

右边 \(16>0\)，是圆，圆心 \((2,-3)\)，半径 \(4\)。

用公式核对：\(D^2+E^2-4F=16+36+12=64>0\)，半径 \(\dfrac{\sqrt{64}}{2}=4\)，一样。

自己试试：\(x^2+y^2+2x-4y-4=0\) 的圆心和半径是？

A。\((x^2+2x+1)+(y^2-4y+4)=4+1+4\)，即 \((x+1)^2+(y-2)^2=9\)。选 C 是配方时只加了常数 \(4\)，忘了把补进去的 \(1\) 和 \(4\) 也加到右边；选 B 是圆心符号反了。

4. 求圆的方程：先设，再解

标准方程有 \(a,b,r\) 三个未知数，一般方程有 \(D,E,F\) 三个，所以一般要三个条件。选哪种设法看条件：

  • 条件和圆心、半径有关（圆心在某条线上、和某点距离多少）→ 设标准方程。
  • 给了圆上三个点 → 设一般方程，代入得到关于 \(D,E,F\) 的一次方程组，好解。

例 3

求过 \(O(0,0)\)、\(A(4,0)\)、\(B(0,2)\) 三点的圆的方程。

设 \(x^2+y^2+Dx+Ey+F=0\)。代入 \(O\)：\(F=0\)；代入 \(A\)：\(16+4D=0\)，\(D=-4\)；代入 \(B\)：\(4+2E=0\)，\(E=-2\)。

方程是 \(x^2+y^2-4x-2y=0\)，配方得 \((x-2)^2+(y-1)^2=5\)，圆心 \((2,1)\)，半径 \(\sqrt5\)。验算 \(B\)：\(4+1=5\)，对。

自己试试：过 \((0,0)\)、\((2,0)\)、\((0,6)\) 三点的圆，圆心是？

A。\(F=0\)；\(4+2D=0\)，\(D=-2\)；\(36+6E=0\)，\(E=-6\)。圆心 \(\left(-\dfrac D2,-\dfrac E2\right)=(1,3)\)。选 B 是直接拿 \(\left(\dfrac D2,\dfrac E2\right)\) 当圆心，少了负号；选 C 把 \(-D\)、\(-E\) 当成了圆心。

5. 简单的轨迹

「点按某个规则动，它走过的路线是什么」，求的就是轨迹方程。做法：设动点 \(M(x,y)\)，把规则翻译成 \(x,y\) 的等式，化简。最后还要回头查：方程上的点是不是都符合规则（多出来的点要去掉）。

例 4

点 \(A(4,0)\)，点 \(Q\) 在圆 \(x^2+y^2=4\) 上运动，求线段 \(AQ\) 的中点 \(M\) 的轨迹方程。

设 \(M(x,y)\)。\(M\) 是中点，所以 \(Q=(2x-4,\,2y)\)。\(Q\) 在圆上：\((2x-4)^2+(2y)^2=4\)，两边除以 \(4\)：\((x-2)^2+y^2=1\)。

反过来查：这个圆上任取一点 \(M\)，令 \(Q=(2x-4,2y)\)，代回去 \(Q\) 正好在 \(x^2+y^2=4\) 上，\(M\) 就是 \(AQ\) 的中点。没有多出来的点。

所以轨迹是以 \((2,0)\) 为圆心、\(1\) 为半径的圆。

自己试试：点 \(P\) 到 \(A(-1,0)\)、\(B(1,0)\) 的距离的平方和是 \(10\)，\(P\) 的轨迹方程是？

A。\((x+1)^2+y^2+(x-1)^2+y^2=10\)，展开 \(2x^2+2y^2+2=10\)，所以 \(x^2+y^2=4\)。选 B 是展开时把两个 \(1\) 丢了。

6. 三步破题思维链：求圆方程与判别式解题标准动作

1
👀 第一眼破题信号

审清几何条件：是给出圆心、半径，圆与直线相切，还是给出圆上不共线的三点坐标。若方程含参数且提问「何时表示圆」，立刻联想到判别式 \(\Delta = D^2+E^2-4F\)。

2
🔧 第二步套公式/方法

① 条件涉及圆心、半径、距离时：设标准方程 \((x-a)^2+(y-b)^2=r^2\)；
② 条件给出圆上三点坐标时：设一般方程 \(x^2+y^2+Dx+Ey+F=0\)，联立解三元一次线性方程组；
③ 含参数判别式：列出 \(D^2+E^2-4F > 0\) 求解参数取值范围。

3
🛡️ 第三步必查防坑结论

① 标准方程右边是 \(r^2\)，回答半径必须开平方根！
② 动点轨迹求出后，必须核验几何边界条件，剔除三点共线等不合题意的空心退化点。

7. 三大翻车现场与反例辨析

翻车现场 1：一般方程判别式为 0 误认成圆
❌ 将 \(x^2+y^2-2x+4y+5=0\) 直接读成圆，计算半径得 0 仍称作圆
✔ 配方得 \((x-1)^2+(y+2)^2=0\)，几何图形仅为单个点 \((1,-2)\)
翻车现场 2：从标准方程读圆心符号弄反
❌ 由 \((x+1)^2+(y-3)^2=4\) 读出圆心坐标为 \((1,-3)\)
✔ 标准方程是 \((x-a)^2\)，圆心为 \((-1,3)\)，切记「负号是公式自带」
翻车现场 3：把右边常数项当半径漏开方
❌ 由 \((x-2)^2+y^2=9\) 答半径 \(r=9\)，导致周长与面积全错
✔ 右侧常数项为 \(r^2=9\)，半径必须开方得出 \(r=3\)
反例微图解：判别式 \(\Delta = 0\) 退化为单点图解
\(D^2+E^2-4F = 0\) 时，配方后右侧半径平方为 \(0\)，图形收缩退化为一个孤立点；\(<0\) 时右侧为负数，无任何实数点！
再深一点（可以先跳过）

为什么「平方」不会多出点：\(\sqrt{(x-a)^2+(y-b)^2}=r\) 两边都不小于 \(0\)，所以平方前后等价。要是右边可能是负数，平方就会多出解，这也是标准方程要求 \(r>0\) 的原因之一。

圆心在已知直线上：比如「圆心在 \(y=x\) 上，过 \((0,0)\) 和 \((2,0)\)」，设 \((x-a)^2+(y-a)^2=r^2\)，两个条件联立解出 \(a=1, r^2=2\)。

① 拖圆心和半径点，看两种方程

拖动圆心 \(C\) 或圆上的点 \(P\)（也可以点一下再按方向键），两个点都停在格点上。看标准方程和展开后的一般方程一起变。

② 进阶：调 D、E、F，什么时候不是圆

方程 \(x^2+y^2+Dx+Ey+F=0\)。拉动三个滑块，看 \(D^2+E^2-4F\) 的正负：正的画圆，等于 \(0\) 只剩一个点，负的一个点都没有。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 圆心 \((-2,1)\)、半径 \(3\) 的圆，一般方程是？

A。\((x+2)^2+(y-1)^2=9\)，展开 \(x^2+4x+4+y^2-2y+1=9\)，移项得 \(x^2+y^2+4x-2y-4=0\)。B 是圆心符号反了；C 把 \(9\) 加到了左边（应该减）；D 减的是 \(3\)，忘了右边是 \(r^2=9\)。

2. 圆 \(x^2+y^2-6x+8y=0\) 的圆心和半径是？

A。\((x-3)^2+(y+4)^2=9+16=25\)，半径 \(5\)。半径由 \(D^2+E^2-4F=36+64-0=100\) 决定，不是看常数项：\(F=0\) 只说明圆过原点（\(0+0+0+0+0=0\)）。

易错

3. 方程 \(x^2+y^2-2x+4y+5=0\) 表示什么？

B。\(D^2+E^2-4F=4+16-20=0\)。配方：\((x-1)^2+(y+2)^2=1+4-5=0\)，两个平方加起来是 \(0\)，只能都是 \(0\)，只有 \((1,-2)\) 一个点。选 A 是没算 \(D^2+E^2-4F\) 就当成了圆。可以在「动手」②里点按钮看看。

4. 下面哪一个方程表示圆？

C。两边除以 \(2\)：\(x^2+y^2-2x+4y+1=0\)，\(D^2+E^2-4F=4+16-4=16>0\)，是圆心 \((1,-2)\)、半径 \(2\) 的圆。

A：\(x^2\)、\(y^2\) 系数不相等。B：有 \(xy\) 项。D：样子对，但 \(4+0-16=-12<0\)，没有点。

5. 经过 \((1,1)\)、\((2,2)\)、\((3,3)\) 三点的圆有几个？

C。三点都在直线 \(y=x\) 上。代入一般方程：\(2+D+E+F=0\)，\(8+2D+2E+F=0\)，\(18+3D+3E+F=0\)。前两式相减得 \(D+E=-6\)，后两式相减得 \(D+E=-10\)，矛盾。一条直线和一个圆最多两个公共点，所以「三点定一圆」要求三点不共线。

挑战

6. \(A(0,0)\)、\(B(2,0)\)，\(\triangle ABC\) 中 \(|CA|=|AB|\)。顶点 \(C\) 的轨迹是？

C。\(|CA|=|AB|=2\)，所以 \(x^2+y^2=4\)。还要 \(A,B,C\) 能构成三角形，\(C\) 不能在直线 \(AB\)（\(x\) 轴）上。圆和 \(x\) 轴交于 \((2,0)\) 和 \((-2,0)\)：前一个和 \(B\) 重合，后一个让三点共线，都要去掉。

B 只想到了和 \(B\) 重合；\((0,\pm2)\) 构成直角三角形，没问题，不用去掉。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
