第一单元 万以上数的认识

从右边起每四个数位是一级，分成个级、万级、亿级；每相邻两个计数单位之间的进率都是 10。无论是读数、写数、比大小，还是改写与求近似数，先画一条分级线就清楚了。

一张图看懂本单元

1. 按照我国的计数习惯，从右边起，每四个数位是一级（个级、万级、亿级）；每相邻两个计数单位之间的进率都是 10。
2. 读数和写数都要先分级，从最高级起按级读、写；每级末尾的 0 不读，其他数位有一个 0 或连续几个 0 都只读一个零。
3. 整万、整亿数改写大小不变用「=」；用「四舍五入」法求近似数要看省略尾数部分的最高位，用「≈」。

本单元容易错的地方

✗ 把万级末尾的 0 读出来；或写数时个级没满 4 位 把 5408000 错读成「五百四十万零八千」；把「六万零五十」错写成 6050。
✓ 先画分级线：级末 0 不读，每级占满 4 位 540|8000 万级末尾的 0 不读，读作「五百四十万八千」；六万零五十写作 6|0050。
✗ 改写时把万级末尾的 0 也去掉；近似数错写「=」 把 48000000 改写成「48 万」；把 386200 ≈ 39 万写成「= 39 万」。
✓ 改写万只去 4 个 0（用 =），求近似数看尾数最高位（用 ≈） 4800|0000 = 4800 万；386200 千位是 6（五入），386200 ≈ 39 万。

一共 10 关，把这一单元的 8 课合在一起考一考。

直接用

1. 按照我国的计数习惯，从个位起（从右往左数），第 5 位是万位，那么第 9 位是什么数位？

B。个级 4 位、万级 4 位，合起来是 8 位；第 9 位是亿级的第 1 位，也就是亿位。

2. 先给 70600800 分级（7060|0800），它应该读作什么？

C。万级「7060」读作七千零六十万（万位上的 0 在级末不读）；个级「0800」千位有 0 要读，末尾两个 0 不读，合起来读作七千零六十万零八百。

3. 「五万零八十」写作多少？

万级写 5，个级千位、百位都没有写 0 占位（0080），合起来是 50080。

4. 读一读亿以上的数 30800400000（分级：308|0040|0000），下面哪个读法正确？

A。亿级是 308（三百零八亿），万级是 0040（零四十万，末尾 0 不读），个级全是 0 不读，合起来是三百零八亿零四十万。

容易错

5. 「六百零四亿零五十万」写作哪个数？

B。亿级写 604，万级写满 4 位是 0050，个级写满 4 位是 0000，合起来是 60400500000。

6. 比较 89650000 和 102300000 的大小，下面说法正确的是？

C。比大小先看位数：89650000 是八位数，102300000 是九位数，位数多的数就大。

7. 把整万数 65000000 改写成用「万」作单位的数：65000000 = （ ）万。

分级后是 6500|0000，去掉个级的 4 个 0 换成「万」字，65000000 = 6500 万。

8. 用「四舍五入」法省略万位后面的尾数：473980 ≈ （ ）万。

千位上是 3，小于 5，把万位后面的尾数 3980 舍去，473980 ≈ 47 万。

想一想

9. 省略亿位后面的尾数求近似数：1984200000 ≈ （ ）亿。

千万位上是 8，大于 5，向亿位进 1：19 + 1 = 20，所以 1984200000 ≈ 20 亿。

10. 要使 73□800 ≈ 74 万，□ 里最小能填几？

73 万变成 74 万，说明千位满 5 向万位进 1 了。□ 里可以填 5、6、7、8、9，其中最小填 5。

到了后面会怎样

综合与实践（1 亿有多大）：1 亿张纸摞起来有一万米高，比珠穆朗玛峰还高！用身边的小数推算大数。

四年级上册（第三单元 多位数乘两位数）：算出几十万、几百万的乘积，还会用计算器探索亿以上大数的乘法规律。

四年级下册（小数的意义和性质）：学习把不是整万、整亿的数用小数准确改写，并把「四舍五入」法用到求小数的近似数上。

本单元 8 课回顾

第 1 课 · 亿以内数的认识：认识十万、百万、千万、亿和数位顺序表，每相邻两个计数单位之间的进率都是 10，认识自然数。

第 2 课 · 亿以内数的读法：先四位分级，先读万级（加「万」字）再读个级；每级末尾的 0 不读，其他位一个或连续几个 0 只读一个零。

第 3 课 · 亿以内数的写法：圈出「万」字分两级，先写万级再写个级；哪一位上一个也没有，就写 0 占位。

第 4 课 · 亿以上数的认识和读法：认识十亿、百亿、千亿与十进制计数法，按亿级、万级、个级三级读出大数。

第 5 课 · 亿以上数的写法：圈出「亿」「万」从亿级写起，万级和个级都必须写满 4 位，缺位补 0。

第 6 课 · 数的大小比较：位数不同时位数多的数就大；位数相同时从最高位起一位一位往下比。

第 7 课 · 用万、亿作单位改写：整万数去掉个级 4 个 0 换「万」字，整亿数去掉后两级 8 个 0 换「亿」字，用「=」连接。

第 8 课 · 求近似数：用「四舍五入」法省略万位（看千位）或亿位（看千万位）后面的尾数，用「≈」连接。
