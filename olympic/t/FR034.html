知识要点

定积分的符号与几何面积

定积分累积带符号的高度，几何面积必须使用非负截线长度。连续函数与横轴之间的面积是 ∫ab​∣f(x)∣dx，不能一概去掉绝对值。例：f(x)=x 在 [−1,1] 上的积分为 0，与横轴围成的两块面积之和却为 1。求面积前先确认上下边界，必要时在零点处分段。

交点与切换点决定积分区间

两边界所夹面积应在交点确定的区间内积上减下；最小值或最大值拼成的边界还要找切换点。例：0≤y≤min{x,2−x} 只在 0≤x≤2 非空，并在 x=1 换边界，面积为 ∫01​xdx+∫12​(2−x)dx=1。参数移动后，要重新确认积分端点是否越过切换点。

原函数核验与牛顿—莱布尼茨公式

连续被积函数在区间上有原函数 F 时，∫ab​f(x)dx=F(b)−F(a)。先求导核原函数，再代两端，常比只算一个数可靠。例：∫13​(2x+1)dx=[x2+x]13​=10。根式端点可在开区间核导数并用连续延拓取端值，不能因导数表达式在端点含零分母就丢掉有限积分。

换积分方向是在换截线

横向与纵向截线描述同一区域，所得面积应相同，但边界函数和积分变量要一起改变。例：0≤y≤1, y2≤x≤1 的面积既是 ∫01​(1−y2)dy，也是 ∫01​x​dx，均为 2/3。选择边界更少分段、逆函数更简单的方向，换向时不能沿用原来的上下端点。

圆弧根式可先读成几何面积

y=r2−x2​ 在 [−r,r] 上是半径 r>0 的上半圆，因此全区间积分为半圆面积。例：∫01​1−x2​dx=π/4。只截取一部分时，可用扇形减三角形，但必须按实际截线辨明应减哪一个三角形；弦截弓形与竖直截线围成的区域不同。

对称积分先拆奇偶与常数

对称区间 [−a,a] 上，连续奇函数的积分为零，连续偶函数的积分为正半段的两倍，其中 a>0。若 f(x)+f(−x)=2c，则 ∫−aa​f(x)dx=2ac。例：∫−22​(x3+3)dx=12；被积函数整体既非奇也非偶，不能把常数项一起消去。

体积累积的是截面积

若高度 h 处的平行截面面积为连续函数 A(h)，则高度 a 到 b 间的体积是 ∫ab​A(h)dh，量纲为长度的三次方。例：0≤h≤3 时 A(h)=9−h2，体积为 [9h−h3/3]03​=18。求截面积前须认清给出的是边、半径还是对角线；正方形对角线为 d 时面积是 d2/2，不能直接取 d2。

积分夹和与最佳常数的量词

严格递增连续函数的单位区间积分可由端点值严格夹住，再逐项相加估计离散和。例：n≥1 时 n2/2<∑k=1n​k<(n2+2n)/2；n=4 给 8<10<12。比值趋近某常数不表示有限下标能取等；证明最佳统一界须先证每个下标成立，再用逼近排除更小或更大的候选常数。

先确定真实截线与参数范围

积分前先确定每一层真正包含的点，再求该层长度或面积。

完整讲解 · 例题 · 可练 6 题

一、是什么

先认识这些量

横截线固定一个横坐标，留下纵坐标区间。面积等于各层长度的积分；体积则积分截面积，不是积分截面的边长。

为什么这样做

两个区域取交集，要同时满足各边界；扫掠形成的并集只计覆盖区域，不计某点被覆盖的次数。

先看一道例题

例 1：三角区域

求 x≥0,y≥0,x+y≤2 围成的面积。

怎么看出来：

固定横坐标后纵向长度为二减横坐标。

解：

0≤x≤2，每层 0≤y≤2−x，故面积 ∫02​(2−x)dx=2。

答案：

2。

二、什么时候想到它

题目里看到应该想到
曲线与直线围成的区域、由最小值或移动竖条给出的交集、动线段的扫掠，或立体各高度截面已知；直接套积分式容易算错覆盖范围。积分前先确定每一层真正包含的点，再求该层长度或面积。
求 x≥0,y≥0,x+y≤2 围成的面积。固定横坐标后纵向长度为二减横坐标。

三、怎么用

  1. 选择固定哪一个坐标或高度。
  2. 求该层所有允许点。
  3. 写出非负长度或截面积及有效范围。
  4. 积分并反查端点和中间值均可达。

四、再做一道

例 2：圆柱切片

半径 2、高 3 的直圆柱体积是多少？

怎么看出来：

水平截面为圆，应积圆面积。

解：

每层截面积为 π⋅22=4π，高度范围 [0,3]，体积 ∫03​4πdh=12π。

答案：

12π。

五、容易错在哪

  • 同一层有几个不相交区间时要加长度，不能把中间空隙也算进去。

分段积分、原函数与换向复核

面积积分先分清上下边界；原函数求出后先求导核验。

完整讲解 · 例题 · 可练 5 题

一、是什么

先认识这些量

原函数 F 满足 F′=f，定积分为 F(b)−F(a)。区域面积应积分上边界减下边界，不能让正负面积互相抵消。

为什么这样做

边界在交点处可能换位，所以先分段；分段后的每个高度必须非负。

先看一道例题

例 1：两曲线之间

求 y=x 与 y=x2 围成的面积。

怎么看出来：

交点零和一，中间直线在上。

解：

面积为 ∫01​(x−x2)dx=[x2/2−x3/3]01​=1/6。

答案：

1/6。

二、什么时候想到它

题目里看到应该想到
已确定区域边界或截面积，剩下是幂函数、指数、根式等积分；上下边界或端点可能随参数切换。面积积分先分清上下边界；原函数求出后先求导核验。
求 y=x 与 y=x2 围成的面积。交点零和一，中间直线在上。

三、怎么用

  1. 求边界交点与有效范围。
  2. 按上下关系变化处分段。
  3. 求原函数并求导复核。
  4. 算终值减初值，相加得到面积。

四、再做一道

例 2：换位边界

求 y=x,y=0,x=−1,x=1 围成的总面积。

怎么看出来：

直线在零点左右换上下位置。

解：

面积 ∫−10​(−x)dx+∫01​xdx=1/2+1/2=1；直接积分 x 会错误抵消。

答案：

1。

五、容易错在哪

  • 原函数相减的次序是终点减起点；面积还要确认被积高度非负。

用几何或对称先简化积分

看到对称区间或圆弧，先辨认配对与几何结构，再求积分。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

奇函数满足 f(−x)=−f(x)，在对称区间的积分为零；偶函数满足 f(−x)=f(x)。半径 r 的圆面积为 πr2。

为什么这样做

左右对称点配对能消掉奇函数部分。根式若表示上半圆，高度的积分就是半圆面积，不必硬求复杂原函数。

先看一道例题

例 1：奇项消失

求 ∫−22​(x3+3)dx。

怎么看出来：

三次项是奇函数。

解：

三次项积分为零，常数项为 3⋅4=12。

答案：

12。

二、什么时候想到它

题目里看到应该想到
根式恰为圆弧，或对称区间上有奇偶结构、对称点函数值之和；硬求原函数会增加运算。看到对称区间或圆弧，先辨认配对与几何结构，再求积分。
求 ∫−22​(x3+3)dx。三次项是奇函数。

三、怎么用

  1. 确认积分区间和被积函数定义域。
  2. 尝试计算对称点函数值之和。
  3. 消去奇部分，或识别圆弧面积。
  4. 计算剩余部分，核区域没有多算。

四、再做一道

例 2：半圆面积

求 ∫−22​4−x2​dx。

怎么看出来：

非负根式是半径二的上半圆。

解：

积分为圆面积的一半，即 π⋅22/2=2π。

答案：

2π。

五、容易错在哪

  • 对称消失的只是奇函数部分，常数和偶函数部分仍需计算。

证明界限并核可达或逼近

界限要配上取等构造；若只能逼近，就说明是上确界或下确界。

完整讲解 · 例题 · 可练 2 题

一、是什么

先认识这些量

值域是实际取得的所有值。最大最小值需达到；仅可无限接近的端点要用开端点表示。

为什么这样做

连续函数在区间上的中间值可填满端点之间的空隙，但端点本身能否取到由原参数域决定。

先看一道例题

例 1：闭区间

0≤t≤1，求 t(1−t) 的值域。

怎么看出来：

配方后中心点合法。

解：

t(1−t)=1/4−(t−1/2)2，最小 0 在端点取，最大 1/4 在中点取。连续性给全区间。

答案：

[0,1/4]。

二、什么时候想到它

题目里看到应该想到
用不等式求扫掠截线的最左、最右端，或用积分估计离散和并求最佳统一常数。界限要配上取等构造；若只能逼近，就说明是上确界或下确界。
0≤t≤1，求 t(1−t) 的值域。配方后中心点合法。

三、怎么用

  1. 写参数准确范围。
  2. 配方或用导数求上下界。
  3. 给取等参数或逼近序列。
  4. 用连续性或反解证明中间值全能取到。

四、再做一道

例 2：开区间

0<t<1，求 t2 的值域。

怎么看出来：

平方函数递增但端点不能取。

解：

有 0<t2<1；任意 0<u<1 取 t=u​ 可实现。t=1/n 与 t=1−1/n 分别逼近两端。

答案：

(0,1)。

五、容易错在哪

  • 只给界没有证明中间值可达，不能直接把整个区间写作值域。

误区对照

容易误以为

直线 y=x、x 轴与直线 x=−1、x=2 围成的面积为 ∫−12​xdx=23​。

应当这样想

定积分把 x 轴下方部分记为负：∫−10​xdx=−21​，∫02​xdx=2。面积应为 21​+2=25​。

为什么

定积分是有向面积；求几何面积要在零点处分段，对负的部分取绝对值。

容易误以为

∫−11​x2dx​=[−x1​]−11​=−1−1=−2。

应当这样想

被积函数在 x=0 处无界，不满足牛顿—莱布尼茨公式的连续前提。∫01​x2dx​ 已发散，所以原积分不存在。正的被积函数算出负值，本身就是警报。

为什么

牛顿—莱布尼茨公式要求被积函数在闭区间上连续（原函数在区间上处处可导）；跨过奇点直接代端点会得到无意义的数。

容易误以为

曲线 y=x3 与直线 y=x 围成的面积为 ∫−11​(x−x3)dx=0。

应当这样想

两曲线交于 x=−1,0,1。在 [−1,0] 上 x3≥x，在 [0,1] 上 x≥x3。面积为 ∫−10​(x3−x)dx+∫01​(x−x3)dx=41​+41​=21​。

为什么

两曲线间面积要用“上方减下方”，而上下位置在每个交点处可能互换，所以要按全部交点分段。

1. 曲线 y=sinx（0≤x≤2π）与 x 轴围成图形的面积为：

遗漏前提：几何面积对 x 轴下方部分要取绝对值。∫02π​sinxdx=0 是有向面积，[π,2π] 上的部分为负，要取绝对值。

遗漏前提：积分区间须覆盖所有切换段。2 只是 [0,π] 一段；[π,2π] 上还有一块面积 2。

正确。∫0π​sinxdx=2，∫π2π​sinxdx=−2，面积 2+2=4。

2. ∫−22​(x3+x+3)dx 的值为：

遗漏前提：对称区间积分为零只适用于奇函数部分。只有奇函数部分 x3+x 在对称区间上积分为零；常数 3 是偶函数，贡献 3×4=12。

遗漏前提：偶函数在对称区间的积分是半区间的两倍。6=∫02​3dx 只算了半个区间；偶函数部分应是半区间积分的两倍。

正确。奇部积分为零，偶部 ∫−22​3dx=12。

3. 关于 ∫−11​x2dx​，正确的是：

遗漏前提：牛顿—莱布尼茨公式要求被积函数在闭区间上连续。−x1​ 在 x=0 处不连续，不能跨过奇点代端点；正的被积函数也不可能积出负数。

遗漏前提：对称区间积分为零要求被积函数为奇函数。x21​ 是偶函数而不是奇函数，正负不会抵消。

正确。∫ε1​x2dx​=ε1​−1→+∞，所以积分发散。
