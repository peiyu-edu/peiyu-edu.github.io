椭圆参数弦的面积范围

F4解答题椭圆

已知椭圆

C:a2x2​+b2y2​=1(a>b>0)

的离心率为 21​，A1​,A2​ 分别为椭圆 C 的左、右顶点， F1​,F2​ 分别为椭圆 C 的左、右焦点，B 为椭圆 C 的上顶点，且 △BA1​F1​ 的外接圆半径为 3221​​。

（1）求椭圆 C 的方程；

（2）设与 x 轴不垂直的直线 l 交椭圆 C 于 P,Q 两点 （P,Q 在 x 轴的两侧）。记四条直线

A1​P,PA2​,A2​Q,QA1​

的斜率依次为 k1​,k2​,k3​,k4​。已知

k1​+k4​=35​(k2​+k3​),

求 △F2​PQ 面积的取值范围。

解析

提示

第（1）问由离心率统一各半轴。

思路

第（2）问用椭圆的半角参数表示四条顶点连线的斜率，斜率条件会化为参数乘积固定，面积随即成为一元函数。

解答

（1）由 c/a=1/2，有 c=a/2,b=3​a/2。三角形 BA1​F1​ 的三边为

A1​F1​=2a​,BF1​=a,BA1​=27​​a,

面积为 a23​/8。故其外接圆半径

R=4⋅a23​/8(a/2)⋅a⋅(7​a/2)​=6a21​​.

由 R=221​/3 得 a=4,b=23​，所以

16x2​+12y2​=1​.

（2）用参数

X(t)=(41+t21−t2​,43​1+t2t​)

表示椭圆上的点。设 P=X(p),Q=X(q)。因二点在 x 轴两侧，pq<0。直接计算四条直线的斜率，得

k1​=23​​p,k2​=−2p3​​,k3​=−2q3​​,k4​=23​​q.

题设条件等价于

(p+q)(1+3pq5​)=0.(1)

若 p+q=0，则 P,Q 的横坐标相等，l 垂直于 x 轴，与题设矛盾。因此

pq=−35​.(2)

把 q=−5/(3p) 代入三点坐标的行列式，化简得到

S△F2​PQ​=(p2+1)(9p2+25)483​∣p∣(3p2+5)​.(3)

令 r=p2>0，去掉正常数后的函数为

h(r)=(r+1)(9r+25)r​(3r+5)​.

求导得

h′(r)=−2r​(r+1)2(9r+25)2(3r−5)(9r2+26r+25)​.

故唯一最大点为 r=5/3，由 (3) 得最大值 95​/2。但 r=5/3 与 (2) 会使 q=−p，对应被排除的竖直直线，故最大值不能取得。 当 r→0+ 或 r→+∞ 时面积趋于 0；函数在最大点两侧连续且单调，所以中间每个正值均能取得。因此面积范围为

(0,295​​)​.

复核

参数式覆盖除左顶点外的椭圆点，而 (2) 保证 p,q 均非零、异号；遗漏的极限点已由 r→0+ 或 r→∞ 纳入端点分析。

方法总结

椭圆顶点弦的斜率在半角参数下分别成为参数与其倒数，适合处理四条顶点连线的线性关系；求范围时必须区分极值点是否对应被排除的退化方向。

为什么评为 F4（会透露解法方向）

先由外接圆尺度求椭圆，继而用两端点有理参数分出竖直分支与固定积分支；面积极值恰落在已排除的竖直分支，必须回查可达性才能给开区间。
