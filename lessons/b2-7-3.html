7.3 复数的三角表示（选学）

用模长与辐角表示复数：让乘除法变成「模相乘除、角相加减」的旋转与伸缩，架起代数与平面几何的桥梁。
本节为选学内容，帮助建立代数与几何旋转的深层联系。

在数轴上，把一个数乘以 \(-1\)，相当于把这个点绕原点逆时针旋转了 \(180^\circ\)（半圈）。如果乘以虚数单位 \(i\)，连续乘两次 \(i\) 的结果是乘以 \(-1\)。猜一猜：乘一次 \(i\) 会怎样？由 \((a+bi)i=-b+ai\)，点 \((a,b)\) 变为 \((-b,a)\)，这正是逆时针转 \(90^\circ\)。下面再用三角形式解释这个结论。

如果从正实轴上的点 \((1, 0)\) 出发，绕原点逆时针旋转 \(45^\circ\)（长度保持为 \(1\)），它落在了第一象限的角平分线上。这个点在复平面上对应的复数是多少？

入门题：把复平面上对应实数 \(1\) 的单位向量绕原点逆时针旋转 \(45^\circ\)，终点对应的复数是？

B。根据直角三角形与三角函数定义：向量长度 \(r=1\)，横坐标为 \(\cos 45^\circ = \dfrac{\sqrt{2}}{2}\)，纵坐标为 \(\sin 45^\circ = \dfrac{\sqrt{2}}{2}\)。所以对应的复数是 \(\dfrac{\sqrt{2}}{2} + \dfrac{\sqrt{2}}{2}i\)。

用代数形式 \(a+bi\) 看起来，这一堆根号并不直观；但如果用「长度为 \(1\)、方向角为 \(45^\circ\)」来看，位置一目了然！这一节我们就来学习复数的三角表示：用距离和方向角描述复数，让几何旋转变成乘除运算。

1. 先认识几个词

要用到：复数的代数形式、复平面和模（回看 7.1）；复数的乘除（回看 7.2）；任意角的三角函数（回看 5.2）；两角和与差的公式（回看 5.5）。

直觉微图解

直角形式 ①代数形式 a + bi：适合线性加减

直角坐标体系：实部虚部分开，可以逐项加减，也可用分配律、共轭或先算低次幂完成乘除与乘方；根据题目选择便于计算的表示。

极坐标形式 ②三角形式 r(cosθ + i sinθ)：便于分析乘除与旋转

旋转与缩放：非零复数化为向径 \(r=|z|>0\) 与辐角 \(\theta\)。乘法化为「模相乘、角相加」，除法「模相除、角相减」，正整数次幂可用棣莫弗公式；涉及辐角的法则要求有关复数非零。

非零复数的模与辐角：设 \(z=a+bi\)，\(a,b\in\mathbb R\)，\(z\ne0\)。\(r=\sqrt{a^2+b^2} > 0\) 为点 \(Z(a,b)\) 到原点的距离；以正实轴为始边、射线 \(OZ\) 为终边的角 \(\theta\) 叫辐角，相差 \(2k\pi\)（\(k\in\mathbb Z\)）的角对应同一射线。零的模仍为 \(0\)，但它没有辐角。

本课的辐角主值约定：对非零复数，本课把 \(\arg z\) 取为无数个辐角中落在区间 \([0, 2\pi)\) 内的唯一值，含 \(0\)、不含 \(2\pi\)（如 \(\arg i = \frac{\pi}{2}\)，\(\arg(-1)=\pi\)）。负角也可以是合法辐角，只有题目要求主值时才按本课约定归入该区间。\(0\) 没有辐角，也没有辐角主值。

2. 核心公式与运算法则

① 标准三角形式：\(z = r(\cos\theta + i\sin\theta)\)（非零复数的标准写法：\(r>0\)、中间是加号、\(\cos\) 在前 \(i\sin\) 在后、两角同为 \(\theta\)）；
② 几何乘法法则：\(z_1 z_2 = r_1 r_2 [\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)]\)（模相乘，辐角相加，\(z_1,z_2\ne0\)）；
③ 几何除法法则：\(\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2} [\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)]\)（模相除，辐角相减，\(z_1,z_2\ne0\)；若仅分子为零，商为零，没有辐角）；
④ 棣莫弗公式（正整数次幂）：\(z^n = r^n (\cos n\theta + i\sin n\theta)\)（\(z\ne0\)，\(n\in\mathbf{N}^*\)）。
为什么乘法会“模乘、角加”？

设 \(z_j=r_j(\cos\theta_j+i\sin\theta_j)\)，\(r_j>0\)。用分配律和 \(i^2=-1\) 展开：

\(z_1z_2=r_1r_2[(\cos\theta_1\cos\theta_2-\sin\theta_1\sin\theta_2)+i(\sin\theta_1\cos\theta_2+\cos\theta_1\sin\theta_2)]\)。

两角和公式把两组括号分别化为 \(\cos(\theta_1+\theta_2)\) 与 \(\sin(\theta_1+\theta_2)\)，就得到乘法法则。除以非零复数等于乘它的倒数，倒数的模为 \(1/r_2\)、辐角可取 \(-\theta_2\)；正整数次幂则由重复相乘得到。

例 1（形式互化示范）

(1) 把 \(z=-\sqrt3+i\) 写成三角形式。(2) 把 \(w=2\left(\cos\dfrac{4\pi}{3}+i\sin\dfrac{4\pi}{3}\right)\) 写成代数形式。

解：(1) 模 \(r=\sqrt{(-\sqrt3)^2+1^2}=2\)。\(\cos\theta=-\dfrac{\sqrt3}{2}\)，\(\sin\theta=\dfrac12\)，点 \((-\sqrt3,1)\) 在第二象限，取 \(\theta=\dfrac{5\pi}{6}\)。

所以 \(z=2\left(\cos\dfrac{5\pi}{6}+i\sin\dfrac{5\pi}{6}\right)\)，辐角主值 \(\dfrac{5\pi}{6}\)。

(2) \(\cos\dfrac{4\pi}{3}=-\dfrac12\)，\(\sin\dfrac{4\pi}{3}=-\dfrac{\sqrt3}{2}\)，\(w=2\left(-\dfrac12-\dfrac{\sqrt3}{2}i\right)=-1-\sqrt3 i\)。

自己试试：把 \(z = 1 - i\) 化为标准三角形式，模和辐角主值是？

A。模 \(r = \sqrt{1^2 + (-1)^2} = \sqrt{2}\)；\(\cos\theta = \dfrac{\sqrt{2}}{2}\)，\(\sin\theta = -\dfrac{\sqrt{2}}{2}\)，点 \((1,-1)\) 在第四象限，主值是 \(\dfrac{7\pi}{4}\)。

B 的表达式等于原复数，但所报的正角 \(\pi/4\) 不是它的辐角主值；C 的模忘了开方；D 的表达式也等于原复数，但外面的负系数不是模，所报的 \(r\) 不符合要求。

例题视频的完整问题

① 将 \(-\sqrt3+i\) 化为三角形式；② 将 \(2(\cos(4\pi/3)+i\sin(4\pi/3))\) 化为代数形式。视频随后另外比较 \(2(\cos(\pi/3)-i\sin(\pi/3))\)，后者是改变条件的对比题。

例 2（乘除法示范）

设 \(z_1=\sqrt2\left(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\right)\)，\(z_2=\sqrt3\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)\)。求 \(z_1 z_2\)。

解：模相乘：\(r = \sqrt2 \times \sqrt3 = \sqrt6\)；辐角相加：\(\theta = \dfrac{\pi}{4} + \dfrac{\pi}{6} = \dfrac{5\pi}{12}\)。

所以 \(z_1 z_2 = \sqrt6\left(\cos\dfrac{5\pi}{12} + i\sin\dfrac{5\pi}{12}\right)\)。

自己试试：已知 \(z_1 = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\)，\(z_2 = 3\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)\)，则 \(z_1 z_2\) 等于？

A。模相乘：\(2\times 3 = 6\)；角相加：\(\dfrac{\pi}{3} + \dfrac{\pi}{6} = \dfrac{\pi}{2}\)。

所以 \(z_1 z_2 = 6\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 6(0 + i) = 6i\)。选 C 的同学模相加了；选 D 的同学角算成了相减。

3. 典型例题：三步思维链精讲

例 3（选学综合·高次幂与复数除法）

已知复数 \(z_1 = \sqrt{3} + i\)，\(z_2 = 1 + i\)。
① 将 \(z_1\) 化为三角形式，并求 \(z_1^6\) 的值；
② 计算 \(\dfrac{z_1}{z_2}\) 的模与辐角主值。

👀 第一眼·破题信号
看到高次幂 \(z_1^6\) 以及复数除法求角 → 可以选用三角形式，把模的乘方与辐角的累加分开计算；也可以寻找便于验算的代数分组！
🔧 第二步·套公式拆解
① 化三角形式：\(r_1 = \sqrt{(\sqrt{3})^2 + 1^2} = 2\)，\(\cos\theta_1 = \dfrac{\sqrt{3}}{2}, \sin\theta_1 = \dfrac{1}{2}\)（第Ⅰ象限）\(\implies \theta_1 = \dfrac{\pi}{6}\)；
    故 \(z_1 = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)\)；
    由棣莫弗公式：\(z_1^6 = 2^6\left[\cos\left(6\times\dfrac{\pi}{6}\right) + i\sin\left(6\times\dfrac{\pi}{6}\right)\right] = 64(\cos\pi + i\sin\pi) = 64(-1 + 0) = \) \(-64\)！
② 计算商 \(\dfrac{z_1}{z_2}\)：
    \(z_2 = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)\)；
    模相除：\(r = \dfrac{2}{\sqrt{2}} = \sqrt{2}\)；
    辐角相减：\(\theta = \dfrac{\pi}{6} - \dfrac{\pi}{4} = -\dfrac{\pi}{12}\)；
    负角加 \(2\pi\) 化为主值：\(-\dfrac{\pi}{12} + 2\pi = \dfrac{23\pi}{12}\)。
🛡️ 第三步·必查防坑点
① 象限核查：\(\theta_1\) 必须由点 \((\sqrt{3}, 1)\) 所在象限确认，不能只算正切；
② 棣莫弗指数不仅作用在角上（乘 6），模长也必须求 6 次方（\(2^6=64\)）；
③ 按本课约定，辐角主值落在 \([0, 2\pi)\) 内，本例的负角加 \(2\pi\) 得到本课主值；一般辐角可能需要加减整数倍 \(2\pi\)。

独立验算：\((\sqrt3+i)^2=2+2\sqrt3i\)，再乘 \(\sqrt3+i\) 得 \(z_1^3=8i\)，所以 \(z_1^6=(8i)^2=-64\)。商也可写成 \(\dfrac{(\sqrt3+i)(1-i)}2=\dfrac{\sqrt3+1}2+\dfrac{1-\sqrt3}2i\)。两种表示可以相互核对。

自己试试：\(z_1=3\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)\)，\(z_2=6\left(\cos\dfrac{5\pi}{6}+i\sin\dfrac{5\pi}{6}\right)\)。\(\dfrac{z_1}{z_2}=\)？

A。模 \(\dfrac36=\dfrac12\)；辐角 \(\dfrac{\pi}{3}-\dfrac{5\pi}{6}=-\dfrac{\pi}{2}\)，所以商 \(=\dfrac12(0-i)=-\dfrac12 i\)。选 B 算反了角；选 C 模除反了。

综合视频的完整问题与示意图约定

已知 \(z_1=\sqrt3+i\)、\(z_2=1+i\)：① 化 \(z_1\) 为三角形式并求 \(z_1^6\)；② 求 \(z_1/z_2\) 的模与本课辐角主值。高次幂段的无坐标轴图仅示方向、箭头长度归一，实际模依次为 \(2,4,8,64\)。视频最后把分子改为零，作为另一个边界问题。

4. 这三种情况最容易翻车

翻车现场 ①非标准三角形式直接错读模和角
错解

对 \(z = 2\left(\cos\dfrac{\pi}{3} - i\sin\dfrac{\pi}{3}\right)\) 误读出辐角为 \(\dfrac{\pi}{3}\)。

正解

先改写成标准的加号结构，再直接读模与角。利用诱导公式化为 \(2\left[\cos\left(-\dfrac{\pi}{3}\right) + i\sin\left(-\dfrac{\pi}{3}\right)\right]\)，辐角主值是 \(\dfrac{5\pi}{3}\)（第四象限）。

翻车现场 ②只看 tanθ 找辐角导致差半圈
错解

对 \(z = -1 - i\) 由 \(\tan\theta = 1\) 误写出辐角主值 \(\dfrac{\pi}{4}\)。

正解

点 \((-1, -1)\) 位于第三象限！必须同时满足正余弦符号，辐角主值是 \(\pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}\)。

翻车现场 ③复数 0 妄图求辐角
错解

写出 \(0 = 0(\cos 0 + i\sin 0)\)，认为 \(\arg 0 = 0\)。

正解

原点没有确定方向，复数 0 没有辐角。恒等式 \(0(\cos\theta+i\sin\theta)=0\) 对任意 \(\theta\) 都成立，但不能由此给零定义辐角；它也不属于本课 \(r>0\) 的标准三角形式。

再深一点（可以先跳过）

方程 \(z^n=1\) 的根（\(n\) 为正整数）：模为 1、辐角为 \(\dfrac{2k\pi}{n}\)（\(k=0,1,\dots,n-1\)）的 \(n\) 个根，当 \(n\ge3\) 时正好是单位圆内接正 \(n\) 边形的顶点。\(n=1\) 时只有点 \(1\)，\(n=2\) 时为一条直径的两个端点 \(\pm1\)。这里辐角的多值性至关重要。

大学延伸：欧拉公式：大学数学中 \(\cos\theta + i\sin\theta = \mathrm{e}^{i\theta}\)，从而「模相乘、角相加」正是指数运算法则 \(\mathrm{e}^{i\theta_1}\cdot\mathrm{e}^{i\theta_2} = \mathrm{e}^{i(\theta_1+\theta_2)}\)。本课只用分配律和两角和差公式推导复数乘除法，不依赖复指数；欧拉公式留待后续学习。

直接用

1. 复数 \(z = 4\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right)\) 的代数形式 \(a+bi\) 是？

A。计算特殊角三角函数值：\(\cos\dfrac{2\pi}{3} = -\dfrac{1}{2}\)，\(\sin\dfrac{2\pi}{3} = \dfrac{\sqrt{3}}{2}\)。

展开可得：\(z = 4\left(-\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right) = -2 + 2\sqrt{3}i\)。

2. 已知 \(z_1 = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)\)，\(z_2 = 3\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\)，则 \(z_1 z_2\) 等于？

B。应用复数乘法的三角法则：模相乘、辐角相加。

模长为 \(2 \times 3 = 6\)；辐角为 \(\dfrac{\pi}{6} + \dfrac{\pi}{3} = \dfrac{\pi}{2}\)。

所以 \(z_1 z_2 = 6\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 6(0 + i) = 6i\)。

选 C 的同学错把模长相加了；选 D 的同学把辐角相减了（\(\dfrac{\pi}{3}-\dfrac{\pi}{6}=\dfrac{\pi}{6}\)），乘法要相加。

易错

3. 下列各式中，哪一个按所写形式即可直接读出正的模与同一个辐角，无需先改写？

D。直接读模与角的标准结构满足：模 \(r > 0\)；中间必须是加号；前余弦、后正弦；两处角完全一致。

A 外面的系数为 \(-2\)，不是模；这个复数的实际模是 \(2\)，需把负号并入角后再按标准形式读数；

B 可用余弦的偶性、正弦的奇性改写成角 \(-\pi/4\) 的标准形式，但不能把所写的正角直接读成辐角；

C 中的两个角不相同，不能直接把外面的 \(2\) 当成模；

D 完全符合标准结构（它对应的正是点 \((\sqrt{2}, -\sqrt{2})\) 在第四象限的三角形式）。

4. 关于复数 \(z = 0\) 的模与辐角，下列说法正确的是？

B。复数 \(0\) 在复平面上对应原点 \(O\)。到原点的距离（模）确定且等于 \(0\)；但从原点出发不能确定一条射线的方向，因此零复数没有辐角，也没有辐角主值。

虽然 \(0(\cos\theta+i\sin\theta)=0\) 对任意角成立，它不赋予零一个方向。除数必须非零，源于零没有乘法逆元；若分子为零、除数非零，商为零，模为零而没有辐角。

挑战

5. 复数 \(z_1 = 1 + \sqrt{3}i\)，\(z_2 = 1 + i\)。计算商 \(\dfrac{z_1}{z_2}\) 的模与辐角主值是？

A。化为三角形式：

\(z_1 = 1 + \sqrt{3}i = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\)，模 \(r_1 = 2\)，\(\arg z_1 = \dfrac{\pi}{3}\)；

\(z_2 = 1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)\)，模 \(r_2 = \sqrt{2}\)，\(\arg z_2 = \dfrac{\pi}{4}\)。

根据除法法则（模相除、角相减）：

模长为 \(\dfrac{r_1}{r_2} = \dfrac{2}{\sqrt{2}} = \sqrt{2}\)；辐角为 \(\dfrac{\pi}{3} - \dfrac{\pi}{4} = \dfrac{\pi}{12}\)。

所以 \(\dfrac{z_1}{z_2} = \sqrt{2}\left(\cos\dfrac{\pi}{12} + i\sin\dfrac{\pi}{12}\right)\)。也可用共轭把分母实数化，得到 \(\dfrac{1+\sqrt3}{2}+\dfrac{\sqrt3-1}{2}i\)，再核对它的模与象限。
