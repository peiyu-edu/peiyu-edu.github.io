1.3 集合的基本运算

两个集合放在一起，能「取公共的」「全放一起」，也能「从全集里去掉」。这一节把这三种运算弄清楚，尤其是数轴上的端点。先从两张名单开始。

班里有两个兴趣小组。篮球组：小明、小红、小刚、小丽；合唱组：小红、小丽、小强。点下面的按钮切换查看不同集合：

两个组都参加了的是谁？

A。两张名单里都出现的只有小红和小丽。

换几个问法：「至少参加一个组的」是小明、小红、小刚、小丽、小强，共 \(5\) 人——小红、小丽在两张名单上，人只算一次；「没参加篮球组的」要先说清在哪群人里找：在全班找，就是全班去掉篮球组那 \(4\) 人。

这三种问法，就是这一节的三种运算：交集（都在）、并集（至少在一个里）、补集（在大范围里、但不在它里面）。

直觉微图解 ①集合三大运算的视觉光影

核心概念 ②交集（\(\cap\) 门扣）vs 并集（\(\cup\) 水杯）

\(\cap\) 口朝下像一道窄门扣，只有两家同时满足的「共同贵客」才能挤进来；\(\cup\) 口朝上像一只大水杯，把两家的元素全部收进来（同一个元素只列一次）！

核心概念 ③补集必须先看全集 \(U\)！

脱离了全集谈补集是无源之水。同一个集合 \(A=\{1,2\}\)，在 \(U=\{1,2,3\}\) 里补集是 \(\{3\}\)；在全体自然数 \(\mathbf{N}\) 里补集则是无穷无尽的自然数！

2. 核心三大运算定义与等价包含链

交集：同时满足两个条件。
\(A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}\)

并集：至少满足一个条件。
\(A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}\)

补集：在 \(U\) 中彻底挖掉 \(A\)。
\(\complement_U A = \{x \in U \mid x \notin A\}\)

例 1（交集与并集计算）

\(A=\{1,2,3,4\}\)，\(B=\{3,4,5,6\}\)，求 \(A\cap B\) 和 \(A\cup B\)。

两边都有的是 \(3\) 和 \(4\)，所以 \(A\cap B=\{3,4\}\)。

把两边的元素放在一起：\(1,2,3,4\) 和 \(3,4,5,6\)，重复的 \(3,4\) 只写一次，\(A\cup B=\{1,2,3,4,5,6\}\)。

自己试试：\(A=\{1,3,5,7\}\)，\(B=\{2,3,5,8\}\)。\(A\cup B\) 有几个元素？

B。\(A\cup B=\{1,2,3,5,7,8\}\)，\(6\) 个。选 C 的同学把 \(3\)、\(5\) 数了两次；选 D 的同学数的是交集 \(\{3,5\}\)。

例 2（补集与全集）

\(U=\{1,2,3,4,5,6\}\)，\(A=\{1,3,5\}\)，求 \(\complement_U A\)。

从 \(U\) 里把 \(A\) 的元素 \(1,3,5\) 去掉，剩下 \(2,4,6\)，所以 \(\complement_U A=\{2,4,6\}\)。

自己试试：\(U=\{1,2,3,4,5,6,7\}\)，\(A=\{2,4,6\}\)，\(B=\{1,2,3\}\)。\((\complement_U A)\cap B=\)？

A。先算 \(\complement_U A=\{1,3,5,7\}\)，再和 \(B=\{1,2,3\}\) 取公共的：\(\{1,3\}\)。选 B 的同学算完补集就停了，忘了「\(\cap B\)」；选 C 算成了 \(A\cap B\)。

3. 数轴上的交、并、补：端点实心空心穿透法则

例 3（示范：跟老师走一遍思考过程）

设全集为 \(\mathbf R\)，\(A=\{x\mid -1\le x<3\}\)，\(B=\{x\mid 1<x\le 5\}\)。求 \(A\cap B\)、\(A\cup B\) 和 \(\complement_{\mathbf R}A\)。

👀 第一眼看交集重叠区： 重叠段在 \(1\) 到 \(3\) 之间。看两端：端点 \(1\) 在 \(B\) 中是空心，交集直接判空心；端点 \(3\) 在 \(A\) 中也是空心。故 \(A\cap B=\{x\mid 1<x<3\}\)。
🔧 第二步看并集覆盖区： 从最左端 \(-1\)（实心）一路连通覆盖到最右端 \(5\)（实心）。虽然 \(3\) 不在 \(A\) 中，但 \(B\) 包含它（\(3 \in B\)），直接填补铺满！故 \(A\cup B=\{x\mid -1\le x\le 5\}\)。
🛡️ 第三步挖洞算补集（实变空、空变实）： 全集 \(\mathbf R\) 挖去 \(A\)：左侧从 \(-1\) 往左，因为 \(-1\in A\) 被挖走，补集变成空心（\(x<-1\)）；右侧从 \(3\) 往右，因为 \(3\notin A\) 未被挖走，留在补集里变成实心（\(x\ge 3\)）！故 \(\complement_{\mathbf R}A=\{x\mid x<-1\text{ 或 }x\ge 3\}\)。

自己试试：\(A=\{x\mid x\le 2\}\)，全集 \(\mathbf R\)。\(\complement_{\mathbf R}A=\)？

A。\(2\) 在 \(A\) 里，补集就不能再要它。选 B 的同学把「反过来」只改了方向，没管端点：那样 \(2\) 同时在 \(A\) 和补集里，不可能。

自己试试：已知 \(A\cup B=B\)。下面哪句一定对？

B。把 \(A\) 并进来，\(B\) 一点没变，说明 \(A\) 的元素本来就都在 \(B\) 里。不一定相等：上面的 \(A=\{1,2\}\)，\(B=\{1,2,3\}\) 就满足。在「动手」① 的 Venn 图里，把所有 A 的数都改成「两个都在」，再看 \(A\cup B\) 和 \(B\)。

4. 用之前必查：三大高频翻车现场

翻车现场 ①求补集时，端点等号未按「实变空、空变实」翻转
❌ 典型错解：全集为 \(\mathbf R\)，已知 \(A=\{x\mid x\le 2\}\)，随手写出 \(\complement_{\mathbf R}A=\{x\mid x\ge 2\}\)。
✅ 一眼看清真相：\(x=2\) 本来属于 \(A\)！如果补集也带等号，就会导致 \(2\) 既在集合中又在补集中，产生悖论！原集合有等号（实心），补集绝对不能带等号（空心），必须是 \(x>2\)！
翻车现场 ②求并集时重复元素未去重
❌ 典型错解：\(A=\{1,3,5\}, B=\{3,5,8\}\)，计算并集元素个数写成 \(3+3=6\) 个。
✅ 一眼看清真相：集合具有互异性，两边都有的元素 \(3,5\) 并入集合后只能保留一份！实际并集为 \(\{1,3,5,8\}\)（容斥公式：\(n(A\cup B)=n(A)+n(B)-n(A\cap B)=3+3-2=4\) 个非重元素）。
翻车现场 ③（高考最高频！）看到 \(A \cup B = B\) 误判为 \(B \subseteq A\)
❌ 典型错解：以为「\(A \cup B = B\)」意味着 \(B\) 包含于 \(A\)。
✅ 看右图秒懂真相：\(A\) 并入 \(B\) 后，\(B\) 毫发未变，说明 \(A\) 原本就是 \(B\) 的一部分，其实是小在大肚子里（\(A \subseteq B\)）！
再深一点（可以先跳过）

德·摩根定律（反演律）：\(\complement_U(A\cup B)=\complement_U A\cap\complement_U B\)，\(\complement_U(A\cap B)=\complement_U A\cup\complement_U B\)。

容斥原理：有限集合中，\(n(A\cup B) = n(A) + n(B) - n(A\cap B)\)。入口的例子：\(4+3-2=5\) 人。

先看元素是什么：\(\{(x,y)\mid y=x\}\cap\{(x,y)\mid y=2-x\}\) 的元素是点，交集是 \(\{(1,1)\}\)，不能写成 \(\{1\}\)。

① Venn 图：点数字，把它放进 A、B

全集 \(U=\{1,2,\dots,12\}\)。点一个数字，它会在「都不在 → 只在 A → 只在 B → 两个都在」之间切换。再点上面的运算，看哪些数被选中。

② 进阶：数轴上拖端点，看交、并、补

拖动圆点（或选中后按方向键）改端点；点端点下面的按钮（或选中圆点按空格）切换「取到 ● / 取不到 ○」。全集是全体实数 \(\mathbf R\)。试试让两段只在一个端点处相碰，再切换这个端点。

端点：

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(A\) 是小于 \(10\) 的正奇数组成的集合，\(B=\{3,6,9\}\)。\(A\cap B=\)？

B。先把 \(A\) 列出来：\(A=\{1,3,5,7,9\}\)。和 \(B\) 都有的是 \(3\)、\(9\)。选 C 的同学把 \(6\) 也算进去了，可 \(6\) 不是奇数；D 是并集。

2. \(A=\{x\mid -2<x\le 3\}\)，\(B=\{x\mid x>1\}\)。\(A\cup B=\)？

A。画数轴：\(A\) 从 \(-2\) 盖到 \(3\)，\(B\) 从 \(1\) 往右一直盖下去，合起来是 \(-2\) 右边的全部。\(-2\) 两个集合都不含，取不到。B 是交集；C 把端点 \(-2\) 算进去了；D 漏了 \(3\) 右边那一段。

易错

3. \(A=\{x\mid x<2\}\)，\(B=\{x\mid x\ge 1\}\)。\(A\cap B\) 是什么？

B（端点）。这里的 \(x\) 没说是整数，所以 \(1\) 和 \(2\) 之间的 \(1.5\)、\(1.99\) 都在两个集合里。

选 A 或 C 的同学，是把它们当成了整数；选 D 的同学，是看到符号方向相反就以为没有交集。画一条数轴，两段一叠就看出来了：左端 \(1\) 取到（\(\ge\)），右端 \(2\) 取不到（\(<\)）。

4. \(A=\{x\mid x<2\}\)。如果全集 \(U=\mathbf Z\)（全体整数），\(\complement_U A\) 是什么？

C（全集）。补集只能在全集里找。全集是整数，补集里就只有整数，是 \(\{x\in\mathbf Z\mid x\ge 2\}\)。A 是 \(U=\mathbf R\) 时的答案；B 把端点 \(2\) 弄丢了：\(A\) 取不到 \(2\)，补集就取到 \(2\)。

5. \(A=\{1,3\}\)，\(B=\{2,4\}\)。\(A\cap B\) 应该写成？

A（空集）。没有公共元素，交集就是空集 \(\varnothing\)。\(\{0\}\) 有一个元素 \(0\)；\(\{\varnothing\}\) 有一个元素（这个元素是空集）；\(0\) 是数，不是集合。

挑战

6. \(B=\{x\mid 1\le x\le 4\}\)，\(A=\{x\mid m\le x\le 2m\}\)，且 \(A\cap B=A\)。\(m\) 的取值范围是？

B。\(A\cap B=A\) 就是 \(A\subseteq B\)。带字母，先想空集：

\(m>2m\)，即 \(m<0\) 时，\(A=\varnothing\)，空集是 \(B\) 的子集，满足。

\(m\ge 0\) 时 \(A\) 不空，要整段落在 \([1,4]\) 里：\(m\ge 1\) 且 \(2m\le 4\)，得 \(1\le m\le 2\)。（\(m=0\) 时 \(A=\{0\}\)，\(0\) 不在 \(B\) 里，不行。）

合起来是 B。选 A 的同学漏了空集；选 C、D 的同学没检查 \(0\le m<1\)：比如 \(m=0.5\)，\(A=\{x\mid 0.5\le x\le 1\}\)，\(0.5\) 不在 \(B\) 里。

选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
