整数加法运算定律推广到分数

整数加法的交换律、结合律，用在分数加法里还管用吗？怎样算更简便？

本单元按旧版教材编排。

+ + ，怎样算比较简便？

B。 + = 1，再加 ，一下子就算出来了。整数的加法运算定律，在分数里同样适用。

1. 哪种算法简便

同一道题，两种算法，比一比。

自己试试 1

+ + = + + ，这一步用了什么定律？

A。把 和 交换了位置，用的是加法交换律。

自己试试 2

接着 ( + ) + ，加了括号，用了什么定律？

B。先把前两个数结合起来，用的是加法结合律。

记住这句话 整数加法的交换律 a + b = b + a、结合律 (a + b) + c = a + (b + c)，对分数加法同样适用。简便计算时，先把分母相同、能凑成整数的分数结合起来。
对：同分母的先凑

分母相同的分数先加，常常能凑成 1。

错：看到括号就通分

先想想有没有更简便的结合方法。

对：加法定律对分数也适用

换位置、加括号，结果不变。

错：减法也能随便加括号

a − b − c 不等于 a − (b − c)。

为什么加法定律对分数也成立？

加法交换律、结合律说的是“数加起来”的规律，不管加数是整数还是分数，把量合在一起，先合哪部分结果都一样。
