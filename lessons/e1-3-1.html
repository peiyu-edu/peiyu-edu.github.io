3.1 椭圆

从圆的一个圆心，到椭圆的两个焦点：固定一根无弹性细绳的两端，用笔尖把绳子绷紧绕一圈，画出来的对称饱满曲线就是椭圆。到两焦点距离之和恒为定值 \(2a\)，这一几何核心决定了它的标准方程、扁平程度与全部性质。

木工师傅或园艺工人要在大片板材或草地上画出一个优美对称的椭圆时，常常使用一个流传久远的木工妙法：找两根钉子作为定点钉在板上，取一条比两钉间距更长的无弹性细绳，将绳的两端分别系在两根钉子上。用笔尖套住绳子并向外拉直，在板面上贴紧滑动绕行一周，就能画出一个完美的椭圆。

假定两根图钉相距 \(6\text{ cm}\)。如果改变绳子的长度，会发生什么有趣的变化？

如果换用一根长度正好只有 \(6\text{ cm}\) 的无弹性绳子，两端依然固定在相距 \(6\text{ cm}\) 的两颗图钉上，笔尖拉直绳子尝试画图，最终能在纸上留下怎样的图形？

B。两颗图钉间的直线距离为 \(6\text{ cm}\)，绳长也恰好为 \(6\text{ cm}\)。

当笔尖把绳子绷直时，笔尖到两颗图钉的距离之和等于 \(6\text{ cm}\)。根据公理「两点之间线段最短」，平面内到两定点距离之和等于两定点间距的点，只能位于两图钉连接的线段上！只要笔尖稍微偏离这条线段，它与两图钉就会构成一个三角形，两边之和必然大于第三边（即大于 \(6\text{ cm}\)），长度为 \(6\text{ cm}\) 的绳子根本够不着。

因此轨迹退化成了一条线段，无法张开成椭圆。要想画出真正的、饱满的椭圆，绳长必须严格大于两定点间的距离（\(2a > 2c\)）！这正是本节要深入探讨的椭圆定义与几何本质。

1. 先认识几个词

要用到：直角坐标系、两点间距离公式（回看 2.3）。

焦点与焦距：

  • 焦点：确定椭圆位置的两个定点，记作 \(F_1, F_2\)。
  • 焦距：两焦点间的距离 \(|F_1F_2|\)，记作 \(2c\)（特别提醒：焦距是 \(2c\)，不是 \(c\)；\(c\) 叫半焦距）。

例：焦点为 \(F_1(-4, 0), F_2(4, 0)\)，则半焦距 \(c = 4\)，焦距是 \(2c = 8\)。

长轴与短轴：

  • 长轴：椭圆对称轴被椭圆截得的较长线段，长轴长为 \(2a\)（半长轴长为 \(a\)）。
  • 短轴：与长轴垂直平分的较短线段，短轴长为 \(2b\)（半短轴长为 \(b\)）。

例：长轴长为 \(10\)，则 \(a = 5\)；短轴长为 \(6\)，则 \(b = 3\)。在椭圆中必有 \(a > b > 0\)。

离心率 \(e\)：

半焦距与半长轴的比值：\(e = \dfrac{c}{a}\)。因为 \(0 < c < a\)，所以 \(e \in (0, 1)\)。它刻画了椭圆的扁平程度：\(e\) 越接近 \(1\) 椭圆越扁；\(e\) 越接近 \(0\) 椭圆越圆。

2. 定义：绳长要比两钉间距长

椭圆：平面内到两个定点 \(F_1, F_2\) 的距离之和等于常数 \(2a\)，并且 \(2a\) 大于 \(|F_1F_2|=2c\) 的点的轨迹。

为什么要加「大于」：三角形两边之和大于第三边，所以任何点都有 \(|PF_1|+|PF_2|\ge|F_1F_2|\)，等号只在 \(P\) 落在线段 \(F_1F_2\) 上时成立。常数 \(2a\) 和 \(2c\) 比一比，结果就分成三种：

① \(2a > 2c\)：轨迹是椭圆；
② \(2a = 2c\)：轨迹是线段 \(F_1F_2\)；
③ \(2a < 2c\)：没有这样的点。

例 1（看一遍怎么写）

\(F_1(-3,0)\)，\(F_2(3,0)\)。动点 \(P\) 满足 \(|PF_1|+|PF_2|\) 分别等于 \(10\)、\(6\)、\(5\)，轨迹各是什么？在第一种情形里，若 \(|PF_1|=3\)，求 \(|PF_2|\)。

两定点距离 \(|F_1F_2|=3-(-3)=6\)，即 \(2c=6\)。

和为 \(10\)：\(10>6\)，是椭圆。验一个点：\(P(5,0)\) 到两点距离 \(8\) 和 \(2\)，和是 \(10\)，在轨迹上。

和为 \(6\)：\(6=6\)，是线段 \(F_1F_2\)，不是椭圆。

和为 \(5\)：\(5<6\)，任何点到两点距离之和都至少是 \(6\)，没有轨迹。

第一种情形：\(|PF_1|+|PF_2|=10\)，所以 \(|PF_2|=10-3=7\)。

自己试试：\(F_1(0,-5)\)，\(F_2(0,5)\)，动点 \(P\) 满足 \(|PF_1|+|PF_2|=8\)。\(P\) 的轨迹是？

C。\(|F_1F_2|=5-(-5)=10\)，而和只有 \(8\)，\(8<10\)，到两点距离之和不可能比两点间距还小。选 A 是一看到「距离之和为常数」就说椭圆，没先拿常数和 \(|F_1F_2|\) 比；常见的还有把 \(|F_1F_2|\) 算成 \(5\)（漏了它是 \(2c\)），误以为 \(8>5\)。

3. 标准方程：焦点在哪条轴

以两焦点连线为一条坐标轴、线段 \(F_1F_2\) 的中点为原点建系。焦点在 \(x\) 轴上时，定义写成

\(\sqrt{(x+c)^2+y^2}+\sqrt{(x-c)^2+y^2}=2a\)，

移项、平方两次整理，再令 \(b^2=a^2-c^2\)（因为 \(a>c>0\)，它是正数），得到标准方程：

  • 焦点在 \(x\) 轴上：\(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\)（\(a>b>0\)），焦点 \((\pm c,0)\)。
  • 焦点在 \(y\) 轴上：\(\dfrac{y^2}{a^2}+\dfrac{x^2}{b^2}=1\)（\(a>b>0\)），焦点 \((0,\pm c)\)。
先把方程化成「右边是 \(1\)、两项分母都为正」的样子，再比分母：哪个分母大，焦点就在哪条轴上，大分母是 \(a^2\)。

例 2

椭圆的焦点在 \(y\) 轴上，焦距为 \(6\)，且经过点 \((4,0)\)。求它的标准方程。

焦点在 \(y\) 轴上，设 \(\dfrac{y^2}{a^2}+\dfrac{x^2}{b^2}=1\)（\(a>b>0\)）。

焦距 \(2c=6\)，所以 \(c=3\)。

点 \((4,0)\) 代入：\(0+\dfrac{16}{b^2}=1\)，得 \(b^2=16\)。

\(a^2=b^2+c^2=16+9=25\)。所以方程是 \(\dfrac{y^2}{25}+\dfrac{x^2}{16}=1\)。

检查：\(a=5>b=4\)，焦点 \((0,\pm3)\) 确实在 \(y\) 轴上。点 \((4,0)\) 在 \(x\) 轴上，这里是短轴端点，不能直接把 \(4\) 当成 \(a\)。

自己试试：椭圆 \(4x^2+y^2=4\) 的焦点坐标是？

B。两边除以 \(4\)：\(x^2+\dfrac{y^2}{4}=1\)，即 \(\dfrac{x^2}{1}+\dfrac{y^2}{4}=1\)。\(y^2\) 的分母 \(4\) 大，焦点在 \(y\) 轴上，\(a^2=4\)，\(b^2=1\)，\(c^2=4-1=3\)。选 A 是没化成标准形式，把系数 \(4\) 当成了 \(x^2\) 的分母；选 C 是把 \(c^2\) 算成了 \(a^2+b^2\)。

4. 几何性质：\(a\)、\(b\)、\(c\) 和离心率

从方程 \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\)（\(a>b>0\)）直接读出：

  • 范围：两项都不超过 \(1\)，所以 \(-a\le x\le a\)，\(-b\le y\le b\)。
  • 对称：把 \(x\) 换成 \(-x\)、\(y\) 换成 \(-y\)，方程不变，所以关于两条坐标轴和原点都对称。
  • 顶点：\((\pm a,0)\)、\((0,\pm b)\)，长轴长 \(2a\)，短轴长 \(2b\)。
\(a^2=b^2+c^2\)，\(a\) 最大。原因：短轴端点到焦点的距离正好是 \(a\)（它到两焦点一样远，和是 \(2a\)），它和原点、焦点围成直角三角形，直角边 \(b\)、\(c\)，斜边 \(a\)。
离心率 \(e=\dfrac{c}{a}\in(0,1)\)，而 \(\dfrac{b}{a}=\sqrt{1-e^2}\)：\(e\) 越大，\(b\) 比 \(a\) 小得越多，椭圆越扁。

例 3

椭圆 \(16x^2+25y^2=400\)，求范围、顶点、焦点、长轴长、短轴长、焦距和离心率。

两边除以 \(400\)：\(\dfrac{x^2}{25}+\dfrac{y^2}{16}=1\)。\(25>16\)，焦点在 \(x\) 轴上，\(a=5\)，\(b=4\)，\(c=\sqrt{25-16}=3\)。

  • 范围：\(-5\le x\le5\)，\(-4\le y\le4\)；顶点 \((\pm5,0)\)、\((0,\pm4)\)；
  • 焦点 \((\pm3,0)\)；
  • 长轴长 \(2a=10\)，短轴长 \(2b=8\)，焦距 \(2c=6\)（都是「2 倍」，不是 \(a,b,c\) 本身）；
  • 离心率 \(e=\dfrac{c}{a}=\dfrac35\)。

自己试试：椭圆 \(\dfrac{x^2}{4}+\dfrac{y^2}{9}=1\) 的焦点坐标和离心率分别是？

B。\(9>4\)，焦点在 \(y\) 轴上，\(a=3\)，\(b=2\)，\(c=\sqrt{9-4}=\sqrt5\)，焦点 \((0,\pm\sqrt5)\)，\(e=\dfrac{c}{a}=\dfrac{\sqrt5}{3}\)。

选 A、D 是没比分母，把焦点放到了 \(x\) 轴上（A 还拿小分母当了 \(a\)）；选 C 是把 \(\dfrac{c^2}{a^2}\) 当成了离心率。

5. 直线和椭圆：联立看交点

直线和椭圆有几个公共点，就看联立方程组有几组解。把直线代入椭圆消去一个字母，得到一元二次方程，用判别式 \(\Delta\) 判断：\(\Delta>0\) 两个交点（相交），\(\Delta=0\) 一个（相切），\(\Delta<0\) 没有（相离）。

两点要先想到：竖直的直线 \(x=t\) 没有斜率，不能设成 \(y=kx+m\)，要单独算；用 \(\Delta\) 之前先确认消元后真的是二次方程。

例 4

直线 \(y=x+m\) 与椭圆 \(\dfrac{x^2}{4}+y^2=1\)。\(m\) 取什么值时有两个交点？\(m=1\) 时求交点和弦长。

代入并两边乘 \(4\)：\(x^2+4(x+m)^2=4\)，整理得

\(5x^2+8mx+4m^2-4=0\)。

\(x^2\) 系数是 \(5\neq0\)，是二次方程。

\(\Delta=64m^2-20(4m^2-4)\)
\(=80-16m^2\)。

\(\Delta>0\iff m^2<5\iff-\sqrt5<m<\sqrt5\)，这时有两个交点；\(m=\pm\sqrt5\) 时相切；\(|m|>\sqrt5\) 时没有交点。

\(m=1\)：方程变成 \(5x^2+8x=0\)，\(x=0\) 或 \(x=-\dfrac85\)。交点 \((0,1)\)、\(\left(-\dfrac85,-\dfrac35\right)\)。

验第二个点：\(\dfrac{64/25}{4}+\dfrac{9}{25}=\dfrac{16}{25}+\dfrac{9}{25}=1\)，在椭圆上。

弦长 \(=\sqrt{\left(\dfrac85\right)^2+\left(\dfrac85\right)^2}=\dfrac{8\sqrt2}{5}\)。

自己试试：直线 \(x=1\) 被椭圆 \(\dfrac{x^2}{4}+\dfrac{y^2}{3}=1\) 截得的弦长是？

B。\(x=1\) 直接代入：\(\dfrac{y^2}{3}=1-\dfrac14=\dfrac34\)，\(y^2=\dfrac94\)，\(y=\pm\dfrac32\)。两个交点 \(\left(1,\pm\dfrac32\right)\)，弦长 \(\dfrac32-\left(-\dfrac32\right)=3\)。选 A 是只取了正根；选 C 是漏乘了分母 \(3\)；选 D 是只会套 \(y=kx+m\)，竖直线直接代入反而最简单。

6. 用之前要注意

  1. 常数要大于两焦点间距，\(2a>2c\) 才是椭圆。
    反例：\(F_1(-3,0)\)、\(F_2(3,0)\)，和为 \(6\) 时只是线段 \(F_1F_2\)；和为 \(5\) 时没有点。
  2. \(a=b\) 是圆，不按本节的椭圆处理（这时 \(c=0\)，两焦点重合，没有离心率 \(e\in(0,1)\) 那一套）。
    反例：\(\dfrac{x^2}{4}+\dfrac{y^2}{4}=1\) 是半径 \(2\) 的圆，不能说「焦点在 \(x\) 轴上，\(e=0\) 的椭圆」。
  3. 先判长轴方向，再读 \(a,b,c\)：大分母才是 \(a^2\)，不一定在 \(x^2\) 下面。
    反例：\(\dfrac{x^2}{4}+\dfrac{y^2}{9}=1\) 的 \(a=3\)，不是 \(2\)。
  4. 焦距是 \(2c\)、长轴长是 \(2a\)、短轴长是 \(2b\)，不是 \(c,a,b\)。
    反例：「焦距为 \(8\)」说的是 \(c=4\)，不是 \(c=8\)。
  5. 含参数的方程要表示椭圆：两个分母都为正、且不相等；要求焦点在某条轴，还要那条轴的分母更大。
    反例：\(\dfrac{x^2}{m}+\dfrac{y^2}{2}=1\) 中 \(m=2\) 是圆，\(m=-1\) 根本不是椭圆。
  6. 直线和椭圆联立：竖直线单独算；用 \(\Delta\) 前确认是二次方程。
    反例：\(x=1\) 设成 \(y=kx+m\) 是设不出来的（例 4 后的「自己试试」）。
  7. 画图的绳子要一直拉紧：绳子松了，笔尖落在椭圆里面，那些点到两钉距离之和小于绳长，不在椭圆上。
再深一点：焦半径与焦点三角形（可以先跳过）

① 焦半径公式：对于焦点在 \(x\) 轴上的椭圆 \(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\)，若椭圆上有点 \(P(x_0, y_0)\)，则点 \(P\) 到左、右焦点的距离分别为：

\(|PF_1| = a + ex_0, \quad |PF_2| = a - ex_0\)

两式直接相加恒为 \(2a\)。椭圆上的点到焦点的最小距离为 \(a - c\)（长轴近端点），最大距离为 \(a + c\)（长轴远端点）。

② 焦点三角形面积公式：若 \(P\) 是椭圆上不与长轴端点重合的动点，\(\angle F_1PF_2 = \theta\)，则 \(\triangle F_1PF_2\) 的面积为：

\(S_{\triangle F_1PF_2} = b^2 \tan\dfrac{\theta}{2}\)

推导巧妙运用了余弦定理与椭圆定义：\(|PF_1|^2 + |PF_2|^2 - 2|PF_1||PF_2|\cos\theta = 4c^2\)，展开并代入 \(|PF_1|+|PF_2|=2a\)，即可消去未知焦半径，得到这一简洁漂亮的结论。

双焦点拉线与椭圆微实验室

拖动椭圆上的动点 \(P\)（或按键盘方向键），观察双焦半径 \(PF_1\)（绿线）与 \(PF_2\)（金线）的变化；下方实时展示「拉直绳线对比条」，直观验证无论 \(P\) 滑到哪里，两段距离之和恒等于 \(2a\)。调节滑块观察离心率 \(e\) 和扁平度；点击预设反例查看 \(2a = 2c\) 时椭圆如何退化为线段。

从易到难排好了。前两题检验标准方程与基本量计算，后三题针对高考与诊断中最常踩的五大陷阱。

直接用

1. 已知椭圆方程为 \(\dfrac{x^2}{16} + \dfrac{y^2}{25} = 1\)，则该椭圆的长轴长、焦距和离心率分别为？

A。比较分母：\(25 > 16\)，所以 \(a^2 = 25 \implies a = 5\)，\(b^2 = 16 \implies b = 4\)。

由 \(a^2 = b^2 + c^2\) 得 \(c^2 = 25 - 16 = 9 \implies c = 3\)。

因此长轴长为 \(2a = 10\)（不是 \(a=5\)）；焦距为 \(2c = 6\)（不是 \(c=3\)）；离心率 \(e = \dfrac{c}{a} = \dfrac{3}{5} = 0.6\)。

选 B 的同学错把半长轴和半焦距当成了长轴长与焦距；选 C 的同学误把小分母当成了长半轴。

2. 已知点 \(F_1(-4, 0), F_2(4, 0)\) 是椭圆 \(\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1\) 的两个焦点，点 \(P\) 在该椭圆上运动。若 \(|PF_1| = 7\)，则 \(|PF_2|\) 的长度为？

B。直接用定义：方程中 \(a^2 = 25 \implies a = 5\)，因此定值 \(2a = 10\)。

验证焦距：\(c = \sqrt{25 - 9} = 4\)，两焦点恰为 \(F_1(-4, 0), F_2(4, 0)\)。根据椭圆的第一定义，椭圆上的任意点 \(P\) 到两焦点距离之和恒等于 \(2a\)：

\(|PF_1| + |PF_2| = 2a = 10\)

代入已知 \(|PF_1| = 7\)，解得 \(|PF_2| = 10 - 7 = 3\)。选 A 的同学误以为焦半径之差为定值（混淆了双曲线）。

易错

3. （边界 1：定义退化）平面内动点 \(P\) 到两定点 \(F_1(-3, 0), F_2(3, 0)\) 的距离之和满足 \(|PF_1| + |PF_2| = 6\)，则点 \(P\) 的轨迹是？

B。计算两定点间距离：\(|F_1F_2| = 3 - (-3) = 6\)。

条件中距离之和 \(2a = 6\)，此时恰好满足 \(2a = 2c = 6\)！

根据公理「两点之间线段最短」，当且仅当点 \(P\) 在线段 \(F_1F_2\) 上时，才满足 \(|PF_1| + |PF_2| = |F_1F_2| = 6\)。若 \(P\) 不在连线段上，由三角形两边之和大于第三边，距离之和必定严格大于 \(6\)。

因此轨迹退化成了线段 \(F_1F_2\)，不是椭圆！只有满足 \(2a > 2c\) 时，轨迹才是真正的椭圆。如果 \(2a < 2c\)，则无轨迹。

4. （边界 3：含参方程与焦点轴向）方程 \(\dfrac{x^2}{m+2} + \dfrac{y^2}{5-m} = 1\) 表示焦点在 \(y\) 轴上的椭圆，则实数 \(m\) 的取值范围是？

C。表示椭圆且焦点在 \(y\) 轴上，必须同时满足三个硬性条件：

  1. \(x^2\) 项的分母必须大于 \(0\)：\(m + 2 > 0 \implies m > -2\)；
  2. \(y^2\) 项的分母必须大于 \(0\)：\(5 - m > 0 \implies m < 5\)；
  3. 焦点在 \(y\) 轴要求 \(y^2\) 项分母严格大于 \(x^2\) 项分母：\(5 - m > m + 2 \implies 2m < 3 \implies m < 1.5\)。

取三者交集，解得 \(-2 < m < 1.5\)。

选 A 的同学忽略了焦点必须在 \(y\) 轴（只列了分母为正）；选 B 的同学漏掉了 \(m + 2 > 0\)（当 \(m \le -2\) 时分母非正，根本不是椭圆）；选 D 的同学把焦点算到 \(x\) 轴上了。

5. （边界 2 & 4 & 5：几何量混淆与短轴长）已知椭圆的两个焦点间的距离是 \(8\)，椭圆的离心率 \(e = \dfrac{4}{5}\)，则该椭圆的短轴长为？

B。抓住词条的核心定义：

  • 两焦点间的距离是焦距 \(2c = 8 \implies c = 4\)（警惕：不能误记为 \(c=8\)！）；
  • 由 \(e = \dfrac{c}{a} = \dfrac{4}{5}\)，得半长轴 \(a = \dfrac{c}{e} = \dfrac{4}{4/5} = 5\)；
  • 由椭圆几何量关系 \(a^2 = b^2 + c^2\)（\(a\) 是老大！），得 \(b^2 = a^2 - c^2 = 25 - 16 = 9 \implies b = 3\)；
  • 题目问的是短轴长，短轴长是 \(2b = 2 \times 3 = 6\)（易错陷阱：\(b=3\) 是半短轴长，不是短轴长！）。

选 A 的同学在最后一步把半短轴长 \(b=3\) 当作了短轴长；选 C 的同学算出了长轴长 \(2a=10\)。
