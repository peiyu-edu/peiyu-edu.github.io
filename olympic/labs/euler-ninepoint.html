原创互动实验

欧拉线与九点圆

拖动三角形顶点 A 或底边端点 C，观察外心 O、重心 G、九点圆心 N、垂心 H 始终共线且保持 OG : GN : NH = 2 : 1 : 3，九个特征点始终共圆且半径恒为 R/2。

改变条件

先预测，再核对

先由外接圆半径 R 估算九点圆半径 R₉=R/2，再核对你的预测（误差允许 0.02；共线或顶点重合退化 yₐ=0 时有限九点圆无有效定义）。

为什么成立，边界在哪里

在非退化 △ABC 中，以重心 G 为位似中心、位似比 −1/2 作位似变换，原三角形顶点 A、B、C 映为三边中点 Ma、Mb、Mc。于是 △ABC 的三条高线（交于垂心 H）映为中点三角形的三条高线——即原三角形的三条中垂线（交于外心 O），故 H 的位似像为 O。由此立得向量关系 GO⃗ = −(1/2)·GH⃗，而 GO⃗ = −OG⃗，故 GH⃗ = −2·GO⃗ = 2·OG⃗，进而 OH⃗ = OG⃗ + GH⃗ = 3·OG⃗：外心 O、重心 G、垂心 H 三点按顺序共线（欧拉线）且 |OG| : |GH| = 1 : 2。例如取有理坐标 A=(0, 1)、B=(−2, 0)、C=(2, 0)，由中垂线与高线可直接算出 O=(0, −3/2)、G=(0, 1/3)、H=(0, 4)，此时 OG⃗=(0, 11/6)，GH⃗=(0, 11/3)=2·OG⃗=−2·GO⃗，OH⃗=(0, 11/2)=3·OG⃗。

再以垂心 H 为位似中心、位似比 1/2 作位似变换，顶点 A、B、C 映为垂心与顶点连线的中点（欧拉点 Ea、Eb、Ec），外接圆 ω(O, R) 映为以 OH 中点 N = (O + H)/2 为圆心、半径 R₉ = R/2 的圆。由重心位似知三边中点 Ma、Mb、Mc 也在此圆上；由上述向量关系可得 Ei 与 Mi 的中点均为 N，且非退化三角形的 R > 0，故 Ei 与 Mi 不同，每条线段 EiMi 为该圆直径。对每个高线垂足 Hi，分两种情形：若 Hi 与 Ei 或 Mi 重合，它已是该圆上的直径端点，无需作角；否则 HiEi 沿相应高线，HiMi 沿相应边所在直线，两条射线均有定义且互相垂直，于是 ∠EiHiMi = 90°，由直径所对圆周角的逆定理知 Hi 在该圆上。因此三个垂足 Ha、Hb、Hc 同样落在该圆上——九点共圆于 ω₉(N, R/2)，且沿欧拉线有 ON⃗ = (3/2)·OG⃗，即有向线段比 OG : GN : NH = 2 : 1 : 3。

边界与特殊姿态：（1）当 xa² + ya² = b² 或 |xa| = b 时，△ABC 为直角三角形，垂心 H 与直角顶点重合，外心 O 落在斜边中点；（2）当 xa = 0 且 ya = √3·b 时，△ABC 为正三角形，O、G、N、H 四心完全重合（|OH| = 0），欧拉线退化为一点，但九点圆半径 R₉ = b/√3 > 0 依然有限且与内切圆重合（因 √3 为无理数，滑条步长 0.02 下如 b=2, xa=0, ya=3.46 为网格近似正三角形态，此时 |OH|≈0.0041 极小；精确 ya=2√3≈3.4641 处 |OH|=0）；（3）当 ya = 0 时，A、B、C 三点共线（或顶点重合），退化为线段，有限外接圆与九点圆无有效定义（R₉ 无定义）。且固定 xa, b 令 ya = h → 0⁺ 时的极限取决于 xa² 与 b² 是否相等：① 当 xa² ≠ b²（A 趋向直线 BC 上异于 B, C 的点）时，外接圆半径 R ~ |xa²−b²|/(2h)、九点圆半径 R₉ = R/2 = √(((xa+b)²+h²)((xa−b)²+h²))/(4h) ~ |xa²−b²|/(4h)，均 → +∞ 发散（例如 xa=0, b=2 时 R₉=(h²+4)/(4h) 在 h=1, 0.1, 0.01, 0.001 时依次为 1.25, 10.025, 100.0025, 1000.00025 → +∞）；② 当 xa = ±b（端点重合边界路径，如 xa=b=2, A=(2,h)→C）时，每个 h>0 下 △ABC 在 C（或 B）处成直角，外心 O=(0, h/2)，九点圆半径 R₉ = √(4b²+h²)/4 = √(b²+h²/4)/2 → b/2 有限收敛（例如 xa=b=2 时 R₉=√(4+h²/4)/2 在 h=0.1, 0.01, 0.001, 0.0001 时依次约为 1.000312, 1.000003, 1.00000003, 1.0000000003 → 1，不发散），但在 ya=0 处 A 与端点重合、三点退化为线段，有限九点圆仍无有效定义。
