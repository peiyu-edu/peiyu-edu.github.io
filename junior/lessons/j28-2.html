把一个图形绕着某一个点旋转 \(180^\circ\)，如果旋转后的图形能够与原来的图形重合，这种特殊的旋转变换就是中心对称。

1. 先认识几个词：什么是中心对称与中心对称图形？

中心对称

绕中心旋转 180° 后与另一图形重合。

轴对称

沿直线折叠后重合；一条对称轴不能替代中心。

抓住关系： \(\color{#2F7A56}{\underbrace{OA}_{\text{原距离}}}=\color{#966524}{\underbrace{OA\prime}_{\text{对应距离}}}\)

先检查条件，再使用关系；彩色标注帮助区分量。

前置知识：旋转的定义（回看 28.1）。中心对称是旋转角为 \(180^\circ\) 的特殊旋转，需严格分清以下两个词：

  • 中心对称（两个图形）：把一个图形绕着某一点旋转 \(180^\circ\)，如果它能够与另一个图形重合，那么就说这两个图形关于这个点成中心对称（central symmetry）。该点叫作对称中心，两个图形中的对应点叫作关于中心的对称点。
  • 中心对称图形（一个图形自身）：把一个图形绕着某一点旋转 \(180^\circ\)，如果旋转后的图形能够与原来的图形自身重合，那么这个图形叫作中心对称图形。这个点就是它的对称中心。
  • 本质区别：中心对称是指「两个图形的位置关系」；中心对称图形是指「一个图形本身的几何对称特征」。

2. 中心对称的核心几何性质：中点平分与线段平行

中心对称作为旋转角为 \(180^\circ\) 的特殊旋转，对应点连线与中心共线，呈现出独特的几何性质：

  • 中点性质：中心对称的两个图形，对称点所连线段都经过对称中心，而且被对称中心平分（即对称中心是任意一对对应点连线段的中点）。
  • 图形全等：中心对称的两个图形是全等形，对应线段相等，对应角相等。
  • 平行性：对应线段互相平行（或者在同一条直线上），且长度相等。

直觉微图解 ②中点平分与共线性：A-O-A' 三点一线且 OA = OA'

自己试试 2：已知点 \(A\) 和点 \(A'\) 关于点 \(O\) 成中心对称，若点 \(A\) 的坐标为 \((-2, 3)\)，对称中心为原点 \(O(0, 0)\)，则点 \(A'\) 的坐标是（ ）

A。因为点 \(A\) 与点 \(A'\) 关于原点中心对称，原点 \(O\) 是线段 \(AA'\) 的中点。

设 \(A'(x', y')\)，由中点坐标公式 \(\frac{-2 + x'}{2} = 0, \frac{3 + y'}{2} = 0\)，直接解得 \(x' = 2, y' = -3\)。即两个关于原点对称的点，横纵坐标互为相反数。

作图心法：如何作出一个图形关于已知点 O 对称的图形？
  1. 连线：连接图形的各个关键顶点与对称中心 \(O\)；
  2. 延长：将连线向另一侧延长；
  3. 截取等长：在延长线上截取与原线段等长的线段，找到各对应点（即取各顶点关于点 \(O\) 的对称点）；
  4. 顺次连接：顺次连接所有对称点，得到成中心对称的图形。
典例 1（波利亚四步法）：过对称中心的直线平分平行四边形

【例 1】平行四边形 \(ABCD\) 的对角线 \(AC, BD\) 相交于点 \(O\)，过点 \(O\) 作直线 \(EF\) 分别交边 \(AB, CD\) 于点 \(E, F\)。若 \(AE = 3, EO = 2\)，求 \(CF + FO\) 的值。

  1. ① 读懂题意：点 \(O\) 是平行四边形对角线交点（即对称中心），直线 \(EF\) 经过对称中心 \(O\)，已知 \(AE = 3, EO = 2\)，求 \(CF + FO\)。
  2. ② 想办法：利用平行四边形绕中心 \(O\) 旋转 \(180^\circ\) 与自身重合的性质（或证 \(\triangle AOE \cong \triangle COF\)），找出点 \(A, E\) 的对称点。
  3. ③ 执行 + 执行中检查：平行四边形 \(ABCD\) 绕点 \(O\) 旋转 \(180^\circ\) 后，边 \(AB\) 与 \(CD\) 重合，直线 \(OE\) 与 \(OF\) 重合，故交点 \(E\) 与 \(F\) 关于点 \(O\) 对称（检查：\(\angle OAE = \angle OCF, OA = OC, \angle AOE = \angle COF \implies \triangle AOE \cong \triangle COF\)）。因此 \(CF = AE = 3\)，\(FO = EO = 2\)，故 \(CF + FO = 3 + 2 = 5\)。
  4. ④ 回头看：过平行四边形对称中心 \(O\) 的任意一条直线，不仅被点 \(O\) 平分（\(OE = OF\)），而且把平行四边形分成两个全等的图形，平分其周长和面积！

3. 直角坐标系中关于原点对称的点的坐标规律

当对称中心落在平面直角坐标系的原点 \(O\) 时，几何对称完美转化为代数上的相反数规律：

  • 核心法则：两个点关于原点对称时，它们的横坐标互为相反数，纵坐标也互为相反数，即：
  • \(P(x, y) \quad \xrightarrow{\text{关于原点对称}} \quad P'(-x, -y)\)
  • 象限对顶迁移：第一象限 \((+,+)\) 与第三象限 \((-,-)\) 互为关于原点对称；第二象限 \((-,+)\) 与第四象限 \((+,-)\) 互为关于原点对称。

直觉微图解 ③直角坐标系关于原点对称图解：对角象限投射

自己试试 3：在平面直角坐标系中，平行四边形 \(ABCD\) 的对角线交点在原点，若点 \(A\) 的坐标为 \((-3, 4)\)，则顶点 \(C\) 的坐标是（ ）

C。平行四边形是中心对称图形，其对角线交点即为对称中心。

因为对角线交点在原点，所以相对的两个顶点 \(A\) 与 \(C\) 关于原点成中心对称。由原点对称坐标法则 \((x, y) \to (-x, -y)\)，点 \(A(-3, 4)\) 的对称点 \(C\) 的坐标为 \((3, -4)\)。

口诀记忆：三类坐标对称规律横向大串联
  • 关于 \(x\) 轴对称：横坐标不变，纵坐标变相反数，即 \((x, y) \to (x, -y)\)；
  • 关于 \(y\) 轴对称：纵坐标不变，横坐标变相反数，即 \((x, y) \to (-x, y)\)；
  • 关于原点对称：横纵坐标双双变相反数，即 \((x, y) \to (-x, -y)\)；
  • 极速口诀：「关于谁对称谁不变，关于原点全变号」！
典例 2（波利亚四步法）：利用原点对称列方程求参数

【例 2】已知点 \(P(a - 1, -5)\) 与点 \(P'(3, b + 1)\) 关于原点对称，求 \(a + b\) 的值。

  1. ① 读懂题意：点 \(P\) 与 \(P'\) 关于原点对称，给出了含有未知数 \(a, b\) 的坐标表达式，求代数和 \(a + b\)。
  2. ② 想办法：根据原点对称点的特征，两点的横坐标互为相反数（相加为 \(0\)）、纵坐标互为相反数（相加为 \(0\)），列出一元一次方程分别求解 \(a\) 和 \(b\)。
  3. ③ 执行 + 执行中检查：由横坐标互为相反数得 \((a - 1) + 3 = 0 \implies a = -2\)；由纵坐标互为相反数得 \(-5 + (b + 1) = 0 \implies b = 4\)（检查：此时 \(P(-3, -5)\)，\(P'(3, 5)\)，确为原点对称）。因此 \(a + b = -2 + 4 = 2\)。
  4. ④ 回头看：用「横坐标之和 \(= 0\)、纵坐标之和 \(= 0\)」列方程，比带负号移项更不易发生符号错误。

用之前必查：三大翻车现场

翻车 1
错误：对应点在中心同侧
核对：不同于中心的对应点分居中心两侧，中心是连线中点。
翻车 2
错误：两个相反数要交换位置
核对：关于原点对称时 (2,3) 变为 (−2,−3)，不是 (−3,−2)。
翻车 3
错误：对称图形一定有对称轴
核对：一般平行四边形有对称中心，却不一定有对称轴。

A。正偶数边形（如正方形、正六边形、正八边形等）都是中心对称图形；正奇数边形（如正三角形、正五边形）不是中心对称图形。直角梯形既不是轴对称图形也不是中心对称图形。

D。根据原点对称点的坐标特征：\((x, y) \to (-x, -y)\)，点 \(P(4, -5)\) 的对称点坐标为 \((-4, 5)\)。

练习 3：在平面直角坐标系 \(xOy\) 中，正方形 \(ABCD\) 的对角线 \(AC, BD\) 相交于原点 \(O\)，若点 \(A\) 的坐标是 \((3, 1)\)，则点 \(C\) 的坐标是（ ）

B。正方形对角线交点 \(O\) 是其对称中心，相对的两个顶点 \(A\) 与 \(C\) 关于原点对称，故点 \(C\) 的坐标为 \((-3, -1)\)。

练习 4：已知点 \(M(m, 4)\) 与点 \(N(-3, n)\) 关于原点对称，则 \(m - n\) 的值是（ ）

B。由原点对称可知，横坐标互为相反数 \(m = 3\)，纵坐标互为相反数 \(n = -4\)。因此 \(m - n = 3 - (-4) = 7\)。

提示

D。因为点 \(A(x, 2)\) 与 \(B(-3, y)\) 关于原点对称，所以 \(x = 3 > 0\)，\(y = -2 \lt 0\)。横正纵负的点 \(M(3, -2)\) 位于第四象限。

易错提醒：中心对称图形的快速辨析法

试翻法：想象将试卷或手机倒过来旋转 \(180^\circ\)：

  • 如果图形看起来与原来完全一样，就是中心对称图形（例如平行四边形、英文字母 N、S、Z、汉字「日」「中」等）；
  • 如果倒过来形状颠倒了（如等边三角形尖朝下、英文字母 A、W 等），就不是中心对称图形。

巩固练习 1：在平面直角坐标系中，点 \(A(-1, 2)\) 关于原点对称的点的坐标是（　）

C。在平面直角坐标系中，点 \(P(x, y)\) 关于原点 \((0, 0)\) 对称的点的坐标为 \(P'(-x, -y)\)，即横、纵坐标同时变号．因此点 \(A(-1, 2)\) 关于原点对称的点的坐标为 \((1, -2)\)，故选 C．
