七年级下册 · 第七章 相交线与平行线

7.2 平行线

两条直线永远不相交，没法一直画下去检验，怎么才能确定？反过来，知道两条直线平行，它们和第三条直线形成的角又有什么规律？答案都藏在 7.1 的「三线八角」里。

本节导读　先修：7.1 相交线 · 本节路线

要用到：对顶角相等、邻补角互补、垂直的定义、同位角/内错角/同旁内角的识别（回看 7.1）；补角（回看 6.3）；等式的性质。

  1. 从画车位线进入：每条线和路边成同样的角，它们会相交吗？
  2. 平行线的定义（同一平面内）和关于平行线的基本事实。
  3. 判定：由「角」推出「线平行」——同位角、内错角、同旁内角。
  4. 性质：由「线平行」推出「角」的关系。
  5. 分清判定和性质，先判定、再用性质。
  6. 练习与中考真题：每一步括号里写依据。

停车场画斜车位：路边先拉一条直线，每画一条车位线，都用量角器让它和路边在同一侧成同样大的角。点下面的按钮，换几种角度，看两条车位线往上（或往下）延长会不会碰到：

工人画的每一条车位线，都和路边在同一侧成 \(55^\circ\)。这些车位线彼此是什么位置关系？

A。路边这条直线把每两条车位线都「截」了一下，截出的同位角一样大，这样的两条直线平行。角度差一点（\(55^\circ\) 和 \(65^\circ\)），延长后就会相交。

不用延长到无穷远，只看角就能判断平行——这一节要讲：由角怎样判定平行？反过来，平行时角又有什么关系？

1. 先认识几个词：平行线与平行的基本事实

前置知识：两直线相交、同位角、内错角、同旁内角（回看 7.1）。点一点，看同一张纸上两条直线的位置：

直觉微图解 ①同一平面内的两条直线：不相交，就平行

  • 平行线：在同一平面内，不相交的两条直线叫作平行线。直线 \(a\) 与 \(b\) 平行，记作 \(a\parallel b\)。
  • 在同一平面内，不重合的两条直线只有两种位置关系：相交或平行。两条线段（射线）平行，是说它们所在的直线平行。
  • 基本事实：过直线外一点，有且只有一条直线与这条直线平行。
  • 推论：如果两条直线都与第三条直线平行，那么这两条直线也互相平行（画一画就能确认）。

核心概念 ②「同一平面内」不能省

一个长方体纸盒，上底面前面那条棱和下底面右边那条棱，永远碰不到，可它们并不平行，因为不在同一个平面里。我们在一张纸上画图，说的平行都是同一平面内的。

核心概念 ③「直线外」不能省

点在直线上时，过这个点的直线要么就是原直线，要么和它相交，谈不上画平行线。所以基本事实说的是「过直线外一点」。

2. 核心点：怎样判定两直线平行（由角推出线）

直线 \(a\)、\(b\) 被直线 \(c\) 所截，八个角的编号和 7.1 一样：\(a\) 上的交点处，右上、左上、左下、右下依次是 \(\angle1\)–\(\angle4\)；\(b\) 上依次是 \(\angle5\)–\(\angle8\)。

\(\color{#2F7A56}{\underbrace{\angle1=\angle5}_{\text{同位角相等}}}\;\Rightarrow\;\color{#966524}{\underbrace{a\parallel b}_{\text{两直线平行}}}\)（基本事实）
\(\color{#2F7A56}{\underbrace{\angle3=\angle5}_{\text{内错角相等}}}\Rightarrow\color{#966524}{a\parallel b}\)，\(\quad\color{#2F7A56}{\underbrace{\angle4+\angle5=180^\circ}_{\text{同旁内角互补}}}\Rightarrow\color{#966524}{a\parallel b}\)

第一条是基本事实，后两条由它推出来（例 1）。已知的是角，要推的是线，这叫判定。简称的语序「角在前、线在后」。

直觉微图解 ②\(\angle1\) 固定为 \(62^\circ\)，转一转 \(b\)：只有 \(\angle5=\angle1\) 时，\(a\)、\(b\) 才不相交

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：自己推出「内错角相等，两直线平行」）

直线 \(a\)、\(b\) 被直线 \(c\) 所截（编号同上），已知 \(\angle3=\angle5\)。说明 \(a\parallel b\)。

① 读懂题意：已知的是一对内错角相等，要推出平行。手里现成能判定平行的依据只有哪一条？

提示 1：转化

手里只有「同位角相等，两直线平行」。能不能把 \(\angle3\) 换成 \(\angle5\) 的一个同位角？\(\angle5\) 的同位角是 \(\angle1\)，而 \(\angle1\) 和 \(\angle3\) 是什么关系？

看完整示范
② 想办法：\(\angle1\) 与 \(\angle3\) 是对顶角，相等；于是 \(\angle1=\angle5\)，变成同位角相等。
③ 执行：∵ \(\angle1=\angle3\)（对顶角相等），\(\angle3=\angle5\)（已知），
∴ \(\angle1=\angle5\)（等量代换）。
∴ \(a\parallel b\)（同位角相等，两直线平行）。
执行中检查：每一行括号里都有依据；最后一步用的是判定，「角在前、线在后」✓。「∵」读作「因为」，「∴」读作「所以」。

④ 回头看：这样推一遍，就得到判定方法 2：内错角相等，两直线平行。同样把 \(\angle4+\angle5=180^\circ\) 里的 \(\angle4\) 换成 \(180^\circ-\angle1\)，可以推出判定方法 3。

自己试试：量得 \(\angle4=108^\circ\)，\(\angle5=72^\circ\)。能判定 \(a\parallel b\) 吗？用哪一条？

C。\(\angle4\) 和 \(\angle5\) 都夹在 \(a\)、\(b\) 之间，都在 \(c\) 的右边，是同旁内角；\(108^\circ+72^\circ=180^\circ\)，互补。同旁内角看的是「和是不是 \(180^\circ\)」，不是看相等，所以 D 错。

3. 核心点：平行线有什么性质（由线推出角）

\(\color{#966524}{\underbrace{a\parallel b}_{\text{已知线平行}}}\;\Rightarrow\;\color{#2F7A56}{\underbrace{\angle1=\angle5}_{\text{同位角相等}}},\;\color{#2F7A56}{\underbrace{\angle3=\angle5}_{\text{内错角相等}}},\;\color{#2F7A56}{\underbrace{\angle4+\angle5=180^\circ}_{\text{同旁内角互补}}}\)

已知的是线，要推的是角，这叫性质，简称「线在前、角在后」。第一条（两直线平行，同位角相等）是度量、观察发现后我们先承认的，它不是基本事实；后两条由它推出来。

直觉微图解 ③\(a\parallel b\) 不动，换一条截线：八个角至多两种大小；截线垂直时全是直角

例 2（示范：已知平行，求角）

直线 \(a\parallel b\)，被直线 \(c\) 所截（编号同上），\(\angle7=124^\circ\)。求 \(\angle1\) 和 \(\angle4\)。

提示：从已知角出发找路

已知平行，要求角，用性质。\(\angle7\) 的同位角是谁？再从它走到 \(\angle1\)、\(\angle4\)。

看完整示范
想办法：\(\angle7\) 在 \(b\) 的左下，它的同位角是 \(a\) 的左下 \(\angle3\)；\(\angle1\) 是 \(\angle3\) 的对顶角，\(\angle4\) 是 \(\angle3\) 的邻补角。
执行：∵ \(a\parallel b\)，∴ \(\angle3=\angle7=124^\circ\)（两直线平行，同位角相等）。
\(\angle1=\angle3=124^\circ\)（对顶角相等）；\(\angle4=180^\circ-\angle3=56^\circ\)（邻补角互补）。
检查：换条路验证：\(\angle5=\angle7=124^\circ\)（对顶角相等）；\(\angle4\) 与 \(\angle5\) 是同旁内角，平行时应互补：\(56^\circ+124^\circ=180^\circ\) ✓。

回头看：性质的依据语序是「线在前、角在后」。平行线被截，八个角至多两种大小，这里是\(124^\circ\) 和 \(56^\circ\)。

自己试试：补全依据。「∵ \(a\parallel b\)，∴ \(\angle4=\angle6\)（　　）」

B。\(\angle4\)（\(a\) 下方、\(c\) 右边）和 \(\angle6\)（\(b\) 上方、\(c\) 左边）是内错角。已知的是线，推出的是角，用性质，「线在前、角在后」。A 是判定，方向反了；它们不是对顶角，也不是同位角。

4. 核心点：先判定，再用性质

判定角 ⇒ 线

已知同位角相等（或内错角相等、同旁内角互补），推出两直线平行。

性质线 ⇒ 角

已知两直线平行，推出同位角相等、内错角相等、同旁内角互补。

做题前先圈出「已知」：已知的是角，多半要先判定；已知平行，就用性质。有时要两步接力：先用一组角判定平行，再用平行求另一组角。

例 3（示范：两条截线接力）

如图，直线 \(a\)、\(b\) 被直线 \(c\)、\(d\) 所截，\(\angle1=\angle2=75^\circ\)，\(\angle3=112^\circ\)。求 \(\angle4\)。

提示：题目没说 a ∥ b

先看 \(\angle1\)、\(\angle2\) 是哪条截线截出的什么角，能不能先得到 \(a\parallel b\)？再看 \(\angle3\)、\(\angle4\) 是截线 \(d\) 截出的什么角。

看完整示范
想办法：\(\angle1\)、\(\angle2\) 是 \(a\)、\(b\) 被 \(c\) 所截的同位角，先判定 \(a\parallel b\)；\(\angle3\)、\(\angle4\) 是 \(a\)、\(b\) 被 \(d\) 所截的同旁内角，再用性质。
执行：∵ \(\angle1=\angle2\)，∴ \(a\parallel b\)（同位角相等，两直线平行）。
∴ \(\angle3+\angle4=180^\circ\)（两直线平行，同旁内角互补）。
∴ \(\angle4=180^\circ-112^\circ=68^\circ\)。
检查：两步依据一个是判定（角在前）、一个是性质（线在前），没有用反 ✓。

回头看：图上 \(a\)、\(b\) 看起来平行不算数，平行必须由已知条件推出来。

自己试试：例 3 里如果去掉条件「\(\angle1=\angle2=75^\circ\)」，只知道 \(\angle3=112^\circ\)，还能求出 \(\angle4\) 吗？

B。「同旁内角互补」是平行线的性质，前提是两直线平行。没有 \(\angle1=\angle2\)，就推不出 \(a\parallel b\)，\(\angle4\) 可以是别的度数。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）以为同位角、内错角总相等
❌ 典型错解：「\(\angle1\) 和 \(\angle5\) 是同位角，\(\angle1=65^\circ\)，所以 \(\angle5=65^\circ\)。」题目根本没说 \(a\parallel b\)。
✅ 看图秒懂：右图 \(a\)、\(b\) 不平行，同位角一个 \(65^\circ\)、一个 \(50^\circ\)。只有先有 \(a\parallel b\)，才能说同位角相等、内错角相等。
翻车现场 ②判定和性质用反
❌ 典型错解：「∵ \(a\parallel b\)，∴ \(\angle1=\angle5\)（同位角相等，两直线平行）。」
✅ 一眼看清：已知线平行、推角，用性质「两直线平行，同位角相等」；已知角、推平行，才用判定。
翻车现场 ③漏掉「同一平面内」「直线外」
❌ 典型错解：「\(a\perp b\)，\(b\perp c\)，所以 \(a\perp c\)。」「过一点有且只有一条直线与已知直线平行。」
✅ 一眼看清：在同一平面内，\(a\)、\(c\) 都垂直于 \(b\)，以 \(b\) 为截线，同位角都是 \(90^\circ\)，所以 \(a\parallel c\)。平行的基本事实里，点必须在直线外。
再深一点（可以先跳过）：为什么「两直线平行，同位角相等」要先承认？

这一条现在没法用已经学过的东西推出来，所以先通过度量确认、接受它。它不算基本事实，是一条暂时不证明的结论，到九年级可以回头证明它。

判定和性质是「反过来」的两句话。判定：同位角相等 ⇒ 平行；性质：平行 ⇒ 同位角相等。两句都对，但不能互相代替。

① 判定：转动 b，找到不相交的位置

直线 \(a\) 和截线 \(c\) 不动，\(\angle1=60^\circ\)。拖动 \(b\) 上的圆点（或按方向键 ↑ ↓）转动 \(b\)，看 \(\angle5\) 等于 \(\angle1\) 时会怎样。

② 性质：a ∥ b 不动，转动截线 c

拖动截线 \(c\) 上的圆点（或按方向键 ↑ ↓），选一类角，看两个角的关系是不是始终成立。

③ 进阶：拐角处的角，过拐点作平行线

\(AB\parallel CD\)，拐点 \(E\) 在两条平行线之间。拖动 \(E\)（或点它后按方向键），看 \(\angle BED\) 和 \(\angle ABE\)、\(\angle CDE\) 的关系。虚线是过 \(E\) 作的 \(EF\parallel AB\)。

从易到难排好了。图和编号都和「讲清楚」里一样（\(a\)、\(b\) 被 \(c\) 所截，\(\angle1\)–\(\angle4\) 在 \(a\) 上，\(\angle5\)–\(\angle8\) 在 \(b\) 上，都从右上起逆时针编号）。

直接用

1. 已知 \(a\parallel b\)，\(\angle1=76^\circ\)。\(\angle6\) 是多少度？

B。∵ \(a\parallel b\)，∴ \(\angle5=\angle1=76^\circ\)（两直线平行，同位角相等）；\(\angle6=180^\circ-76^\circ=104^\circ\)（邻补角互补）。C 是把互补错成了互余。

2. 下面哪个条件不能判定 \(a\parallel b\)？

D。\(\angle2\) 和 \(\angle4\) 是对顶角，不管 \(a\)、\(b\) 平不平行都相等，说明不了什么。A、B、C 分别是同位角相等、内错角相等、同旁内角互补。

易错

3. 「∵ \(\angle3=\angle5\)，∴ \(a\parallel b\)（　　）」括号里应填什么？

提示

圈出已知：已知的是角还是线？推出的是什么？

A。已知的是角，推出的是线，用判定，「角在前、线在后」。\(\angle3\)、\(\angle5\) 是内错角，不是同位角。B 是性质，方向反了。

4. 直线 \(a\)、\(b\) 被直线 \(c\) 所截（题目没有说 \(a\)、\(b\) 的位置关系），\(\angle1=70^\circ\)。\(\angle5\) 是多少度？

提示

「同位角相等」成立的前提是什么？题目给了吗？

D。\(\angle1\) 和 \(\angle5\) 是同位角，但没有 \(a\parallel b\) 这个条件，同位角不一定相等。图上「看起来平行」不能当已知。

5. 在同一平面内，直线 \(a\perp b\)，\(b\perp c\)。直线 \(a\) 和 \(c\) 是什么关系？

提示

把 \(b\) 看成截线，\(a\)、\(c\) 和 \(b\) 相交成的同位角各是多少度？

B。以 \(b\) 为截线，\(a\)、\(c\) 与 \(b\) 所成的同位角都是 \(90^\circ\)（垂直的定义），相等，所以 \(a\parallel c\)（同位角相等，两直线平行）。「垂直再垂直还是垂直」是凭感觉类推，错了。

挑战

6. 已知 \(a\parallel b\)，\(\angle4\) 比 \(\angle1\) 大 \(40^\circ\)。\(\angle6\) 是多少度？

提示 1：先求 ∠1、∠4

\(\angle1\) 和 \(\angle4\) 有公共边（\(a\) 向右的部分），另一边互为反向延长线：它们是什么关系？和是多少？

提示 2：∠6 和谁有关系

\(\angle6\) 在 \(b\) 上方、\(c\) 左边，和 \(\angle4\) 是哪一类角？

B。\(\angle1+\angle4=180^\circ\)（邻补角互补），又 \(\angle4-\angle1=40^\circ\)，所以 \(\angle1=70^\circ\)，\(\angle4=110^\circ\)。∵ \(a\parallel b\)，∴ \(\angle6=\angle4=110^\circ\)（两直线平行，内错角相等）。检查：\(\angle5=\angle1=70^\circ\)（同位角），\(\angle5+\angle6=180^\circ\) ✓。A 是 \(\angle1\)。

「已知平行求角」几乎是各地中考选择题的固定题型。点选项自动判对错，做完看解析。
