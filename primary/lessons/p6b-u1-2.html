以前用温度计，先找 0 刻度，再看液柱位置。怎样把这种读法搬到一条直线上？

把竖着的温度计放平，会怎样？

横线只标了 0，其余刻度等你来安排。先在脑中猜温度计的刻度会怎样放，不急着看答案。

想好后，再试一种研究办法

横线上的格子还要怎样画，才能和温度计上一样方便读数？先画一个草稿，做完预测再到工作台检验。

把温度计放平后，零下的温度会跑到 0 的哪一边？

温度计上，低的在下；放平后，小的在左，大的在右。负数在 0 的左边。

1. 画一条能表示数的直线：三样东西不能少

回想尺子：只画一条线，能读数吗？在工作台依次找出 0 的位置、向右的箭头和相等的格子，试着说清每样有什么用。

也可在直线上点或拖，选中的点会移到最近的格线上；聚焦图后用左右方向键移动。

自己试试

点 A 在 0 左边 3 格，1 格 = 1，它表示（ ）。

0 的左边是负数：一格 −1，两格 −2，三格就是 −3。

2. 换几组数，找共同点

每次先用温度猜谁大，再移点检查：① −5 和 4；② −5 和 −4；③ −4 和 0。谁在右边？读数的大小和位置有什么联系？再改成“1 格 = 2”，先猜两点读数怎么变，再验证。

先说你的发现，再去下一步看归纳。这样的直线叫数轴：要有 0 的位置、正方向和单位长度。

从温度计到直线：为什么右边的数大？

  1. 先找到温度计的 0 刻度，再把刻度等距排在直线上，规定向右表示更高的温度。
  2. 0 向右一格是 1，向左一格是 −1；每格同样宽，才能用格数读出位置。
  3. 比较 −16 与 −11：−11 ℃ 更暖，对应的点也更靠右。再观察 −6 与 4、−11 与 0，方向一致。

归纳：沿直线向右，表示的数越来越大。把每格代表的数从 1 改为 2，点的位置不动，读数却变了；读点前必须先看单位长度。

数轴上，越往右的数越大，越往左的数越小；正数在 0 的右边，负数在 0 的左边，0 比所有负数大。

两个容易错的地方

✗ 负数“数字大”就更大 说“−16 比 −11 大，因为 16 大”。
✓ 看谁在右边，右边的大 −11 在 −16 的右边，所以 −11 > −16。气温 −16 ℃ 比 −11 ℃ 冷。
✗ 格子画得宽窄不一样 0 到 1 画一格，1 到 2 画两格，读数就乱了。
✓ 单位长度要处处相等 每一格同样宽，0 向左数的格子和向右数的格子一样宽。

例题 · 先看单位，再读点

直线上规定向右为正，每格代表 3。点 P 在 0 左边 5 格，点 Q 在 0 左边 2 格。各表示什么数？谁大？

① 读懂题意：先找哪三样？

先找 0 的位置、正方向、每格代表的数。两个点都在 0 左边。

② 读数与说理：先画点，再展开

从 0 向左一格读 −3，两格读 −6，依次读到五格是 −15。所以 P 表示 −15，Q 表示 −6；Q 在 P 右边，−6 > −15。

③ 检验：用温度再想一次

−6 ℃ 比 −15 ℃ 暖，比较结果一致。不能因为 15 比 6 大，就说 −15 更大。

自己试试

−8 和 −3，哪个大？想一想它们在数轴上的位置。

气温 −8 ℃ 比 −3 ℃ 更冷。数轴上 −3 在 −8 的右边，所以 −3 > −8。

直接用

1. 画数轴不能少的三样是（ ）。

数轴必须有 0 的位置、正方向和单位长度，缺一样就没法读出数。

2. 数轴上 1 格 = 2。点 P 在 0 右边 3 格，它表示几？

3 格 × 2 = 6，点 P 表示 6。

容易错

3. 比较大小，正确的是（ ）。

−2 在 −9 的右边，所以 −2 > −9。−1 在 0 的左边，−1 < 0。

4. 把 3、−5、0、−1 按从小到大排列，是（ ）。

从左往右数：−5，−1，0，3。左边的小，右边的大。

5. 数轴上，在 −3 和 2 之间（不含 −3 和 2）有几个整数？

从左往右数：−2、−1、0、1，共 4 个。

想一想

6. 三个城市某天最低气温：甲 −12 ℃，乙 −4 ℃，丙 3 ℃。最冷的是（ ）。

数轴上最靠左的是 −12，所以甲最冷。

7. 小丽说：“0 是最小的数，因为再往左就没有了。”她的话（ ）。

数轴向左一直延伸，−1、−2、−3 …… 都比 0 小，没有最小的数。
