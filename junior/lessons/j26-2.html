26.2 二次函数的图象和性质

平滑优美的抛物线，初中代数几何综合的最核心母体！从最简式 \(y = ax^2\) 出发，经历平移链条掌握顶点式 \(y = a(x-h)^2+k\)，运用配方法攻克一般式，看透“左加右减，上加下减”与对称轴增减性。

观察画出的图象，它是关于哪条直线对称的？它的最低点位于何处？

B。二次函数 \(y = x^2\) 的图象是一条关于 \(y\) 轴（直线 \(x = 0\)）对称的平滑曲线，它的最低点是坐标原点 \((0, 0)\)。

这条曲线像投掷铅球或喷水池水柱在空中画出的弧线，数学上把二次函数的图象统称为抛物线（parabola）。顶点是抛物线的转折点，也是函数的极值点。

1. 先认识几个词：抛物线与它的核心四要素

二次函数的图象是一条关于对称轴对称的连续平滑曲线，研究任何一条抛物线都抓住这四个核心词：

  • 开口方向与最值：由二次项系数 \(a\) 决定。\(a \gt 0\) 开口向上，顶点是最低点（有最小值）；\(a \lt 0\) 开口向下，顶点是最高点（有最大值）。
  • 对称轴：抛物线的折叠对称中心线。抛物线上的点成双成对地关于对称轴对称。
  • 顶点坐标：抛物线与对称轴的唯一交点，是曲线的巅峰或谷底。
  • 增减性（单调性）：以对称轴为分水岭，两侧函数值的升降方向完全相反。

直觉微图解 ①最简式 \(y = ax^2\)：参数 \(a\) 决定开口与胖瘦

核心规律 1\(|a|\) 的几何意义：决定抛物线形状

只要 \(|a|\) 相等，抛物线的开口大小和形状就完全一样！\(|a|\) 越大，曲线收拢得越窄（越陡峭）；\(|a|\) 越小，曲线张开得越宽（越平缓）。平移过程中 \(a\) 始终不改变。

核心规律 2增减性必须带上「范围限定」

绝对不能说“二次函数单调递增”！当 \(a \gt 0\) 时：在对称轴左侧（\(x \lt 0\)），\(y\) 随 \(x\) 增大而减小；在对称轴右侧（\(x \gt 0\)），\(y\) 随 \(x\) 增大而增大。分水岭正是对称轴。

2. 核心进阶：平移链条与顶点式 \(y = a(x-h)^2 + k\)

直觉微图解 ②平移四步大迁徙：左加右减，上加下减

顶点式：\(y = a(x - h)^2 + k\)
对称轴为直线 \(\mathbf{x = h}\)，顶点坐标为 \(\mathbf{(h, k)}\)。当 \(a \gt 0\) 时，在 \(x=h\) 处取得最小值 \(k\)；当 \(a \lt 0\) 时，在 \(x=h\) 处取得最大值 \(k\)。

3. 一般式化顶点式：配方法的威力与系数法则

对于一般式 \(y = ax^2 + bx + c\)，利用配方法提取二次项系数 \(a\)：

\(y = a\left(x^2 + \dfrac{b}{a}x\right) + c = a\left(x + \dfrac{b}{2a}\right)^2 + \dfrac{4ac - b^2}{4a}\)

由此直接导出通用公式：

  • 对称轴公式：直线 \(x = -\dfrac{b}{2a}\)；
  • 顶点坐标公式：\(\left(-\dfrac{b}{2a}, \dfrac{4ac - b^2}{4a}\right)\)；

4. 自己试试与典例示范

【自测 1】将抛物线 \(y = 2x^2\) 先向右平移 3 个单位长度，再向上平移 1 个单位长度，所得新抛物线的顶点坐标是（ ）

D。原顶点是 \((0, 0)\)。向右平移 3 个单位横坐标加 3，向上平移 1 个单位纵坐标加 1，新顶点为 \((3, 1)\)。解析式为 \(y = 2(x-3)^2 + 1\)。

【自测 2】已知二次函数 \(y = (x-2)^2 + 3\)，下列说法正确的是（ ）

B。二次项系数 \(a = 1 \gt 0\)，开口向上；对称轴是 \(x = 2\)；当 \(x=2\) 时取最低点最小值 \(y = 3\)；在对称轴右侧（\(x \gt 2\)），\(y\) 随 \(x\) 增大而增大。

【自测 3】已知点 \(A(-2, y_1)\)，\(B(1, y_2)\) 在抛物线 \(y = -x^2\) 上，则 \(y_1\) 与 \(y_2\) 的大小关系是（ ）

A。开口向下，离对称轴（\(y\) 轴）越远，函数值越小。点 \(A\) 到对称轴距离为 \(|-2| = 2\)，点 \(B\) 距离为 \(|1| = 1\)。因为 \(2 \gt 1\)，所以点 \(A\) 离对称轴更远，\(y_1 \lt y_2\)。或直接算：\(y_1 = -4\)，\(y_2 = -1\)，\(-4 \lt -1\)。

【例题 1·波利亚示范】配方法求一般式顶点与对称轴

题目：求二次函数 \(y = -2x^2 + 8x - 5\) 的图象的开口方向、对称轴、顶点坐标及最值。

第一步（提取系数）：提二次项系数 \(-2\)：\(y = -2(x^2 - 4x) - 5\)。注意提出负号后括号内一次项变号！
第二步（配方）：一次项系数一半的平方是 \((-2)^2 = 4\)：
\(y = -2(x^2 - 4x + 4 - 4) - 5 = -2(x - 2)^2 + 8 - 5 = -2(x - 2)^2 + 3\)。
第三步（结论输出）：
① \(a = -2 \lt 0\)，抛物线开口向下；
② 对称轴为直线 \(x = 2\)；
③ 顶点坐标为 \((2, 3)\)；
④ 当 \(x = 2\) 时，函数取得最大值 \(3\)。

【例题 2·波利亚示范】待定系数法求二次函数解析式（顶点式）

题目：已知一条抛物线的顶点坐标是 \((1, -4)\)，且经过点 \((3, 0)\)，求这条抛物线的解析式。

解答思路：已知顶点坐标优先设顶点式：设 \(y = a(x - 1)^2 - 4\)（\(a \ne 0\)）。
将点 \((3, 0)\) 代入方程：
\(0 = a(3 - 1)^2 - 4 \implies 4a - 4 = 0 \implies a = 1\)。
∴ 解析式为 \(y = (x - 1)^2 - 4\)，化为一般式即 \(y = x^2 - 2x - 3\)。

【例题 3·波利亚示范】到对称轴距离法秒杀函数值比大小

题目：已知点 \(A(-3, y_1)\)，\(B(-1, y_2)\)，\(C(2, y_3)\) 在抛物线 \(y = -x^2 - 2x + c\) 上，试比较 \(y_1, y_2, y_3\) 的大小。

规范解答：
① 对称轴为 \(x = -\dfrac{b}{2a} = -\dfrac{-2}{2(-1)} = -1\)，开口向下（\(a = -1 \lt 0\)）。
② 开口向下时：离对称轴越近函数值越大；离对称轴越远函数值越小。
点 \(B(-1, y_2)\) 在对称轴上，距离为 0（最大值）；
点 \(A(-3, y_1)\) 距离为 \(|-3 - (-1)| = 2\)；
点 \(C(2, y_3)\) 距离为 \(|2 - (-1)| = 3\)；
③ ∵ \(0 \lt 2 \lt 3\)，∴ \(y_3 \lt y_1 \lt y_2\)。

【例题 4·波利亚示范】中考必考：多代数式符号判断技巧

题目：已知抛物线开口向下，与 \(y\) 轴交于正半轴，对称轴为直线 \(x = 1\)，过点 \((-1, 0)\)。判断 \(abc\) 与 \(2a+b\) 的符号。

解答推导：
① 开口向下 \(\implies a \lt 0\)；交 \(y\) 轴正半轴 \(\implies c \gt 0\)；对称轴在 \(y\) 轴右侧，由“左同右异”得 \(b \gt 0\)；∴ \(abc \lt 0\)。
② 对称轴公式：\(x = -\dfrac{b}{2a} = 1 \implies b = -2a \implies 2a + b = 0\)。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）平移方向和括号里的符号反着记
❌ 典型错解：「\(y=(x-2)^2\) 是向左平移 \(2\) 个单位，对称轴是 \(x=-2\)」。
✅ 看图秒懂：令括号里 \(x-2=0\)，得 \(x=2\)，这才是顶点横坐标——图象向右移了 \(2\)，对称轴 \(x=2\)。
翻车现场 ②说增减性，不指明在对称轴哪一侧
❌ 典型错解：「\(y=x^2-2x\)，\(a=1 \gt 0\)，所以 \(y\) 随 \(x\) 增大而增大」。
✅ 一眼看清：对称轴 \(x=1\)。左侧（\(x \lt 1\)）\(y\) 随 \(x\) 增大而减小，右侧（\(x \gt 1\)）才随 \(x\) 增大而增大。取 \(x=0\to1\)：\(y\) 从 \(0\) 降到 \(-1\)。
翻车现场 ③配方时只补了括号里，没在外面还账
❌ 典型错解：\(y=2x^2+4x+1=2(x^2+2x+1)+1-1=2(x+1)^2\)。
✅ 一眼看清：括号里补了 \(1\)，括号外有个 \(2\)，实际多加了 \(2\times1=2\)，要减 \(2\)：\(y=2(x+1)^2-2+1=2(x+1)^2-1\)。验算：\(x=0\) 时原式 \(1\)，新式 \(2-1=1\)。
再深一点（可以先跳过）：为什么 \(a\) 相同的抛物线都能「叠」在一起？

平移只改变顶点位置，不改变形状，所以 \(y=a(x-h)^2+k\) 总可以由 \(y=ax^2\) 平移得到。这就是为什么只要 \(a\) 相同、顶点不同，两条抛物线就能重合：研究任意二次函数，先研究 \(y=ax^2\) 就够了。

【巩固 1】抛物线 \(y = 3(x+2)^2 - 5\) 的顶点坐标与对称轴分别是（ ）

C。对照顶点式 \(y = a(x-h)^2 + k\)，这里 \(x+2 = x - (-2)\)，所以 \(h = -2\)，\(k = -5\)。顶点坐标是 \((-2, -5)\)，对称轴为直线 \(x = -2\)。

【巩固 2】将抛物线 \(y = x^2\) 向左平移 2 个单位，再向下平移 3 个单位，得到的新抛物线解析式为（ ）

B。左加右减：向左平移 2 个单位在括号内加 2 得 \((x+2)^2\)；上加下减：向下平移 3 个单位在末尾减 3。得到 \(y = (x+2)^2 - 3\)。

【巩固 3·易错题】已知点 \(A(-1, y_1)\)，\(B(2, y_2)\) 在二次函数 \(y = -(x-1)^2 + 4\) 的图象上，则（ ）

提示

对称轴为直线 \(x = 1\)，开口向下，计算两点到对称轴的距离。

A。对称轴为 \(x = 1\)，开口向下。点 \(A\) 到对称轴距离为 \(|-1 - 1| = 2\)；点 \(B\) 到对称轴距离为 \(|2 - 1| = 1\)。因为 \(2 \gt 1\)，点 \(A\) 离对称轴更远，故 \(y_1 \lt y_2\)。直接算得 \(y_1 = 0, y_2 = 3\)，\(0 \lt 3\)。

【巩固 4·挑战题】二次函数 \(y = ax^2 + bx + c\) 的图象开口向上，对称轴为直线 \(x = 1\)，则下列结论错误的是（ ）

提示

对称轴在 y 轴右侧，由左同右异判定 b 的符号。

B。开口向上 \(\implies a \gt 0\)；对称轴在 \(y\) 轴右侧 \(\implies a, b\) 异号，因此 \(b \lt 0\)！选项 B 声称 \(b \gt 0\)，是错误的。

【易错挑战】对称轴求法与配方中的提系数失误

题目：把 \(y = 3x^2 - 6x + 1\) 化为顶点式，常见错误解法如下，错在哪里？
\(y = 3(x^2 - 2x) + 1 = 3(x^2 - 2x + 1) + 1 - 1 = 3(x-1)^2\)（错！）

正解剖析：在括号内加上 1 时，因为括号外乘以了 3，实际上整体增加了 \(3 \times 1 = 3\)！因此在外面必须减去 3，而不是减 1！
正确配方：\(y = 3(x^2 - 2x + 1) + 1 - 3 = 3(x-1)^2 - 2\)。顶点坐标是 \((1, -2)\)。

巩固练习 1：将函数 \(y=3x^2\) 的图象向下平移 \(2\) 个单位长度，得到的新函数的解析式为 ______。

查看答案与解析，自行核对

答案：\(y=3x^2-2\)

「上加下减」：向下平移 \(2\) 个单位，在整个式子后面减 \(2\)，得 \(y=3x^2-2\)。

巩固练习 2：将抛物线 \(y=2x^2\) 向右平移 \(3\) 个单位长度，所得新抛物线的顶点坐标为（ ）

D。原顶点 \((0,0)\)，向右平移 \(3\) 个单位得 \(y=2(x-3)^2\)，顶点 \((3,0)\)。选 D。

巩固练习 3：已知点 \(A(-3,y_1)\)，\(B(-1,y_2)\)，\(C(2,y_3)\) 都在二次函数 \(y=-x^2-2x+c\) 的图象上，则 \(y_1,y_2,y_3\) 的大小关系是（ ）

B。对称轴 \(x=-\dfrac{-2}{2\times(-1)}=-1\)，开口向下。\(B\) 在对称轴上，\(y_2\) 最大；\(A\) 到对称轴距离 \(2\)，\(C\) 到对称轴距离 \(3\)，离得越远越小，所以 \(y_3<y_1<y_2\)。也可直接算：\(y_1=c-3,\ y_2=c+1,\ y_3=c-8\)。选 B。

巩固练习 4：已知二次函数 \(y=ax^2+bx+c\) 的图象开口向下，对称轴在直线 \(x=1\) 的右侧，且与 \(y\) 轴交于正半轴，则下列结论一定正确的是（ ）

D。开口向下，\(a<0\)，A 错；对称轴 \(-\dfrac{b}{2a}>1>0\)，\(a,b\) 异号，故 \(b>0\)，B 错；与 \(y\) 轴交于正半轴，\(c>0\)，C 错；由 \(-\dfrac{b}{2a}>1\)，两边同乘正数 \(-2a\)，得 \(b>-2a\)，即 \(2a+b>0\)，D 正确。选 D。

巩固练习 5：已知二次函数 \(y=ax^2+bx+c\) 的图象开口向下，与 \(x\) 轴的一个交点为 \(A(-1,0)\)，对称轴为直线 \(x=1\)。下列四个结论：① \(abc>0\)；② \(2a+b=0\)；③ \(a+b+c>0\)；④ 抛物线与 \(x\) 轴的另一个交点是 \((3,0)\)。其中正确结论的个数为（ ）

C。由对称性，另一交点 \((3,0)\)，④ 正确；设 \(y=a(x+1)(x-3)\)（\(a<0\)），则 \(b=-2a>0\)，\(c=-3a>0\)，\(abc<0\)，① 错；\(b=-2a\) 即 \(2a+b=0\)，② 对；\(x=1\) 在两根之间且开口向下，\(y=a+b+c>0\)，③ 对。正确的是 ②③④，共 3 个，选 C。
