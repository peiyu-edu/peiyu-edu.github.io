18.1 分式及其基本性质

分子、分母都是整式，并且分母里含有字母，这样的式子叫“分式”。它什么时候有意义、什么时候等于 0？怎样像分数那样约分、通分？这一节全程拿分数来比。

本节导读　先修：整式、因式分解 · 本节路线

要用到：整式（回看 4.1）；提公因式法、公式法分解因式（回看 17.1、17.2）；小学分数的约分、通分。

  1. 从“平均分”进入：除数是字母时，商写成什么样？
  2. 认识分式：分子、分母都是整式，分母含字母。
  3. 两个条件：有意义（分母 ≠ 0）；值为 0（分子 = 0 且分母 ≠ 0）。
  4. 基本性质：分子分母同乘（除以）一个不为 0 的整式，值不变。
  5. 约分与通分：先分解因式，再约公因式、找最简公分母。
  6. 练习与中考真题，回看“哪一步最容易错”。

一桶水 \(12\) 升，平均倒进几个杯子。先点下面的按钮，看杯子数变了，每杯的水怎么变：

如果平均倒进 \(n\) 个杯子，每杯有多少升？

B。平均分用除法：\(12\div n\)，写成 \(\dfrac{12}{n}\)。选 A 是把除法当成了乘法；选 C 是把被除数和除数弄反了。

\(\dfrac{12}{n}\) 长得像分数，可分母是字母 \(n\)。还有一件事：\(n\) 能不能取 \(0\)？这一节要回答：分母含字母的式子叫什么，什么时候有意义，能不能像分数一样约分、通分？

1. 先认识几个词：分式、有意义、最简分式

前置知识：整式（回看 4.1）；分解因式（回看 17.2）。先看几个都带分数线的式子，哪些是分式：

直觉微图解 ①有分数线不一定是分式：看分母里有没有字母

分式：\(A\)、\(B\) 表示两个整式，并且 \(B\) 中含有字母，式子 \(\dfrac{A}{B}\) 叫做分式，\(A\) 叫分子，\(B\) 叫分母。分子可以不含字母（如 \(\dfrac{12}{n}\)）。和分数一样，\(\dfrac{A}{B}\) 既表示除法 \(A\div B\)，也表示这个商。

有意义：分母相当于除数，除数不能为 \(0\)。分母 \(B\ne 0\) 时，分式才有意义。以后没有特别说明时，出现的分式都默认有意义。

核心概念 ②分式 vs 整式：看原来的样子

\(\dfrac{x}{3}\) 的分母是数 \(3\)，它就是 \(\tfrac13x\)，是整式；\(\pi\) 是一个确定的数，\(\dfrac{x}{\pi}\) 也是整式。\(\dfrac{x^2}{x}\) 是分式：判断时不先约分。

核心概念 ③有意义 vs 值为 0

有意义只看分母：分母 \(\ne 0\)。值为 \(0\) 要两条同时满足：分子 \(=0\)，并且分母 \(\ne 0\)。分母等于 \(0\) 时分式根本没有值，谈不上等于 \(0\)。

2. 核心点：什么时候有意义、什么时候值为 0

\(\dfrac{A}{B}\) 有意义：\(\color{#B5452F}{B\ne 0}\)

除数不能为 \(0\)。

\(\dfrac{A}{B}=0\)：\(\color{#2F7A56}{A=0}\) 且 \(\color{#B5452F}{B\ne 0}\)

分子为 \(0\)，同时分母不为 \(0\)。

直觉微图解 ②在数轴上标出：哪些 \(x\) 让分母为 0（✕），哪些让分式的值为 0（○）

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

(1) \(x\) 取什么值时，分式 \(\dfrac{x+5}{4x-8}\) 有意义？(2) \(x\) 取什么值时，分式 \(\dfrac{x^2-9}{x-3}\) 的值为 \(0\)？

① 读懂题意：(1) 问「有意义」，(2) 问「值为 0」。两问要看的地方一样吗？

提示 1：各盯哪里

(1) 只看分母，分子是什么都不用管。(2) 先让分子为 \(0\)，再回头查分母。

看完整示范
② 想办法：(1) 列「分母 \(\ne 0\)」再解；(2) 列「分子 \(=0\)」解出候选值，再一个一个代进分母检查。
③ 执行：(1) 要使分式有意义，则 \(4x-8\ne 0\)，即 \(x\ne 2\)。(2) 分子 \(x^2-9=0\)，\(x^2=9\)，\(x=3\) 或 \(x=-3\)。
执行中检查：(2) 代回分母：\(x=3\) 时 \(x-3=0\)，分式没有意义，排除；\(x=-3\) 时分母 \(-6\ne 0\) ✓。所以 \(x=-3\)。

④ 回头看：「值为 0」比「有意义」多一个条件。分母含两个字母时，条件是字母之间的关系：\(\dfrac{a}{a-2b}\) 有意义要 \(a\ne 2b\)，不是「\(a\ne 0\) 且 \(b\ne 0\)」。

自己试试：\(x\) 取什么值时，分式 \(\dfrac{2x-1}{x^2+9}\) 有意义？

C。\(x^2\) 不会是负数，\(x^2+9\ge 9\)，分母永远不为 \(0\)。A、B 是把 \(x^2+9\) 当成了 \(x^2-9\)；D 是去看分子了，分子为 \(0\) 不影响有没有意义。

再试一个：\(x\) 取什么值时，分式 \(\dfrac{x+3}{x^2-9}\) 的值为 \(0\)？

D。分子 \(x+3=0\) 只能 \(x=-3\)，可这时分母 \(9-9=0\)，分式没有意义。唯一的候选被排除，所以值不可能为 \(0\)。选 A 是只看了分子；选 B、C 是去解分母了。

3. 核心点：基本性质——上下同乘（除以）不为 0 的整式

分数 \(\dfrac23=\dfrac{2\times 5}{3\times 5}\)，靠的是“分子分母同乘一个不为 0 的数，值不变”。分式也一样，只是把“数”换成“整式”：

\(\dfrac{A}{B}=\dfrac{A\cdot \color{#2F7A56}{C}}{B\cdot \color{#2F7A56}{C}}\)

\(\dfrac{A}{B}=\dfrac{A\div \color{#2F7A56}{C}}{B\div \color{#2F7A56}{C}}\)

不能漏掉条件：\(\color{#B5452F}{C\ne 0}\)。

\(A\)、\(B\)、\(C\) 都是整式。只对乘、除成立；同加、同减不行。

直觉微图解 ③取 \(x=3\) 验一验：对 \(\dfrac{x}{x+1}\) 做四种变形，值还是 \(\dfrac34\) 吗？

例 2（示范：看分母怎么变，想分子怎么变）

填空：(1) \(\dfrac{3a}{2b}=\dfrac{(\quad)}{8ab^2}\)；(2) \(\dfrac{x^2+2x}{x^2-4}=\dfrac{x}{(\quad)}\)。

提示：先比较已知的那一半

(1) 分母从 \(2b\) 变成 \(8ab^2\)，乘了什么？(2) 分子从 \(x^2+2x\) 变成 \(x\)，除以了什么？先把分子分母分解因式。

看完整示范
想办法：(1) \(2b\cdot 4ab=8ab^2\)，分母乘了 \(4ab\)，分子也乘 \(4ab\)。(2) \(x^2+2x=x(x+2)\)，\(x^2-4=(x+2)(x-2)\)，分子除以了 \(x+2\)。
执行：(1) \(3a\cdot 4ab=12a^2b\)，填 \(12a^2b\)。(2) 分母也除以 \(x+2\)：填 \(x-2\)。
检查：(1) 乘的 \(4ab\) 不为 \(0\)：原式有意义已有 \(b\ne 0\)，还要 \(a\ne 0\)，右边分母 \(8ab^2\) 才不为 0。(2) 原式有意义时 \(x+2\ne 0\)，可以除。

回头看：上下做的必须是同一件事：同乘同一个整式，或同除以同一个整式。

自己试试：下面哪个变形一定正确？

C。\(x^2+1\ge 1\)，永远不为 \(0\)，可以同乘。A 是同加，取 \(a=1,b=2\)：\(\tfrac12\ne\tfrac23\)；B 是同减，取 \(a=1,b=3\)：\(\tfrac13\ne\tfrac02=0\)。如果同乘的是可能为 \(0\) 的式子（比如 \(c\)），还得先说明它不为 \(0\)。D 是分子乘 \(a\)、分母乘 \(b\)，乘的不是同一个式子。

4. 核心点：约分和通分，第一步都是分解因式

约分：根据基本性质，约去分子和分母的公因式。分子分母没有公因式的分式叫最简分式；约分要约到底，结果是最简分式或整式。通分：把几个异分母分式化成同分母分式，值不变。一般取各分母所有因式的最高次幂的积（系数取最小公倍数）作公分母，叫最简公分母。

先把分子、分母分解因式（用第十七章的两种方法）。

再约去公因式或定最简公分母（依据：分式的基本性质）。

直觉微图解 ④把分子分母拆成一块块因式，上下都有的才能划掉

例 3（示范）

(1) 约分：\(\dfrac{m^2-4m}{m^2-8m+16}\)；(2) 通分：\(\dfrac{1}{3x^2y}\) 与 \(\dfrac{5}{6xz}\)。

提示 1：先分解

(1) 分子提公因式，分母用完全平方公式。(2) 分母是单项式：系数 \(3\)、\(6\) 和字母 \(x,y,z\) 分开看。

看完整示范
想办法：(1) \(m^2-4m=m(m-4)\)，\(m^2-8m+16=(m-4)^2\)，公因式 \(m-4\)。(2) 系数取 \(6\)；\(x\) 取最高次 \(x^2\)；\(y\)、\(z\) 各只在一个分母里，也要带上：最简公分母 \(6x^2yz\)。
执行：(1) \(\dfrac{m(m-4)}{(m-4)^2}=\dfrac{m}{m-4}\)。(2) \(\dfrac{1}{3x^2y}=\dfrac{2z}{6x^2yz}\)（上下乘 \(2z\)），\(\dfrac{5}{6xz}=\dfrac{5xy}{6x^2yz}\)（上下乘 \(xy\)）。
检查：(1) 再看 \(m\) 和 \(m-4\)：没有公因式了 ✓。(2) 分母乘了什么，分子就乘什么：\(2z\)、\(xy\) 两处都乘到了 ✓。

回头看：约分找「上下都有的」，通分找「每个分母都能整除的最小的」。

自己试试：约分 \(\dfrac{4x^2-1}{2x^2+x}\) 的结果是？

A。\(4x^2-1=(2x+1)(2x-1)\)，\(2x^2+x=x(2x+1)\)，约去 \(2x+1\)。B 是把 \(4x^2\)、\(2x^2\) 里的 \(x^2\) 当成公因式「约」掉了（在项之间约分）；C 约错了因式；D 把分母里的 \(x\) 也约没了。

5. 用之前必查：三大翻车现场

翻车现场 ①（最高频！）在“项”之间约分
❌ 典型错解：\(\dfrac{x+3}{x+6}\) 上下都有 \(x\)，约掉得 \(\dfrac36=\dfrac12\)。
✅ 代个数秒懂：取 \(x=2\)，原式 \(=\dfrac58\)，不是 \(\dfrac12\)。\(x+3\) 是两项的和，\(x\) 不是它的因式。只有乘积里的公因式才能约。
翻车现场 ②值为 0 只看分子
❌ 典型错解：“\(\dfrac{x^2-1}{x-1}=0\)，分子 \(x^2-1=0\)，所以 \(x=\pm1\)。”
✅ 一眼看清：\(x=1\) 时分母 \(x-1=0\)，分式没有意义，要排除。只有 \(x=-1\)。
翻车现场 ③通分只乘分母，分子忘了乘
❌ 典型错解：\(\dfrac{3}{a}=\dfrac{3}{a(a+1)}\)，分母乘了 \(a+1\)，分子还是 \(3\)。
✅ 一眼看清：基本性质要求分子分母乘同一个整式：\(\dfrac{3}{a}=\dfrac{3(a+1)}{a(a+1)}\)。
再深一点（可以先跳过）：负号放在哪里都行，但要成对改

分子、分母、分式本身前面的符号，同时改其中两个，值不变：\(\dfrac{-a}{b}=\dfrac{a}{-b}=-\dfrac{a}{b}\)，\(\dfrac{-a}{-b}=\dfrac{a}{b}\)。这就是基本性质：分子分母同乘 \(-1\)。所以 \(\dfrac{m-n}{n-m}=\dfrac{m-n}{-(m-n)}=-1\)，不是 \(1\)。

① 拖动 x：分式有没有意义、值是多少

先选一个分式，再拖数轴上的圆点（或点一下圆点用方向键）。红色 ✕ 是让分母为 0 的值，绿色圈是让分式值为 0 的值。

② 约分前后：值总一样吗？

\(\dfrac{x^2-4}{x^2+2x}\) 约分得 \(\dfrac{x-2}{x}\)。拖动 \(x\)，比一比两个式子的值，特别留意 \(x=-2\) 和 \(x=0\)。

③ 进阶：最简公分母为什么取“最高次”

两个分母：① \(4a^{p}(x+1)^{q}\)，② \(6a^{r}(x+1)^{s}\)。上下拖动前四根柱子的顶端（或点一下用方向键）改次数，看每组第三根柱（③，红色）——最简公分母里这个因式的次数——怎么跟着变。

从易到难排好了。卡住时先展开提示。

直接用

1. 下列式子中，是分式的是哪一个？

C。只有它的分母 \(2+y\) 含字母。A、D 的分母是数；B 的 \(\pi\) 是圆周率，一个确定的数，不是字母变量。它们都是整式。

2. 约分 \(\dfrac{15x^2y}{20xy^3}\) 的结果是？

B。公因式是 \(5xy\)：\(15\div5=3\)，\(20\div5=4\)；\(x^2\div x=x\)；\(y\div y=1\)，\(y^3\div y=y^2\)。A 漏约了 \(x\)；C 分母的 \(y\) 没约；D 系数约错了。

易错

3. 分式 \(\dfrac{x^2-16}{x^2+4x}\) 的值为 \(0\)，则 \(x\) 等于？

提示

先让分子为 \(0\)，再把每个候选值代进分母 \(x^2+4x\) 查一查。

B。分子 \(x^2-16=0\) 得 \(x=\pm4\)；分母 \(x^2+4x=x(x+4)\)，\(x=-4\) 时为 \(0\)，排除。选 A 是只看分子（翻车现场 ②）；\(x=0\) 时分母也为 \(0\)，D 错。

4. 下列变形中，正确的是哪一个？

提示

每个选项问自己：分子分母是不是乘（除以）了同一个式子？约掉的是不是因式？

C。\(x^2-2x=x(x-2)\)，\(x^2-4=(x+2)(x-2)\)，约去 \(x-2\)。A 是在项之间约分（\(x=1\) 时左边 \(\tfrac74\)）；B 的 \(a^2+b^2\) 不能分解，没有因式 \(a+b\)；D 应等于 \(-1\)。

5. \(\dfrac{1}{2x^2-2x}\) 与 \(\dfrac{3}{x^2-2x+1}\) 的最简公分母是？

提示

先分解：\(2x^2-2x=2x(\ \ )\)，\(x^2-2x+1=(\ \ )^2\)。每个因式取最高次。

A。\(2x^2-2x=2x(x-1)\)，\(x^2-2x+1=(x-1)^2\)。系数 \(2\)、\(x\)、\((x-1)\) 取最高次 \((x-1)^2\)。B 没取最高次；C 直接相乘，多了一个 \(x-1\)；D 的 \(x\) 次数取高了。

挑战

6. 不改变分式的值，把 \(\dfrac{\frac12x-0.4}{0.3x+2}\) 的分子、分母中各项的系数都化成整数，结果是？

提示 1：乘几

要让 \(\tfrac12\)、\(0.4\)、\(0.3\) 都变成整数，分子分母同乘的最小正整数是几？

提示 2：每一项都乘

分母里的常数项 \(2\) 也要乘，不能只乘带 \(x\) 的项。

A。\(\tfrac12=0.5\)，分子分母同乘 \(10\)：分子 \(5x-4\)，分母 \(3x+20\)。B 是常数项 \(2\) 忘了乘；C 只乘了 \(2\)，系数还不全是整数。
