3的倍数特征

12 和 22 个位一样，却一个是 3 的倍数、一个不是。判断 3 的倍数，要看什么？

旧版目录，待新版核对。

12 和 22 的个位都是 2。12 是 3 的倍数，那么 22 呢？

B。22 = 3 × 7 + 1，不是 3 的倍数。判断 3 的倍数，要用别的办法。

1. 拨一拨，数字加一加

调一调每一位上的数，看各位上的数加起来是几，再看它是不是 3 的倍数。

自己试试 1

345 的各位数字加起来是 3 + 4 + 5 = 12，345 是 3 的倍数吗？

A。各位数字的和是 3 的倍数，这个数就是 3 的倍数：345 = 3 × 115。

自己试试 2

下面哪个数不是 3 的倍数？

C。10 不是 3 的倍数，361 ÷ 3 = 120……1。

记住这句话 把各个数位上的数相加，和是 3 的倍数，这个数就是 3 的倍数。
对：先加各位上的数

123 的各位和 1 + 2 + 3 = 6，6 是 3 的倍数，所以 123 是 3 的倍数。

错：只看个位

个位是 3 的 13 不是 3 的倍数，个位是 2 的 12 却是，不能只看个位。

对：和是 6、9、12、15…… 都行

只要和是 3 的倍数就行，不一定要等于 3。

错：以为和必须等于 3

18 的和是 9，9 是 3 的倍数，18 就是 3 的倍数，和不用等于 3。

为什么要把各位上的数加起来？

一个百和一个十，3 个一组去分，都会剩下 1 个（100 = 33 × 3 + 1，10 = 3 × 3 + 1）。所以一个数 3 个一组分后剩几个，看的是各位上的数加起来是多少。加起来正好是 3 的倍数，就没有剩余。

动手算一算（7 题）

直接用

1. 456 的各位数字加起来是几？

15。4 + 5 + 6 = 15，15 是 3 的倍数，所以 456 是 3 的倍数。

直接用

2. 在 52□ 的 □ 里填一个数字，使它是 3 的倍数，最小填几？

2。5 + 2 = 7，再加 2 得 9，9 是 3 的倍数；填 0 或 1 得 7、8，不是。

直接用

3. 从 100 到 110（含 100 和 110）里，3 的倍数一共有几个？

3 个。102（1+0+2=3）、105（6）、108（9）。

容易错

4. 下面哪个数是 3 的倍数？

C。6 + 3 = 9，9 是 3 的倍数，63 = 3 × 21。个位是 3 的数不一定是 3 的倍数。

容易错

5. 123、124、125、126 这四个数里，是 3 的倍数的有几个？

2 个。123（1+2+3=6）和 126（1+2+6=9）。

想一想

6. 既是 2 的倍数，又是 3 的倍数，还是 5 的倍数的最小三位数是几？

120。个位是 0；1 + 2 + 0 = 3，是 3 的倍数。100、110 的数字和是 1、2，不行。

想一想

7. 用数字 1、2、3 各一次组成三位数，一共能组成 6 个，其中是 3 的倍数的有几个？

6 个。不管怎么排，各位数字和都是 1 + 2 + 3 = 6，都是 3 的倍数。
