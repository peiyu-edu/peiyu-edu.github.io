F2选择题椭圆

方程

sin((19n)∘)x2​+cos((19n)∘)y2​=1(n∈N∗)

所表示的曲线为（ ）。

  1. (A)

    焦点在 x 轴上的双曲线

  2. (B)

    双曲线，其焦点所在的轴与 n 有关

  3. (C)

    焦点在 y 轴上的椭圆

  4. (D)

    椭圆，其焦点所在的轴与 n 有关

示意取 n=1；焦轴的判定须对全部正整数 n 证明。

作答

标准答案：C

解析

思路

先对完整角度周期取模，再比较两个正分母。

解答

因为 192=361≡1(mod360)，所以奇数 n 时角度同余 19∘，偶数时同余 1∘。两个角都在 0∘ 与 45∘ 之间，因此总有 0<sin((19n)∘)<cos((19n)∘)。方程的两个平方项分母均正，且纵轴半轴较长，故总是焦点在 y 轴上的椭圆，选 C​。

复核

所有正整数指数由同余关系一次覆盖，不是只计算前几项。双曲线要求异号分母，本题不可能出现；焦轴也不随奇偶改变。

方法总结

先判断分母符号，再比较大小；无平方的三角分母不能擅自改成平方。

为什么评为 F2（会透露解法方向）

用模三百六十的幂周期覆盖所有指数，再依分母符号与大小统一判断曲线类型和焦轴。

用到的方法（会透露解法方向）

核心工具：剩余类、幂周期与局部排除、周期象限与精确角归约
