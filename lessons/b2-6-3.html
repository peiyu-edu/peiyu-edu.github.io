6.3 平面向量基本定理及坐标表示

给平面挑两个不共线的基准向量，任何向量都能被唯一分解；选单位正交基底，几何图形就彻底变成了有序数对——从此向量加减、求模、判定平行和垂直，全都可以由代数坐标代劳。

方格棋盘上，巡检无人机停在基准点 \(O(0,0)\)。它接收两种基础位移指令：\(\boldsymbol{e}_1\)（向东 \(1\) 格）与 \(\boldsymbol{e}_2\)（向北 \(1\) 格）。目标设备在点 \(P(4,3)\)，先点按钮试飞看看：

下面四种指令组合，哪一种能使无人机从 \(O\) 抵达 \(P\)？

B。向东 \(4\) 步加上向北 \(3\) 步，合位移就是 \(4\boldsymbol{e}_1 + 3\boldsymbol{e}_2\)。而且只要目标位置 \(P\) 确定，这组步数 \((4, 3)\) 是有且仅有一组的。

更巧妙的是：只要两个基准方向不共线（哪怕不是正东和正北，而是斜着交叉），平面上的任何一个点、任何一条向量，都能用它们唯一地表示出来！

这就是平面向量基本定理。借由这个定理，几何里的线段和夹角，就化作了一目了然的代数坐标。

1. 先认识几个词

要用到：向量加法的平行四边形法则、数乘向量与数量积（回看 6.2）；初中平面直角坐标系与勾股定理。

直觉微图解

基底形式 ①斜基底分解：任意不共线向量皆可作基

分解唯一：只要 \(\boldsymbol{e}_1,\boldsymbol{e}_2\) 不共线，任意向量 \(\boldsymbol{a} = \lambda_1\boldsymbol{e}_1 + \lambda_2\boldsymbol{e}_2\) 的分解系数唯一确立；但绝不能直接套用勾股模长与点积公式，必须用数量积夹角展开。

基底形式 ②单位正交基底：坐标系与代数化的基石

运算极大简化：基向量互相垂直且模为 \(1\)（\(\boldsymbol{i}\perp\boldsymbol{j}\)）。向量直接化为有序数对 \((x, y)\)，勾股模长 \(|\boldsymbol{a}|=\sqrt{x^2+y^2}\) 与数量积 \(x_1x_2+y_1y_2\) 畅通无阻。

基底与基向量：同一平面内两个不共线的向量 \(\boldsymbol{e}_1, \boldsymbol{e}_2\) 叫作该平面的一组基底，\(\boldsymbol{e}_1, \boldsymbol{e}_2\) 叫作基向量。基向量绝不能共线，也不能是零向量。

例：向东 \(1\) 格的 \(\boldsymbol{e}_1\) 与向北 \(1\) 格的 \(\boldsymbol{e}_2\) 不共线，是一组基底；而 \((1, 0)\) 与 \((2, 0)\) 共线，不能当基底。

向量的坐标：在单位正交基底下，若 \(\boldsymbol{a} = x\boldsymbol{i} + y\boldsymbol{j}\)，有序实数对 \((x, y)\) 就叫向量 \(\boldsymbol{a}\) 的坐标，记作 \(\boldsymbol{a} = (x, y)\)。起点在原点 \(O(0,0)\)、终点在 \(P(x, y)\) 时，\(\overrightarrow{OP} = (x, y)\)。

2. 核心公式与坐标法则

① 基本定理：平面内任意向量 \(\boldsymbol{a} = \lambda_1\boldsymbol{e}_1 + \lambda_2\boldsymbol{e}_2\)（\(\boldsymbol{e}_1,\boldsymbol{e}_2\) 不共线，系数唯一）；
② 和差与数乘：\(\boldsymbol{a}\pm\boldsymbol{b} = (x_1\pm x_2, y_1\pm y_2)\)，\(\lambda\boldsymbol{a} = (\lambda x_1, \lambda y_1)\)；
③ 终点减起点：若 \(A(x_1, y_1), B(x_2, y_2)\)，则 \(\overrightarrow{AB} = (x_2 - x_1, y_2 - y_1)\)；
④ 模长与点乘：\(|\boldsymbol{a}| = \sqrt{x^2+y^2}\)，\(\boldsymbol{a}\cdot\boldsymbol{b} = x_1x_2 + y_1y_2\)；
⑤ 垂直与共线判定（高考必背）：
    • 垂直（\(\boldsymbol{a},\boldsymbol{b}\ne\boldsymbol{0}\)）：\(\boldsymbol{a}\perp\boldsymbol{b} \iff x_1x_2 + y_1y_2 = 0\)（同轴相乘相加等于 \(0\)）；
    • 共线：\(\boldsymbol{a}\parallel\boldsymbol{b} \iff x_1y_2 - x_2y_1 = 0\)（交叉相乘相减等于 \(0\)）。

例 1（基底表示）

平行四边形 \(ABCD\) 的对角线交于 \(O\)，\(M\) 为 \(BC\) 中点，\(\vec{AB}=\boldsymbol{a},\vec{AD}=\boldsymbol{b}\)。用这组基底表示 \(\vec{AC},\vec{AO},\vec{AM}\)。

波利亚四问：读懂 → 想办法 → 执行并检查 → 回头看。提示按需展开，思路可往返。

读懂：已知邻边向量和中点，求有方向的位移；图中没有直角条件。

提示 1：先找一条路

从 \(A\) 到 \(M\)，能否先到 \(B\)？每段方向是否首尾相接？

提示 2：换成基向量

对边向量如何替换？中点与对角线交点带来什么比例？

看示范与回顾

想办法：沿路把位移拆成邻边方向。只需向量加法与数乘，无需长度和夹角。

执行：平行四边形法则给出 \(\vec{AC}=\boldsymbol{a}+\boldsymbol{b}\)；对角线互相平分，\(\vec{AO}=\tfrac12(\boldsymbol{a}+\boldsymbol{b})\)；沿 \(A\to B\to M\)，\(\vec{AM}=\vec{AB}+\tfrac12\vec{BC}=\boldsymbol{a}+\tfrac12\boldsymbol{b}\)。

检查：\(\vec{BC}=\vec{AD}\)，方向相同；\(\vec{AO}=\tfrac12\vec{AC}\)。

回头看：若 \(M\) 换成 \(B\) 或 \(C\)，\(\boldsymbol{b}\) 的系数分别变为 \(0\)、\(1\)，还原 \(\vec{AB}\)、\(\vec{AC}\)。换分点，沿路拆分仍适用。

自己试试：在 \(\triangle ABC\) 中，点 \(D\) 是 \(BC\) 边上的中点。若设 \(\vec{AB} = \boldsymbol{c}, \vec{AC} = \boldsymbol{b}\)，则中线向量 \(\vec{AD} =\)？

A。以 \(AB, AC\) 为邻边作平行四边形 \(ABEC\)，对角线 \(\vec{AE} = \boldsymbol{b} + \boldsymbol{c}\)。因为平行四边形对角线互相平分，中点 \(D\) 正好是对角线中点，所以 \(\vec{AD} = \dfrac{1}{2}\vec{AE} = \dfrac{1}{2}\boldsymbol{b} + \dfrac{1}{2}\boldsymbol{c}\)。

例 2（坐标线性运算）

已知点 \(A(1, 2), B(3, -1), C(-2, 4)\)。

(1) 求向量 \(\vec{AB}\) 和 \(\vec{BC}\) 的坐标；(2) 求 \(2\vec{AB} - 3\vec{BC}\) 的坐标。

解：

(1) 终点减起点：\(\vec{AB} = (3-1, -1-2) = (2, -3)\)；\(\vec{BC} = (-2-3, 4-(-1)) = (-5, 5)\)；

(2) \(2\vec{AB} - 3\vec{BC} = 2(2, -3) - 3(-5, 5) = (4, -6) - (-15, 15) = (4 - (-15), -6 - 15) = (19, -21)\)。

自己试试：已知点 \(A(-1, 3)\)，向量 \(\vec{AB} = (4, -2)\)，则终点 \(B\) 的坐标为？

A。设 \(B(x, y)\)，由 \(\vec{AB} = (x - (-1), y - 3) = (x+1, y-3) = (4, -2)\)，解得 \(x+1=4 \implies x=3\)，\(y-3=-2 \implies y=1\)。故 \(B(3, 1)\)。选 B 的同学错当成了起点减终点；选 C 的同学把两点坐标直接加反了。

3. 典型例题：三步思维链精讲

例 3（位置关系判定·垂直与共线综合）

已知向量 \(\boldsymbol{a} = (3, 4)\)，\(\boldsymbol{b} = (m, -6)\)。

(1) 若 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，求实数 \(m\)；
(2) 若 \(\boldsymbol{a}\perp\boldsymbol{b}\)，求实数 \(m\)。

👀 第一眼·破题信号
看到向量坐标判定平行与垂直 → 核心破题信号：认准「垂直同轴相乘和为 0，共线交叉相乘差为 0」，绝不能记反，更不能用坐标除法！
🔧 第二步·套公式拆解
① 共线判定：套用交叉差公式 \(x_1y_2 - x_2y_1 = 0\)：
    \(3\times(-6) - 4\times m = 0 \implies -18 - 4m = 0 \implies m = -\dfrac{9}{2}\)；
② 垂直判定：套用同乘和公式 \(x_1x_2 + y_1y_2 = 0\)：
    \(3\times m + 4\times(-6) = 0 \implies 3m - 24 = 0 \implies m = 8\)。
🛡️ 第三步·必查防坑点
① 共线是「交叉相乘作差」：\(x_1y_2 - x_2y_1=0\)，中间是减号；
② 垂直是「对应坐标相乘作和」：\(x_1x_2 + y_1y_2=0\)，中间是加号；
③ 负号带括号：\(3\times(-6)=-18\)，避免负号丢失。

自己试试：已知向量 \(\boldsymbol{a} = (3, 4), \boldsymbol{b} = (x, -6)\)。若 \(\boldsymbol{a}\parallel\boldsymbol{b}\)，则 \(x\) 的值为？

C。套用共线公式 \(x_1y_2 - x_2y_1 = 0\)：\(3\times(-6) - 4\times x = 0 \implies -18 - 4x = 0 \implies x = -\dfrac{9}{2}\)。选 B 的同学误用了垂直公式 \(3x + 4(-6) = 0\)；选 D 的算漏了负号。

例 4（夹角与投影）：已知 \(\boldsymbol{a}=(4,2)\)、\(\boldsymbol{b}=(1,3)\)，求两向量的夹角及 \(\boldsymbol{b}\) 在 \(\boldsymbol{a}\) 上的投影向量。

本题两向量非零，夹角有定义。投影方向要求 \(\boldsymbol{a}\ne\boldsymbol{0}\)，用 \(\mathrm{proj}_{\boldsymbol{a}}\boldsymbol{b}=\dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}|^2}\boldsymbol{a}\)；下方视频还会检查负投影变式，区分投影向量、有向投影值与投影长度。

4. 这三种情况最容易翻车

翻车现场 ①共线公式与垂直公式彻底记反
错解

共线写成 \(x_1x_2 + y_1y_2 = 0\)，或者垂直写成 \(x_1y_2 - x_2y_1 = 0\)。

正解

垂直源于数量积为 0，是同轴乘积之和：\(x_1x_2 + y_1y_2 = 0\)；共线源于面积为 0，是交叉乘积之差：\(x_1y_2 - x_2y_1 = 0\)。

翻车现场 ②共线判定盲目套用除法形式
错解

写出 \(\dfrac{x_1}{x_2} = \dfrac{y_1}{y_2}\)，遇到坐标为 \(0\) 时直接除以 \(0\) 崩溃。

正解

反例：\(\boldsymbol{a}=(0, 2)\) 与 \(\boldsymbol{b}=(0, 4)\) 都在 \(y\) 轴上共线，但除法 \(\frac{0}{0}=\frac{2}{4}\) 无意义！永远使用整式交叉差 \(x_1y_2 - x_2y_1 = 0\)。

翻车现场 ③斜基底下误套勾股与点积公式
错解

在两基向量的模均为 \(1\)、夹角为 \(60^\circ\) 的基底下，对 \(\boldsymbol{a}=\boldsymbol{e}_1+\boldsymbol{e}_2\) 算模长直接写 \(\sqrt{1^2+1^2}=\sqrt{2}\)。

正解

勾股公式与数量积坐标公式严格依赖单位正交基底！斜基底真实模长为 \(\sqrt{|\boldsymbol{e}_1|^2 + 2\boldsymbol{e}_1\cdot\boldsymbol{e}_2 + |\boldsymbol{e}_2|^2} = \sqrt{3}\)，必须数量积展开。

再深一点（可以先跳过）

为什么共线是交叉相乘之差：二阶行列式 \(\begin{vmatrix}x_1 & y_1\\ x_2 & y_2\end{vmatrix} = x_1y_2 - x_2y_1\) 的几何意义是以 \(\boldsymbol{a}, \boldsymbol{b}\) 为邻边的平行四边形的有向面积。面积等于 \(0\)，说明平行四边形压成了一条线段，两向量自然共线。

向量三点共线定理：若点 \(P\) 在直线 \(AB\) 上，且 \(O\) 是直线外一点，则必有 \(\vec{OP} = \lambda\vec{OA} + \mu\vec{OB}\)，且实数满足 \(\lambda + \mu = 1\)。当 \(\lambda, \mu > 0\) 时，\(P\) 在线段 \(AB\) 内部；一正一负时，\(P\) 在线段延长线上。

① 基础：平面直角坐标系中的双向量与判定器

拖动墨绿点 \(A(x_1, y_1)\) 改变向量 \(\boldsymbol{a}\)，拖动赤金点 \(B(x_2, y_2)\) 改变向量 \(\boldsymbol{b}\)。观察下方坐标、模长、数量积与判定式徽章的实时计算。键盘操作：Tab 选中端点，方向键每次移动 \(1\) 个单位。

坐标：(3, 2)，模长：\(\sqrt{13} \approx 3.61\)

坐标：(-2, 3)，模长：\(\sqrt{13} \approx 3.61\)

② 进阶：斜基底 vs 直角基底（为什么斜基底不能套勾股？）

设单位基底 \(|\boldsymbol{e}_1|=1, |\boldsymbol{e}_2|=1\)，夹角为 \(\theta\)。观察合成向量 \(\boldsymbol{v} = 2\boldsymbol{e}_1 + 2\boldsymbol{e}_2\) 的真实模长与误套直角坐标勾股公式算出的假模长。拖动滑块改变夹角 \(\theta\)：

60°
真实模长 \(|\boldsymbol{v}|\)（余弦数量积求模）
\(\sqrt{8 + 8\cos 60^\circ} = \sqrt{12} \approx 3.46\)
误套直角勾股算出的假模长
\(\sqrt{2^2 + 2^2} = \sqrt{8} \approx 2.83\)

从易到难排好了。前两道直接用，中间三道是专题卡里的高频边界，最后一道是综合挑战。

直接用

1. 已知点 \(A(-1, 2), B(2, 6)\)，则向量 \(\vec{AB}\) 的模长 \(|\vec{AB}|\) 等于？

A。由终点减起点得 \(\vec{AB} = (2 - (-1), 6 - 2) = (3, 4)\)。由模长公式：\(|\vec{AB}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\)。选 C 的同学横坐标忘了减去负号（误算成了 \(2 - 1 = 1\)）；选 D 的同学忘了开平方。

2. 已知向量 \(\boldsymbol{a} = (2, 3), \boldsymbol{b} = (-6, x)\)。若 \(\boldsymbol{a}\perp\boldsymbol{b}\)，则实数 \(x =\)？

B。两非零向量垂直充要条件是数量积为 \(0\)：\(\boldsymbol{a}\perp\boldsymbol{b} \iff x_1x_2 + y_1y_2 = 0\)。代入得 \(2\times(-6) + 3\times x = 0 \implies -12 + 3x = 0 \implies x = 4\)。选 A 的同学混淆了共线与垂直公式（误算了 \(2x - 3(-6) = 0\)）；选 C 的符号算错。

易错

3. 已知向量 \(\boldsymbol{a} = (0, 3)\) 与 \(\boldsymbol{b} = (m, -6)\) 共线，则实数 \(m =\)？

B。牢记共线充要条件是交叉相乘之差为 0：\(x_1y_2 - x_2y_1 = 0\)。

代入得 \(0\times(-6) - m\times 3 = 0 \implies -3m = 0 \implies m = 0\)。此时 \(\boldsymbol{b} = (0, -6) = -2\boldsymbol{a}\)，两向量都在 \(y\) 轴上，完全共线。如果套用「坐标相除」\(\dfrac{0}{m} = \dfrac{3}{-6}\)，就会陷入分母为 0 的困境甚至误选 A。

4. 下列各组向量中，不能作为平面向量一组基底的是？

B。基底的数学前提是两个不共线的向量。检查 B 选项：\(2\times 6 - (-3)\times(-4) = 12 - 12 = 0\)，即 \(\boldsymbol{e}_2 = -2\boldsymbol{e}_1\)，两向量在同一直线上（共线），无法分解出垂直于该直线方向的分量，因此不能作为基底。其余三组交叉相乘之差均不为 \(0\)，两向量互不共线，都是合格基底。

5. 已知平面基底 \(\{\boldsymbol{e}_1, \boldsymbol{e}_2\}\) 满足 \(|\boldsymbol{e}_1| = 1, |\boldsymbol{e}_2| = 1\)，且 \(\boldsymbol{e}_1\) 与 \(\boldsymbol{e}_2\) 的夹角为 \(60^\circ\)。若向量 \(\boldsymbol{a} = \boldsymbol{e}_1 + \boldsymbol{e}_2\)，则模长 \(|\boldsymbol{a}| =\)？

B。选 A 的同学直接套用了直角坐标勾股公式 \(\sqrt{1^2 + 1^2} = \sqrt{2}\)，这是大忌！只有在单位正交基底（夹角为 \(90^\circ\)）下勾股公式才成立。这里夹角是 \(60^\circ\)，必须求模平方：\(|\boldsymbol{a}|^2 = (\boldsymbol{e}_1 + \boldsymbol{e}_2)^2 = |\boldsymbol{e}_1|^2 + 2\boldsymbol{e}_1\cdot\boldsymbol{e}_2 + |\boldsymbol{e}_2|^2 = 1 + 2\times 1\times 1\times\cos 60^\circ + 1 = 1 + 1 + 1 = 3\)，开方得 \(|\boldsymbol{a}| = \sqrt{3}\)。

挑战

6. 点 \(O\) 为平面内任一点，向量 \(\vec{OP} = x\vec{OA} + y\vec{OB}\)（其中 \(O, A, B\) 三点不共线）。则点 \(A, P, B\) 三点共线的充要条件是？

需要一点方向提示？

把共线写成 \(\vec{AP}=t\vec{AB}\)，再把两边都换成从 \(O\) 出发的向量。为什么能比较系数？

A。这是经典的向量三点共线定理。推导如下：

\(A, P, B\) 共线 \(\iff \vec{AP} = t\vec{AB}\) \(\iff \vec{OP} - \vec{OA} = t(\vec{OB} - \vec{OA})\) \(\iff \vec{OP} = (1-t)\vec{OA} + t\vec{OB}\)。令 \(x = 1-t, y = t\)，立得 \(x + y = 1\)。

反过来，只要基底前面的两个系数之和等于 \(1\)，终点 \(P\) 就必然落在过 \(A, B\) 的直线上。

回顾变式：若要求 \(P\) 在线段内部，还须 \(x,y>0\)；系数和为 \(1\) 也允许端点和延长线。比较系数依据基底分解唯一。
