2.3 直线的交点坐标与距离公式

有了直线的方程，「两条路在哪儿相交」「两地相距多远」「点离直线多远」都能直接算出来。先从地图上的一段路开始。

一张公园地图画在坐标纸上，每格 \(100\) 米。小林家在点 \((1,2)\)，学校在点 \((4,6)\)。先点按钮对比「沿街走折线」和「穿草坪走直线」：

如果能穿过草坪走直线，家到学校有多远？

A。往右 \(3\) 格、往上 \(4\) 格，直线正好是直角三角形的斜边：\(\sqrt{3^2+4^2}=5\) 格，即 \(500\) 米。沿格子线走才是 \(3+4=7\) 格（\(700\) 米）。

这一节就是把这种「用坐标算」做成公式：两条直线的交点、两点间距离、点到直线的距离、两条平行线间的距离。

1. 先认识几个词

要用到：斜率（回看 2.1）；直线的一般式（回看 2.2）；向量的坐标和数量积（回看 6.3）。

课本用词：点到直线距离公式的分母是 \(\sqrt{A^2+B^2}\)，一般式系数不能同时为零；两直线平行时才使用平行线距离。

伴读直觉微图解：交点、点线距离与平行线距离

直线一般式：任何直线均可化为 \(Ax+By+C=0\)（\(A,B\) 不同时为 \(0\)）。求距离前必须先化一般式。

例：\(y=2x+1\) 移项得 \(2x-y+1=0\)，\(A=2, B=-1, C=1\)（注意 \(B=-1\)，不是 \(1\)）。竖直线 \(x=3\) 即 \(x-3=0\)，\(A=1, B=0, C=-3\)。

垂足与距离：过点 \(P\) 向直线作垂线，交点叫垂足 \(H\)。线段 \(PH\) 的长就是点到直线的距离，是 \(P\) 到线上所有点中最短的一条。

例：\((3,4)\) 到 \(x\) 轴的垂足是 \((3,0)\)，距离为 \(|4|=4\)；到原点距离为 \(5\)，显然比垂距长。

前提辨析 平行线距离公式 vs 系数统一前提

严格前提：公式 \(d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}\) 必须两方程的 \(A, B\) 完全相同！

翻车警示：若求 \(3x+4y-2=0\) 与 \(6x+8y+1=0\) 距离，绝不可直接 \(\frac{|-2-1|}{\sqrt{3^2+4^2}}\)！必须先将第二条化为 \(3x+4y+\frac12=0\)。

口诀：系数不一致，先倍化统一，再直接相减分子常数项。

算法辨析 坐标垂足联立法 vs 法向量代数投影法

垂足法：求垂线斜率 \(\to\) 设垂线方程 \(\to\) 联立方程求垂足 \(H \to\) 套两点距离公式。步骤多且易错。

距离公式：直接把点 \((x_0,y_0)\) 代入方程左边分子加绝对值，分母除以 \(\sqrt{A^2+B^2}\)，一步得出极值垂距。

高考秒杀：点到线距离直接用公式；唯有题目指名问垂足坐标时才联立求交点。

点到直线距离：\(d = \dfrac{\color{#dc2626}{|A x_0 + B y_0 + C|}}{\color{#059669}{\sqrt{A^2 + B^2}}} \quad (A^2+B^2 \ne 0)\)
两条平行线间距离：\(d = \dfrac{\color{#2563eb}{|C_1 - C_2|}}{\color{#059669}{\sqrt{A^2 + B^2}}} \quad (l_1, l_2 \text{ 的 } A, B \text{ 必须统一！})\)

2. 两条直线的交点：解方程组

交点同时在两条直线上，所以它的坐标同时满足两个方程。把两个方程联立，解出来的 \((x,y)\) 就是交点。

例 1（看一遍怎么写）

求直线 \(2x-y+1=0\) 与 \(x+y-4=0\) 的交点。

两式相加，\(y\) 消掉：\(3x-3=0\)，\(x=1\)。代回第二式：\(1+y-4=0\)，\(y=3\)。

检验：\((1,3)\) 代进第一式 \(2-3+1=0\)，代进第二式 \(1+3-4=0\)，都成立。交点是 \((1,3)\)。

自己试试：直线 \(x-y-1=0\) 与 \(x+y-5=0\) 的交点是？

A。相加得 \(2x-6=0\)，\(x=3\)；代回 \(3+y-5=0\)，\(y=2\)。选 B 的同学把 \(x\)、\(y\) 写反了；最后代回两个方程检验一下就能发现。

方程组有唯一解 ⟺ 两直线相交；无解 ⟺ 平行；无穷多解 ⟺ 重合。

3. 两点间的距离

点 \(P_1(x_1,y_1)\)、\(P_2(x_2,y_2)\)：横着差 \(|x_2-x_1|\)，竖着差 \(|y_2-y_1|\)，这两段是直角边，\(P_1P_2\) 是斜边。勾股定理给出

\(|P_1P_2|=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\)

平方之后正负号就不要紧了，所以谁减谁都可以。

例 2

\(A(-1,2)\)，\(B(2,-2)\)，求 \(|AB|\)。

\(x\) 差 \(2-(-1)=3\)，\(y\) 差 \(-2-2=-4\)。\(|AB|=\sqrt{3^2+(-4)^2}=\sqrt{25}=5\)。

自己试试：\(M(-2,3)\)，\(N(4,-5)\)，\(|MN|\) 是？

A。\(x\) 差 \(6\)，\(y\) 差 \(-8\)，\(\sqrt{36+64}=10\)。B 是 \(6+8\)，那是沿格子走；C 是把坐标加起来了（\(-2+4\)、\(3-5\)）；D 忘了开方。

4. 点到直线的距离

点 \(P(x_0,y_0)\) 到直线 \(Ax+By+C=0\)（\(A^2+B^2>0\)）的距离

\(d=\dfrac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}\)

先看特殊的：直线 \(y=2\)，写成 \(0\cdot x+1\cdot y-2=0\)。点 \((3,5)\) 到它的距离一眼看出是 \(5-2=3\)，公式给出 \(\dfrac{|0+5-2|}{\sqrt{0+1}}=3\)，一样。直线斜过来时，分子 \(|Ax_0+By_0+C|\) 还是「代进去差多少」，分母 \(\sqrt{A^2+B^2}\) 把系数的大小除掉。

例 3（公式算一遍，再用垂足验一遍）

求点 \(P(2,1)\) 到直线 \(3x+4y+5=0\) 的距离。

公式：\(d=\dfrac{|3\cdot2+4\cdot1+5|}{\sqrt{3^2+4^2}}=\dfrac{15}{5}=3\)。

验证：过 \(P\) 的垂线沿方向 \((3,4)\)，上面的点是 \((2+3t,\ 1+4t)\)。代进直线：\(3(2+3t)+4(1+4t)+5=15+25t=0\)，\(t=-0.6\)，垂足 \(H(0.2,-1.4)\)。\(|PH|=\sqrt{1.8^2+2.4^2}=\sqrt{9}=3\)，对上了。

自己试试：原点到直线 \(3x-4y+10=0\) 的距离是？

A。\(\dfrac{|0-0+10|}{\sqrt{9+16}}=\dfrac{10}{5}=2\)。B 是除以 \(25\)，忘了开方；C 忘了分母；D 是除以 \(3+4\)。

5. 两条平行线间的距离

在一条上任取一点，算它到另一条的距离就行。如果两条写成同一组 \(A\)、\(B\)：\(Ax+By+C_1=0\) 与 \(Ax+By+C_2=0\)，就有

\(d=\dfrac{|C_1-C_2|}{\sqrt{A^2+B^2}}\)

例 4

求 \(3x+4y-2=0\) 与 \(6x+8y+1=0\) 间的距离。

第二条的 \(A\)、\(B\) 是 \(6\)、\(8\)，先两边除以 \(2\)：\(3x+4y+\dfrac12=0\)。现在 \(A\)、\(B\) 一样了，\(d=\dfrac{|-2-\frac12|}{5}=\dfrac12\)。

验证：第一条上取点 \((0,\frac12)\)，到第二条 \(\dfrac{|0+4+1|}{\sqrt{36+64}}=\dfrac{5}{10}=\dfrac12\)。

自己试试：\(x+y-1=0\) 与 \(x+y+3=0\) 间的距离是？

A。\(\dfrac{|-1-3|}{\sqrt{1+1}}=\dfrac4{\sqrt2}=2\sqrt2\)。B 忘了分母；C 是 \(C_1+C_2\) 当成了 \(C_1-C_2\)。

6. 三步破题思维链：直线距离与交点解题标准动作

1
👀 第一眼破题信号

审清题目信息：是求点到直线距离、求两条平行线间距离，还是由距离已知反求动点或直线参数。先把涉及的所有直线方程无条件全部化成一般式 \(Ax+By+C=0\)。

2
🔧 第二步套公式/方法

① 点到直线距离：代入 \(d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}\)，严禁漏掉分子绝对值；
② 平行线间距离：先倍化统一两方程的 \(A, B\) 项，再套用 \(d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}\)；
③ 若已知距离求直线方程：脱绝对值时必须分类讨论正负双解（对称分布在两侧）。

3
🛡️ 第三步必查防坑结论

① 平行线距离千万不可在 \(A, B\) 不同的情况下直接分子相减；
② 动点轨迹到直线距离为定值时，当给定距离d>0时，轨迹是两条平行直线；d=0时是原直线，d<0时没有满足条件的点。

7. 三大翻车现场与反例辨析

翻车现场 1：平行线求距未统系数直接相减
❌ 求 \(3x+4y-2=0\) 与 \(6x+8y+1=0\) 距离，直接套公式 \(\frac{|-2-1|}{\sqrt{3^2+4^2}}=\frac35\)
✔ 第二式化为 \(3x+4y+\frac12=0\)，距离为 \(\frac{|-2-\frac12|}{5}=\frac12\)
翻车现场 2：斜截式代入距离公式符号混乱
❌ 求 \((1,1)\) 到 \(y=2x+1\) 距离，直接把 \(A=2,B=1,C=1\) 代入公式
✔ 移项化一般式 \(2x-y+1=0\)，正确读出 \(A=2, B=-1, C=1\)
翻车现场 3：已知距离反解参数遗漏双解
❌ 由 \(\frac{|m+3|}{5}=2\) 直接脱绝对值写 \(m+3=10 \Rightarrow m=7\)，只写一个答案
✔ 脱绝对值必带正负：\(m+3=\pm 10 \Rightarrow m=7\) 或 \(m=-13\)，两解齐全
反例微图解：平行线距离系数未统一的严重偏差
\(6x+8y+1=0\) 的常数项 \(1\) 相当于在 \(3x+4y\) 基底下的 \(\frac12\)。未统一系数时错算为0.6，正确是0.5，偏大20%。
再深一点（可以先跳过）

向量投影法推公式：直线 \(Ax+By+C=0\) 上任取两点 \(Q_1\)、\(Q_2\)，相减得 \(A(x_2-x_1)+B(y_2-y_1)=0\)，向量 \(\boldsymbol{n}=(A,B)\) 是直线的法向量。在直线上任取一点 \(Q(x_q,y_q)\)，距离就是 \(\overrightarrow{QP}\) 在 \(\boldsymbol{n}\) 方向上投影的长：\(d=\dfrac{|\overrightarrow{QP}\cdot\boldsymbol{n}|}{|\boldsymbol{n}|}=\dfrac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}\)。

符号的几何意义：\(Ax_0+By_0+C\) 的正负表示点在直线的哪一侧，同侧同号、异侧异号。常用于线性规划与不等式区域判定。

① 拖点 P 和直线，看垂足和距离

直线由 \(Q_1\)、\(Q_2\) 两点决定。拖动 \(P\)、\(Q_1\)、\(Q_2\)（或选中后按方向键，每次一格）。金色线是垂线段 \(PH\)。下面用两种方法算距离：点线距离公式、两点距离公式算 \(|PH|\)，看它们是不是一样。

② 进阶：两条直线，方程组有几个解

绿线 \(L_1\) 过 \(P_1\)、\(P_2\)，赤金线 \(L_2\) 过 \(P_3\)、\(P_4\)，四个点都能拖。相交时给交点；平行时先把系数统一，再算两线距离；重合时说明方程组有无穷多解。用按钮可以直接调成平行或重合。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 点 \(A(1,2)\) 到直线 \(3x-4y+15=0\) 的距离是？

A。\(\dfrac{|3-8+15|}{\sqrt{9+16}}=\dfrac{10}{5}=2\)。B 忘了分母；C 除以 \(25\) 没开方；D 把 \(-4\times2\) 算成了 \(+8\)。

2. \(A(a,3)\)，\(B(1,-1)\)，\(|AB|=5\)，且 \(a>0\)。\(a\) 是？

A。\((a-1)^2+(3+1)^2=25\)，\((a-1)^2=9\)，\(a=4\) 或 \(a=-2\)。题目说 \(a>0\)，只留 \(4\)。选 C 的同学没看条件；D 是漏了 \(y\) 方向的差，只算了 \(a-1=5\)。

易错

3. 直线 \(x-2y+1=0\) 与 \(3x-6y+3=0\) 的位置关系是？

C。斜率都是 \(\dfrac12\)，但第二个方程就是第一个乘 \(3\)，方程组有无穷多解，两条线是同一条。选 A 的同学只看了斜率，忘了先排除重合。

4. 点 \((2,3)\) 到直线 \(y=3x-1\) 的距离是？

A。先化一般式 \(3x-y-1=0\)：\(\dfrac{|6-3-1|}{\sqrt{9+1}}=\dfrac{2}{\sqrt{10}}=\dfrac{\sqrt{10}}{5}\)。B 是把 \(B\) 当成了 \(+1\)（\(|6+3-1|=8\)）；C 是漏了 \(y\) 那一项（\(|6-1|=5\)）。

5. 平行直线 \(x+y+1=0\) 与 \(2x+2y+5=0\) 间的距离是？

C。系数不一样，不能直接减。第二条除以 \(2\)：\(x+y+\dfrac52=0\)，\(d=\dfrac{|1-\frac52|}{\sqrt2}=\dfrac{3}{2\sqrt2}=\dfrac{3\sqrt2}{4}\)。A 是直接拿 \(1\) 和 \(5\) 相减；B 是相减后除以 \(\sqrt{8}\)；D 忘了分母。也可以在「动手」②里摆出两条平行线看。

挑战

6. 过点 \(P(1,2)\)、并且到原点距离为 \(1\) 的直线有几条？

B。设斜率 \(k\)：\(y-2=k(x-1)\)，即 \(kx-y+2-k=0\)。\(\dfrac{|2-k|}{\sqrt{k^2+1}}=1\)，平方得 \(4-4k+k^2=k^2+1\)，\(k=\dfrac34\)，直线 \(3x-4y+5=0\)。

只得到一条就停的同学（选 A），漏了没有斜率的竖直线 \(x=1\)：它过 \(P\)，到原点距离正好是 \(1\)。设斜率之前，先单独看竖直线。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
