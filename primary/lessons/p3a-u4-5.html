有关 0 的乘法

盘子都是空的，一共有几个桃？

桌上有 5 个盘子，每个盘子都是空的。盘子里一共有几个桃？

对，一个也没有，是 0 个。用加法算：0 + 0 + 0 + 0 + 0 = 0。

用乘法怎样写？这一课来看看。

1. 每盘 0 个

先摆 4 个盘子，每盘 2 个桃：2 + 2 + 2 + 2 = 8，就是 2 × 4 = 8。再把「每盘」减到 0，看一共几个。

每盘 0 个，4 个盘子：4 个 0 相加，是 0。写成乘法：0 × 4 = 0，也可以写成 4 × 0 = 0。

自己试试

0 × 5 = ？

5 个 0 相加，0 + 0 + 0 + 0 + 0 = 0，所以 0 × 5 = 0。

2. 连盘子也没有

再把「盘子」减到 0。没有盘子，一共几个桃？每盘改成 0 个，再看看。

自己试试

0 × 0 = ？

0 × 0 = 0。没有盘子，也没有桃，一共 0 个。

3. 乘 0 和加 0 不一样

9 + 0 = 9：9 个桃，再放 0 个，还是 9 个。

9 × 0 = 0：9 个 0 相加，一个也没有。

0 + 9 = 9，0 × 9 = 0。加 0、乘 0，得数不一样，先看清是加号还是乘号。

自己试试

哪一个算式的得数和别的不一样？

9 + 0 = 9，别的三个都是 0。

0 和任何数相乘都得 0。

0 和任何数相乘都得 0。

说的时候照这样说：「0 × 4 是 4 个 0 相加，一个也没有，所以是 0。」

两个容易错的地方

✗ 4 × 0 = 4把乘 0 当成了加 0。
✓ 4 × 0 = 04 个 0 相加，是 0。4 + 0 才是 4。
✗ 0 × 0 不能算以为两个 0 没法乘。
✓ 0 × 0 = 0没有盘子，也没有桃，一共 0 个。

直接用

0 × 4 = ？

0 和任何数相乘都得 0。

3 × 0 = ？

3 个 0 相加，是 0。

7 + 0 = ？

加 0，还是原来的数：7 + 0 = 7。

容易错

7 ○ 0 = 0，○ 里填什么？

7 × 0 = 0。

0 ○ 3 = 3，○ 里填什么？

0 + 3 = 3。

4 × 0 + 9 = ？

先算 4 × 0 = 0，再算 0 + 9 = 9。

想一想

□ × 7 = 0，□ 里填几？

0 × 7 = 0，□ 里填 0。
