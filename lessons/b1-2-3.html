2.3 二次函数与一元二次方程、不等式

一条抛物线，同时回答三个问题：方程 \(ax^2+bx+c=0\) 有哪些根，不等式 \(ax^2+bx+c>0\)（或 \(<0\)）在哪里成立。看图读答案，比背表格可靠。这里 \(a\ne0\)；二次项系数为零时另按一次式或常数处理。先从抛一个球的简化模型开始。

用一个竖直抛球的简化模型：从抛出到落地只看 \(0\le t\le4\)，\(t\) 秒后的高度是 \(h=4t-t^2\)（米）。点下面不同时刻 \(t\)（或直接点图上的圆点），看小球高度和抛物线怎么对应：

下面哪一刻，球正好落回地面？

代进去算：\(t=1\) 时 \(h=3\)，\(t=2\) 时 \(h=4\)，\(t=3\) 时 \(h=3\)，\(t=4\) 时 \(h=16-16=0\)。D。

「落地」就是 \(h=0\)，也就是方程 \(4t-t^2=0\)，即 \(t(4-t)=0\)，根是 \(0\)（刚抛出）和 \(4\)（落地）。「在空中」就是 \(h>0\)，也就是不等式 \(4t-t^2>0\)，答案是 \(0<t<4\)。

把 \(h\) 随 \(t\) 的变化画出来是一条开口向下的抛物线：和横轴交在 \(0\) 和 \(4\)，中间拱在横轴上方。方程的根看交点，不等式的解看上方还是下方——这一节就讲这件事。

1. 先认识几个词：从“抛物线浮沉”建立直觉

要用到：初中的二次函数图象（开口方向、与 \(x\) 轴交点）和因式分解；集合的写法（回看 1.1）；2.1 的不等式性质，两边乘负数要反向（回看 2.1）。先看下面这幅微图解：

直觉微图解 ①开口向上（\(a>0\)）时：抛物线浮沉与判别式 \(\Delta\)

核心概念 ②零点是实数，不是坐标点！

让函数值 \(y=0\) 的那个自变量 \(x\) 叫零点，它是一个实数（如 \(x=-1\) 和 \(x=2\)）；图象经过的 \((-1,0)\) 和 \((2,0)\) 叫与 \(x\) 轴的交点，零点是交点的横坐标！

核心概念 ③口诀“大于取两边、小于取中间”前提是 \(a > 0\)

只有开口向上时，水上部分才在两边展翅、水下部分才在谷底凹槽。若 \(a<0\)，可直接按开口向下的图象读正负，也可以两边同乘 \(-1\)、不等号反向后再用开口向上的规则。

2. 一个二次三项式，三种角色合一

设 \(a>0\)，并且 \(\Delta=b^2-4ac>0\)，有两个不同实根 \(x_1<x_2\)，三个问题一张图看清：

\(ax^2+bx+c = 0\)：找水面交点（实根 / 零点）。

\(ax^2+bx+c > 0\)：水上两侧，
\(x < x_1\) 或 \(x > x_2\)。

\(ax^2+bx+c < 0\)：水下凹槽，
\(x_1 < x < x_2\)。

例 1（看一遍怎么写）

求方程 \(2x^2-3x-2=0\) 的实根、函数 \(y=2x^2-3x-2\) 的零点，以及图象和 \(x\) 轴的交点。

因式分解：\(2x^2-3x-2=(2x+1)(x-2)\)。令它等于 \(0\)，得 \(x=-\dfrac12\) 或 \(x=2\)。

所以方程的实根是 \(-\dfrac12\) 和 \(2\)；函数的零点也是 \(-\dfrac12\) 和 \(2\)；图象和 \(x\) 轴交于 \(\left(-\dfrac12,0\right)\) 和 \((2,0)\)。

自己试试：函数 \(y=x^2-4x+3\) 的零点是？

B。\(x^2-4x+3=(x-1)(x-3)\)，\(x=1\) 和 \(x=3\) 时函数值是 \(0\)。选 A 的同学写成了交点，零点是交点的横坐标，是实数。C 是和 \(y\) 轴的交点；D 是 \(y<0\) 的解集。

3. 开口向上标准解法：三步破题思维链

例 2（示范：跟老师走一遍思考过程）

解不等式 \(x^2-x-6\ge0\)。

👀 第一眼看破题信号：二次项系数 \(a=1>0\) 开口向上已就绪，不等号是「\(\ge 0\)」，对应水上两侧且包含端点！
🔧 第二步因式分解求根： \(x^2-x-6=(x+2)(x-3)=0 \implies\) 两根为 \(x_1=-2, x_2=3\)。
🛡️ 第三步读图写出解集（带等号）： 开口向上，「\(\ge0\)」取两根外侧，两个有限端点取到，解集为 \(\{x\mid x\le-2\text{ 或 }x\ge3\}\)，即 \((-\infty,-2]\cup[3,+\infty)\)。

自己试试：不等式 \(x^2-5x+4<0\) 的解集是？

A。\(x^2-5x+4=(x-1)(x-4)\)，两根 \(1\) 和 \(4\)，「\(<0\)」取中间，根不要。选 D 的同学把根的符号弄反了：\(x-1=0\) 得 \(x=1\)，不是 \(-1\)。选 B 是读成了「\(>0\)」，选 C 是多要了端点。

4. 开口向下：两步化归法则

例 3（示范：跟老师走一遍思考过程）

解不等式 \(-2x^2+x+1\ge0\)。

👀 第一眼看破题信号：二次项系数是负数 \(-2\)，开口向下！绝不能直接套「大于取两边」！
🔧 第二步同乘 -1 变向（化归为标准型）： 两边同乘 \(-1\)，不等号反向：\(2x^2-x-1\le0\)。
🛡️ 第三步因式分解取中间： \((2x+1)(x-1)\le0\)，两根 \(-\dfrac12\) 和 \(1\)。标准型开口向上，「\(\le0\)」取中间，解集为 \(\left[-\dfrac12,1\right]\)。

自己试试：不等式 \(-x^2+2x+8>0\) 的解集是？

A。乘 \(-1\) 得 \(x^2-2x-8<0\)，即 \((x+2)(x-4)<0\)，取中间 \(-2<x<4\)。选 B 的同学乘了 \(-1\) 却忘了把「\(>\)」改成「\(<\)」。代 \(x=0\) 检查：\(8>0\)，\(0\) 应该在解集里，B 里没有它。

自己试试：不等式 \(x^2+2x+1<0\) 的解集是？

A。\(x^2+2x+1=(x+1)^2\ge0\)，永远不会小于 \(0\)。选 B 的同学把「\(<0\)」当成了「\(\le0\)」：\(x=-1\) 时值是 \(0\)，不满足「小于」。D 是「\(>0\)」的答案。

重根与无实根的边界：设 \(a>0\)。若 \(\Delta=0\)，令重根为 \(x_0\)，则 \(f(x)=a(x-x_0)^2\)：\(f<0\) 无解，\(f\le0\) 只取 \(x_0\)，\(f>0\) 取 \(\mathbf R\setminus\{x_0\}\)，\(f\ge0\) 取全体实数。若 \(\Delta<0\)，则恒有 \(f>0\)。

若 \(a<0\)，上述正负相反；严格不等号仍不能包括函数值为零的位置。若 \(a=0\)，不能再用二次函数的判别式规则。

5. 用之前必查：三大高频翻车现场

翻车现场 ①二次项系数含字母，漏查 \(a=0\)
❌ 典型错解：解不等式 \(mx^2+x-2>0\)，直接当成二次不等式计算判别式 \(\Delta\)。
✅ 一眼看清真相：\(m\) 正负与是否为零未知！若 \(m=0\)，原不等式退化为一次不等式 \(x-2>0 \implies x>2\)，图象是一条直线而非抛物线，必须单独拉出 \(m=0\) 讨论！
翻车现场 ②开口向下盲目套“大于取两边”
❌ 典型错解：解 \(-x^2+1>0\)，不看系数直接背口诀写成 \(x<-1\text{ 或 }x>1\)。
✅ 一眼看清真相：代入 \(x=2\) 得 \(-3>0\) 当场穿帮！开口向下时中间拱在水上，也可两边同乘 \(-1\)、不等号反向，化成 \(x^2-1<0\)，解得 \((-1,1)\)。
翻车现场 ③（高考最高频！）恒成立问题把 \(\Delta\) 符号弄反
❌ 典型错解：以为「\(ax^2+bx+c > 0\) 对一切 \(x\) 恒成立」要求判别式 \(\Delta > 0\)。
✅ 看右图秒懂真相：恒大于零意味着整条抛物线高悬在水面上方，和水面一个交点都不能有！因此需同时有 \(a>0\) 与 \(\Delta<0\)；只看判别式符号还不够。
再深一点（可以先跳过）

根不是整数时：\(x^2-2x-1<0\) 不能分成两个整系数一次因式，可以用求根公式：\(\Delta=4+4=8\)，根 \(x=\dfrac{2\pm2\sqrt2}{2}=1\pm\sqrt2\)。开口向上取中间，解集 \((1-\sqrt2,1+\sqrt2)\)。

从解集倒推：如果 \(ax^2+bx+c>0\) 的解集是 \((-1,2)\)，“\(>0\)”取了中间，说明开口向下 \(a<0\)，并且 \(-1\)、\(2\) 是两根，所以 \(ax^2+bx+c=a(x+1)(x-2)\)。

另一种看法：符号：\((x+1)(x-3)<0\) 就是两个因式一正一负，只能 \(x+1>0\) 且 \(x-3<0\)，得 \(-1<x<3\)，和读图的答案一样。

“一侧一直上升”：开口向上的抛物线在顶点右边越来越高，这里靠初中的图象知识就够用；严格的说法（单调性）在第 3 章。

① 拖抛物线，看根和解集

拉滑块改 \(a,b,c\)；也可以直接拖图上的顶点（键盘：先按 Tab 选中，再用方向键）。点下面四个按钮切换不等号，图上 \(x\) 轴的高亮段就是解集。实心点 ● 表示根在解集里，空心点 ○ 表示不在。

试试：

② 进阶：含参数，什么时候对一切 \(x\) 都成立

看 \(f(x)=mx^2-mx+1\)。拉 \(m\)（选中滑块后也能用方向键），看抛物线是不是整条在 \(x\) 轴上方。红色是 \(f(x)\le0\) 的地方，有红色就说明“\(f(x)>0\) 对一切 \(x\) 成立”不对。特别看看 \(m=0\) 和 \(m=4\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 不等式 \(x^2+x-12\le0\) 的解集是？

A。\(x^2+x-12=(x+4)(x-3)\)，两根 \(-4\) 和 \(3\)。开口向上，「\(\le0\)」取中间，根也要。选 B 漏了端点；选 C 读到了上方；选 D 是根的符号弄反了。

2. 关于 \(x\) 的方程 \(x^2-2x+k=0\) 没有实根，\(k\) 的取值范围是？

A。没有实根就是 \(\Delta<0\)：\((-2)^2-4k=4-4k<0\)，得 \(k>1\)。选 C 的同学把 \(k=1\) 也算进来了：那时 \(\Delta=0\)，方程是 \((x-1)^2=0\)，有一个重根 \(1\)。B、D 是有实根的情形。

易错

3. 不等式 \(-x^2+x+2>0\) 的解集是什么？（提示：\(-x^2+x+2=0\) 的两个根是 \(-1\) 和 \(2\)。）

B。卡在「开口朝哪」：\(x^2\) 前面是 \(-1\)，开口向下，中间拱在 \(x\) 轴上方，两边掉到下方，所以「大于 0」在两根中间。代 \(x=0\)：\(2>0\)，确实成立。

选 A 的同学背了「大于取两边」，这句话只在开口向上时对。稳妥的做法是先乘 \(-1\)、不等号反向，变成 \(x^2-x-2<0\) 再读。选 D 是把不等式和方程弄混了：\(-1\) 和 \(2\) 让式子等于 0，恰恰不满足「大于 0」。

4. 不等式 \(x^2-4x+4>0\) 的解集是？

C。卡在「根要不要」：\(x^2-4x+4=(x-2)^2\)，\(\Delta=0\)，抛物线在 \(x=2\) 处碰到 \(x\) 轴又回到上方——重根处不变号。除了 \(x=2\) 那一点值是 0，其余地方都大于 0。B 是「\(\ge 0\)」的答案；D 是「\(\le0\)」的答案。在「动手」①里点「重根」，再把四个不等号点一遍。

5. 一块长方形菜地，长比宽多 \(2\) 米，面积至少 \(8\) 平方米。设宽为 \(x\) 米，\(x\) 的取值范围是？

A。卡在「实际问题取交集」：\(x(x+2)\ge8\)，即 \(x^2+2x-8\ge0\)，\((x+4)(x-2)\ge0\)，解得 \(x\le-4\) 或 \(x\ge2\)。宽是长度，要 \(x>0\)，取交集只剩 \(x\ge2\)。选 B 的同学停在了不等式的解集；选 C 读成了中间。

挑战

6. 关于 \(x\) 的不等式 \(mx^2-mx+1>0\) 对一切实数 \(x\) 都成立，\(m\) 的取值范围是？

B。卡在「真是二次吗」：\(m\) 是参数，先看 \(m=0\)：式子变成 \(1>0\)，对所有 \(x\) 都成立，所以 \(m=0\) 要算进去。

\(m\neq0\) 时是二次式。要整条抛物线都在 \(x\) 轴上方，必须开口向上 \(m>0\)，并且和 \(x\) 轴没有交点 \(\Delta=m^2-4m<0\)，得 \(0<m<4\)。\(m=4\) 时 \(\Delta=0\)，式子是 \((2x-1)^2\)，在 \(x=\tfrac12\) 处等于 0，不满足「\(>0\)」。合起来是 \(0\le m<4\)。选 A 漏了 \(m=0\)；选 C 多了 \(m=4\)。可以在「动手」②里拉 \(m\) 对照。

先独立作答，做完再对照分步解析。选择题点选项自动判对错；填空题写法不同时（集合写法、区间写法都对），看答案自己判。要用到后面章节的题收在最后，学到那里再做。
