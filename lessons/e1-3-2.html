3.2 双曲线

从声源定位的时间差到冷却塔的双曲面外形，双曲线以「距离差的绝对值恒定」刻画了两支无限延伸的对称曲线。正项定实轴、渐近线无限逼近、离心率大于 1 是洞悉双曲线本质的三把钥匙。

在海防导航或防空预警中，两个相距 \(10\text{ km}\) 的监测站 \(F_1, F_2\) 同时记录到某处海域传来的爆炸声。由于声音传播需要时间，\(F_1\) 站比 \(F_2\) 站晚了 \(2\) 秒听到声响（声速取 \(3\text{ km/s}\)）。

这意味着声源 \(P\) 到两监测站的距离差满足 \(|PF_1| - |PF_2| = 2 \times 3 = 6\text{ km}\)。

如果动点 \(P\) 满足条件 \(|PF_1| - |PF_2| = 6\text{ km}\)（注意：此处没有加绝对值！），那么声源 \(P\) 可能所在的轨迹是什么图形？

B。注意看式子：\(|PF_1| - |PF_2| = 6 > 0\)，这意味着 \(|PF_1| = |PF_2| + 6\)。

点 \(P\) 到 \(F_1\) 的距离永远比到 \(F_2\) 的距离大 \(6\text{ km}\)，因此点 \(P\) 必然更靠近 \(F_2\)，只能画出靠近 \(F_2\) 的单单一支（右支）！

只有当我们加上绝对值，写成 \(||PF_1| - |PF_2|| = 6\) 时，点 \(P\) 既可以更靠近 \(F_2\)（\(|PF_1| - |PF_2| = 6\)），也可以更靠近 \(F_1\)（\(|PF_2| - |PF_1| = 6\)），此时才是一左一右两支对称的完整双曲线！

这就是双曲线定义中最容易被忽略的第一道关键红线：距离差的「绝对值」！

1. 先认识几个词

要用到：两点间距离公式（回看 2.3）；椭圆的定义和 \(a,b,c\)（回看 3.1 椭圆），双曲线的研究路子和它一样。

焦点、焦距：定义里那两个定点叫焦点 \(F_1,F_2\)，它们之间的距离 \(|F_1F_2|=2c\) 叫焦距，\(c\) 叫半焦距。

例：\(F_1(-5,0)\)、\(F_2(5,0)\)，焦距 \(2c=10\)，\(c=5\)。

实轴、虚轴：双曲线和焦点所在直线交于两个顶点，两顶点之间的线段是实轴，长 \(2a\)；另一条对称轴上取长 \(2b\) 的线段叫虚轴（曲线并不经过它的端点，所以叫「虚」）。

例：\(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\) 的顶点是 \((\pm4,0)\)，实轴长 \(8\)，虚轴长 \(2\times3=6\)。

离心率：\(e=\dfrac{c}{a}\)，和椭圆的写法一样，用来比曲线「张得多开」。

例：\(c=5\)，\(a=4\)，\(e=\dfrac54\)。

渐近线：曲线往远处走时越来越贴近的一条直线。

例：\(y=\dfrac1x\) 在 \(x=100\) 时 \(y=0.01\)，在 \(x=1000\) 时 \(y=0.001\)，越来越贴近 \(x\) 轴，但永远不等于 \(0\)。\(x\) 轴就是它的一条渐近线。

2. 定义：距离差的绝对值等于 \(2a\)

椭圆是「到两焦点距离的和一定」；把「和」换成「差」，就得到双曲线：

平面内到两个定点 \(F_1,F_2\) 的距离之差的绝对值等于常数 \(2a\)，并且 \(0<2a<|F_1F_2|=2c\)，这样的点的轨迹叫双曲线。$$\big||PF_1|-|PF_2|\big|=2a$$
  • 为什么要绝对值：\(|PF_1|-|PF_2|=2a\) 说明 \(P\) 离 \(F_2\) 更近，只得到靠近 \(F_2\) 的一支；\(|PF_1|-|PF_2|=-2a\) 是靠近 \(F_1\) 的另一支。加上绝对值，两支合起来才是整条双曲线。
  • 为什么要 \(2a<2c\)：三角形两边之差小于第三边，\(\big||PF_1|-|PF_2|\big|\) 最多等于 \(2c\)。等于 \(2c\) 时只剩两条射线，大于 \(2c\) 时一个点也没有（见第 6 块）。

例 1（两支都要想到）

双曲线 \(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\) 上一点 \(P\) 到右焦点 \(F_2\) 的距离是 \(10\)，求它到左焦点 \(F_1\) 的距离。

\(a=4\)，\(b=3\)，\(c=\sqrt{16+9}=5\)。由定义 \(\big||PF_1|-10\big|=2a=8\)，所以 \(|PF_1|=18\) 或 \(|PF_1|=2\)。

两个都要检查能不能取到：

右支上的点到 \(F_2\) 的距离最小是 \(c-a=1\)，\(10\ge1\)，可以；这时 \(|PF_1|=10+8=18\)。

左支上的点到 \(F_2\) 的距离最小是 \(a+c=9\)，\(10\ge9\)，也可以；这时 \(|PF_1|=10-8=2\)，而左支上到 \(F_1\) 的距离最小是 \(c-a=1\)，\(2\ge1\)，对得上。

所以 \(|PF_1|=18\) 或 \(2\)。题目若说明 \(P\) 在右支上，就只剩 \(18\)。

自己试试：\(P\) 在双曲线 \(\dfrac{x^2}{9}-\dfrac{y^2}{16}=1\) 的右支上，\(|PF_1|=10\)，那么 \(|PF_2|=\)？

A。\(a=3\)，\(2a=6\)。右支上的点离 \(F_2\) 更近，\(|PF_1|-|PF_2|=6\)，所以 \(|PF_2|=10-6=4\)。选 B 是把差的方向弄反了（那是左支）；选 C 是没用上「右支」这个条件；选 D 是把 \(c-a\) 当成了答案。

3. 标准方程：正项定焦点

焦点放在 \(x\) 轴上：\(F_1(-c,0)\)、\(F_2(c,0)\)。用距离公式写出定义式，移项、两次平方化简，得到 \((c^2-a^2)x^2-a^2y^2=a^2(c^2-a^2)\)。因为 \(c>a\)，令 \(b^2=c^2-a^2>0\)，就是

焦点在 \(x\) 轴：$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1,\quad F(\pm c,0)$$ 焦点在 \(y\) 轴：$$\frac{y^2}{a^2}-\frac{x^2}{b^2}=1,\quad F(0,\pm c)$$ 其中 \(a>0\)，\(b>0\)，\(c^2=a^2+b^2\)。

怎么看焦点在哪个轴：哪一项是正的，焦点就在哪个轴上，正项下面的分母是 \(a^2\)。这和椭圆「看分母谁大」不一样：双曲线里 \(a\) 可以比 \(b\) 小。

例 2

双曲线 \(\dfrac{y^2}{9}-\dfrac{x^2}{16}=1\)，求实轴长、虚轴长、焦距、焦点和顶点坐标。

正号在 \(y^2\) 项上，焦点在 \(y\) 轴上。\(a^2=9\)，\(a=3\)；\(b^2=16\)，\(b=4\)。这里 \(a<b\)，没有问题。

\(c^2=a^2+b^2=9+16=25\)，\(c=5\)。

实轴长 \(2a=6\)，虚轴长 \(2b=8\)，焦距 \(2c=10\)。

焦点 \((0,-5)\)、\((0,5)\)；顶点 \((0,\pm3)\)。

自己试试：方程 \(-\dfrac{x^2}{9}+\dfrac{y^2}{7}=1\) 表示的双曲线，焦点坐标是？

A。改写成 \(\dfrac{y^2}{7}-\dfrac{x^2}{9}=1\)，正项是 \(y^2\)，焦点在 \(y\) 轴上；\(c^2=7+9=16\)，\(c=4\)。选 B 是按「分母大的在哪个轴」判断，那是椭圆的做法；选 C、D 是用了椭圆的 \(c^2=a^2-b^2\)。

4. \(a,b,c\) 的关系和离心率

双曲线里 \(c^2=a^2+b^2\)，\(c\) 最大，像直角三角形的斜边；椭圆里是 \(a^2=b^2+c^2\)，\(a\) 最大。两个式子别记混。

因为 \(c>a>0\)，离心率

$$e=\frac ca=\sqrt{1+\Big(\frac ba\Big)^2}>1$$

（椭圆的 \(e\) 在 \(0\) 和 \(1\) 之间。）\(e\) 越大，\(\dfrac ba\) 越大，双曲线的开口越开阔。

例 3

双曲线的焦点在 \(x\) 轴上，虚轴长 \(6\)，离心率 \(e=\dfrac54\)，求它的标准方程。

虚轴长 \(2b=6\)，\(b=3\)。由 \(e=\dfrac ca=\dfrac54\) 得 \(c=\dfrac54a\)。

代入 \(c^2=a^2+b^2\)：\(\dfrac{25}{16}a^2=a^2+9\)，\(\dfrac{9}{16}a^2=9\)，\(a^2=16\)。

所以方程是 \(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\)。验算：\(c=5\)，\(e=\dfrac54\)，对。

自己试试：双曲线 \(\dfrac{x^2}{4}-\dfrac{y^2}{5}=1\) 的离心率是？

A。\(a=2\)，\(c^2=4+5=9\)，\(c=3\)，\(e=\dfrac32\)。选 B 算的是 \(\dfrac ba\)；选 D 算的是 \(\dfrac cb\)；选 C 把 \(a^2=4\) 当成了 \(a\)，而且双曲线的 \(e\) 不可能小于 \(1\)，看一眼就能排除。

5. 渐近线

把标准方程右边的 \(1\) 换成 \(0\)，因式分解就得到两条渐近线：

\(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\) 的渐近线是 \(y=\pm\dfrac bax\)；\(\dfrac{y^2}{a^2}-\dfrac{x^2}{b^2}=1\) 的渐近线是 \(y=\pm\dfrac abx\)。

为什么叫「渐近」：看 \(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\) 在第一象限的部分，\(y=\dfrac ba\sqrt{x^2-a^2}\)，比直线上的 \(\dfrac bax\) 小一点，差是

\(\dfrac ba\left(x-\sqrt{x^2-a^2}\right)=\dfrac{ab}{x+\sqrt{x^2-a^2}}\)，

\(x\) 越大，分母越大，差越小，趋近 \(0\) 但始终是正的：曲线越来越贴近直线，却碰不到。

例 4（接例 2：换了轴，斜率要重算）

\(\dfrac{y^2}{9}-\dfrac{x^2}{16}=1\)：令 \(\dfrac{y^2}{9}-\dfrac{x^2}{16}=0\)，得 \(y^2=\dfrac{9}{16}x^2\)，渐近线 \(y=\pm\dfrac34x\)。

对比 \(\dfrac{x^2}{9}-\dfrac{y^2}{16}=1\)：令右边为 \(0\)，得 \(y^2=\dfrac{16}{9}x^2\)，渐近线 \(y=\pm\dfrac43x\)。分母一样，正项换了，斜率就倒过来。

在 \(\dfrac{x^2}{9}-\dfrac{y^2}{16}=1\) 上看看有多「近」：

\(x=15\) 时，曲线 \(y=\dfrac43\sqrt{216}=8\sqrt6\approx19.60\)，直线 \(y=20\)，差约 \(0.40\)；

\(x=30\) 时，曲线 \(y=\dfrac43\sqrt{891}=12\sqrt{11}\approx39.80\)，直线 \(y=40\)，差约 \(0.20\)。

自己试试：已知双曲线方程为 \(\dfrac{x^2}{4} - \dfrac{y^2}{12} = 1\)，则该双曲线的离心率 \(e\) 和渐近线方程分别为：

A。正项是 \(x^2\)，焦点在 \(x\) 轴上。\(a^2 = 4\)，\(a = 2\)；\(b^2 = 12\)，\(b = 2\sqrt{3}\)。

\(c^2 = a^2 + b^2 = 16\)，\(c = 4\)，离心率 \(e = \dfrac{c}{a} = 2\)。

令右端为 \(0\)：\(y^2 = 3x^2\)，\(y = \pm \sqrt{3}x\)。

选 C 是把斜率写成了 \(\dfrac ab\)（那是焦点在 \(y\) 轴时的写法）；选 D 是把 \(\dfrac ba\) 当成了 \(e\)；选 B 的 \(4\) 是 \(\dfrac{c^2}{a^2}\)，忘了开方。

6. 专题卡 E1-03-B：用之前要注意

  1. 绝对值决定一支还是两支：\(\big||PF_1|-|PF_2|\big|=2a\) 是两支；没有绝对值的 \(|PF_1|-|PF_2|=2a\) 只是靠近 \(F_2\) 的一支。
    反例：\(F_1(-5,0)\)、\(F_2(5,0)\)，\(|PF_1|-|PF_2|=8\)。平方化简得到的 \(\dfrac{x^2}{16}-\dfrac{y^2}{9}=1\) 是整条双曲线，但左顶点 \((-4,0)\) 代回去是 \(1-9=-8\)，不满足。要筛掉左支，只留 \(x\ge4\) 的部分。
  2. 常数和焦距比大小（\(|F_1F_2|=2c\)，常数为 \(2a\)）：
    • \(0<2a<2c\)：双曲线；
    • \(2a=2c\)：两条射线（从 \(F_1\)、\(F_2\) 各自向外）；
    • \(2a>2c\)：没有这样的点；
    • 常数为 \(0\)，即 \(|PF_1|=|PF_2|\)：线段 \(F_1F_2\) 的垂直平分线。
    反例：\(F_1(-3,0)\)、\(F_2(3,0)\)，\(\big||PF_1|-|PF_2|\big|=6\)。点 \((5,0)\) 满足 \(8-2=6\)，可不在 \(x\) 轴上的点 \(P\) 和 \(F_1,F_2\) 围成三角形，两边之差小于 \(6\)，都不满足：轨迹是 \(x\ge3\) 和 \(x\le-3\) 两条射线，不是双曲线。
  3. 正项定实轴，不看分母大小。
    反例：\(\dfrac{y^2}{4}-\dfrac{x^2}{25}=1\) 的 \(a=2\)，不是 \(5\)；焦点在 \(y\) 轴上。
  4. \(c^2=a^2+b^2\)，不是椭圆的 \(a^2=b^2+c^2\)。
    反例：\(\dfrac{x^2}{25}-\dfrac{y^2}{16}=1\) 的 \(c=\sqrt{41}\)；用椭圆的公式会算成 \(3\)。
  5. 换了轴，渐近线要重新算：焦点在 \(y\) 轴时斜率是 \(\pm\dfrac ab\)，不要套 \(\pm\dfrac ba\)（例 4）。
  6. 渐近线说的是「无限贴近」：图上画到远处看着和直线贴在一起，不等于相交；双曲线和自己的渐近线确实没有公共点。但这不能推广成「任何曲线都不和自己的渐近线相交」。
    反例：\(y=\dfrac{\sin x}{x}\) 以 \(x\) 轴为渐近线，可它在 \(x=\pi,2\pi,\dots\) 处都和 \(x\) 轴相交。
再深一点（可以先跳过）

等轴双曲线：\(a=b\) 时方程是 \(x^2-y^2=a^2\)（或 \(y^2-x^2=a^2\)），渐近线 \(y=\pm x\) 互相垂直，\(c=\sqrt2a\)，离心率 \(e=\sqrt2\)。

共渐近线的双曲线：\(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=\lambda\)（\(\lambda\ne0\)）都以 \(y=\pm\dfrac bax\) 为渐近线；\(\lambda>0\) 时焦点在 \(x\) 轴，\(\lambda<0\) 时焦点换到 \(y\) 轴。「练一练」第 5 题会用到。

双曲线左右支与渐近线无限逼近微实验室

拖动动点 \(P\)（或按键盘方向键）沿双曲线移动。观察到两焦点的距离差绝对值 \(||PF_1| - |PF_2|| = 2a\) 恒定不变；当点 \(P\) 沿着曲线延伸向远处时，观察点 \(P\) 到渐近线的垂直距离 \(d \to 0\)：

从易到难排好了。做完直接出解析，帮你在实战中巩固几何量计算与避坑直觉。

直接用

1. 双曲线 \(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1\) 的焦点坐标与渐近线方程分别为：

A。① 正项是 \(x^2\)，焦点在 \(x\) 轴上；\(a^2 = 9 \implies a = 3\)，\(b^2 = 16 \implies b = 4\)。

② 由 \(c^2 = a^2 + b^2\) 得 \(c^2 = 9 + 16 = 25 \implies c = 5\)，故焦点坐标为 \((\pm 5, 0)\)（选 D 错用成椭圆的 \(c^2 = a^2 - b^2\)）。

③ 令右端为 \(0\)：\(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 0 \implies \dfrac{y^2}{16} = \dfrac{x^2}{9} \implies y = \pm \dfrac{4}{3}x\)（选 C 倒置了渐近线斜率）。

2. 已知双曲线的中心在原点，焦点在 \(y\) 轴上，焦距为 \(8\)，离心率 \(e = \dfrac{4}{3}\)，则该双曲线的标准方程为：

A。焦距 \(2c = 8 \implies c = 4\)。由离心率 \(e = \dfrac{c}{a} = \dfrac{4}{a} = \dfrac{4}{3}\) 得 \(a = 3 \implies a^2 = 9\)。

再由 \(c^2 = a^2 + b^2\) 得 \(b^2 = c^2 - a^2 = 16 - 9 = 7\)。

因为焦点在 \(y\) 轴上，正项为 \(y^2\)，故标准方程为 \(\dfrac{y^2}{9} - \dfrac{x^2}{7} = 1\)。选 B 选错焦点轴，选 C 误把半焦距 \(c\) 当作实半轴 \(a\)。

易错

3. 双曲线 \(\dfrac{y^2}{4} - \dfrac{x^2}{25} = 1\) 的实轴长为：

A。专题卡核心红线：正项确定实轴，绝不能看分母大小！

方程中带正号的项是 \(y^2\) 项，因此实半轴平方 \(a^2 = 4 \implies a = 2\)，虚半轴平方 \(b^2 = 25 \implies b = 5\)。

实轴长为 \(2a = 2 \times 2 = 4\)（切记问的是实轴长 \(2a\)，不是实半轴 \(a\)！选 C 漏乘了 2；选 B 或 D 受椭圆思维定势误把较大的分母 25 当作 \(a^2\)）。

4. 平面内两定点 \(F_1(-3, 0), F_2(3, 0)\)，动点 \(P\) 满足条件 \(|PF_1| - |PF_2| = 6\)，则点 \(P\) 的轨迹是：

C。计算两定点距离：焦距 \(2c = |F_1F_2| = 3 - (-3) = 6\)。

题目条件为 \(|PF_1| - |PF_2| = 6 = |F_1F_2|\)。根据平面几何两边之差小于第三边，任意点 \(P\) 都有 \(|PF_1| - |PF_2| \le |F_1F_2| = 6\)。

当且仅当点 \(P\) 落在以 \(F_2\) 为端点且背离 \(F_1\) 的射线（即 \(x \ge 3, y = 0\)）上时，才有 \(|PF_1| - |PF_2| = (x + 3) - (x - 3) = 6\)！

因此轨迹退化为一条射线！只有当常数严格满足 \(0 < 2a < 2c\) 且有绝对值时，才是双曲线。

5. 与双曲线 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\) 具有公共渐近线，且经过点 \((4, 3\sqrt{2})\) 的双曲线，其离心率 \(e\) 为：

B。设共渐近线的双曲线系方程为 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = \lambda \; (\lambda \ne 0)\)。

代入点 \((4, 3\sqrt{2})\)：\(\dfrac{16}{16} - \dfrac{18}{9} = 1 - 2 = -1 \implies \lambda = -1\)。

因此双曲线方程为 \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = -1\)，即 \(\dfrac{y^2}{9} - \dfrac{x^2}{16} = 1\)。

注意！焦点轴发生了转变：正项变成了 \(y^2\)，因此焦点在 \(y\) 轴上！此时实半轴 \(a = 3\)，虚半轴 \(b = 4\)，半焦距 \(c = \sqrt{9 + 16} = 5\)。

离心率 \(e = \dfrac{c}{a} = \dfrac{5}{3}\)（若误以为焦点仍为 \(x\) 轴算得 \(e = \dfrac{5}{4}\) 则选 A 掉入陷阱！）。

挑战

6. 点 \(P\) 是双曲线 \(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1\) 上一点，\(F_1, F_2\) 分别为其左、右焦点。若 \(\angle F_1PF_2 = 90^\circ\)，则 \(\triangle F_1PF_2\) 的面积为：

B。设 \(r_1 = |PF_1|, r_2 = |PF_2|\)。

① 根据双曲线定义：\(|r_1 - r_2| = 2a = 2 \times 3 = 6\)；两边平方得：\(r_1^2 + r_2^2 - 2r_1r_2 = 36\)。

② 在直角 \(\triangle F_1PF_2\) 中，勾股定理：\(r_1^2 + r_2^2 = |F_1F_2|^2 = (2c)^2 = 4c^2\)。

已知 \(c^2 = a^2 + b^2 = 9 + 16 = 25\)，所以 \(4c^2 = 100\)。
