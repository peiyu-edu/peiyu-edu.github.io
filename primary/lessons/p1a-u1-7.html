0 的认识和加、减法

家长先看（30 秒）
  • 今天认识数字0。0 有两个核心意思：①盘子里的东西吃光了，一个也没有，用 0 表示；②在直尺上排在 1 的最前面，表示起点。
  • 有关 0 的三类加减法请结合小故事帮孩子理解，不死背口诀：①全拿走了（3 − 3 = 0）；②一边一个也没有（4 + 0 = 4，0 + 4 = 4）；③一个也没拿走（5 − 0 = 5）。
  • 写 0 时在日字格左半格从上端起笔，逆时针一笔写成圆润的鹅蛋形，封口要合拢。
  • 留心一个常见错：看见算式里有 0 就一律写得数 0（把 5 − 0 或 4 + 0 也算成 0）。问孩子一句：“减 0 是全拿走了，还是一个也没拿走？”

每个喇叭按钮都能把字读出来；孩子认不全字时，点一下就行。

在家玩：空盘子与直尺寻 0

准备：1 把学生直尺，2 个小盘子，3 块小饼干（或葡萄）。

  1. 吃光盘子认 0：盘子里放 3 块饼干，吃掉 1 块问还剩几块，直到吃光，让孩子指着空盘子说「一个也没有，是 0」。
  2. 直尺找起点：拿出直尺，让孩子用手指找到最左边的「0」，顺着读「0、1、2、3、4、5」。
  3. 两个盘子演加减：左盘放 3 块、右盘空着（0 块），让孩子说出「3 + 0 = 3」；再玩「全部拿走（3 − 3 = 0）」和「一块也不拿（3 − 0 = 3）」。

夸孩子「你分清了全拿走是减 3，没拿走是减 0，真清楚」。
