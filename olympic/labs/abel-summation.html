04 / 为什么可以换方向？

设 N ≥ 0，a₁,…,aN 与 b₁,…,bN 为任意有限实数列，A₀ = 0，Aₖ = Σⱼ₌₁ᵏ aⱼ。对整数 1 ≤ m ≤ n ≤ N：

Σₖ₌ₘⁿ aₖbₖ = Aₙbₙ − Aₘ₋₁bₘ + Σₖ₌ₘⁿ⁻¹ Aₖ(bₖ − bₖ₊₁)

由 aₖ = Aₖ − Aₖ₋₁，展开为 Σ Aₖbₖ − Σ Aₖ₋₁bₖ。将第二个和的下标改为 j = k − 1，它从 m − 1 到 n − 1；配对中间项，剩下末项 Aₙbₙ 与起点扣除项 −Aₘ₋₁bₘ。这就是离散的分部积分。

若改用 Bₘ₋₁ = 0、Bₖ = Σⱼ₌ₘᵏ aⱼ = Aₖ − Aₘ₋₁，则公式变为：

Σₖ₌ₘⁿ aₖbₖ = Bₙbₙ + Σₖ₌ₘⁿ⁻¹ Bₖ(bₖ − bₖ₊₁)

两种部分和不能混用。n = m 时差分和为空，公式退为 (Aₘ − Aₘ₋₁)bₘ = aₘbₘ。m = n + 1 时原和为 0，本实验直接返回空图与 0，不套用非空区间的边界公式，也不读取不存在的 b₀ 或 bₙ₊₁。

图解中令 P 表示当前选用的 A 或 B。左图第 k 块为 [Pₖ₋₁ → Pₖ] × [0 → bₖ]，有向面积 aₖbₖ。右图末矩形为 [0 → Pₙ] × [0 → bₙ]；横层为 [0 → Pₖ] × [bₖ₊₁ → bₖ]；全局约定还须减去 [0 → Aₘ₋₁] × [0 → bₘ]。一般矩形按 c(x₁ − x₀)(y₁ − y₀) 计贡献，c 为显示的系数；宽高都负时贡献为正。负项、零宽与零高都合法；不要求单调、非负或无重叠。

当 a 非负且 b 非负递减、m = 1 时，矩形较容易看作普通阶梯区域；超出这些条件就须保留方向。此处只讨论有限恒等式，不据此断言无穷级数收敛。
