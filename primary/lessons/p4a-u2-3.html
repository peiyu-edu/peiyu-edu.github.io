四年级上册 · 第二单元 角的度量 · 第 3 课

画角

会用量角器量角了，反过来要画出指定度数的角（比如 50° 或 75°），该怎么动笔？

手工课上要画一个 50° 的角做纸飞机机翼。手里有直尺、一副三角尺和量角器。单靠三角尺上的现成角（30°、45°、60°、90°）能直接描出 50° 吗？

对！像 50°、70°、115° 这样的角，我们要用量角器按步骤画出来；而像 75°、105°、135° 这样的特殊角，不仅可以用量角器画，还能用一副三角尺拼出来！

1. 用量角器画角：定线 → 定点 → 连线

点下面的“第 1 步”“第 2 步”“第 3 步”，看怎样一步一步画出指定度数的角；再切换“开口向左”或点“看错圈会怎样”。

自己试试

在上面教具里选「画向左 70°」：先向左画了一条射线，这条射线对着量角器左边外圈的 0°。第 2 步找 70° 刻度点时，应该点在哪一圈的 70° 地方？

A。射线指着外圈的 0°，就顺着外圈找到 70° 点一个点，这样连出来的才是开口向左的 70° 锐角。

2. 用一副三角尺拼角：15° 的倍数都能拼

一副三角尺有两把：一把是 30°、60°、90°，另一把是等腰直角三角尺 45°、45°、90°。点下面的按钮把两把三角尺拼起来（相加）或叠起来（相减），看看能画出哪些角！

自己试试

用一把三角尺的 45° 角和另一把三角尺的 90° 角拼在一起，能画出多少度的角？

135°。45° + 90° = 135°。

用量角器画角三步：一画射线对 0°，二找刻度点个点，三过端点连射线；一副三角尺能拼出 75°、105°、120°、135°、150°、180° 和 15°。

两个容易错的地方

✗ 画完角不检查，把 60° 锐角画成了 120° 钝角 定点时看错了内外圈，连出来开口比直角还大也没发觉。
✓ 画完第一眼先看是锐角还是钝角，标上弧线和度数 要画的角小于 90°，画出来就必须是尖尖的锐角。
✗ 记混两把三角尺上的角，以为有 50° 或 70° 把 30°、60°、90° 和 45°、45°、90° 以外的角也当成三角尺自带的角。
✓ 三角尺只能拼出 15° 的倍数角 15°、30°、45°、60°、75°、90°、105°、120°、135°、150°、180°。

直接用

1. 用量角器画一个 80° 的角，正确的步骤顺序是哪一项？
① 在量角器 80° 刻度线的地方点一个点
② 画一条射线，使量角器的中心和射线的端点重合，0° 刻度线和射线重合
③ 以画出的射线的端点为端点，通过刚画的点，再画一条射线

C。先画射线对准中心和 0°（②），再找 80° 刻度点个点（①），最后从端点穿过这个点画第二条射线（③）。

2. 用一副三角尺里的 30° 角和 45° 角拼在一起，拼出的角是多少度？

75°。30° + 45° = 75°。

3. 用一副三角尺里的 60° 角和 90° 角拼在一起，拼出的钝角是多少度？

150°。60° + 90° = 150°。

容易错

4. 小明要画一个 115° 的角，他先画了一条朝右的射线（对齐内圈 0°），接着应该找哪个刻度点点？

B。射线对齐内圈 0°，就顺着内圈找 115°（在 90° 左边），连出来才是钝角。

想一想

5. 把两把三角尺的顶点和一条边对齐，让 30° 角叠在 45° 角的里面。多出来的那个小角是多少度？

15°。45° − 30° = 15°（用 60° − 45° 也能同样画出 15°）。

6. 一张长方形纸的每个角都是 90°。把其中一个直角对折，折出 45° 的角；再和一个 90° 的直角合在一起，可以得到多少度的钝角？

135°。直角对折一半是 90° ÷ 2 = 45°，再加一个直角：90° + 45° = 135°。
