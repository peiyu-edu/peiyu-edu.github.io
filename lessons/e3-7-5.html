7.5 正态分布

身高、零件尺寸、测量误差……很多量的直方图都是「中间高、两边低、左右对称」。这一节用一条钟形曲线描述它们：概率就是曲线下的面积。

一台机器往袋子里装大米，每袋标的是 \(500\) 克。抽了 \(100\) 袋称重，结果如下（每组含左端、不含右端）。先点下面的按钮看这 \(100\) 袋大米的柱状分布与钟形轮廓：

\(502\sim504\)\(14\)
\(504\) 及以上\(2\)

再随手拿一袋，重量在 \(498\sim502\) 克之间的可能性，用这组数据估计大约是多少？

C。\(498\sim500\) 有 \(34\) 袋，\(500\sim502\) 有 \(34\) 袋，合起来 \(68\) 袋，频率 \(0.68\)，用它估计概率约 \(68\%\)。

再看整张表：中间多、两边少，左右差不多对称。画成直方图就是一个「钟」。袋数再多、分组再细，直方图的上沿会越来越像一条光滑的钟形曲线。

这一节就讲这条曲线——正态曲线：落在某一段的概率，就是这一段曲线下面的面积。那个 \(68\%\) 也不是巧合，后面会看到。

1. 先认识几个词

要用到：必修二 9.2 频率分布直方图（回看 9.2）；7.3 均值与方差（回看 7.3）。正态分布是自然界中最普遍、最重要的连续型随机变量分布。

课本用词：正态曲线下的面积才是概率；标准化 \(Z=(X-\mu)/\sigma\) 要求 \(\sigma>0\)，区间端点要按同一方向变换。

正态分布 \(X \sim N(\mu, \sigma^2)\)：当样本量无限扩大、分组组距无限缩小时，直方图的折线逐渐光滑收敛为一条钟形对称曲线，称为高斯正态分布曲线。

两个核心参数：
• \(\mu\)：均值 / 位置参数，决定曲线的对称轴位置（\(x = \mu\)）；
• \(\sigma\)：标准差 / 形状参数，决定曲线的胖瘦分散度（\(\sigma\) 越小曲线越陡峭瘦高，\(\sigma\) 越大曲线越矮胖平坦）。
致命陷阱：记号 \(N(\mu, \sigma^2)\) 中，第二个参数是方差 \(\sigma^2\)，做题必须先开方求出标准差 \(\sigma\)！

正态曲线三大几何特征：

① 完美轴对称：关于直线 \(x = \mu\) 镜像对称，在 \(x = \mu\) 处取得最高峰值；
② 全域总面积为 1：曲线与 \(x\) 轴之间的全部面积恒等于 \(1\)；对称轴两侧面积各为 \(0.5\)：

$$P(X \le \mu) = P(X \ge \mu) = 0.5$$

③ 落在区间的概率就是曲线下面积：连续型随机变量单点概率为 \(0\)（\(P(X = c) = 0\)），因此带不带等号概率完全相同：\(P(a \le X \le b) = P(a < X < b)\)。

\(3\sigma\) 原则（高斯法则）：对 \(X \sim N(\mu, \sigma^2)\)，数据落在中心附近的概率具有确定经验数值：

• \(P(\mu - \sigma \le X \le \mu + \sigma) \approx 68.27\%\)；
• \(P(\mu - 2\sigma \le X \le \mu + 2\sigma) \approx 95.45\%\)；
• \(P(\mu - 3\sigma \le X \le \mu + 3\sigma) \approx 99.73\%\)。
落在 \(3\sigma\) 之外的概率仅有 \(0.27\%\)，属于几乎不可能发生的小概率事件。

正态分布直觉微图解：高斯钟形曲线、3σ原则与轴对称割补计算
加载中...
位置参数 \(\mu\) 中心对称轴

物理意义：均值、期望、中位数三位一体。

几何表现：决定整条曲线沿数轴左右平移的位置。

对称基石：\(P(X < \mu - c) = P(X > \mu + c)\)。

形状参数 \(\sigma\) 陡峭松散度

物理意义：标准差（方差 \(\sigma^2\) 的算术平方根）。

几何表现：\(\sigma\) 小则峰高腰细；\(\sigma\) 大则峰低腰阔。

面积守恒：曲线下总面积始终恒等于 1。

2. 正态分布色彩语义主公式与 3σ 原则

核心参数与 \(3\sigma\) 黄金常数：

分布记号：\(X \sim N(\color{#1976d2}{\mu}, \color{#2e7d32}{\sigma^2})\quad (\color{#1976d2}{\mu \text{ 为均值}}, \color{#2e7d32}{\sigma \text{ 为标准差}})\)

\(3\sigma\) 原则区间概率：

• \(P(\color{#1976d2}{\mu}-\color{#2e7d32}{\sigma} \le X \le \color{#1976d2}{\mu}+\color{#2e7d32}{\sigma}) \approx \color{#1976d2}{68.27\%} \approx 0.683\)

• \(P(\color{#1976d2}{\mu}-2\color{#2e7d32}{\sigma} \le X \le \color{#1976d2}{\mu}+2\color{#2e7d32}{\sigma}) \approx \color{#2e7d32}{95.45\%} \approx 0.954\)

• \(P(\color{#1976d2}{\mu}-3\color{#2e7d32}{\sigma} \le X \le \color{#1976d2}{\mu}+3\color{#2e7d32}{\sigma}) \approx \color{#d97706}{99.73\%} \approx 0.997\)

对称割补口诀：中轴平分各一半（0.5）；双侧对称算单侧，总面积 1 减中间再除以 2！

自己试试：\(X\sim N(10,9)\)，\(X\) 的标准差是？

B。括号里第二个数是方差 \(\sigma^2=9\)，标准差 \(\sigma=\sqrt9=3\)。选 A 是把方差当成了标准差，这是最常见的错；\(10\) 是均值。

自己试试：\(X\sim N(1,\sigma^2)\)，\(P(X<-1)=0.2\)。\(P(1<X<3)\) 是？

B。\(-1\) 和 \(3\) 关于 \(x=1\) 对称，\(P(X>3)=0.2\)；\(P(-1<X<3)=1-0.4=0.6\)；\(1\) 到 \(3\) 是它的一半，\(0.3\)。选 C 的同学停在了 \(0.6\)，忘了只要右半边。

3. 三步破题思维链例题

典型例题：某市高三年级一模数学考试成绩 \(X\) 服从正态分布 \(N(100, 100)\)。全市共有 10,000 名考生参加考试。
① 求数学成绩超过 110 分的考生占比及大约人数；
② 若已知 \(P(X < 80) = 0.0228\)，求数学成绩在 \([100, 120]\) 分之间的考生人数。

👀 第一眼破题信号： 审读参数：\(X \sim N(100, 100) \Longrightarrow \mu = 100\)，方差 \(\sigma^2 = 100 \Longrightarrow\) 标准差 \(\sigma = \sqrt{100} = 10\)！
观察关键数字：\(110 = \mu + \sigma\)；\(80 = \mu - 2\sigma\)；\(120 = \mu + 2\sigma\)；\(100 = \mu\)。全部完美吻合对称轴与 \(k\sigma\) 格点！
🔧 第二步对称性割补求解：
• ① 求 \(P(X > 110)\)：
\(110 = \mu + \sigma\)。由 \(3\sigma\) 原则，\(P(90 \le X \le 110) \approx 0.6827\)；
落在两边尾部的概率总和为 \(1 - 0.6827 = 0.3173\)；
由轴对称性，右侧单尾概率为：
$$P(X > 110) = \dfrac{0.3173}{2} \approx 0.1587\quad (15.87\%)$$ 超过 110 分的人数约为：\(10000 \times 0.1587 \approx 1587\text{ 人}\)。
• ② 求 \(P(100 \le X \le 120)\)：
由对称性，\(P(X > 120) = P(X < 80) = 0.0228\)；
而对称轴右半区总概率为 \(P(X \ge 100) = 0.5\)；
因此：
$$P(100 \le X \le 120) = P(X \ge 100) - P(X > 120) = 0.5 - 0.0228 = 0.4772$$ 考生人数为：\(10000 \times 0.4772 = 4772\text{ 人}\)。
🛡️ 第三步防坑结论核查： 防坑 1：标准差是 \(\sqrt{100}=10\)，切勿把 100 直接当 \(\sigma\)；防坑 2：问②求的是 \([100, 120]\)（半边对称区间），绝不能与整体对称区间 \([80, 120]\) 混淆（整体为 \(1 - 2\times 0.0228 = 0.9544\)，除以 2 正好为 0.4772）！

自己试试：\(X\sim N(80,25)\)，\(P(X>85)\) 约是？

A。\(\sigma=\sqrt{25}=5\)，\(85=\mu+\sigma\)。\(\mu\pm\sigma\) 外面一共约 \(1-0.6827=0.3173\)，右边一半约 \(0.1587\)。选 B 忘了除以 \(2\)；选 D 是错用了 \(2\sigma\) 那一行。

4. 三大翻车现场红绿对比卡

翻车现场 1：把方差 \(\sigma^2\) 误当成标准差 \(\sigma\)，未开方导致格点全盘移位

❌ 翻车：\(X \sim N(80, 25)\)，直接把 \(\sigma\) 当作 25，认为 \(\mu+\sigma = 105\)。

✔ 正确：正态分布的标准形式是 \(N(\mu, \sigma^2)\)，第二项是方差！必须先开方算出标准差 \(\sigma = \sqrt{25} = 5\)，故 \(\mu+\sigma = 85\)。不开方是高考考场最惨痛的送分失误。

翻车现场 2：单侧尾部概率忘记除以 2，两头尾巴当一头

❌ 翻车：求 \(P(X > \mu+\sigma)\)，直接用 \(1 - 0.6827 = 0.3173\) 交卷。

✔ 正确：\(1 - 0.6827 = 0.3173\) 是左右两个单尾的面积总和！因为曲线关于 \(\mu\) 严格对称，右单尾 \(P(X > \mu+\sigma)\) 必须除以 2：\(\dfrac{0.3173}{2} \approx 0.1587\)。

翻车现场 3：把曲线最高峰的高度 \(f(\mu)\) 当成发生概率

❌ 翻车：当 \(\sigma = 0.1\) 时，最高峰高度 \(f(\mu) = \dfrac{1}{\sqrt{2\pi}\times 0.1} \approx 3.99\)，误以为概率超过了 1 或这就是概率值。

✔ 正确：曲线上点的纵坐标是概率密度，绝不是概率值！连续型随机变量在任何单一点的概率都为 0（\(P(X=x_0) = 0\)），只有与 \(x\) 轴围成的面积才代表概率。面积恒等于 1，而高度完全可以大于 1。

反例微图解：单尾概率除以 2（左右双尾面积对半拆分）直觉对比
两翼总面积 1 - 0.6827 = 0.3173，由于对称轴平分秋色，每一侧尾部面积必须严格除以 2 得 0.1587。

① 正态曲线：调 \(\mu\)、\(\sigma\)，拖 \(a\)、\(b\) 看面积

拖横轴上的圆点 \(a\)、\(b\)（或选中后按方向键），阴影面积就是 \(P(a<X<b)\)。点下面的按钮一键设成 \(\mu\pm\sigma\)、\(\mu\pm2\sigma\)、\(\mu\pm3\sigma\)，再调 \(\mu\)、\(\sigma\)：面积不变。把 \(\sigma\) 调到最小，看最高点有多高。

② 进阶：增加样本有助于观察分布；\(3\sigma\) 外也可能出现

下面的大米重量是电脑按 \(N(500,2^2)\) 模拟出来的（所以我们知道它是正态；真实数据要先看图再决定能不能用正态）。拖动样本量，观察直方图的随机波动与整体形状；红点是落在 \(\mu\pm3\sigma\)（\(494\sim506\) 克）外面的袋子。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(X\sim N(\mu,\sigma^2)\)，且 \(P(X<1)=P(X>5)\)。\(\mu=\)？

B。左边 \(x<1\) 的尾巴和右边 \(x>5\) 的尾巴一样大，说明 \(1\) 和 \(5\) 关于对称轴 \(x=\mu\) 对称，\(\mu=\dfrac{1+5}{2}=3\)。选 D 是把 \(1+5\) 忘了除以 \(2\)。

2. 某次考试 \(1000\) 人参加，题目给出成绩 \(X\sim N(100,10^2)\)。\(120\) 分以上的大约有多少人？

A。\(\sigma=10\)，\(120=\mu+2\sigma\)。\(\mu\pm2\sigma\) 外约 \(1-0.9545=0.0455\)，右边一半约 \(0.0228\)，\(1000\times0.0228\approx23\)。选 B 没除以 \(2\)；选 C 用的是 \(\mu+\sigma\) 那一行；选 D 用的是 \(3\sigma\)。

易错

3. \(X\sim N(0,0.2^2)\)，它的曲线在 \(x=0\) 处最高，高约 \(1.99\)。\(P(X=0)\) 是？

C。概率是面积，不是高度。\(1.99\) 比 \(1\) 还大，本来就不可能是概率。「\(X=0\)」只是一个点，没有宽度，面积为 \(0\)。

B 是 \(P(X\le0)\)，D 是 \(P(-0.2\le X\le0.2)\)，都是一段，不是一个点。

4. 某市居民月收入的直方图：左边一个高峰，右边拖着很长的尾巴。小明说：「收入服从正态分布，所以收入低于平均数的人正好占一半。」

B。用正态之前先问：是题目给的，还是数据支持的假设？这张图左右不对称，正态的「关于均值对称」不成立。少数很高的收入会把平均数往上拉，低于平均数的人往往超过一半。

C 也错：样本再多，也只是把原来的形状看得更清楚，歪的还是歪的。

5. 一条生产线上零件长度 \(X\sim N(\mu,\sigma^2)\)，一直运行正常。今天抽检，有一个零件落在 \(\mu\pm3\sigma\) 外。下面哪个说法对？

B。\(\mu\pm3\sigma\) 外的概率约 \(0.0027\)，很小但不是 \(0\)：正常机器做 \(10000\) 个，平均也有二三十个落在外面。「几乎不可能」不等于「绝不发生」，一次异常是警报，不是证明。可以在「动手」②增加样本或换一批观察；有限一批也可能没有红点。

挑战

6. 某种灯泡的寿命 \(X\sim N(1000,50^2)\)（单位：小时，题设）。买一只，寿命在 \(950\sim1100\) 小时之间的概率约是？

A。\(\sigma=50\)：\(950=\mu-\sigma\)，\(1100=\mu+2\sigma\)，左右不一样宽，以 \(\mu=1000\) 为界拆成两块：

左块 \(950\sim1000\) 是 \(\mu\pm\sigma\) 的一半，约 \(0.6827\div2=0.34135\)；右块 \(1000\sim1100\) 是 \(\mu\pm2\sigma\) 的一半，约 \(0.9545\div2=0.47725\)。合计约 \(0.8186\)。

B、C 只用了一边的数；D 是 \(P(X<1050)\approx0.5+0.34135\)，区间看错了。
