2014 年辽宁预赛 第 16 题

P010803 · 抛物线

已知抛物线 C:y2=2px (p>0)，直线 l 与抛物线 C 相交于 A,B 两点。连接 A 与抛物线顶点 O 的直线交准线于 B′，连接 B 与 O 的直线交准线于 A′，并且 AA′ 与 BB′ 都平行于 x 轴。

(1) 证明：直线 l 过定点；

(2) 求四边形 ABB′A′ 的面积的最小值。

先把几何关系化为抛物线焦点弦的两参数乘积，再把面积中共同的高、焦半径和或纵坐标差合并；目标只剩一个非负平方量，取等还需回到真实焦弦。

前题是在焦点圆内外分段后合并两个共高三角形；后题是准线射影给出的梯形，边长直接是焦半径，不能把两套面积因子照搬。
