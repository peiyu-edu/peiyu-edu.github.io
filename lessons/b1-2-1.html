2.1 等式性质与不等式性质

等式两边同做合法运算，还相等；不等式两边同做运算，方向却可能反过来。这一节弄清楚：同加同减为什么不变向，乘除、平方、取倒数要检查哪些符号与定义条件。先从两个人比身高开始。

小明身高 \(165\) 厘米，小红身高 \(160\) 厘米。拍合照时，两人一起站上一级 \(20\) 厘米高的台阶。点下面按钮切换看看：

站上台阶以后，谁的头顶更高？高多少？

A。\(185-180=5\)：两个人都加了 \(20\)，差一点没变，谁高谁矮也不变。

比大小，其实就是看差：差是正的，前一个大。这一节先学会「看差」，再用它检查：两边同加、同乘、平方、取倒数以后，大小关系还在不在。加法像站台阶一样安全；别的操作，有时会把方向反过来。

1. 先认识几个词：从「数轴位移」建立直觉

要用到：初中解一元一次不等式（乘负数要变号）；1.4 的「\(\Rightarrow\)」和「\(\iff\)」（回看 1.4）。不用死背规则，先看下面这幅微图解：

直觉微图解 ①作差的本质：数轴上从 \(b\) 走向 \(a\) 的位移向量

核心概念 ②等价（\(\iff\)）vs 单向（\(\Rightarrow\)）

\(\iff\)：双向互推（如 \(x+2>5 \iff x>3\)）。
\(\Rightarrow\)：只断言前者能推出后者，逆向是否成立要另证。如 \(x>3 \Rightarrow x>1\) 的逆向不成立：\(x=2\) 满足 \(x>1\)，却不满足 \(x>3\)。

核心概念 ③非负（\(\ge 0\)）≠ 严格正数（\(>0\)）

非负是「正数或 \(0\)」。任何实数的平方 \(x^2 \ge 0\)，当 \(x=0\) 时等于 \(0\)，绝不能擅自写成 \(x^2>0\)（漏掉 \(0\) 是高考常客）！

先梳理等式，再类比不等式：等式可以交换两边：\(a=b\iff b=a\)；也有传递性：\(a=b,\ b=c\Rightarrow a=c\)。若 \(a=b\)，两边同加同减一个数仍相等，\(a\pm c=b\pm c\)；同乘任意实数也有 \(ac=bc\)。同除则必须 \(c\ne0\)，才有 \(\dfrac ac=\dfrac bc\)。后面研究不等式时，重点检查这些运算怎样影响大小顺序。

2. 核心大招：比大小首选「作差法」

两个式子谁大？不用猜，作差看符号：

\(\color{#2F7A56}{\underbrace{a - b > 0}_{\text{从 } b \text{ 往右走到 } a}} \;\iff\; \color{#2F7A56}{a} > \color{#966524}{b}\) \(\color{#3E5C76}{\underbrace{a - b = 0}_{\text{两点重合}}} \;\iff\; a = b\) \(\color{#B5452F}{\underbrace{a - b < 0}_{\text{从 } b \text{ 往左走到 } a}} \;\iff\; \color{#2F7A56}{a} < \color{#966524}{b}\)

例 1（示范：跟老师走一遍思考过程）

对任意实数 \(x\)，比较 \(x^2+3\) 和 \(2x+1\) 的大小。

👀 第一眼看破题信号：比较两未知代数式大小，直接看不出谁大，立刻启动作差法！
🔧 第二步套公式变形（配方）： 作差：\((x^2+3) - (2x+1) = x^2 - 2x + 2 = (x-1)^2 + 1\)。
🛡️ 第三步必查符号下结论： 对任意实数 \(x\)，完全平方 \((x-1)^2 \ge 0\)，再加 \(1\) 恒有 \((x-1)^2 + 1 \ge 1 > 0\)！差恒为正，所以恒有 \(x^2+3 > 2x+1\)。

自己试试：对任意实数 \(a\)，\(a^2+1\) 和 \(2a\) 的大小关系是？

B。作差：\(a^2+1-2a=(a-1)^2\ge0\)，\(a=1\) 时差是 \(0\)。选 A 的同学把「平方 \(\ge0\)」当成了「平方 \(>0\)」：\(a=1\) 时 \(2=2\)，不是严格大于。

3. 不等式变形的三大铁律

不等式两边同做运算，方向会怎么变？先看这幅微图解：

直觉微图解 ②乘负数为什么一定要变向？（原点镜像翻转）

不等式三大黄金法则：
• 同加、同减：\(\color{#2F7A56}{\text{方向永远不变}}\)（两边加任何正数、负数或零，相对距离一点不变）。
• 同乘、同除：必须先看这个数的符号！ - 乘正数（\(c>0\)）：\(\color{#2F7A56}{\text{方向不变}}\)；
- 乘负数（\(c<0\)）：\(\color{#B5452F}{\text{方向必须反过来！}}\)
- 乘零（\(c=0\)）：两边都变成 \(0\) 相等，原来的严格大于号或小于号不能保留；除数绝不能为 \(0\)。

例 3（示范：跟老师走一遍思考过程）

已知 \(a>b\)，比较 \(1-3a\) 和 \(1-3b\) 的大小。

👀 第一眼看破题信号：式子中未知数乘了 \(-3\)，这是负数！
🔧 第二步套公式变形： ① 两边同乘 \(-3\)：因为 \(-3<0\)，方向反过来，得 \(-3a < -3b\)；
② 两边同加 \(1\)：同加不改变不等号方向，得 \(1-3a < 1-3b\)。
🛡️ 第三步作差核验： \((1-3a) - (1-3b) = -3(a-b)\)。已知 \(a>b \Rightarrow a-b>0\)，负数乘正数必为负（\(<0\)），结论 \(1-3a < 1-3b\) 绝对可靠！

自己试试：已知 \(a>b\)，那么 \(5-2a\) ___ \(5-2b\)。

B。乘 \(-2\) 要变向：\(-2a<-2b\)，再加 \(5\)：\(5-2a<5-2b\)。选 A 的同学乘了负数却忘了变向。

例 4（示范：跟老师走一遍思考过程）

已知 \(1<a<3\)，\(2<b<5\)，求 \(a+b\) 和 \(a-b\) 的范围。

👀 第一眼看破题信号：求 \(a-b\) 必须拆成 \(a + (-b)\)，绝不能上下直接相减！
🔧 第二步套公式变形： • 同向相加求 \(a+b\)：\(1+2 < a+b < 3+5 \implies 3 < a+b < 8\)；
• 求 \(-b\) 的范围：由 \(2<b<5\) 两边同乘 \(-1\)，变向得 \(-5 < -b < -2\)。
🛡️ 第三步同向相加出结果： 将 \(1<a<3\) 与 \(-5<-b<-2\) 同向相加：\((1)+(-5) < a+(-b) < (3)+(-2) \implies -4 < a-b < 1\)。

自己试试：已知 \(3<a<6\)，\(1<b<2\)，\(a-b\) 的范围是？

A。\(-2<-b<-1\)，加上 \(3<a<6\)：\(1<a-b<5\)。选 B 的同学「下限减下限、上限减上限」：\(3-1=2\)，\(6-2=4\)。可 \(a=5.9\)，\(b=1.1\) 时 \(a-b=4.8\)，已经超过 \(4\)。

自己试试：已知 \(a>b\)，且 \(a,b\) 都不为 \(0\)。什么时候一定有 \(\dfrac1a<\dfrac1b\)？

答案 C。作差：\(\dfrac1a-\dfrac1b=\dfrac{b-a}{ab}\)，分子 \(b-a<0\)。\(ab>0\) 时整个差是负的，\(\dfrac1a<\dfrac1b\)；\(ab<0\) 时结论反过来。

B 的反例：\(a=2,\ b=-1\)，\(a>0\)，可 \(\tfrac12>-1\)。「大数的倒数小」只在两个数同号时才对。

5. 用之前必查：三大高频翻车现场

翻车现场 ①同向不等式直接相减（大忌！）
❌ 典型错解：已知 \(3<a<6, 1<b<2\)，直接两式上下相减：\((3-1) < a-b < (6-2) \implies 2 < a-b < 4\)。
✅ 一眼看清真相：代入极端值 \(a=5.9, b=1.1\)，\(a-b=4.8 > 4\) 瞬间穿帮！不等式绝不能直接相减，必须先乘 \(-1\) 变向成 \(-2 < -b < -1\)，再同向相加得到正确范围 \(1 < a-b < 5\)。
翻车现场 ②两边乘含未知数的式子（未讨论符号）
❌ 典型错解：解不等式 \(mx > 2m\)，两边直接约掉 \(m\)，写出解集 \(x > 2\)。
✅ 一眼看清真相：未知数 \(m\) 正负未定！若 \(m=-1\)，原式是 \(-x > -2 \implies x < 2\)；若 \(m=0\)，原式是 \(0>0\) 无解！必须分 \(m>0, m=0, m<0\) 三类严密讨论。
翻车现场 ③（最高频！）盲目认为「两边取倒数一定变向」
❌ 典型错解：因为 \(2 > -1\)，两边直接取倒数写出 \(\dfrac{1}{2} < -1\)。
✅ 看右图秒懂真相：正数倒数依然是正数，负数倒数依然是负数，正数永远大于负数！只有当两数同号（\(ab>0\)）时取倒数才会反向！
再深一点（可以先跳过）

全部性质一张表（每条都能用作差证）：

性质条件与结论为什么（作差）
对称\(a>b\iff b<a\)换个说法
传递\(a>b,\ b>c\Rightarrow a>c\)\(a-c=(a-b)+(b-c)\)
同加\(a>b\iff a+c>b+c\)差还是 \(a-b\)
同乘\(c>0\)：\(ac>bc\)；\(c<0\)：\(ac<bc\)\(ac-bc=c(a-b)\)
同向相加\(a>b,\ c>d\Rightarrow a+c>b+d\)\((a-b)+(c-d)\)
同正相乘\(a>b>0,\ c>d>0\Rightarrow ac>bd\)\(ac-bd=c(a-b)+b(c-d)\)
乘方\(a>b>0\Rightarrow a^n>b^n\)（\(n\ge2\) 为整数）同正相乘反复用

开方：\(a>b\ge0\Rightarrow\sqrt a>\sqrt b\)。反过来想：要是 \(\sqrt a\le\sqrt b\)，两边非负，平方得 \(a\le b\)，矛盾。在实数范围内，负数没有平方根，所以要求非负。

作商法：两个正数比大小，也可以看 \(\dfrac ab\) 和 \(1\) 谁大。比如 \(\dfrac{2^{10}}{3^{6}}=\dfrac{1024}{729}>1\)，所以 \(2^{10}>3^6\)。前提是 \(b>0\)，否则除完方向会变。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 对任意实数 \(x\)，比较 \((x+1)(x+3)\) 和 \((x+2)^2\)。

B。作差：\((x^2+4x+3)-(x^2+4x+4)=-1<0\)，不管 \(x\) 是多少，前者总比后者小 \(1\)。选 D 的同学没算差就猜了：式子里有 \(x\)，差却可能是个常数。

2. 已知 \(-1<x<2\)，\(3-2x\) 的范围是？

A。乘 \(-2\) 变向：\(-4<-2x<2\)；再加 \(3\)：\(-1<3-2x<5\)。核对端点：\(x\) 接近 \(-1\) 时 \(3-2x\) 接近 \(5\)，\(x\) 接近 \(2\) 时接近 \(-1\)。B 是把 \(-2x\) 当成了 \(2x\)；C 是忘了加 \(3\)。

易错

3. 已知 \(a>b\)，\(c\) 是任意实数。下面哪一个一定成立？

答案是 D：两边同时减去同一个数，差 \(a-b\) 一点没变，方向当然不变。

A：取 \(a=1,\ b=-2\)，\(a>b\)，可是 \(a^2=1<4=b^2\)。两边有负数时不能放心平方。

B：取 \(a=1,\ b=-1\)，\(\tfrac1a=1\)，\(\tfrac1b=-1\)，\(1<-1\) 不成立。而且 \(b=0\) 时 \(\tfrac1b\) 根本没有意义。

C：\(c=0\) 时两边都是 \(0\)；\(c<0\) 时方向还会反过来。

记住：两边同加同减同一个数不变向；乘、除、平方、取倒数之前，先查符号与定义条件。

4. 下面两个推理，哪个对？
① 若 \(a>b\)，则 \(ac^2>bc^2\)　② 若 \(ac^2>bc^2\)，则 \(a>b\)

答案 B。\(c^2\) 不会是负数，很多人就当它是正数，选 A。可它可以是 0。

①：\(c=0\) 时两边都是 \(0\)，\(0>0\) 不成立，所以 ① 错。

②：既然 \(ac^2>bc^2\)，两边就不可能都等于 0，说明 \(c^2\ne0\)，即 \(c^2>0\)。两边同除以正数 \(c^2\)，方向不变，得 \(a>b\)。② 对。

同一对式子，一个方向对、一个方向错——这就是「单向推论」。乘一个带字母的数之前，正、负、零三种情况都要想到。

5. 已知 \(a>b\)，\(c>d\)。能推出 \(ac>bd\) 吗？

答案 B。同向不等式能相加，不能随便相乘。

A、C 的反例：\(a=1,\ b=-2,\ c=1,\ d=-3\)。\(a,c\) 都是正数，但 \(ac=1\)，\(bd=6\)，\(ac<bd\)。

原因看作差：\(ac-bd=c(a-b)+b(c-d)\)。若再有 \(c>0\)、\(b>0\)，就能保证两项都正，从而 \(ac>bd\)。四个数都为正是一组充分条件，不能说是个别数值下乘积不等式成立的必要条件。例如 \(a=3,b=2,c=-1,d=-2\)，仍有 \(ac=-3>-4=bd\)。

挑战

6. 已知 \(-1<a+b<3\)，\(2<a-b<4\)。\(2a+3b\) 的范围是？

A。常见错法：先分别求出 \(\dfrac12<a<\dfrac72\)，\(-\dfrac52<b<\dfrac12\)，再相加得 B。可 B 的上端要 \(a\) 靠近 \(\dfrac72\)、\(b\) 靠近 \(\dfrac12\) 同时发生：前者要 \(a-b\) 靠近 \(4\)，后者要 \(a-b\) 靠近 \(2\)，做不到。拆成 \(a\)、\(b\) 两个范围再相加，丢了它们之间的联系，范围被放大了。

正确做法：把 \(2a+3b\) 直接写成 \(a+b\) 和 \(a-b\) 的组合。设 \(2a+3b=m(a+b)+n(a-b)\)，比较系数 \(m+n=2\)，\(m-n=3\)，得 \(m=\dfrac52\)，\(n=-\dfrac12\)。

\(-\dfrac52<\dfrac52(a+b)<\dfrac{15}{2}\)，\(-2<-\dfrac12(a-b)<-1\)（乘负数变向），相加：\(-\dfrac92<2a+3b<\dfrac{13}{2}\)。两端分别在 \(a+b\to-1,\ a-b\to4\) 和 \(a+b\to3,\ a-b\to2\) 时靠近，都能无限接近。
