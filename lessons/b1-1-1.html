必修第一册 · 第 1 章 集合与常用逻辑用语

1.1 集合的概念

把一些对象「打包」成一个整体，并且能说清楚：谁在里面，谁不在。

班里学号 \(1\) 到 \(10\) 的十位同学，老师说：「学号是双数的同学，去搬新书。」

一共有几位同学去搬书？

B。学号 \(2, 4, 6, 8, 10\)，一共 \(5\) 位。

老师这句话把「谁去」说得清清楚楚：报任何一个学号，都能马上答出他去不去——\(7\) 号不去，\(8\) 号去。

这样一群说得清的对象，看成一个整体，就是这一节要讲的集合。同一群人还有两种说法：一个个点名「\(2, 4, 6, 8, 10\) 号」，或者讲规则「\(1\) 到 \(10\) 号里的双数」。这正是集合的两种写法。

1. 先认识几个词

要用到：初中学过的自然数、整数、有理数、实数，和解简单的方程。这是全书第一节，没有要回看的前一节。

元素和集合：我们研究的对象叫元素；把一些元素放在一起、看成一个整体，叫集合。通常用大写字母 \(A, B, \dots\) 表示集合，小写字母 \(a, b, \dots\) 表示元素。

例：小于 \(5\) 的正整数是 \(1, 2, 3, 4\)，把它们放在一起，写成 \(A=\{1, 2, 3, 4\}\)。\(A\) 有 \(4\) 个元素。

属于、不属于：\(a\) 是 \(A\) 的元素，记作 \(a\in A\)，读「\(a\) 属于 \(A\)」；不是，记作 \(a\notin A\)。对一个确定的集合，二者必居其一。

例：\(A=\{1, 2, 3, 4\}\)。\(3\in A\)，\(5\notin A\)，\(0\notin A\)。

常用数集的记号：自然数集 \(\N\)（含 \(0\)），正整数集 \(\N^*\)（也写 \(\N_+\)），整数集 \(\Z\)，有理数集 \(\Q\)，实数集 \(\R\)。

例：\(0\in\N\)，但 \(0\notin\N^*\)；\(-3\in\Z\)；\(\dfrac12\in\Q\)，但 \(\dfrac12\notin\Z\)；\(\sqrt2\in\R\)，但 \(\sqrt2\notin\Q\)。

2. 能当集合的三条规矩

  • 确定：给一个对象，必须能判断它在不在里面。「比较大的数」说不清多大算大，不能组成集合；「大于 \(10\) 的数」就可以。
  • 互不相同：同一个元素只算一次。
  • 不讲顺序：\(\{1, 2, 3\}\) 和 \(\{3, 1, 2\}\) 是同一个集合。两个集合只要元素完全一样，就相等。
集合只关心「谁在里面」：能判断在不在、重复的只算一次、顺序无所谓。

例 1（看一遍怎么写）

方程 \(x^2-2x+1=0\) 的解组成的集合是什么？有几个元素？

左边是 \((x-1)^2\)，所以 \((x-1)^2=0\)，两个根都是 \(1\)。集合里同一个元素只记一次，所以是 \(\{1\}\)，只有 \(1\) 个元素。

对比：方程 \((x-1)(x+2)=0\) 的解是 \(1\) 和 \(-2\)，集合是 \(\{1, -2\}\)；写成 \(\{-2, 1\}\) 也是同一个集合。

自己试试：下面哪一组对象能组成集合？

B，就是 \(\{1, 2, 3, 4\}\)。A 和 C 都说不清：多高算高？多近算近？\(0.001\) 算接近，\(0.1\) 算不算？给一个对象判断不了在不在，就不「确定」。常见的错是觉得 C 也行——「接近」听起来像数学词，其实没给标准。

3. 两种写法：列举法和描述法

列举法：把元素一个个写在大括号里，如 \(\{-1, 0, 1\}\)。元素少、能写完时最清楚。

描述法：写成 \(\{\,x \in A \mid x \text{ 满足的条件}\,\}\)。竖线左边说「元素是什么、从哪里取」，右边说「要满足什么条件」。

例 2

用列举法写出 \(B=\{x\in\Z\mid x^2<5\}\)。

左边：\(x\) 是整数。右边：\(x^2<5\)。从 \(0\) 往两边试：\(0^2=0\)，\((\pm1)^2=1\)，\((\pm2)^2=4\)，都小于 \(5\)；\((\pm3)^2=9\) 不行，再往外更大。

所以 \(B=\{-2, -1, 0, 1, 2\}\)，共 \(5\) 个元素。

自己试试：集合 \(\{x\in\N\mid x<4\}\) 有几个元素？

B，是 \(\{0, 1, 2, 3\}\)。选 A 的同学漏了 \(0\)：\(\N\) 含 \(0\)。选 C 是把 \(4\) 也算进去了，可条件是 \(x<4\)，不含 \(4\)。

4. 先看竖线左边：数还是点

读描述法，先看竖线左边：元素是数还是点（或别的东西）？左边一变，集合就完全变了。

同一个等式 \(y = x^2\)：先想满足它的所有点 \((x, y)\)，也就是抛物线上的点；再看竖线左边要的是这些点的什么：

  • \(\{x \mid y = x^2\}\)：要的是横坐标。对任意实数 \(x\)，都能取 \(y=x^2\) 让等式成立，所以横坐标能取所有实数，这个集合是 \(\R\)。
  • \(\{y \mid y = x^2\}\)：要的是纵坐标。\(y = x^2\) 只能取 \(\ge 0\) 的数，所以它是 \(\{y \mid y \ge 0\}\)。
  • \(\{(x, y) \mid y = x^2\}\)：元素是点，它是抛物线上所有点组成的点集。

例 3

用列举法写出 \(C=\{(x, y)\mid x+y=3,\ x\in\N,\ y\in\N\}\)。

左边是 \((x, y)\)，元素是点。\(x\) 从 \(0\) 试到 \(3\)，\(y=3-x\) 也要是自然数：\((0, 3)\)，\((1, 2)\)，\((2, 1)\)，\((3, 0)\)。

所以 \(C=\{(0, 3), (1, 2), (2, 1), (3, 0)\}\)，共 \(4\) 个元素。\((1, 2)\) 和 \((2, 1)\) 是两个不同的点，都要写。

自己试试：集合 \(\{(1, 2), (3, 4)\}\) 有几个元素？

A。元素是两个点 \((1, 2)\) 和 \((3, 4)\)。选 B 的同学把每个点里的两个数拆开来数了：一个点不管写几个数，只是一个元素。

5. 带字母、可能为空：要回头检查

集合里出现字母（参数），或者条件可能谁都满足不了时，有三件事要留心：

  1. 求出参数，代回去查互不相同。
    用列举法写出 \(\{1, a\}\)，就是在说「这里有 \(1\) 和 \(a\) 两个元素」，按约定它们互不相同，所以默认 \(a\ne1\)；\(a=1\) 时两个写法并成一个，和「两个元素」对不上，这样的 \(a\) 要舍去。（用描述法给的集合不一样：\(\{x\mid x^2-4x+4=0\}\) 的两个根都是 \(2\)，就只算一个元素 \(\{2\}\)，不用舍。）
  2. 别默认集合里一定有元素。
    反例：\(\{x\mid x^2=-1\}\)：没有实数的平方是 \(-1\)，一个元素都没有。
  3. 「没有元素」不是 \(\{0\}\)。
    反例：\(\{x\mid x^2=0\}=\{0\}\)，里面有一个元素 \(0\)；\(\{x\mid x^2=-1\}\) 才是一个元素都没有。
一个元素都没有的集合也是集合（下一节叫它空集 \(\varnothing\)）。它和 \(\{0\}\) 不一样：\(\{0\}\) 里有一个元素 \(0\)。
再深一点（可以先跳过）

有限集和无限集：\(\{1, 2, 3\}\) 元素能数完，叫有限集；\(\N\)、\(\{x\mid x>1\}\) 元素数不完，叫无限集。无限集一般用描述法；元素有规律时也可以列举加省略号，如 \(\{1, 3, 5, 7, \dots\}\)。

描述法里的字母可以换：\(\{x\mid x>1\}\) 和 \(\{t\mid t>1\}\) 是同一个集合，字母只是个代号。从实数里取时，「\(\in\R\)」常常省略不写。

元素可以是任何东西：数、点、字母、人，甚至集合本身。比如 \(\{\{1\}, 2\}\) 有两个元素：一个是集合 \(\{1\}\)，一个是数 \(2\)。

① 描述法 → 列举法

选一个集合，拖动滑块改参数 \(a\)。数轴上实心绿点是集合里的元素。点一个数（或用 Tab 选中后按回车），看它为什么在或不在。

② 进阶：数集还是点集

拖动点 \(P\)（或选中后用方向键移动，每次 0.5）。靠近抛物线会自动吸上去。看同一个 \(y = x^2\) 配三种「左边」时，判断结果有什么不同。

图例：蓝色抛物线 是点集 \(\{(x,y)\mid y=x^2\}\)；整条 x 轴 是 \(\{x\mid y=x^2\}\)；y 轴的上半段 是 \(\{y\mid y=x^2\}\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 用列举法写 \(\{x\in\Z\mid -1\le x<3\}\)，是哪一个？

B。左边：\(x\) 是整数；右边：\(-1\le x<3\)。\(-1\) 能取（带等号），\(3\) 不能取（不带等号）。选 A 的同学漏了 \(-1\)：负整数也是整数。选 C 的同学多写了 \(3\)。

2. 下面哪个写法是对的？

C。\(-3\) 是整数。A：\(\N^*\) 是正整数，\(0\) 不是正数；B：\(\sqrt2\) 是无理数，不在 \(\Q\) 里；D：\(\dfrac12\) 不是整数。

易错

3. 把英文单词 letter 里出现的字母放进一个集合。这个集合里有几个元素？

C，是 \(\{l, e, t, r\}\)。

选 6 的同学是在数「字母出现了几次」。可集合只关心「谁在里面」：\(e\) 和 \(t\) 各出现两次，也只算一个元素——互不相同。顺序也不重要，写成 \(\{r, t, e, l\}\) 还是同一个集合。

4. \(\{(1, 2)\}\) 和 \(\{1, 2\}\) 是同一个集合吗？

\(\{(1, 2)\}\) 的元素是一个点 \((1, 2)\)，只有 1 个元素；\(\{1, 2\}\) 的元素是两个数。比较集合前，先弄清元素是数还是点。

5. \(a\) 是一个实数。集合 \(\{x \mid x^2 = a\}\) 里一定有元素吗？

\(a < 0\) 时，没有实数的平方等于 \(a\)，集合里一个元素都没有。A 默认了 \(\sqrt a\) 存在；C 把「没有元素」当成了 \(\{0\}\)，可 \(0^2 = 0 \ne a\)，0 根本不在里面。有参数时，先想清楚集合会不会是空的。

挑战

6. 已知集合 \(A = \{1,\ a,\ a^2 - a\}\) 含有 3 个元素，且 \(2 \in A\)，那么 \(a\) 等于多少？

B。\(\{1,\ a,\ a^2-a\}\) 含有 3 个元素，说明这三个式子的值必须互不相同。

\(2 \in A\)，要么 \(a = 2\)，要么 \(a^2 - a = 2\)（解得 \(a = 2\) 或 \(a = -1\)）。

• 若 \(a = 2\)，则 \(a = 2\) 且 \(a^2 - a = 2\)，集合退化为 \(\{1, 2\}\) 只有 2 个元素，与题设「含有 3 个元素」矛盾，舍去；

• 若 \(a = -1\)，集合为 \(\{1, -1, 2\}\)，三个元素互不相同，符合题意。因此只有 \(a = -1\)。

【核心经验】：解出含参集合的参数后，必须代回原集合核验互异性！
