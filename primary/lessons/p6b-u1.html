负数

负数全景图

竖着的温度计放平，就是一条能表示正数、0、负数的直线：

比 0 大的是正数，比 0 小的是负数，0 不正不负；数轴上右边的数比左边的大。

三个最容易踩的「坑」

✗ 把 −3 读成「减三」 看见横线就读「减」。
✓ 数前面的横线读「负」 −3 读「负三」，9 − 3 才读「减」。
✗ 把 0 当成正数，或「没有」 说「0 ℃ 是零上」「0 ℃ 就是没有温度」。
✓ 0 是分界 0 ℃ 不是零上也不是零下，0 既不是正数也不是负数。
✗ 数字大的负数更大 说「−9 比 −2 大」。
✓ 看数轴上谁在右边 −2 在 −9 的右边，所以 −2 > −9。

直接用

1. 「−0.5」读作（ ）。

−0.5 读作「负零点五」。

2. 某商店本周盈利 800 元记作 +800 元，那么亏损 30 元应记作（ ）。

盈利记正，亏损就记负：−30 元。

3. 下面说法对的是（ ）。

0 是正数和负数的分界。

4. 下面哪两个量是相反意义的量？

同一件事、方向相反，才是相反意义的量。

容易错

5. 在 1 格 = 1 的数轴上，点 P 在 0 左边 2 格半（半格即 0.5），它表示（ ）。

左 2 格半就是 −2.5，在 −2 和 −3 之间。

6. 数轴上，点 A 在 −4 的位置，点 B 在 1 的位置。点 B 在点 A 的（ ）。

1 在 −4 的右边，所以 1 > −4。

7. 比较大小，正确的是（ ）。

−9 在 −2 的左边，所以 −9 < −2。

想一想

8. 把 −1、4、−6、0 按从小到大排列是（ ）。

从左往右：−6，−1，0，4。

9. 哈尔滨某天最低气温 −20 ℃，北京 −5 ℃。哪里更冷？

−20 在 −5 的左边，更小，所以哈尔滨更冷。

10. 「0 左边的数都比 0 小」这句话（ ）。

0 左边的负数都比 0 小，而且一直往左没有尽头，所以没有最小的数。

本单元 2 课导航

  • 第 1 课：认识负数 —— 用温度计和账本认识正数、负数、0，会读会写，分清「负」和「减」。
  • 第 2 课：在直线上表示数 —— 把温度计放平得到数轴，在数轴上表示数、比较大小。

往下衔接

  • ✨ 这一单元只认识负数、会比较大小；负数怎么加、减，要到初中再学。

往后学 · 初中数学

把这一单元学扎实，到了初中就能顺畅接上下面的内容：

  • 初中 · 1.1 正数和负数小学用温度计和收支初步认识具有相反意义的量与负号，初中在此基础上把数的范围正式扩充到有理数。
  • 初中 · 1.2 有理数及其大小比较小学在直线上初步标出正负数，初中将其规范化为带原点、正方向和单位长度的数轴，并用数轴与绝对值比较有理数大小。
