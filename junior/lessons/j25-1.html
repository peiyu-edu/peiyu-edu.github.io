25.1 一元二次方程的概念

未知数带上了平方，方程该怎么看？从纸板折盒与循环赛场次出发，看清一元二次方程的三个硬性条件、一般形式 \(ax^2+bx+c=0\) 的威力，以及根的检验与整体代入。

  3. 建立一般形式 \(ax^2+bx+c=0\)：为什么必须咬定 \(a \ne 0\)？各项系数如何认准符号。
  4. 理解方程的「根」：代入左右两边验算，掌握整体代入求值技巧。
  5. 动手试验：在图形折叠与赛制网络中感受二次关系的暴增效应。

有一块长 \(20\text{ cm}\)、宽 \(14\text{ cm}\) 的长方形硬纸板，要在它的四个角各剪去一个同样大小的小正方形，然后把四边折起，做成一个无盖方盒。如果要做成的方盒底面积正好是 \(160\text{ cm}^2\)，剪去的小正方形边长应是多少？

设剪去的小正方形边长为 \(x\text{ cm}\)，底面的长为 \((20-2x)\text{ cm}\)，宽为 \((14-2x)\text{ cm}\)。由底面积等于 \(160\text{ cm}^2\)，得到方程 \((20-2x)(14-2x)=160\)。展开化简后，未知数 \(x\) 的最高次数是几？

B。展开左边：\(280 - 40x - 28x + 4x^2 = 160\)，整理得 \(4x^2 - 68x + 120 = 0\)，两边同除以 4 得 \(x^2 - 17x + 30 = 0\)。未知数的最高次数是 2。

这和我们七年级学过的一元一次方程不同：未知数出现了二次方！这类刻画现实世界中面积、传播、速度与增长等复杂数量关系的方程，就叫作一元二次方程。

1. 先认识几个词：什么是一元二次方程？

前置知识：方程的概念与解（回看 5.1）。我们来看看一个方程要成为「一元二次方程」，需要满足哪三个硬条件：

  • 整式方程：方程两边含未知数的式子必须是整式（未知数不能在分母里，也不能在根号里）。
  • 一元：只含有一个未知数。
  • 二次：整理化简后，未知数的最高次数必须是 2。

直觉微图解 ①方程类型快速辨析器：逐条核验三个门槛

对比一一元一次方程 vs 一元二次方程

一元一次方程形如 \(ax+b=0\)（\(a \ne 0\)），未知数最高次数是 1，在实数范围内有且仅有 1 个解；一元二次方程最高次数是 2，最多可以有 2 个实数根。

对比二判断前必须先「移项化简」

看似有二次项的式子不一定是二次方程！例如 \((x+1)^2 = x^2 + 3x\)，展开后两边都有 \(x^2\)，抵消后变成 \(2x+1=3x\)，本质是一元一次方程。必须整理为右边为 0 后再下结论。

2. 核心点一：一般形式与系数符号

任何一个一元二次方程经过移项、合并同类项，都可以化成如下标准形式：

\(\color{#B5452F}{\underbrace{ax^2}_{\text{二次项}}} + \color{#2F7A56}{\underbrace{bx}_{\text{一次项}}} + \color{#966524}{\underbrace{c}_{\text{常数项}}} = 0 \quad (\mathbf{a \ne 0})\)

其中 \(a\) 叫作二次项系数，\(b\) 叫作一次项系数，\(c\) 叫作常数项。各项系数必须带着前面的正负号！

直觉微图解 ②为什么规定二次项系数 \(a \ne 0\)？

示范例题 1：化一般形式与识别各项系数

题目：将方程 \(3x(x - 2) = 2(x + 1) - 5\) 化成一元二次方程的一般形式，并指出二次项系数、一次项系数和常数项。

① 读懂题意：两边都有带括号的整式，目标是去括号、移项合并，整理成 \(ax^2+bx+c=0\) 的形式。

② 想办法：左边用单项式乘多项式展开，右边去括号；把所有项都移到等号左边，右边留 0；按降幂排列提取系数。

③ 执行与检查：
去括号，得：\(3x^2 - 6x = 2x + 2 - 5\)，即 \(3x^2 - 6x = 2x - 3\)．
移项，得：\(3x^2 - 6x - 2x + 3 = 0\)．
合并同类项，得一般形式：\(3x^2 - 8x + 3 = 0\)．
对照 \(ax^2+bx+c=0\)：二次项系数为 \(3\)，一次项系数为 \(-8\)（注意负号！），常数项为 \(3\)．

④ 回头看：检查移项变号：右边的 \(2x\) 移到左边变 \(-2x\)，\(-3\) 移到左边变 \(+3\)，没有遗漏。

自己试试 1：将一元二次方程 \(5x^2 - 1 = 4x\) 化为一般形式后，二次项系数、一次项系数、常数项分别是（　）

C。移项得 \(5x^2 - 4x - 1 = 0\)。注意一次项 \(4x\) 从右边移到左边要变号为 \(-4x\)，所以一次项系数是 \(-4\)；常数项原本就在左边，保持 \(-1\)。选 A 是移项忘记变号。

示范例题 2：含字母参数的一元二次方程条件判断

题目：已知关于 \(x\) 的方程 \((k - 2)x^{|k|} + 3x - 1 = 0\) 是一元二次方程，求 \(k\) 的值。

① 读懂题意：方程已整理为一般形式，未知数是 \(x\)，含有待定常数 \(k\)；题干明确指出它是「一元二次方程」。

② 想办法：一元二次方程有两大硬性门槛：最高次数必须等于 2，即 \(|k| = 2\)；二次项系数绝对不能为 0，即 \(k - 2 \ne 0\)。解出两个条件并求交集。

③ 执行与检查：
由未知数的最高次数为 2，得：\(|k| = 2 \implies k = 2\) 或 \(k = -2\)．
由二次项系数不能为 0，得：\(k - 2 \ne 0 \implies k \ne 2\)．
综合两条件，排除 \(k = 2\)，得 \(k = -2\)．

④ 回头看：若误取 \(k = 2\)，二次项系数 \(k - 2 = 0\)，方程变成 \(3x - 1 = 0\)，退化为一元一次方程，不合题意；故必须舍去 \(k = 2\)。

3. 核心点二：方程的解（根）与代入验算

使一元二次方程左右两边相等的未知数的值，叫作一元二次方程的解，一元方程的解也常称为根。判断一个数值是不是方程的根，唯一的法则就是代入计算两边是否相等。

直觉微图解 ③天平平衡验根器：对于方程 \(x^2 - 3x + 2 = 0\)

示范例题 3：已知方程的根，整体代入求代数式的值

题目：已知 \(m\) 是关于 \(x\) 的一元二次方程 \(x^2 + 2x - 4 = 0\) 的一个实数根，求代数式 \(3m^2 + 6m - 5\) 的值。

① 读懂题意：已知 \(m\) 是方程的根，但我们还没学求根公式，不能直接解出 \(m\)。要求的是一个含 \(m\) 的多项式的值。

② 想办法：根据根的定义，\(m\) 代入原方程必然成立，得到恒等式 \(m^2 + 2m - 4 = 0 \implies m^2 + 2m = 4\)。观察目标式 \(3m^2 + 6m - 5\)，前面两项提公因数 3，恰好包含整体 \((m^2+2m)\)！

③ 执行与检查：
因为 \(m\) 是方程 \(x^2 + 2x - 4 = 0\) 的根，所以：
\(m^2 + 2m - 4 = 0 \implies m^2 + 2m = 4\)．
将 \(m^2 + 2m = 4\) 整体代入所求式：
\(3m^2 + 6m - 5 = 3(m^2 + 2m) - 5 = 3\times 4 - 5 = 12 - 5 = 7\)．

④ 回头看：这种「不解方程、整体代入」是初高中极其重要的代数变形技巧，利用已知根将高次式降次化简。

自己试试 2：若 \(x = 2\) 是一元二次方程 \(x^2 + ax - 8 = 0\) 的一个根，则常数 \(a\) 的值为（　）

B。直接代入 \(x = 2\)：\(2^2 + 2a - 8 = 0 \implies 4 + 2a - 8 = 0 \implies 2a - 4 = 0 \implies a = 2\)。选 A 是移项变号弄错。

自己试试 3：已知 \(t\) 是一元二次方程 \(x^2 - 3x - 1 = 0\) 的根，则代数式 \(2t^2 - 6t + 2024\) 的值为（　）

A。因为 \(t\) 是根，所以 \(t^2 - 3t - 1 = 0 \implies t^2 - 3t = 1\)。所求式子提取公因式：\(2(t^2 - 3t) + 2024 = 2\times 1 + 2024 = 2026\)。

翻车现场 ①含参方程忽略二次项系数非零

题目说「关于 \(x\) 的一元二次方程 \((k-1)x^2 + 3x - 2 = 0\)」，很多同学只顾着算判别式或求根，却忘记第一步必须注明 \(k - 1 \ne 0 \implies k \ne 1\)。若 \(k=1\)，方程退化为一次方程！

翻车现场 ②没有移项化简就急着数项

面对 \(2x^2 + 3 = 2x(x - 1)\)，一眼看到有 \(2x^2\) 就判为二次方程；展开后右边也是 \(2x^2\)，抵消后其实是 \(3 = -2x \implies 2x + 3 = 0\)，是典型的一元一次方程。

翻车现场 ③系数带上了未知数或丢掉负号

对于 \(4x^2 - 7x + 5 = 0\)，问一次项系数是多少，常见错误写成 \(-7x\)（包含了未知数）或者写成 \(7\)（丢了负号）。系数是数，不含字母未知数，一次项系数是 \(-7\)。

再深一点：古人怎么解带平方的问题？《九章算术》与勾股容方

中国古代很早就遇到了实际问题中的二次方程。《九章算术》勾股章里有一类「邑方」问题：一座方城四面正中开门，出北门、南门各走若干步各有一棵树，再折向西走一段路恰好看到北门外的树，问城边长多少。列出来就是二次方程。中国古代数学家采用几何面积拼补（割补法）来求平方根，称作「开方术」或「带纵开方」，正是现代「配方法」的几何原型！

1. 直接用：下列方程中，属于一元二次方程的是（　）

D。A 选项没标明 \(a \ne 0\)，若 \(a=0\) 就不是二次方程；B 选项分母含未知数是分式方程；C 选项含两个未知数是二元方程；D 选项是整式方程、含一个未知数且最高次数为 2，是一元二次方程。

2. 直接用：将一元二次方程 \(3x^2 = 2 - 5x\) 化为一般形式后，其二次项系数、一次项系数和常数项分别为（　）

B。移项整理使右边为 0：\(3x^2 + 5x - 2 = 0\)。各项系数分别为 \(a=3, b=5, c=-2\)。

3. 易错题：若 \(x = -1\) 是关于 \(x\) 的一元二次方程 \(a x^2 + b x - 3 = 0\) 的一个根，则代数式 \(a - b + 2025\) 的值为（　）

提示

将 \(x = -1\) 代入方程，注意 \((-1)^2 = 1\) 以及 \(b(-1) = -b\)。

A。把 \(x = -1\) 代入原方程：\(a(-1)^2 + b(-1) - 3 = 0 \implies a - b - 3 = 0 \implies a - b = 3\)。所以 \(a - b + 2025 = 3 + 2025 = 2028\)。

4. 挑战题：已知关于 \(x\) 的一元二次方程 \(x^2 + px + q = 0\) 有一个根是 \(1\)，则代数式 \(p + q + 2\) 的值是（　）

提示

将 \(x = 1\) 代入方程，能得到 \(p+q\) 的整体数值。

B。代入 \(x = 1\) 得 \(1^2 + p(1) + q = 0 \implies 1 + p + q = 0 \implies p + q = -1\)。所以 \(p + q + 2 = -1 + 2 = 1\)。

巩固练习 1：若关于 \(x\) 的方程 \((m-2)x^{|m|}+3x-1=0\) 是一元二次方程，则 \(m\) 的值为（　）

B。方程是一元二次方程，要求未知数最高次数为 2，即 \(|m|=2\)，得 \(m=\pm 2\)；同时二次项系数 \(m-2\ne 0\)，即 \(m\ne 2\)．所以 \(m=-2\)，选 B．

巩固练习 2：已知 \(x=-2\) 是关于 \(x\) 的方程 \(x^2+kx-6=0\) 的一个根，则 \(k=\)______．

查看答案与解析，自行核对

答案：\(-1\)

把 \(x=-2\) 代入方程，得 \((-2)^2+k\times(-2)-6=0\)，即 \(4-2k-6=0\)，\(-2k-2=0\)，解得 \(k=-1\)．
