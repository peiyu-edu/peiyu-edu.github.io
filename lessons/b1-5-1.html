5.1 任意角和弧度制

角不只是「两条边夹出来的那块」，而是一条射线转出来的：可以反着转、可以转好几圈。再换一把以半径为单位的尺子去量它——弧度。

一个定时转盘（或滑板选手空中转体、拧阀门手轮）逆时针匀速转动，转一整圈（\(360^\circ\)）要 \(30\) 分钟。现在连续转了 \(45\) 分钟。先点下面的按钮，看指针留下的螺旋轨迹：

这 \(45\) 分钟（\(1\) 圈半）里，转盘指针一共转过了多少度？

D。\(45\) 分钟是 \(30\) 分钟的 \(1.5\) 倍，转了一圈半：\(360^\circ+180^\circ=540^\circ\)。

看上面的螺旋轨迹：转 \(540^\circ\) 时指针停的位置，和只转半圈（\(180^\circ\)）时一样都在正左方；可它实际绕了一圈半，多出来的那一整圈（\(360^\circ\)）不能丢。

初中的角都在 \(0^\circ\) 到 \(360^\circ\) 之间，装不下 \(540^\circ\)。这一节把角看成射线转出来的：说清往哪边转、转了多少、停在哪。再换一把用半径量角的尺子——弧度，用它算弧长和扇形面积。

1. 先认识几个词：任意角、终边相同角与弧度制

要用到：初中的角与度、圆周长 \(2\pi r\)、平面直角坐标系的四个象限；1.1 集合的描述法（回看 1.1）。先看下面这幅微图解：

直觉微图解 ①任意角旋转、弧度定义与扇形细分求和

几何真相终边相同不等于角相等

\(\beta = \alpha + 2k\pi\ (k\in\mathbb{Z})\) 仅说明终边停在同一射线方向上；但转动的周数、方向完全可以天差地别（如 \(390^\circ\) 与 \(30^\circ\)）！只有 \(k=0\) 时两角才真正相等。

书写红线度与弧度严禁跨界混用

严禁在同一个角表达式中写出 \(2k\pi + 60^\circ\) 或 \(k\cdot 360^\circ + \dfrac{\pi}{3}\)！必须纯度数或纯弧度！扇形公式 \(l=r|\alpha|\) 与 \(S=\dfrac{1}{2}r^2|\alpha|\) 必须代纯弧度！

2. 核心数学公式与角集合表达

普通扇形的圆心角大小取非负弧度 θ，0≤θ≤2π，面积 S=θr²/2。任意角转过多圈时，r|α|表示累计弧长；重叠扫过的区域不能按圈数重复算作一个普通扇形的面积。

\(\color{#2F7A56}{\underbrace{\beta = \alpha + 2k\pi,\ k\in\mathbb{Z}\quad (\text{角度制：}\beta = \alpha + k\cdot 360^\circ)}_{\text{终边相同角集合：相差整数圈}}}\) \(\color{#966524}{\underbrace{180^\circ = \pi\text{ rad},\ 1\text{ rad} = \left(\frac{180}{\pi}\right)^\circ \approx 57.30^\circ}_{\text{角度与弧度互化核心桥梁}}}\) \(\color{#3E5C76}{\underbrace{l = r|\alpha|,\quad S = \frac{1}{2}lr = \frac{1}{2}r^2|\alpha|}_{\text{弧度制下扇形弧长与面积（}\alpha\text{ 必须为弧度）}}}\)

例 1（分针顺时针旋转转角）

分针走了 \(40\) 分钟，转过的角是多少？把分针往回拨 \(10\) 分钟呢？

分针 \(60\) 分钟转一圈 \(360^\circ\)，每分钟 \(6^\circ\)。走 \(40\) 分钟顺时针转了 \(240^\circ\)，顺时针为负，即 \(-240^\circ\)。往回拨是逆时针转了 \(60^\circ\)，即 \(+60^\circ\)。

自己试试：把钟表的分针拨快 1 小时 15 分钟，分针转过的角是多少？

B。1 小时转一整圈 \(360^\circ\)，加 15 分钟的 \(90^\circ\)，共转 \(450^\circ\)；分针是顺时针旋转，形成负角 \(-450^\circ\)。选 A 的同学忘了方向；选 C、D 的同学只看指针最后停的位置，丢掉了整圈！

3. 三步破题思维链：大角归象限与扇形综合计算

例 2（示范：大角归象限与扇形面积三步思维链）

已知角 \(\alpha = -1470^\circ\)，写出与 \(\alpha\) 终边相同的角集合，判断 \(\alpha\) 是第几象限角；并求以此角对应主区间正角为圆心角、半径为 \(6\) 的扇形面积。

👀 第一步模除 360° 剥离整圈锁定主角： 对负角累加整圈化归到 \([0^\circ, 360^\circ)\)：
\(-1470^\circ + 5\times 360^\circ = -1470^\circ + 1800^\circ = 330^\circ\)；
写出终边相同集合：\(S = \{\beta\mid \beta = 330^\circ + k\cdot 360^\circ,\ k\in\mathbb{Z}\}\)。
🔧 第二步判定象限并化为标准弧度制： 因 \(270^\circ < 330^\circ < 360^\circ\)，终边落在第四象限，故 \(-1470^\circ\) 是第四象限角！
将主圆心角化为弧度制：\(\theta = 330^\circ \times \dfrac{\pi}{180^\circ} = \dfrac{11\pi}{6}\)。
🛡️ 第三步套扇形公式防带负号与防混角度： 扇形面积公式必须代入纯弧度：
\(S = \dfrac{1}{2} r^2 \theta = \dfrac{1}{2} \times 6^2 \times \dfrac{11\pi}{6} = 18 \times \dfrac{11\pi}{6} = 33\pi\)！（严禁直接代入角度 \(330\)，严防算成负面积！）

自己试试：\(1290^\circ\) 是第几象限角？

C。\(1290^\circ - 3\times 360^\circ = 1290^\circ - 1080^\circ = 210^\circ\)，介于 \(180^\circ\) 与 \(270^\circ\) 之间，落在第三象限。

例 3（度与弧度互化）

把 \(150^\circ\) 化成弧度，把 \(\dfrac{3\pi}{4}\) 化成度。

\(150^\circ \times \dfrac{\pi}{180^\circ} = \dfrac{5\pi}{6}\)；\(\dfrac{3\pi}{4} \times \dfrac{180^\circ}{\pi} = 135^\circ\)。

自己试试：\(210^\circ\) 化成弧度是？

A。\(210\times\dfrac{\pi}{180}=\dfrac{7\pi}{6}\)。比 \(\pi\)（\(180^\circ\)）稍大，符合直觉。

例 4（扇形弧长与面积求法）

半径 \(3\)、圆心角 \(120^\circ\) 的扇形，求弧长和面积。

先化纯弧度：\(120^\circ = \dfrac{2\pi}{3}\)。弧长 \(l = 3\times\dfrac{2\pi}{3} = 2\pi\)；面积 \(S = \dfrac{1}{2}\times 3^2 \times \dfrac{2\pi}{3} = 3\pi\)。

自己试试：半径 \(4\)、圆心角 \(45^\circ\) 的扇形，弧长是？

A。\(45^\circ = \dfrac{\pi}{4}\)，\(l = 4\times\dfrac{\pi}{4} = \pi\)。选 B 的同学直接代入角度 \(45\)；选 D 忘了乘以半径！

4. 用之前必查：三大高频翻车现场

翻车现场 ①度与弧度在同一集合中穿越混写
❌ 典型错解：写出终边相同的角集合：\(\{\beta\mid \beta = 2k\pi + 60^\circ\}\) 或 \(\{\beta\mid \beta = k\cdot 360^\circ + \dfrac{\pi}{3}\}\)。
✅ 一眼看清真相：单位严禁跨界杂交！必须整齐划一：要么纯度数 \(k\cdot 360^\circ + 60^\circ\)，要么纯弧度 \(2k\pi + \dfrac{\pi}{3}\)！
翻车现场 ②把第一象限角直接等同于锐角
❌ 典型错解：「终边在第一象限，所以它一定是锐角。」
✅ 看右图秒懂真相：\(390^\circ\) 和 \(-330^\circ\) 终边都在第一象限，但转过了多圈或反向旋转，绝非锐角！锐角必须严格限定在 \((0^\circ, 90^\circ)\) 内！
翻车现场 ③算扇形弧长面积直接代入角度制
❌ 典型错解：已知半径 \(r=2\)，圆心角 \(60^\circ\)，直接套公式写出弧长 \(l=2\times 60 = 120\)。
✅ 一眼看清真相：公式 \(l=r|\alpha|\) 成立的生命线是\(\alpha\) 为纯弧度！\(60^\circ\) 必须先化成 \(\dfrac{\pi}{3}\)，正确弧长为 \(2\times\dfrac{\pi}{3} = \dfrac{2\pi}{3}\)！
再深一点（可以先跳过）

象限角的严格区间表示：第一象限角集合是 \(\{\alpha\mid 2k\pi < \alpha < \dfrac{\pi}{2} + 2k\pi,\ k\in\mathbb{Z}\}\)。坐标轴上的轴线角不属于任何象限。

半角 \(\dfrac{\alpha}{2}\) 象限分析模型：若 \(\alpha\) 是第二象限角，有 \(\dfrac{\pi}{2}+2k\pi < \alpha < \pi+2k\pi\)，两边同除以 2 得 \(\dfrac{\pi}{4}+k\pi < \dfrac{\alpha}{2} < \dfrac{\pi}{2}+k\pi\)。当 \(k\) 为偶数时落在第一象限，\(k\) 为奇数时落在第三象限！

角与实数的完全一一对应：采用弧度制后，角彻底脱离了几何量角器的束缚，与全体实数 \(\mathbb{R}\) 建立了一对一的双射，使三角函数真正成为定义在实数集上的函数！

① 转一转：任意角、终边和扇形

拖动绿色圆点让终边转起来——可以转好几圈、也可以顺时针转成负角。蓝色螺线记下转过的全过程，绿色是终边，赤金色是始边。键盘：Tab 选中圆点，左右方向键转 \(15^\circ\)，PageUp / PageDown 转一整圈。

试试：把角调到 \(-300^\circ\)，再调到 \(420^\circ\)，终边一样吗？扇形的弧长和面积一样吗？

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(\dfrac{5\pi}{12}\) 化成度是？

A。\(\dfrac{5\pi}{12}\times\dfrac{180}{\pi}=\dfrac{5\times180}{12}=75\)。也可以记 \(\dfrac{\pi}{12}=15^\circ\)，再乘 \(5\)。选 D 的同学只算了 \(\dfrac{\pi}{12}\)，忘了乘 \(5\)。

2. 一个扇形的半径是 \(2\)，弧长是 \(3\)。它的面积是？

A。已知弧长，用 \(S=\dfrac12lr=\dfrac12\times3\times2=3\)。也可以先求角：\(|\alpha|=\dfrac lr=\dfrac32\)，\(S=\dfrac12\times2^2\times\dfrac32=3\)。选 B 的同学忘了 \(\dfrac12\)。

易错

3. 下面哪句话是对的？

答案 C。\(390^\circ=30^\circ+1\times360^\circ\)，终边重合；但一个转了一圈多，一个没转满一圈，是两个不同的角。

A 错：\(-330^\circ\)、\(390^\circ\) 都是第一象限角，都不是锐角。B 错：终边相同的角相差 \(360^\circ\) 的整数倍，只有 \(k=0\) 时才相等。D 错：\(-30^\circ\)、\(0^\circ\) 都小于 \(90^\circ\)，都不是锐角。

4. 角 \(-270^\circ\) 是第几象限角？

答案 D。\(-270^\circ=90^\circ-360^\circ\)，和 \(90^\circ\) 终边相同，终边落在 \(y\) 轴的正半轴上。

有的同学想「顺时针转过了第四、第三象限，停在第二象限边上」，于是选 B 或 C。可象限角只看终边停在哪；终边在坐标轴上，就不属于任何象限。在「动手」的图里把角拖到 \(-270^\circ\) 看看。

本视频题目：已知 \(\alpha\) 是第二象限角，判断 \(\alpha/2\) 所在象限。视频保留整周参数 \(k\in\mathbb Z\)，按奇偶分类；最后另以 \(\alpha/3\) 作对比变式。

5. 半径为 2 的圆中，一条射线从始边顺时针转过 \(60^\circ\)，扫出一个扇形（圆心角为 \(-60^\circ\)）。这个扇形的面积是多少？

答案 D。先化弧度：\(|-60^\circ|=\dfrac{\pi}{3}\)，再算 \(S=\dfrac12\times2^2\times\dfrac{\pi}{3}=\dfrac{2\pi}{3}\)。

A、B 是把 \(60\) 直接当弧度代进去了——\(60\) 弧度差不多转了 9 圈半，跟 \(60^\circ\) 差得远。A、C 还把负号带进了面积。角的正负只说明转的方向，扇形的大小看 \(|\alpha|\)。

挑战

6. 用一根长 \(8\) 的铁丝围成一个扇形（两条半径加一段弧，周长 \(8\)）。面积最大时，圆心角是多少弧度？

B。设半径 \(r\)，弧长 \(l=8-2r\)。面积 \(S=\dfrac12lr=\dfrac12(8-2r)r=r(4-r)\)。

\(r\) 和 \(4-r\) 的和是定值 \(4\)，用基本不等式（2.2）：\(r(4-r)\le\left(\dfrac{r+4-r}{2}\right)^2=4\)，等号在 \(r=4-r\)，即 \(r=2\) 时取到。这时 \(l=4\)，圆心角 \(|\alpha|=\dfrac lr=2\)。

选 D 的同学以为半圆最大；半圆时 \(r(\pi+2)=8\)，\(r\approx1.56\)，面积约 \(3.8\)，比 \(4\) 小。
