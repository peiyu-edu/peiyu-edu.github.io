有关 0 的运算

加、减、乘、除里碰到 0，结果会怎样？哪一种情况根本算不出来？

旧版目录，待新版核对

食堂摆了 6 个盘子，每个盘子里放了 0 个橘子（一个也没放）。6 个盘子里一共有几个橘子？

对，一共 0 个。6 个 0 加在一起，还是 0。这节课我们专门来看：加、减、乘、除里出现 0 会怎样。

1. 盘子和苹果：乘法里的 0

先摆 5 个盘子，每盘 3 个苹果。再把“盘子数”调到 0，或者把“每盘个数”调到 0，看一共有几个。

没有盘子，没有苹果可放，是 0；有盘子但每盘 0 个，也是 0。写成算式：0 × 7 = 0，7 × 0 = 0。0 乘任何数得 0，任何数乘 0 也得 0。

自己试试

9 × 0 = □，□ 是几？

9 个盘子，每盘 0 个，一共 0 个：9 × 0 = 0。

2. 加法和减法里的 0

8 个苹果，又放进 0 个：8 + 0 = 8。盘子里本来没有，放进 8 个：0 + 8 = 8。加 0，数不变。

8 个苹果，拿走 0 个：8 − 0 = 8。8 个苹果，全部拿走：8 − 8 = 0。一个数减去它自己，得 0。

自己试试

14 + 0 = □，□ 是几？

14 + 0 = 14，原来的苹果一个也没少。

自己试试

0 ÷ 5 = □，□ 是几？

0 ÷ 5 = 0。0 除以一个不是 0 的数，得 0。

加 0、减 0，数不变；一个数减去它自己得 0；0 乘任何数、任何数乘 0 都得 0；0 除以不是 0 的数得 0；0 不能作除数。

两个容易错的地方

✗ 0 × 8 = 8，8 + 0 = 0

把乘 0 和加 0 弄混了。

✓ 乘 0 变 0，加 0 不变

8 个盘子每盘 0 个，一个也没有：0 × 8 = 0。8 个苹果又放进 0 个，还是 8 个：8 + 0 = 8。

✗ 5 ÷ 0 = 0，或 0 ÷ 5 不行

分不清 0 在哪个位置。

✓ 0 ÷ 5 = 0，5 ÷ 0 没有答案

0 个苹果分给 5 人，每人 0 个。可是 5 ÷ 0 要找 □ × 0 = 5，乘 0 只能得 0，找不到。

直接用

1. 0 × 38 = □，□ 是几？

0 × 38 = 0。

2. 57 + 0 = □，□ 是几？

57 + 0 = 57。

3. 下面哪个算式的结果不是 0？

C。9 − 0 = 9，减 0 数不变。其余三个都是 0。

容易错

4. 305 × 4 = □，□ 是几？

300 × 4 = 1200，0 × 4 = 0，5 × 4 = 20，1200 + 0 + 20 = 1220。

5. 5 ÷ 0 等于多少？

C。5 ÷ 0 要找 □ × 0 = 5，可是任何数乘 0 都得 0，找不到这样的数。

想一想

6. 4 × 0 + (12 − 0) = □，□ 是几？

4 × 0 = 0，12 − 0 = 12，0 + 12 = 12。

7. 哪句话最能说明 6 ÷ 0 没有答案？

A。除法要用乘法检验，6 ÷ 0 的结果乘 0 要得 6，可是乘 0 只能得 0。

8. 小丽摆了一些盘子，每盘放 0 颗糖，旁边另外放着 23 颗糖。糖一共有多少颗？

盘子里是 0 颗，0 + 23 = 23（颗）。
