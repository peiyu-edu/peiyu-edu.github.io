2.2 基本不等式

两个正数，「和的一半」总不小于「积的平方根」。这一句话能求很多最大值、最小值。先从一个长方形开始。

一根 \(20\) 厘米的铁丝，围成一个长方形。长和宽加起来总是 \(10\) 厘米，可围法不同，面积不一样。

下面四种围法，哪种面积最大？

算一算：\(9\times1=9\)，\(7\times3=21\)，\(6\times4=24\)，\(5\times5=25\)。D 最大。

长宽的和都是 \(10\)，两条边越接近，面积（积）越大；正好相等时最大。

这一节就讲这件事：两个正数，和一定时，积在它们相等时最大；反过来，积一定时，和在它们相等时最小。

1. 先认识几个词

要用到：平方根（初中学过）；2.1 的不等式性质，比如两边同乘一个正数、方向不变（回看 2.1）。

两种平均数：两个正数 \(a\)、\(b\)，

  • 算术平均数 \(\dfrac{a+b}{2}\)：加起来，除以 \(2\)。
  • 几何平均数 \(\sqrt{ab}\)：乘起来，开平方。

例：\(2\) 和 \(8\)。算术平均数 \(\dfrac{2+8}{2}=5\)，几何平均数 \(\sqrt{2\times8}=\sqrt{16}=4\)。

再换几组：\(3\) 和 \(12\) 是 \(7.5\) 和 \(6\)；\(5\) 和 \(5\) 是 \(5\) 和 \(5\)。几何平均数从没比算术平均数大，两个数相等时两者一样。这就是本节的结论。

叫「几何」平均数，是因为 \(\sqrt{ab}\) 正好是和 \(a\times b\) 长方形面积一样大的正方形的边长：\(2\times8\) 的长方形面积 \(16\)，同面积的正方形边长 \(4\)。

定值：不随别的量变化的数。

例：周长 \(20\) 的长方形，长 \(9\) 宽 \(1\)、长 \(7\) 宽 \(3\)、长 \(5\) 宽 \(5\)……长、宽一直在变，长 \(+\) 宽始终是 \(10\)：「和是定值」。

再看 \(x\) 和 \(\dfrac4x\)：\(x=1\) 时是 \(1\) 和 \(4\)，\(x=2\) 时是 \(2\) 和 \(2\)，\(x=8\) 时是 \(8\) 和 \(0.5\)。两个数都在变，乘积始终是 \(4\)：「积是定值」。

当且仅当：「当且仅当 \(a=b\) 时等号成立」是两句话合在一起：

  • \(a=b\) 时，等号一定成立；
  • 等号成立时，一定是 \(a=b\)。只要 \(a\ne b\)，就是严格的「\(<\)」。

例：\(a=b=3\)，\(\sqrt{9}=3\)，\(\dfrac{3+3}{2}=3\)，相等；\(a=2\)，\(b=8\)，\(4<5\)，不相等。

最小值和下界：

  • 「\(f(x)\ge m\)」只是说值不会比 \(m\) 小，\(m\) 叫一个下界。下界可以有很多：值都 \(\ge 4\) 的话，说「\(\ge 3\)」「\(\ge 0\)」也都对。
  • 最小值是真能取到的那个最小的值：要找得到一个 \(x\)，让值等于它。

例：\(x\ge 3\) 时看 \(x+\dfrac4x\)。\(x=3\) 时约 \(4.33\)，\(x=4\) 时是 \(5\)，\(x=6\) 时约 \(6.67\)。值都 \(\ge 4\)，所以 \(4\) 是下界；可没有一个 \(x\) 能让它等于 \(4\)，所以 \(4\) 不是最小值。（这里的最小值是 \(x=3\) 时的 \(\dfrac{13}{3}\)，「练一练」第 4 题会讲。）

2. 结论

设 \(a>0\)，\(b>0\)，那么

\(\sqrt{ab}\le\dfrac{a+b}{2}\)，当且仅当 \(a=b\) 时取等号。

用上面的词说：两个正数的几何平均数不大于算术平均数，当且仅当两数相等时取等号。常用的写法是 \(a+b\ge 2\sqrt{ab}\)。

为什么：任何数的平方都不是负数，\((\sqrt a-\sqrt b)^2\ge 0\)，展开是 \(a-2\sqrt{ab}+b\ge 0\)，移项就得到 \(a+b\ge 2\sqrt{ab}\)。等号只在 \(\sqrt a=\sqrt b\)，也就是 \(a=b\) 时成立。

回到长方形：长 \(a\)、宽 \(b\)，\(a+b=10\)，那么 \(\sqrt{ab}\le 5\)，面积 \(ab\le 25\)，\(a=b=5\) 时取到。

3. 积一定，求和的最小值

例 1（看一遍怎么写）

\(x>0\)，求 \(x+\dfrac4x\) 的最小值。

\(x\) 和 \(\dfrac4x\) 都是正数，它们的积 \(x\cdot\dfrac4x=4\) 是定值，所以

\(x+\dfrac4x\ge 2\sqrt{x\cdot\dfrac4x}=2\sqrt4=4\)。

等号要 \(x=\dfrac4x\)，即 \(x=2\)。\(x=2\) 满足 \(x>0\)，能取到。所以最小值是 \(4\)，在 \(x=2\) 时取到。

自己试试：\(x>0\)，\(x+\dfrac9x\) 的最小值是？

B。积 \(x\cdot\dfrac9x=9\)，所以 \(x+\dfrac9x\ge 2\sqrt9=6\)，等号在 \(x=\dfrac9x\)，即 \(x=3\) 时取到。选 A 的同学只算了 \(\sqrt9\)，忘了前面的 \(2\)。

4. 和一定，求积的最大值

例 2

\(a>0\)，\(b>0\)，\(a+b=6\)，求 \(ab\) 的最大值。

\(\sqrt{ab}\le\dfrac{a+b}{2}=3\)，两边平方得 \(ab\le 9\)。等号要 \(a=b\)，配上 \(a+b=6\) 得 \(a=b=3\)，能取到。所以最大值是 \(9\)。

自己试试：\(x>0\)，\(y>0\)，\(x+y=8\)，\(xy\) 的最大值是？

C。\(\sqrt{xy}\le\dfrac{8}{2}=4\)，平方得 \(xy\le 16\)，\(x=y=4\) 时取到。选 A 的同学停在了 \(\sqrt{xy}\le 4\)，还没平方。

积一定，和有最小值：\(ab=P\) 时，\(a+b\ge 2\sqrt P\)。
和一定，积有最大值：\(a+b=S\) 时，\(ab\le\dfrac{S^2}{4}\)。
两种都在 \(a=b\) 时取到。

5. 用之前，查三件事

上面两个例子都顺利，是因为三件事都满足了。换一道题，可能就有一件不满足：

  1. 正：两个数都是正数。
    反例：只说 \(x\ne0\)，那 \(x=-1\) 时 \(x+\dfrac1x=-2\)，比 \(2\) 小，「\(\ge2\)」不对。
  2. 定：积是定值（求和的最小值），或和是定值（求积的最大值）。
    反例：\(x+\dfrac1{x^2}\) 里 \(x\cdot\dfrac1{x^2}=\dfrac1x\) 会变，直接套就算不出一个数。
  3. 等：等号要求的 \(a=b\)，在题目条件下真能做到。
    反例：\(x\ge3\) 时 \(x+\dfrac4x\ge4\) 没错，但等号要 \(x=2\)，不在范围里，\(4\) 取不到。
得到「\(\ge m\)」还不等于「最小值是 \(m\)」：要写出等号在哪里取到，并确认它满足题目条件。
再深一点（可以先跳过）

对任意实数都成立的一条：\((a-b)^2\ge 0\) 展开得 \(a^2+b^2\ge 2ab\)，\(a,b\) 正负都行，等号也在 \(a=b\) 时取到。别和 \(a+b\ge 2\sqrt{ab}\) 混：后者要求 \(a,b\) 不是负数，\(a=b=-1\) 时 \(a+b=-2\)，\(2\sqrt{ab}=2\)，就错了。

有一个是 \(0\) 也行：\(a\ge0\)，\(b\ge0\) 时结论照样成立（这时 \(\sqrt{ab}=0\)）。课本按正数写，知道 \(0\) 也对就行。

几何上看：线段长 \(a+b\)，被点 \(C\) 分成 \(a\)、\(b\) 两段，以它为直径画半圆，过 \(C\) 的垂线交半圆于 \(D\)。那么 \(CD=\sqrt{ab}\)，半径 \(=\dfrac{a+b}{2}\)，半弦不会比半径长。下一步可以拖着看。

连用几次：一道题里用两次基本不等式，两处的等号要能同时成立，否则得到的数取不到。「练一练」最后一题就是这种。

① 半圆：拖点 C，比较半弦和半径

直径长 \(a+b=8\)。拖动点 \(C\)（或选中后按方向键）改变 \(a\)。金色线 \(CD=\sqrt{ab}\)，蓝线是半径 \(OD=\dfrac{a+b}{2}=4\)。把 \(C\) 拖到正中间看看。

② 进阶：等号取不到时，最小值在哪

看 \(f(x)=x+\dfrac kx\)，只在 \(x\ge m\) 上取值。基本不等式给出 \(f(x)\ge 2\sqrt k\)，等号要 \(x=\sqrt k\)。先保持 \(m\) 很小，看最小值在 \(x=\sqrt k\)；再把 \(m\) 拖过 \(\sqrt k\)，看最小值怎么变。圆点 \(P\) 也能拖。

从易到难排好了。前两道直接用，中间两道是最常见的错，最后一道是挑战。

直接用

1. \(x>0\)，\(2x+\dfrac8x\) 的最小值是？

A。两个正数 \(2x\) 和 \(\dfrac8x\)，积 \(2x\cdot\dfrac8x=16\) 是定值，所以和 \(\ge 2\sqrt{16}=8\)。等号要 \(2x=\dfrac8x\)，\(x=2\)，能取到。选 B 的同学只算了 \(\sqrt{16}\)；选 C 是代了 \(x=1\)，那只是一个值，不是最小的。

2. \(x>0\)，\(y>0\)，\(2x+y=4\)，\(xy\) 的最大值是？

B。和是定值的是 \(2x\) 与 \(y\)（不是 \(x\) 与 \(y\)），先凑出来：\(xy=\dfrac12\cdot(2x)\cdot y\le\dfrac12\left(\dfrac{2x+y}{2}\right)^2=\dfrac12\cdot4=2\)。等号要 \(2x=y\)，配上 \(2x+y=4\) 得 \(x=1\)，\(y=2\)。选 C 的同学把 \(x\)、\(y\) 当成和为 \(4\) 了。

易错

3. \(x\) 是不等于 \(0\) 的实数。\(x+\dfrac1x\) 的最小值是？

C。「正」这一条不满足：题目没说 \(x>0\)。取 \(x=-1\)，值是 \(-2\)；取 \(x=-10\)，值是 \(-10.1\)；\(x\) 往负的方向走，值要多小有多小。

A 只在 \(x>0\) 时对。B 的 \(-2\) 是 \(x<0\) 时的最大值，不是最小值。

4. \(x\ge 3\)，\(x+\dfrac4x\) 的最小值是？

B。「等」这一条不满足：\(x+\dfrac4x\ge 4\) 没错，但等号要 \(x=2\)，不在 \(x\ge3\) 里，\(4\) 只是下界。在「动手」②里把 \(k\) 调成 \(4\)、\(m\) 调成 \(3\)：这一段一直往上走，最低点在端点 \(x=3\)，值是 \(3+\dfrac43=\dfrac{13}{3}\)。（「越往右越大」的严格说明要到第 3 章学单调性，现在看图、代几个数就能确认。）

挑战

5. \(a>0\)，\(b>0\)，\(a+2b=1\)。\(\dfrac1a+\dfrac1b\) 的最小值是？

B。常见错法：\(\dfrac1a+\dfrac1b\ge\dfrac{2}{\sqrt{ab}}\)，又 \(1=a+2b\ge 2\sqrt{2ab}\)，两步一接得 \(\ge 4\sqrt2\)。可第一步等号要 \(a=b\)，第二步要 \(a=2b\)，不可能同时成立，\(4\sqrt2\) 取不到。

正确做法只用一次：\(\dfrac1a+\dfrac1b=\left(\dfrac1a+\dfrac1b\right)(a+2b)=3+\dfrac{2b}{a}+\dfrac ab\ge 3+2\sqrt2\)，等号在 \(a=\sqrt2\,b\) 时取到，配上 \(a+2b=1\) 得 \(b=\dfrac{2-\sqrt2}{2}\)、\(a=\sqrt2-1\)，都是正数，能取到。

这一节的真题还在整理。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
