8.3 简单几何体的表面积与体积

表面积靠「展开化平」，体积抓「底面与高」。理解柱锥台球的统一结构，牢记母线与高的勾股差异，识别组合体接合面陷阱与祖暅原理思维。

冷饮店有两种相同高度 \(h=10\text{ cm}\)、底面半径都是 \(r=3\text{ cm}\) 的冰淇淋容器：一个是直筒圆柱杯，一个是尖底圆锥蛋筒。

如果将圆柱杯盛满冰淇淋，刚好能倒满几个这种等底等高的圆锥蛋筒？

B。刚好倒满 3 个！无论是圆锥与圆柱，还是棱锥与等底等高的棱柱，锥体体积恒为对应柱体体积的 \(\dfrac{1}{3}\)。

南北朝数学家祖冲之父子创立的「祖暅原理」更是揭示了空间体积的核心本质：「幂势既同，则积不容异」。这一节我们就来系统搞懂柱体、锥体、台体和球的表面积与体积计算法则。

1. 先认识几个词

要用到：初中的矩形与扇形面积、勾股定理、圆周长与圆面积公式。

高（\(h\)）与母线（\(l\)）：高是两底面或顶点到底面的垂直距离；母线是旋转体侧面的倾斜生成线。圆锥中满足勾股定理：\(l = \sqrt{r^2+h^2} > h\)。

算侧面积必须用母线 \(l\)；算体积必须用垂直高 \(h\)！

表面积与侧面积：所有侧面的面积之和叫侧面积；侧面积与底面积之和叫表面积（全面积），即 \(S_{\text{表}} = S_{\text{侧}} + S_{\text{底}}\)。

祖暅（gèng）原理：「幂势既同，则积不容异」。两等高立体在所有等高处的水平截面面积恒相等，则两立体体积必相等。这是推导柱、锥、球体积公式的灵魂基石。

2. 侧面展开与表面积：圆柱、圆锥、圆台

研究旋转体表面积的核心思想是把曲面展开成平面多边形或扇形：

  • 圆柱：侧面展开是长为 \(2\pi r\)、宽为 \(h\) 的矩形。\(S_{\text{侧}} = 2\pi rh\)，\(S_{\text{表}} = 2\pi r(r+h)\)。
  • 圆锥：侧面展开是半径为母线 \(l\)、弧长为底面周长 \(2\pi r\) 的扇形。
    \(S_{\text{侧}} = \dfrac{1}{2}(2\pi r)l = \pi rl\)，\(S_{\text{表}} = \pi r(r+l)\)；展开扇形圆心角 \(\theta = \dfrac{r}{l} \times 360^\circ\)。
  • 圆台：侧面展开是扇环。\(S_{\text{侧}} = \pi(r_1+r_2)l\)，\(S_{\text{表}} = \pi(r_1+r_2)l + \pi r_1^2 + \pi r_2^2\)。
展开扇形抓两量：半径等于母线 \(l\)，弧长等于底面周长 \(2\pi r\)。圆心角占比等于底面半径与母线之比：\(\theta = 360^\circ \times \dfrac{r}{l}\)。

例 1（看一遍怎么写）

已知圆锥底面半径 \(r = 3\)，垂直高度 \(h = 4\)。求：① 侧面积与全面积；② 侧面展开扇形圆心角 \(\theta\)；③ 底部拼接等底且高为 \(2\) 的圆柱，求组合体表面积。

解：

① 由勾股定理，母线长 \(l = \sqrt{r^2+h^2} = \sqrt{3^2+4^2} = 5\)。

侧面积 \(S_{\text{侧}} = \pi rl = \pi \times 3 \times 5 = 15\pi\)；全面积 \(S_{\text{表}} = 15\pi + \pi \times 3^2 = 24\pi\)。

② 展开扇形圆心角：\(\theta = \dfrac{r}{l} \times 360^\circ = \dfrac{3}{5} \times 360^\circ = 216^\circ\)（弧度制 \(\dfrac{6\pi}{5}\)）。

③ 拼接组合体表面积警示：拼接处的内部公共底面绝不能算进表面积！外露表面为：圆锥侧面（\(15\pi\)）+ 圆柱侧面（\(2\pi \times 3 \times 2 = 12\pi\)）+ 圆柱下底（\(9\pi\)）。总表面积 \(S = 15\pi + 12\pi + 9\pi = 36\pi\)。

自己试试：已知一个圆锥的底面半径为 \(3\)，高为 \(4\)，则该圆锥的侧面积是：

B。侧面积必须用母线斜长 \(l\)，绝不能把垂直高代入！由勾股定理，母线 \(l = \sqrt{3^2+4^2} = 5\)，代入得 \(S_{\text{侧}} = \pi rl = 15\pi\)。选 A 把垂直高当成了母线；选 C 算成了全面积。

3. 柱、锥、台的体积体系与祖暅原理

体积体系由柱体出发，由祖暅原理统一贯通：

  • 柱体：\(V_{\text{柱}} = Sh\)。无论是直柱还是斜柱，只要截面积相等、高相等，体积恒相等。
  • 锥体：\(V_{\text{锥}} = \dfrac{1}{3}Sh\)。等于等底等高柱体体积的三分之一。
  • 台体：\(V_{\text{台}} = \dfrac{1}{3}h\left(S_1 + \sqrt{S_1S_2} + S_2\right)\)。
台体公式是通式：当上底缩小为一个点（\(S_1 = 0\)）退化为锥体 \(V = \frac{1}{3}S_2h\)；当上底与下底全等（\(S_1 = S_2 = S\)）退化为柱体 \(V = Sh\)。

例 2

正四棱台的上底面边长为 \(2\)，下底面边长为 \(4\)，高为 \(3\)。① 用台体公式求体积；② 用大棱锥减去小棱锥验证。

解：

① 上底面积 \(S_1 = 2^2 = 4\)，下底面积 \(S_2 = 4^2 = 16\)，\(\sqrt{S_1S_2} = \sqrt{4 \times 16} = 8\)。

代入台体公式：\(V = \dfrac{1}{3} \times 3 \times (4 + 8 + 16) = 28\)。

② 还原法验证：设补上的小棱锥高为 \(x\)，由相似比 \(\dfrac{x}{x+3} = \dfrac{2}{4} \implies x = 3\)。大棱锥高为 \(6\)。大棱锥体积 \(V_{\text{大}} = \dfrac{1}{3} \times 16 \times 6 = 32\)；小棱锥体积 \(V_{\text{小}} = \dfrac{1}{3} \times 4 \times 3 = 4\)；棱台体积 \(V = 32 - 4 = 28\)。

自己试试：已知一个圆锥和一个圆柱的底面半径相等，高也相等。若圆柱的体积为 \(18\pi\)，则圆锥的体积是：

C。等底等高的圆锥与圆柱体积之比为 \(1:3\)。\(V_{\text{锥}} = \dfrac{1}{3}V_{\text{柱}} = \dfrac{1}{3} \times 18\pi = 6\pi\)。选 B 是除以了 2；选 D 是乘了 3。

4. 球的表面积、体积与经典切接模型

$$S_{\text{球}} = 4\pi R^2, \qquad V_{\text{球}} = \frac{4}{3}\pi R^3$$ 球表面积等于最大截面大圆面积的 4 倍；体积可看作以球心为顶点的微小锥体累加：\(V = \dfrac{1}{3}SR = \dfrac{4}{3}\pi R^3\)。

高考中球的切接核心是找准球心与半径 \(R\)：

  • 长方体外接球（补形法）：长宽高为 \(a, b, c\) 的长方体，体对角线长 \(\sqrt{a^2+b^2+c^2}\)。外接球直径等于体对角线：\(2R = \sqrt{a^2+b^2+c^2}\)。三条两两垂直棱的几何体（墙角模型）均可补成长方体求外接球！
  • 正方体内切球：切于 6 个面，直径等于棱长：\(2r_{\text{内}} = a \implies r_{\text{内}} = \dfrac{a}{2}\)。
  • 正方体棱切球：切于 12 条棱，直径等于面对角线：\(2R_{\text{棱}} = \sqrt{2}a \implies R_{\text{棱}} = \dfrac{\sqrt{2}}{2}a\)。

例 3（墙角模型求外接球）

在三棱锥 \(P-ABC\) 中，\(PA \perp PB\)，\(PB \perp PC\)，\(PC \perp PA\)，且 \(PA = 2, PB = 3, PC = 6\)。求外接球的表面积与体积。

解：

三条侧棱两两垂直，补成长宽高分别为 \(2, 3, 6\) 的长方体。外接球直径等于长方体体对角线：

$$2R = \sqrt{2^2+3^2+6^2} = \sqrt{4+9+36} = 7 \implies R = \frac{7}{2}$$

外接球表面积 \(S = 4\pi R^2 = 4\pi \left(\dfrac{7}{2}\right)^2 = 49\pi\)；体积 \(V = \dfrac{4}{3}\pi R^3 = \dfrac{343}{6}\pi\)。

自己试试：棱长为 \(2\) 的正方体，它的外接球体积与内切球体积之比为：

A。内切球半径 \(r = 1\)；外接球直径 \(2R = \sqrt{2^2+2^2+2^2} = 2\sqrt{3} \implies R = \sqrt{3}\)。体积比等于半径比的立方：\(\left(\dfrac{\sqrt{3}}{1}\right)^3 = 3\sqrt{3}\)。选 B 是面积比；选 C 是半径比。

5. 边界与高频易错（各配一个反例）

① 算体积误把斜高或母线当成高。反例：底面半径为 \(3\)、母线长为 \(5\) 的圆锥，垂直高为 \(4\)，体积是 \(12\pi\)，代入母线会错算成 \(15\pi\)。

② 组合体表面积不扣除内部粘合面。反例：两棱长为 \(1\) 的正方体拼成长方体，表面积是 \(10\) 不是 \(12\)，贴合面已在内部。

③ 台体体积中间项是几何平均数。反例：中间项是 \(\sqrt{S_1S_2}\)，不能写成 \(\dfrac{S_1+S_2}{2}\)，由均值不等式用算术平均会高估体积。

④ 半球表面积忘加底面圆面。反例：封闭半球表面积是半球面 \(2\pi R^2\) 加上底圆 \(\pi R^2\)，等于 \(3\pi R^2\)。

⑤ 并非所有几何体外接球球心都在内部。反例：直角三棱柱外接球球心在斜边面对角线中点；钝角三角形底面棱柱的外接球球心在几何体外。

再深一点（可以先跳过）

祖冲之父子与「牟合方盖」：西方 17 世纪才由卡瓦列里提出类似原理。早在公元 5 世纪，祖暅就提出了「幂势既同，则积不容异」。祖冲之和祖暅设计了两个垂直圆柱相交形成的「牟合方盖」，其截面与外切正方体截面之差正好等于倒立四棱锥截面，严密推导出球体体积公式为 \(\dfrac{4}{3}\pi R^3\)。

直接用

1. 已知一个球的表面积为 \(36\pi\)，则该球的体积为：

C。由球的表面积公式 \(S = 4\pi R^2 = 36\pi\)，解得 \(R^2 = 9\)，因为半径 \(R > 0\)，所以 \(R = 3\)。再代入球的体积公式：\(V = \dfrac{4}{3}\pi R^3 = \dfrac{4}{3}\pi \times 3^3 = 36\pi\)。

2. 一个圆台的上、下底面半径分别为 \(1\) 和 \(3\)，高为 \(3\)，则该圆台的体积为：

B。上底面积 \(S_1 = \pi \times 1^2 = \pi\)，下底面积 \(S_2 = \pi \times 3^2 = 9\pi\)。代入台体体积公式：

$$V = \frac{1}{3}h\left(S_1 + \sqrt{S_1S_2} + S_2\right) = \frac{1}{3}\times 3 \times (\pi + \sqrt{\pi \cdot 9\pi} + 9\pi) = \pi + 3\pi + 9\pi = 13\pi$$

易错

3. 某工件由一个底面半径为 \(1\)、高为 \(2\) 的圆柱和一个底面半径为 \(1\)、母线长为 \(2\) 的圆锥拼接而成（圆锥底面与圆柱上底面完全贴合）。则该工件的表面积为：

B。组合体表面积是外露在外部的所有面积之和，内部重合贴合的接触面绝不能算入表面积！

外露表面由三部分组成：

① 圆柱下底面：\(S_1 = \pi r^2 = \pi \times 1^2 = \pi\)；

② 圆柱侧面：\(S_2 = 2\pi r h = 2\pi \times 1 \times 2 = 4\pi\)；

③ 圆锥侧面：\(S_3 = \pi r l = \pi \times 1 \times 2 = 2\pi\)。

总表面积 \(S = S_1 + S_2 + S_3 = \pi + 4\pi + 2\pi = 7\pi\)。

易错警示：如果把圆柱全面积 \(6\pi\) 与圆锥全面积 \(3\pi\) 盲目相加得到 \(9\pi\)，就多算了贴合在内部的两个接触面。

4. 若一个圆锥的侧面展开图是一个半圆（圆心角为 \(180^\circ\)），且该半圆展开图的面积为 \(8\pi\)，则该圆锥的底面半径 \(r\) 和垂直高 \(h\) 分别为：

B。绝不能把展开扇形的母线长误认作圆锥的高！

展开扇形的半径是圆锥的母线长 \(l\)。半圆面积为 \(\dfrac{1}{2}\pi l^2 = 8\pi \implies l^2 = 16 \implies l = 4\)。

展开扇形的圆心角 \(\theta = \pi = 2\pi \times \dfrac{r}{l} \implies \dfrac{r}{4} = \dfrac{1}{2} \implies r = 2\)。

垂直高由勾股定理求得：\(h = \sqrt{l^2-r^2} = \sqrt{4^2-2^2} = \sqrt{12} = 2\sqrt{3}\)。

5. 有两个等底等高的几何体，一个为底面是正方形的正四棱锥，一个为底面是圆的圆锥。现用平行于底面的平面在高度的中点处将它们同时截开，关于截得的下半部分台体体积，下列说法正确的是：

C。本题考查等底等高锥体体积本质与台体生成规律：

① 原正四棱锥与圆锥等底（底面积均为 \(S\)）且等高（均为 \(h\)），体积公式均为 \(V = \dfrac{1}{3}Sh\)，两锥体体积相等（两锥在任一等高处的截面面积由相似比可知均为 \(\left(\dfrac{y}{h}\right)^2 S\)，处处相等，亦契合祖暅原理）；

② 在高度中点处平行截开，截去的小棱锥和小圆锥与原锥体相似比均为 \(1:2\)，故截去的小锥体体积均为原体积的 \(\left(\dfrac{1}{2}\right)^3 = \dfrac{1}{8}\)；

③ 剩余的棱台与圆台体积均为 \(1 - \dfrac{1}{8} = \dfrac{7}{8}\) 原锥体积。因此两台体体积完全相等，且均为原锥体积的 \(\dfrac{7}{8}\)。

挑战

6. 边长为 \(2\) 的正方体内部有一个内切球 \(O_1\)，外部有一个外接球 \(O_2\)。则内切球 \(O_1\) 与外接球 \(O_2\) 的表面积之比和体积之比分别为：

B。正方体边长为 \(a=2\)：

① 内切球切于 6 个面中心，其直径等于棱长：\(2R_1 = a = 2 \implies R_1 = 1\)；

② 外接球过正方体 8 个顶点，其直径等于正方体的体对角线：\(2R_2 = \sqrt{a^2+a^2+a^2} = \sqrt{3}a = 2\sqrt{3} \implies R_2 = \sqrt{3}\)；

③ 表面积之比等于半径比的平方：\(\dfrac{S_1}{S_2} = \left(\dfrac{R_1}{R_2}\right)^2 = \left(\dfrac{1}{\sqrt{3}}\right)^2 = 1:3\)；

④ 体积之比等于半径比的立方：\(\dfrac{V_1}{V_2} = \left(\dfrac{R_1}{R_2}\right)^3 = \left(\dfrac{1}{\sqrt{3}}\right)^3 = 1:3\sqrt{3}\)。
