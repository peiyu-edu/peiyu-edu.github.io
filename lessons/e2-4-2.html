4.2 等差数列

每一项都比前一项多同一个数，这样的数列最简单，也最常用。这一节讲它的第 \(n\) 项怎么写、前 \(n\) 项怎么加，以及加出来的和什么时候最大。

一个小礼堂，第 \(1\) 排有 \(20\) 个座位，往后每一排都比前一排多 \(2\) 个座位。

第 \(6\) 排有几个座位？

一排一排数：\(20,\ 22,\ 24,\ 26,\ 28,\ 30\)。第 \(6\) 排是 \(30\)，选 A。

从第 \(1\) 排走到第 \(6\) 排，只多了 \(5\) 次，所以是 \(20+5\times2\)，不是 \(20+6\times2\)。

「每次多同一个数」的数列叫等差数列。这一节讲：第 \(n\) 排有几个座位（通项），前 \(n\) 排一共几个座位（前 \(n\) 项和）。

1. 先认识几个词

要用到：4.1 的数列、项、通项公式、前 \(n\) 项和 \(S_n\)（回看 4.1）；一次函数 \(y=kx+b\) 和二次函数的顶点（函数 3.1、二次函数 2.3）。

相邻两项的差：后一项减前一项，\(a_{n+1}-a_n\)。

例：\(3,7,11,15\) 的相邻差是 \(4,4,4\)，都一样；\(1,2,4,7\) 的相邻差是 \(1,2,3\)，不一样。

公差：相邻差每一处都等于同一个常数时，这个常数叫公差，记作 \(d\)。它可以是正数、负数，也可以是 \(0\)。

例：\(3,7,11,15,\dots\) 的 \(d=4\)；\(10,7,4,1,\dots\) 的 \(d=-3\)；\(5,5,5,\dots\) 的 \(d=0\)。

前 \(n\) 项和 \(S_n\)：从第 \(1\) 项加到第 \(n\) 项，\(S_n=a_1+a_2+\dots+a_n\)。

例：数列 \(2,5,8,11,\dots\)，\(S_1=2\)，\(S_3=2+5+8=15\)。

一次函数的斜率：\(y=kx+b\) 里，\(x\) 每加 \(1\)，\(y\) 就加 \(k\)；图象是直线。

例：\(y=2x+1\)，\(x=1,2,3\) 时 \(y=3,5,7\)，每次多 \(2\)。是不是很像等差数列？下面会用到。

2. 定义和通项公式

一个数列，从第 \(2\) 项起，每一项减它的前一项都等于同一个常数 \(d\)，就叫等差数列：

\(a_{n+1}-a_n=d\)（对每一个正整数 \(n\) 都成立）

为什么通项长这样：\(a_2=a_1+d\)，\(a_3=a_1+2d\)，\(a_4=a_1+3d\)……从第 \(1\) 项走到第 \(n\) 项，一共走 \(n-1\) 步，每步加 \(d\)：

\(a_n=a_1+(n-1)d\)

把它整理成 \(a_n=dn+(a_1-d)\)：点 \((n,a_n)\) 都落在直线 \(y=dx+(a_1-d)\) 上，斜率就是公差 \(d\)。不过只取 \(n=1,2,3,\dots\)，图象是一个个分开的点，不是整条直线。

例 1（看一遍怎么写）

等差数列中 \(a_3=7\)，\(a_7=19\)，求通项公式和 \(a_{20}\)。

从第 \(3\) 项到第 \(7\) 项走了 \(4\) 步：\(a_7-a_3=4d\)，即 \(12=4d\)，\(d=3\)。

再往回走 \(2\) 步：\(a_1=a_3-2d=7-6=1\)。

所以 \(a_n=1+3(n-1)=3n-2\)，\(a_{20}=3\times20-2=58\)。

自己试试：等差数列 \(a_1=2\)，\(d=3\)，\(a_{20}\) 是？

A。\(a_{20}=2+(20-1)\times3=2+57=59\)。选 B 的同学用了 \(20\times3\)：从第 \(1\) 项到第 \(20\) 项只走 \(19\) 步。

3. 等差中项

三个数 \(a,A,b\) 排成等差数列，就要 \(A-a=b-A\)，整理得

\(2A=a+b\)，即 \(A=\dfrac{a+b}{2}\)

\(A\) 叫 \(a\) 与 \(b\) 的等差中项，就是两数的平均数；任意两个数都有，而且只有一个。

放到整个数列里：\(a_m+a_n=2a_1+(m+n-2)d\) 只和 \(m+n\) 有关。所以下标之和相等，两项之和就相等：\(m+n=p+q\) 时 \(a_m+a_n=a_p+a_q\)。比如 \(a_1+a_n=a_2+a_{n-1}=a_3+a_{n-2}=\cdots\)，下面求和就靠这一条。

例 2

(1) \(3\) 与 \(11\) 的等差中项：\(A=\dfrac{3+11}{2}=7\)。检验：\(3,7,11\) 的相邻差都是 \(4\)。

(2) 等差数列中 \(a_2+a_8=10\)，求 \(a_5\)。因为 \(2+8=5+5\)，所以 \(a_2+a_8=2a_5\)，\(a_5=5\)。

自己试试：\(-4\) 与 \(10\) 的等差中项是？

A。\(\dfrac{-4+10}{2}=3\)，检验 \(-4,3,10\) 的相邻差都是 \(7\)。选 B 的同学算的是 \(\dfrac{10-(-4)}{2}\)，那是公差，不是中项。

4. 前 \(n\) 项和：倒过来再加一遍

先算 \(1+2+\dots+100\)。把它正着写一遍、倒着写一遍，上下对齐相加：

\(S=1+2+\dots+99+100\)

\(S=100+99+\dots+2+1\)

每一列都是 \(101\)，共 \(100\) 列：\(2S=100\times101\)，\(S=5050\)。

一般的等差数列也一样：\(S_n\) 正写、倒写，每一列是 \(a_1+a_n\)，\(a_2+a_{n-1}\)，……由上一块，这些都相等，共 \(n\) 列，于是 \(2S_n=n(a_1+a_n)\)。再把 \(a_n=a_1+(n-1)d\) 代进去，得到第二种写法：

\(S_n=\dfrac{n(a_1+a_n)}{2}=na_1+\dfrac{n(n-1)}{2}d\)

知道首项和末项用第一个，知道首项和公差用第二个。

例 3

等差数列 \(a_1=2\)，\(d=3\)，求 \(S_{10}\)。

用第二个公式：\(S_{10}=10\times2+\dfrac{10\times9}{2}\times3=20+135=155\)。

用第一个公式验算：\(a_{10}=2+9\times3=29\)，\(S_{10}=\dfrac{10\times(2+29)}{2}=155\)。一样。

自己试试：\(1+3+5+\dots+19\) 等于？

A。先数项数：\(19=1+(n-1)\times2\)，\(n=10\)。\(S_{10}=\dfrac{10\times(1+19)}{2}=100\)。选 B 是忘了除以 \(2\)；选 C 是把项数当成了 \(19\)。

5. 用之前，看清四件事

  1. 公差可以是 \(0\)。\(5,5,5,\dots\) 的每个相邻差都是 \(0\)，是等差数列（常数数列）。
    反例：「等差数列的点都在一条斜着的直线上」不对。\(d=0\) 时 \(a_n=5\)，点排成一条水平线，\(a_n\) 是常数，不是非恒定的一次函数；这时 \(S_n=5n\) 也不是 \(n\) 的二次式。
  2. 判断是不是等差，用定义，不凭几项。要说明 \(a_{n+1}-a_n\) 对每一个 \(n\) 都是同一个常数。
    反例：\(1,2,3,5,8,\dots\) 前三项差都是 \(1\)，看着像，第四项就破了。正例：\(a_n=3n+1\)，\(a_{n+1}-a_n=3(n+1)+1-(3n+1)=3\)，对所有 \(n\) 都是 \(3\)，才能说它是等差数列。
  3. 求 \(S_n\) 的最值，\(n\) 只能取正整数。\(d\ne0\) 时 \(S_n=\dfrac d2n^2+\left(a_1-\dfrac d2\right)n\) 是 \(n\) 的二次式，可它的实数顶点常常不是整数。
    反例：\(a_1=10\)，\(d=-3\)，\(S_n=-\dfrac32n^2+\dfrac{23}2n\)，实数顶点 \(n=\dfrac{23}{6}\approx3.83\)，没有「第 \(3.83\) 项」，那里的值 \(\approx22.04\) 也取不到。比较两边的整数：\(S_3=21\)，\(S_4=22\)，最大值是 \(S_4=22\)。从项看也对得上：\(10,7,4,1\) 是正的，\(a_5=-2\) 开始变负，加到第 \(4\) 项最大。如果 \(n\) 还有范围（比如只到 \(n\le3\)），还要比较范围端点。
  4. 解出 \(n\)，检验是不是正整数、在不在范围里。
    反例：\(2+4+6+\dots\)，\(S_n=n(n+1)=30\)，解得 \(n=5\) 或 \(n=-6\)，项数不能是负数，只留 \(n=5\)。\(1+3+5+\dots\)，\(S_n=n^2=50\)，\(n=\sqrt{50}\) 不是整数，说明和永远不会正好是 \(50\)。
实数顶点只是「找最值的地方大概在哪」：真正的答案要在它两边的正整数（以及范围端点）里比较出来。
再深一点（可以先跳过）

通项是 \(pn+q\) 的形式（\(p,q\) 是常数）：一定是等差数列，公差是 \(p\)。因为 \(a_{n+1}-a_n=p\) 对所有 \(n\) 成立。\(p=0\) 也算，就是常数数列。

前 \(n\) 项和是 \(An^2+Bn\) 的形式（没有常数项）：数列一定是等差数列，公差 \(d=2A\)。如果多了常数项，比如 \(S_n=n^2+1\)，第 \(1\) 项会「多出来」，就不是了。「练一练」有一道这样的题。

顶点正好在两个整数中间：比如 \(a_1=8\)，\(d=-2\)，实数顶点 \(n=4.5\)，这时 \(S_4=S_5=20\)，两个 \(n\) 都取到最大值（因为 \(a_5=0\)，加不加它和一样）。在「动手」②里调出来看看。

① 拖首项和公差：点落在一条直线上

画的是前 \(8\) 项 \((n,a_n)\)。拖第 \(1\) 个点改 \(a_1\)，拖第 \(2\) 个点改 \(a_2\)（也就改了 \(d=a_2-a_1\)）；选中圆点后按上下方向键也行。虚线是 \(y=dx+(a_1-d)\)。把 \(d\) 调成 \(0\) 看看。

② 进阶：\(S_n\) 什么时候最大（最小）

实心点是 \(S_1,S_2,\dots,S_{20}\)；虚线是把 \(n\) 当实数画出的抛物线。空心圈是实数顶点，金色点是真正取到最值的整数 \(n\)。拖圆点 \(P\)（或按左右方向键）读任意一个 \(S_n\)。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. 等差数列中 \(a_3=7\)，\(a_9=25\)，\(a_1\) 是？

A。第 \(3\) 项到第 \(9\) 项走 \(6\) 步：\(6d=25-7=18\)，\(d=3\)；再往回走 \(2\) 步：\(a_1=7-2\times3=1\)。选 C 的同学只往回走了 \(1\) 步。

2. 等差数列中 \(a_2+a_8=16\)，\(S_9\) 是？

A。\(1+9=2+8\)，所以 \(a_1+a_9=a_2+a_8=16\)，\(S_9=\dfrac{9\times16}{2}=72\)。不用求出 \(a_1\) 和 \(d\)。选 B 是忘了除以 \(2\)。

易错

3. 数列 \(5,5,5,5,\dots\)（每一项都是 \(5\)）。下面说法对的是？

B。每个相邻差都是 \(0\)，同一个常数，符合定义，\(d=0\) 完全可以。这时 \(a_n=5\)，点排成水平一行；「等差数列的通项是 \(n\) 的一次函数、图象斜着」只在 \(d\ne0\) 时成立。在「动手」①把 \(d\) 调到 \(0\) 就能看到。

4. 数列的前 \(n\) 项和 \(S_n=n^2+1\)。它是等差数列吗？

B。\(a_1=S_1=2\)。\(n\ge2\) 时 \(a_n=S_n-S_{n-1}=2n-1\)，得 \(a_2=3\)，\(a_3=5\)，\(a_4=7\)。数列是 \(2,3,5,7,\dots\)：\(a_2-a_1=1\)，后面都是 \(2\)，不是每一处都一样，不是等差数列。

A 错在 \(a_n=S_n-S_{n-1}\) 只对 \(n\ge2\) 成立，第 \(1\) 项要单独用 \(S_1\) 算；只看后面几项是 \(2\) 就下结论，正是「凭几项」。

5. 等差数列 \(a_1=13\)，\(d=-3\)。\(S_n\) 的最大值是？

B。\(S_n=13n-\dfrac{3n(n-1)}{2}=-\dfrac32n^2+\dfrac{29}{2}n\)。当实数看，顶点 \(n=\dfrac{29}{6}\approx4.83\)，那里的值是 \(\dfrac{841}{24}\approx35.04\)，但没有第 \(4.83\) 项，A 取不到。

比较两边的整数：\(S_4=52-18=34\)，\(S_5=65-30=35\)，最大值是 \(S_5=35\)。选 C 是把 \(4.83\) 直接截成了 \(4\)。从项看：\(13,10,7,4,1\) 都是正的，\(a_6=-2\)，加到第 \(5\) 项最大。

挑战

6. 等差数列 \(a_1=20\)，\(d=-2\)，\(S_n=54\)。\(n\) 是？

C。\(S_n=20n-n(n-1)=21n-n^2=54\)，即 \(n^2-21n+54=0\)，\((n-3)(n-18)=0\)。检验：两个根都是正整数，都要。

\(n=18\) 为什么也行：\(a_4=14\)，\(a_{18}=-14\)，从第 \(4\) 项到第 \(18\) 项正负抵消，和是 \(0\)，所以 \(S_{18}=S_3=54\)。只留一个的同学没把每个根都检验。

对比：若 \(S_n=100\)，\(n^2-21n+100=0\) 的根是 \(\dfrac{21\pm\sqrt{41}}{2}\)，不是整数，这个和取不到。

这一节的真题还在整理。选择题点选项自动判对错；填空题写法不同时，看答案自己判。要用到后面章节的题收在最后，学到那里再做。
