7.2 复数的四则运算

把 \(i\) 当作字母像多项式一样加减乘，唯独记住 \(i^2=-1\)；除法借共轭把分母实数化。

初中我们做多项式运算时，遇到含字母的式子如 \((2 + 3x) + (4 - x)\)，只需要把同类项合并，就得到 \(6 + 2x\)。

在复数中，复数由实部和虚部组成。如果把两个复数加起来，运算法则也是这样自然：

入门题：计算 \((1 + 2i) + (3 + 4i)\)，实部和实部相加、虚部和虚部相加，结果是？

A。很自然！实部 \(1+3=4\)，虚部 \(2+4=6\)，合起来就是 \(4+6i\)。

复数的加减法，跟多项式合并同类项一模一样：实部与实部算，虚部与虚部算。

那如果遇到两个虚数相乘（会出现 \(i^2\)），或者除法（分母上有 \(i\)），该怎么算？这一节我们就把复数的加、减、乘、除四则运算与几何意义一次讲透。

1. 先认识几个词

要用到：7.1 复数的概念与复平面（回看 7.1）；初中多项式乘法与平方差公式；平面向量的加减法则。

直觉微图解

线性加减 ①加减法：对应复平面向量的平行四边形法则

实虚部独立：\((a+bi) \pm (c+di) = (a\pm c) + (b\pm d)i\)。差的模长 \(|z_1 - z_2|\) 几何意义即为复平面上两点间的欧氏距离。

乘除本质 ②乘除法：遇见 i² 换成 -1，除法借共轭化实

多项式与实数化：展开后遇 \(i^2=-1\) 合并同类项；除法分子分母同乘分母共轭 \((c-di)\)，分母平方差必出非负实数 \(c^2+d^2\)。

虚数单位 \(i\)：定义 \(i^2 = -1\)。加减乘时把它当成多项式中的字母，唯独在遇到 \(i^2\) 时替换为 \(-1\)（例：\(3i \times 2i = 6i^2 = -6\)）。

共轭复数与分母实数化：若 \(z = a + bi\)，共轭为 \(\overline{z} = a - bi\)。乘积恒为实数：\(z\overline{z} = a^2 + b^2 = |z|^2\)。除法借此消去分母虚部。

2. 核心公式与运算法则

① 加法与减法：\((a+bi) \pm (c+di) = (a\pm c) + (b\pm d)i\)；
② 乘法法则：\((a+bi)(c+di) = (ac - bd) + (ad + bc)i\)（\(bd\cdot i^2 = -bd\) 变号！）；
③ 共轭乘积：\(z \cdot \overline{z} = (c+di)(c-di) = c^2 + d^2 = |z|^2\)（中间是加号，恒为非负实数！）；
④ 除法分母实数化：\(\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{c^2+d^2} = \dfrac{ac+bd}{c^2+d^2} + \dfrac{bc-ad}{c^2+d^2}i\)；
⑤ 模的乘除性质与 i 周期性：\(|z_1 z_2| = |z_1||z_2|\)，\(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\)；\(i^1=i, i^2=-1, i^3=-i, i^4=1\)（周期为 4）。

例 1（加减法示范）

已知 \(z_1 = 3 - 2i\)，\(z_2 = -1 + 4i\)，求 \(z_1 + z_2\) 与 \(z_1 - z_2\)。

解：

\(z_1 + z_2 = [3 + (-1)] + [-2 + 4]i = 2 + 2i\)。

\(z_1 - z_2 = [3 - (-1)] + [-2 - 4]i = 4 - 6i\)。

自己试试：已知 \(z_1 = 2 + 3i\)，\(z_2 = 4 - i\)，则 \(z_1 - z_2\) 等于？

B。实部相减：\(2 - 4 = -2\)；虚部相减：\(3 - (-1) = 4\)，所以结果为 \(-2 + 4i\)。选 A 的同学把虚部算成了 \(3 - 1 = 2\)（漏掉负负得正）。

例 2（乘法与共轭示范）

计算：(1) \((2 + i)(3 - 2i)\)；(2) \((2 - 3i)(2 + 3i)\)。

解：

(1) 展开：\(2\times 3 + 2\times(-2i) + i\times 3 - 2i^2 = 6 - 4i + 3i - 2(-1) = 8 - i\)。

(2) 利用共轭乘积性质：\(2^2 + 3^2 = 4 + 9 = 13\)。

自己试试：计算 \((1 + 2i)(2 - i)\) 的结果是？

A。展开：\(2 - i + 4i - 2i^2 = 2 + 3i - 2(-1) = 4 + 3i\)。选 B 的同学忘了算常数项 \(2 - (-2) = 4\)。

3. 典型例题：三步思维链精讲

例 3（高频综合·分母实数化与高次幂模长）

已知复数 \(z = \dfrac{3-i}{1+i} + 2i^{2026}\)。
① 将 \(z\) 化为代数形式 \(a+bi\)（\(a, b\in\mathbf{R}\)）；
② 求复数 \(z\) 的共轭复数 \(\overline{z}\) 以及模长 \(|z|\)。

👀 第一眼·破题信号
看到分式除法与高次幂 \(i^k\) → 核心破题信号：分子分母同乘分母共轭做「分母实数化」，高次幂除以 4 看余数化简！
🔧 第二步·套公式拆解
① 分母实数化：分子分母同乘 \(1-i\)：
    \(\dfrac{3-i}{1+i} = \dfrac{(3-i)(1-i)}{(1+i)(1-i)} = \dfrac{3 - 3i - i + i^2}{1^2 - i^2} = \dfrac{3 - 4i - 1}{1 - (-1)} = \dfrac{2 - 4i}{2} = 1 - 2i\)；
② 高次幂化简：\(2026 = 4\times 506 + 2\)，余数为 2：
    \(i^{2026} = (i^4)^{506}\cdot i^2 = 1\cdot(-1) = -1 \implies 2i^{2026} = -2\)；
③ 代数求和：\(z = (1 - 2i) + (-2) = \) \(-1 - 2i\)；
④ 共轭与模长：\(\overline{z} = \) \(-1 + 2i\)，模长 \(|z| = \sqrt{(-1)^2 + (-2)^2} = \sqrt{1 + 4} = \) \(\sqrt{5}\)。
🛡️ 第三步·必查防坑点
① 分母是 \((1+i)(1-i) = 1^2 - i^2 = 1 - (-1) = 2\)，绝不是 \(1-1=0\)；
② 模长公式根号内必为加号：\((-1)^2 + (-2)^2 = 1 + 4 = 5\)，绝不能写成 \(1 - 4 = -3\)；
③ \(i^2 = -1\) 负负得正变号千万别错。

自己试试：化简 \(\dfrac{2}{1+i}\) 的结果是？

D。分子分母同乘 \(1-i\)：\(\dfrac{2(1-i)}{(1+i)(1-i)} = \dfrac{2(1-i)}{1 - i^2} = \dfrac{2(1-i)}{2} = 1 - i\)。选 B 的同学分子乘了共轭，分母却忘了乘以共轭。

4. 这三种情况最容易翻车

翻车现场 ①分母平方差写成减号算出除以 0
错解

把 \((c+di)(c-di)\) 算成 \(c^2 - d^2\)，当 \(c=1, d=1\) 时算得分母 \(1-1=0\)。

正解

\((c+di)(c-di) = c^2 - d^2 i^2 = c^2 + d^2\)！中间是加号，分母恒正不为 0。

翻车现场 ②负数开方相乘套用实数乘法漏负号
错解

\(\sqrt{-2}\times\sqrt{-3} = \sqrt{(-2)\times(-3)} = \sqrt{6}\)。

正解

必须先化为虚数单位：\(\sqrt{2}i \times \sqrt{3}i = \sqrt{6}i^2 = -\sqrt{6}\)！相差负号。

翻车现场 ③只乘分子忘记乘分母
错解

化简 \(\dfrac{2}{1+i}\) 直接写成 \(2(1-i) = 2-2i\)。

正解

必须分子分母同乘共轭，分母为 \(1^2 - i^2 = 2\)，约分后为 \(1-i\)。

再深一点：高频简算结构与模的运算技巧（可以先跳过）

高考与模拟高频结构：

  • \((1+i)^2 = 2i\)，\((1-i)^2 = -2i\)（计算高次幂时先平方秒杀）。
  • \(\dfrac{1+i}{1-i} = i\)；\(\dfrac{1-i}{1+i} = -i\)。
  • 模的乘除法性质：\(|z_1 \cdot z_2| = |z_1| \cdot |z_2|\)；\(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\)。只求模长时先取模后乘除，速度翻倍！

① 复平面的四则运算与几何向量

复平面上实轴为横轴，虚轴为纵轴。拖动圆点 \(z_1\)（松绿）或 \(z_2\)（赤金）（或选中后用键盘方向键操作），切换上方运算按钮，观察代数运算式与几何向量的动态对应。

方向键微调选中点坐标；拖动可自由改变位置。

从易到难排好了。前两道直接用，中间三道是典型易错陷阱，最后一道是挑战。

直接用

1. 计算 \((2 + i)(1 - 2i)\) 的结果是？

A。展开得 \(2 - 4i + i - 2i^2 = 2 - 3i - 2(-1) = 4 - 3i\)。

选 B 的同学漏算了 \(-2i^2 = +2\)；选 C 的同学虚部符号搞反。

2. 已知复数 \(z = \dfrac{3+i}{1-i}\)，则 \(z\) 的共轭复数 \(\overline{z}\) 是？

B。先化简 \(z\)：分子分母同乘 \(1+i\)，得 \(z = \dfrac{(3+i)(1+i)}{(1-i)(1+i)} = \dfrac{3+3i+i+i^2}{1-(-1)} = \dfrac{2+4i}{2} = 1 + 2i\)。

注意题目问的是共轭复数 \(\overline{z}\)，虚部变号，得 \(\overline{z} = 1 - 2i\)。选 A 的同学直接选了 \(z\) 而忘了求共轭！

易错

3. 计算 \(\sqrt{-3} \times \sqrt{-12}\) 的结果是？

B。在复数范围内，负数根式乘法不能套用实数乘法公式 \(\sqrt{a}\cdot\sqrt{b} = \sqrt{ab}\)！

必须先提虚数单位 \(i\)：\(\sqrt{-3} = \sqrt{3}i\)，\(\sqrt{-12} = 2\sqrt{3}i\)。相乘得 \((\sqrt{3}i)(2\sqrt{3}i) = 6i^2 = -6\)。

若直接算 \(\sqrt{(-3)\times(-12)} = \sqrt{36} = 6\) 就中了经典负号陷阱！

4. 计算 \(i + i^2 + i^3 + \dots + i^{2026}\) 的值是？

C。因为 \(i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1\)，连续四项之和 \(i + i^2 + i^3 + i^4 = 0\)。以 4 为周期循环。

一共有 2026 项，\(2026 \div 4 = 506\) 余 \(2\)。因此前 \(506\times 4 = 2024\) 项全部抵消为 0，只剩下最后两项：\(i^{2025} + i^{2026} = i^1 + i^2 = i + (-1) = -1 + i\)。

5. 设 \(z_1 = 3 + 4i\)，\(z_2 = 1 + 2i\)，下列结论正确的是？

B。复数没有本章意义下的大小顺序，只要含有非零虚部，两个复数就绝不能写大于号或小于号！A、C、D 都是严重的概念错误。

但是，模长 \(|z_1| = \sqrt{3^2+4^2}=5\)，\(|z_2| = \sqrt{1^2+2^2}=\sqrt{5}\)，模长是实数，可以比较大小，\(|z_1| > |z_2|\)。

挑战

6. 已知复数 \(z\) 满足 \((1+i)z = |3 - 4i| + 3i\)，则复数 \(z\) 的模 \(|z|\) 是？

A。注意 \(|3-4i| = \sqrt{3^2+(-4)^2} = 5\) 是实数，所以等式为 \((1+i)z = 5 + 3i\)。

方法一（速算模长）：两边同时取模，\(|(1+i)z| = |1+i| \cdot |z| = \sqrt{2}|z|\)。右边模长 \(|5+3i| = \sqrt{5^2+3^2} = \sqrt{34}\)。所以 \(|z| = \dfrac{\sqrt{34}}{\sqrt{2}} = \sqrt{17}\)。

方法二（先求 \(z\)）：\(z = \dfrac{5+3i}{1+i} = \dfrac{(5+3i)(1-i)}{2} = \dfrac{8-2i}{2} = 4-i\)，则 \(|z| = \sqrt{4^2+(-1)^2} = \sqrt{17}\)。
