B。基本性质是“同乘或同除”，不是同加。 = ， 比 大。

记住这句话 分数的分子和分母同时乘或者除以相同的数（0 除外），分数的大小不变。
对：同乘或同除

分子、分母要同时乘或同时除以同一个数。

错：只乘分母，或同加一个数

只乘分母会变小，同加一个数大小也会变。

对：这个数不能是 0

乘 0 或除以 0 都没有意义。

错：乘 0 也行

乘 0 分母就变成 0 了。

为什么同乘或同除，大小不变？

把 1 份再平均分成 k 小份，份数乘了 k，取的份数也乘了 k，涂的总长不变，所以大小不变。
