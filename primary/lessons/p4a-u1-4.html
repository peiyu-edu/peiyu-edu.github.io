亿以上数的认识和读法

从一亿往后数还有哪些更大的计数单位？含有亿级、万级、个级三级的数怎样读？

人一生的心跳大约有 25 亿到 30 亿次。如果从一亿开始，一亿一亿地数，数满 10 个一亿是多少？

对！10 个一亿是十亿，10 个十亿是一百亿，10 个一百亿是一千亿。像这样，每相邻两个计数单位之间的进率都是 10 的计数方法叫作十进制计数法。

1. 十二位三级数位表与分级读数台

点下面的亿以上大数，或者直接点表格里的数字改变它，看看分成亿级、万级、个级三级后，每一级怎样读、末尾和中间的 0 怎样处理。

亿以上数的读法：
1. 先分级（从右边起每四位一级，分成个级、万级、亿级），再从最高级（亿级）读起；
2. 读完亿级或万级的数，要在后面加上「亿」字或「万」字；
3. 每级末尾不管有几个 0，都不读；其他数位上有一个 0 或连续几个 0，都只读一个零。

自己试试

先给十位数 7000000000 分级（70|0000|0000），它应该读作什么？

B。亿级是 70，读作七十亿；万级和个级全是 0 不读，所以读作七十亿。

自己试试

再读十二位数 5008|0600|0000，下面哪个读法是对的？

A。亿级「5008」读作五千零八亿，万级「0600」读作零六百万，个级全 0 不读，合起来是五千零八亿零六百万。

每相邻两个计数单位之间的进率都是 10 的计数方法叫作十进制计数法。读亿以上的数，先从右往左每四位分级，从亿级读起，读完亿级加「亿」字、读完万级加「万」字。

两个容易错的地方

✗ 从左往右每四位分级 把九位数 258004000 从左往右分成 2580|0400|0，读错位数。
✓ 必须「从右边起（从个位起）」每四位一级 从右往左分：2|5800|4000，读作「二亿五千八百万四千」。
✗ 亿级末尾的 0 误读出来，或万级开头的 0 漏读 把 200|5000|3000 错读成「二百亿零五千万三千」。
✓ 亿级末尾 0 不读，万级千位也不是 0 就不读零 200|5000|3000 读作「二百亿五千万三千」（一个零也不读）。

直接用

1. 一个十二位数，它的最高位是什么数位？

C。个级 4 位、万级 4 位、亿级 4 位（亿位、十亿位、百亿位、千亿位），第 12 位是千亿位。

2. 根据十进制计数法，10 个一亿是十亿，（ ）个十亿是一百亿，10 个一百亿是一千亿。

10 个十亿是一百亿。

容易错

3. 读出 380|0700|0000 这个数：

B。亿级「380」末尾 0 不读（三百八十亿），万级「0700」开头 0 读一个零、末尾两个 0 不读（零七百万），合起来是三百八十亿零七百万。

4. 当万级上全是 0 时：6|0000|0500 应该怎么读？

A。亿级是 6（六亿），万级全是 0 且个级千位也是 0，中间连续的 0 合起来只读一个「零」，读作六亿零五百。

想一想

5. 7504000000 是由 （ ）个亿和 400 个万组成的。

分级后是 75|0400|0000，亿级是 75，万级是 400，所以由 75 个亿和 400 个万组成。

6. 读出十二位数 904030000800 时，一共要读出（ ）个「零」。

分级 9040|3000|0800，读作「九千零四十亿三千万零八百」，一共读出 2 个零。
