7.3 离散型随机变量的数字特征

分布列把一个随机变量的情况全列出来了，可表太长时，我们想用一两个数说清楚：平均能得多少？结果稳不稳？这就是均值和方差。

小店门口有个十等分抽奖转盘：转一次，有 \(\dfrac1{10}\) 的机会得 \(10\) 元，\(\dfrac3{10}\) 的机会得 \(2\) 元，其余 \(\dfrac6{10}\) 什么也没有。先点下面的按钮看转盘扇区与 \(100\) 次总账：

转 \(100\) 次，大约 \(10\) 次得 \(10\) 元、\(30\) 次得 \(2\) 元、\(60\) 次没得。这 \(100\) 次一共大约得多少元？

B。\(10\times10+2\times30+0\times60=160\) 元。

平均每次大约 \(160\div100=1.6\) 元，也就是 \(10\times\dfrac1{10}+2\times\dfrac3{10}+0\times\dfrac6{10}=1.6\)：每个取值乘上它的概率再加起来。

这个「按概率加权的平均」就是本节的均值。注意 \(1.6\) 元一次也转不出来，它说的是转很多次之后的平均。光有平均还不够，每次得多得少差得大不大，要用方差来量。

1. 先认识几个词

要用到：7.2 分布列与概率性质（回看 7.2）；必修二 9.2 样本均值与方差（回看 9.2）。期望与方差是用两个核心数刻画随机变量全貌的指标。

课本用词：期望可线性变换；方差对加常数不变、对乘常数平方缩放，标准差是方差开平方，单位与原变量一致。

数学期望 \(E(X)\)（概率加权平均值 / 物理重心）：随机变量 \(X\) 的所有可能取值与其对应概率乘积的总和，记作 \(E(X)\) 或 \(\mu\)：

$$E(X) = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n$$

直觉：就像杠杆原理，每个取值 \(x_i\) 是秤杆上的刻度，概率 \(p_i\) 是挂在该位置的重物，期望 \(E(X)\) 正好就是让杠杆保持绝对平衡的支点位置！

方差 \(D(X)\) 与标准差 \(\sigma(X)\)（偏离中心的波动与风险）：各可能取值偏离均值的平方的概率加权平均值，记作 \(D(X)\) 或 \(\operatorname{Var}(X)\)：

$$D(X) = \sum_{i=1}^n (x_i - E(X))^2 p_i = E(X^2) - [E(X)]^2$$

标准差 \(\sigma(X) = \sqrt{D(X)}\) 是方差的算术平方根（与 \(X\) 具有相同量纲单位）。方差越大，说明数据分布越分散、波动越剧烈、风险越高。

线性变换法则（平移与放缩）：若 \(Y = aX + b\)（\(a, b\) 为常数）：

• 期望：\(E(aX + b) = aE(X) + b\)（均值随之同比例拉伸并平移）；
• 方差：\(D(aX + b) = a^2 D(X)\)（常数 \(b\) 整体平移不改变离散离度，倍数 \(a\) 平方放大）；
• 标准差：\(\sigma(aX + b) = |a|\sigma(X)\)（恒为非负）。

数学期望 \(E(X)\) 中心位置

度量对象：随机变量的加权中心平均水平（重心）。

公式：\(E(X) = \sum x_i p_i\)。

运算：\(E(aX+b) = aE(X)+b\)（线性平移放缩）。

方差 \(D(X)\) 与标准差 \(\sigma\) 离散程度

度量对象：数据偏离重心的离散波动程度（风险）。

公式：\(D(X) = E(X^2) - [E(X)]^2\)。

运算：\(D(aX+b) = a^2 D(X)\)（常数 \(b\) 平移彻底消失）。

2. 期望与方差主公式与两点分布特征

核心公式与特殊分布：

数学期望：\(E(X) = \sum_{i=1}^n \color{#1976d2}{x_i} \cdot \color{#2e7d32}{p_i}\)

方差快捷算法：\(D(X) = \color{#d97706}{E(X^2)} - [\color{#ef4444}{E(X)}]^2 = \sum \color{#1976d2}{x_i^2}\color{#2e7d32}{p_i} - \mu^2\)

线性性质：\(E(aX+b) = aE(X)+b,\quad D(aX+b) = \color{#ef4444}{a^2} D(X),\quad \sigma(aX+b) = \color{#ef4444}{|a|}\sigma(X)\)

两点分布 \(X \sim B(1, p)\)：\(E(X) = p,\quad D(X) = p(1-p)\)

自己试试：\(X\) 取 \(1,2,3\) 的概率分别是 \(0.2,0.5,0.3\)。\(E(X)\) 是？

B。\(1\times0.2+2\times0.5+3\times0.3=0.2+1+0.9=2.1\)。选 A 的同学把 \(1,2,3\) 直接平均了，等于把三个概率都当成 \(\dfrac13\)；可 \(3\) 的概率 \(0.3\) 比 \(1\) 的 \(0.2\) 大，均值要往 \(3\) 那边偏一点。选 C 是只把取值加起来、没乘概率。

自己试试：\(X\) 取 \(1\) 和 \(3\)，概率各 \(0.5\)。\(D(X)\) 是？

A。\(E(X)=2\)，两个值离 \(2\) 都是 \(1\)，\(D(X)=1^2\times0.5+1^2\times0.5=1\)。或者 \(E(X^2)=\dfrac{1+9}2=5\)，\(D(X)=5-2^2=1\)。选 B 是偏离平方后忘了乘概率；选 C 是算成了 \(E(X^2)-E(X)\)，均值忘了平方；选 D 只算了 \(E(X^2)\)。

3. 三步破题思维链例题

典型例题：某投资人有两种投资方案。方案 A 的年收益率 \(X\)（万元）分布列为：\(P(X=-10)=0.2,\; P(X=10)=0.6,\; P(X=30)=0.2\)；方案 B 的年收益率 \(Y\)（万元）分布列为：\(P(Y=0)=0.3,\; P(Y=10)=0.4,\; P(Y=20)=0.3\)。
① 计算两方案的数学期望 \(E(X)\) 与 \(E(Y)\)；
② 计算两方案的方差 \(D(X)\) 与 \(D(Y)\)，并给出投资决策建议。

👀 第一眼破题信号： 期望反映平均收益水平，方差反映收益的风险波动度。解题次序：先由定义式算期望，再用定义或捷径公式算方差。
🔧 第二步求出数字特征数值：
• ① 计算期望：
\(E(X) = (-10)\times0.2 + 10\times0.6 + 30\times0.2 = -2 + 6 + 6 = 10\text{ 万元}\)；
\(E(Y) = 0\times0.3 + 10\times0.4 + 20\times0.3 = 0 + 4 + 6 = 10\text{ 万元}\)。
两方案期望相同，说明长期平均收益完全一致。
• ② 计算方差：
\(D(X) = (-10-10)^2\times0.2 + (10-10)^2\times0.6 + (30-10)^2\times0.2 = 400\times0.2 + 0 + 400\times0.2 = 160\)；
\(D(Y) = (0-10)^2\times0.3 + (10-10)^2\times0.4 + (20-10)^2\times0.3 = 100\times0.3 + 0 + 100\times0.3 = 60\)。
🛡️ 第三步双维度综合决策与防坑核查： 两方案期望收益均为 10 万元；但 \(D(X) = 160 > D(Y) = 60\)，说明方案 A 波动剧烈、可能面临亏损（-10 万元），风险极高；方案 B 波动小、不亏损、平稳度高。稳健型投资者应选择方案 B。防坑：切勿只比期望大小，高考大题常考期望相同时比方差！

自己试试：\(E(X)=3\)，\(D(X)=4\)，\(Y=-2X+1\)。\(\sigma(Y)\) 是？

B。\(\sigma(X)=\sqrt4=2\)，\(\sigma(Y)=|-2|\times2=4\)；或 \(D(Y)=(-2)^2\times4=16\)，开方得 \(4\)。选 A 把 \(-2\) 直接乘上去了，可标准差是非负平方根，不会是负数。C 是 \(D(Y)\)，还没开方。D 是把 \(E\) 的公式套到了 \(D\) 上：\(-2\times4+1\)。

4. 三大翻车现场红绿对比卡

翻车现场 1：把数学期望当成各取值的「算术平均数」，直接相加除以 \(n\)

❌ 翻车：\(X\) 取 1, 2, 3，概率分别为 0.2, 0.5, 0.3，直接算 \((1+2+3)/3 = 2\)。

✔ 正确：数学期望是加权平均数！每个值的权重是它发生的概率：\(E(X) = 1\times0.2 + 2\times0.5 + 3\times0.3 = 2.1\)！只有在各个值发生概率完全相等的特例下，期望才等于算术平均数。

翻车现场 2：线性变换算方差时常数项 \(b\) 盲目带入或漏平方

❌ 翻车：已知 \(D(X) = 4\)，求 \(D(3X - 5)\) 时写成 \(3\times4 - 5 = 7\) 或 \(3\times4 = 12\)。

✔ 正确：平移不改变离散离度，常数 \(b\) 彻底清零！倍数 \(a\) 必须平方！由方差定义，\(D(aX+b) = a^2 D(X)\)，故 \(D(3X-5) = 3^2 \times 4 = 36\)！常数 -5 毫无影响。

翻车现场 3：标准差写出负数（符号运算大意）

❌ 翻车：\(\sigma(X) = 2\)，算 \(\sigma(-3X + 2)\) 时直接写成 \(-3\times2 = -6\)。

✔ 正确：标准差作为算术平方根，恒为非负数！线性公式是 \(\sigma(aX+b) = |a|\sigma(X)\)，负号必须取绝对值：\(\sigma(-3X+2) = |-3|\times2 = 6\)。

反例微图解：方差线性平移不变性（D(X+b) = D(X)）直觉对比
整体平移 +b 只是把整个数据群在数轴上滑动，内部各点之间的相对距离完全不变，因此方差恒定！

① 分布列跷跷板：拖柱子改概率

\(X\) 取 \(1,2,3,4,5\)。上下拖某根柱子（或选中后按方向键）改它的概率，其余柱子按原来的比例自动让出，总和始终是 \(1\)。三角是支点 \(E(X)\)，金色带是 \(E(X)\pm\sigma\)。试试：把概率堆到两头，支点不动，方差却变大。

② 进阶：\(Y=aX+b\)，均值、方差怎么变

用的是①里现在的分布。上面一行是 \(X\)，下面一行是 \(Y=aX+b\)。动 \(b\)：整排柱子平移，波动带宽度不变；动 \(a\)：柱子拉开或挤拢，\(a\) 为负时左右翻过来，方差按 \(a^2\) 变。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(X\) 取 \(-1,0,2\) 的概率分别是 \(0.2,0.5,0.3\)。\(E(X)\) 是？

A。\((-1)\times0.2+0\times0.5+2\times0.3=-0.2+0+0.6=0.4\)。选 B 是把三个取值简单平均了；选 C 是漏了 \(-1\) 那一项的负号贡献。

2. \(E(X)=2\)，\(D(X)=3\)，\(Y=3X-1\)。\(E(Y)\) 和 \(D(Y)\) 分别是？

A。\(E(Y)=3\times2-1=5\)，\(D(Y)=3^2\times3=27\)。B 是 \(a\) 没平方；C 是把 \(-1\) 也减到了方差上，可平移不改变方差；D 是均值忘了 \(-1\)。

易错

3. 掷一个均匀骰子，点数为 \(X\)，\(E(X)=3.5\)。下面哪句话对？

B。均值是按概率加权的平均，说的是很多次的平均水平，它不一定是 \(X\) 能取到的值。A、C 都把「均值」当成了「某一次的结果」。

4. 一张刮刮卡卖 \(5\) 元：\(0.03\) 的机会中 \(100\) 元，\(0.1\) 的机会中 \(10\) 元，其余不中。买一张，净收益（奖金减去 \(5\) 元）的均值是？

B。净收益可能是 \(95\)、\(5\)、\(-5\) 元，概率 \(0.03\)、\(0.1\)、\(0.87\)：

\(95\times0.03+5\times0.1+(-5)\times0.87=2.85+0.5-4.35=-1\)。

也可以先算奖金均值 \(100\times0.03+10\times0.1=4\)，再减成本 \(5\)。A 忘了扣成本。C 把长期平均当成了每一次的结果：单买一张只会是 \(95\)、\(5\) 或 \(-5\)，不会正好是 \(-1\)。

5. 两个方案的收益（万元）：甲取 \(1\) 和 \(3\)，概率各 \(0.5\)；乙取 \(-2\) 的概率 \(0.2\)、取 \(3\) 的概率 \(0.8\)。小王的要求是「不能亏钱」。他该选？

A。均值确实都是 \(2\)：甲 \(1\times0.5+3\times0.5=2\)，乙 \(-2\times0.2+3\times0.8=2\)。可方差甲是 \(1\)，乙是 \(4\times0.2+9\times0.8-2^2=4\)，乙波动大，而且有 \(0.2\) 的机会亏 \(2\) 万。

小王的目标是不亏，甲最少也赚 \(1\) 万，选甲。C 只看了均值；B 只看了最好的结果。均值一样时，要看风险和目标。

挑战

6. \(E(X)=2\)，\(E(X^2)=5\)，\(Y=2X+3\)。\(E(Y^2)\) 是？

A。先求 \(D(X)=5-2^2=1\)。于是 \(E(Y)=2\times2+3=7\)，\(D(Y)=2^2\times1=4\)。再把 \(D(Y)=E(Y^2)-\big(E(Y)\big)^2\) 倒过来：\(E(Y^2)=4+7^2=53\)。

B 是把 \(E(Y^2)\) 当成了 \(\big(E(Y)\big)^2\)，差的正是方差。C 是把 \((2X+3)^2\) 展开成 \(4X^2+9\)，漏了中间项 \(12X\)：正确是 \(4\times5+12\times2+9=53\)。D 是把 \(E(aX+b)\) 的公式直接套到 \(X^2\) 上：\(4\times5+3\)。
