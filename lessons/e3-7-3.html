7.3 离散型随机变量的数字特征

分布列把一个随机变量的情况全列出来了，可表太长时，我们想用一两个数说清楚：平均能得多少？结果稳不稳？这就是均值和方差。

小店门口有个转盘：转一次，有 \(\dfrac1{10}\) 的机会得 \(10\) 元，\(\dfrac3{10}\) 的机会得 \(2\) 元，其余什么也没有。

转 \(100\) 次，大约 \(10\) 次得 \(10\) 元、\(30\) 次得 \(2\) 元、\(60\) 次没得。这 \(100\) 次一共大约得多少元？

B。\(10\times10+2\times30+0\times60=160\) 元。

平均每次大约 \(160\div100=1.6\) 元，也就是 \(10\times\dfrac1{10}+2\times\dfrac3{10}+0\times\dfrac6{10}=1.6\)：每个取值乘上它的概率再加起来。

这个「按概率加权的平均」就是本节的均值。注意 \(1.6\) 元一次也转不出来，它说的是转很多次之后的平均。光有平均还不够，每次得多得少差得大不大，要用方差来量。

1. 先认识几个词

要用到：分布列（回看 7.2）；样本的平均数和方差（回看必修二 9.2）。这一节就是把它们从「一组数据」搬到「一个随机变量」上。

分布列：随机变量 \(X\) 能取哪些值、各取到的概率是多少，列成一张表；概率都不是负数，加起来是 \(1\)。

例：上面的转盘，得到的钱 \(X\)：

\(X\)\(0\)\(2\)\(10\)
\(P\)\(0.6\)\(0.3\)\(0.1\)

\(0.6+0.3+0.1=1\)。

加权平均：每个数乘上自己的「分量」（权重），再加起来；权重加起来是 \(1\)。

例：平时成绩 \(80\) 分占 \(40\%\)，期末 \(90\) 分占 \(60\%\)，总评 \(80\times0.4+90\times0.6=86\) 分，不是 \(\dfrac{80+90}2=85\)。期末分量重，总评就偏向 \(90\)。

偏离：一个值离平均值有多远，写成 \(x-\mu\)（\(\mu\) 是平均值）。有正有负，所以要先平方再平均，正负才不会抵消。

例：平均值 \(\mu=3\)，取值 \(1\) 的偏离是 \(-2\)，平方是 \(4\)；取值 \(5\) 的偏离是 \(2\)，平方也是 \(4\)。不平方的话 \(-2+2=0\)，像是「没有偏离」。

单位：平方之后单位也跟着平方。\(X\) 以「元」计，偏离的平方就是「元²」；开平方才回到「元」。

例：偏离平方的平均是 \(4\) 元²，开方得 \(2\) 元，这才能和「平均 \(1.6\) 元」放在一起比。

2. 均值：按概率加权的平均

\(X\) 的分布列是 \(P(X=x_i)=p_i\)（\(i=1,2,\dots,n\)），定义

\(E(X)=x_1p_1+x_2p_2+\cdots+x_np_n=\displaystyle\sum_{i=1}^n x_ip_i\)

叫 \(X\) 的均值（也叫数学期望）。为什么这样算：做很多次试验，\(x_i\) 大约出现「次数 \(\times p_i\)」次，总和除以次数，就剩下 \(\sum x_ip_i\)。所以概率就是权重。

把分布列想成一根杆上挂的砝码：在 \(x_i\) 处挂 \(p_i\) 那么重，\(E(X)\) 就是杆能平衡的支点（「动手」①可以拖着看）。

例 1（看一遍怎么写）

小明投一次篮的得分 \(X\)：没进得 \(0\) 分，概率 \(0.3\)；两分球进得 \(2\) 分，概率 \(0.5\)；三分球进得 \(3\) 分，概率 \(0.2\)。求 \(E(X)\)。

先查概率和：\(0.3+0.5+0.2=1\)，表没问题。

\(E(X)=0\times0.3+2\times0.5+3\times0.2=0+1+0.6=1.6\)（分）。

意思：投很多次，平均每次约得 \(1.6\) 分。一次投篮得不了 \(1.6\) 分，这没关系，均值本来就不一定是能取到的值。

自己试试：\(X\) 取 \(1,2,3\) 的概率分别是 \(0.2,0.5,0.3\)。\(E(X)\) 是？

B。\(1\times0.2+2\times0.5+3\times0.3=0.2+1+0.9=2.1\)。选 A 的同学把 \(1,2,3\) 直接平均了，等于把三个概率都当成 \(\dfrac13\)；可 \(3\) 的概率 \(0.3\) 比 \(1\) 的 \(0.2\) 大，均值要往 \(3\) 那边偏一点。选 C 是只把取值加起来、没乘概率。

3. 方差和标准差：量波动

均值一样，结果可以很不一样：一个人每次都得 \(2\) 分，另一个人一半得 \(0\) 一半得 \(4\)，均值都是 \(2\)。区别在每次离均值远不远。把偏离平方，再按概率加权平均：

\(D(X)=\displaystyle\sum_{i=1}^n\big(x_i-E(X)\big)^2p_i=E(X^2)-\big(E(X)\big)^2\)
\(\sigma(X)=\sqrt{D(X)}\)

\(D(X)\) 叫方差，\(\sigma(X)\) 叫标准差，是方差的非负平方根，单位和 \(X\) 一样。方差、标准差越大，取值越分散，结果越不稳定。右边的 \(E(X^2)=\sum x_i^2p_i\)，用它算常常更省事。

例 2

接着例 1，求 \(D(X)\) 和 \(\sigma(X)\)。

按定义：\(E(X)=1.6\)，

\(D(X)=(0-1.6)^2\times0.3+(2-1.6)^2\times0.5+(3-1.6)^2\times0.2\)
\(=0.768+0.08+0.392=1.24\)（分²）。

换一种算：\(E(X^2)=0^2\times0.3+2^2\times0.5+3^2\times0.2=3.8\)，\(D(X)=3.8-1.6^2=3.8-2.56=1.24\)。两种一样。

\(\sigma(X)=\sqrt{1.24}\approx1.11\)（分）。

自己试试：\(X\) 取 \(1\) 和 \(3\)，概率各 \(0.5\)。\(D(X)\) 是？

A。\(E(X)=2\)，两个值离 \(2\) 都是 \(1\)，\(D(X)=1^2\times0.5+1^2\times0.5=1\)。或者 \(E(X^2)=\dfrac{1+9}2=5\)，\(D(X)=5-2^2=1\)。选 B 是偏离平方后忘了乘概率；选 C 是算成了 \(E(X^2)-E(X)\)，均值忘了平方；选 D 只算了 \(E(X^2)\)。

4. 把 \(X\) 变成 \(aX+b\)

常见情形：得分 \(X\) 换算成奖金，每分 \(a\) 元，再加（或减）固定的 \(b\) 元，得 \(Y=aX+b\)。

  • 加 \(b\)：每个取值都挪 \(b\)，支点跟着挪 \(b\)；可每个值离支点的距离没变，所以方差不变。
  • 乘 \(a\)：每个取值、连同支点都乘 \(a\)；离支点的距离变成 \(|a|\) 倍，平方后是 \(a^2\) 倍。
\(E(aX+b)=aE(X)+b\)，\(D(aX+b)=a^2D(X)\)，\(\sigma(aX+b)=|a|\,\sigma(X)\)

例 3

接着例 1：每得 \(1\) 分奖 \(5\) 元，每次投篮先交 \(2\) 元。一次的净收入 \(Y=5X-2\)（元）。求 \(E(Y)\)、\(D(Y)\)、\(\sigma(Y)\)。

\(E(Y)=5E(X)-2=5\times1.6-2=6\)（元）。

\(D(Y)=5^2D(X)=25\times1.24=31\)（元²）；\(-2\) 不影响方差。

\(\sigma(Y)=5\,\sigma(X)=5\sqrt{1.24}\approx5.57\)（元），也等于 \(\sqrt{31}\)。

自己试试：\(E(X)=3\)，\(D(X)=4\)，\(Y=-2X+1\)。\(\sigma(Y)\) 是？

B。\(\sigma(X)=\sqrt4=2\)，\(\sigma(Y)=|-2|\times2=4\)；或 \(D(Y)=(-2)^2\times4=16\)，开方得 \(4\)。选 A 把 \(-2\) 直接乘上去了，可标准差是非负平方根，不会是负数。C 是 \(D(Y)\)，还没开方。D 是把 \(E\) 的公式套到了 \(D\) 上：\(-2\times4+1\)。

5. 用均值、方差做判断时，记住五件事

  1. 概率是权重，不能把取值简单平均。
    反例：转盘的 \(0,2,10\) 简单平均是 \(4\) 元，可真实的长期平均只有 \(1.6\) 元——\(10\) 元只有 \(\dfrac1{10}\) 的机会。
  2. 均值不一定是能取到的值。
    反例：掷一个均匀骰子，点数的均值 \(\dfrac{1+2+\cdots+6}{6}=3.5\)，可没有哪次能掷出 \(3.5\)。
  3. 算「划不划算」要扣成本；均值是长期平均，不保证某一次。
    反例：花 \(2\) 元抽一次，\(0.01\) 的机会中 \(100\) 元。奖金均值 \(100\times0.01=1\) 元，扣掉成本，平均每次净亏 \(1\) 元。可某一次的结果只能是赚 \(98\) 元或亏 \(2\) 元，不会正好亏 \(1\) 元。
  4. 比较方案，均值和风险一起看。
    反例：方案甲每次稳得 \(2\) 万；方案乙一半机会得 \(6\) 万、一半机会亏 \(2\) 万。均值都是 \(2\) 万，乙的方差是 \(16\)，甲是 \(0\)。亏不起的人该选甲；先看清目标，再定标准。
  5. 标准差是非负平方根，单位和 \(X\) 相同；方差的单位是平方。
    反例：\(D(-3X)=9D(X)\)，\(\sigma(-3X)=3\sigma(X)\)，写成 \(-3\sigma(X)\) 就错了。
「均值大就选它」不一定对：先扣成本，再看方差（风险），最后看题目要的是什么。
再深一点（可以先跳过）

为什么 \(D(X)=E(X^2)-\big(E(X)\big)^2\)：记 \(\mu=E(X)\)，展开 \(\sum(x_i-\mu)^2p_i=\sum x_i^2p_i-2\mu\sum x_ip_i+\mu^2\sum p_i=E(X^2)-2\mu^2+\mu^2\)。用到了 \(\sum p_i=1\)。

两点分布：\(X\) 只取 \(1\)（概率 \(p\)）和 \(0\)（概率 \(1-p\)）。\(E(X)=p\)，\(E(X^2)=p\)，所以 \(D(X)=p-p^2=p(1-p)\)。\(p=0.5\) 时最大，是 \(0.25\)：成败各半时最难预测。

方差为 \(0\)：每一项 \((x_i-\mu)^2p_i\) 都不小于 \(0\)，加起来是 \(0\) 只能每项都是 \(0\)，也就是 \(X\) 其实只取一个值，没有波动。

两个随机变量相加：均值、方差的公式这里只讲了 \(aX+b\)。两个随机变量的和，方差一般不能直接把两个方差相加；什么情况下可以，要另有理由，以后用到再说。

① 分布列跷跷板：拖柱子改概率

\(X\) 取 \(1,2,3,4,5\)。上下拖某根柱子（或选中后按方向键）改它的概率，其余柱子按原来的比例自动让出，总和始终是 \(1\)。三角是支点 \(E(X)\)，金色带是 \(E(X)\pm\sigma\)。试试：把概率堆到两头，支点不动，方差却变大。

② 进阶：\(Y=aX+b\)，均值、方差怎么变

用的是①里现在的分布。上面一行是 \(X\)，下面一行是 \(Y=aX+b\)。动 \(b\)：整排柱子平移，波动带宽度不变；动 \(a\)：柱子拉开或挤拢，\(a\) 为负时左右翻过来，方差按 \(a^2\) 变。

从易到难排好了。前两道直接用，中间三道是最常见的错，最后一道是挑战。

直接用

1. \(X\) 取 \(-1,0,2\) 的概率分别是 \(0.2,0.5,0.3\)。\(E(X)\) 是？

A。\((-1)\times0.2+0\times0.5+2\times0.3=-0.2+0+0.6=0.4\)。选 B 是把三个取值简单平均了；选 C 是漏了 \(-1\) 那一项的负号贡献。

2. \(E(X)=2\)，\(D(X)=3\)，\(Y=3X-1\)。\(E(Y)\) 和 \(D(Y)\) 分别是？

A。\(E(Y)=3\times2-1=5\)，\(D(Y)=3^2\times3=27\)。B 是 \(a\) 没平方；C 是把 \(-1\) 也减到了方差上，可平移不改变方差；D 是均值忘了 \(-1\)。

易错

3. 掷一个均匀骰子，点数为 \(X\)，\(E(X)=3.5\)。下面哪句话对？

B。均值是按概率加权的平均，说的是很多次的平均水平，它不一定是 \(X\) 能取到的值。A、C 都把「均值」当成了「某一次的结果」。

4. 一张刮刮卡卖 \(5\) 元：\(0.03\) 的机会中 \(100\) 元，\(0.1\) 的机会中 \(10\) 元，其余不中。买一张，净收益（奖金减去 \(5\) 元）的均值是？

B。净收益可能是 \(95\)、\(5\)、\(-5\) 元，概率 \(0.03\)、\(0.1\)、\(0.87\)：

\(95\times0.03+5\times0.1+(-5)\times0.87=2.85+0.5-4.35=-1\)。

也可以先算奖金均值 \(100\times0.03+10\times0.1=4\)，再减成本 \(5\)。A 忘了扣成本。C 把长期平均当成了每一次的结果：单买一张只会是 \(95\)、\(5\) 或 \(-5\)，不会正好是 \(-1\)。

5. 两个方案的收益（万元）：甲取 \(1\) 和 \(3\)，概率各 \(0.5\)；乙取 \(-2\) 的概率 \(0.2\)、取 \(3\) 的概率 \(0.8\)。小王的要求是「不能亏钱」。他该选？

A。均值确实都是 \(2\)：甲 \(1\times0.5+3\times0.5=2\)，乙 \(-2\times0.2+3\times0.8=2\)。可方差甲是 \(1\)，乙是 \(4\times0.2+9\times0.8-2^2=4\)，乙波动大，而且有 \(0.2\) 的机会亏 \(2\) 万。

小王的目标是不亏，甲最少也赚 \(1\) 万，选甲。C 只看了均值；B 只看了最好的结果。均值一样时，要看风险和目标。

挑战

6. \(E(X)=2\)，\(E(X^2)=5\)，\(Y=2X+3\)。\(E(Y^2)\) 是？

A。先求 \(D(X)=5-2^2=1\)。于是 \(E(Y)=2\times2+3=7\)，\(D(Y)=2^2\times1=4\)。再把 \(D(Y)=E(Y^2)-\big(E(Y)\big)^2\) 倒过来：\(E(Y^2)=4+7^2=53\)。

B 是把 \(E(Y^2)\) 当成了 \(\big(E(Y)\big)^2\)，差的正是方差。C 是把 \((2X+3)^2\) 展开成 \(4X^2+9\)，漏了中间项 \(12X\)：正确是 \(4\times5+12\times2+9=53\)。D 是把 \(E(aX+b)\) 的公式直接套到 \(X^2\) 上：\(4\times5+3\)。
