2024 年福建预赛

F5解答题数论

设正整数 n 是合数，d1​,d2​,…,dk​ (k≥3) 是 n 的全部正因数，且

1=d1​<d2​<⋯<dk​=n.

对于 2≤i≤k−1，若 di​∤di−1​di+1​，则称 di​ 是 n 的一个“好因数”。 若 n 的“好因数”个数小于 n 的不同素因子个数，则称 n 为“好数”。

  1. (1)

    问：16,2024 是否为“好数”？

  2. (2)

    求所有的“好数”。

作答

这是解答题，请在纸上写出完整过程。写完后对照解答给自己评分。

解析

提示

先按不同素因子从小到大设置“门槛”：每个新素数之前的最大因数必是好因数，从而得到 r−1 个互异好因数。

思路

若至少有三个不同素因子，再研究最大素因子 P 以及 psP，证明二者至少一个 还能提供额外的好因数。最后只需完整分析含一、两个不同素因子的情形。

解答

设 n 的不同素因子为

p1​<p2​<⋯<pr​.

对 1≤j<r，令 Dj​ 为小于 pj+1​ 的最大正因数。则 Dj​ 的后一个因数正是 pj+1​。又因 Dj​<pj+1​，Dj​ 的素因子都小于 pj+1​，所以 gcd(Dj​,pj+1​)=1。若 Ej​ 是 Dj​ 的前一个因数，而 Dj​∣Ej​pj+1​，便会推出 Dj​∣Ej​，与 Ej​<Dj​ 矛盾。因此 D1​,…,Dr−1​ 是 r−1 个互不相同的好因数。以下把这一结论记为（1）。

下面证明当 r≥3 时还至少有一个好因数。记

p=p1​,q=p2​,P=pr​,D1​=x=ps.

这里 s≥1，且小于 q 的因数只有 1,p,…,ps。 若 P 本身是好因数，结论已经成立。以下设 P 不是好因数。

因 P 的前一个因数不含素因子 P，要使 P 整除前后两个因数之积，P 的后一个因数必须含 P。 大于 P 的最小 P 倍因数是 pP，所以 P,pP 在因数序列中相邻。我们断言 xP 是好因数。 设 U,V 分别是 xP 的前、后一个因数，反设 xP∣UV。由于 P∣UV，分两种情形。

若 P∣V，则因 q 是大于 x 的最小因数，必有 V=qP。于是 x∣Uq，而 gcd(x,q)=1，故 U=xw，其中 w<P。因 pw∣U∣n， 并且 P,pP 相邻，pw 不可能严格落在二者之间；又 pw=P 不可能，故 pw<P。 从而

U=xw<pxP​.

但 (x/p)P 是一个小于 xP 的因数，这与 U 是其前一个因数矛盾。

若 P∣U，则小于 x 的最大因数为 x/p，故

U=pxP​.

由 xP∣UV 得 p∣V。若还成立 P∣V，则 V 只能是 qP，但 p∤qP，矛盾；所以 P∤V。写 V=pw，则 w 也是 n 的因数，并且

U<w<V.

在因数序列中，U,xP,V 三者相邻，故只能有 w=xP，这又会推出 P∣V，仍矛盾。 两种情形都不可能，故 xP∤UV，即 xP 是好因数。

由（1），当 r≥3 时，好因数至少有 r 个，因而 n 不是好数。于是只需考虑 r=1 或 r=2。

若 r=1，则 n=pα (α≥2)。相邻三个因数 pi−1,pi,pi+1 满足 pi∣pi−1pi+1，所以没有好因数； 0<1，故所有素数幂 pα (α≥2) 都是好数。

若 r=2，写

n=pαqβ,p<q,α,β≥1.

设 ps<q<ps+1，其中当 q>pα 时约定 s=α。 前面的论证已说明 ps 是好因数。

当 q<pα 时，q 的前后两个因数分别是 ps,ps+1，它们的乘积不含素因子 q， 故 q 也是好因数，此时不是好数。

当 q>pα 且 β≥2 时，因数 pαq 的前后两个因数分别是 pα−1q,q2，其乘积不被 pαq 整除，所以除 pα 外又有一个好因数， 此时也不是好数。

最后，当 q>pα 且 β=1 时，全部因数依次为

1,p,…,pα,q,pq,…,pαq.

逐段检查可知，只有交界处的 pα 是好因数，其余内部因数都整除相邻两因数之积。 此时恰有一个好因数，小于两个不同素因子的个数，所以是好数。

综上，所有好数恰为

pα (α≥2)​

以及

pαq(p<q 为素数, α≥1, q>pα)​.

对第（1）问，16=24 是好数。另一方面，

2024=23⋅11⋅23

有三个不同素因子，故不是好数。直接列出其因数还能核得好因数为

8,22,23,44,46,88,184,

共有七个。

复核

分类中的充分性已逐个检查全部因数段；必要性不仅给出 r−1 个门槛好因数，还在 r≥3 时 严格构造了与它们不同且不小于 P 的额外好因数。边界 α=1 也包含在第二族中，得到所有半素数 pq。

方法总结

排序因数的局部整除条件可在“新素数首次出现”的门槛处制造反例；当门槛计数还差一个时， 利用最大素因子及其最小倍数的相邻性继续逼出额外好因数。最后按不同素因子个数分类，能把全局问题降为两条显式因数链。

为什么评为 F5（会透露解法方向）

须构造r减1个门槛好因数，并为r至少3时另造不重合的好因数，再按素数幂间的大小关系完成全部分类。
