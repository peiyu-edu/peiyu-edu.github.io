2021 年福建预赛

P006973 · 椭圆

已知椭圆

C:a2x2​+b2y2​=1(a>b>0)

的离心率为 2/3，A1​,A2​ 分别为椭圆 C 的左、右顶点，B 为椭圆 C 的上顶点， F1​ 为椭圆 C 的左焦点，且 △A1​F1​B 的面积为 5​/2。

（1）求椭圆 C 的方程；

（2）设过点 D(1,0) 的动直线 l 交椭圆 C 于 E,F 两点（点 E 在 x 轴上方）， M,N 分别为直线 A1​E,A2​F 与 y 轴的交点。求 ∣OM∣/∣ON∣ 的值。

两题都先把投影到固定直线后的截距写成椭圆端点参数的分式，再利用两端点同属一条过定点的割线消去自由参数。常用的是端点参数的和、积关系，而不是分别求出两个交点。

一题用半角参数把距离变成正参数并排除重合分支，另一题用横坐标韦达关系处理有向截距比，还须单查竖直线。
