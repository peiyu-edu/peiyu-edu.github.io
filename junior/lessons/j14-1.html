14.1 全等三角形及其性质

两个三角形「一模一样」，到底是什么意思？能叠在一起完全重合，就叫全等。这一节学会读「≌」这个记号，从记号里直接读出谁和谁相等。

本节导读　先修：13.1、13.3、7.4 · 本节路线

要用到：三角形的边、角和记法（回看 13.1）；三角形内角和是 \(180^\circ\)（回看 13.3）；平移不改变图形的形状和大小（回看 7.4）。

  1. 从剪小旗进入：什么样的两个图形能完全重合。
  2. 认识全等形、全等三角形；平移、翻折、旋转前后的图形全等。
  3. 读懂记号「≌」：字母的位置就是对应关系。
  4. 全等三角形的性质：对应边相等，对应角相等。
  5. 用性质求边、求角，学会「整体看」：减去公共部分。
  6. 练习与中考真题，回看最容易看走眼的地方。

美术课要剪一批三角形小旗。老师先剪好一面样旗（下图涂色的），同学们剪了甲、乙、丙三面。点按钮，把每一面拿过来往样旗上叠：

哪一面小旗能和样旗完全重合？

C。丙翻个面就能和样旗叠得严丝合缝：翻面只改变了位置，形状、大小都没变。甲形状一样但大了一圈；乙面积一样，可形状不同。两者都叠不严。

像样旗和丙这样能够完全重合的两个图形，就是这一节的主角。要回答的是：怎么用符号写「完全重合」？重合之后，能得出哪些边、哪些角相等？

1. 先认识几个词：全等形、全等三角形、对应元素

前置知识：三角形的顶点、边、角（回看 13.1），平移（回看 7.4）。

全等形：能够完全重合的两个图形。全等三角形：能够完全重合的两个三角形。叠在一起的顶点叫对应顶点，叠在一起的边叫对应边，叠在一起的角叫对应角。

一个三角形经过平移、翻折、旋转，位置变了，形状、大小都不变，所以前后两个三角形全等。下面用同一种颜色标出对应顶点：

直觉微图解 ①动一动，位置变了，形状大小不变

记号：「全等」用「≌」表示，读作「全等于」。\(\triangle ABC\) 和 \(\triangle DEF\) 全等，A 和 D、B 和 E、C 和 F 是对应顶点，就写成 \(\triangle ABC\cong\triangle DEF\)。对应顶点的字母要写在对应的位置上，本站一律这样写。

核心概念 ②字母的位置就是「对号入座」

\(\triangle ABC\cong\triangle DEF\)：左边第 1 个字母对右边第 1 个，第 2 个对第 2 个，第 3 个对第 3 个。对应边就是 AB 与 DE、BC 与 EF、CA 与 FD，对应角是 ∠A 与 ∠D、∠B 与 ∠E、∠C 与 ∠F。不看图也能读出来。

核心概念 ③「对应边」不是「对边」

对应边、对应角说的是两个三角形之间谁和谁叠在一起；对边、对角说的是同一个三角形里边和角的位置，比如 \(\triangle ABC\) 中 ∠A 的对边是 BC。

2. 核心点：从记号读出对应

写全等式，就是把「谁和谁重合」一次说清。右边的三角形是左边的绕图中心转半圈得到的，两个三角形全等，图上同色的是对应顶点。三种写法，哪一种说对了？

直觉微图解 ②按字母位置连线：同色才算连对

试着用四步想问题：读懂题意 → 想办法 → 执行并检查 → 回头看。卡住时按需展开提示。

例 1（示范：跟老师走一遍思考过程）

已知 \(\triangle PQR\cong\triangle XYZ\)，\(PQ=QR=7\)，\(\angle P=52^\circ\)，\(\angle Y=76^\circ\)。求 XY、YZ 的长和 ∠Z 的度数。

① 读懂题意：没有图，只有一个全等式。第一件事做什么？

提示 1：先配对

按字母位置写出三对对应顶点：P 和 X，Q 和 Y，R 和 Z。

看完整示范
② 想办法：XY 由第 1、2 个字母组成，对应左边的 PQ；YZ 对应 QR。∠Z 不能直接对过去（∠R 不知道），要在 \(\triangle XYZ\) 里用内角和。
③ 执行：\(XY=PQ=7\)，\(YZ=QR=7\)；\(\angle X=\angle P=52^\circ\)，在 \(\triangle XYZ\) 中，\(\angle Z=180^\circ-52^\circ-76^\circ=52^\circ\)。
执行中检查：∠Y 是 \(\triangle XYZ\) 的角，它对应 ∠Q，不对应 ∠P；求 ∠Z 用的三个角都在同一个三角形里 ✓；\(\angle X=\angle Z\)，它们的对边 YZ、XY 也一样长，数据前后相容 ✓。

④ 回头看：写理由的格式：∵ \(\triangle PQR\cong\triangle XYZ\)，∴ \(XY=PQ=7\)，\(\angle X=\angle P\)（全等三角形的对应边相等，对应角相等）。

自己试试：\(\triangle MNK\cong\triangle STU\)。下面哪一对是对应边？

B。N 是左边第 2 个、K 是第 3 个，右边第 2、3 个是 T、U，所以 NK 对 TU。A：MN 对的是 ST；C、D：MK 对的是 SU。

3. 核心点：全等三角形的性质

完全重合，叠在一起的边当然一样长，叠在一起的角当然一样大。这就是全等三角形的性质，由定义直接得到：

\(\color{#2F7A56}{\underbrace{\triangle ABC\cong\triangle DEF}_{\text{已知全等}}}\Rightarrow\color{#966524}{\underbrace{AB=DE,\ BC=EF,\ CA=FD}_{\text{对应边相等}}},\ \color{#B5452F}{\underbrace{\angle A=\angle D,\ \angle B=\angle E,\ \angle C=\angle F}_{\text{对应角相等}}}\)

方向别弄反：这是先知道全等，再得出边、角相等。怎样判断两个三角形全等，是下一节的事。

用性质求线段时，常常要「整体看」：两个全等三角形有一段重叠，对应边相等，去掉公共部分，剩下的也相等。

直觉微图解 ③沿直线平移：两条 BC、EF 一样长，去掉公共的 EC

例 2（示范：整体看线段）

把 \(\triangle ABC\) 沿直线 \(l\) 平移得到 \(\triangle DEF\)，点 B、E、C、F 依次在 \(l\) 上（像微图解 ③ 那样）。量得 \(BF=11\)，\(EC=3\)。求平移的距离 BE 和 BC 的长。

① 读懂题意：平移前后的两个三角形是什么关系？BF 由哪几段组成？

提示 1：先写全等

平移不改变形状和大小，\(\triangle ABC\cong\triangle DEF\)，所以 \(BC=EF\)。

提示 2：去掉公共部分

BC 和 EF 都包含 EC。\(BE=BC-EC\)，\(CF=EF-EC\)，所以 \(BE=CF\)。

看完整示范
② 想办法：设 \(BE=CF=x\)，BF 是三段之和：\(BF=BE+EC+CF\)。
③ 执行：\(x+3+x=11\)，\(x=4\)。平移的距离 \(BE=4\)，\(BC=BE+EC=4+3=7\)。
执行中检查：\(4+3+4=11\) ✓；\(EF=EC+CF=3+4=7=BC\) ✓。

④ 回头看：「对应边相等，减去公共部分，剩下的也相等」是全等题里很常用的一步，角也一样可以这样减。

自己试试：\(\triangle ABC\cong\triangle DEF\)，\(\angle A=48^\circ\)，\(\angle E=75^\circ\)。∠F 是多少度？

B。\(\angle D=\angle A=48^\circ\)，在 \(\triangle DEF\) 中，\(\angle F=180^\circ-48^\circ-75^\circ=57^\circ\)。A 是把 ∠F 当成了 ∠A 的对应角（∠A 对的是 ∠D）；D 是只减了 ∠E，忘了 ∠D。

例 3（示范：整体看角）

如图，\(\triangle ABC\cong\triangle ADE\)，射线 AB、AD、AC、AE 依次排列。已知 \(\angle BAE=110^\circ\)，\(\angle DAC=40^\circ\)，求 ∠BAD。

提示：哪两个大角相等？

∠BAC 和 ∠DAE 是对应角。它们都包含 ∠DAC。

看完整示范
想办法：∵ \(\triangle ABC\cong\triangle ADE\)，∴ \(\angle BAC=\angle DAE\)。两边同时减去 ∠DAC，得 \(\angle BAD=\angle CAE\)。
执行：\(\angle BAE=\angle BAD+\angle DAC+\angle CAE\)，即 \(2\angle BAD+40^\circ=110^\circ\)，\(\angle BAD=35^\circ\)。
检查：\(35^\circ+40^\circ+35^\circ=110^\circ\) ✓；\(\angle BAC=35^\circ+40^\circ=75^\circ=\angle DAE\) ✓。

再试一个：例 3 中，如果改成 \(\angle BAE=140^\circ\)，\(\angle DAC=30^\circ\)，∠BAD 是多少度？

A。\(2\angle BAD+30^\circ=140^\circ\)，\(\angle BAD=55^\circ\)。B 是 \(140^\circ-30^\circ\) 后忘了除以 2；C 是 \(140^\circ\div2\)，没减中间的 ∠DAC；D 是先把 \(140^\circ\) 平分成 \(70^\circ\)，再减去 \(30^\circ\)：中间的 ∠DAC 不该从一半里扣。

4. 用之前必查：三大翻车现场

翻车现场 ①字母顺序随手写
❌ 典型错解：A 和 E、B 和 D、C 和 F 是对应顶点，写成「\(\triangle ABC\cong\triangle DEF\)」，觉得反正都是这几个字母。
✅ 一眼看清：这样写说的是 A↔D、B↔E，意思全变了：按它会把 AC 的对应边读成 DF，实际应是 EF。应写 \(\triangle ABC\cong\triangle EDF\)。
翻车现场 ②（最高频！）按「摆的位置」找对应
❌ 典型错解：右边的三角形是左边翻折过来的，\(\triangle ABC\cong\triangle DEF\)。「B 在左下角，F 也在左下角，所以 ∠B = ∠F。」
✅ 看图秒懂：翻折后左右颠倒，和 ∠B 相等的是标同样记号的 ∠E。找对应看记号、看角的大小和边的长短，不看摆放位置。
翻车现场 ③形状相同、面积相等就说全等
❌ 典型错解：「两个三角形形状一模一样，所以全等。」「两个三角形面积都是 6，所以全等。」
✅ 一眼看清：按比例放大后形状相同、大小不同，叠不严；两条直角边分别是 4、3 和 6、2 的两个直角三角形，面积都是 6，却不能重合。全等要形状、大小都相同。
再深一点（可以先跳过）：翻折会把「转向」倒过来

沿 \(\triangle ABC\) 按 A→B→C 走一圈，如果是顺时针，那么平移或旋转后的 \(\triangle DEF\) 按 D→E→F 走，也是顺时针；翻折后的就变成逆时针了。所以翻折得到的两个全等三角形，对应顶点看起来常常「左右颠倒」。「动手」② 里可以亲手试：方向反了，怎么转都叠不上，必须先翻一次。

全等形不只是三角形：两枚同版的邮票、两片同一模具压出的饼干都是全等形。这一章只研究三角形。

① 改变形状，对应边、对应角始终相等

拖动 \(\triangle ABC\) 的三个顶点（或点一下顶点再用方向键）。右边的 \(\triangle DEF\) 是它绕图中心转半圈得到的，会跟着变。看读数。

② 进阶：把它叠上去

绿色的 \(\triangle ABC\) 不动。拖中间的圆点平移 \(\triangle DEF\)（选中后方向键每次 10 格）；拖外侧的小圆点旋转（方向键每次 15°）；需要时点「翻折」。叠严了，读数会告诉你谁落在谁上。图形靠到框边、或旋转、翻折后会超出框时，会自动移回框内。

从易到难排好了。卡住时先展开提示。

直接用

1. \(\triangle ABC\cong\triangle DEF\)，\(AB=5\)，\(BC=7\)，\(CA=6\)。\(\triangle DEF\) 的周长和 EF 的长分别是多少？

A。三条对应边分别相等，周长也是 \(5+7+6=18\)。E、F 是第 2、3 个字母，对应 B、C，所以 \(EF=BC=7\)。B 是把 EF 对成了 CA，C 是对成了 AB。

2. \(\triangle GHK\cong\triangle PQR\)，\(\angle G=35^\circ\)，\(\angle Q=100^\circ\)。∠R 是多少度？

B。\(\angle P=\angle G=35^\circ\)，在 \(\triangle PQR\) 中，\(\angle R=180^\circ-35^\circ-100^\circ=45^\circ\)。D 是只减了 \(35^\circ\)；A、C 是把 ∠R 错对成了 ∠G 或 ∠Q。

易错

3. 两个全等三角形中，A 和 F、B 和 D、C 和 E 是对应顶点。下面写法正确的是哪一个？

提示

左边写 \(\triangle ABC\)，右边第 1 个位置放 A 的对应点，第 2 个放 B 的，第 3 个放 C 的。

B。A 对 F、B 对 D、C 对 E，依次写成 \(\triangle ABC\cong\triangle FDE\)。A 是按字母表顺序写的（翻车现场 ①）；C 把 B、C 的对应点写反了；D 三个都错了位。

4. 下面说法正确的是哪一个？

D。全等就能完全重合，周长、面积当然相等。反过来不行：边长 3、4、5 和边长 4、4、4 的三角形周长都是 12，却不能重合；形状相同的还可能一大一小；面积见翻车现场 ③。

5. \(\triangle PQR\cong\triangle RSP\)（PR 是公共边）。下面哪个结论不一定成立？

提示

逐个字母配对：P 对 R，Q 对 S，R 对 P。公共边 PR 自己对自己（位置换了）。

D。对应关系 P↔R、Q↔S、R↔P：PQ 对 RS，QR 对 SP，∠QPR（顶点 P）对 ∠SRP（顶点 R）。PQ 和 PS 不是一对对应边，不能说相等。这种「公共边自己换位」的写法最容易看走眼，要一个字母一个字母地对。

挑战

6. 把 \(\triangle ABC\) 沿 BC 方向平移得到 \(\triangle DEF\)，B、E、C、F 依次在同一直线上。已知 \(BC=8\)，\(CF=3\)，\(\angle A=70^\circ\)，\(\angle B=45^\circ\)。EC 的长和 ∠F 的度数分别是多少？

提示 1：EC 怎么算

\(EF=BC=8\)，EF 由 EC 和 CF 两段组成。

提示 2：∠F 对应谁

F 是 \(\triangle DEF\) 的第 3 个字母，对应 \(\triangle ABC\) 的 C。先在 \(\triangle ABC\) 里求 ∠ACB。

A。\(EC=EF-CF=8-3=5\)；\(\angle F=\angle ACB=180^\circ-70^\circ-45^\circ=65^\circ\)。B 把 ∠F 对成了 ∠B；C 把 EC 当成和 CF 一样长；D 是把 BC、CF 加起来，又把 ∠F 对成了 ∠A。

已知全等、求边求角，是中考的常见小题。选择题点选项自动判对错，做完看解析。
